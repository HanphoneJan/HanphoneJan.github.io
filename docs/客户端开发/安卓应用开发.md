## 环境

### Android Studio

[Android Studio 安装配置教程 - Windows](https://blog.csdn.net/qq_38436214/article/details/105073213)

安装向导里的 SDK 检测那一步可以跳过，装完在 SDK Manager 里补：

- **SDK Platforms**：至少勾一个目标 API（如 API 35）
- **SDK Tools**：`Android SDK Build-Tools`、`Android SDK Command-line Tools`、`Google USB Driver`（真机调试）
- **JDK**：AS 自带的 JBR 就够，在 `Settings → Build, Execution, Deployment → Build Tools → Gradle` 里能看到用的是哪一个

### Gradle 下载镜像

新建项目后第一次同步会去 `services.gradle.org` 下 Gradle，国内经常超时。改 `gradle/wrapper/gradle-wrapper.properties`：

```properties
distributionUrl=https\://mirrors.cloud.tencent.com/gradle/gradle-8.9-bin.zip
```

可用镜像：

```text
https://mirrors.cloud.tencent.com/gradle/
https://mirrors.aliyun.com/macports/distfiles/gradle/
```

Maven 依赖的镜像在项目级 `settings.gradle.kts` 的 `pluginManagement` 与 `dependencyResolutionManagement` 里换阿里云。

### 代理

走了本机代理（如 `127.0.0.1:7890`）时，要同时告诉 AS 和 Gradle：

- **AS**：`Settings → Appearance & Behavior → System Settings → HTTP Proxy`，填 `127.0.0.1` 与端口
- **Gradle**：项目根目录或 `~/.gradle/gradle.properties` 里

```properties
systemProp.http.proxyHost=127.0.0.1
systemProp.http.proxyPort=7890
systemProp.https.proxyHost=127.0.0.1
systemProp.https.proxyPort=7890
```

关掉代理时，把这两处的配置一起删，只删一处会出现「AS 能下、Gradle 不能下」或反过来。

### 把 SDK 与缓存挪出 C 盘

1. 复制 `.android` 文件夹到新位置（如 `D:\Android\Config`），路径不要有中文和空格
2. 新增环境变量 `ANDROID_SDK_HOME`，值为这个新路径
3. 打开 `C:\Users\<用户名>\.android\avd\*.ini`，把 `path=` 改成新路径
4. `Settings → Build, Execution, Deployment → Build Tools → Gradle` 里把 Gradle user home 也指到 D 盘
5. 重启 AS，旧的 `.gradle` 确认没被占用后再删

## 项目结构

```text
app/src/main/
├── java/<包名>/        # 代码：Activity、ViewModel、Repository
├── res/
│   ├── layout/        # 布局 XML
│   ├── values/        # strings.xml、colors.xml、themes.xml
│   ├── drawable/      # 图片与 shape；SVG 放进来 AS 会转成 vector drawable
│   └── mipmap-*/      # 应用图标
└── AndroidManifest.xml # 组件声明、权限、应用基本信息
```

- `res/values`：字符串、颜色、主题这类常量的集中处，代码里用 `R.string.xxx` 引用
- `res/drawable`：图标与背景，XML shape 也放这里
- `res/mipmap`：只放 launcher icon
- `AndroidManifest.xml`：Activity 必须在这里注册，否则启动就 `ActivityNotFoundException`

**分区存储**（Android 10 / API 29 起）：应用不能再按绝对路径读写公共目录。共享文件要用 `FileProvider` 暴露成 `content://` URI，而不是把 `filesDir` 的路径直接交给别的应用。

## Gradle 依赖

依赖声明在模块级 `app/build.gradle.kts`：

```kotlin
dependencies {
    implementation("androidx.core:core-ktx:1.13.1")
    implementation("androidx.appcompat:appcompat:1.7.0")
    implementation("com.google.android.material:material:1.12.0")
    testImplementation("junit:junit:4.13.2")
}
```

- `implementation`：只对当前模块可见；`api`：传递给依赖它的模块（库项目才用）
- 默认仓库是 Maven Central + Google，国内换成阿里云镜像会快很多
- 版本冲突先看 `./gradlew :app:dependencies` 的依赖树，再用 `resolutionStrategy` 或 BOM 统一

## MVVM

```text
Activity / Fragment（View）
        │ observe
        ▼
ViewModel（状态与业务逻辑，不带 View 引用）
        │
        ▼
Repository（网络 / 数据库）
```

- **ViewModel** 的生命周期比 Activity 长，屏幕旋转时不会重建，数据不会丢
- **LiveData** 由 ViewModel 持有，View 层 `observe`；主线程用 `setValue`，子线程用 `postValue`
- **Fragment** 是可复用的 UI 片段，有自己的生命周期，可以挂在多个 Activity 上
- 服务器返回的 JSON 先用 `kotlinx.serialization` 或 Gson 转成实体类再给 ViewModel

## UI

AS 右上角可以在 **Code / Design** 两种视图间切换，Design 里能直接拖控件，复杂布局仍然手写 XML 更快。

- **ConstraintLayout**：用约束定位，层级浅，复杂布局优先用它，避免嵌套多层 `LinearLayout`
- **RecyclerView**：列表用这个，不要用 `ListView`
- **Compose**：新项目可以考虑，声明式 UI，与 XML 体系并存

### 尺寸单位

| 单位 | 含义 | 用在哪 |
|---|---|---|
| `px` | 屏幕物理像素 | 基本不用 |
| `dp` / `dip` | 设备独立像素，160 dpi 下 1dp = 1px | 宽高、间距、边距 |
| `sp` | 缩放像素，跟随系统字体大小 | 文字 |

`dp` 类似 Web 的 `em`：同样写 `16dp`，在不同密度屏幕上物理大小接近，而不是像素数相同。文字必须用 `sp`，否则用户在系统里调大字体时你的文字不会跟着变。

## 打包

`Build → Generate Signed Bundle / APK`：

- **APK**：直接安装、分发用
- **AAB**：上架 Google Play 用，由商店按设备拆分

签名文件（`.jks`）与口令自己保管，不要写进仓库。首次打包时创建 keystore，之后每次复用同一个，换签名会导致已安装用户无法覆盖升级。

### AVD 起不来

点启动只弹一个 `xxxx terminal` 之类的提示、没有其他错误，而且时好时坏：多半是 Hyper-V 占了端口。用管理员权限执行：

```bash
net stop winnat
net start winnat
```

再启动模拟器。
