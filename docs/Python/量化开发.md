## 零、金融市场基础理论

> **学习目标**：理解证券市场运作原理、价格形成机制、收益与风险的本质

### 0.1 证券市场基本概念

#### 0.1.1 什么是股票？

**股票（Stock）** 是股份公司发行的所有权凭证。持有股票意味着：

1. **所有权**：成为公司的股东，享有公司利润分配权
2. **收益权**：通过股息（分红）和资本利得（价差）获利
3. **投票权**：参与公司重大决策
4. **有限责任**：最大损失为投资本金

**股票价格的影响因素：**

```
股票价格 = f(公司基本面, 市场情绪, 宏观经济, 行业趋势, 资金流动)
```

- **基本面**：盈利能力、成长性、财务健康度
- **市场情绪**：投资者信心、恐慌指数
- **宏观经济**：GDP增长、利率、通胀
- **行业趋势**：政策导向、技术变革
- **资金流动**：北向资金、机构持仓

#### 0.1.2 交易机制

**A股交易规则：**

| 要素 | 规则 |
|------|------|
| 交易时间 | 9:30-11:30, 13:00-15:00 |
| 涨跌幅限制 | 主板±10%，科创板/创业板±20%，ST股票±5%，北交所±30% |
| 最小交易单位 | 1手 = 100股 |
| 交易费用 | 佣金（万2.5-万3）+ 印花税（0.05%，仅卖出）+ 过户费（0.001%） |
| T+1制度 | 当天买入的股票次日才能卖出 |

**订单类型：**

- **市价单（Market Order）**：以当前最优价格立即成交
- **限价单（Limit Order）**：指定价格，价格达到时成交
- **止损单（Stop Order）**：价格触及止损线时自动卖出

#### 0.1.3 K线图基础

**K线（蜡烛图）** 是记录价格变动的图表，每根K线包含四个价格：

```
最高价 ─┐
        │  ┌─ 实体（开盘价和收盘价之间）
收盘价 ─┤  │  - 红色/阳线：收盘价 > 开盘价（上涨）
开盘价 ─┘  │  - 绿色/阴线：收盘价 < 开盘价（下跌）
        │  └─ 影线（最高/最低价的延伸）
最低价 ─┘
```

**常见K线形态的含义：**

| 形态 | 特征 | 含义 |
|------|------|------|
| 大阳线 | 长实体，几乎没有上下影线 | 强烈上涨信号 |
| 大阴线 | 长实体，几乎没有上下影线 | 强烈下跌信号 |
| 十字星 | 开盘价≈收盘价，有上下影线 | 趋势可能反转 |
| 锤子线 | 小实体，长下影线 | 底部反转信号 |
| 流星线 | 小实体，长上影线 | 顶部反转信号 |

### 0.2 价格形成机制

#### 0.2.1 供需理论

股票价格由**供给**和**需求**决定：

$$
价格 P = \frac{需求量 D}{供给量 S}
$$

- **需求增加** → 买盘强劲 → 价格上涨
- **供给增加** → 卖盘压力 → 价格下跌

**影响供需的因素：**

```
需求因素：
├─ 企业盈利预期上升
├─ 行业景气度提升
├─ 市场流动性充裕（降息、宽松政策）
└─ 投资者信心增强

供给因素：
├─ 限售股解禁
├─ 大股东减持
├─ IPO/增发扩容
└─ 投资者恐慌性抛售
```

#### 0.2.2 价格发现过程

交易所通过**连续竞价**实现价格发现：

1. **集合竞价**（9:15-9:25）：所有订单汇总，按"价格优先、时间优先"原则撮合
2. **连续竞价**（9:30-15:00）：实时撮合买卖订单

**成交原则：**

```
买入订单：价格从高到低排列
卖出订单：价格从低到高排列

成交价 = 使成交量最大的价格
```

### 0.3 市场有效性假说

#### 0.3.1 有效市场假说（EMH）

**核心观点**：市场价格已经充分反映了所有可获得的信息。

**三种形态：**

| 形态 | 信息范围 | 推论 | 对量化交易的启示 |
|------|----------|------|------------------|
| 弱式有效 | 历史价格 | 技术分析无效 | 需要结合其他信息 |
| 半强式有效 | 公开信息 | 基本面分析无效 | 寻找信息优势 |
| 强式有效 | 所有信息（含内幕） | 任何分析都无效 | 市场并非完全有效 |

**实际情况**：

- 市场**并非完全有效**，存在：
  - **信息不对称**：散户vs机构投资者
  - **行为偏差**：羊群效应、过度反应、损失厌恶
  - **流动性差异**：大盘股vs小盘股
  - **交易摩擦**：手续费、滑点、冲击成本

#### 0.3.2 行为金融学

**人性弱点影响决策：**

| 偏差 | 表现 | 对交易的影响 |
|------|------|--------------|
| 损失厌恶 | 亏损的痛苦 > 盈利的快乐 | 过早止盈、死守亏损 |
| 过度自信 | 高估自己的判断能力 | 过度交易、忽视风险 |
| 锚定效应 | 过度依赖初始信息 | 无法适应市场变化 |
| 羊群效应 | 跟随大众决策 | 追涨杀跌 |
| 确认偏差 | 只看支持自己观点的信息 | 忽视风险信号 |

**量化交易的优势**：用程序化交易消除情绪干扰。

### 0.4 收益与风险的量化

#### 0.4.1 收益率的计算

**简单收益率（Simple Return）：**

$$
R_t = \frac{P_t - P_{t-1}}{P_{t-1}} = \frac{P_t}{P_{t-1}} - 1
$$

**对数收益率（Log Return）：**

$$
r_t = \ln\left(\frac{P_t}{P_{t-1}}\right) = \ln(P_t) - \ln(P_{t-1})
$$

**为什么用对数收益率？**

优势：
1. **可加性**：多期收益 = 各期对数收益之和
2. **时间可比性**：不同时间段收益率可直接比较
3. **统计性质好**：更接近正态分布

```python
import numpy as np
import pandas as pd

## 计算收益率
prices = pd.Series([100, 102, 105, 103, 108])

## 简单收益率
simple_return = prices.pct_change()
print("简单收益率:", simple_return)

## 对数收益率
log_return = np.log(prices / prices.shift(1))
print("对数收益率:", log_return)

## 累计收益
cumulative_return = (1 + simple_return).cumprod() - 1
print("累计收益率:", cumulative_return.iloc[-1])
```

#### 0.4.2 风险的度量

**波动率（Volatility）：** 收益率的标准差

$$
\sigma = \sqrt{\frac{1}{n-1} \sum_{i=1}^{n} (R_i - \bar{R})^2}
$$

**年化波动率：**

$$
\sigma_{年化} = \sigma_{日} \times \sqrt{252}
$$

（A股每年约252个交易日）

```python
## 计算波动率
returns = df['close'].pct_change().dropna()

## 日波动率
daily_vol = returns.std()

## 年化波动率
annual_vol = daily_vol * np.sqrt(252)

print(f"日波动率: {daily_vol:.4f}")
print(f"年化波动率: {annual_vol:.2%}")
```

**其他风险指标：**

| 指标 | 公式 | 含义 |
|------|------|------|
| VaR（风险价值） | $P(损失 > VaR) = \alpha$ | α置信度下的最大损失 |
| CVaR（条件VaR） | $E[损失 \| 损失 > VaR]$ | 超过VaR时的平均损失 |
| 下行波动率 | 只计算负收益的波动 | 更关注下跌风险 |

## 一、量化交易基础

### 1.1 什么是量化交易？

**定义**：将交易逻辑转化为计算机程序，利用数学模型和统计方法自动执行买卖决策。

**量化交易 vs 主观交易：**

| 维度 | 量化交易 | 主观交易 |
|------|----------|----------|
| 决策依据 | 数学模型、统计规律 | 经验、直觉、盘感 |
| 执行方式 | 程序自动化 | 人工手动操作 |
| 情绪影响 | 无情绪干扰 | 易受恐惧/贪婪影响 |
| 可回溯性 | 可用历史数据验证 | 难以量化验证 |
| 适应性 | 需重新编程 | 灵活应变 |
| 交易频率 | 可高频（毫秒级） | 低频（分钟/小时级） |

**核心优势：**

1. **消除情绪干扰**：避免"追涨杀跌"、"死扛亏损"等人性弱点
2. **可验证性**：用历史数据检验策略有效性（回测）
3. **执行纪律性**：严格按规则操作，不受市场情绪影响
4. **高效处理信息**：同时监控数百个标的，捕捉稍纵即逝的机会
5. **风险可控**：预设止损止盈，最大回撤可量化

**量化交易流程：**

```
┌──────────────────────────────────────────────────────┐
│                   量化交易完整流程                      │
└──────────────────────────────────────────────────────┘
        │
        ├─→ 1. 理论假设
        │    └─ 市场存在某种可预测的规律（均值回归、动量效应等）
        │
        ├─→ 2. 数据获取
        │    └─ 历史价格、成交量、财务数据、宏观指标
        │
        ├─→ 3. 特征工程
        │    └─ 计算技术指标、提取统计特征
        │
        ├─→ 4. 策略开发
        │    └─ 将假设转化为可执行的交易规则
        │
        ├─→ 5. 历史回测
        │    └─ 用过去数据验证策略的有效性
        │         ├─ 收益率如何？
        │         ├─ 最大回撤多大？
        │         ├─ 胜率和盈亏比？
        │         └─ 是否过拟合？
        │
        ├─→ 6. 参数优化
        │    └─ 寻找最优参数组合（避免过度拟合）
        │
        ├─→ 7. 样本外测试
        │    └─ 用未参与优化的数据进行验证
        │
        ├─→ 8. 模拟盘验证
        │    └─ 小资金实盘测试，观察滑点、冲击成本
        │
        └─→ 9. 实盘交易
             └─ 持续监控、定期评估、动态调整
```

### 1.2 技术分析的理论基础

#### 1.2.1 技术分析三大假设

**假设一：市场行为包容一切**

- 价格已反映所有信息（基本面、政策、情绪）
- 只需分析价格和成交量，无需关注"为什么涨跌"

**假设二：价格沿趋势移动**

- 趋势一旦形成，倾向于延续（牛顿第一定律：惯性）
- 趋势反转需要强大的外力（政策、黑天鹅事件）

**假设三：历史会重演**

- 人性不变 → 行为模式重复 → 价格形态重现
- K线形态、支撑阻力位具有参考价值

**争议与局限性：**

| 批评观点 | 反驳 |
|----------|------|
| 历史数据无法预测未来 | 统计规律在大样本下有效 |
| 市场是随机游走的 | 存在短期动量和长期均值回归 |
| 自我实现的预言 | 部分成立，但不影响策略盈利 |

#### 1.2.2 趋势理论

**道氏理论（Dow Theory）：** 最早的技术分析理论

**核心观点：**

1. **市场有三种趋势**：
   - **主要趋势**（1年以上）：牛市/熊市
   - **次要趋势**（3周-3个月）：主趋势的回调
   - **短期波动**（少于3周）：市场噪音

2. **趋势的三个阶段**：
   ```
   牛市阶段：
   ├─ 累积期：聪明资金布局，成交量低
   ├─ 上涨期：大众跟进，成交量放大
   └─ 派发期：主力出货，散户接盘
   
   熊市阶段：
   ├─ 派发期：高位震荡，主力出货
   ├─ 恐慌期：加速下跌，成交量放大
   └─ 筑底期：跌无可跌，成交量萎缩
   ```

3. **价格与成交量的关系**：
   - **健康上涨**：价涨量增（量价齐升）
   - **虚假上涨**：价涨量缩（拉高出货）
   - **健康下跌**：价跌量缩（抛压减轻）
   - **恐慌下跌**：价跌量增（恐慌性抛售）

#### 1.2.3 支撑与阻力

**定义：**

- **支撑位（Support）**：价格下跌遇到强劲买盘，难以跌破的价格区域
- **阻力位（Resistance）**：价格上涨遇到强劲卖盘，难以突破的价格区域

**形成原因：**

| 类型 | 原理 | 示例 |
|------|------|------|
| 心理关口 | 整数价位（如50元、100元） | 投资者心理定价 |
| 历史高点 | 前期高点的卖压 | 解套盘涌出 |
| 均线支撑 | MA成为动态支撑/阻力 | 60日均线 |
| 缺口 | 跳空缺口形成阻力 | 填权/填息 |

**突破的确认：**

```
真突破：
├─ 放量突破（成交量明显放大）
├─ 突破幅度 > 3%
└─ 连续3天站稳

假突破（Bull Trap/Bear Trap）：
├─ 缩量突破
├─ 突破后快速回落
└─ 诱多/诱空陷阱
```

### 1.3 量化交易的数学基础

#### 1.3.1 时间序列的基本概念

**时间序列（Time Series）**：按时间顺序排列的数据点序列。

**重要性质：**

1. **平稳性（Stationarity）**：
   - 均值、方差、自协方差不随时间变化
   - 大多数统计模型要求数据平稳
   
   **检验方法**：ADF检验（Augmented Dickey-Fuller Test）
   
   ```python
   from statsmodels.tsa.stattools import adfuller
   
   # 检验序列是否平稳
   result = adfuller(df['close'])
   
   print(f"ADF统计量: {result[0]}")
   print(f"p值: {result[1]}")
   print(f"是否平稳: {'是' if result[1] < 0.05 else '否'}")
   ```

2. **自相关性（Autocorrelation）**：
   - 序列与其滞后值之间的相关性
   - 用于判断是否存在趋势/周期

   **公式：**
   $$
   ACF(k) = \frac{Cov(X_t, X_{t-k})}{Var(X_t)}
   $$

   ```python
   from statsmodels.graphics.tsaplots import plot_acf
   import matplotlib.pyplot as plt
   
   # 绘制自相关图
   plot_acf(df['close'], lags=40)
   plt.show()
   ```

#### 1.3.2 随机游走与均值回归

**随机游走（Random Walk）：**

$$
P_t = P_{t-1} + \epsilon_t, \quad \epsilon_t \sim N(0, \sigma^2)
$$

- 价格变化完全随机，无法预测
- 符合"弱式有效市场假说"

**均值回归（Mean Reversion）：**

$$
P_t = \mu + \phi(P_{t-1} - \mu) + \epsilon_t, \quad |\phi| < 1
$$

- 价格偏离均值后会回归
- $\phi$ 接近0：快速回归；接近1：缓慢回归

**实际情况**：

- **短期（分钟/小时）**：随机游走为主
- **中期（天/周）**：动量效应（趋势延续）
- **长期（月/年）**：均值回归

**检验均值回归：**

```python
from statsmodels.tsa.stattools import coint

## 协整检验（检验两个股票是否存在均值回归关系）
stock1 = df1['close']
stock2 = df2['close']

score, pvalue, _ = coint(stock1, stock2)

if pvalue < 0.05:
    print("存在协整关系，可进行配对交易")
else:
    print("不存在协整关系")
```

#### 1.3.3 风险与收益的权衡

**马科维茨投资组合理论（Modern Portfolio Theory, MPT）：**

核心思想：通过分散化投资降低风险。

**有效前沿（Efficient Frontier）：**

```
收益率
  ↑
  │        ● ← 最优组合（夏普比率最高）
  │      ●●●
  │    ●●●●●
  │  ●●●●●●●
  │●●●●●●●●●
  └──────────→ 风险（标准差）
```

**夏普比率（Sharpe Ratio）：** 衡量风险调整后收益

$$
Sharpe = \frac{E[R_p] - R_f}{\sigma_p}
$$

- $E[R_p]$：组合预期收益率
- $R_f$：无风险利率（如国债利率）
- $\sigma_p$：组合标准差

**含义**：每承担1单位风险，获得多少超额收益。

```python
def calculate_sharpe(returns, risk_free_rate=0.03):
    """
    计算夏普比率
    
    Args:
        returns: 收益率序列
        risk_free_rate: 年化无风险利率
    """
    # 年化收益率
    annual_return = returns.mean() * 252
    
    # 年化波动率
    annual_vol = returns.std() * np.sqrt(252)
    
    # 夏普比率
    sharpe = (annual_return - risk_free_rate) / annual_vol
    
    return sharpe

## 使用
returns = df['close'].pct_change()
sharpe = calculate_sharpe(returns)
print(f"夏普比率: {sharpe:.2f}")
```

## 二、统计学与概率论基础

> **学习目标**：掌握量化交易中常用的统计方法和概率分布

### 2.1 描述性统计

#### 2.1.1 集中趋势

**均值（Mean）：** 所有数据的平均值

$$
\bar{X} = \frac{1}{n}\sum_{i=1}^{n} X_i
$$

**中位数（Median）：** 排序后位于中间的值（50%分位数）

**众数（Mode）：** 出现频率最高的值

**为什么不只用均值？**

- 均值受极端值影响大（outlier敏感）
- 中位数更稳健（robust）

```python
import numpy as np

returns = df['close'].pct_change().dropna()

print(f"均值: {returns.mean():.4f}")
print(f"中位数: {returns.median():.4f}")
print(f"50%分位数: {returns.quantile(0.5):.4f}")  # 与中位数相同
```

#### 2.1.2 离散程度

**方差（Variance）：** 衡量数据分散程度

$$
\sigma^2 = \frac{1}{n-1}\sum_{i=1}^{n}(X_i - \bar{X})^2
$$

**标准差（Standard Deviation）：** 方差的平方根

$$
\sigma = \sqrt{\sigma^2}
$$

**变异系数（CV）：** 相对离散程度

$$
CV = \frac{\sigma}{\bar{X}}
$$

**四分位距（IQR）：** 25%分位数与75%分位数之差

```python
## 计算离散程度指标
print(f"标准差: {returns.std():.4f}")
print(f"方差: {returns.var():.6f}")
print(f"25%分位数: {returns.quantile(0.25):.4f}")
print(f"75%分位数: {returns.quantile(0.75):.4f}")
print(f"IQR: {returns.quantile(0.75) - returns.quantile(0.25):.4f}")
```

#### 2.1.3 分布形态

**偏度（Skewness）：** 衡量分布的对称性

$$
Skewness = \frac{E[(X - \mu)^3]}{\sigma^3}
$$

- **Skew > 0**：右偏（正偏），长尾在右侧
- **Skew < 0**：左偏（负偏），长尾在左侧
- **Skew = 0**：对称分布（如正态分布）

**峰度（Kurtosis）：** 衡量分布的尖峭程度

$$
Kurtosis = \frac{E[(X - \mu)^4]}{\sigma^4} - 3
$$

- **Kurt > 0**：厚尾分布（Leptokurtic），极端值出现概率高
- **Kurt < 0**：薄尾分布（Platykurtic）
- **Kurt = 0**：正态分布

```python
from scipy import stats

## 计算偏度和峰度
skew = stats.skew(returns)
kurt = stats.kurtosis(returns)

print(f"偏度: {skew:.2f}")
print(f"峰度: {kurt:.2f}")

if skew > 0:
    print("→ 收益率分布右偏，大涨天数较多")
elif skew < 0:
    print("→ 收益率分布左偏，大跌天数较多")

if kurt > 0:
    print("→ 厚尾分布，黑天鹅事件概率高于正态分布")
```

### 2.2 概率分布

#### 2.2.1 正态分布（Normal Distribution）

**概率密度函数：**

$$
f(x) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)
$$

**特性：**

- 68%的数据在 $[\mu - \sigma, \mu + \sigma]$ 范围内
- 95%的数据在 $[\mu - 2\sigma, \mu + 2\sigma]$ 范围内
- 99.7%的数据在 $[\mu - 3\sigma, \mu + 3\sigma]$ 范围内

**在金融中的应用：**

- 收益率近似服从正态分布（实际上是厚尾分布）
- VaR计算、期权定价（Black-Scholes模型）

```python
import matplotlib.pyplot as plt

## 检验收益率是否服从正态分布

sigma = returns.std()

plt.show()

## Shapiro-Wilk 正态性检验
stat, p_value = stats.shapiro(returns)
print(f"Shapiro-Wilk 检验 p值: {p_value:.4f}")
print(f"是否服从正态分布: {'否' if p_value < 0.05 else '是'}")
```

#### 2.2.2 学生t分布（Student's t-Distribution）

**特点：**

- 比正态分布更厚的尾部
- 更适合描述金融收益率（极端值多）
- 自由度越大，越接近正态分布


### 2.4 时间序列分析

#### 2.4.1 移动平均（Moving Average, MA）

**简单移动平均（SMA）：**

$$
MA_t = \frac{1}{n}\sum_{i=0}^{n-1} P_{t-i}
$$

**指数移动平均（EMA）：**

$$
EMA_t = \alpha \cdot P_t + (1-\alpha) \cdot EMA_{t-1}
$$

其中 $\alpha = \frac{2}{n+1}$

**区别：**

- SMA：所有数据权重相同
- EMA：近期数据权重更大，响应更快


$$

- $p$：阶数（使用过去p期数据）
- $\phi_i$：自回归系数

```python
def check_data_quality(df: pd.DataFrame):
    """检查数据质量"""
    issues = []
    
    # 1. 检查缺失值
    missing = df.isnull().sum()
    if missing.any():
        issues.append(f"存在缺失值: {missing[missing > 0].to_dict()}")
    
    # 2. 检查价格异常（负值或零值）
    for col in ['open', 'high', 'low', 'close']:
        if (df[col] <= 0).any():
            issues.append(f"{col} 列存在非正值")
    
    # 3. 检查成交量异常
    if (df['volume'] < 0).any():
        issues.append("成交量列存在负值")
    
    # 4. 检查价格逻辑（最高价 >= 最低价）
    invalid = (df['high'] < df['low']).sum()
    if invalid > 0:
        issues.append(f"存在 {invalid} 条数据最高价低于最低价")
    
    # 5. 检查连续性
    date_diff = df.index.to_series().diff()
    non_trading_days = date_diff[date_diff > pd.Timedelta(days=7)].count()
    if non_trading_days > 0:
        issues.append(f"存在 {non_trading_days} 处长时间间隔")
    
    # 输出报告
    if issues:
        print("⚠️  数据质量问题:")
        for issue in issues:
            print(f"  - {issue}")
    else:
        print("✅ 数据质量检查通过")
    
    return len(issues) == 0

## 使用
```

```python
def clean_data(df: pd.DataFrame) -> pd.DataFrame:
    """数据清洗"""
    df = df.copy()
    
    # 1. 填充缺失值（前向填充）
    df.fillna(method='ffill', inplace=True)
    
    # 2. 删除仍存在的缺失行
    df.dropna(inplace=True)
    
    # 3. 处理异常值（使用滚动中位数替换）
    for col in ['open', 'high', 'low', 'close']:
        median = df[col].rolling(window=5, center=True).median()
        # 替换超出3倍标准差的值
        std = df[col].rolling(window=5).std()
        outliers = (df[col] - median).abs() > 3 * std
        df.loc[outliers, col] = median
    
    # 4. 计算收益率
    df['return'] = df['close'].pct_change()
    df['log_return'] = np.log(df['close'] / df['close'].shift(1))
    
    # 5. 计算成交量移动平均
    df['volume_ma5'] = df['volume'].rolling(5).mean()
    df['volume_ma20'] = df['volume'].rolling(20).mean()
    
    return df
```

## 四、技术指标理论与策略开发

> **学习目标**：理解技术指标的数学原理、适用场景和局限性

### 4.1 技术指标分类与选择

#### 4.1.1 技术指标的四大类别

**1. 趋势类指标（Trend Indicators）**

- **原理**：通过平滑价格波动，识别趋势方向
- **代表**：MA、EMA、MACD
- **适用场景**：趋势明显的市场（单边行情）
- **失效场景**：震荡市（横盘整理）

**2. 震荡类指标（Oscillators）**

- **原理**：衡量价格偏离正常范围的程度
- **代表**：RSI、KDJ、随机指标
- **适用场景**：震荡市、超买超卖判断
- **失效场景**：强趋势市场（连续超买/超卖）

**3. 波动率指标（Volatility Indicators）**

- **原理**：衡量价格波动的剧烈程度
- **代表**：布林带（BOLL）、ATR
- **适用场景**：风险控制、突破判断
- **用途**：设置止损止盈位置

**4. 成交量指标（Volume Indicators）**

- **原理**：通过成交量确认价格趋势
- **代表**：OBV、量价关系
- **核心思想**：量先于价（成交量是价格的先行指标）

#### 4.1.2 指标选择的黄金法则

| 法则 | 说明 | 原因 |
|------|------|------|
| 趋势+震荡组合 | 同时使用不同类型指标 | 互相确认，降低假信号 |
| 避免同类指标 | 不要同时用MA和EMA | 冗余信息，无新增价值 |
| 简单优于复杂 | 优先选择简单指标 | 可解释性强，参数少 |
| 验证再使用 | 回测验证有效性 | 避免"数据拟合陷阱" |

### 4.2 趋势类指标深入解析

#### 4.2.1 移动平均线（MA）

**数学定义：**

$$
MA_t(n) = \frac{1}{n}\sum_{i=0}^{n-1} P_{t-i}
$$

**核心思想**：通过平均价格消除短期波动，显示趋势方向。

**常用周期及含义：**

| 周期 | 名称 | 用途 | 交易者类型 |
|------|------|------|------------|
| MA5 | 5日线 | 超短线趋势 | 日内交易者 |
| MA10 | 10日线 | 短期趋势 | 短线交易者 |
| MA20 | 月线 | 中短期趋势 | 波段交易者 |
| MA60 | 季线 | 中期趋势 | 趋势交易者 |
| MA120 | 半年线 | 长期趋势 | 价值投资者 |
| MA250 | 年线 | 牛熊分界 | 长期投资者 |

**交易信号：**

```
金叉（Golden Cross）：
├─ 定义：短期MA上穿长期MA
├─ 含义：多头趋势形成
└─ 操作：买入信号

死叉（Death Cross）：
├─ 定义：短期MA下穿长期MA
├─ 含义：空头趋势形成
└─ 操作：卖出信号

黏合（MA Convergence）：
├─ 定义：多条MA聚集
├─ 含义：变盘在即（蓄势待发）
└─ 操作：观望等待突破
```

**优缺点：**

✅ **优点**：
- 简单直观，易于理解
- 平滑噪音，显示趋势
- 可作为动态支撑/阻力位

❌ **缺点**：
- 滞后性（Lagging Indicator）：趋势已经形成才发出信号
- 震荡市频繁假突破
- 参数敏感性：不同周期结果差异大

#### 4.2.2 指数移动平均线（EMA）

**数学定义：**

$$
EMA_t = \alpha \cdot P_t + (1-\alpha) \cdot EMA_{t-1}
$$

其中平滑因子：$\alpha = \frac{2}{n+1}$

**与SMA的区别：**

```
SMA（简单移动平均）：
├─ 所有数据权重相同
├─ 计算：(P1 + P2 + ... + Pn) / n
└─ 特点：反应慢，噪音少

EMA（指数移动平均）：
├─ 近期数据权重大
├─ 计算：递归加权
└─ 特点：反应快，更贴近实时价格
```

**权重衰减示例（EMA20）：**

| 天数 | 权重 | 说明 |
|------|------|------|
| 今天 | 9.52% | 最近数据权重最大 |
| 1天前 | 8.61% | 权重呈指数衰减 |
| 5天前 | 6.09% | ... |
| 10天前 | 3.71% | ... |
| 20天前 | 1.29% | 远期数据权重小 |

```python

```

#### 4.2.3 MACD（指数平滑异同移动平均线）

**核心思想**：比较两条不同周期的EMA，衡量动量变化。

**计算公式：**

$$
\begin{align}
DIF &= EMA_{12} - EMA_{26} \\
DEA &= EMA_9(DIF) \\
MACD柱 &= (DIF - DEA) \times 2
\end{align}
$$

**三条线的含义：**

| 线 | 计算 | 含义 |
|------|------|------|
| DIF线（快线） | EMA12 - EMA26 | 短期动量 |
| DEA线（慢线） | DIF的9日EMA | 动量的趋势 |
| MACD柱 | (DIF - DEA) × 2 | 动量加速度 |

**交易信号：**

```
1. DIF与DEA的交叉：
   ├─ DIF上穿DEA：金叉，买入
   └─ DIF下穿DEA：死叉，卖出

2. MACD柱的变化：
   ├─ 柱体由负转正：多头力量增强
   ├─ 柱体由正转负：空头力量增强
   ├─ 柱体放大：趋势加速
   └─ 柱体缩小：趋势减弱

3. 零轴的意义：
   ├─ DIF > 0：短期均价 > 长期均价，多头市场
   └─ DIF < 0：短期均价 < 长期均价，空头市场

4. 背离（Divergence）：
   ├─ 顶背离：价格创新高，MACD未创新高 → 见顶信号
   └─ 底背离：价格创新低，MACD未创新低 → 见底信号
```

### 4.3 震荡类指标深入解析

#### 4.3.1 RSI（相对强弱指标）

**核心思想**：衡量一定时期内上涨力量与下跌力量的对比。

**计算公式：**

$$
RSI = 100 - \frac{100}{1 + RS}
$$

其中：

$$
RS = \frac{平均上涨幅度}{平均下跌幅度} = \frac{\sum 上涨日涨幅 / n}{\sum 下跌日跌幅 / n}
$$

**取值范围：** 0 ~ 100

**判断标准：**

| RSI值 | 市场状态 | 操作建议 |
|-------|----------|----------|
| > 70 | 超买（Overbought） | 警惕回调，可考虑减仓 |
| 50~70 | 强势 | 持股观望 |
| 30~50 | 弱势 | 观望 |
| < 30 | 超卖（Oversold） | 可能反弹，可考虑买入 |

**交易信号：**

```
1. 超买超卖：
   ├─ RSI > 80：严重超买，警惕顶部
   ├─ RSI < 20：严重超卖，可能见底
   └─ 注意：强趋势中RSI可长期超买/超卖

2. 中线穿越：
   ├─ RSI上穿50：多头市场
   └─ RSI下穿50：空头市场

3. 背离：
   ├─ 顶背离：价格新高，RSI未新高 → 趋势弱化
   └─ 底背离：价格新低，RSI未新低 → 即将反转

4. 形态分析：
   ├─ 头肩顶/底：与价格形态对应
   └─ 支撑阻力：RSI也有支撑阻力位
```

**代码实现：**

```python
    """改进的RSI策略：结合趋势过滤"""
    df = df.copy()
    
    # 计算RSI和MA
    df['RSI'] = talib.RSI(df['close'].values, timeperiod=rsi_period)
    df['MA50'] = df['close'].rolling(50).mean()
    
    # 信号生成
    df['signal'] = 0
    
    # 只在上升趋势中买入超卖
    buy_condition = (
        (df['RSI'] < 30) &  # RSI超卖
        (df['close'] > df['MA50'])  # 价格在MA50之上（确认趋势）
    )
    df.loc[buy_condition, 'signal'] = 1
    
    # 只在下降趋势中卖出超买
    sell_condition = (
        (df['RSI'] > 70) &  # RSI超买
        (df['close'] < df['MA50'])  # 价格在MA50之下
    )
    df.loc[sell_condition, 'signal'] = -1
    
    return df
```

#### 4.3.2 KDJ 随机指标

**核心思想**：比较收盘价在一定周期内最高最低价区间的位置。

**计算公式：**

$$
\begin{align}
RSV_t &= \frac{C_t - L_n}{H_n - L_n} \times 100 \\
K_t &= \frac{2}{3}K_{t-1} + \frac{1}{3}RSV_t \\
D_t &= \frac{2}{3}D_{t-1} + \frac{1}{3}K_t \\
J_t &= 3K_t - 2D_t
\end{align}
$$

- $C_t$：今日收盘价
- $L_n$：n日内最低价
- $H_n$：n日内最高价
- RSV：未成熟随机值（Raw Stochastic Value）

**三条线的含义：**

| 线 | 含义 | 特点 |
|------|------|------|
| K线 | RSV的平滑（快线） | 反应灵敏 |
| D线 | K的平滑（慢线） | 反应平缓 |
| J线 | K和D的偏离度 | 最敏感，可超出0-100 |

**判断标准：**

```
超买超卖：
├─ K、D > 80：超买区
├─ K、D < 20：超卖区
└─ J > 100或< 0：极度超买/超卖

金叉死叉：
├─ K上穿D：金叉，买入
└─ K下穿D：死叉，卖出

钝化现象：
├─ 强势股：KDJ长期高位钝化（>80）
└─ 弱势股：KDJ长期低位钝化（<20）
```

### 4.4 波动率指标深入解析

#### 4.4.1 布林带（Bollinger Bands）

**核心思想**：价格在均值±标准差的范围内波动。

**计算公式：**

$$
\begin{align}
中轨 &= MA(n) \\
上轨 &= MA(n) + k \times \sigma(n) \\
下轨 &= MA(n) - k \times \sigma(n)
\end{align}
$$

- $MA(n)$：n日移动平均（通常n=20）
- $\sigma(n)$：n日标准差
- $k$：标准差倍数（通常k=2）

**统计意义：**

根据正态分布：
- 68%的价格在 ± 1倍标准差内
- 95%的价格在 ± 2倍标准差内
- 99.7%的价格在 ± 3倍标准差内

**交易信号：**

```
1. 触及上轨：
   ├─ 上涨趋势：继续持有
   └─ 震荡/顶部：考虑减仓

2. 触及下轨：
   ├─ 下跌趋势：观望
   └─ 震荡/底部：考虑买入

3. 布林带宽度（Bandwidth）：
   ├─ 收窄：波动率降低，变盘在即
   └─ 扩张：波动率增加，趋势确认

4. 保利加通道突破：
   ├─ 突破上轨 + 放量：强势突破
   └─ 跌破下轨 + 放量：弱势破位

5. 布林中轨：
   ├─ 价格在中轨之上：多头市场
   └─ 价格在中轨之下：空头市场
```

**代码实现：**

#### 4.4.2 ATR（平均真实波幅）

**核心思想**：衡量价格波动的剧烈程度（波动率）。

**计算公式：**

$$
\begin{align}
TR_t &= \max(H_t - L_t, |H_t - C_{t-1}|, |L_t - C_{t-1}|) \\
ATR_t &= \frac{1}{n}\sum_{i=0}^{n-1} TR_{t-i}
\end{align}
$$

- $TR$：真实波幅（True Range）
- $H_t$：今日最高价
- $L_t$：今日最低价
- $C_{t-1}$：昨日收盘价

**应用场景：**

1. **设置止损位**：
   ```
   止损距离 = ATR × 倍数（通常2-3倍）
   止损价 = 入场价 - 2 × ATR（做多时）
   ```

2. **判断突破有效性**：
   ```
   有效突破 = 突破幅度 > ATR × 1.5
   ```

3. **仓位管理**：
   ```
   波动率大（ATR高）→ 减小仓位
   波动率小（ATR低）→ 增加仓位
   ```

```python
## 计算ATR
df['ATR14'] = talib.ATR(df['high'].values, df['low'].values, df['close'].values, timeperiod=14)

## 基于ATR的止损策略
def atr_stop_loss(entry_price, atr, position='long', multiplier=2):
    """
    基于ATR的止损价计算
    
    Args:
        entry_price: 入场价格
        atr: 当前ATR值
        position: 'long' 或 'short'
        multiplier: ATR倍数
    """
    if position == 'long':
        stop_loss = entry_price - multiplier * atr
    else:
        stop_loss = entry_price + multiplier * atr
    
    return stop_loss

## 使用

print(f"入场价: {entry}, ATR: {current_atr}, 止损价: {stop:.2f}")
```

### 3.4 双均线策略

```python
class DualMAStrategy:
    """双均线策略"""
    
    def __init__(self, fast_period: int = 5, slow_period: int = 20):
        self.fast_period = fast_period
        self.slow_period = slow_period
    
    def generate_signals(self, df: pd.DataFrame) -> pd.DataFrame:
        """
        生成交易信号
        
        Returns:
            DataFrame 添加以下列：
            - signal: 买入=1, 卖出=-1, 无信号=0
            - position: 持仓状态
        """
        df = df.copy()
        
        # 计算均线
        df['MA_fast'] = df['close'].rolling(self.fast_period).mean()
        df['MA_slow'] = df['close'].rolling(self.slow_period).mean()
        
        # 生成信号
        # 金叉：快线上穿慢线
        df['signal'] = 0
        df.loc[(df['MA_fast'] > df['MA_slow']) & 
               (df['MA_fast'].shift(1) <= df['MA_slow'].shift(1)), 'signal'] = 1
        
        # 死叉：快线下穿慢线
        df.loc[(df['MA_fast'] < df['MA_slow']) & 
               (df['MA_fast'].shift(1) >= df['MA_slow'].shift(1)), 'signal'] = -1
        
        # 计算持仓
        df['position'] = df['signal'].replace(0, method='ffill').fillna(0)
        
        return df
    
    def backtest(self, df: pd.DataFrame, initial_capital: float = 100000) -> dict:
        """简单回测"""
        df_signals = self.generate_signals(df)
        
        # 计算收益
        df_signals['strategy_return'] = df_signals['position'].shift(1) * df_signals['return']
        df_signals['cumulative_return'] = (1 + df_signals['strategy_return']).cumprod()
        
        # 计算策略最终价值
        final_value = initial_capital * df_signals['cumulative_return'].iloc[-1]
        buy_hold_return = (df['close'].iloc[-1] / df['close'].iloc[0] - 1) * initial_capital
        
        return {
            'final_value': final_value,
            'strategy_return': final_value - initial_capital,
            'buy_hold_return': buy_hold_return,
            'excess_return': final_value - initial_capital - buy_hold_return,
            'signals_df': df_signals
        }

## 使用
strategy = DualMAStrategy(fast_period=5, slow_period=20)
result = strategy.backtest(df_clean)

print(f"初始资金: ¥100,000")
print(f"策略最终: ¥{result['final_value']:,.2f}")
print(f"策略收益: ¥{result['strategy_return']:,.2f}")
print(f"买入持有: ¥{result['buy_hold_return']:,.2f}")
print(f"超额收益: ¥{result['excess_return']:,.2f}")
```

### 3.5 MACD + RSI 组合策略

```python
class MACDRSIStrategy:
    """MACD + RSI 组合策略"""
    
    def __init__(self, macd_fast: int = 12, macd_slow: int = 26, 
                 macd_signal: int = 9, rsi_period: int = 14,
                 rsi_oversold: int = 30, rsi_overbought: int = 70):
        self.macd_fast = macd_fast
        self.macd_slow = macd_slow
        self.macd_signal = macd_signal
        self.rsi_period = rsi_period
        self.rsi_oversold = rsi_oversold
        self.rsi_overbought = rsi_overbought
    
    def generate_signals(self, df: pd.DataFrame) -> pd.DataFrame:
        """生成交易信号"""
        df = df.copy()
        
        # 计算指标
        close = df['close'].values
        df['MACD'], df['MACD_signal'], df['MACD_hist'] = talib.MACD(
            close, 
            fastperiod=self.macd_fast,
            slowperiod=self.macd_slow,
            signalperiod=self.macd_signal
        )
        df['RSI'] = talib.RSI(close, timeperiod=self.rsi_period)
        
        # 生成信号
        # 买入条件：MACD金叉且RSI未超买
        buy_signal = (
            (df['MACD'] > df['MACD_signal']) &
            (df['MACD'].shift(1) <= df['MACD_signal'].shift(1)) &
            (df['RSI'] < self.rsi_overbought)
        )
        
        # 卖出条件：MACD死叉或RSI超买
        sell_signal = (
            ((df['MACD'] < df['MACD_signal']) &
             (df['MACD'].shift(1) >= df['MACD_signal'].shift(1))) |
            (df['RSI'] > self.rsi_overbought)
        )
        
        df['signal'] = 0
        df.loc[buy_signal, 'signal'] = 1
        df.loc[sell_signal, 'signal'] = -1
        
        # 计算持仓
        df['position'] = df['signal'].replace(0, method='ffill').fillna(0)
        
        return df
```

## 六、风险管理理论与实践

> **学习目标**：深入理解金融风险的本质、度量方法和管理策略

### 6.1 风险的本质与分类

#### 6.1.1 什么是风险？

**定义**：投资收益的不确定性。

**风险 ≠ 亏损**：
- 风险是**波动性**（Volatility），包括上涨和下跌的不确定性
- 现代金融理论：风险 = 标准差（收益率的离散程度）

**风险的两面性：**

```
                收益
                 ↑
    高风险 ──────┼──────── 高收益
                 │
    低风险 ──────┼──────── 低收益
                 │
               风险 →
```

#### 6.1.2 风险的分类

| 风险类型 | 定义 | 能否分散 | 应对方法 |
|----------|------|----------|----------|
| **系统性风险** | 整个市场的风险（经济衰退、战争） | ❌ 不能 | 对冲、止损 |
| **非系统性风险** | 个股/行业特有风险（公司破产） | ✅ 能 | 分散投资 |
| **流动性风险** | 无法快速变现  | ❌ 不能 | 选择大盘股 |
| **信用风险** | 对手方违约 | ⚠️ 部分能 | 选择优质标的 |

**系统性风险（Beta）vs 非系统性风险（Alpha）：**

$$
总风险 = \underbrace{\beta \times 市场风险}_{系统性风险} + \underbrace{\epsilon}_{非系统性风险}
$$

- **系统性风险**：无法通过分散化消除（如2008年金融危机）
- **非系统性风险**：可通过持有多只股票分散

**分散化的数学原理：**

$$
\sigma_p = \sqrt{\frac{1}{n^2}\sum_{i=1}^{n}\sum_{j=1}^{n}\sigma_i\sigma_j\rho_{ij}}
$$

当股票数量 $n$ 增加且相关性 $\rho < 1$ 时，组合波动率 $\sigma_p$ 下降。

```python
import numpy as np

## 模拟分散化效果
n_stocks = np.arange(1, 51)
portfolio_risk = []

for n in n_stocks:
    # 假设单股风险20%，股票间相关性0.3

    correlation = 0.3

plt.xlabel('持股数量')

plt.legend()
plt.grid(True)
plt.show()
```

### 6.2 风险度量指标详解

#### 6.2.1 最大回撤（Maximum Drawdown, MDD）

**定义**：从历史最高点到最低点的最大跌幅。

$$
MDD = \max_{t \in [0,T]} \left( \frac{Peak_t - Trough_t}{Peak_t} \right)
$$

**计算步骤：**

1. 计算每日累计收益
2. 计算每日历史最高峰值
3. 计算每日回撤 = (峰值 - 当前值) / 峰值
4. 取最大回撤

```python
def calculate_max_drawdown(returns: pd.Series) -> dict:
    """
    计算最大回撤及相关指标
    
    Returns:
        dict: 包含最大回撤、回撤开始/结束日期、持续天数
    """
    # 计算累计收益
    cumulative = (1 + returns).cumprod()
    
    # 计算历史最高点
    running_max = cumulative.cummax()
    
    # 计算回撤序列
    drawdown = (cumulative - running_max) / running_max
    
    # 最大回撤
    max_dd = drawdown.min()
    
    # 最大回撤结束时间（谷底）
    end_date = drawdown.idxmin()
    
    # 最大回撤开始时间（峰值）
    start_date = cumulative[:end_date].idxmax()
    
    # 持续天数
    duration = (end_date - start_date).days
    
    return {
        'max_drawdown': max_dd,
        'start_date': start_date,
        'end_date': end_date,
        'duration_days': duration,
        'drawdown_series': drawdown
    }

## 使用
returns = df['close'].pct_change().dropna()
dd_info = calculate_max_drawdown(returns)

print(f"最大回撤: {dd_info['max_drawdown']:.2%}")
print(f"开始日期: {dd_info['start_date']}")
print(f"结束日期: {dd_info['end_date']}")
print(f"持续天数: {dd_info['duration_days']} 天")

## 可视化回撤曲线
plt.figure(figsize=(14, 7))
dd_info['drawdown_series'].plot(kind='area', color='red', alpha=0.3)
plt.title('回撤曲线')
plt.ylabel('回撤比例')
plt.axhline(dd_info['max_drawdown'], color='darkred', linestyle='--', 
            label=f'最大回撤: {dd_info["max_drawdown"]:.2%}')
plt.legend()
plt.grid(True)
plt.show()
```

**最大回撤的实际意义：**

```
最大回撤 -50% 的含义：
├─ 需要 +100% 才能回本（1 / (1 - 0.5) - 1 = 1）
├─ 心理压力极大，容易割肉
└─ 对杠杆交易尤其致命

可接受的最大回撤：
├─ 保守型投资者：< 10%
├─ 稳健型投资者：10% ~ 20%
├─ 激进型投资者：20% ~ 30%
└─ 超过 30%：需审视策略
```

#### 6.2.2 夏普比率（Sharpe Ratio）

**定义**：每承担一单位风险，获得多少超额收益。

$$
Sharpe = \frac{E[R_p - R_f]}{\sigma_p} = \frac{年化收益率 - 无风险利率}{年化波动率}
$$

- $R_p$：投资组合收益率
- $R_f$：无风险利率（如3年期国债利率 ≈ 3%）
- $\sigma_p$：收益率标准差（波动率）

**判断标准：**

| 夏普比率 | 评价 | 说明 |
|----------|------|------|
| < 0 | 差 | 收益低于无风险利率，不如买国债 |
| 0 ~ 1 | 一般 | 风险收益比不高 |
| 1 ~ 2 | 良好 | 专业水平 |
| 2 ~ 3 | 优秀 | 顶级水平 |
| > 3 | 卓越 | 极少见，需警惕数据拟合 |

```python
def calculate_sharpe_ratio(returns: pd.Series, risk_free_rate: float = 0.03) -> float:
    """
    计算夏普比率
    
    Args:
        returns: 日收益率序列
        risk_free_rate: 年化无风险利率
    """
    # 年化收益率
    annual_return = returns.mean() * 252
    
    # 年化波动率
    annual_vol = returns.std() * np.sqrt(252)
    
    # 夏普比率
    sharpe = (annual_return - risk_free_rate) / annual_vol
    
    return sharpe

## 使用
sharpe = calculate_sharpe_ratio(returns)
print(f"夏普比率: {sharpe:.2f}")

if sharpe < 0:
    print("⚠️  策略收益低于无风险利率，建议优化")
elif sharpe < 1:
    print("📊 策略表现一般")
elif sharpe < 2:
    print("✅ 策略表现良好")
else:
    print("🏆 策略表现优秀")
```

**夏普比率的局限性：**

1. **假设收益服从正态分布**（实际是厚尾分布）
2. **无法区分上行和下行波动**（索提诺比率改进）
3. **对异常值敏感**

**改进版：索提诺比率（Sortino Ratio）**

$$
Sortino = \frac{E[R_p - R_f]}{\sigma_{下行}} 
$$

只惩罚下行波动（负收益的标准差）：

```python
def calculate_sortino_ratio(returns: pd.Series, risk_free_rate: float = 0.03) -> float:
    """计算索提诺比率（只考虑下行风险）"""
    # 年化收益率
    annual_return = returns.mean() * 252
    
    # 下行波动率（只计算负收益）
    downside_returns = returns[returns < 0]
    downside_vol = downside_returns.std() * np.sqrt(252)
    
    # 索提诺比率
    sortino = (annual_return - risk_free_rate) / downside_vol
    
    return sortino

sortino = calculate_sortino_ratio(returns)
print(f"索提诺比率: {sortino:.2f}")
```

#### 6.2.3 VaR（风险价值）

**定义**：在给定置信水平下，预期的最大损失。

$$
P(损失 > VaR_\alpha) = \alpha
$$

**示例**：
- 95% VaR = ¥50,000 的含义：
  - 有95%的概率，日亏损 < ¥50,000
  - 有5%的概率，日亏损 > ¥50,000

**计算方法：**

**方法一：历史模拟法**

```python
def calculate_var_historical(returns: pd.Series, confidence_level: float = 0.95) -> float:
    """
    历史模拟法计算VaR
    
    Args:
        returns: 收益率序列
        confidence_level: 置信水平（如0.95表示95%）
    """
    # 计算分位数
    var = returns.quantile(1 - confidence_level)
    
    return var

## 使用
var_95 = calculate_var_historical(returns, 0.95)
var_99 = calculate_var_historical(returns, 0.99)

print(f"95% VaR: {var_95:.2%}（日亏损不超过此值的概率为95%）")
print(f"99% VaR: {var_99:.2%}（日亏损不超过此值的概率为99%）")

## 换算成金额
capital = 100000
print(f"\n如果本金 ¥{capital:,}：")
print(f"95% VaR: 日亏损 < ¥{abs(var_95 * capital):,.2f}")
print(f"99% VaR: 日亏损 < ¥{abs(var_99 * capital):,.2f}")
```

**方法二：参数法（假设正态分布）**

```python
def calculate_var_parametric(returns: pd.Series, confidence_level: float = 0.95) -> float:
    """参数法计算VaR（假设正态分布）"""
    from scipy import stats
    
    mu = returns.mean()
    sigma = returns.std()
    
    # 标准正态分布的分位数
    z_score = stats.norm.ppf(1 - confidence_level)
    
    # VaR
    var = mu + z_score * sigma
    
    return var
```

**方法三：蒙特卡洛模拟**

```python
def calculate_var_monte_carlo(returns: pd.Series, confidence_level: float = 0.95, 
                              n_simulations: int = 10000) -> float:
    """蒙特卡洛模拟计算VaR"""
    mu = returns.mean()
    sigma = returns.std()
    
    # 模拟未来收益率
    simulated_returns = np.random.normal(mu, sigma, n_simulations)
    
    # 计算VaR
    var = np.percentile(simulated_returns, (1 - confidence_level) * 100)
    
    return var
```

#### 6.2.4 CVaR（条件风险价值）

**定义**：超过VaR时的平均损失（尾部风险）。

$$
CVaR_\alpha = E[损失 \mid 损失 > VaR_\alpha]
$$

```python
def calculate_cvar(returns: pd.Series, confidence_level: float = 0.95) -> float:
    """计算CVaR（条件VaR）"""
    var = calculate_var_historical(returns, confidence_level)
    
    # 计算超过VaR的平均损失
    cvar = returns[returns < var].mean()
    
    return cvar

cvar_95 = calculate_cvar(returns, 0.95)

```

### 6.3 仓位管理理论

#### 6.3.1 固定比例法

**原理**：每次交易投入固定比例的资金。

$$
仓位 = 总资金 \times 固定比例
$$

**优点**：
- 简单易行
- 风险可控

**缺点**：
- 未考虑胜率和盈亏比
- 可能过于保守或激进

```python
def fixed_ratio_position(capital: float, allocation_pct: float = 0.2) -> float:
    """固定比例仓位管理"""
    return capital * allocation_pct
```

#### 6.3.2 凯利公式（Kelly Criterion）

**理论基础**：信息论创始人 John Kelly 于1956年提出。

**目标**：最大化资金增长的长期几何平均收益。

**公式：**

$$
f^* = \frac{bp - q}{b} = p - \frac{q}{b}
$$

- $f^*$：最优仓位比例
- $p$：获胜概率（胜率）
- $q = 1 - p$：失败概率
- $b$：盈亏比（平均盈利 / 平均亏损）

**示例计算：**

```
假设策略：
├─ 胜率 p = 60%
├─ 平均盈利 = ¥500
├─ 平均亏损 = ¥300
└─ 盈亏比 b = 500/300 = 1.67

凯利仓位：
f* = 0.6 - (0.4 / 1.67) = 0.6 - 0.24 = 0.36 = 36%
```

**实战中的修正：**

凯利公式过于激进，实际使用**分数凯利（Fractional Kelly）**：

$$
f_{实际} = f^* \times k, \quad k \in [0.25, 0.5]
$$

```python
def kelly_criterion(win_prob: float, win_loss_ratio: float, 
                   fraction: float = 0.25) -> float:
    """
    凯利公式仓位管理
    
    Args:
        win_prob: 胜率（0-1）
        win_loss_ratio: 盈亏比（平均盈利/平均亏损）
        fraction: 凯利系数（0.25-0.5），降低风险
    
    Returns:
        建议仓位比例
    """
    # 完整凯利仓位
    kelly = win_prob - (1 - win_prob) / win_loss_ratio
    
    # 分数凯利
    adjusted_kelly = max(kelly, 0) * fraction
    
    # 限制最大仓位
    adjusted_kelly = min(adjusted_kelly, 0.5)
    
    return adjusted_kelly

## 使用
position = kelly_criterion(win_prob=0.6, win_loss_ratio=1.67, fraction=0.25)
print(f"建议仓位: {position:.1%}")
```

**凯利公式的局限性：**

| 局限 | 说明 | 解决方法 |
|------|------|----------|
| 需要准确的p和b | 历史数据不代表未来 | 保守估计参数 |
| 波动巨大 | 满仓凯利风险极高 | 使用分数凯利（0.25-0.5） |
| 不考虑回撤 | 可能导致大幅回撤 | 结合最大回撤限制 |

#### 6.3.3 风险平价（Risk Parity）

**核心思想**：每个资产贡献相同的风险。

$$
w_i = \frac{1/\sigma_i}{\sum_j 1/\sigma_j}
$$

- $w_i$：资产i的权重
- $\sigma_i$：资产i的波动率

**原理**：波动率高的资产配置少，波动率低的资产配置多。

```python
def risk_parity_weights(volatilities: np.array) -> np.array:
    """
    风险平价权重计算
    
    Args:
        volatilities: 各资产的波动率数组
    
    Returns:
        各资产的权重
    """
    # 权重与波动率成反比
    inv_vol = 1 / volatilities
    weights = inv_vol / inv_vol.sum()
    
    return weights

## 使用
vols = np.array([0.15, 0.20, 0.25])  # 三个资产的年化波动率
weights = risk_parity_weights(vols)

print("风险平价权重:")
for i, w in enumerate(weights):
    print(f"资产{i+1} (波动率{vols[i]:.0%}): {w:.1%}")
```

### 6.4 止损止盈策略

#### 6.4.1 固定百分比止损

**原理**：价格跌破入场价一定比例时平仓。

$$
止损价 = 入场价 \times (1 - 止损比例)
$$

```python
def fixed_stop_loss(entry_price: float, stop_pct: float = 0.05) -> float:
```

**缺点**：未考虑波动率，可能过早止损

#### 6.4.2 ATR动态止损

**原理**：根据市场波动率（ATR）设置止损。

$$
止损价 = 入场价 - n \times ATR
$$

通常 $n = 2 \sim 3$

```python
def atr_stop_loss(entry_price: float, atr: float, multiplier: float = 2.0) -> float:
    """基于ATR的动态止损"""
    return entry_price - multiplier * atr

entry = 100.0
atr = 3.0
stop = atr_stop_loss(entry, atr, multiplier=2.5)
print(f"入场价: ¥{entry}, ATR: {atr}, 止损价: ¥{stop:.2f}")
```

**优点**：适应市场波动  
**缺点**：波动大时止损位宽，风险大

#### 6.4.3 移动止损（Trailing Stop）

**原理**：跟随价格上涨而上移止损位，锁定利润。

```python
class TrailingStopManager:
    """移动止损管理"""
    
    def __init__(self, initial_stop_pct: float = 0.05, 
                 trailing_pct: float = 0.08):
        self.initial_stop_pct = initial_stop_pct
        self.trailing_pct = trailing_pct
        
        self.entry_price = None
        self.highest_price = None
        self.current_stop = None
    
    def open_position(self, entry_price: float):
        """开仓"""
        self.entry_price = entry_price
        self.highest_price = entry_price
        self.current_stop = entry_price * (1 - self.initial_stop_pct)
        
        print(f"✅ 开仓: 价格 ¥{entry_price:.2f}, 初始止损 ¥{self.current_stop:.2f}")
    
    def update(self, current_price: float) -> tuple:
        """
        更新止损位
        
        Returns:
            (should_close, stop_price)
        """
        # 更新最高价
        if current_price > self.highest_price:
            self.highest_price = current_price
            
            # 更新移动止损
            new_stop = self.highest_price * (1 - self.trailing_pct)
            
            # 止损只能上移，不能下移
            if new_stop > self.current_stop:
                self.current_stop = new_stop
                print(f"📈 止损上移至 ¥{self.current_stop:.2f}")
        
        # 检查是否触发止损
        if current_price <= self.current_stop:
            return (True, self.current_stop)
        
        return (False, self.current_stop)
```

```python
class RiskManager:
    """完整的风险管理框架"""
    
    def __init__(self, stop_loss_pct=0.05, take_profit_pct=0.15, trailing_stop_pct=0.08):
        self.stop_loss_pct = stop_loss_pct  # 止损比例
        self.take_profit_pct = take_profit_pct  # 止盈比例
        self.trailing_stop_pct = trailing_stop_pct  # 移动止损比例

        self.entry_price = price
        self.highest_price = price
        print(f"开仓价格: {price:.2f}")
        print(f"止损价格: {price * (1 - self.stop_loss_pct):.2f}")
        print(f"止盈价格: {price * (1 + self.take_profit_pct):.2f}")
    
    def check_close(self, current_price: float) -> tuple:
        """
        检查是否应该平仓
        
        Returns:
            (should_close, reason)
        """
        if self.entry_price is None:
            return (False, "无持仓")
        
        # 更新最高价（用于移动止损）
        self.highest_price = max(self.highest_price, current_price)
        
        # 计算止损价格
        stop_loss_price = self.entry_price * (1 - self.stop_loss_pct)
        
        # 计算止盈价格
        take_profit_price = self.entry_price * (1 + self.take_profit_pct)
        
        # 计算移动止损价格
        trailing_stop_price = self.highest_price * (1 - self.trailing_stop_pct)
        
        # 检查止损
        if current_price <= stop_loss_price:
            return (True, f"止损触发 (价格: {current_price:.2f})")
        
        # 检查止盈
        if current_price >= take_profit_price:
            return (True, f"止盈触发 (价格: {current_price:.2f})")
        
        # 检查移动止损
        if trailing_stop_price > self.entry_price and current_price <= trailing_stop_price:
            return (True, f"移动止损触发 (价格: {current_price:.2f})")
        
        return (False, "持仓中")
```

```python
class MeanReversionStrategy:
    """均值回归策略"""
    
    def __init__(self, lookback: int = 20, entry_std: float = 2.0,
                 exit_std: float = 0.5):
        self.lookback = lookback
        self.entry_std = entry_std
        self.exit_std = exit_std
    
    def generate_signals(self, df: pd.DataFrame) -> pd.DataFrame:
        """生成信号"""
        df = df.copy()
        
        # 计算均线和标准差
        df['mean'] = df['close'].rolling(self.lookback).mean()
        df['std'] = df['close'].rolling(self.lookback).std()
        
        # 计算 Z-score
        df['z_score'] = (df['close'] - df['mean']) / df['std']
        
        # 生成信号
        # 价格低于均值2倍标准差时买入
        df['signal'] = 0
        df.loc[df['z_score'] < -self.entry_std, 'signal'] = 1
        
        # 价格回归到均值附近时平仓
        df.loc[abs(df['z_score']) < self.exit_std, 'signal'] = -1
        
        df['position'] = df['signal'].replace(0, method='ffill').fillna(0)
        
        return df
```

```python
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import train_test_split
from sklearn.metrics import accuracy_score

class MLStrategy:
    """机器学习策略"""
    
    def __init__(self, lookback: int = 20, prediction_horizon: int = 5):
        self.lookback = lookback
        self.prediction_horizon = prediction_horizon
        self.model = RandomForestClassifier(n_estimators=100, random_state=42)
        self.is_trained = False
    
    def prepare_features(self, df: pd.DataFrame) -> pd.DataFrame:
        """准备特征"""
        df = df.copy()
        
        # 价格特征
        df['return_1'] = df['close'].pct_change(1)
        df['return_5'] = df['close'].pct_change(5)
        df['return_10'] = df['close'].pct_change(10)
        
        # 技术指标
        df['RSI'] = talib.RSI(df['close'].values, timeperiod=14)
        df['MACD'], _, _ = talib.MACD(df['close'].values)
        
        # 波动率
        df['volatility'] = df['close'].pct_change().rolling(20).std()
        
        # 目标变量
        df['target'] = (df['close'].shift(-self.prediction_horizon) > 
                       df['close']).astype(int)
        
        # 删除缺失值
        df.dropna(inplace=True)
        
        return df
    
    def train(self, df: pd.DataFrame):
        """训练模型"""
        df_features = self.prepare_features(df)
        
        # 特征列
        feature_cols = ['return_1', 'return_5', 'return_10', 
                       'RSI', 'MACD', 'volatility']
        
        X = df_features[feature_cols]
        y = df_features['target']
        
        # 划分训练集和测试集
        X_train, X_test, y_train, y_test = train_test_split(
            X, y, test_size=0.2, shuffle=False
        )
        
        # 训练
        self.model.fit(X_train, y_train)
        
        # 评估
        y_pred = self.model.predict(X_test)
        accuracy = accuracy_score(y_test, y_pred)
        
        print(f"训练完成，测试集准确率: {accuracy:.2%}")
        self.is_trained = True
    
    def predict(self, df: pd.DataFrame) -> pd.DataFrame:

        df_features.loc[df_features['prediction'] == 0, 'signal'] = -1
```

```python
                       self.email_config['password'])
```

```python
        self.logger = logging.getLogger('Trading')
        self.logger.setLevel(logging.INFO)
        
        # 文件处理器
        file_handler = RotatingFileHandler(
            log_file, maxBytes=10*1024*1024, backupCount=5
        )
        file_handler.setLevel(logging.INFO)
        
        # 控制台处理器
        console_handler = logging.StreamHandler()
        console_handler.setLevel(logging.INFO)
        
        # 格式化
        formatter = logging.Formatter(
            '%(asctime)s - %(name)s - %(levelname)s - %(message)s',
            datefmt='%Y-%m-%d %H:%M:%S'
        )
        file_handler.setFormatter(formatter)
        console_handler.setFormatter(formatter)
        
        self.logger.addHandler(file_handler)
        self.logger.addHandler(console_handler)
    
    def log_trade(self, action: str, stock_code: str, price: float, 
                  volume: int, timestamp: str = None):
        """记录交易"""
        trade_log = {
            'action': action,
            'stock_code': stock_code,
            'price': price,
            'volume': volume,
            'timestamp': timestamp or datetime.now().isoformat()
        }
        
        self.logger.info(f"交易: {json.dumps(trade_log, ensure_ascii=False)}")
    
    def log_signal(self, stock_code: str, signal: int, price: float):
        """记录信号"""
        self.logger.info(f"信号: {stock_code}, {signal}, 价格: {price}")
    
    def log_error(self, error: str):
        """记录错误"""
        self.logger.error(f"错误: {error}")
```

## 十、最佳实践

### 10.1 策略开发原则

| 原则 | 说明 |
|------|------|
| 简单有效 | 策略越简单，越容易理解和维护 |
| 风险优先 | 优先考虑亏损控制，而非收益最大化 |
| 参数优化 | 避免过度拟合，使用样本外测试 |
| 多样化 | 不要只依赖单一策略或指标 |
| 持续监控 | 定期检查策略表现，及时调整 |

### 10.2 常见陷阱

| 陷阱 | 说明 | 避免方法 |
|------|------|----------|
| 过拟合 | 回测表现好，实盘差 | 样本外测试、参数范围约束 |
| 幸存者偏差 | 只看成功案例 | 全市场测试 |
| 前视偏差 | 使用未来数据 | 严格按时间顺序处理 |
| 交易成本忽略 | 手续费、滑点 | 回测中加入成本 |
| 数据质量问题 | 缺失、错误 | 数据清洗、质量检查 |

```python
import yaml
from dataclasses import dataclass

@dataclass
```
