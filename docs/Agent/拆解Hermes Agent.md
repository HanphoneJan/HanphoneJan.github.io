## 自进化学习机制


Hermes-Agent 的自进化学习机制，并非单一技术，而是一个精密设计的系统闭环。其核心思想是赋予智能体从自身经验中学习与优化的能力，模拟人类 “**实践-反思-沉淀-复用**” 的成长过程。这个机制主要包含以下五个紧密协作的层次：

###  第一层：基石——分层记忆系统

这是自我进化的前提，它让Agent拥有了“记性”。Hermes-Agent采用分层记忆（Memory）架构，从瞬时到持久，层层递进地存储信息。这套分层结构使得记忆系统不仅能记录用户偏好，还能沉淀问题解决方法，实现AI Agent知识体系的持续积累。

| 记忆层级 | 存储形态 | 核心功能 | 技术实现 |
| :--- | :--- | :--- | :--- |
| **L1: 即时记忆**<br>(Instant Memory) | 会话上下文 (Context) | 记住当前对话的每一个细节，确保多轮对话的连贯性。 | 基于Redis的毫秒级响应缓存，支持滑动窗口保留最近200个交互轮次。 |
| **L2: 工作/持久记忆**<br>(Working Memory) | `USER.md` 与 `MEMORY.md` | `USER.md` 记录你的偏好和习惯；`MEMORY.md` 记录项目约定、环境事实等。两者共同构建Agent对你的“认知模型”。 | 普通文本文件，但通过**严格的字符限制**（USER: 1375 chars, MEMORY: 2200 chars）来**倒逼Agent进行信息筛选和压缩**，保持记忆高密度。 |
| **L3: 历史检索记忆**<br>(Archival Memory) | 会话归档数据库 | 存储海量的历史对话记录，供Agent在需要时进行检索和回忆。 | 采用 **SQLite + FTS5全文搜索引擎** 构建向量索引，实现跨会话的语义检索。 |
| **L4: 用户深层画像**<br>(User Modeling) | 实验性模型 | 通过分析交互行为，推断并构建更深层次的用户特征、习惯甚至未明说的偏好。 | 这是更高阶的用户建模系统，旨在更深入地理解用户。 |

### 🛠️第二层：技能化——自动技能生成

有了记忆，Agent便能把经验“做”成可复用的工具——技能（Skill）。这是自进化的核心输出，将抽象经验转化为具体、可复用的操作指南。

Agent并非事无巨细都生成技能，会在以下“有学习价值”的时刻自动触发：
*   ✅ 任务中**调用了5次及以上的工具**。
*   ✅ 成功**从某个错误中恢复**过来。
*   ✅ 用户**给出了明确的修正或指导**。
*   ✅ 发现了一套**非平凡的、有效的工作流程**。

一个Skill会被保存为一个标准格式的 `SKILL.md` 文件，存放在 `~/.hermes/skills/` 目录下。遵循开源的 `agentskills.io` 标准。
### 第三层：引擎——自我改进闭环

这是驱动整个自进化系统运转的动力核心。它由五个环节组成，持续运转，推动Agent不断优化。

1.  **记忆筛选**：在对话间隙，Agent会收到内部“提醒”（Nudge），自主回顾对话，判断并**筛选有价值的信息存入记忆**。
2.  **技能创建**：如前所述，完成任务后，Agent自动评估并**创建新技能**。
3.  **技能自改进**：当用户对技能的执行结果不满意并给出反馈时，Agent会**自动启动差异分析**流程。通过比对执行日志和用户反馈，**自动更新或优化**对应的技能文件。
4.  **跨会话检索**：在新的对话中，Agent会自动通过**全文搜索引擎，按需检索并加载相关的历史记忆片段**，而非全量加载，避免上下文污染和Token浪费。
5.  **可选的强化学习（RL）训练（深度进化）**：这是一种更为彻底的进化方式，可由开发者手动触发，从更根本的层面优化模型性能。

### 第四层：优化器——GEPA算法

在技能优化的底层，Hermes-Agent利用了一个强大的优化算法——**GEPA (Genetic-Pareto Prompt Evolution)**。它能自动分析Agent的执行记录，从失败中学习，并生成更优版本的技能指令（Prompt）。
GEPA的核心优势在于：它不需要进行昂贵的GPU训练，仅通过API调用即可完成优化，使每次优化的成本低至2-10美元，效率极高。

### 第五层：保障——质量与风险控制

为确保进化方向的正确性，系统引入了多重保障机制：
*   **多维度任务价值评估**：生成技能前，Agent会从**执行耗时、用户反馈、未来复用概率**三个维度评估任务，避免为低价值任务创建无用技能。
*   **质量验证门槛**：新生成的技能通过验证、准确率**不低于92%** 后才会被激活。
*   **热更新与版本管理**：技能库支持热更新，系统会为每个技能模块维护一个版本树，支持**快速回滚和A/B测试**，确保系统的稳定性。
