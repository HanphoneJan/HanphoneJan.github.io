# Agent 系列导读

> 这一组按「先用 AI、再看别人怎么搭、最后自己做」的顺序排。它不是 LLM 原理课——Transformer、预训练、微调与部署在 [机器学习](../机器学习/导读.md)。

## 一条线

```text
提示词工程 ──→ Agent 的设计（含 PEAS 与经典范式）──→ 拆解 Claude Code / Hermes
                              │
                              ↓
                        LangChain 入门
```

## 每篇管什么

| 页面 | 什么时候看 |
|---|---|
| [提示词工程](./提示词工程.md) | 写系统提示词、做结构化输出、选 CoT / Few-shot / PAL 时；开头是「把 AI 当结对程序员」的几条习惯 |
| [Agent 的设计](./Agent的设计.md) | 主手册：PEAS 与两套思维方式、开发框架、ReAct / Plan-and-Solve / Reflection、工具体系与 MCP、记忆分层、RAG、上下文工程、向量库、Agentic RL、安全与评估、前端渲染、多 Agent 协议 |
| [拆解 Claude Code](/docs/Agent/拆解Claude%20Code.html) | 想抄一个成熟 CLI Agent 的工程结构：三层 Command / Tool / Skill、分层权限、Plan Mode、子代理、上下文管理、Hook，附安装与配置 |
| [拆解 Hermes Agent](/docs/Agent/拆解Hermes%20Agent.html) | 想做「越用越好」的 Agent：分层记忆、技能自动生成、自我改进闭环 |
| [LangChain 入门](./LangChain入门.md) | 要用框架把模型、提示模板、检索、记忆与 Agent 串起来时 |
