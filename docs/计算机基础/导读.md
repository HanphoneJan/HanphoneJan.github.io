# 系列导读：计算机基础（通用篇）

> 「计算机基础」在这个站上有三套，容易让人以为是三个版本，其实是三个视角。这一篇负责说清楚它们的分工，以及新内容该写进哪一套。

## 三套是什么关系

```text
        计算机基础（通用篇）        ← 概念、原理、教材口径
                 │
      ┌──────────┴──────────┐
      ↓                     ↓
计算机基础（Java 视角）   计算机基础（Python 视角）
   JVM / 字节码 / GC         CPython / GIL / 私有堆
```

- **通用篇（这里，`docs/计算机基础/`）**：操作系统、计算机网络、数据库、编译原理、计算机组成、软件工程这些课程本身的概念与机制。**不绑定任何语言**。
- **[Java 视角](../Java与计算机基础/导读.md)**：同一个概念在 JVM 上落地时多出来的一层——字节码、类加载、GC、虚拟线程、JIT。
- **[Python 视角](../Python与计算机基础/导读.md)**：同一个概念在 CPython 上落地时多出来的一层——GIL、引用计数、pymalloc、字节码。

## 写新内容时放哪一套

1. **默认写进通用篇**——只要这个结论对任何语言都成立。
2. **只有「平台特有行为」才进语言篇**：虚拟线程、GIL、GC 算法、对象头、字节码指令这类，换个运行时就不成立的东西。
3. **不要为了对齐目录而复制一份**。三套之间的差异靠上面的表格互链，不靠内容复制。
