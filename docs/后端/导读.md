# 后端系列导读

> 这一组不是「后端知识体系」，是「哪些东西真正动手跑过」。同一个概念的原理在 [计算机基础](../计算机基础/导读.md) 那三套里，这里只记怎么用、哪里会踩坑。

## 一条线

```text
语言与框架
├─ Java 基础 → Maven → Spring 开发基础
└─ Django / Flask / FastAPI
        ↓
数据库：SQL 速记 → PostgreSQL / ClickHouse / Redis / MongoDB
        ↓
网关与工具：Docker → Nginx
        ↓
实时通信：WebSocket / SSE / WebRTC
        ↓
架构：分布式系统与微服务
        ↓
一个 AI 应用的部署：Dify
```

## 与「计算机基础」三套的分工

站上有三套「计算机基础」，容易和这里混。判据是**问的是"为什么"还是"怎么用"**：

- [计算机基础（通用篇）](../计算机基础/导读.md)：操作系统、计算机网络、数据库、编译原理这些课程本身的概念与机制，不绑定语法、不绑定语言。
- [计算机基础（Java 视角）](../Java与计算机基础/导读.md)、[计算机基础（Python 视角）](../Python与计算机基础/导读.md)：同一个概念在 JVM / CPython 上多出来的那一层——字节码、GC、虚拟线程、GIL、引用计数。
- **这里（后端）**：具体技术栈怎么用。同一个「事务」，通用篇讲 ACID 与隔离级别；[Java 与数据库](../Java与计算机基础/数据库.md) 讲 `@Transactional` 在 JVM 里为什么会失效；这里的 [PostgreSQL 基础](./PostgreSQL基础.md) 讲 MVCC 与 VACUUM 在库内部怎么实现，[SQL 速记](./SQL速记.md) 只给语法。

## 补基础去哪

这一组是「我在用的东西」，不是「该学的东西」。缺的那部分去这几个站点补，按用途挑一个进去，别同时开五个：

- [JavaGuide](https://javaguide.cn/) —— 覆盖面最广的一份中文笔记（网络、操作系统、Java 基础、框架都有）。缺点是太全，容易从头看到尾却什么都没记住；当索引用，遇到具体问题再翻对应章节。
- [Java 全栈知识体系](https://www.pdai.tech/) —— 比 JavaGuide 更偏工程实践，讲框架的来龙去脉而不只是结论，适合系统过一遍 Java 后端技术栈。
- [小林 coding](https://xiaolincoding.com/) —— 图解网络、操作系统、MySQL、Redis。图多，理解机制比背结论快。
- [Waking-Up](https://github.com/wolverinn/Waking-Up) —— 轻量，一条问题一段答案，面试前一周快速过一遍，把忘记的捡回来。
- [代码随想录](https://www.programmercarl.com/) —— 按题型分类的刷题路线，配合本站的[算法训练](/code-training)一起用：那边讲思路，这边讲题单顺序。

三条用法，来自当初记这些链接时的备注：

1. **别通读**。带着问题进去，读那一节，出来。
2. **看完写一遍**。哪怕只写三行摘要——写不出来说明没懂。
3. **过期的结论要标出来**。这类站点更新频率不一，涉及版本行为的（GC、JVM 参数、框架默认值）以官方文档为准。
