这些不是「收藏夹」，是按用途排的四类：系统学、面试前突击、刷题、补系统设计。用的时候挑一个进去，别同时开五个。

## 系统学

- [JavaGuide](https://javaguide.cn/) —— 覆盖面最广的一份中文笔记，网络、操作系统、Java 基础、框架都有。缺点是太全，容易从头看到尾却什么都没记住；适合当索引，遇到具体问题再翻对应章节。
- [Java 全栈知识体系](https://www.pdai.tech/) —— 比 JavaGuide 更偏「工程实践」，讲框架的来龙去脉而不只是结论。适合系统过一遍 Java 后端技术栈。

## 面试前突击

- [Waking-Up](https://github.com/wolverinn/Waking-Up) —— 轻量，一条问题一段答案，适合面试前一周快速过一遍，把忘记的捡回来。
- [小林 coding](https://xiaolincoding.com/) —— 图解网络、操作系统、MySQL、Redis。图多，理解机制比背结论快。

## 刷题

- [代码随想录](https://www.programmercarl.com/) —— 按题型分类的刷题路线，配套本站的[算法训练](/code-training)一起用：那边讲思路，这边讲题单顺序。

## 怎么用

1. **别通读**。带着问题进去，读那一节，出来。
2. **看完写一遍**。哪怕只写三行摘要——写不出来说明没懂。
3. **过期的结论要标出来**。这类站点更新频率不一，涉及版本行为的（GC、JVM 参数、框架默认值）以官方文档为准。
