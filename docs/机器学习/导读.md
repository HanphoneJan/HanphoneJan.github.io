# 机器学习系列导读

> 这一组不是一门课，而是三层：传统机器学习打底，网络结构解释「模型长什么样」，大模型那几篇只在你要动手时才翻。

```text
机器学习入门 ──→ CNN ──→ RNN ──→ 动手学深度学习笔记（第 10–15 章）
                                        │
                                        ↓
```

## 两条使用建议

1. **不要按目录顺序读。** 侧边栏按文件名排，真正的顺序是上面那张流程图。
2. **遇到公式先看形状。** 这一组的推导都围绕「输入输出是什么形状」展开（矩阵乘法、注意力权重、卷积输出尺寸），形状对上了，公式不用背。

## 想跑代码去哪

这一组是**笔记**，不是练习册。可运行的 notebook（回归、K-Means、PCA、DQN 等，带 PyTorch / NumPy 两种实现）在算法训练板块的 [机器学习](/code-training/category/机器学习) 下，两边按主题互相对照即可。
