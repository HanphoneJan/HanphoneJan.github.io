# 运维与排障

这页接着前两页：[A2A 接口](./协议与接口.md)讲远端客户端怎么调，[面板 API](./面板接口.md)讲本机脚本怎么调；这页讲实例怎么管、配置怎么填、数据放哪、出问题按什么顺序查。读者是部署、值守和排障的人。`preset`、`trace`、`facade`、`a2a` 域这些词见[导读的术语表](./导读.md#术语最小集)。前提是 DSH 正在运行，能改 DSH 的 profile（一套宿主配置），也能读宿主日志。

下文统一用 `http://127.0.0.1:3080`。没有配置 `baseUrl`、宿主也没报端口时会回退到 `3000`，以实际监听为准。

## 三个控制面

| 入口 | 在哪里 | 适合 |
|---|---|---|
| 设置页 | 设置 → A2A 连接 | 日常增删改、启停、看对端/会话/任务 |
| `/a2a` 命令 | DSH 聊天窗口 | 不开面板时快速看状态或做同样的操作 |
| 回环 API | `http://127.0.0.1:3080/a2a/api` | 脚本、集成、自动巡检 |

三处最终都落到同一个服务入口（`ctx.a2a` facade）、同一组 manager（两个实例管理器）和同一个 `a2a` 域，状态不会分叉。面板每 3 秒拉一次快照。命令和 API 是即时读写。

## 实例生命周期

![入站与出站实例从创建到删除、以及重启后的状态](/img/dsh-a2a/instance-lifecycle.png)

下面按方向拆开，先看入站。

**入站 server**

| 动作 | 结果 |
|---|---|
| 新建 | 算技能、取 token、搭运行时、落记录。按开关决定是否挂路由 |
| 编辑 | 写 patch，重算技能与 token，替换活实例。路由保持原状态 |
| 启停 | 挂上或撤下卡片与端点。记录、技能、会话池都不动 |
| 删除 | 拆活实例，`inbound_servers` 里写空字符串 |
| 重启 | 逐条重新搭。启用的重新挂路由。活会话和 SSE 订阅丢失 |

**出站连接**

| 动作 | 结果 |
|---|---|
| 添加 | 先落记录，再连。成功记时间并挂工具，失败留 `failed` 视图与 `lastError` |
| 启动 | 每条记录建 registry。启用的异步连接并排刷新定时器 |
| 启停 | 停用会注销工具并断开活连接，视图落 `disconnected`；启用会重新连接。启动时就禁用、没有活连接的实例，启停只写开关，要保存一次编辑或重启才会真正连接 |
| 刷新 | 重读卡片，重建工具 |
| 编辑 | 写 patch，换 registry。启用的重新连 |
| 设置 token | 写凭据、换托管名、重建并重连 |
| 删除 | 拆连接，`outbound_servers` 里写空字符串 |
| 重启 | 记录重新搭，启用的重连。活连接丢失 |

入站 id 是名称 slug 加 8 位十六进制，出站 id 是 `out-` 加 12 位十六进制。删除写空字符串 tombstone（删除标记）而不是删键。读取时只认带前缀且非空的值，所以重启不会复活已删实例。

## 配置与宿主服务

宿主级参数放在 DSH profile 的用户 patch 层，路径是 `$DSH_HOME/profiles/<name>/cordis.patch.yml`（`DSH_HOME` 是 DSH 的 home 目录，默认 `~/.dsh`）：

```yaml
- id: a2a
  config:
    baseUrl: http://127.0.0.1:3080
    subagentProvider: in-process
    defaultTimeoutMs: 60000
    inboundTimeoutMs: 600000
    requestsPerMinute: 120
    maxConcurrentTasks: 32
    maxBodyBytes: 1048576
    outboundRefreshMs: 300000
    inboundTrace: false
```

| 键 | 默认 | 作用 |
|---|---|---|
| `baseUrl` | 未设。按 webServer 端口 → `DSH_A2A_PORT` → `3000` 回退 | 卡片里的对外地址 |
| `subagentProvider` | `in-process` | `subagent` 执行器使用的 provider |
| `defaultTimeoutMs` | `60000` | 出站单次调用超时 |
| `inboundTimeoutMs` | `600000` | 单任务执行预算，超过落 `FAILED`，`0` 关闭 |
| `requestsPerMinute` | `120` | 单来源 60 秒请求数上限，超过 `429`，`0` 关闭 |
| `maxConcurrentTasks` | `32` | 单实例并发任务上限，`0` 关闭 |
| `maxBodyBytes` | `1048576` | 入站请求体上限 |
| `outboundRefreshMs` | `300000` | 出站卡片重读间隔，`0` 关闭 |
| `inboundTrace` | `false` | trace 总闸，也是实例未设置时的默认值 |

启动时会创建 `$DSH_HOME/a2a-sessions` 作为入站会话的工作目录。`DSH_HOME` 默认 `~/.dsh`。

只有 `storageDomain` 缺了就挂不上。表里的 `storageDomain`、`webServer`、`agents` 等是 DSH 的宿主服务名；插件启动时逐个探测，缺了只是对应能力变空：

| 服务 | 缺了会怎样 |
|---|---|
| `storageDomain` | 插件不加载 |
| `webServer` | 入站端点、卡片、面板 API 都不存在 |
| `agents` | 入站任务交给报错的 `refuse` 执行器 |
| `agentPresets` | 选不了 preset，技能退回 `chat` |
| `skills` | 卡片只宣告 `chat` |
| `attachments` | 原始附件变占位文本，输入模式只剩文本 |
| `credentials` | 面板存不了 token。外部环境变量仍可用 |
| `subagents` | 不接 `subagent` 执行器 |
| `agentDefaultModel` | 会话用 harness 默认模型 |
| `tools` | 出站能连，但工具注册不上 |
| `commands` | `/a2a` 不注册 |

基础 `web` profile 会带齐这些服务。自己组合时，至少要有 `storageDomain`、`webServer`、`agents`、`agentPresets`、`skills`、`tools`、`commands`。再按需要补 `attachments`、`credentials`、`subagents`、`agentDefaultModel`。trace 还依赖 `agents` 与 harness 的 `session/event`。

## 存储、备份与升级

持久数据都在 `a2a` 域，版本 `1`，值是 JSON 字符串：

| 表 | 键 | 存什么 |
|---|---|---|
| `tasks` | `task:<taskId>` | 任务记录、输入历史、可选 trace |
| `contexts` | `ctx:<serverId>:<contextId>` | 上下文到会话的绑定 |
| `agents` | `out:<outboundId>` | 该出站连接的 agent 记录数组 |
| `identity` | `service` | 卡片身份字段。当前没有代码写它 |
| `inbound_servers` | `in:<id>` | 入站实例 |
| `outbound_servers` | `out:<id>` | 出站实例 |

默认用 DSH profile 的 JSON 后端。只把 `a2a` 换到 SQLite：

```yaml
- id: storage-domain
  config:
    backend: json
    routes:
      a2a: sqlite
- insert:
    - id: storage-sqlite
      name: '@deepseek-ai/dsh-storage-sqlite'
      config:
        path: /absolute/path/to/a2a.sqlite
```

- **一个 home 同时只能有一个写者。** 两个进程共用 `DSH_HOME` 会写同一个域，实例和任务互相覆盖。跑两个实例时，给它们各自的 home 和端口。
- **任务和绑定会留下，活状态不会。** SSE 订阅、对端表、执行器都在内存。重启清零。
- **记录会变大。** 每次被接受的输入都进 `inputs`。trace 最多 64 条。大附件与长续接会放大体积。
- **旧记录能直接读。** 缺少 `inputs` 时用当前 `parts` 补一条，不需要迁移脚本。
- **会话日志另放。** DSH 自己的持久化在 `$DSH_HOME/sessions/...`。插件只用 `$DSH_HOME/a2a-sessions` 当工作目录。

升级：

```sh
dsh plugin --profile web add @hanphone/dsh-a2a@latest
```

装完重启 `dsh web`。实例与任务还在，活会话不保留。

卸载：

```sh
dsh plugin --profile web remove @hanphone/dsh-a2a
```

卸载不删域数据。要清空实例和任务，得自己删域记录或存储文件。升级或清理前先备份 JSON/SQLite。

## 访问与安全

- **面板 API 只认回环。** 来源必须是 `127.0.0.1`、`::1` 或 `::ffff:127.0.0.1`，否则 `403`。即使套了反向代理，它也不会因此变成可远程调用的接口。
- **A2A 端点与 GUI 共用一个 web server。** 对外暴露时，给每个入站实例配 Bearer，TLS 交给代理。插件自己不监听 TLS。
- **token 只存引用。** 面板把值写进 credentials 服务，托管名是 `A2A_INBOUND_<ID>` 或 `A2A_OUTBOUND_<ID>`（大写，非字母数字变 `_`）。记录里只有名字，卡片里只有方案。
- **取值先问 credentials，再读进程环境。** 外部 `export` 同名变量仍可用。面板改 token 会立刻重建实例，外部变量要等下一次组装。
- **一实例一 token。** 一个泄露不会连带打开其它实例。
- **trace 默认关闭，只走 metadata。** 部署开关、实例策略、`A2A-Extensions` 请求头三者同时满足才生效。摘要里有 callId、工具名、阶段、状态、耗时与时间，参数已脱敏。能读任务的人都能看到它，只对可信对端开。
- **没有 OAuth、mTLS 或按客户端凭据。** 需要更强身份时只能靠代理或网络层。

## 排障顺序

按顺序走，别跳步：

1. **插件在不在？** `/a2a status`，或 `curl -sS http://127.0.0.1:3080/a2a/api`。有快照就说明插件与面板 API 都起来了。
2. **实例有没有？开没开？** `/a2a inbound list`、`/a2a outbound list`。目标要在列表里，`enabled` 为 `true`。
3. **卡片能不能取？** `curl -v <cardUrl>`。`200` 加 JSON 说明路由和端口都对。`404` 多半是停用或路径写错。
4. **协议通不通？** 发一条很小的 `SendMessage`。拿到 `{task}` 且状态 `COMPLETED` 就通了。`401`、`-32602`、`-32001` 分别指向鉴权、参数/门禁、任务。
5. **任务是什么状态？** `/a2a task get <id>` 或 `GET /a2a/api/task?id=`。看 `state`、`error`、`statusText`。
6. **日志怎么说？** 宿主日志搜 `a2a`。会话问题再看 `$DSH_HOME/sessions` 下 `a2a-<实例>-<contextId>`。
7. **版本对不对？** 当前验证组合是插件 `0.5.4` 加 harness `0.2.2-rc.3`。看到 `incompatible-version` 就按下面的条目处理。

## 常见故障

### 任务完成但没有可见回复

**症状**：`state` 是 `TASK_STATE_COMPLETED`，`status.message` 写着 `The agent completed without visible output.`，没有 `result` artifact。

**查什么**：这一轮没有 assistant 文本，可能只调了工具。先确认不是 `FAILED`。再用同样的 preset 开一个普通会话，看 provider 是否正常。

**处理**：要工具过程就开 trace。要文本就换 provider 或改 prompt。执行异常会落 `FAILED`，不会停在这里。

### 请求返回 401

**症状**：HTTP `401`，带 `WWW-Authenticate: Bearer`。

**查什么**：实例是否配了 token。`Authorization: Bearer <token>` 是否带上。token 是否写到了正确的托管名。流式请求也会在读 SSE 之前先返回 `401`。

**处理**：在面板重设或清空 token。外部环境变量要等实例重组。只在代理加头没用，实例自己也会校验。

### 卡片 404 或连接被拒

**症状**：取卡片得到 `404`，或 TCP 直接拒绝。

**查什么**：实例是否启用。路径是不是 `/a2a/<id>/agent-card.json`。DSH 是否监听这个地址。代理有没有转发 `/a2a/` 并保留 `Host`。

**处理**：启用实例，改用面板给出的完整卡片地址。代理补路径与 Host。

### 出站连接是 failed

**症状**：`state` 为 `failed`，`lastError` 有文本。

**查什么**：`HTTP 401` 看 token，`HTTP 404` 看卡片 URL，`invalid agent card` 看返回体是不是卡片 JSON，`advertises no JSON-RPC interface` 看卡片接口。超时、TLS、DNS 各自查网络。

**处理**：改 token 或 URL，点「刷新」重连。失败记录会保留，可直接编辑，不必删。

### 工具缺失或模型不调用

**症状**：连接是 `connected`，但模型工具列表里没有预期条目，或 `toolCount` 为 0。

**查什么**：`skillCount` 与 `toolCount`。技能是否被单独禁用。工具名是否被归一化。连接是否在启动时就处于禁用状态。

**处理**：启用被禁技能。到模型工具列表里看真实名字。启动时禁用的连接，启停只写开关，要先保存一次编辑或重启，连接才会建立。

### 工具返回远端错误

**症状**：工具报错，或返回一个远端 `taskId`。

**查什么**：`Remote agent task failed: ...` 是远端任务失败。`[remote agent TASK_STATE_INPUT_REQUIRED task=<id>] ...` 是要补充输入。`AUTH_REQUIRED` 是要更新 token。`(remote agent returned no output)` 是远端完成但没有可见文本。

**处理**：失败看远端状态消息。中断就用返回的 id 再调。鉴权问题更新出站 token。

### 插件没加载，报 incompatible-version

**症状**：导入前被拒，错误里有 `incompatible-version` 与不满足的范围。

**查什么**：当前 harness 版本是否落在 `package.json` 的 peer 范围里（peer 预检是 DSH 导入插件前的版本范围检查）。插件版本是否与验证记录一致。

**处理**：升级插件或 harness。确实要过一版时用精确豁免：

```sh
dsh plugin allow-version <pkg@version> --dsh-version <runtime> --accept-risk
```

不要用放宽范围来掩盖不兼容。

### 两个 DSH 进程抢存储

**症状**：实例或任务偶尔消失，两个进程看到的列表不一致。

**查什么**：两个进程是否共用同一个 `DSH_HOME`。`a2a` 域按 home 存放，没有多写者协调。

**处理**：一个 `DSH_HOME` 只留一个写者。要跑两个实例，分别给 home 和端口。

### 流式行为不对

**症状**：`curl -N` 没有输出，收到 `METHOD_NOT_FOUND`，或断线后补不到状态。

**查什么**：请求是否带 `Accept: text/event-stream`。方法是不是 `SendStreamingMessage` 或 `SubscribeToTask`。是否把 `SendMessage` 发到了 SSE 路径。任务是否已经终态。

**处理**：换正确的方法与 `Accept`。断线后用 `SubscribeToTask` 加 `Last-Event-ID`。终态任务改用 `GetTask`。事件日志只在当前进程内，重启后补不了。

### trace 没有出现

**症状**：卡片没有扩展，状态帧没有 metadata，任务也没有摘要。

**查什么**：部署 `inboundTrace` 是否为 `true`。实例策略是否允许。卡片 `capabilities.extensions` 是否有 URI。请求是否带 `A2A-Extensions` 且响应回显。任务是否在启动时激活。

**处理**：按部署、实例、卡片、请求头、任务五层核对。给已经跑起来的任务补订阅不会补开 trace。`subagent` 路径不观察子工具。
