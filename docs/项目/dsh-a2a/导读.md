# 导读

本栏目是一套「dsh-a2a」的文档（已做脱敏处理，用于个人复习）。`@hanphone/dsh-a2a` 是 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 的 **Agent2Agent（A2A）v1.0.1 双端插件**：它把一个 DSH profile 变成 A2A 一等公民——一个或多个**入站 server** 把 DSH agent 发布给其他 A2A 客户端；一个或多个**出站连接**把远端 A2A 技能映射为 DSH 内的模型工具。所有实例都在 GUI 里创建、编辑、启停和删除，不需要改配置文件。

本栏目面向安装、运维、排障与维护插件的人：既讲怎么用，也讲内部为什么这样设计。内容描述 **v0.4.0** 在 DeepSeek Harness **0.2.1-rc.2** 上的当前行为。
