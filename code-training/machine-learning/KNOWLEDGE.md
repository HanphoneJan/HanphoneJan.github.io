## 1. 回归算法 (regression/)

### 1.1 线性回归 (Linear Regression)

**核心概念**：建立特征与目标值之间的线性关系模型

**实现方式**：

- **NumPy实现**：从零实现梯度下降，理解参数更新原理

  - 成本函数：均方误差 (MSE)
  - 梯度计算：对权重w和偏置b求偏导
  - 参数更新：w = w - α * ∂J/∂w
- **PyTorch实现**：使用nn.Linear和优化器

  - 利用PyTorch的自动微分(autograd)机制
  - 支持GPU加速训练
- **Scikit-learn实现**：使用LinearRegression类

  - 直接调用，适合快速原型开发

### 1.2 逻辑回归 (Logistic Regression)

**核心概念**：用于二分类问题，输出概率值

**关键要素**：

- Sigmoid激活函数：将线性输出映射到(0,1)区间
- 交叉熵损失函数：衡量预测概率与真实标签的差异
- 决策边界：P(y=1|x) = 0.5 时的分界线

### 1.3 Softmax回归 (Softmax Regression)

**核心概念**：逻辑回归的多分类扩展

**关键要素**：

- Softmax函数：将输出转换为概率分布，满足Σp_i = 1
- 适用于多分类问题（类别数>2）
- 每个类别有独立的权重向量

### 1.4 多项式回归 (Polynomial Regression)

**核心概念**：通过多项式特征扩展，拟合非线性关系

**关键要点**：

- 使用PolynomialFeatures生成高阶特征
- 注意过拟合问题，需要配合正则化
- 选择合适的特征阶数

## 2. 梯度下降 (gradient-descent/)

### 核心原理

**梯度下降**是优化神经网络的核心算法。

**关键概念**：

- **损失函数曲面**：参数空间中的"地形"，目标是找到最低点
- **学习率(α)**：控制每次更新的步长
  - 过大：震荡不收敛
  - 过小：收敛缓慢
- **梯度**：指向损失增长最快的方向，负梯度方向即为下降方向

**交互式可视化**：

- 3D损失曲面与梯度下降轨迹
- 实时调整学习率、初始值观察收敛过程
- 理解局部最小值与全局最小值

## 3. 核心概念实践 (practice/)

### 3.1 激活函数 (activation_functions.ipynb)

激活函数为神经网络引入非线性，是深度学习的关键。

| 激活函数 | 公式                     | 特点                    | 适用场景       |
| -------- | ------------------------ | ----------------------- | -------------- |
| Linear   | f(x) = x                 | 无变化                  | 回归输出层     |
| ReLU     | f(x) = max(0, x)         | 计算简单，解决梯度消失  | 隐藏层默认选择 |
| Sigmoid  | f(x) = 1/(1+e^(-x))      | 输出(0,1)，存在饱和问题 | 二分类输出层   |
| Softmax  | f(x_i) = e^x_i / Σe^x_j | 输出概率分布            | 多分类输出层   |

### 3.2 主成分分析 PCA (pca.ipynb)

**核心概念**：降维技术，保留数据最大方差方向

**实现步骤**：

1. 数据中心化（减去均值）
2. 计算协方差矩阵
3. 特征值分解，获取特征向量
4. 选择前k个最大特征值对应的特征向量
5. 将数据投影到新特征空间

**应用场景**：

- 数据可视化（降至2D/3D）
- 特征压缩
- 降噪

### 3.3 计算图 (computation_graph.ipynb)

**核心概念**：表示复杂运算的有向图，用于自动微分

**关键要素**：

- 节点：变量或运算
- 边：数据流向
- 前向传播：计算输出
- 反向传播：计算梯度（链式法则）

### 3.4 特征缩放 (feature_scaling.ipynb)

**核心概念**：将特征值缩放到相同范围，加速收敛

**常用方法**：

- **标准化(Z-score)**：x' = (x - μ) / σ，均值为0，方差为1
- **归一化(Min-Max)**：x' = (x - min) / (max - min)，范围[0,1]

**重要性**：

- 梯度下降更快收敛
- 避免某些特征主导模型
- 提高数值稳定性

### 3.5 正则化 (tuning_regularization.ipynb)

**核心概念**：防止过拟合的技术

**L2正则化（权重衰减）**：

- 在损失函数中添加 λ/2 * Σw²
- 使权重趋向于小值
- 惩罚大的权重参数

**L1正则化**：

- 添加 λ * Σ|w|
- 产生稀疏权重（部分权重为0）

**正则化系数λ的选择**：

- λ太小：过拟合
- λ太大：欠拟合

## 4. K-Means聚类 (k-means/)

### 核心概念

无监督学习算法，将数据划分为K个簇。

### 算法步骤

1. **初始化**：随机选择K个质心
2. **分配**：每个样本分配到最近的质心
3. **更新**：重新计算每个簇的质心（均值）
4. **迭代**：重复2-3直到收敛

### 距离度量

- 欧氏距离：d(x, c) = √Σ(x_i - c_i)²

### 应用：图像压缩

- 将RGB颜色空间从24位压缩到log₂(K)位
- 用K个颜色表示整幅图像

## 5. 异常检测 (anomaly-detection/)

### 核心概念

基于高斯分布识别偏离正常模式的数据点。

### 算法流程

1. **参数估计**：计算每个特征的均值μ和方差σ²
2. **概率计算**：p(x) = Π p(x_j; μ_j, σ_j²)
3. **阈值选择**：通过验证集选择最佳阈值ε
4. **异常判断**：p(x) < ε 则判定为异常

### 评估指标

- **精确率(Precision)**：预测为异常的样本中真正异常的比例
- **召回率(Recall)**：真正异常的样本中被正确预测的比例
- **F1分数**：精确率和召回率的调和平均

## 6. 决策树 (decision-trees/)

### 核心概念

通过递归分割数据集构建树形决策结构。

### 关键要素

- **特征选择**：选择最佳分割特征（信息增益、基尼不纯度）
- **分割准则**：找到最优分割阈值
- **停止条件**：树深度、叶子节点最小样本数等

### 优点

- 可解释性强
- 无需特征缩放
- 能处理非线性关系

## 7. 推荐系统 (unsupervised-learning/)

### 7.1 协同过滤 (Collaborative Filtering)

**核心概念**：基于用户行为相似性进行推荐

**模型表示**：

- X：电影特征矩阵（电影数 × 特征数）
- W：用户参数矩阵（用户数 × 特征数）
- b：用户偏置项
- 预测评分：y = X · Wᵀ + b

**学习过程**：

- 最小化预测评分与实际评分的误差
- 使用梯度下降优化X、W、b
- 正则化防止过拟合

### 7.2 基于内容的过滤 (Content-Based Filtering)

**核心概念**：基于物品特征和用户偏好的匹配

## 8. 深度强化学习 (reinforcement-learning/)

### 深度Q学习 (Deep Q-Learning, DQN)

**核心概念**：用神经网络近似Q函数，学习最优策略

**关键组件**：

- **Q网络**：输入状态，输出每个动作的Q值
- **目标网络**：计算目标Q值，提高稳定性
- **经验回放(Replay Buffer)**：存储历史经验，随机采样训练
- **ε-贪婪策略**：平衡探索与利用

**更新公式**：

```
Q(s,a) ← Q(s,a) + α[r + γ·max(Q(s',a')) - Q(s,a)]
```

**应用场景**：LunarLander-v3环境控制

## 9. 深度学习模板 (templates/)

### U-Net架构

**核心概念**：编码器-解码器结构，用于图像分割

**结构组成**：

- **DoubleConv**：双层卷积模块
  - Conv + BatchNorm + ReLU
- **Encoder**：下采样路径，提取特征
- **Decoder**：上采样路径，恢复分辨率
- **Skip Connection**：跳跃连接，保留细节信息

### 训练流程模板

- 数据加载 (Dataset/Dataloader)
- 模型定义
- 损失函数和优化器
- 训练循环
- 模型保存与加载
