## 一、深度学习基础认知

### 1.1 深度学习是什么？

**本质**：深度学习是一种**表示学习**（Representation Learning），它通过多层非线性变换，自动从原始数据中学习层次化的特征表示。

**与传统机器学习的区别**：

| 维度     | 传统机器学习     | 深度学习                         |
| -------- | ---------------- | -------------------------------- |
| 特征工程 | 需要人工设计特征 | 自动学习特征                     |
| 数据依赖 | 小数据即可工作   | 需要大量数据                     |
| 计算资源 | 要求较低         | 需要GPU加速                      |
| 可解释性 | 相对较好         | 黑盒特性                         |
| 适用范围 | 结构化数据       | 非结构化数据（图像、文本、语音） |

### 1.2 神经网络的核心组件

```
输入 → [线性变换 → 激活函数] × N → 输出
         ↑         ↑
       权重W    非线性引入
       偏置b
```

**每个组件的作用**：

- **线性变换**：`y = Wx + b`，实现特征的线性组合与维度变换
- **激活函数**：引入非线性，使网络能够逼近任意函数（万能逼近定理）
- **深度（多层）**：学习层次化特征，浅层学边缘/纹理，深层学语义/概念

### 1.3 训练的本质

训练神经网络 = **在高维参数空间中寻找损失函数的极小值**

```
损失函数 L(θ): 衡量模型预测与真实值的差距
目标: 找到 θ* = argmin L(θ)
方法: 梯度下降沿着负梯度方向更新参数
```

**关键问题**：

1. 为什么梯度下降能找到最优解？

   - 对于凸函数，梯度下降保证收敛到全局最优
   - 对于非凸函数（神经网络），梯度下降找到局部最优，通常足够好
2. 为什么随机梯度下降（SGD）比批量梯度下降好？

   - 计算效率高，每次只用一个batch
   - 噪声有助于逃离鞍点和浅层局部最优
   - 隐式正则化效果

## 二、线性神经网络

### 2.1 线性回归：一切的基础

**模型**：`ŷ = Xw + b`

**损失函数（均方误差 MSE）**：

```
L = (1/2n) Σ(ŷᵢ - yᵢ)²
```

除以2是为了求导后消去系数2，简化计算。

**梯度推导**：

```
∂L/∂w = (1/n) Xᵀ(Xw + b - y)
∂L/∂b = (1/n) Σ(ŷᵢ - yᵢ)
```

**参数更新**：

```
w := w - α * ∂L/∂w
b := b - α * ∂L/∂b
```

**为什么线性回归有解析解（正规方程）还需要梯度下降？**

```
解析解: w* = (XᵀX)⁻¹Xᵀy
```

- 解析解需要计算矩阵逆，时间复杂度 O(d³)，d大时不现实
- 梯度下降时间复杂度 O(nd)，适合大规模数据
- 解析解对内存要求高，需要存储整个数据集

### 2.2 Softmax回归：多分类的基石

**Softmax函数**：

```
softmax(zᵢ) = exp(zᵢ) / Σⱼ exp(zⱼ)
```

**为什么用指数函数？**

1. 保证输出为正数
2. 放大差异，最大值更突出
3. 可导，便于梯度计算

**数值稳定性问题**：

```python
# 直接计算会导致指数爆炸
exp(1000) = inf

# 解决方案：减去最大值
softmax(z) = exp(z - max(z)) / Σ exp(z - max(z))
```

**交叉熵损失 vs 均方误差**：

| 特性   | 交叉熵                   | 均方误差           |
| ------ | ------------------------ | ------------------ |
| 梯度   | 与误差成正比，学习信号强 | 梯度小，学习慢     |
| 非线性 | 配合Softmax非线性更强    | 二次函数，曲率固定 |
| 适用   | 分类任务                 | 回归任务           |

**交叉熵的梯度推导**：

```
L = -Σ yᵢ log(ŷᵢ)
∂L/∂z = ŷ - y  (非常简洁！)
```

这个简单的梯度形式是交叉熵配合Softmax被广泛使用的原因。

## 三、多层感知机与优化

### 3.1 为什么需要非线性激活？

**关键结论**：没有激活函数，多层网络等价于单层网络

```
线性 + 线性 = 线性
y = W₂(W₁x + b₁) + b₂ = (W₂W₁)x + (W₂b₁ + b₂) = W'x + b'
```

**常见激活函数对比**：

```python
# ReLU (Rectified Linear Unit)
f(x) = max(0, x)
优点：计算简单，缓解梯度消失
缺点：负值区域神经元死亡

# Leaky ReLU
f(x) = max(αx, x), α=0.01
解决ReLU死亡问题

# Sigmoid
f(x) = 1 / (1 + e^(-x))
优点：输出在(0,1)，适合概率解释
缺点：两端饱和，梯度消失

# Tanh
f(x) = (e^x - e^(-x)) / (e^x + e^(-x))
优点：零中心化，输出在(-1,1)
缺点：仍有梯度消失问题
```

**现代推荐**：隐藏层用 ReLU/LeakyReLU，输出层根据任务选择。

### 3.2 梯度消失与梯度爆炸

**根本原因**：链式法则导致的连乘效应

```
对于L层网络：
∂L/∂W₁ = ∂L/∂hₗ * ∂hₗ/∂hₗ₋₁ * ... * ∂h₂/∂h₁ * ∂h₁/∂W₁

如果每层的梯度 < 1，连乘后指数级减小 → 梯度消失
如果每层的梯度 > 1，连乘后指数级增大 → 梯度爆炸
```

**Sigmoid的梯度消失问题**：

```
sigmoid'(x) = sigmoid(x)(1-sigmoid(x)) ≤ 0.25
即使最优情况，梯度每层衰减为1/4
10层后梯度变为(1/4)^10 ≈ 10⁻⁶
```

**解决方案**：

| 问题     | 解决方案   | 原理                   |
| -------- | ---------- | ---------------------- |
| 梯度消失 | ReLU激活   | 正区间梯度恒为1        |
| 梯度消失 | 残差连接   | 跳跃连接，梯度直接回传 |
| 梯度消失 | 批量归一化 | 稳定每层分布           |
| 梯度爆炸 | 梯度裁剪   | 设定梯度上限           |
| 梯度爆炸 | 权重正则化 | 限制权重大小           |

### 3.3 参数初始化：为什么重要？

**不良初始化的后果**：

- 全零初始化：所有神经元学习相同特征
- 过大初始化：梯度爆炸
- 过小初始化：梯度消失

**Xavier初始化（Glorot初始化）**：

```
W ~ Uniform(-√(6/(n_in+n_out)), √(6/(n_in+n_out)))
```

原理：保持前向和反向传播时方差一致

**He初始化（ReLU专用）**：

```
W ~ Normal(0, √(2/n_in))
```

原理：考虑ReLU会屏蔽一半神经元，方差需要加倍

## 七、优化算法深度解析

### 7.1 梯度下降变体

```
批量梯度下降 (BGD): 用全部数据，方向准但慢
随机梯度下降 (SGD): 用一个样本，快但噪声大
小批量梯度下降 (Mini-batch): 折中，最常用
```

### 7.2 动量法（Momentum）

**物理直觉**：将参数更新类比为球在损失函数表面滚动

```
vₜ = βvₜ₋₁ + (1-β)∇L(θₜ)
θₜ₊₁ = θₜ - αvₜ
```

**效果**：

- 加速收敛（在一致方向上累积速度）
- 减少震荡（垂直方向速度相互抵消）
- 有助于逃离局部最优

### 7.3 Adam优化器

**核心思想**：自适应学习率 + 动量

```
mₜ = β₁mₜ₋₁ + (1-β₁)gₜ      # 一阶矩估计（动量）
vₜ = β₂vₜ₋₁ + (1-β₂)gₜ²     # 二阶矩估计（梯度平方的指数平均）
m̂ₜ = mₜ / (1-β₁ᵗ)           # 偏差修正
v̂ₜ = vₜ / (1-β₂ᵗ)           # 偏差修正
θₜ₊₁ = θₜ - α·m̂ₜ/(√v̂ₜ + ε)
```

**参数推荐**：

- β₁ = 0.9（动量系数）
- β₂ = 0.999（二阶矩系数）
- ε = 10⁻⁸（数值稳定）

**Adam vs SGD**：

- Adam：收敛快，适合稀疏梯度，调参简单
- SGD：泛化通常更好，最终精度可能更高，需要调学习率

## 八、正则化与泛化

### 8.1 过拟合的本质

**定义**：模型在训练集表现好，但在测试集表现差

**原因**：

1. 模型复杂度相对于数据量过高
2. 训练数据包含噪声，模型学习了噪声
3. 训练数据不具代表性

**检测方法**：

```
训练误差 << 测试误差 → 过拟合
训练误差 ≈ 测试误差但都高 → 欠拟合
```

### 8.2 L2正则化（权重衰减）

**原理**：惩罚大的权重，使模型更平滑

```
L' = L + λ/2 * ||W||²
```

**为什么有效？**

- 权重小 → 函数变化平缓 → 对输入噪声不敏感
- 限制模型复杂度 → 奥卡姆剃刀原则

**与提前停止的关系**：
理论上等价，实际中提前停止更常用（不需要调λ）

### 8.3 Dropout

**原理**：训练时随机丢弃神经元，测试时用全部

**为什么有效？**

1. **集成学习解释**：每次dropout相当于训练一个子网络，测试时是 ensemble
2. **共适应打破**：防止神经元过度依赖特定其他神经元
3. **隐式数据增强**：每次训练看到不同的"数据视图"

**实现细节**：

```python
# 训练
mask = (torch.rand(x.shape) > p).float()
x = mask * x / (1-p)  # 缩放保证期望不变

# 测试
x = x  # 不变，但通常实现为训练时缩放，测试时不做
```

**Dropout率选择**：

- 输入层：0.2（信息不能丢太多）
- 隐藏层：0.5（常用默认值）
- 太高：欠拟合；太低：过拟合

### 8.4 数据增强

**图像数据增强**：

- 几何变换：翻转、旋转、裁剪、缩放
- 颜色变换：亮度、对比度、饱和度
- 噪声添加：高斯噪声、椒盐噪声

**原则**：增强后的数据应该保持标签不变

## 九、计算机视觉实践

### 9.1 卷积神经网络核心思想

**全连接层的问题**：

- 28×28图像 → 784维输入，参数量巨大
- 没有利用图像的空间结构信息

**卷积的优势**：

1. **稀疏连接**：每个神经元只连接局部区域
2. **权重共享**：同一卷积核在整个图像滑动
3. **平移等变**：目标移动，特征图相应移动

### 9.2 目标检测：SSD

**核心思想**：

1. **多尺度检测**：不同层负责检测不同大小的目标
2. **锚框机制**：预设不同比例的先验框
3. **端到端训练**：同时预测类别和位置偏移

**损失函数**：

```
L = L_cls（分类损失） + λL_loc（定位损失）
```

**与两阶段检测器（Faster R-CNN）对比**：

- SSD：速度快，适合实时应用
- Faster R-CNN：精度高，速度慢

### 9.3 语义分割：FCN

**核心思想**：全卷积网络，输出与输入等大的分割图

**关键技术**：

1. **转置卷积（反卷积）**：上采样恢复空间分辨率
2. **跳跃连接**：融合深层语义信息和浅层位置信息

## 十、自然语言处理实践

### 10.1 Word2Vec

**Skip-gram模型**：用中心词预测上下文词

**关键技术——负采样**：

```
原始：Softmax需要计算整个词汇表
负采样：将多分类转为二分类（正样本+K个负样本）
```

**为什么负采样有效？**

- 计算复杂度从 O(V) 降到 O(K)，K=5-20
- 高频词被更多采样，符合Zipf定律

### 10.2 BERT深度解析

**预训练任务**：

1. **MLM（Masked Language Model）**：

   ```
   输入：我 [MASK] 北京 天安门
   目标：预测 [MASK] = 爱

   掩码策略：
   - 80% 替换为 [MASK]
   - 10% 随机替换为其他词
   - 10% 保持不变

   目的：让模型学到双向上下文
   ```
2. **NSP（Next Sentence Prediction）**：

   ```
   输入：[CLS] 句子A [SEP] 句子B [SEP]
   目标：判断B是否是A的下一句

   目的：学习句子级别关系
   ```

**BERT vs GPT**：

| 特性   | BERT                | GPT                      |
| ------ | ------------------- | ------------------------ |
| 架构   | Transformer Encoder | Transformer Decoder      |
| 方向   | 双向                | 单向（自回归）           |
| 预训练 | 完形填空            | 语言模型（预测下一个词） |
| 适用   | 理解任务            | 生成任务                 |

**微调（Fine-tuning）策略**：

1. 分类任务：[CLS] token的输出接分类器
2. 序列标注：每个token的输出独立分类
3. 问答任务：预测答案的开始和结束位置

## 十一、实战技巧与踩坑总结

### 11.1 训练不收敛的排查清单

```
□ 学习率是否合适？（太大震荡，太小不收敛）
□ 损失函数是否正确？（分类用交叉熵，回归用MSE）
□ 数据是否归一化？（输入范围应在合理区间）
□ 梯度是否正常？（检查是否有nan/inf）
□ 标签是否正确？（检查数据加载器）
□ 模型架构是否合理？（层数、维度）
```

### 11.2 提升模型性能的技巧

**必做**：

1. 数据归一化/标准化
2. 权重初始化
3. 学习率衰减
4. 早停（Early Stopping）

**进阶**：

1. 学习率预热（Warmup）
2. 标签平滑（Label Smoothing）
3. 混合精度训练
4. 模型集成

### 11.3 常见错误与解决方案

| 错误现象         | 可能原因             | 解决方案                |
| ---------------- | -------------------- | ----------------------- |
| Loss不下降       | 学习率太小/梯度消失  | 增大学习率/换激活函数   |
| Loss震荡         | 学习率太大/batch太小 | 减小学习率/增大batch    |
| Loss为nan        | 梯度爆炸/数值溢出    | 梯度裁剪/降低学习率     |
| 训练集好测试集差 | 过拟合               | Dropout/正则化/更多数据 |
| 两者都差         | 欠拟合               | 增加模型容量/训练更久   |
