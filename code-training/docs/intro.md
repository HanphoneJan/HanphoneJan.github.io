# 算法训练场

欢迎来到算法训练场。这里是我系统刷题、整理知识点、总结算法模式的学习空间。

## 内容结构

| 板块 | 说明 |
|------|------|
| [题目库](category/题库) | 按平台分类的算法题解，包含完整思路、代码和复杂度分析 |
| [机器学习](category/机器学习) | Jupyter Notebooks 转换的机器学习深度笔记 |
| [知识点](category/知识点) | 数据结构、算法分类的知识体系梳理 |
| [算法模式](category/算法模式) | 通用解题套路和思维框架 |
| [代码模板](category/代码模板) | 常用算法的标准实现，可直接复用 |
| [复习系统](category/复习系统) | 错题本和周总结，用于巩固薄弱点 |

## 使用方式

- **搜索**：页面右上角搜索框支持全局搜索所有内容
- **分类浏览**：通过左侧边栏按板块浏览
- **代码复制**：代码块右上角有复制按钮
- **评论**：每道题解底部都有 Giscus 评论，可留言讨论

## 统计

- 题解数量：持续增长中
- 覆盖平台：LeetCode 为主
- 难度分布：简单、中等、困难全覆盖
