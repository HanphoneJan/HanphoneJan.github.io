# AI Coding编程题技巧

> AI Coding 题给的是 README、一份可能不完整的代码和一套隐藏用例。它不像算法题那样考某个套路，考的是能不能把需求拆成功能点、写成能执行的文档，再分块做到过用例。下面是目前整理出的技巧。

## 技巧一：五步，从 README 到能过用例

1. **读 README，列功能点。** 先让模型复述需求，复述歪了说明它没读懂，后面全是错的；再把复述拆成功能点清单，每一点要能回答「什么输入、做什么、输出什么」。

2. **圈出重点模块，补功能点，写开发文档。** 指出 README 里重点写的几个模块，让它在这几块上深入，顺手补齐第一步漏掉的功能；然后把代码也给它，产出开发文档（每个功能的入口、输入输出、依赖谁、失败怎么处理）。

3. **新开会话做对齐。** 同时给 README 和开发文档，让它逐条对功能，把没覆盖、写歪的地方补回文档。这一步的产出只有文档，别让它顺手改代码。

4. **按文档分功能实现，一个大功能一个会话。** 每个会话只给它文档里对应的那一节和相关代码，做完就提交。到这一步，提交一般都 88xx 了。

5. **再新开会话压边界。** 把提交结果给它，让它想清楚边界条件、补测试样例；测试自己跑，把真实输出贴回去再让它改代码。反复几次，基本就能 888x。

五步的顺序不能换：文档在前、代码在后，对齐在实现之前。
