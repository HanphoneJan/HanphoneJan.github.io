# P5919. 脉冲后序右侧和

> 场次：2026年10月14日-非AI方向 · 来源：[CodeFun2000 P5919](https://codefun2000.com/p/P5919)

## 题目描述

星际探索途中，人类撞见一座年代久远的外星通讯塔。坐标靠一串能量脉冲向外发送。科学家确认，这些互不相同的正整数强度，其实按**二叉排序树**组织，用来加快检索。

接收端拿到的是一整段脉冲。它记录的是这棵树的**后序遍历**。

宇宙射线会把这段记录弄乱，于是它未必还能还原成合法的二叉排序树。请完成下面这个核心模块：

- **校验：** 判断这段强度能否当作某棵合法二叉排序树的后序遍历。
- **解码：** 若能够还原，再求出这座塔「**右缘轮廓**」上的强度总和。

**注：** 「右缘轮廓」是从树的右侧望过去，每一层最后映入眼帘的那个结点（也就是该层最靠右的结点）所带的强度。

**输出：** 能还原时，写下右缘轮廓的强度总和；不能还原时，记成 $-1$。

## 输入格式

数据来自标准输入。

- 单独一行，若干整数以空格隔开，依次是收到的强度。

**数据范围：**

- 序列长度 $m$：$1 \le m \le 10000$
- 每个强度 $w$：$1 \le w \le 10^9$，且彼此不重复

## 输出格式

- 能够还原时，输出一个整数，即右缘轮廓的强度总和。
- 不能还原时，输出 $-1$。

## 示例

### 示例 1

**输入：**

```
3 8 6 12 15 10
```

**输出：**

```
37
```

**说明：**

这段记录末尾的根是 $10$。比 $10$ 小的 $[3, 8, 6]$ 是左子树，比 $10$ 大的 $[12, 15]$ 是右子树。还原后的树是：

![](file://Omllk4yGPiFp8wKPlgon-.png)

- 第 $0$ 层最靠右：$10$
- 第 $1$ 层最靠右：$15$
- 第 $2$ 层最靠右：$12$

右缘轮廓总和：$10 + 15 + 12 = 37$。

### 示例 2

**输入：**

```
3 10 5 8
```

**输出：**

```
-1
```

**说明：**

根是 $8$。由最后一个小于 $8$ 的数 $5$ 划出的左段是 $[3, 10, 5]$。其中 $10 > 8$，破坏了左子树必须更小的规则，所以这段记录不能还原，输出 $-1$。

### 示例 3

**输入：**

```
4 7 9
```

**输出：**

```
20
```

**说明：**

根是 $9$。$4 < 9$、$7 < 9$，都落在左子树；又有 $4 < 7$，于是 $4$ 挂在 $7$ 的左侧，整棵树一路向左（根 $9$，左孩子 $7$，再往左是 $4$）。从右侧望去，各层可见的强度分别是 $9$、$7$、$4$。

右缘轮廓总和：$9 + 7 + 4 = 20$。

## 提示

1. 当 $m = 1$ 时，序列里只有一个结点，它自己就是合法的根。
2. 还原这棵树要在 $O(m)$ 内完成，否则极端形态可能超时。建议用**单调栈**从叶子往根挂边，以免朴素递归分治退化成 $O(m^2)$，也避免递归过深把调用栈撑爆。

## 解题思路

### 输出有两层：先判断「能不能还原」，再谈「右缘和」

题面把两个问题缝在一次输出里。第一层是校验：给出的序列必须确实是**某棵**二叉排序树的后序遍历，否则输出 $-1$。第二层是统计：校验通过后，把「右缘轮廓」——每一层最靠右那个结点的强度——加起来。

后序的定义决定了校验的形状：最后一个元素是根，剩下的部分被切成「右子树的后序」和「左子树的后序」两段，而且这两段的**每一个**元素都要落在祖先一路给出的开区间里。统计那一半与校验无关，只要树的父子关系建好了，一次「先右后左」的遍历就能拿到每层最右的结点。

数值上留个心眼：$m \le 10^4$、单值 $10^9$，和可以到 $10^{13}$ 量级。Python 的整数不受限，写成 C++ 就得用 `long long`。

### 朴素做法：递归切分，代价是 O(m²) 与 m 层递归

把上面的定义直译成代码：

```python
def ok(seq, lo, hi):
    if not seq:
        return True
    root = seq[-1]
    if not (lo < root < hi):
        return False
    k = len(seq) - 1
    while k > 0 and seq[k - 1] > root:   # 从右往左找「右子树」与「左子树」的分界
        k -= 1
    return ok(seq[k:-1], root, hi) and ok(seq[:k], lo, root)
```

它是对的，但 $m \le 10^4$ 下有两条退化路径，各自踩一个坑：

- **递减序列**（右链）：$[7,6,5,4,3,2,1]$ 每层的根都是最小值，`while` 要扫完整段才停，总代价 $m+(m-1)+\dots = O(m^2)$，$10^4$ 时约 $5\times10^7$ 次比较；
- **递增序列**（左链）：每层只剥掉一个元素，递归深度正好 $m$，超过 Python 默认的 $1000$ 层直接 `RecursionError`。

递归写法其实是把「同一段序列被反复扫描」和「树形决定调用深度」两件事一起押上了，而这两件事在本题的极端形态下都会输。

### 关键观察：倒着读后序，栈里躺着一条「右脊」

后序是「左、右、根」，所以**倒着读**是「根、右子树、左子树」。从头往回走：

- 当前值比栈顶大，它必然是栈顶的**右孩子**——因为右子树整体排在父亲前面，倒读时就紧跟在父亲后面；
- 当前值比栈顶小，说明右子树已经结束、进入某棵左子树了：把栈里所有比它大的结点弹出，**最后弹出的那个就是它的父亲**。

于是栈里保存的正是「从根一路向右走、还没往左分叉」的那条链，值自底向顶严格递增。每个结点还要随身带着它这棵子树允许的**开区间**，因为「右孩子比父亲大」只保证了对直接父亲成立，对更上面的祖先不一定：

```python
if v > stack[-1][0]:
    # 右孩子：必须小于栈顶那棵子树的上界
    val, _lo, hi, p = stack[-1]
    if v >= hi:
        return -1
    right[p] = i
    stack.append((v, val, hi, i))
else:
    # 左孩子：弹掉所有大于 v 的结点，最后弹出的是父亲
    parent = stack.pop()
    while stack and stack[-1][0] > v:
        parent = stack.pop()
    if v <= parent[1]:          # 必须大于父亲那棵子树的下界
        return -1
    left[parent[3]] = i
    stack.append((v, parent[1], parent[0], i))
```

两处区间检查就是全部校验。`parent[1]` 是父亲的下界（由更上面的祖先给出），`parent[0]` 是父亲自己的值——左孩子必须落在 $(\text{父下界},\ \text{父值})$ 之间，所以入栈时区间正好是 `(parent[1], parent[0])`。

这个过程与树的高度无关：每个结点至多入栈、出栈各一次，$O(m)$ 扫完，也没有一帧递归。

### 统计右缘：先右后左，每层只看第一个

「每层最靠右」换个说法就是：**从右往左看，每个深度第一个被访问到的结点**。所以遍历顺序定为先右子树、后左子树，再用一个 visited 集合记下已经统计过的深度：

```python
work = [(m - 1, 0)]        # (结点下标, 深度)，根在下标 m-1
while work:
    node, depth = work.pop()
    if depth not in visited:
        visited.add(depth)
        total += post[node]
    if left[node] != -1:
        work.append((left[node], depth + 1))
    if right[node] != -1:
        work.append((right[node], depth + 1))
```

注意入栈顺序：显式栈是后进先出，想让右孩子先出栈，就得**左孩子先入、右孩子后入**。写反了每个深度记录的就成了最靠左的结点。

### 为什么这里不能用「先序的 low 界」那一招

校验 BST 有一个很有名的 $O(n)$ 写法：正着读先序，栈里放还没往左分叉的结点，每弹出一个就更新 `low`，当前值小于 `low` 即非法。把这段代码原样搬到「倒读后序」上，样例 1 的合法序列会被判死：

```text
倒读 [3,8,6,12,15,10] = 10, 15, 12, 6, 8, 3
读 10 -> 栈 [10]
读 15 -> 弹出 10 并把 low 抬到 10，栈 [15]
读 12 -> 12 > low(10)，栈 [15,12]
读  6 -> 6 < low(10)，判非法   ← 但整棵树明明是合法的
```

原因在于倒读后序是「根、右、左」，同一个结点既要受祖先给的上界约束（右孩子一侧），又要受下界约束（左孩子一侧），单个 `low` 只压住了其中一边。这也正是这里每个栈元素要带 `(值, 下界, 上界)` 三元组的原因。

### 实现映射

- `run(post)`：校验与统计都在这里；$m=1$ 直接返回该结点本身（它既是根，也是唯一位于第 0 层的结点）；
- 栈的初值是根 `(post[-1], 0, 1 << 62, m - 1)`，下界取 $0$（强度都是正整数）、上界给一个足够大的哨兵值；
- `left[]` / `right[]` 两个数组记父子关系，下标就是序列下标，省掉建对象；
- 校验通过后才进入那段先右后左的显式栈遍历。

## 完整代码实现

```python
"""
P5919. 脉冲后序右侧和 - 单调栈还原 BST + 右缘轮廓

一段两两不同的正整数序列，声称是某棵二叉排序树的后序遍历。
先校验它能否还原；能还原时，求「右缘轮廓」的强度总和——从树的
右侧望过去，每层最后一个（最靠右的）结点强度之和；不能还原输出 -1。

输入格式：
- 单独一行，若干空格隔开的正整数（长度 m ≤ 10000，值 ≤ 1e9 且互不相同）。

输出格式：
- 能还原时输出右缘轮廓强度总和；否则输出 -1。

核心思路：
后序遍历倒着读是「根 → 右子树 → 左子树」。维护一条单调递增的栈
（还没向左分叉的右脊）：当前值比栈顶大，就作为栈顶的右孩子入栈，
必须落在 (栈顶, 栈顶上界) 这个开区间里；比栈顶小，就把所有比它大的
结点弹出，最后一个弹出的是它的父亲，它作为左孩子必须大于父亲自己的
下界。两处区间检查任一不满足即整段作废。整个过程每条边只处理一次，
O(m) 内还原完毕，也不受树退化成链时的递归深度影响。校验通过后再用
显式栈做一次「先右后左」的 DFS，每个深度第一次到达的结点就是该层
最靠右的结点。

时间复杂度：O(m)
空间复杂度：O(m)
"""

# https://codefun2000.com/p/P5919
import io
import sys

# @sample-start
"""
样例输入 1:
3 8 6 12 15 10

样例输出 1:
37
"""
# @sample-end

# @sample-start
"""
样例输入 2:
3 10 5 8

样例输出 2:
-1
"""
# @sample-end

# @sample-start
"""
样例输入 3:
4 7 9

样例输出 3:
20
"""
# @sample-end


def run(post):
    """校验并求右缘轮廓和；不能还原返回 -1。"""
    m = len(post)
    if m == 1:
        return post[0]

    left = [-1] * m
    right = [-1] * m
    # 栈元素：(值, 子树取值下界, 子树取值上界, 结点下标)，
    # 左右孩子的取值都必须落在开区间（下界, 上界）之内
    stack = [(post[-1], 0, 1 << 62, m - 1)]

    for i in range(m - 2, -1, -1):
        v = post[i]
        if v > stack[-1][0]:
            # 比栈顶大：作为栈顶的右孩子
            val, _lo, hi, p = stack[-1]
            if v >= hi:
                return -1
            right[p] = i
            stack.append((v, val, hi, i))
        else:
            # 比栈顶小：弹出所有更大的结点，最后弹出的就是父亲
            parent = stack.pop()
            while stack and stack[-1][0] > v:
                parent = stack.pop()
            # v 是父亲的左孩子，必须落在父亲子树的开区间下界之上
            if v <= parent[1]:
                return -1
            left[parent[3]] = i
            stack.append((v, parent[1], parent[0], i))

    # 先右后左的 DFS：栈是后进先出，左孩子先入队、右孩子后入队，
    # 每个深度第一次出栈的就是该层最靠右的结点
    total = 0
    visited = set()
    work = [(m - 1, 0)]
    while work:
        node, depth = work.pop()
        if depth not in visited:
            visited.add(depth)
            total += post[node]
        if left[node] != -1:
            work.append((left[node], depth + 1))
        if right[node] != -1:
            work.append((right[node], depth + 1))
    return total


def solve():
    post = [int(x) for x in sys.stdin.buffer.read().split()]
    if not post:
        return
    print(run(post))


def run_tests():
    """运行嵌入的官方样例与边界/随机对拍用例，方便本地自测。"""
    import random
    from itertools import permutations

    cases = [
        # 官方样例 1：右缘 10 + 15 + 12 = 37
        ("3 8 6 12 15 10\n", "37"),
        # 官方样例 2：10 落在左子树里，破坏 BST 性质
        ("3 10 5 8\n", "-1"),
        # 官方样例 3：一路向左的链，右缘就是这条链
        ("4 7 9\n", "20"),
        # 单结点：它自己就是全部
        ("5\n", "5"),
        # 严格递增：整棵树是一条左链，右缘从底到顶全部可见
        ("1 2 3 4 5 6 7\n", "28"),
        # 严格递减：整棵树是一条右链，右缘就是全链之和
        ("7 6 5 4 3 2 1\n", "28"),
        # 3 挂成根 4 的左孩子后，5 再无处可挂（越 4 的上界）
        ("5 3 4\n", "-1"),
        # 右孩子的孩子越过（祖父）上界：5 只能挂在 2 的右孩子上，却大于 4 的上界
        ("1 5 2 4\n", "-1"),
        # 比样例 1 多一枚挂在最左下、轮廓仍与样例 1 相同
        ("5 6 12 15 10\n", "37"),
        # 双结点两种次序：和都是 3
        ("1 2\n", "3"),
        ("2 1\n", "3"),
        # 10000 长度左链（严格递增序列），O(m) 直通
        (" ".join(map(str, range(1, 10001))) + "\n", str(sum(range(1, 10001)))),
        # 10000 长度右链（严格递减序列）
        (" ".join(map(str, range(10000, 0, -1))) + "\n", str(sum(range(1, 10001)))),
    ]

    for i, (inp, expected) in enumerate(cases, 1):
        old_stdin, old_stdout = sys.stdin, sys.stdout
        sys.stdin = io.TextIOWrapper(io.BytesIO(inp.encode("utf-8")))
        sys.stdout = io.StringIO()
        try:
            solve()
            output = sys.stdout.getvalue().strip()
        finally:
            sys.stdin, sys.stdout = old_stdin, old_stdout
        status = "✓" if output == expected else "✗"
        print(f"用例 {i}: 期望={expected}, 实际={output} {status}")

    # 随机对拍：小规模全排列穷举 + 较大规模随机抽样，
    # 与「递归区间校验 + 递归建树求右缘」的独立实现比对
    random.seed(20261027)
    fails = 0
    checked = 0

    def brute(post):
        """递归版：区间校验通过则建树求右缘和，否则 -1。"""
        def ok(seq, lo, hi):
            if not seq:
                return True
            root = seq[-1]
            if not (lo < root < hi):
                return False
            k = len(seq) - 1
            while k > 0 and seq[k - 1] > root:
                k -= 1
            # 后半段 > root 是右子树，前半段 < root 是左子树
            return ok(seq[k:-1], root, hi) and ok(seq[:k], lo, root)

        if not ok(post, 0, 1 << 62):
            return -1

        def build(seq, lo, hi):
            root = seq[-1]
            k = len(seq) - 1
            while k > 0 and seq[k - 1] > root:
                k -= 1
            left_sub = build(seq[:k], lo, root) if k else None
            right_sub = build(seq[k:-1], root, hi) if k < len(seq) - 1 else None
            return (root, left_sub, right_sub)

        tree = build(post, 0, 1 << 62)
        seen, total = set(), 0

        def walk(node, depth):
            nonlocal total
            if node is None:
                return
            # 先右后左：每个深度第一次到达的就是最靠右结点
            if depth not in seen:
                seen.add(depth)
                total += node[0]
            walk(node[2], depth + 1)
            walk(node[1], depth + 1)

        walk(tree, 0)
        return total

    for m in (1, 2, 3, 4, 5, 6):
        for perm in permutations(range(1, m + 1)):
            got, expect = run(list(perm)), brute(list(perm))
            checked += 1
            if got != expect:
                fails += 1
                print(f"穷举不一致: {list(perm)} got={got} expect={expect}")
    for _ in range(400):
        m = random.randint(7, 11)
        perm = list(range(1, m + 1))
        random.shuffle(perm)
        got, expect = run(perm), brute(perm)
        checked += 1
        if got != expect:
            fails += 1
            print(f"抽样不一致: {perm} got={got} expect={expect}")
    print(f"对拍 {checked} 组: {'全部一致 ✓' if fails == 0 else f'{fails} 组不一致 ✗'}")


if __name__ == "__main__":
    if len(sys.argv) > 1 and sys.argv[1] == "--test":
        run_tests()
    else:
        solve()
```

## 示例推演

样例 1，$post = [3, 8, 6, 12, 15, 10]$，$m = 6$。初始把根 $(10,\ 0,\ +\infty,\ 5)$ 压栈，然后从下标 $4$ 往回走：

| 读入 | 与栈顶比较 | 弹栈 | 区间检查 | 结果 |
| ---- | ---------- | ---- | -------- | ---- |
| $15$ | 大于 $10$ | 不弹 | 右孩子须 $<+\infty$ ✓ | `right[10]=15`，栈 $[10,15]$ |
| $12$ | 小于 $15$ | 弹 $15$ | 左孩子须 $>10$ ✓ | `left[15]=12`，栈 $[10,12]$ |
| $6$ | 小于 $12$ | 弹 $12$、弹 $10$ | 左孩子须 $>0$ ✓ | `left[10]=6`，栈 $[6]$ |
| $8$ | 大于 $6$ | 不弹 | 右孩子须 $<10$（$10$ 是 $6$ 的上界）✓ | `right[6]=8`，栈 $[6,8]$ |
| $3$ | 小于 $8$ | 弹 $8$、弹 $6$ | 左孩子须 $>0$ ✓ | `left[6]=3`，栈 $[3]$ |

还原出来的树：

```text
        10
       /  \
      6    15
     / \   /
    3   8 12
```

先右后左遍历：根 $10$ 记第 $0$ 层；接着进右子树，$15$ 记第 $1$ 层；$15$ 只有左孩子，$12$ 记第 $2$ 层；再回到左子树，$6$、$8$、$3$ 所在深度都已被记录过。右缘 $=10+15+12=37$。

样例 2，$post = [3, 10, 5, 8]$：根是 $8$。读 $5$ 时弹掉 $8$，$5$ 成为 $8$ 的左孩子，入栈区间取 $(0,\ 8)$。接着读 $10$：它比栈顶 $5$ 大，走右孩子分支，而上界正是 $8$——$10 \ge 8$，当场判 $-1$。错就错在「$10$ 明明比 $8$ 大，却被安排进了 $8$ 的左侧」。

样例 3，$post = [4, 7, 9]$：$7<9$ 成为 $9$ 的左孩子（区间 $(0,9)$），$4<7$ 又成为 $7$ 的左孩子（区间 $(0,7)$）。整棵树是一条向左的链，每一层只有一个结点，右缘自然就是 $9+7+4=20$。

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| ---- | ---------- | ---------- | ---- |
| 递归切分校验 + 递归建树 | $O(m^2)$ | $O(m)$ | 递减序列每层扫完整段前缀；递增序列递归深度到 $m$，超过默认上限 $1000$ |
| 单调栈挂边 + 显式栈求右缘（最优） | $O(m)$ | $O(m)$ | 每个结点至多入栈、出栈各一次，无递归深度风险 |

空间里最重的是 `left` / `right` 两个长度 $m$ 的数组和那个深度不超过 $m$ 的工作栈。

## 易错点总结

### 1. 右缘遍历把两个孩子入栈的顺序写反

显式栈是后进先出。想先访问右子树，就必须 `left` 先入、`right` 后入；顺序反过来，每个深度第一次出栈的就成了最靠左的结点。样例 1 的输出会从 $37$ 变成 $10+6+3=19$——树建得完全正确，错全在统计这一步。

### 2. 左孩子继承父亲的整个区间

左孩子入栈的四元组是 `(v, parent[1], parent[0])`，上界被收紧成父亲的值。若图省事写成 `(v, parent[1], parent[2])`，区间整整松了一圈，样例 2 那种「本该被上界拦下的 $10$」会顺利通过，页面输出一个数字而不是 $-1$。

### 3. 弹栈只弹一层

挂左孩子要 `while stack and stack[-1][0] > v` 一路弹到栈顶比 $v$ 小为止，**最后**弹出的才是直接父亲。把 `while` 写成 `if`，样例 1 读 $6$ 那一步只弹掉 $12$、把 $10$ 留在栈里，于是「父亲」变成 $12$、它的下界是 $10$，`6 <= 10` 立刻触发下界检查——一个完全合法的序列被判成 $-1$，输出不是 $37$。

## 扩展思考

序列换成先序或层序，区间校验的思路不变，只是父子方向与悬链方向反过来；「每层最靠右」放到多叉树就是层序遍历里每层最后一个，显式栈换成队列即可。校验的副产品是整棵树的父子关系都建好了，需要输出树形本身时也已备齐。
