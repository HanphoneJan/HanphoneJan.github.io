# P5413. 直线基站部署中的邻近干扰总和

> 场次：2026年9月9日-非AI方向 · 来源：[CodeFun2000 P5413](https://codefun2000.com/p/P5413)

## 题目描述

在一条直线上规划 $5$G 组网时，需要依次在若干点位部署基站。每个点位 $p$ 对应一个已知场强 $a[p]$。为了评估信号干扰情况，需要计算每一座基站被左右邻近基站干扰的程度。

对位置 $p$ 的基站，定义两个观察区间。左侧观察区间从 $p-1$ 开始向左延伸，最多包含 $t$ 个基站；右侧观察区间从 $p+1$ 开始向右延伸，最多包含 $t$ 个基站。所有观察都必须限制在数组边界内。

在左侧观察区间中，沿着从近到远的方向寻找第一个场强严格大于 $a[p]$ 的基站。如果找到，设其下标为 $L$，则左侧干扰指数为 $a[p]\times(p-L)$；如果不存在这样的基站，则左侧干扰指数为 $0$。类似地，在右侧观察区间中寻找第一个场强严格大于 $a[p]$ 的基站。如果找到，设其下标为 $R$，则右侧干扰指数为 $a[p]\times(R-p)$；如果不存在，则右侧干扰指数为 $0$。

每座基站的总干扰指数定义为左侧干扰指数与右侧干扰指数之和。请计算所有基站的总干扰指数之和，并对 $10^9+7$ 取模后输出。

约束条件：
- 数组 $a$ 的长度 $m$ 满足 $1 \le m \le 10^5$。
- 每个场强 $a[p]$ 满足 $1 \le a[p] \le 10^9$。
- $t$ 满足 $1 \le t \le m$。

## 输入格式

第一行包含若干个以空格分隔的整数，依次表示数组 $a$ 中从左到右每个点位上的基站场强。

第二行包含一个整数 $t$，表示向一侧最多观察的基站座数。

## 输出格式

输出一个整数，表示所有基站的总干扰指数之和对 $10^9+7$ 取模后的结果。

## 示例

### 示例 1

**输入：**

```
3 1 4 1 5
2
```

**输出：**

```
18
```

**说明：**

下标从 `0` 开始。

下标 `0` 场强为 `3`。左侧无基站，干扰为 `0`。右侧观察区间最多包含 `2` 个基站，场强分别为 `1`、`4`；第一个严格大于 `3` 的是场强 `4`，距离为 `2`，右侧干扰为 $3 \times 2 = 6$，总干扰为 `6`。

下标 `1` 场强为 `1`。左侧第一个严格大于 `1` 的是场强 `3`，距离为 `1`，贡献 $1 \times 1 = 1$；右侧第一个严格大于 `1` 的是场强 `4`，距离为 `1`，贡献 $1 \times 1 = 1$，总干扰为 `2`。

下标 `2` 场强为 `4`。左侧场强 `1` 和 `3` 都不大于 `4`，左侧干扰为 `0`；右侧场强 `1` 和 `5` 中第一个严格大于 `4` 的是场强 `5`，距离为 `2`，右侧干扰为 $4 \times 2 = 8$，总干扰为 `8`。

下标 `3` 场强为 `1`。左侧第一个严格大于 `1` 的是场强 `4`，距离为 `1`，贡献 $1 \times 1 = 1$；右侧第一个严格大于 `1` 的是场强 `5`，距离为 `1`，贡献 $1 \times 1 = 1$，总干扰为 `2`。

下标 `4` 场强为 `5`。左侧场强 `1` 和 `4` 都不大于 `5`，右侧无基站，总干扰为 `0`。

求和得到 $6+2+8+2+0=18$，取模后仍为 `18`。

下标 `1` 场强为 `20`。左侧下标 `0` 场强 `10` 不大于 `20`，左侧干扰为 `0`；右侧观察区间只包含下标 `2`，场强 `15` 不大于 `20`，右侧干扰为 `0`。虽然更右侧下标 `3` 的场强 `30` 大于 `20`，但距离为 `2`，超出了 $t=1$ 的观察范围，因此不计入干扰。总干扰为 `0`。

下标 `3` 场强为 `30`。左侧观察区间只包含下标 `2`，场强 `15` 不大于 `30`，右侧无基站，总干扰为 `0`。

求和得到 $10+0+30+0=40$，取模后仍为 `40`。

下标 `1` 场强为 `500000000`。左侧第一个严格大于它的是下标 `0`，距离为 `1`，贡献 $500000000 \times 1 = 500000000$；右侧第一个严格大于它的是下标 `3`，距离为 `2`，贡献 $500000000 \times 2 = 1000000000$，总干扰为 `1500000000`。

下标 `2` 场强为 `1`。左侧第一个严格大于它的是下标 `1`，距离为 `1`，贡献 $1 \times 1 = 1$；右侧第一个严格大于它的是下标 `3`，距离为 `1`，贡献 $1 \times 1 = 1$，总干扰为 `2`。

## 解题思路

### 干扰指数实际问的是什么

题面对每座基站给出两个观察窗口：左侧从 `p-1` 向左最多 `t` 座，右侧从 `p+1` 向右最多 `t` 座，然后在窗口里「从近到远」找第一个场强**严格大于** `a[p]` 的基站，干扰为 `a[p]` 乘上与它的距离。这条定义里藏着一个把问题简化的机关：窗口里看的是**第一个**更大值，也就是那一侧的「最近严格更大元素」。设右侧最近严格更大元素的距离是 `dist`，那么：

- `dist <= t` 时，窗口内确实存在更大值，且第一个就是它，干扰为 `a[p] * dist`；
- `dist > t` 时，最近的一个更大值都已经出窗，更远的只会更远，该侧干扰必为 0——样例 2 的下标 1（场强 20，右侧距离 2 处才有 30，`t=1`）正是这一条：干扰为 0，不是 10×2。

所以 `t` 根本不改变搜索目标，它只是对「最近严格更大元素的距离」做一次截断判定。问题化为经典子问题：对每个下标求左右两侧最近严格更大元素的距离，再按 `0 < dist <= t` 逐项累加。

### 为什么用单调栈

数据范围是 `m <= 1e5` 而 `t <= m`。对每个点位把窗口里的最多 `t` 座逐个扫一遍找第一个更大值，最坏 `O(m·t)` 达到 1e10 次，必超时。而「最近严格更大元素」正是单调栈的固定产出：一遍扫描、每个下标至多进栈出栈一次，整段 `O(m)`。窗口在这里只留下一个 `<= t` 的判断，不需要任何额外结构。

严格性由弹栈条件保证：比较写成 `a[栈顶] <= a[当前值]` 时才弹出，相等值不会留在栈里冒充「严格更大」的答案；反之若条件写成 `<`，全相等的数据（如 `5 5 5`）会把左侧的 5 错当成更大值。

### 到实现上的映射

- `nearest_greater_distances` 里两次独立扫描：从左到右得到 `left[i] = i - 栈顶`（左侧最近严格更大的距离），从右到左对称地得到 `right[i] = 栈顶 - i`；两侧的减法方向相反，写混会得到负距离。
- `solve` 里求和时每一步都 `% MOD`：单次乘积可达 `1e9 × 1e5 = 1e14`，当场取模把数值压住（Python 大整数不溢出，取模同时保证输出口径）。
- 输入解析按「最后一个整数是 `t`、其余全是数组」切分，单元素数组（官方样例 4）也天然成立。

```python
"""
P5413. 直线基站部署中的邻近干扰总和 - 单调栈求左右最近严格更大元素

题面要点：
- 每个位置 p 有场强 a[p]。左侧观察区间是从 p-1 向左最多 t 座基站，
  右侧是从 p+1 向右最多 t 座；观察只能落在数组边界内。
- 某侧干扰：从近到远找第一个场强「严格大于」a[p] 的基站，找到（下标 L/R）
 则该侧干扰为 a[p]*(p-L) 或 a[p]*(R-p)，找不到为 0。
- 输出所有基站左右干扰之和，对 1e9+7 取模。

输入格式：
- 第 1 行：数组 a 的全部元素（1 <= m <= 1e5）；
- 第 2 行：整数 t（1 <= t <= m）。

输出格式：一个整数，总和 mod 1e9+7。

核心思路（为什么是单调栈）：
1. 窗口有一个不显眼的机关：要看的是「从近到远第一个」更大值。设某侧
   最近严格更大元素的距离是 dist，那么 dist > t 时窗口内没有任何更大值
   （更远的更大值更远），该侧必为 0；dist <= t 时干扰照算。于是窗口
   只是对「最近严格更大元素的距离」做一个截断，答案完全由
   left[i] / right[i]——左右最近严格更大元素的距离——决定。
2. 最近严格更大元素正是单调栈的经典产出：从五万长度的数组里对每个下标
   O(m) 总时间求出，逐对扫描的 O(m*t) 会退化到 1e10，挂死。
3. 弹栈条件用「<=」保证留下的栈顶是严格大于，相等值不会冒充更大值。

时间复杂度：O(m)（每个下标至多进栈、出栈一次）
空间复杂度：O(m)
"""

# https://codefun2000.com/p/P5413
import sys

MOD = 10**9 + 7

# @sample-start
"""
样例输入 1:
3 1 4 1 5
2

样例输出 1:
18
"""
# @sample-end

# @sample-start
"""
样例输入 2:
10 20 15 30
1

样例输出 2:
40
"""
# @sample-end

# @sample-start
"""
样例输入 3:
1000000000 500000000 1 1000000000
3

样例输出 3:
499999995
"""
# @sample-end

# @sample-start
"""
样例输入 4:
7
1

样例输出 4:
0
"""
# @sample-end


def nearest_greater_distances(a):
    """返回 (left, right)：每个下标到左/右侧最近严格更大元素的距离，没有则为 0。"""
    n = len(a)
    left = [0] * n
    right = [0] * n

    # 从左到右：栈内下标的场强严格递减；弹出所有 <= 当前值的元素后，
    # 栈顶就是当前元素左侧第一个严格更大的位置。
    stack = []
    for i in range(n):
        while stack and a[stack[-1]] <= a[i]:
            stack.pop()
        left[i] = i - stack[-1] if stack else 0
        stack.append(i)

    # 从右到左做对称的一遍，得到右侧最近严格更大的距离。
    stack = []
    for i in range(n - 1, -1, -1):
        while stack and a[stack[-1]] <= a[i]:
            stack.pop()
        right[i] = stack[-1] - i if stack else 0
        stack.append(i)

    return left, right


def solve():
    """读入数组与 t，输出干扰总和 mod 1e9+7。"""
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    nums = list(map(int, data))
    # t 在第二行，是最后一个整数；前面全部是数组（m >= 1）。
    a = nums[:-1]
    t = nums[-1]

    left, right = nearest_greater_distances(a)

    total = 0
    for i, v in enumerate(a):
        # dist 为 0 表示该侧不存在更大值；dist > t 时窗口内没有更大值。
        if 0 < left[i] <= t:
            total = (total + v * left[i]) % MOD
        if 0 < right[i] <= t:
            total = (total + v * right[i]) % MOD
    print(total)


def run_tests():
    """运行嵌入的官方样例与自加用例，方便本地自测。"""
    import io
    import random

    def run(stdin_text):
        old_stdin, old_stdout = sys.stdin, sys.stdout
        # solve() 用 sys.stdin.buffer 快速读取，这里提供带 buffer 的文本流。
        sys.stdin = io.TextIOWrapper(io.BytesIO(stdin_text.encode("utf-8")))
        sys.stdout = io.StringIO()
        try:
            solve()
            return sys.stdout.getvalue().strip()
        finally:
            sys.stdin, sys.stdout = old_stdin, old_stdout

    test_cases = [
        # 官方样例 1
        ("3 1 4 1 5\n2\n", "18"),
        # 官方样例 2：t=1，下标 1 右侧距离 2 的 30 必须被窗口挡住
        ("10 20 15 30\n1\n", "40"),
        # 官方样例 3：1e9 量级乘积触发取模回绕
        ("1000000000 500000000 1 1000000000\n3\n", "499999995"),
        # 官方样例 4：单元素，两侧都无观察对象
        ("7\n1\n", "0"),
        # 全相等：没有「严格更大」，全部为 0（相等不算）
        ("5 5 5\n1\n", "0"),
        # 严格性：下标 1 左侧相邻是 2 不算更大，必须越过它看到下标 0 的 2
        # 也不算，所以只有下标 0/1 借右侧 9 计分
        ("2 2 9\n3\n", "6"),
        # 窗口截断：t=1 时下标 0 到 10 的距离 2 超窗不计
        ("5 1 10\n1\n", "2"),
        # 同一数组放开窗口：距离 2 的贡献回来了
        ("5 1 10\n3\n", "12"),
        # 取模回绕：1999999998 + 2 = 2000000000，减去 1e9+7 剩 999999993
        ("999999999 1 1000000000\n3\n", "999999993"),
    ]

    failures = 0
    for i, (inp, expected) in enumerate(test_cases, 1):
        output = run(inp)
        ok = output == expected
        if not ok:
            failures += 1
        print(f"样例 {i}: 期望={expected}, 实际={output} {'✓' if ok else '✗'}")

    # 随机对照：与 O(m*t) 的逐格扫描暴力比对 200 组，钉住单调栈的边界。
    rng = random.Random(20260909)
    rand_bad = 0
    for _ in range(200):
        m = rng.randint(1, 12)
        a = [rng.randint(1, 50) for _ in range(m)]
        t = rng.randint(1, m)
        expected = 0
        for i in range(m):
            for side in (-1, 1):
                for k in range(1, t + 1):
                    j = i + side * k
                    if not 0 <= j < m:
                        break
                    if a[j] > a[i]:
                        expected = (expected + a[i] * k) % MOD
                        break
        output = run(" ".join(map(str, a)) + f"\n{t}\n")
        if output != str(expected):
            rand_bad += 1
            print(f"随机对照失败: a={a} t={t} 期望={expected} 实际={output}")
    if rand_bad == 0:
        print("随机对照 200 组: 全部一致 ✓")
    failures += rand_bad

    if failures:
        raise SystemExit(1)


if __name__ == "__main__":
    if len(sys.argv) > 1 and sys.argv[1] == "--test":
        run_tests()
    else:
        solve()
```

## 示例推演

以官方样例 1 为例，`a = [3, 1, 4, 1, 5]`，`t = 2`。先走左侧扫描（从左到右，栈内下标的场强严格递减）：

| i | 值 | 弹出的下标 | 栈内变化 | left[i] |
| --- | --- | --- | --- | --- |
| 0 | 3 | — | 入栈 [0] | 0（栈空） |
| 1 | 1 | 无（3 > 1） | 入栈 [0, 1] | 1 - 0 = 1 |
| 2 | 4 | 1、0（1≤4、3≤4） | 入栈 [2] | 0（栈空） |
| 3 | 1 | 无（4 > 1） | 入栈 [2, 3] | 3 - 2 = 1 |
| 4 | 5 | 3、2（1≤5、4≤5） | 入栈 [4] | 0（栈空） |

再对称地走一遍从右到左的扫描，得到 `right = [2, 1, 2, 1, 0]`。逐项计分（`dist` 不在 `(0, t]` 内的一侧为 0）：

| i | 场强 | 左贡献 | 右贡献 | 小计 |
| --- | --- | --- | --- | --- |
| 0 | 3 | 无 | 3×2 = 6 | 6 |
| 1 | 1 | 1×1 | 1×1 | 2 |
| 2 | 4 | 无 | 4×2 = 8 | 8 |
| 3 | 1 | 1×1 | 1×1 | 2 |
| 4 | 5 | 无 | 无 | 0 |

合计 18，与官方输出一致。

样例 2（`t=1`）展示截断规则生效的位置：下标 1 的右侧最近更大元素是距离 2 的 30，`2 > t` 直接判 0——若不检查 `dist <= t`，这里会多算 40，总数从 40 变成 80。

样例 3 演示取模：下标 1 的两侧贡献 `5e8×1 + 5e8×2 = 1.5e9 + 2 = 1500000002`，减去 `1000000007` 得输出 `499999995`。

## 易错点总结

### 1. 弹栈条件把严格比较写松

`nearest_greater_distances` 里两个 `while stack and a[stack[-1]] <= a[i]` 用的是 `<=`。若写成 `<`，与当前值相等的元素会留在栈里，被当作「严格更大」的答案返回——全相等数组 `5 5 5` 本应输出 0，会算出非零干扰。

### 2. 两个方向的距离公式写混

`left[i] = i - stack[-1]` 与 `right[i] = stack[-1] - i` 是同一对扫描在不同方向上的镜像，减法方向相反。若从右到左那段照抄左侧公式取 `i - stack[-1]`，得到的是负距离，`0 < dist <= t` 恒为假，一整侧的贡献静默丢失，输出明显偏小且没有报错。

## 扩展思考

把 `t` 放宽到 `t >= m`，本题退化为「两侧最近严格更大元素之和」的经典题，单调栈骨架原样保留。若观察目标反过来变成「窗口内第一个严格更小」，弹栈条件与比较方向对称翻转即可；环形数组版本（循环寻找更大元素）则把两遍扫描各延长一倍并用取模下标访问。
