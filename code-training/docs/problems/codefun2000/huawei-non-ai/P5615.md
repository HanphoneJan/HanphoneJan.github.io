# P5615. 隔断染病计时

> 场次：2026年10月10日-非AI方向 · 来源：[CodeFun2000 P5615](https://codefun2000.com/p/P5615)

## 题目描述

身为健康防护软件的编写者，要做的是把长方形屋子里病菌逐步蔓延的经过仿真出来。屋子被画成一张二维格子表，表中的格子只有下面三类：

$0$ 表示尚未染病的人

$1$ 表示已经染病的人

$x$ 表示挡住去路的物体（例如隔板、墙体）

每一轮病菌只会迈进紧贴着的上、下、左、右格子，一轮过去记作 $1$ 小时。请给出把所有还有机会染上的人全部染完所要的最少小时数。只要仍有人因为挡路物体被隔开、再也染不上，就输出 $-1$。

## 输入格式

首行是两个整数 $r$ 和 $c$，依次为格子表的行数与列数，二者之间用一个空格分开。$1 \le r \le 100$，$1 \le c \le 100$。

随后恰好 $r$ 行。每行是一串长度为 $c$ 的字符，字符紧挨着书写、中间不留空格，从左到右给出该行每个格子：尚未染病写 $0$，已经染病写 $1$，挡路物体写 $x$。

## 输出格式

输出一个整数，表示把还有机会染上的人全部染完所要的最少小时数。若仍有人被挡路物体隔开、始终染不上，则输出 $-1$。

## 示例

### 示例 1

**输入：**

```
3 4
0100
00x0
x010
```

**输出：**

```
2
```

**说明：**

为便于对照，下面把同一张表用空格拆开。正式输入里这些空格并不存在。

```
0 1 0 0
0 0 x 0
x 0 1 0
```

开局已经染病的，是第 $1$ 行第 $2$ 格，以及第 $3$ 行第 $3$ 格。

- 第 $1$ 小时：第 $1$ 行第 $2$ 格把左边、右边、下边三个人染上；第 $3$ 行第 $3$ 格把左边和右边两个人染上。它的正上方是挡路物体，过不去。
- 第 $2$ 小时：还剩三个人，分别位于第 $1$ 行最右、第 $2$ 行最左、第 $2$ 行最右，这一小时也被染上。

尚未染病的人已经没有，答案是 $2$。

### 示例 2

**输入：**

```
3 3
0x0
x1x
00x
```

**输出：**

```
-1
```

**说明：**

```
0 x 0
x 1 x
0 0 x
```

染病者只有正中间那一个。第 $1$ 小时只能染到正下方那个人；第 $2$ 小时再染到左下角。左上角的右边和下边都是挡路物体，右上角的左边和下边同样被挡住，病菌到不了这两处。因此输出 $-1$。

## 解题思路

### 输出到底是「最晚染上的时刻」，不是逐格时刻

输出的判定标准只有一句话：把所有**还有机会**染上的人全部染完所需的最少小时数。拆开看是三件事——所有尚未染病的 0 格都会在某一小时被染上，答案是其中最晚那格的小时数；只要存在一个 0 格无论如何都到不了，整局即告失败，输出 $-1$；屋里根本没有待染的人（全 1、或全是挡板）时不算失败，答案为 $0$。三个出口都要落在代码里，缺一个就在别的用例上翻车。

### 关键观察：传染是同时发生的，感染时刻就是 BFS 距离

病菌同一小时从**所有**染病者同时向外扩一步。一个格子第一次被染上的时刻，等于它在「从病源集合出发、每步 1」的图搜索里的最短距离——这正是 BFS 求的东西，而且只关心每个 0 格的最早时刻，不需要任何感染顺序或路径。数据范围 $r, c \le 100$、格子总数至多一万，一遍 $O(rc)$ 的搜索绰绰有余；逐小时开一张表模拟轮转既要在轮次与边界上防错，也没有任何复杂度优势。

病源往往不止一处。给每个病源单独跑一遍 BFS 再取最大是自然的起步，但同一片格子会被反复扫描；多源 BFS 把所有时刻为 0 的病源一次性入队，一遍扫描就得到与「离最近病源多远」完全一致的感染时刻场——队列按时刻从小到大出队，第一次到达即最短。

### 实现映射

- `dist` 数组兼任 visited：入队瞬间就写时刻并扣减待染人数，出队时不再判重，也杜绝同一格被两个邻格先后入队两次；
- 挡板与已染格在四方向的过滤条件里同时排除（必须既判 `rows[ni][nj] == '0'` 又判 `dist == -1`）；
- 待染人数 `remaining` 是收局判定的唯一状态：队列清空后它大于 0 就输出 $-1$；
- 最晚时刻 `best` 沿途取最大，把它与 `remaining == 0` 组合，全 1 屋子（`remaining == 0`、`best == 0`）自然落到 0。

## 完整代码实现

```python
"""
P5615. 隔断染病计时 - 多源 BFS

长方形屋子是一张 r×c 的格子表：0 表示尚未染病、1 表示已经染病、
x 表示挡住去路的物体。病菌每一轮只迈进上下左右紧邻的格子，一轮
记作 1 小时。要输出把所有「还有机会」染上的人全部染完所需的最少
小时数；只要仍有人被挡路物体隔开、永远染不上，输出 -1。

输入格式：
- 第 1 行：r c（行数与列数）；
- 随后 r 行：每行一个长度为 c 的字符串，字符为 0 / 1 / x。

输出格式：
- 一个整数：把可染尽的人全部染完所需的小时数；有人永远染不上则为 -1。

核心思路：
答案是「最晚染上的人发生在第几小时」。所有染病者从 0 时刻同时向外
扩散，谁先谁后不影响每个格子被染上的时刻，因此把全部染病者（时刻 0）
一起入队做多源 BFS：每个 0 格第一次被染上的时刻，就是它被染上的
最小时刻。队列清空后若仍有 0 格没被到达，说明有人被隔开，输出 -1；
否则输出扩散过程中出现的最大时刻。

时间复杂度：O(r * c)，每个格子至多入队一次
空间复杂度：O(r * c)
"""

# https://codefun2000.com/p/P5615
import sys
from collections import deque

# @sample-start
"""
样例输入 1:
3 4
0100
00x0
x010

样例输出 1:
2
"""
# @sample-end

# @sample-start
"""
样例输入 2:
3 3
0x0
x1x
00x

样例输出 2:
-1
"""
# @sample-end


def spread(r, c, rows):
    """多源 BFS：返回全部可染尽时的小时数；仍有人永远染不上时返回 -1。"""
    dist = [[-1] * c for _ in range(r)]
    queue = deque()
    remaining = 0  # 尚未被染上的 0 格数量
    best = 0       # 最晚一次染上发生在第几小时
    for i in range(r):
        for j, ch in enumerate(rows[i]):
            if ch == '1':
                dist[i][j] = 0
                queue.append((i, j))
            elif ch == '0':
                remaining += 1

    while queue:
        i, j = queue.popleft()
        d = dist[i][j] + 1
        for ni, nj in ((i - 1, j), (i + 1, j), (i, j - 1), (i, j + 1)):
            if 0 <= ni < r and 0 <= nj < c and rows[ni][nj] == '0' and dist[ni][nj] == -1:
                dist[ni][nj] = d
                remaining -= 1
                if d > best:
                    best = d
                queue.append((ni, nj))

    return -1 if remaining else best


def solve():
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    r, c = int(data[0]), int(data[1])
    rows = [data[2 + i].decode() for i in range(r)]
    print(spread(r, c, rows))


def run_tests():
    """运行嵌入的官方样例与边界/变形用例，方便本地自测。"""
    import io

    def run_once(text):
        """solve() 走 sys.stdin.buffer，这里提供带 buffer 的文本流。"""
        old_stdin, old_stdout = sys.stdin, sys.stdout
        sys.stdin = io.TextIOWrapper(io.BytesIO(text.encode("utf-8")))
        sys.stdout = io.StringIO()
        try:
            solve()
            return sys.stdout.getvalue().strip()
        finally:
            sys.stdin, sys.stdout = old_stdin, old_stdout

    hundred_zeros = "0" * 100
    cases = [
        # 官方样例 1：两处病源同时扩散，2 小时染完全部
        ("3 4\n0100\n00x0\nx010\n", "2"),
        # 官方样例 2：左上与右上两格被挡板围死，永远染不上
        ("3 3\n0x0\nx1x\n00x\n", "-1"),
        # 没有任何染病者：所有人都染不上，输出 -1
        ("3 3\n000\n000\n000\n", "-1"),
        # 单格已经染病：没有待染的人，0 小时
        ("1 1\n1\n", "0"),
        # 全部已染病：同样 0 小时
        ("2 3\n111\n111\n", "0"),
        # 屋子里全是挡路物体：没有可染的人，按 0 处理
        ("2 2\nxx\nxx\n", "0"),
        # 单个染病者在一行中间，向两边扩散，最远端要 2 小时
        ("1 5\n00100\n", "2"),
        # 挡板把屋子切成两半，染病者只在一侧：另一侧永远染不上
        ("3 3\n1x0\nxx0\nxx0\n", "-1"),
        # 样例 1 的最小变形：(2,3) 换成 x，最右一列要拐到第 3 小时才染完
        ("3 4\n0100\n00x0\nx01x\n", "3"),
        # 100×100 空屋，左上角一个病源：最远的右下角要 99+99=198 小时
        ("100 100\n" + "1" + "0" * 99 + "\n" + (hundred_zeros + "\n") * 99, "198"),
        # 100×100 空屋居中一个病源：到任一角都是 50+50=100 小时
        (
            "100 100\n"
            + (hundred_zeros + "\n") * 49
            + "0" * 49 + "1" + "0" * 50 + "\n"
            + (hundred_zeros + "\n") * 50,
            "100",
        ),
        # 两条走廊被中央挡板分开，两个对角病源各自沿同行同列扩散，最远点 3 小时
        ("4 4\n1000\n0xx0\n0xx0\n0001\n", "3"),
    ]

    for i, (inp, expected) in enumerate(cases, 1):
        output = run_once(inp)
        status = "✓" if output == expected else "✗"
        print(f"用例 {i}: 期望={expected}, 实际={output} {status}")


if __name__ == "__main__":
    if len(sys.argv) > 1 and sys.argv[1] == "--test":
        run_tests()
    else:
        solve()
```

## 示例推演

以样例 1 为例，病源是第 1 行第 2 格 $(0,1)$ 与第 3 行第 3 格 $(2,2)$（下标从 0 计，表中 $x$ 是挡板）：

| 时刻 | 新染上的格子 | 说明 |
| ---- | ----------- | ---- |
| 1 | $(0,0)$、$(0,2)$、$(1,1)$ | 来自 $(0,1)$ |
| 1 | $(2,1)$、$(2,3)$ | 来自 $(2,2)$；它的上方 $(1,2)$ 是挡板，过不去 |
| 2 | $(1,0)$、$(0,3)$、$(1,3)$ | 分别由 $(1,1)$、$(0,2)$、$(2,3)$ 这一批第 1 小时新病源推进 |

8 个 0 格全部进过队列，`remaining` 清零，最晚的一次染上发生在第 2 小时，输出 2。

样例 2 里病源只有正中间一格 $(1,1)$：第 1 小时染上正下方 $(2,1)$（其余三个方向全是挡板），第 2 小时从 $(2,1)$ 向左染上 $(2,0)$。$(0,0)$ 的右边、下边，以及 $(0,2)$ 的左边、下边都是挡板——队列为空时这两格从未被染上，`remaining` 停在 2，输出 $-1$。

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| ---- | ---------- | ---------- | ---- |
| 逐个病源单独 BFS 再取最大 | $O(K \cdot r \cdot c)$（$K$ 为病源数） | $O(r \cdot c)$ | 每个病源扫一遍全屋，同一片格子被反复访问 |
| 多源 BFS，病源一次入队（最优） | $O(r \cdot c)$ | $O(r \cdot c)$ | 每个格子至多入队一次；本题采用 |

---

## 易错点总结

### 1. 入队前漏查 `dist[ni][nj] == -1`

八个方向放出去的格子共用同一张 `dist` 表，**入队瞬间就要标时刻**；若把 visited 检查漏掉或挪到出队时再做，同一格会被两个邻格先后入队两次，`remaining` 被多扣——明明还有人被隔开，却因为计数提前归零而输出了一个假的非 $-1$ 值。

### 2. 把挡板误判成病源

病源入队的判断必须严格等于 `'1'`。写成 `ch != '0'` 之类的取反判断时，挡板 `x` 会以 0 时刻入队并向四周扩散，把被它隔开的人也染上——该出 $-1$ 的屋子会输出一个偏小的正数。

### 3. 收局输出用「非零就输出」

最后一步若写成 `print(best or -1)` 这类按真值判断的表达式，全 1 的屋子（没有待染的人，`best == 0`）会被误报成 $-1$。正确的结构是按 `remaining` 判失败、否则输出 `best` 两段互斥走。

---

## 扩展思考

若输出还要逐格的感染时刻，把 `best` 换成逐格取 `dist` 的最大值即可，骨架一字不动。格子量级到十万、病源上千时，时距数组压成一维定长表可省一层寻址；若挡板本身随时间变化，图就不再是静态的，需要重新设计状态机，超出 BFS 一遍到位的适用范围。
