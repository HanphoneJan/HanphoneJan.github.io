# P5615. 隔断染病计时

> 场次：2026年10月10日-非AI方向 · 来源：[CodeFun2000 P5615](https://codefun2000.com/p/P5615)

## 题目描述

身为健康防护软件的编写者，要做的是把长方形屋子里病菌逐步蔓延的经过仿真出来。屋子被画成一张二维格子表，表中的格子只有下面三类：

$0$ 表示尚未染病的人

$1$ 表示已经染病的人

$x$ 表示挡住去路的物体（例如隔板、墙体）

每一轮病菌只会迈进紧贴着的上、下、左、右格子，一轮过去记作 $1$ 小时。请给出把所有还有机会染上的人全部染完所要的最少小时数。只要仍有人因为挡路物体被隔开、再也染不上，就输出 $-1$。

## 输入格式

首行是两个整数 $r$ 和 $c$，依次为格子表的行数与列数，二者之间用一个空格分开。$1 \le r \le 100$，$1 \le c \le 100$。

随后恰好 $r$ 行。每行是一串长度为 $c$ 的字符，字符紧挨着书写、中间不留空格，从左到右给出该行每个格子：尚未染病写 $0$，已经染病写 $1$，挡路物体写 $x$。

## 输出格式

输出一个整数，表示把还有机会染上的人全部染完所要的最少小时数。若仍有人被挡路物体隔开、始终染不上，则输出 $-1$。

## 示例

### 示例 1

**输入：**

```
3 4
0100
00x0
x010
```

**输出：**

```
2
```

**说明：**

为便于对照，下面把同一张表用空格拆开。正式输入里这些空格并不存在。

```
0 1 0 0
0 0 x 0
x 0 1 0
```

开局已经染病的，是第 $1$ 行第 $2$ 格，以及第 $3$ 行第 $3$ 格。

- 第 $1$ 小时：第 $1$ 行第 $2$ 格把左边、右边、下边三个人染上；第 $3$ 行第 $3$ 格把左边和右边两个人染上。它的正上方是挡路物体，过不去。
- 第 $2$ 小时：还剩三个人，分别位于第 $1$ 行最右、第 $2$ 行最左、第 $2$ 行最右，这一小时也被染上。

尚未染病的人已经没有，答案是 $2$。

### 示例 2

**输入：**

```
3 3
0x0
x1x
00x
```

**输出：**

```
-1
```

**说明：**

```
0 x 0
x 1 x
0 0 x
```

染病者只有正中间那一个。第 $1$ 小时只能染到正下方那个人；第 $2$ 小时再染到左下角。左上角的右边和下边都是挡路物体，右上角的左边和下边同样被挡住，病菌到不了这两处。因此输出 $-1$。

## 解题思路

### 输出是「最后一个被染上的时刻」，另带一个失败出口

题面一句话里其实藏了三件事，缺一件就在别的用例上翻车：

- 所有还没染病的 $0$ 格都会在某一小时被染上，答案是其中**最晚**那一格的时刻；
- 只要有一个 $0$ 格被挡板围死、永远到不了，整局作废，输出 $-1$；
- 屋子里根本没有待染的人（全是 $1$、或者全是 $x$）时不算失败，答案是 $0$。

### 关键观察：同时扩散等于「到最近病源的距离」

病菌每一小时从**所有**染病者同时往外走一步。一个格子第一次被染上的时刻，等于它到「最近的染病者」的四连通距离——挡板不能穿，所以只走 $0$ 格。这正是 BFS 求的东西：队列按距离由小到大出队，第一次到达就是最早时刻。

数据范围给了明确许可：$r, c \le 100$，格子总数最多 $10^4$，一遍 $O(rc)$ 的搜索绰绰有余，最远的格子也只需要 $99 + 99 = 198$ 小时。

### 一次把所有病源入队，而不是每个病源各跑一遍

病源往往不止一处（样例 1 就有两个）。按「每个病源单独 BFS、再逐格取最小」也正确，但同一片区域会被扫描 $K$ 遍，$K$ 最多等于格子数，复杂度退成 $O(K \cdot rc)$。多源 BFS 只是把所有病源在时刻 $0$ 一次性入队：

```python
dist = [[-1] * c for _ in range(r)]
queue = deque()
remaining = 0                 # 还没被染上的 0 格数量
best = 0                      # 最晚一次染上发生在第几小时
for i in range(r):
    for j, ch in enumerate(rows[i]):
        if ch == '1':
            dist[i][j] = 0    # 病源自己是 0 时刻
            queue.append((i, j))
        elif ch == '0':
            remaining += 1
```

队列里同时躺着所有源，出队顺序自然按时刻排序——这一步替换掉的是「轮次循环」，感染时刻照样正确。

扩散部分：

```python
while queue:
    i, j = queue.popleft()
    d = dist[i][j] + 1
    for ni, nj in ((i - 1, j), (i + 1, j), (i, j - 1), (i, j + 1)):
        if 0 <= ni < r and 0 <= nj < c and rows[ni][nj] == '0' and dist[ni][nj] == -1:
            dist[ni][nj] = d
            remaining -= 1
            if d > best:
                best = d
            queue.append((ni, nj))
```

条件里的三项各管一件事：边界、只能染 $0$（$x$ 和 $1$ 都不进）、以及 `dist[ni][nj] == -1` 这个「还没被染过」。最后一项与 `dist[ni][nj] = d` 必须成对出现在**入队之前**：一个格子可能同时是两个邻格的候选，只有立刻标上时刻，第二个邻格才会被挡住。

收尾是一句二选一：

```python
return -1 if remaining else best
```

`remaining` 是「还有没有人没染上」的唯一凭据，`best` 是「最晚几小时」。全程没有待染格子时 `best` 停在初值 $0$，与「全 $1$ 屋子输出 $0$」的约定正好对上。

### 实现映射

- `spread(r, c, rows)`：初始化（数待染人数、病源入队）、扩散、收尾判定，全在这里；
- `dist` 同时兼任 visited，不需要另开一张布尔表；
- `solve()`：读 $r$、$c$ 与 $r$ 行字符串（`data` 已按空白切分，行内没有空格，正好一行一个 token）。

## 完整代码实现

```python
"""
P5615. 隔断染病计时 - 多源 BFS

长方形屋子是一张 r×c 的格子表：0 表示尚未染病、1 表示已经染病、
x 表示挡住去路的物体。病菌每一轮只迈进上下左右紧邻的格子，一轮
记作 1 小时。要输出把所有「还有机会」染上的人全部染完所需的最少
小时数；只要仍有人被挡路物体隔开、永远染不上，输出 -1。

输入格式：
- 第 1 行：r c（行数与列数）；
- 随后 r 行：每行一个长度为 c 的字符串，字符为 0 / 1 / x。

输出格式：
- 一个整数：把可染尽的人全部染完所需的小时数；有人永远染不上则为 -1。

核心思路：
答案是「最晚染上的人发生在第几小时」。所有染病者从 0 时刻同时向外
扩散，谁先谁后不影响每个格子被染上的时刻，因此把全部染病者（时刻 0）
一起入队做多源 BFS：每个 0 格第一次被染上的时刻，就是它被染上的
最小时刻。队列清空后若仍有 0 格没被到达，说明有人被隔开，输出 -1；
否则输出扩散过程中出现的最大时刻。

时间复杂度：O(r * c)，每个格子至多入队一次
空间复杂度：O(r * c)
"""

# https://codefun2000.com/p/P5615
import sys
from collections import deque

# @sample-start
"""
样例输入 1:
3 4
0100
00x0
x010

样例输出 1:
2
"""
# @sample-end

# @sample-start
"""
样例输入 2:
3 3
0x0
x1x
00x

样例输出 2:
-1
"""
# @sample-end


def spread(r, c, rows):
    """多源 BFS：返回全部可染尽时的小时数；仍有人永远染不上时返回 -1。"""
    dist = [[-1] * c for _ in range(r)]
    queue = deque()
    remaining = 0  # 尚未被染上的 0 格数量
    best = 0       # 最晚一次染上发生在第几小时
    for i in range(r):
        for j, ch in enumerate(rows[i]):
            if ch == '1':
                dist[i][j] = 0
                queue.append((i, j))
            elif ch == '0':
                remaining += 1

    while queue:
        i, j = queue.popleft()
        d = dist[i][j] + 1
        for ni, nj in ((i - 1, j), (i + 1, j), (i, j - 1), (i, j + 1)):
            if 0 <= ni < r and 0 <= nj < c and rows[ni][nj] == '0' and dist[ni][nj] == -1:
                dist[ni][nj] = d
                remaining -= 1
                if d > best:
                    best = d
                queue.append((ni, nj))

    return -1 if remaining else best


def solve():
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    r, c = int(data[0]), int(data[1])
    rows = [data[2 + i].decode() for i in range(r)]
    print(spread(r, c, rows))


def run_tests():
    """运行嵌入的官方样例与边界/变形用例，方便本地自测。"""
    import io

    def run_once(text):
        """solve() 走 sys.stdin.buffer，这里提供带 buffer 的文本流。"""
        old_stdin, old_stdout = sys.stdin, sys.stdout
        sys.stdin = io.TextIOWrapper(io.BytesIO(text.encode("utf-8")))
        sys.stdout = io.StringIO()
        try:
            solve()
            return sys.stdout.getvalue().strip()
        finally:
            sys.stdin, sys.stdout = old_stdin, old_stdout

    hundred_zeros = "0" * 100
    cases = [
        # 官方样例 1：两处病源同时扩散，2 小时染完全部
        ("3 4\n0100\n00x0\nx010\n", "2"),
        # 官方样例 2：左上与右上两格被挡板围死，永远染不上
        ("3 3\n0x0\nx1x\n00x\n", "-1"),
        # 没有任何染病者：所有人都染不上，输出 -1
        ("3 3\n000\n000\n000\n", "-1"),
        # 单格已经染病：没有待染的人，0 小时
        ("1 1\n1\n", "0"),
        # 全部已染病：同样 0 小时
        ("2 3\n111\n111\n", "0"),
        # 屋子里全是挡路物体：没有可染的人，按 0 处理
        ("2 2\nxx\nxx\n", "0"),
        # 单个染病者在一行中间，向两边扩散，最远端要 2 小时
        ("1 5\n00100\n", "2"),
        # 挡板把屋子切成两半，染病者只在一侧：另一侧永远染不上
        ("3 3\n1x0\nxx0\nxx0\n", "-1"),
        # 样例 1 的最小变形：(2,3) 换成 x，最右一列要拐到第 3 小时才染完
        ("3 4\n0100\n00x0\nx01x\n", "3"),
        # 100×100 空屋，左上角一个病源：最远的右下角要 99+99=198 小时
        ("100 100\n" + "1" + "0" * 99 + "\n" + (hundred_zeros + "\n") * 99, "198"),
        # 100×100 空屋居中一个病源：到任一角都是 50+50=100 小时
        (
            "100 100\n"
            + (hundred_zeros + "\n") * 49
            + "0" * 49 + "1" + "0" * 50 + "\n"
            + (hundred_zeros + "\n") * 50,
            "100",
        ),
        # 两条走廊被中央挡板分开，两个对角病源各自沿同行同列扩散，最远点 3 小时
        ("4 4\n1000\n0xx0\n0xx0\n0001\n", "3"),
    ]

    for i, (inp, expected) in enumerate(cases, 1):
        output = run_once(inp)
        status = "✓" if output == expected else "✗"
        print(f"用例 {i}: 期望={expected}, 实际={output} {status}")


if __name__ == "__main__":
    if len(sys.argv) > 1 and sys.argv[1] == "--test":
        run_tests()
    else:
        solve()
```

## 示例推演

样例 1，$3\times4$，病源是 $(0,1)$ 与 $(2,2)$（行、列下标都从 $0$ 起）：

```text
0 1 0 0
0 0 x 0
x 0 1 0
```

初始时刻队列里有 $(0,1)$、$(2,2)$ 两个源，`remaining = 8`（八个 $0$ 格），`best = 0`。

| 时刻 | 新染上的格子 | 来自 | 说明 |
| ---- | ------------ | ---- | ---- |
| 1 | $(0,0)$、$(0,2)$、$(1,1)$ | $(0,1)$ | 三个方向都在界内且是 $0$ |
| 1 | $(2,1)$、$(2,3)$ | $(2,2)$ | 正上方 $(1,2)$ 是 $x$，过不去 |
| 2 | $(1,0)$ | $(0,0)$ 与 $(1,1)$ | 两处都指向它；先到者写时刻，后到者被 `dist == -1` 挡住 |
| 2 | $(0,3)$ | $(0,2)$ | 第 1 小时那批格子继续往外推一格 |
| 2 | $(1,3)$ | $(2,3)$ | 同上 |

八个 $0$ 格全部进过队列，`remaining` 归零，`best` 在时刻 $2$ 最后一次刷新，输出 $2$。

这里能看清「入队即标时刻」为什么关键：$(1,0)$ 同时是 $(0,0)$ 与 $(1,1)$ 的邻格（两者都在第 $1$ 小时被染上）。若入队时不写 `dist`、把判重挪到出队之后，$(1,0)$ 会被反复入队，它的 `dist` 又被后来者不断改写，队列永远清不空——样例 1 就卡在这一步，既不输出也不报错。

样例 2，$3\times3$：

```text
0 x 0
x 1 x
0 0 x
```

病源只有正中间的 $(1,1)$，四个方向里只有正下方 $(2,1)$ 是 $0$，第 $1$ 小时染上；第 $2$ 小时从 $(2,1)$ 往左染上 $(2,0)$。此后队列清空，$(0,0)$ 与 $(0,2)$ 从未被访问——`remaining` 停在 $2$，输出 $-1$。左上角的右边和下边、右上角的左边和下边都是 $x$，这两格与病源之间根本没有通路。

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| ---- | ---------- | ---------- | ---- |
| 每个病源各跑一次 BFS，再逐格取最小值 | $O(K \cdot r \cdot c)$，$K$ 为病源数 | $O(r \cdot c)$ | 结果正确，但同一片区域被扫描 $K$ 遍 |
| 多源 BFS，所有病源一次入队（最优） | $O(r \cdot c)$ | $O(r \cdot c)$ | 每个格子至多入队一次 |

$K$ 最大可以等于格子数，所以第一条在全是 $1$ 的极端盘面上会放大成 $O((rc)^2)$。多源版本没有这个因子：无论几个源，每个格子只被访问一次。

---

## 易错点总结

### 1. 入队时不写 `dist`，把判重挪到出队之后

`dist[ni][nj] = d` 必须和 `queue.append((ni, nj))` 贴着写。若改成出队时再看「访问过没有」，同一格会从多个邻格被反复入队、`dist` 被一次次改写，队列永远清不空：样例 1 直接卡住不动（既无输出也无报错），不会给出那个 $2$。

### 2. 病源判定写成 `ch != '0'`

`if ch == '1'` 不能顺手取反成 `if ch != '0'`。取反之后挡板 $x$ 会以时刻 $0$ 入队并向四周扩散，本该被隔开的人也一起被染上：样例 2 会输出一个正整数而不是 $-1$。

### 3. 用 `print(best or -1)` 收尾

`best` 为 $0$ 有两种含义——「一格都没染过」和「根本没有待染的人」。按真值判断的写法会把后者也判成失败：输入 `2 3` / `111` / `111` 本应输出 $0$，实际输出 $-1$。正确结构是按 `remaining` 判失败、否则输出 `best`，两段互斥。

---

## 扩展思考

需要逐格感染时刻时，把 `best` 换成直接读 `dist` 即可，骨架一字不动。若挡板会随时间变化，图不再是静态的，BFS 一遍到位的结论失效，得把「时刻」并入状态重新设计。
