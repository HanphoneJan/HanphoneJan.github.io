# P5563. 边缘模型清洗

> 场次：2026年9月23日-非AI方向 · 来源：[CodeFun2000 P5563](https://codefun2000.com/p/P5563)

## 题目描述

云网络设备做自动化部署时，边缘设备资源很紧，要尽快把 YANG 模型装进内存，因此得先把模型文件里多余的说明文字、初始取值之类信息清掉。

请按下面的规则写一个函数：这些字段要去掉，注释必须原封不动留下来，最后把清洗结果作为字符串返回。

### 清洗规则

**规则1：目标字段删除**

- 要删掉的关键字：$remark$、$preset$、$required$
- 删掉的跨度：从该关键字第一个字符起，一直删到本句结束用的 $;$（这个分号也删掉）
- 允许跨行：关键字和分号中间可以夹着换行，匹配与删除都要跨过这些行

**规则2：内容处理**

- 被删区间：从关键字第一个字符到分号 $;$
- 区间里面：换行符 $\n$ 留下，别的字符（空格、正文、分号）都拿掉
- 处理后的样子：
  - 关键字左边、还没进入区间的缩进空白，照原样留着
  - 不管这句有没有跨行，每一行在区间里都只剩换行，行的条数不增不减

**规则3：注释保护**

- 单行注释：从 $//$ 起直到这一行结束
- 多行注释：从 $/*$ 起直到 $*/$，中间可以换行
- 保留方式：注释整段照抄，不能被清掉

**规则4：边界定义**

- 关键字左侧只能是：一行的开头、空格、制表符、$\{$ 或 $;$
- 关键字右侧只能是：空格、制表符、换行或 $;$
- 两侧对不上：就当成普通名字，不要删（例如 $myremark$）

## 输入格式

- 给出一段字符串，内容是 YANG 文本
- 保证这段文本语法大体正确，分号 $;$ 都是真正的语句结束

## 输出格式

- 输出清洗之后的 YANG 字符串：指定关键字连同它后面直到分号的内容已经去掉，注释仍在

## 示例

### 示例 1

**输入：**

```
    }

```

**输出：**

```

        type string;

/*
块注释中出现 remark "fake";
整段都要留下
*/
    leaf flag {
        type string;



    }
    leaf alias {
        type string;
        myremark "keep";
    }
}
```

**说明：**

只含空格的行在渲染里容易看成空行，下面按行写清空格个数。

- $remark\ "Edge\ port";$ 与 $preset\ "eth0";$ 两行，关键字左侧各有 $8$ 个空格，这些空格留在区间外，所以这两行各剩 $8$ 个空格。
- 块注释整段照抄，里面的 $remark\ "fake";$ 不动。
- 跨行的 $remark$：关键字所在行左侧有 $8$ 个空格，保留；接下来 $Line-a$、$Line-b$ 两行整行都落在区间里，只留下换行，行首没有空格。接着 $required\ true;$ 那一行左侧又是 $8$ 个空格，保留。所以 $type\ string;$ 和 $leaf\ flag$ 的右括号之间，空格数依次是 $8$、$0$、$0$、$8$。
- $myremark$ 左侧是字母，不是合法边界，整行保留。

### 示例 2

**输入：**

```
leaf y {
    remark "y";
}
```

**输出：**

```
leaf y {

}
```

**说明：**

中间那一行关键字左侧有 $4$ 个空格，清洗后这 $4$ 个空格还在。

## 提示

1. 执行顺序：规则 $1$ 到 $4$ 按这个先后做，也就是先圈出要删的片段，再按区间规则改写片段，接着把注释保住，最后用两侧边界再核对一遍。
2. 注释一律保留：注释里就算出现了目标关键字，也整段不动。
3. 可以跨行：一次删除允许盖住很多行，删完以后换行的骨架还在。
4. 两侧边界：只有左右都满足边界，这个关键字才删；否则当普通名字留下。
5. 语法不用再查：输入已经保证大体合法，不必另做语法检查。
6. 可以放心简化：关键字那一句里（跨不跨行都一样）不会夹注释；引号中间也不会再嵌套关键字。例如不用处理 $remark$ // $remark$ $note$，也不用处理 $remark$ "$xx$ $remark$ $note$";。

## 解题思路

### 输出到底长什么样：删掉的是区间，不是整行

题面把删除定义得很细：从关键字的第一个字符起，到本句结束的 `;` 为止（含分号）整段拿掉，**但这段区间里的换行符要留下**。这条「留换行」的规定决定了输出形状，也决定了三条判定标准：

- 关键字左边的缩进不在区间里，原样保留。所以以 8 个空格开头的 `remark "Edge port";` 清洗之后剩下的是一行 8 个空格，不是彻底的空行；
- 区间里每有一个换行，输出就补一个换行。跨行语句删完只留下若干空行，**行的条数不增不减**；
- 注释是独立的保护区：`//` 到本行末尾、`/*` 到 `*/` 整段照抄，里面就算写着 `remark "fake";` 也不动。

于是输出不是「把哪几行删掉」，而是「把某些片段改写成一串换行骨架」，其余字符原样拼回。判定一段该不该删要同时看两侧：左侧只能是行首、空格、制表符、`{` 或 `;`；右侧只能是空格、制表符、换行或 `;`。`myremark` 的左侧是字母 `y`，`remarkable` 的右侧是字母 `a`，任意一侧对不上就按普通名字处理。

### 为什么是单遍扫描：三类区间天然互斥

这题要区别对待的区间只有三种：注释（整段照抄）、待删语句（只留换行）、普通正文（逐字照抄）。它们都从某个起点向右延伸，而且不会互相嵌套 —— 题面明确保证关键字所在语句里不夹注释、引号里不嵌关键字。这正好适配「一个下标从左往右走，遇到谁就按谁的规则整段处理，然后直接跳到这一段末尾」：

- 遇到 `//`：抄到行尾；
- 遇到 `/*`：抄到 `*/`；
- 遇到目标关键字且两侧边界合法：跳到分号之后，只输出区间里的换行；
- 其余字符：抄一个，下标加一。

由于每次「整段处理」都把下标推到了这一段之后，**任何字符最多被访问常数次**，总时间是 $O(L)$。换成用正则对整段文本反复替换就麻烦了：先替换关键字会破坏注释，先去注释又会误删真语句，两套规则互相打架；而且每次替换都要重建字符串，删除次数一多就退化成 $O(L^2)$。

### 四条规则分别落在代码的哪几行

- **规则 3（注释保护）**：第 111 行的 `if ch == "/" and text[i + 1 : i + 2] == "/"` 与第 118 行的 `"*"` 分支。它们排在关键字识别**之前**并直接 `continue`，所以注释内部根本不会进入关键字判断；`text.find("\n", i)` 与 `text.find("*/", i + 2)` 负责找出整段注释的边界。
- **规则 1（目标字段）**：第 128 行的 `text.startswith(kw, i)` 认关键字，第 136 行的 `semi = text.find(";", i + klen)` 找本句分号，第 142 行的 `i = semi + 1` 跳过整句。
- **规则 2（区间内容处理）**：第 141 行的 `out.append("\n" * text.count("\n", i, semi + 1))` 是删除时唯一往输出写内容的地方。乘数是区间内的换行个数，其余字符一个都不写 —— 缩进之所以还在，是因为它在进入区间之前就已经被逐字符抄进 `out` 了。
- **规则 4（两侧边界）**：第 130 行的 `left = i == 0 or text[i - 1] in " \t{;\n"` 与第 132 行的 `right = text[i + klen] in " \t\n;"`。`i == 0` 覆盖「行首」是文件开头的情形，字符集里的 `\n` 覆盖「行首」出现在中间行的情形。

## 完整代码实现

```python
"""
P5563. 边缘模型清洗 - 注释感知的单遍扫描模拟

把 YANG 文本里 remark / preset / required 三个关键字所在的语句删掉，
注释原样保留。特殊的删除方式：从关键字第一个字符起删到本句结束的 ';'，
这段闭区间里的所有字符都丢掉，唯独换行符保留 —— 于是跨行语句的行数不变，
关键字左侧的缩进因为在区间外而照原样留下。

输入格式：
- 一段 YANG 文本（可能多行）。

输出格式：
- 清洗后的文本。

核心思路：
1. 单遍扫描。先认注释：遇到 // 抄到行尾、遇到 /* 抄到 */，注释内部
   不再找关键字 —— 这是注释保护的全部实现。
2. 正文里若当前位置正好以 remark / preset / required 之一开头，再核对
   两侧边界：左侧必须是行首、空格、制表符、{ 或 ;（否则像 myremark 一样
   当普通名字）；右侧必须是空格、制表符、换行或 ';'。
3. 两侧都合法时，找到后面第一个 ';'（题面保证语句内不夹注释、引号内
   不嵌关键字，因此直接找即可）。区间里逐字符检查，只有 '\n' 写进结果，
   表示"这些行的骨架还在"；扫描位置跳到分号之后。
4. 其余字符原样写入，前进一格。

时间复杂度：O(len)（每字符常数趟，关键字分发用元组循环，长度固定为 3）
空间复杂度：O(len)
"""

# https://codefun2000.com/p/P5563
import sys

KEYWORDS = ("remark", "preset", "required")

# @sample-start
"""
样例输入 1:
container node {
    leaf port {
        type string;
        remark "Edge port";
        preset "eth0";
    }
/*
块注释中出现 remark "fake";
整段都要留下
*/
    leaf flag {
        type string;
        remark
            "Line-a
            Line-b";
        required true;
    }
    leaf alias {
        type string;
        myremark "keep";
    }
}

样例输出 1:
container node {
    leaf port {
        type string;
[8 个空格]
[8 个空格]
    }
/*
块注释中出现 remark "fake";
整段都要留下
*/
    leaf flag {
        type string;
[8 个空格]
[空行]
[空行]
[8 个空格]
    }
    leaf alias {
        type string;
        myremark "keep";
    }
}
"""
# @sample-end

# @sample-start
"""
样例输入 2:
leaf y {
    remark "y";
}

样例输出 2:
leaf y {
[4 个空格]
}
"""
# @sample-end


def solve():
    text = sys.stdin.read()

    out = []
    i = 0
    n = len(text)
    while i < n:
        ch = text[i]
        # 注释保护：整段照抄，内部不再找关键字
        if ch == "/" and text[i + 1 : i + 2] == "/":
            end = text.find("\n", i)
            if end == -1:
                end = n
            out.append(text[i:end])
            i = end
            continue
        if ch == "/" and text[i + 1 : i + 2] == "*":
            end = text.find("*/", i + 2)
            end = n if end == -1 else end + 2
            out.append(text[i:end])
            i = end
            continue

        # 关键字识别 + 两侧边界
        removed = False
        for kw in KEYWORDS:
            if text.startswith(kw, i):
                klen = len(kw)
                left = i == 0 or text[i - 1] in " \t{;\n"
                if i + klen < n:
                    right = text[i + klen] in " \t\n;"
                else:
                    right = True
                if left and right:
                    semi = text.find(";", i + klen)
                    if semi == -1:
                        # 题面保证分号存在；无分号时按普通文本对待
                        break
                    # 闭区间 [i, semi] 里只保留换行符：行的骨架不增不减
                    out.append("\n" * text.count("\n", i, semi + 1))
                    i = semi + 1
                    removed = True
                break
        if removed:
            continue

        out.append(ch)
        i += 1

    sys.stdout.write("".join(out))


def _clean(text):
    """对任意输入文本跑一遍清洗逻辑，供自测复用。"""
    import io, sys as _sys

    old_in, old_out = _sys.stdin, _sys.stdout
    _sys.stdin = io.TextIOWrapper(io.BytesIO(text.encode("utf-8")))
    _sys.stdout = io.StringIO()
    try:
        solve()
        return _sys.stdout.getvalue()
    finally:
        _sys.stdin, _sys.stdout = old_in, old_out


def run_tests():
    """官方样例 + 边界/变形用例。空格行按题面说明的真实字节数书写。"""
    SP8 = " " * 8
    SP4 = " " * 4

    sample1_in = (
        "container node {\n"
        "    leaf port {\n"
        "        type string;\n"
        '        remark "Edge port";\n'
        '        preset "eth0";\n'
        "    }\n"
        "/*\n"
        '块注释中出现 remark "fake";\n'
        "整段都要留下\n"
        "*/\n"
        "    leaf flag {\n"
        "        type string;\n"
        "        remark\n"
        '            "Line-a\n'
        "            Line-b\";\n"
        "        required true;\n"
        "    }\n"
        "    leaf alias {\n"
        "        type string;\n"
        '        myremark "keep";\n'
        "    }\n"
        "}\n"
    )
    sample1_out = (
        "container node {\n"
        "    leaf port {\n"
        "        type string;\n"
        f"{SP8}\n"  # remark 行：缩进留、语句删
        f"{SP8}\n"  # preset 行同上
        "    }\n"
        "/*\n"
        '块注释中出现 remark "fake";\n'
        "整段都要留下\n"
        "*/\n"
        "    leaf flag {\n"
        "        type string;\n"
        f"{SP8}\n"  # 跨行 remark 的第一行
        "\n"  # Line-a 整行落在区间里
        "\n"  # Line-b 同上
        f"{SP8}\n"  # required 行
        "    }\n"
        "    leaf alias {\n"
        "        type string;\n"
        '        myremark "keep";\n'
        "    }\n"
        "}\n"
    )

    sample2_in = "leaf y {\n    remark \"y\";\n}\n"
    sample2_out = "leaf y {\n" f"{SP4}\n" "}\n"

    test_cases = [
        # 官方样例 1 / 2（空格行按说明写明个数：8、0、0、8 与 4）
        (sample1_in, sample1_out),
        (sample2_in, sample2_out),
        # 左边界保护：;remark 前是分号、{preset 前是花括号，都算合法左侧，会删
        ("a {;remark \"x\";\n{preset y;\n}\n", "a {;\n{\n}\n"),
        # 左边界不合法：字母、数字、下划线后面的关键字当普通名字
        ("myremark \"keep\";\nx remark2 \"k\";\n_required \"k\";\n", "myremark \"keep\";\nx remark2 \"k\";\n_required \"k\";\n"),
        # 右边界保护：remark2 / remarkable 这种后接字母/数字的不删
        ("remarkable \"keep\";\nremark  \"del\";\n", 'remarkable "keep";\n\n'),
        # 单行注释里的关键字不动，行注释结构整体保留
        ("type string; // remark \"keep\"\nremark \"del\";\n", "type string; // remark \"keep\"\n\n"),
        # 跨行语句：换行保留、每个被删字符的行数不变
        ("leaf a {\n    required\n        true\n        ;\n}\n", "leaf a {\n    \n\n\n}\n"),
        # 关键字后紧跟分号：整句就是一个关键字 + 分号
        ("required;\nremark;\n", "\n\n"),
    ]

    for i, (inp, expected) in enumerate(test_cases, 1):
        got = _clean(inp)
        status = "✓" if got == expected else "✗"
        if got != expected:
            print(f"样例 {i}: 期望={expected!r}, 实际={got!r} {status}")
        else:
            print(f"样例 {i} ✓")


if __name__ == "__main__":
    import sys as _s

    if len(_s.argv) > 1 and _s.argv[1] == "--test":
        run_tests()
    else:
        solve()
```

## 示例推演

以官方样例 1 为例，从左往右扫，`out` 是输出缓冲区，`i` 是当前下标。几个关键位置的处理如下：

| 扫到 | 命中哪条规则 | 输出变化 | `i` 的走向 |
| --- | --- | --- | --- |
| `container node {`、`    leaf port {`、`        type string;` | 普通正文 | 逐字符原样抄入 | 每次 +1 |
| 第 4 行的 `remark` 的 `r` | 关键字，左侧是空格、右侧是空格 | 8 个空格已在区间外抄入；`[r, ;]` 里 0 个换行，写入 0 个字符 | 跳到分号后 |
| `preset` 的 `p` | 关键字，两侧合法 | 8 个空格已在；写入 0 个字符 | 跳到分号后 |
| `/*` | 块注释 | 整段抄到 `*/`，里面的 `remark "fake";` 从未被检查 | 跳到 `*/` 之后 |
| 第 13 行的 `remark` 的 `r` | 关键字，两侧合法 | 8 个空格已在；区间一直跨到 `Line-b";` 的分号，含 2 个换行，写入 `\n\n` | 跳到分号后，紧随的换行再被当普通字符抄 1 次 |
| `required` 的 `r` | 关键字，两侧合法 | 8 个空格已在；区间 0 个换行 | 跳到分号后 |
| `myremark` 里的 `r` | `startswith("remark", i)` 成立，但左侧是 `y` | 不删，逐字符抄 | +1 |

跨行那一段值得单独数一遍。原文是

```
        remark
            "Line-a
            Line-b";
```

`remark` 前那 8 个空格已经进了 `out`；从 `r` 到分号之间有两个换行（`remark` 之后一个、`Line-a` 之后一个），于是写入 `\n\n`；分号后面那个换行不属于删除区间，随后按普通字符抄进去。合起来是「8 个空格 + 3 个换行」，展开就是一行 8 个空格、一行空行、一行空行，紧跟着才是 `        required true;` 所在的那一行。这就是题面说明里四个行首空格数 $8, 0, 0, 8$ 的来源；整段输出的行数与输入相同，仍是 22 行。

块注释那一段则是另一条路：扫到 `/*` 时，`text.find("*/", i + 2)` 直接定位到第 10 行的 `*/`，`out.append(text[i:end])` 把整段原样搬过去，`i` 跳过 `*/`。里面的 `remark "fake";` 之所以安全，不是因为做了什么特殊判断，而是因为这段文本从未被逐字符审查。

样例 2 更短：`leaf y {` 逐字抄入；第二行先把 4 个空格抄进 `out`，再用 `remark "y";` 整句换成一个换行（区间内 0 个换行，所以什么都不写，只跳到分号后）；`}` 照抄。结果三行，中间那行是 4 个空格。

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| ---- | ---------- | ---------- | ---- |
| 每删一段就重建整串 | $O(L^2)$ | $O(L)$ | 删除次数可达 $O(L)$，每次切片拼接都要复制全串 |
| 单遍扫描 + 注释保护（最优） | $O(L)$ | $O(L)$ | 每次整段处理都把下标推到段尾，被删区间与注释区间首尾相接、互不重叠，每个字符只过常数次 |

---

## 易错点总结

### 1. 注释保护没有真正跳过注释正文

第 111 行的 `//` 分支与第 118 行的 `/*` 分支把整段注释抄进 `out` 之后，必须用 `i = end` 把下标直接推到注释末尾并 `continue`，注释正文才算完全绕开了后面的关键字判断。若这两条分支缺失（或者只抄了 `//`、`/*` 两个字符就继续逐字符扫描），注释里的 `remark "fake";` 会被照常删掉：样例 1 的 `块注释中出现 remark "fake";` 会变成 `块注释中出现 `，自测第 6 组（`type string; // remark "keep"\nremark "del";`）的输出会变成 `type string; // ` 加一个空行 —— 注释正文被清掉后，`find(";", ...)` 一路找到下一行的分号，把两行内容一起吞进了删除区间。

### 2. 删除区间把换行也扔掉

第 141 行的 `out.append("\n" * text.count("\n", i, semi + 1))` 一旦写成 `out.append("")`，跨行语句就会连行数一起塌掉。样例 1 里那个跨三行的 `remark` 会少 2 行，输出从 22 行缩到 20 行，`leaf flag` 的右括号提前出现，与题面说明的 $8, 0, 0, 8$ 对不上。

### 3. 右侧边界没检查

第 132 行的 `right = text[i + klen] in " \t\n;"` 是拦住 `remarkable`、`remark2` 的唯一一道闸。若只判左侧就删除，`remarkable "keep";` 这一行会被整句清掉，只剩 0 个字符加一个换行；自测里的第 5 组用例（输入 `remarkable "keep";` 与 `remark  "del";` 两行）期望第一行原样、第二行只剩换行，此时会变成两行都只剩换行。

## 扩展思考

题面特意保证了「关键字语句里不夹注释」「引号里不嵌关键字」，扫描才敢直接 `find(";")`。如果去掉这两条保证（例如字符串字面量里出现 `// remark`），就要在同一个单遍骨架上再加一个「当前是否在引号内」的状态：在引号内时 `//` 不再是注释起点，`;` 也不算语句结束。结构不变，判断变复杂，这也正是真实编译器词法分析器的做法。
