# P5564. 迷宫最短救援

> 场次：2026年9月23日-非AI方向 · 来源：[CodeFun2000 P5564](https://codefun2000.com/p/P5564)

## 题目描述

穿越这片迷宫、把受困公主救出来，是王子此刻要办的事。毒雾正往四处散开，因此他得用尽量少的时间赶到公主身边。挡路的不只有墙，还有守在若干区域上的怪物。

### 题目内容

地图已经给出。王子从出发点动身，要算出抵达公主所在格的最少移动次数。

### 移动规则

- 每次只许朝上、左、下、右迈一格，斜向跨步不算合法
- 跑出地图边界的格子，一律按墙处理
- 墙所在的格子，王子踏不上去

### 怪物规则

- 怪物上、下、左、右紧挨的那一格，没拿到宝剑时都不能踏入
- 地图上会出现宝剑，王子能够把它捡起来
- 宝剑一旦到手，王子就具备击杀怪物的能力
- 宝剑到手之后，怪物上、下、左、右紧挨的格子也可以进入
- 宝剑到手之后，王子还能踏进怪物所在格，并且只击倒脚下这一只（其余怪物仍留在原地）
- 宝剑若正好放在怪物紧挨的格子上，王子仍可进入该格并把剑捡走
- 出发时若王子本人就站在怪物紧挨的格子上，这并不妨碍他迈出下一步（下一步应当离开危险格）

### 策略选择

王子得在两条路线里挑更省步数的一条：

- 先把宝剑拿到手再去击倒怪物，步数会不会更少
- 或者干脆不靠近怪物、从旁边绕，步数会不会更少

## 输入格式

数据来自标准输入。
第一行给出两个整数 $h$ 和 $w$，分别是地图的行数与列数（$1 \le h,w \le 100$），$h$ 与 $w$ 用空格隔开。
随后是 $h$ 行，每一行有 $w$ 个字符，用来描绘整张地图：
- $.$ 代表可以落脚的空地
- `#` 代表不能落脚的墙
- $S$ 代表王子出发的格子
- $P$ 代表公主所在的格子
- $M$ 代表一只怪物
- $W$ 代表一把宝剑

输入保证出发格 $S$ 与公主格 $P$ 都恰好出现一次。

## 输出格式

答案写到标准输出。只写出一个整数，即王子走到公主处所需的最少步数。
公主处不可达时，结果记成 $-1$。

## 示例

### 示例 1

**输入：**

```
3 3
S.M
...
.MP
```

**输出：**

```
-1
```

**说明：**

公主在右下角，左边紧挨着一只怪物，地图里又没有宝剑。没剑时那一格进不去，所以无解。

### 示例 2

**输入：**

```
3 5
S.#.P
..#..
W.M..
```

**输出：**

```
8
```

**说明：**

行列都从 $0$ 计。一条最短路线是 $(0,0)\rightarrow(1,0)\rightarrow(2,0)\rightarrow(2,1)\rightarrow(2,2)\rightarrow(2,3)\rightarrow(2,4)\rightarrow(1,4)\rightarrow(0,4)$，共 $8$ 步。$(2,0)$ 处捡到宝剑后才能穿过怪物及其左右两侧。列下标 $2$ 的前两行是墙，不拿剑就无法从左侧走到右侧的公主。

### 示例 3

**输入：**

```
1 5
S...P
```

**输出：**

```
4
```

**说明：**

这一行没有墙也没有怪物。王子从最左格一直向右，走到最右的公主处，步数是 $4$。

## 解题思路

### 答案是什么：最少步数，以及两张「通行证」

题目要的输出只有一个整数：王子从 S 走到 P 的最少四向移动次数；走不到就输出 $-1$。墙和怪物都只是路上的限制，题目并不要求击杀怪物，也不要求捡剑——宝剑只是用来解锁道路的工具。

真正决定「这一步能不能走」的，是王子此刻手里有没有剑：

- 没剑时，怪物格不能进；怪物上下左右紧挨的四格也不能进。唯一的例外是宝剑格：即使它贴着怪物，王子也能走进去，进格的同时就把剑捡了。
- 有剑时，上面这些限制全部消失，怪物格和它周围的格子都能走。踩进怪物格只会放倒脚下这一只，其余怪物还在，但它们已经影响不了通行。

还有一个容易忽略的设定：出发格 S 本身可以贴着怪物。规则约束的是「踏入某一格」这个动作，S 是起点，不需要先通过一次检查。

### 关键观察：只需要记住「有没有剑」

怪物的死活看起来像一个会变化的状态，其实不用记录。理由分两半：没剑的时候一只怪物也杀不掉；有剑之后，所有怪物的贴身格和怪物格本来就都能走，脚下这一只死没死，对「下一步能去哪」没有任何影响。所以整张地图上真正会改变通行规则的，只有「是否持剑」这一个布尔量。地图上有多把剑也无所谓，拿到一把之后，其余剑格与普通空地没有区别。

于是搜索状态写成三元组 `(行, 列, 是否持剑)`，同一个格子在「无剑层」和「持剑层」各有一份最短步数。求的是最少步数，而每一步的代价都恰好是 $1$，这正是 BFS 的适用条件：BFS 按步数一层层向外扩，某个状态第一次被弹出时，它的步数就是最少步数。DFS 只能保证「找到一条路」，不能保证最短；带权最短路（Dijkstra）在这里也没有必要，因为边权全是 $1$。

规模上，$h, w \le 100$，状态总数最多 $2hw = 2 \times 10^4$，每个状态只入队一次，BFS 绰绰有余。

### 实现映射：先标危险格，再在入队前做检查

代码把上面的分析拆成五步：

1. 读图时记下 S、P、所有怪物和所有剑格；用 `danger[r][c]` 预处理「没剑时不能踏入」的格子——对每只怪物，把它自己和上下左右四格都标上（越界的邻居直接跳过）。怪物自己也在里面，所以即使不单独写一条「不能进 M」，危险格判断也能挡住它。
2. `dist[r][c][sw]` 全部初始化成 $-1$，起点是 `(sr, sc, 0)`，表示站在 S、没有剑。
3. 每次从队首取出 `(r, c, sw)`：如果这就是 P，直接输出步数并返回——BFS 保证这是最短的。否则枚举四个方向，依次检查：越界（按墙处理）、`#`、以及没剑时的两条禁令（怪物格；危险格且不是剑格）。剑格是危险格判断里的例外，因为「进格即捡剑」，题面明确允许。
4. 通过检查后计算下一层的持剑状态：`nsw = 1 if (sw or ch == "W") else 0`。这里必须带上 `sw`，剑是「带着走」的，不是只在剑格上生效。只有 `dist[nr][nc][nsw]` 还是 $-1$ 时才入队。
5. 队列空了还没碰到 P，说明公主不可达，输出 $-1$。

`dist` 的第三维不能省。同一格先以「无剑」到达、后以「持剑」到达，是两种不同的处境：前者可能被怪物挡住，后者却能继续往前。把它们合并成一个 visited，就会让先到的无剑访问挡掉后来的持剑访问，丢掉本来存在的路线。

## 完整代码实现

```python
"""
P5564. 迷宫最短救援 - 带宝剑状态的广度优先搜索

王子从 S 出发，用最少的四向步数到达 P。没拿到宝剑时，怪物格自己以及
它上下左右相邻的格都不能踏入（宝剑格例外——即使贴着怪物也放行，进格
即捡剑）；拿到宝剑后这些限制全部消失，还能踩进怪物格并击倒脚下这一只。

输入格式：
- 第 1 行：h、w（1 <= h, w <= 100）；
- 接下来 h 行、每行 w 个字符：'.'空地 '#'墙 'S'王子 'P'公主 'M'怪物 'W'宝剑。

输出格式：
- 最少步数；公主不可达输出 -1。

核心思路：
1. 关键观察：怪物有两类影响——"贴身格禁入"只在没剑时生效；"踩进怪物格
   只击倒脚下这一只"在持剑后对剩余怪物毫无约束力（持剑者本来就能进任何
   贴身格和怪物格）。因此持剑与否是唯一需要记忆的资格状态，不必记录
   每只怪物的死活。
2. 求最少步数 -> 边权全为 1 的 BFS。状态扩成 (行, 列, 是否持剑)：同一格
   在两个资格层各有一个最短步数，互不吞并——先捡剑再回来的路线不会被
   无剑层的旧访问挡掉。
3. 无剑搬家规则：目标格是墙跳过；是怪物跳过；是"贴身危险格"跳过，但
   该格恰好是宝剑则放行（进格即捡剑，状态切到持剑层）。
4. 起点即使贴着怪物也从 (S, 无剑) 开始——禁入只约束"踏入"这个动作，
   不约束起点本身。

时间复杂度：O(h * w)，每个格子至多入队两次（两个资格层）
空间复杂度：O(h * w)
"""

# https://codefun2000.com/p/P5564
import sys

# @sample-start
"""
样例输入 1:
3 3
S.M
...
.MP

样例输出 1:
-1
"""
# @sample-end

# @sample-start
"""
样例输入 2:
3 5
S.#.P
..#..
W.M..

样例输出 2:
8
"""
# @sample-end

# @sample-start
"""
样例输入 3:
1 5
S...P

样例输出 3:
4
"""
# @sample-end


def solve():
    data = sys.stdin.buffer.read().split()
    h, w = int(data[0]), int(data[1])
    grid = [data[2 + r].decode() for r in range(h)]

    from collections import deque

    sr = sc = pr = pc = -1
    sword_cells = []
    monsters = []
    for r in range(h):
        row = grid[r]
        for c in range(w):
            ch = row[c]
            if ch == "S":
                sr, sc = r, c
            elif ch == "P":
                pr, pc = r, c
            elif ch == "M":
                monsters.append((r, c))
            elif ch == "W":
                sword_cells.append((r, c))

    # danger[r][c]：怪物所在格及其四邻（没剑时不能踏入的格）
    danger = [[False] * w for _ in range(h)]
    for r, c in monsters:
        for dr, dc in ((0, 0), (-1, 0), (1, 0), (0, -1), (0, 1)):
            nr, nc = r + dr, c + dc
            if 0 <= nr < h and 0 <= nc < w:
                danger[nr][nc] = True
    swordset = set(sword_cells)

    # BFS 状态 (r, c, 持剑?)；同一格在两个资格层里各有自己的最短步数
    dist = [[[-1, -1] for _ in range(w)] for _ in range(h)]
    dist[sr][sc][0] = 0
    q = deque([(sr, sc, 0)])
    while q:
        r, c, sw = q.popleft()
        steps = dist[r][c][sw]
        if r == pr and c == pc:
            print(steps)
            return
        for dr, dc in ((-1, 0), (0, -1), (0, 1), (1, 0)):
            nr, nc = r + dr, c + dc
            if not (0 <= nr < h and 0 <= nc < w):
                continue  # 越界按墙处理
            ch = grid[nr][nc]
            if ch == "#":
                continue  # 墙踩不上去
            if sw == 0:
                if ch == "M":
                    continue  # 没剑不能踏进怪物格
                if danger[nr][nc] and (nr, nc) not in swordset:
                    continue  # 贴身危险格禁入；宝剑格是例外，进格即捡剑
            nsw = 1 if (sw or ch == "W") else 0
            if dist[nr][nc][nsw] == -1:
                dist[nr][nc][nsw] = steps + 1
                q.append((nr, nc, nsw))

    print(-1)


def run_tests():
    """官方样例 + 语义角落用例（每个用例的答案都手工推过）。"""
    import io

    test_cases = [
        # 官方样例 1：没剑、公主贴着怪物 -> 无解
        ("3 3\nS.M\n...\n.MP\n", "-1"),
        # 官方样例 2：先到 (2,0) 捡剑，持剑后穿过怪物一排，共 8 步
        ("3 5\nS.#.P\n..#..\nW.M..\n", "8"),
        # 官方样例 3：无怪无剑的直线
        ("1 5\nS...P\n", "4"),
        # 宝剑贴着怪物：W 格例外放行，捡剑后踩进怪物格再进公主格，共 4 步
        ("1 5\nS.WMP\n", "4"),
        # P 贴着怪物且无剑可达必经危险格 -> 无解
        ("1 3\nSMP\n", "-1"),
        # 无剑时绕不开贴身格、必须先捡剑：W 位于怪物正下方
        ("2 3\nS.M\n.WP\n", "3"),
        # 无怪无墙的平凡 BFS
        ("2 2\nSP\n..\n", "1"),
        # 起点贴身怪物：起点不受禁入约束，可以迈出第一步
        ("3 3\nSM.\n...\n..P\n", "4"),
        # 两只怪物：持剑后过路，贴身规则消失即够用，无需逐只记死活
        ("3 5\nS.M.P\n..M..\nW....\n", "8"),
        # 怪物贴身只算上下左右，对角不算
        ("3 3\nSM.\n.#.\nP.W\n", "2"),
        # 同一格"无剑先到"会锁死持剑迟到状态：单层判重直接判无解（正确 5 步）
        ("2 4\nS.MP\nW...\n", "5"),
    ]

    for i, (inp, expected) in enumerate(test_cases, 1):
        old_stdin, old_stdout = sys.stdin, sys.stdout
        sys.stdin = io.TextIOWrapper(io.BytesIO(inp.encode("utf-8")))
        sys.stdout = io.StringIO()
        try:
            solve()
            output = sys.stdout.getvalue().strip()
        finally:
            sys.stdin, sys.stdout = old_stdin, old_stdout
        status = "✓" if output == expected else "✗"
        print(f"样例 {i}: 期望={expected}, 实际={output} {status}")


if __name__ == "__main__":
    if len(sys.argv) > 1 and sys.argv[1] == "--test":
        run_tests()
    else:
        solve()
```

## 示例推演

用示例 2（$h=3,\ w=5$）走一遍。怪物在 $(2,2)$，危险格是 $(2,2)$、$(2,1)$、$(2,3)$，第四格 $(1,2)$ 是墙；宝剑在 $(2,0)$，离怪物两格，本身不是危险格。

BFS 从 $(0,0)$（无剑）出发，按步数分层，只列每层新入队的状态：

| 步数 | 新入队的状态 | 说明 |
| --- | --- | --- |
| 0 | $(0,0)$ 无剑 | 起点 |
| 1 | $(1,0)$ 无剑、$(0,1)$ 无剑 | 只能向下或向右 |
| 2 | $(2,0)$ 持剑、$(1,1)$ 无剑 | 踩到 $(2,0)$ 的剑，状态切到持剑层 |
| 3 | $(2,1)$ 持剑、$(1,0)$ 持剑 | 持剑后危险格 $(2,1)$ 放行 |
| 4 | $(2,2)$ 持剑、$(1,1)$ 持剑、$(0,0)$ 持剑 | 持剑可以踩怪物格 |
| 5 | $(2,3)$ 持剑、$(0,1)$ 持剑 | |
| 6 | $(2,4)$ 持剑、$(1,3)$ 持剑 | |
| 7 | $(1,4)$ 持剑、$(0,3)$ 持剑 | |
| 8 | $(0,4)$ 持剑 | 公主格，弹出即得 $8$ |

对应的一条最短路线是 $(0,0) \to (1,0) \to (2,0)$ 捡剑 $\to (2,1) \to (2,2) \to (2,3) \to (2,4) \to (1,4) \to (0,4)$，共 $8$ 步。注意 $(0,2)$ 是墙，想从上面直接向右走不通；不捡剑时 $(2,1)$、$(2,3)$ 这些危险格又过不去，所以必须先下到 $(2,0)$ 拿剑。

示例 1 里公主 $(2,2)$ 紧贴着怪物 $(2,1)$，本身是危险格，而地图里没有剑，BFS 到不了，输出 $-1$。示例 3 没有怪物也没有墙，就是一条直线，BFS 的层数等于列差 $4$。

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| ---- | ---------- | ---------- | ---- |
| DFS 枚举不重复路径 | 指数级（最坏要枚举全部简单路径） | $O(hw)$ | 同一格会被反复展开，网格一大就走不完，而且不能保证最短 |
| 按 (行, 列, 是否持剑) 分层的 BFS（最优） | $O(hw)$ | $O(hw)$ | 状态数 $2hw$，每个状态至多入队一次、四条出边各检查一次 |

## 易错点总结

### 1. `dist` 压成二维，先到的无剑状态锁死后面的持剑状态

代码用 `dist[r][c][sw]` 记步数，第三维就是持剑层。若压成 `dist[r][c]`，同一格「先无剑到达」会占掉位置，让「后持剑到达」无法入队：

```
3 4
S.MP
.#..
W#..
```

正确走法是 $(0,0) \to (1,0) \to (2,0)$ 捡剑，再原路退回 $(1,0)$、$(0,0)$，穿过怪物到公主，共 $7$ 步；二维 visited 会认为 $(1,0)$ 在第 $1$ 步就来过，把退回的那一步挡掉，最后输出 $-1$。

### 2. 危险格判断丢掉剑格例外

`if danger[nr][nc] and (nr, nc) not in swordset:` 里的 `not in swordset` 是题面写明的例外：剑放在怪物旁边时仍然能进去捡。若写成 `if danger[nr][nc]:`，输入 `1 5` 和一行 `S.WMP` 会从正确答案 $4$ 变成 $-1$，因为唯一的剑格恰好贴着怪物。

### 3. 持剑状态没有继承

`nsw = 1 if (sw or ch == "W") else 0` 中的 `sw` 不能漏。若写成 `1 if ch == "W" else 0`，只有踩在剑格上的那一步算持剑，一离开剑格就丢剑。示例 2 会在 $(2,1)$ 重新变回无剑，被 $(2,2)$ 的怪物挡住，输出 $-1$ 而不是 $8$。

## 扩展思考

把「一把剑」换成多把颜色不同的钥匙、不同怪物只认对应颜色，状态就从布尔量扩成钥匙集合，用状压 BFS（`dist[r][c][mask]`）即可，骨架不变。若不同格子的移动代价不再相同，同样这套状态定义可以直接交给 Dijkstra。
