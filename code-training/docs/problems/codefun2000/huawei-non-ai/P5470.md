# P5470. 推理模型分批约束

> 场次：2026年9月18日-非AI方向 · 来源：[CodeFun2000 P5470](https://codefun2000.com/p/P5470)

## 题目描述

一次偏复杂的推理会拉起若干模型，每一份都对应一个整型编号（若份数是 $6$，编号便是 $1,2,3,4,5,6$）。各模型可能有先后约束：前一份产出会作为后一份的入口，这些约束登记在表 $rel$ 中。

已知模型份数 $p$ 以及约束表 $rel$。第 $k$ 条若写作 $rel[k]=[u,v]$，意思是编号 $v$ 必须等编号 $u$ 先结束，也就是 $u$ 要排到 $v$ 前面。

请把这次推理里的模型切成若干波次来跑；同一波次内彼此没有先后约束，因此允许同时开工。请给出最少要切几波，才能让全部模型都跑完。

下面这 $5$ 份模型的先后约束可以当作例子：

```text
    4
   / \
  1   5
     / \
    2   3
```

编号 $1$ 与 $5$ 都要等 $4$ 结束，编号 $2$ 与 $3$ 都要等 $5$ 结束。于是先跑 $4$，再让 $1$、$5$ 同时跑，最后让 $2$、$3$ 同时跑，合计 $3$ 波。

**注意：**

1、各模型保证不会形成环形等待。

限制范围：

$1\le p\le 10^{5}$

$0\le e\le\min(p\times(p-1),1.5\times 10^{6})$

## 输入格式

$p$：整数，模型份数。

$e$：整数，先后约束一共有几条。

随后给出 $e$ 行，每一行两个模型编号，用来标明这一对谁先谁后。

## 输出格式

一个整数，即最少要安排的波次数。

## 示例

### 示例 1

**输入：**

```
6 5
2 1
2 5
1 4
5 4
3 6
```

**输出：**

```
3
```

**说明：**

一共 $6$ 份模型。先后约束是：$1$ 等 $2$，$5$ 等 $2$，$4$ 等 $1$ 也等 $5$，$6$ 等 $3$。

可按 $(2,3)\to(1,5,6)\to(4)$ 安排：第一波同时跑 $2$ 与 $3$，第二波同时跑 $1$、$5$、$6$，第三波跑 $4$。最少 $3$ 波。

### 示例 2

**输入：**

```
5 4
5 3
3 2
2 1
1 4
```

**输出：**

```
5
```

**说明：**

一共 $5$ 份模型。先后约束是：$3$ 等 $5$，$2$ 等 $3$，$1$ 等 $2$，$4$ 等 $1$。只能沿 $5\to 3\to 2\to 1\to 4$ 依次开跑，需要 $5$ 波。

## 解题思路

### 判定标准：最少波次就是最长链

每条约束 $u\to v$（$v$ 等 $u$）意味着 $u$、$v$ 不能同波，$v$ 至少排在 $u$ 之后一波。放到一条约束链 $u_1\to u_2\to\cdots\to u_k$ 上看：链上模型两两互斥，只能一波一个，任何合法方案至少要 $k$ 波；而把每个模型放到「以它结尾的最长链长度」编号的那一波——同编号的两点之间不可能有边（$v$ 至少比 $u$ 多 1）——恰好构成 $k$ 波的合法方案。两个方向夹出结论：

$$\text{最少波次} = \text{DAG 上最长链的模型数}$$

它既不是连通块数，也不是最大入度加一——样例 2 的链上每点入度至多 1，输出却是 5。

### 数据范围指向线性一遍

$p\le10^5$、$e\le1.5\times10^6$。任何反复全表扫描的结构都偏贵，题面规模只容许每个点、每条边各被处理常数次。拓扑序 DP 恰好线性：Kahn 队列每个点进出各一次、每条边被松弛一次。

### 拓扑序 DP 的结算时机

$dp[x]$ 表示以 $x$ 结尾的最长链模型数，初值 1——无任何约束的模型自成一波。$dp[x]$ 的终值要等**全部入边**都松弛过才能定案；Kahn 的「入度归零才入队」正是这一点的充要条件：弹出一个点时它的 $dp$ 已收齐所有前驱的贡献，此刻对每条出边 $u\to v$ 松弛

$$dp[v] = \max\bigl(dp[v],\ dp[u]+1\bigr)$$

$v$ 的入度归零后入队。答案最后取 $\max(dp[1..p])$。样例 1 的 4 号点有两条入边（来自 1 与 5），必须两条都处理过才结算——按编号顺序直接扫边（相当于只做一轮松弛，编号靠后的前驱不会回头补贡献）就会漏。

### 实现落点

- 建图 `adj[u].append(v)` 与入度计数随读边同步完成；方向是 u→v，「v 等 u」不走反向。
- $e$ 达百万行，读入用 `readline` 逐行解析：整包 `read().split()` 会一次物化约 300 万个 token，内存峰值高得多。
- 队列用列表加游标 `qi` 推进，避免 `pop(0)` 每次 $O(\text{队列长})$ 的位移。

## 完整代码实现

```python
"""
P5470. 推理模型分批约束 - DAG 上拓扑序 DP（最长链长度）

一次推理拉起 p 份模型，约束 rel[k]=[u,v] 表示 u 必须排在 v 前面
（v 要等 u 结束）。同一波次内的模型必须互无先后约束，允许同时开工；
求让全部模型跑完的最少波次数。

输入格式：
- 第 1 行：模型份数 p 与约束条数 e
  （1<=p<=1e5，0<=e<=min(p*(p-1), 1.5e6)，保证无环）；
- 随后 e 行：每行先 u 后 v，即 u 排在 v 前面。

输出格式：
- 一个整数：最少波次数。

核心思路：
1. 每条约束 u -> v 把 v 至少推到比 u 更后的一波，所以「最少波次」
   就是依赖链最长那条的长度：沿链上的模型只能一波一个、逐波排开，
   而任何不在链上的模型总可以在链头那波一起跑。
2. dp[x] = 以 x 结尾（x 是链上最后一个）的最长链的模型数。初值 1，
   拓扑序下松弛 dp[v] = max(dp[v], dp[u] + 1)。用 Kahn 队列实现：
   入度为 0 的点先入队，每弹出一个 u，就把它还没有依赖的邻居 v 的
   dp 与入度一并更新，入度归零再入队。
3. 答案 = max(dp[1..p])。e=0 时所有点都是孤立点，答案 1；
   一条贯穿 p 个点的链答案 p。

时间复杂度：O(p + e)
空间复杂度：O(p + e)
"""

# https://codefun2000.com/p/P5470
import sys

# @sample-start
"""
样例输入 1:
6 5
2 1
2 5
1 4
5 4
3 6

样例输出 1:
3
"""
# @sample-end

# @sample-start
"""
样例输入 2:
5 4
5 3
3 2
2 1
1 4

样例输出 2:
5
"""
# @sample-end


def solve():
    """读入约束建 DAG，Kahn 拓扑序上做最长链 DP。"""
    readline = sys.stdin.buffer.readline

    def read_ints():
        parts = readline().split()
        while not parts:  # 跳过可能出现的空行
            parts = readline().split()
        return [int(x) for x in parts]

    head = read_ints()
    p, e = head[0], head[1]

    adj = [[] for _ in range(p + 1)]
    indeg = [0] * (p + 1)
    for _ in range(e):
        pair = read_ints()
        u, v = pair[0], pair[1]
        adj[u].append(v)
        indeg[v] += 1

    # dp[x]：以 x 结尾的最长链长度；成链前每个模型自成一波
    dp = [1] * (p + 1)
    queue = [x for x in range(1, p + 1) if indeg[x] == 0]
    ans = 1
    qi = 0
    while qi < len(queue):
        u = queue[qi]
        qi += 1
        if dp[u] > ans:
            ans = dp[u]
        du1 = dp[u] + 1
        out = adj[u]
        for v in out:
            if du1 > dp[v]:
                dp[v] = du1
            indeg[v] -= 1
            if indeg[v] == 0:
                queue.append(v)
    print(ans)


def run_tests():
    """运行官方样例与边界用例，方便本地自测。"""
    import io

    test_cases = [
        # 官方样例 1：(2,3) -> (1,5,6) -> (4) 三波
        (
            "6 5\n2 1\n2 5\n1 4\n5 4\n3 6\n",
            "3",
        ),
        # 官方样例 2：一条贯成全链，5 波
        (
            "5 4\n5 3\n3 2\n2 1\n1 4\n",
            "5",
        ),
        # 无任何约束：一波全并行
        (
            "3 0\n",
            "1",
        ),
        # 单个模型
        (
            "1 0\n",
            "1",
        ),
        # 菱形两链等长：1->2 与 1->3 汇合到 4，最长链 3
        (
            "4 4\n1 2\n1 3\n2 4\n3 4\n",
            "3",
        ),
        # 两条独立短链：最长各 2
        (
            "4 2\n1 2\n3 4\n",
            "2",
        ),
        # 记录重复出现的同一条约束：不应多算波次
        (
            "3 3\n1 2\n1 2\n2 3\n",
            "3",
        ),
        # 分叉汇聚且长短不一：长链决定答案
        (
            "5 5\n1 2\n2 3\n1 4\n4 5\n5 3\n",
            "4",
        ),
        # 链头编号大于链身：按编号直扫会漏掉靠后前驱的贡献
        (
            "3 2\n3 1\n1 2\n",
            "3",
        ),
    ]

    for i, (inp, expected) in enumerate(test_cases, 1):
        old_stdin, old_stdout = sys.stdin, sys.stdout
        sys.stdin = io.TextIOWrapper(io.BytesIO(inp.encode("utf-8")))
        sys.stdout = io.StringIO()
        try:
            solve()
            output = sys.stdout.getvalue().strip()
        finally:
            sys.stdin, sys.stdout = old_stdin, old_stdout

        status = "✓" if output == expected else "✗"
        print(f"样例 {i}: 期望={expected}, 实际={output} {status}")


if __name__ == "__main__":
    if len(sys.argv) > 1 and sys.argv[1] == "--test":
        run_tests()
    else:
        solve()
```

## 示例推演

### 样例 1：两条链汇入同一个点

约束 $(2,1),(2,5),(1,4),(5,4),(3,6)$ 给出边 $2{\to}1$、$2{\to}5$、$1{\to}4$、$5{\to}4$、$3{\to}6$。入度：$1,5,6$ 各 1，$4$ 为 2；$2,3$ 入度为 0，初始队列 $[2,3]$，各点 $dp$ 初值 1。

| 弹出 | 松弛与入队 |
| ---- | ---- |
| 2 | $dp[1]=2$、$dp[5]=2$，两者入度归零入队 → 队列 $[2,3,1,5]$ |
| 3 | $dp[6]=2$，入队 |
| 1 | $dp[4]\to2+1=3$；4 的入度还剩 1（5 的入边未到），不入队 |
| 5 | $dp[4]=\max(3,\ 2+1)=3$，入度归零入队 |
| 6 | 无出边 |
| 4 | 无出边；$dp[4]=3$ 即全局最大 |

答案 3，对应 $\{2,3\}\to\{1,5,6\}\to\{4\}$ 的三波方案。第 3、4 行是关键：4 号的 $dp$ 经两条入边先后松弛才定案；约束换成 $(3,1)$、$(1,2)$（自测第 9 组）时，按编号直扫只会输出 2，链长其实是 3——这正是结算时机错位的代价。

### 样例 2：单链五波

约束 $(5,3),(3,2),(2,1),(1,4)$ 构成链 $5\to3\to2\to1\to4$，松弛沿链逐级加一：$dp[3]=2$、$dp[2]=3$、$dp[1]=4$、$dp[4]=5$。每波只能放下一个模型，答案 5。

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| ---- | ---------- | ---------- | ---- |
| DFS + 记忆化求每点最长链 | $O(p + e)$ | $O(p + e)$ | 递归深度可达 $p=10^5$，Python 需扩递归上限，栈深风险高 |
| Kahn 队列拓扑 DP（最优） | $O(p + e)$ | $O(p + e)$ | 迭代式一遍扫完，$e=1.5\times10^6$ 时实测约 1 秒 |

每条边在队列里被松弛一次、每个点进出各一次，两者同阶时迭代式在栈深与常数上都占优。

## 易错点总结

### 1. dp 初值从 0 起步

每个模型至少自占一波，$dp$ 初值 1（`solve()` 里 `dp = [1] * (p + 1)`）。若按「松弛几次就是几波」的习惯从 0 起步，无约束（$e=0$）时所有点停在 0，输出 0 而正确是 1——自测第 3 组直接卡这一条。

### 2. 不按拓扑序就扫边

把邻接表存好后按编号 `for u in 1..p` 直接过一遍邻边，相当于只做一轮松弛：编号靠后的前驱不会回头补贡献。拓扑序只有在 DAG 上才存在，Kahn 的入度归零机制维护的正是这个序。自测第 9 组（约束 `(3,1)`、`(1,2)`）按编号直扫会输出 2，正确链长 3。

### 3. 大数据下行细节放大成故障

$e\le1.5\times10^6$：`read().split()` 一次性物化约 300 万个 token，内存峰值远高于逐行 `readline`，大用例容易顶到内存上限；同样，出队每用一次 `pop(0)` 就做一次全队列位移，$p$ 个点叠加成隐性 $O(p^2)$。现象分别是大用例 MLE 与 TLE。

## 扩展思考

- 有了 $dp[x]$，每波成员的范围也顺手拿到：$dp$ 值相同的点之间必无边（$v$ 至少比 $u$ 多 1），把 $dp$ 值当波次编号就是一个最优方案。
- 这道题的图论名字是「DAG 的深度」；加上每波容量等资源限制后，就成了带约束的调度问题，拓扑 DP 之外还要叠加容量维。
