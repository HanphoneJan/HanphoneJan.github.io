# P5454. 雷达等距计数

> 场次：2026年9月16日-非AI方向 · 来源：[CodeFun2000 P5454](https://codefun2000.com/p/P5454)

## 题目描述

整点网格铺成的平面上，散落着若干座雷达站，每座站都用一对整数记下它的位置。

把其中一座站设成探测原点之后，若它到另外两座彼此不同的站，欧氏间距恰好相等，就把这三座站记成一次等心探测。

现给出 $m$ 座两两位置不同的站 $loc$，第 $p$ 座写作 $loc[p]=[u_p,v_p]$。

所谓等心探测组，指有序三元 $(p,q,r)$：从 $p$ 到 $q$ 的欧氏间距等于从 $p$ 到 $r$ 的欧氏间距。间距按平面欧氏度量来算。请统计这样的有序三元一共出现多少次。

排列会计入次数：$(p,q,r)$ 一旦成立，把后两项对调得到的 $(p,r,q)$ 要再记一次。

## 输入格式

首行给出站点总数 $m$。

随后连续 $m$ 行，每一行是两个整数 $u_p$ 与 $v_p$，对应一座站的横纵坐标。

读入先后对应编号 $1,2,\dots,m$。

$3 \le m \le 2\times 10^3$

$-10^5 \le u_p,v_p \le 10^5$

各站点位置两两不重合

## 输出格式

输出一个整数，表示等心探测组的总次数。

## 示例

### 示例 1

**输入：**

```
4
0 0
0 3
3 0
3 3
```

**输出：**

```
8
```

**说明：**

四座站落在边长为 $3$ 的正方形顶点上。

- 以 $(0,0)$ 为原点：到 $(0,3)$、$(3,0)$ 的间距都是 $3$，到 $(3,3)$ 为 $3\sqrt{2}$，因此有序对有 $2$ 组
- 其余三座顶点情形相同
- 总次数 $4\times 2=8$

### 示例 2

**输入：**

```
3
0 0
4 0
2 3
```

**输出：**

```
2
```

**说明：**

三座站构成等腰三角形。

- 以 $(2,3)$ 为原点：到 $(0,0)$ 与到 $(4,0)$ 的间距都是 $\sqrt{13}$，得到 $(p,q,r)$ 与 $(p,r,q)$ 各一次
- 以 $(0,0)$ 或 $(4,0)$ 为原点时，到另外两座的间距不相等
- 总次数为 $2$

## 解题思路

### 判定标准：把三元组数清点成「桶里挑两个有序」

题面把「等心探测组」定义成有序三元 $(p,q,r)$：$p$ 作探测原点，$q$、$r$ 是两座互不相同的站，$p$ 到它们的欧氏距离恰好相等，且 $(p,q,r)$ 与 $(p,r,q)$ 各计一次。对固定原点 $p$，这个定义只依赖一件事：到 $p$ 距离相同的其余站有几个。设某段距离上聚集了 $c$ 座站，从中选有序对 $(q,r)$ 的方案数是 $c\cdot(c-1)$——先选 $q$ 有 $c$ 种，再选一个不同于 $q$ 的 $r$ 有 $c-1$ 种，两个方向的顺序由这「先后各选一次」天然计入。于是答案

$$\text{答案} = \sum_{p}\ \sum_{\text{距离桶 } d}\ c_{p,d}\cdot(c_{p,d}-1)$$

桶的大小 $c$ 代替了逐对枚举，三元组的个数由乘法一次给出。

### 数据范围把算法指到 $O(m^2)$

$m \le 2\times10^3$。最直觉的做法是三重循环枚举 $(p,q,r)$：约 $m^3=8\times10^9$ 组距离比较，任何语言都扛不住。往回退一步：外层只枚举原点（$m$ 种），内层把其余 $m-1$ 座站「按到原点的距离」归堆（$m^2\approx4\times10^6$ 次加法），每段距离的答案靠一次乘法收账。数据范围恰好在「逐三元枚举不可行、按原点分桶宽裕」的分界上，这就是这道题该走的路。

### 距离相等 ⇔ 平方距离相等

分桶的键不能用开方后的浮点值：$sqrt(13)$、$sqrt(2)$ 一类无理数距离经过舍入，相等的两条可能判成不等。而对非负数，$|PQ|=|PR|$ 当且仅当 $|PQ|^2=|PR|^2$——平方距离相等与距离相等完全等价，整点坐标下平方距离 $dx^2+dy^2$ 还是整数。坐标至多 $\pm10^5$，平方距离可达 $8\times10^{10}$，Python 的整数不受位宽影响。

### 实现落点

`solve()` 里：外层 `for i in range(m)` 枚举原点；`Counter(...)` 一行把其余站按平方距离归堆，`j != i` 把原点自身挡在候选外；`total += c * (c - 1)` 这两行就是排列数公式。站点两两不重合保证每站到原点的距离恒大于 0，桶里不会有零距离的特殊情形，$q$、$r$ 的互异性也由「第二次选择排除自己」自动保住。

## 完整代码实现

```python
"""
P5454. 雷达等距计数 - 枚举原点 + 平方距离分桶计数

m 座两两不同的整点雷达站，统计「等心探测组」：有序三元 (p,q,r)，
p 作探测原点，q、r 是两座互不相同的站，且 p 到 q 与 p 到 r 的
欧氏距离恰好相等。(p,q,r) 与 (p,r,q) 各计一次。

输入格式：
- 第 1 行：站点数 m（3 <= m <= 2e3）；
- 随后 m 行：每行两个整数 u_p、v_p（|坐标| <= 1e5），位置两两不重合。

输出格式：
- 一个整数：等心探测组的总次数。

核心思路：
1. 枚举每个原点 p，把其余 m-1 座站到 p 的距离分桶。比较用平方距离
   dx*dx + dy*dy：两条线段长度相等当且仅当平方距离相等，
   既避开开方的浮点误差，也省一次 sqrt。
2. 到 p 距离相同的站有 c 座时，从中选有序对 (q,r) 共 c*(c-1) 种
   ——是排列数不是组合数，(p,q,r) 与 (p,r,q) 都要计入。
3. 站点两两不同，任一站到原点的距离恒大于 0，桶键不会是 0，
   选出的 q、r 天然互不相同。所有原点的桶贡献累加即答案。

时间复杂度：O(m^2)（m=2000 时约 4e6 次平方距离计算）
空间复杂度：O(m)（每次只保留当前原点的桶）
"""

# https://codefun2000.com/p/P5454
import sys
from collections import Counter

# @sample-start
"""
样例输入 1:
4
0 0
0 3
3 0
3 3

样例输出 1:
8
"""
# @sample-end

# @sample-start
"""
样例输入 2:
3
0 0
4 0
2 3

样例输出 2:
2
"""
# @sample-end


def solve():
    """读入站点坐标，按原点分桶统计等腰三元组。"""
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    m = int(data[0])
    nums = list(map(int, data[1 : 2 * m + 1]))
    xs = nums[0::2]
    ys = nums[1::2]

    total = 0
    for i in range(m):
        xi = xs[i]
        yi = ys[i]
        # 其余 m-1 座站到原点 i 的平方距离，直接进 Counter 分桶
        bucket = Counter(
            (xs[j] - xi) ** 2 + (ys[j] - yi) ** 2 for j in range(m) if j != i
        )
        # 同一距离上 c 座站贡献 c 个「等距点选 q」乘 (c-1) 个「选 r」
        for c in bucket.values():
            total += c * (c - 1)
    print(total)


def run_tests():
    """运行官方样例与边界用例，方便本地自测。"""
    import io

    test_cases = [
        # 官方样例 1：正方形四顶点，每个原点 2 座等距站
        (
            "4\n0 0\n0 3\n3 0\n3 3\n",
            "8",
        ),
        # 官方样例 2：等腰三角形，只有顶点作原点时成立
        (
            "3\n0 0\n4 0\n2 3\n",
            "2",
        ),
        # 无任何等对：三点两两距离互不相等，应输出 0
        (
            "3\n0 0\n1 0\n0 3\n",
            "0",
        ),
        # 一个原点带 4 座等距站：桶贡献 4*3=12，另 4 个原点各 2*1=2
        (
            "5\n0 0\n2 0\n0 2\n-2 0\n0 -2\n",
            "20",
        ),
        # 三点共线且等间距：中点作原点时两侧距离相等
        (
            "3\n0 0\n1 0\n2 0\n",
            "2",
        ),
        # 大坐标（1e5）：平方距离达 1e10 量级，检验无精度/溢出问题
        (
            "3\n-100000 0\n100000 0\n0 0\n",
            "2",
        ),
        # 汇合型：两站到同一个中间站等距，与方向无关
        (
            "4\n0 0\n4 0\n2 2\n2 -2\n",
            "8",
        ),
    ]

    for i, (inp, expected) in enumerate(test_cases, 1):
        old_stdin, old_stdout = sys.stdin, sys.stdout
        sys.stdin = io.TextIOWrapper(io.BytesIO(inp.encode("utf-8")))
        sys.stdout = io.StringIO()
        try:
            solve()
            output = sys.stdout.getvalue().strip()
        finally:
            sys.stdin, sys.stdout = old_stdin, old_stdout

        status = "✓" if output == expected else "✗"
        print(f"样例 {i}: 期望={expected}, 实际={output} {status}")


if __name__ == "__main__":
    if len(sys.argv) > 1 and sys.argv[1] == "--test":
        run_tests()
    else:
        solve()
```

## 示例推演

### 样例 1：正方形四顶点

先看原点 $(0,0)$，对三座邻站算平方距离：

| 邻站 | $dx^2+dy^2$ | 归堆 |
| ---- | ---- | ---- |
| $(0,3)$ | $9$ | 桶 $d{=}9$ 计 1 |
| $(3,0)$ | $9$ | 桶 $d{=}9$ 计 2 |
| $(3,3)$ | $18$ | 桶 $d{=}18$ 计 1 |

桶 $d=9$ 里有 $c=2$ 座站，贡献 $2\times1=2$（$q$、$r$ 互换各一次）；$d=18$ 只有 1 座，贡献 0。其余三个顶点的邻居结构与 $(0,0)$ 完全对称，各贡献 2，总计 $4\times2=8$，与输出一致。

### 样例 2：等腰三角形的腰

三站 $(0,0),(4,0),(2,3)$ 只在原点 $(2,3)$ 处凑出一对：到 $(0,0)$ 与到 $(4,0)$ 的平方距离都是 $4+9=13$，桶 $\{13{:}\ 2\}$ 贡献 2；另外两个原点的平方距离集合是 $\{16,13\}$，全是单桶，贡献 0。合计 $2$。

更高聚拢的桶看自测第 4 组：原点 $(0,0)$ 带上、下、左、右四臂，四座邻站的平方距离都是 $4$，桶 $\{4{:}\ 4\}$ 贡献 $4\times3=12$——这里若误用组合数 $\binom{4}{2}=6$，答案立刻少一半。

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| ---- | ---------- | ---------- | ---- |
| 三重循环枚举有序对 $(p,q,r)$ | $O(m^3)$ | $O(1)$ | $m=2000$ 时约 $8\times10^9$ 次距离比较，不可行 |
| 原点枚举 + 平方距离分桶（最优） | $O(m^2)$ | $O(m)$ | 约 $4\times10^6$ 次平方距离计算 |

$m=2000$ 时外层循环 2000 次，每次对 1999 个邻站求平方距离并进同一个 `Counter`，Python 在数秒内完成。

## 易错点总结

### 1. 排列数当成组合数

同一距离桶里有 $c$ 座站时贡献是 $c\cdot(c-1)$（`total += c * (c - 1)` 那两行）。误写成 $\binom{c}{2}$ 等于把 $(p,q,r)$ 与 $(p,r,q)$ 折成一份，全部输出减半：样例 1 会给出 4，自测第 4 组会给出 6。题面「把后两项对调得到的 $(p,r,q)$ 要再记一次」就是这条公式的出处。

### 2. 开方之后再比较相等

把距离开方再判等（如 `math.sqrt(dx*dx + dy*dy)` 的返回值作桶键），无理数距离受舍入误差支配，样例 2 恰好就踩在 $\sqrt{13}$ 上。分桶键应直接用整数 `dx*dx + dy*dy`，判定等价且精确。

## 扩展思考

- 「同距离站数」数的是以原点 $p$ 为圆心的圆上落了几座站；本题只要个数，不关心站间的夹角。若还要输出具体的等腰三角形清单，桶内对 $(q,r)$ 配对展开即可，开销与答案数同阶。
- 分桶键的内容可以按题型替换：改成「平方距离相等且面积也相等」就用 $(d^2,\ \cdot)$ 复合键，分桶框架不变。
