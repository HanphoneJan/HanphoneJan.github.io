# P5469. 主机灰度分批

> 场次：2026年9月18日-非AI方向 · 来源：[CodeFun2000 P5469](https://codefun2000.com/p/P5469)

## 题目描述

云上要给一大批计算节点做版本滚动。为了把风险压住，升级会拆成若干波次，也就是常说的灰度放量。

越靠前的波次越希望把各类机型都点到，好尽早把隐患暴露出来。

### 任务描述

手里有 $p$ 台主机，每台带着 $d$ 个维度的标签（比如板型、系统发行版）。某一维上标签相同，就认定这两台在该维属于同一类。

请按下面的规则排出分波方案：越靠前的波次，标签种类要尽量铺得开。

### 核心规则

1. 波次容量：

   主机总数记为 $p$，波次总数记为 $b$。

   - 基准容量 $q=\lfloor p/b\rfloor$。
   - 余数 $r=p\bmod b$。
   - 前 $b-r$ 个波次容量都是 $q$，最后 $r$ 个波次容量都是 $q+1$。

2. 增量尽量大：

   填当前波次时，只能从未入选的主机里挑。看哪一台还能给本波次补进最多尚未出现的标签。

   - 增量：该机某个维度上的标签，若本波次已入选的机器里还没出现过，就记一分。
   - 先比增量，越大越先拿。
   - 增量打平则拿 $nid$ 更小的那台。

3. 执行顺序：

   从第 $1$ 波填到第 $b$ 波，每波填满为止。某台一旦进了某一波，后面的波次不再考虑它。

## 输入格式

1. 首行两个整数 $p$ 和 $d$，即主机台数与标签维度。$(1\le p\le 2\times 10^{2},\ 1\le d\le 2)$

2. 随后 $p$ 行：每台主机一行，格式为

   `nid tag_1 tag_2 ... tag_d`

3. 末行一个整数 $b$，即波次总数。$(1\le b\le 2\times 10^{1})$

## 输出格式

输出 $b$ 行。第 $i$ 行给出该波次里的 $nid$，同一行按数值升序，相邻编号用空格隔开。

## 示例

### 示例 1

**输入：**

```
4 1
10 A
11 A
12 A
13 A
2
```

**输出：**

```
10 11
12 13
```

**说明：**

- $4\div 2=2$ 余 $0$，两波容量都是 $2$。
- 标签全是 $A$，第一台进波次后其余增量都变成 $0$。
- 增量打平时按 $nid$ 从小到大，故第一波 $10\ 11$，其余进第二波。

### 示例 2

**输入：**

```
6 2
1 X P
2 X Q
3 Y P
4 Y Q
5 Z Q
6 Z R
2
```

**输出：**

```
1 4 6
2 3 5
```

**说明：**

- $6\div 2=3$ 余 $0$，两波容量都是 $3$。
- 第一波：空盘先拿 $nid=1$（增量 $2$）；已有 $\{X,P\}$ 后再拿 $nid=4$（增量 $2$）；已有 $\{X,Y,P,Q\}$ 后再拿 $nid=6$（增量 $2$）。
- 剩下 $2,3,5$ 进第二波。

## 提示

1. 多样性按各维标签种类相加；越靠前的波次越优先把种类铺开。
2. 容量：总数 $p$、波次 $b$，基准是 $\lfloor p/b\rfloor$，多出来的台数摊到最后若干波。

## 解题思路

### 判定标准的性质：这不是优化题

题面把挑机规则逐条写死——容量怎么分、增量怎么算、平手拿谁——每条都唯一确定下一步取哪台。所以正确做法是**逐条规则模拟**，把三条规则各翻译成一处代码；任何「自己设计一个更合理的分批策略」的念头都会直接答错。

### 三条规则各自落在哪

1. **容量分布**：$q=\lfloor p/b\rfloor$、$r=p\bmod b$，前 $b-r$ 波容量 $q$、最后 $r$ 波容量 $q{+}1$——余数只摊在末尾，前面的波次一台不多。代码里 `caps = [q] * (b - r) + [q + 1] * r` 一行。
2. **增量口径**：每波重开 `dim_seen`（各维一个已见标签集合）；一台主机的增量等于它各维标签中未在本波出现过的维数。口径是「本波次」，不是从全场第一次启用起累计——换波要清空。`gain = sum(...)` 与波循环体内的 `dim_seen = [set() ...]` 是这条规则的两处落点。
3. **平手裁决**：增量打平拿 nid 更小的那台。扫描遵循「更优才替换」：`gain > best_gain or (gain == best_gain and nid < best_nid)`，严格小于保证输入顺序不影响裁决。

输出每波成员、行内按 nid 升序：波内入选顺序是「增量优先」的，与 nid 升序没有必然关系，所以收尾要显式 `picked.sort()`。

### 数据范围确认模拟足够快

$p\le200$、$d\le2$、$b\le20$。每选一台扫全部未选主机、每台做 $d$ 次集合查询；整场约 $p^2\cdot d\approx8\times10^4$ 次查询，纯列表加集合足够，不需要堆或懒更新。

## 完整代码实现

```python
"""
P5469. 主机灰度分批 - 贪心规则模拟

p 台主机各带 d（<= 2）个维度的标签，要切成 b 波灰度。规则由题面写死，
本质是按规则模拟，不另寻最优划分：
1. 容量：q = p // b，r = p % b；前 b-r 波容量 q，最后 r 波容量 q+1。
2. 每波从空集开始，逐台从未入选主机里挑「增量」最大者：该机某一维的
   标签若在本波已入选机器中还没出现过记 1 分；增量打平拿 nid 更小者。
   增量相对的是「本波次」已见标签，换波即清空。
3. 某台进过一波后不再参与。输出每波成员，行内按 nid 数值升序。

输入格式：
- 第 1 行：p d（1<=p<=2e2，1<=d<=2）；
- 随后 p 行：nid tag_1 [tag_2]；
- 末行：b（1<=b<=2e1）。

输出格式：
- b 行：每波 nid 升序、空格分隔（容量为 0 的波输出空行）。

时间复杂度：O(p^2 * d)（每波每选一台扫全部未选主机）
空间复杂度：O(p * d)
"""

# https://codefun2000.com/p/P5469
import sys

# @sample-start
"""
样例输入 1:
4 1
10 A
11 A
12 A
13 A
2

样例输出 1:
10 11
12 13
"""
# @sample-end

# @sample-start
"""
样例输入 2:
6 2
1 X P
2 X Q
3 Y P
4 Y Q
5 Z Q
6 Z R
2

样例输出 2:
1 4 6
2 3 5
"""
# @sample-end


def solve():
    """按题面规则逐波模拟：容量前少后多，波内挑增量最大且 nid 最小者。"""
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    p = int(next(it))
    d = int(next(it))
    hosts = []  # (nid, tags 元组)
    for _ in range(p):
        nid = int(next(it))
        tags = tuple(next(it) for _ in range(d))
        hosts.append((nid, tags))
    b = int(next(it))
    used = [False] * p

    # 容量分布：基准 q，余数 r 摊到最后的 r 个波次，后面的波只大不小
    q, r = divmod(p, b)
    caps = [q] * (b - r) + [q + 1] * r

    out_lines = []
    for wave in range(b):
        dim_seen = [set() for _ in range(d)]  # 本波已出现过的各维标签
        picked = []
        for _ in range(caps[wave]):
            best = -1
            best_gain = -1
            best_nid = None
            for h in range(p):
                if used[h]:
                    continue
                nid, tags = hosts[h]
                gain = sum(1 for j in range(d) if tags[j] not in dim_seen[j])
                if gain > best_gain or (gain == best_gain and nid < best_nid):
                    best, best_gain, best_nid = h, gain, nid
            used[best] = True
            picked.append(hosts[best][0])
            for j in range(d):
                dim_seen[j].add(hosts[best][1][j])
        picked.sort()
        out_lines.append(" ".join(map(str, picked)))
    print("\n".join(out_lines))


def run_tests():
    """运行官方样例与边界用例，方便本地自测。"""
    import io

    test_cases = [
        # 官方样例 1：全同标签，增量全 0，按 nid 顺次进波
        (
            "4 1\n10 A\n11 A\n12 A\n13 A\n2\n",
            "10 11\n12 13",
        ),
        # 官方样例 2：两波各 3 台，第一波三连增量 2
        (
            "6 2\n1 X P\n2 X Q\n3 Y P\n4 Y Q\n5 Z Q\n6 Z R\n2\n",
            "1 4 6\n2 3 5",
        ),
        # b=1：所有主机进同一波，行内按 nid 升序
        (
            "3 1\n30 A\n10 B\n20 A\n1\n",
            "10 20 30",
        ),
        # 余数 r>0：p=5、b=2，前波容量 2、后波容量 3
        (
            "5 1\n1 A\n2 A\n3 A\n4 A\n5 A\n2\n",
            "1 2\n3 4 5",
        ),
        # 增量对照本波次而非全局：第二波里标签 A 应重新计分，
        # 于是 nid 2（A，增量 1）先于 nid 9（C，增量 1）按平手 nid 取 2
        (
            "4 1\n1 A\n2 A\n3 B\n9 C\n2\n",
            "1 3\n2 9",
        ),
        # nid 与输入顺序相反：平手时应拿 nid 更小的那台
        (
            "2 1\n20 A\n10 A\n2\n",
            "10\n20",
        ),
        # 两波之间标签集清空：第二波第一台增量恢复为满 d
        (
            "4 2\n1 X X\n2 Y Y\n3 X X\n4 Y Y\n2\n",
            "1 2\n3 4",
        ),
    ]

    for i, (inp, expected) in enumerate(test_cases, 1):
        old_stdin, old_stdout = sys.stdin, sys.stdout
        sys.stdin = io.TextIOWrapper(io.BytesIO(inp.encode("utf-8")))
        sys.stdout = io.StringIO()
        try:
            solve()
            output = sys.stdout.getvalue().strip()
        finally:
            sys.stdin, sys.stdout = old_stdin, old_stdout

        status = "✓" if output == expected else "✗"
        print(f"样例 {i}: 期望={expected!r}, 实际={output!r} {status}")


if __name__ == "__main__":
    if len(sys.argv) > 1 and sys.argv[1] == "--test":
        run_tests()
    else:
        solve()
```

## 示例推演

### 样例 2：平手如何一轮轮裁决

$6\div2=3$ 余 0，两波各 3 台。第一波从空集开始，所有主机两维都没见过，增量全是 2，平手拿最小 nid，先选 1，集合变为 $\{X\}$、$\{P\}$：

| 未选主机 | 已见 $\{X\}$、$\{P\}$ 下的增量 |
| ---- | ---- |
| 2 (X, Q) | 1 |
| 3 (Y, P) | 1 |
| 4 (Y, Q) | 2 |
| 5 (Z, Q) | 2 |
| 6 (Z, R) | 2 |

增量 2 打平的是 4、5、6，取最小 nid 4。集合变为 $\{X,Y\}$、$\{P,Q\}$：主机 2、3 增量归 0，5 剩 $Z$ 一分，6 的 $Z,R$ 两维全新、增量 2 直接入选。第一波 $1,4,6$。

第二波清空集合重算：$\{2,3,5\}$ 在空集下增量都是 2，平手按 nid 依次排出 $2,3,5$，行内升序输出。

顺带看波次口径出错的样子（自测第 5 组）：四台 $1(A),2(A),3(B),9(C)$，两波各 2 台。第一波增量全 1，平手取 1；剩下 $2(0),3(1),9(1)$ 打平取 3——第一波 $1,3$。第二波从空集重算，$2$ 与 $9$ 增量都是 1，平手取 2，输出 `1 3` / `2 9`。若把第一波的 $\{A,B\}$ 累计进第二波，主机 2 的增量被压成 0，会先拿 9，输出变成 `1 3` / `9 2`。

### 样例 1 的对照：全同标签

标签全是 A：第一台入选后其余增量全 0，整场只剩平手裁决，两波按 nid 顺次填出 `10 11` / `12 13`。这组是「完全平手」，专门钉住「平手拿小 nid」而不是任何标签驱动的选择。

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| ---- | ---------- | ---------- | ---- |
| 不维护已选标记，选机时扫全部 $p$ 台并重复处理已选 | $O(b\cdot p^2\cdot d)$ | $O(p)$ | 多一个 $b=20$ 的因子，同样能过但无谓 |
| 已选标记 + 每台现算增量（最优） | $O(p^2 \cdot d)$ | $O(p)$ | $p=200$、$d=2$ 时约 $8\times10^4$ 次集合查询 |

复杂度已把「每台现算增量」的 $d$ 次集合查询计入主量；改成按波缓存或堆维护都不改变量级，本题规模纯模拟已经足够。

## 易错点总结

### 1. 余数摊到了前几波

定义是「前 $b-r$ 个波次容量都是 $q$，最后 $r$ 个波次容量都是 $q+1$」。写成 `[q + 1] * r + [q] * (b - r)` 把余数摊到前面，行数不变但归属整体前移：$p=5$、$b=2$、全同标签时输出 `1 2 3` / `4 5`，正确是 `1 2` / `3 4 5`。

### 2. 增量口径接到了全局

`dim_seen` 必须在波循环体内重建（`solve()` 里它的位置在 `for wave in range(b)` 内部）。挪到循环外累计，第二波起步时上一波的标签全部占位，增量被普遍压低，选机结果随之改变——示例推演里 `1 3` / `2 9` 与 `1 3` / `9 2` 的差别就是这一条。

### 3. 平手裁决交给输入顺序

严格小于的比较（平手比 nid）不能换成先到先得：nid 与输入顺序没有必然关系。输入 `20 A`、`10 A` 两台（自测第 6 组），先到先得的第一波会拿 20，正确是 10。

## 扩展思考

- 这类「多样性优先」的分批在真实灰度调度里对应「早暴露组合」的目标：余数如何摊、增量口径取本波还是历史，都是从需求侧来的自由度，实现时对照规则逐条落位。
- 若把增量口径改成全局累计，题目就换了一副面孔；示例推演里那组自测数据两种口径都覆盖，改需求时可以直接复用它来校验。
