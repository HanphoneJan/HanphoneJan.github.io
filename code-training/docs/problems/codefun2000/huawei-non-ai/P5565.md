# P5565. 登岛最大功力

> 场次：2026年9月23日-非AI方向 · 来源：[CodeFun2000 P5565](https://codefun2000.com/p/P5565)

## 题目描述

功夫迷小明一心想闯出名声。他所处的世界里藏着一座秘岛：人留在岛上时要按时间扣掉功力，岛上冒出来的异事却能把功力补回来。

一辈子里，上岛和离岛最多各发生两次；只去一趟，或者始终不上岛，也都允许。若第一次进入、离开的时刻记成 $L_1$、$R_1$，第二次进入必须严格晚于第一次离开，也就是 $L_2 > R_1$，两段停留不能叠在一起。

假如时刻 $L$ 上岛、时刻 $R$ 离岛，这一段扣掉的功力是 $(R - L) \times c$，意思是每个时间单位扣 $c$ 点。

秘岛上共有 $p$ 起异事。第 $k$ 起能补上的功力是 $w_k$，它占着闭区间 $[a_k, b_k]$。只有整段都落在同一次停留里面，也就是 $L \le a_k$ 并且 $b_k \le R$，这起异事的功力才算拿到。

结算功力等于拿到的各起异事相加，再减掉停留期间扣掉的部分。各起异事的时段可以互相交叉，也可以完全叠在同一段时间上。

请替小明定下每次上岛和离岛的时刻，使结算功力达到最大。

## 输入格式

首行两个整数 $p$ 和 $c$。$p$ 表示异事的起数，$c$ 表示留在岛上时每个时间单位要扣的功力。

随后 $p$ 行，每行三个整数，依次是这起异事的开始时刻 $a_k$、结束时刻 $b_k$、功力 $w_k$。

## 数据范围

- $1 \le p \le 10^4$
- $0 \le w_k, c \le 10^9$
- $1 \le a_k, b_k \le 10^9$
- $a_k \le b_k$

## 输出格式

第一行输出一个整数，表示能达到的最大结算功力。

后面用一行或两行写出停留的进入时刻和离开时刻。若最优选择是不上岛，这里改写 NA。若好几组停留的结算功力一样大，要输出字典序最小的那一组，并且每一段单独算出来的净功力都必须大于 $0$。有两段时，按进入时刻从早到晚输出。

上岛、离岛的时刻只能从这些异事出现过的时刻里挑。

上岛和离岛允许落在同一个时刻。

## 示例

### 示例 1

**输入：**

```
2 10
1 2 3
5 6 4
```

**输出：**

```
0
NA
```

**说明：**

停留 $[1,2]$ 的结算是 $3 - (2-1)\times 10 = -7$，停留 $[5,6]$ 的结算是 $4 - (6-5)\times 10 = -6$，一次罩住全部的 $[1,6]$ 则是 $7 - (6-1)\times 10 = -43$。每一段都是负数，所以上岛不如不去，答案是 $0$，并写出 NA。

### 示例 2

**输入：**

```
3 3
1 4 20
2 3 5
8 9 12
```

**输出：**

```
25
1,4
8,9
```

**说明：**

停留 $[1,4]$ 能罩住前两起，结算为 $20+5-(4-1)\times 3 = 16$。

停留 $[8,9]$ 罩住第三起，结算为 $12-(9-8)\times 3 = 9$。

若改成只留 $[1,9]$，三起都能罩住，但结算只有 $37-(9-1)\times 3 = 13$，不如分成两段的 $16+9 = 25$。

### 示例 3

**输入：**

```
3 4
2 5 30
3 4 6
10 14 5
```

**输出：**

```
24
2,5
```

**说明：**

停留 $[2,5]$ 罩住前两起，结算为 $30+6-(5-2)\times 4 = 24$。

停留 $[10,14]$ 的结算是 $5-(14-10)\times 4 = -11$，一次从 $2$ 留到 $14$ 的结算是 $41-(14-2)\times 4 = -7$。这两段都不如只保留 $[2,5]$。

## 解题思路

### 输出要什么：先最大化总功力，再挑字典序最小的方案

一次停留 $[L,R]$ 的净功力，等于「完全落在区间里的异事功力之和」减去「停留时长的扣分」：

$$\text{net}(L,R)=\sum_{a_k \ge L,\ b_k \le R} w_k-c(R-L).$$

题目允许至多两段停留，两段不能重叠，且第二次进入必须严格晚于第一次离开（$L_2>R_1$）；也可以只停一段，或者干脆不上岛。第一行输出最大总功力，后面每行一段 `L,R`（两段按进入时刻从早到晚），不上岛则输出 `0` 和 `NA`。并列最大时要输出字典序最小的一组方案，并且每一段自己的净功力都必须大于 $0$。

最后这条「每段必须为正」不影响最大值的求法：一段净功力不超过 $0$ 的停留，删掉它总功力不会变小，所以最大值一定可以由「每段都为正」的方案（或空方案）达到。它约束的是最后输出的方案长什么样，因此在重建答案时才需要检查。

进出时刻还有一个重要的限制：只能取异事出现过的时刻，也就是所有 $a_k$、$b_k$ 这至多 $2p$ 个值。理由是固定一段停留罩住的异事集合后，把 $L$ 往右推到其中最小的 $a_k$、把 $R$ 往左推到最大的 $b_k$，不会漏掉任何异事，停留时长只会变短，净功力不会变差。所以只需在这 $2p$ 个离散时刻里选，$n \le 2 \times 10^4$。题目还允许 $L=R$，即零长度停留，用来接住 $a_k=b_k$ 的异事。

### 把一段停留拆成「与 $L$ 有关」和「与 $R$ 有关」两半

对固定的进入时刻 $L$，把上式里的 $cL$ 提出来：

$$\text{net}(L,R)=\Big(\sum_{a_k\ge L,\ b_k\le R} w_k-cR\Big)+cL.$$

括号里只和 $R$ 有关。于是把候选离岛时刻按大小排好，叶子 $j$ 先放上 $-c\cdot\text{times}[j]$；当某起异事 $[a_k,b_k]$ 满足 $a_k\ge L$ 时，它对所有 $R\ge b_k$ 的停留都有贡献，也就是给下标区间 $[\text{idx}[b_k],\ n)$ 整体加上 $w_k$。这样叶子 $j$ 的值就是「已激活异事中 $b\le\text{times}[j]$ 的功力和，再减去 $c\cdot\text{times}[j]$」，对后缀 $[i,n)$ 取最大值再加 $c\cdot\text{times}[i]$，就得到以 $\text{times}[i]$ 进入时的最好单段净功力 `single[i]`。

实现上让 $L$ 从右往左扫（下标 $i$ 递减）。$L$ 变小时会有更多异事满足 $a_k\ge L$，把它们依次激活；每起异事只会被激活一次。需要的操作是「区间加」和「区间最大值」，线段树正好支持，单次 $O(\log n)$。如果对每个 $L$ 都从头扫一遍 $R$，$p=10^4$ 时是 $4\times 10^8$ 量级，Python 会超时——这是选择线段树而不是二重循环的原因。

### 第二段：把「之后最好的一段」预先叠进叶子里

只停一段的答案已经由 `single` 给出。要接第二段，先算后缀最大：

$$\text{ssuf}[j]=\max_{k>j}\text{single}[k],$$

下标严格大于 $j$，对应「第二段必须在第一段离开之后才进入」这条限制。对第一段 $[L,R=\text{times}[j]]$ 来说，后面能接到的最好一段就是 $\max(0,\text{ssuf}[j])$（接不到更好的就不接）。于是把每个叶子再额外加上 $\text{ssuf}[j]$（记作 $\text{leaf}_2[j]$），用同样的后缀加和后缀最大值查询，得到

$$\text{first}[i]=c\cdot\text{times}[i]+\max_{j\ge i}\big(\text{leaf}_2[j]\big),$$

它表示「以 $\text{times}[i]$ 进入、把第二段也补满」时的最大总功力。两段的时间区间不重叠，第二段选哪一段不会改变第一段罩住哪些异事，所以这里可以直接用后缀最大，不需要再记别的状态。

最终答案

$$T=\max\Big(0,\ \max_i\max\big(\text{single}[i],\ \text{first}[i]\big)\Big),$$

外层的 $0$ 就是「不上岛」这个选项。

### 重建字典序最小方案：先定 $L$，再定 $R$，最后定第二段

有了 $T$，从最小的进入时刻开始找。对每个候选 $L$，用 `timeline(L)` 把「以 $L$ 进入、在各个候选 $R$ 离开」的净功力算出来：筛出 $a_k\ge L$ 的异事，按 $b_k$ 排序，随着 $R$ 增大把 $b_k\le R$ 的功力累加进前缀和即可。

- 第一段：$L$ 从小到大，$R$ 从小到大。要求 `net > 0`，并且 `net + max(0, ssuf[R]) == T`。这个等式就是「存在一种补法把总数凑到 $T$」：后面最多还能贡献 $\max(0,\text{ssuf}[R])$，若它比 $T-\text{net}$ 还大，总数就会超过最大值，不可能；所以取到等号的位置恰好可行。第一个满足的 $(L,R)$ 就是字典序最小的首段。
- 第二段：若 `max(0, ssuf[R])` 大于 $0$，说明还需要一段，且它的净功力必须正好等于这个后缀值。从 $R$ 之后最小的进入时刻开始，再按 $R$ 从小到大找第一个净功力等于该值的停留，就是字典序最小的第二段。

整个重建最多调用两次 `timeline`，每次 $O(p\log p)$ 的排序加 $O(n)$ 的扫描。

## 完整代码实现

```python
"""
P5565. 登岛最大功力 - 线段树（区间加 + 区间最大值）上的至少两段区间选择

在秘岛上每个单位时间扣 c 点功力；每起异事发力于闭区间 [a_k, b_k]、功力
w_k，只有整段 [a_k, b_k] 完全落进某次停留 [L, R]（L <= a_k 且 b_k <= R）
才算拿到。停留进出时刻只能取自异事出现过的时刻，至多两段且第二段进入
时刻严格晚于第一段离开（L_2 > R_1），每一段单独的净功力（异事功力和减
c*(R-L)）都必须大于 0。求总功力最大的进出方案；无正收益方案输出 0 / NA；
并列最优取停留列表字典序最小的一组。

输入格式：
- 第一行 p、c（1 <= p <= 1e4，0 <= w_k, c <= 1e9）；
- 随后 p 行，每行 a_k、b_k、w_k（a_k <= b_k）。

输出格式：
- 第一行最大结算功力；
- 后面一行或两行"进入,离开"（两段时按进入时刻从早到晚）；无上岛方案写 NA。

核心思路：
1. 候选起止时刻只有异事件出现过的 ~2p 个离散值，把停留 [L, R] 的净功力
   改写成   net(L,R) = prefW(b <= R 且 a >= L) - c*R + c*L，
   对固定的"进入下标 i"而言，prefW 通过"按 b 落位"的后缀加法进一张
   线段树（叶子 j 存 prefW_{b<=times[j]} - c*times[j]），所以「单段」
   与「接一段」两种查询都落在同一棵树上。
2. 自晚时间往早扫一遍可同时得到：
   single[i] = c*times[i] + max_{R >= times[i]} net  （以 times[i] 进入的最好单段）
   再从 single 的后缀最大值得 ssuf[j] = max_{L > times[j]} single  （在 R 之后
   能接到的最好一段）。第二遍扫描把 ssuf 预置进叶子里，得到
   first[i] = max_{R >= times[i]} (net + ssuf[R])  （以 times[i] 进入、
   补满第二段的总功力）。最优总功力 T = max(0, max_i max(single[i], first[i]))。
3. 输出重建按字典序贪心：从小到大枚举进入时刻 L、再枚举离开时刻 R，
   满足（net > 0 且 net + max(0, ssuf[R]) == T），即存在总功力恰为 T 的
   正收益解；找到后若还有第二段，再在 R 之后贪最小进入、最早离岛时刻。

时间复杂度：两遍扫描 O((p + |S|) log |S|)，重建每段的净功力时间线 O(p log p)
空间复杂度：O(|S| + p)
"""

# https://codefun2000.com/p/P5565
import sys

NEG = -(1 << 60)


class SegMax:
    """区间加、区间最大值的迭代式线段树（push 沿边界路径的标准模板）。"""

    def __init__(self, base):
        n = len(base)
        sz = 1
        while sz < n:
            sz <<= 1
        self.sz = sz
        self.h = sz.bit_length() - 1
        self.t = [NEG] * (2 * sz)
        self.d = [0] * sz
        self.t[sz : sz + n] = base
        for x in range(sz - 1, 0, -1):
            self.t[x] = max(self.t[2 * x], self.t[2 * x + 1])

    def _apply(self, x, v):
        self.t[x] += v
        if x < self.sz:
            self.d[x] += v

    def _push(self, leaf):
        i = leaf
        for s in range(self.h, 0, -1):
            j = i >> s
            dv = self.d[j]
            if dv:
                self._apply(j << 1, dv)
                self._apply((j << 1) | 1, dv)
                self.d[j] = 0

    def _pull(self, leaf):
        x = leaf >> 1
        while x:
            self.t[x] = max(self.t[2 * x], self.t[2 * x + 1]) + self.d[x]
            x >>= 1

    def update(self, l, r, v):
        """给 [l, r) 加 v。"""
        if l >= r:
            return
        l += self.sz
        r += self.sz
        self._push(l)
        self._push(r - 1)
        l0, r0 = l, r
        while l < r:
            if l & 1:
                self._apply(l, v)
                l += 1
            if r & 1:
                r -= 1
                self._apply(r, v)
            l >>= 1
            r >>= 1
        self._pull(l0)
        self._pull(r0 - 1)

    def query(self, l, r):
        """返回 [l, r) 的最大值。"""
        if l >= r:
            return NEG
        l += self.sz
        r += self.sz
        self._push(l)
        self._push(r - 1)
        res = NEG
        while l < r:
            if l & 1:
                if self.t[l] > res:
                    res = self.t[l]
                l += 1
            if r & 1:
                r -= 1
                if self.t[r] > res:
                    res = self.t[r]
            l >>= 1
            r >>= 1
        return res

def solve():
    data = sys.stdin.buffer.read().split()
    it = iter(data)
    p = int(next(it))
    c = int(next(it))
    events = []
    for _ in range(p):
        a = int(next(it))
        b = int(next(it))
        w = int(next(it))
        events.append((a, b, w))

    # 候选进出时刻 = 全部异事出现过的时刻（离散化）
    times = sorted({t for e in events for t in (e[0], e[1])})
    n = len(times)
    idx = {t: i for i, t in enumerate(times)}
    by_a_desc = sorted(events, key=lambda e: -e[0])

    # 第一遍扫描：single[i] = 以 times[i] 进入的最好单段净功力
    # 叶子 j 存 net(L=fixed, R=times[j]) 中随 L 变化的公共部分：
    #   prefW_{激活异事, b<=times[j]} - c*times[j]
    single = [0] * n
    tree1 = SegMax([-c * t for t in times])
    ptr = 0
    for i in range(n - 1, -1, -1):
        while ptr < p and by_a_desc[ptr][0] >= times[i]:
            _, b, w = by_a_desc[ptr]
            tree1.update(idx[b], n, w)
            ptr += 1
        single[i] = c * times[i] + tree1.query(i, n)

    # ssuf[i] = 在 times[i] 之后（严格晚）进入的最好单段净功力
    ssuf = [NEG] * n
    run = NEG
    for i in range(n - 1, -1, -1):
        ssuf[i] = run
        if single[i] > run:
            run = single[i]

    # 第二遍扫描：多段情形。叶子额外带上 ssuf[j]：
    # 第一段 [times[i], R] 的净功力 + 之后最好一段的净功力
    tree2 = SegMax([-c * t + ssuf[j] for j, t in enumerate(times)])
    ptr = 0
    first = [NEG] * n
    for i in range(n - 1, -1, -1):
        while ptr < p and by_a_desc[ptr][0] >= times[i]:
            _, b, w = by_a_desc[ptr]
            tree2.update(idx[b], n, w)
            ptr += 1
        first[i] = c * times[i] + tree2.query(i, n)

    best_first = [
        (single[i] if single[i] > first[i] else first[i]) for i in range(n)
    ]
    T = max(0, max(best_first))

    if T <= 0:
        print(0)
        print("NA")
        return

    # 输出重建：字典序贪心。第一段最小的进入时刻，再最小离开时刻。
    def timeline(L0):
        """给定进入时刻 L0，沿候选离岛时刻算出净功力时间线（事件按 b 前缀和）。"""
        evs = sorted((e for e in events if e[0] >= L0), key=lambda e: e[1])
        out = []
        k2 = 0
        pref = 0
        for t in times:
            if t < L0:
                out.append(None)
                continue
            while k2 < len(evs) and evs[k2][1] <= t:
                pref += evs[k2][2]
                k2 += 1
            out.append(pref - c * (t - L0))
        return out

    start_i = None
    for i in range(n):
        if best_first[i] != T:
            continue
        lines = timeline(times[i])
        for j in range(i, n):
            net = lines[j]
            if net is None or net <= 0:
                continue  # 每一段独立净功力都必须为正
            cont = ssuf[j] if ssuf[j] > 0 else 0
            if net + cont == T:
                start_i = (i, j, net)
                break
        if start_i:
            break
    i1, j1, net1 = start_i
    L1, R1 = times[i1], times[j1]

    print(T)
    out = [f"{L1},{R1}"]

    cont = ssuf[j1] if ssuf[j1] > 0 else 0
    if cont > 0:
        # 第二段：贪最小进入时刻（须严格晚于第一段的离开），最早离岛时刻
        target = cont
        second = None
        for i2 in range(j1 + 1, n):
            if single[i2] < target:
                continue  # 从这里进入的最好一段都压不到 target，出不了精确命中
            lines2 = timeline(times[i2])[i2:]
            for off, net in enumerate(lines2):
                if net is None:
                    continue
                if net == target:
                    second = (i2, i2 + off)
                    break
                if net > target:
                    # 净功力还可能随离岛时刻回落（-c），继续等精确命中
                    continue
            if second:
                break
        i2, j2 = second
        out.append(f"{times[i2]},{times[j2]}")

    print("\n".join(out))


def _run(inp):
    import io

    old_in, old_out = sys.stdin, sys.stdout
    sys.stdin = io.TextIOWrapper(io.BytesIO(inp.encode("utf-8")))
    sys.stdout = io.StringIO()
    try:
        solve()
        return sys.stdout.getvalue().strip()
    finally:
        sys.stdin, sys.stdout = old_in, old_out


def _brute(events, c):
    """小规模暴力：枚举全部候选停留与两段组合，连带字典序最小方案。"""
    times = sorted({t for e in events for t in (e[0], e[1])})

    def net(L, R):
        s = sum(w for (a, b, w) in events if L <= a and b <= R)
        return s - c * (R - L)

    stays = [
        (L, R, net(L, R))
        for L in times
        for R in times
        if L <= R and net(L, R) > 0
    ]
    sols = [([], 0)]
    for L, R, nw in stays:
        sols.append(([(L, R)], nw))
    for x, (L1, R1, n1) in enumerate(stays):
        for L2, R2, n2 in stays[x + 1 :]:
            if L2 > R1:
                sols.append(([(L1, R1), (L2, R2)], n1 + n2))

    best = max((sol[1] for sol in sols), default=0)
    if best <= 0:
        return "0\nNA"
    winners = sorted(sol[0] for sol in sols if sol[1] == best)
    lines = [str(best)] + [f"{L},{R}" for L, R in winners[0]]
    return "\n".join(lines)


def run_tests():
    """官方样例 + 边界用例 + 随机对拍（暴力含字典序最小方案）。"""
```

## 示例推演

用示例 2：$p=3,\ c=3$，异事为 $[1,4]$ 功力 $20$、$[2,3]$ 功力 $5$、$[8,9]$ 功力 $12$。候选时刻是

$$\text{times}=[1,2,3,4,8,9].$$

先固定 $L=1$，逐个试 $R$（只统计 $a_k\ge 1$ 且 $b_k\le R$ 的异事）：

| $R$ | 1 | 2 | 3 | 4 | 8 | 9 |
| --- | --- | --- | --- | --- | --- | --- |
| 罩住的功力 | 0 | 0 | 5 | 25 | 25 | 37 |
| 扣分 $3(R-1)$ | 0 | 3 | 6 | 9 | 21 | 24 |
| 净功力 | 0 | $-3$ | $-1$ | 16 | 4 | 13 |

所以 `single[L=1] = 16`（在 $R=4$ 取到）。对每个 $L$ 都算一遍，得到：

| $L$ | 1 | 2 | 3 | 4 | 8 | 9 |
| --- | --- | --- | --- | --- | --- | --- |
| `single` | 16 | 2 | 0 | 0 | 9 | 0 |

后缀最大值（严格向后看）为：

| $R$ | 1 | 2 | 3 | 4 | 8 | 9 |
| --- | --- | --- | --- | --- | --- | --- |
| `ssuf` | 9 | 9 | 9 | 9 | 0 | `NEG` |

再看 $L=1$ 接第二段的情形，把每个 $R$ 的净功力加上 `ssuf[R]`：

| $R$ | 1 | 2 | 3 | 4 | 8 | 9 |
| --- | --- | --- | --- | --- | --- | --- |
| 净功力 + `ssuf` | $0+9=9$ | $-3+9=6$ | $-1+9=8$ | $16+9=25$ | $4+0=4$ | 不取（`ssuf` 是 `NEG`） |

最大值 $25$ 出现在 $R=4$：第一段 $[1,4]$ 净 $16$，第二段接在它后面最好的单段是 $[8,9]$，净 $12-(9-8)\times 3=9$，合计 $25$。重建时 $L=1$ 下第一个满足 `net > 0` 且 `net + ssuf[R] == 25` 的 $R$ 正是 $4$，于是首段定为 `1,4`；第二段的目标值是 $9$，在 $R=4$ 之后从 $L=8$ 开始，$R=9$ 时净功力正好 $9$，输出 `8,9`。

对比示例 3：第二段只剩负收益，`ssuf` 在 $R=5$ 之后是 $0$，等式 `net + 0 == 24` 在首段 $[2,5]$ 处成立，所以只输出一段 `2,5`。

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| ---- | ---------- | ---------- | ---- |
| 枚举全部停留，再两两组合 | $O(p^4)$ | $O(p^2)$ | 候选时刻至多 $2p$，停留有 $O(p^2)$ 个，两段组合 $O(p^4)$，$p=10^4$ 时不可行 |
| 固定 $L$ 扫一遍 $R$ 增量累加，再配后缀最大 | $O(p^2)$ | $O(p)$ | 每个 $L$ 扫 $O(p)$ 个 $R$，$p=10^4$ 时约 $4\times 10^8$ 次运算，Python 仍会超时 |
| 两遍扫描 + 区间加/区间最大线段树（最优） | $O(p\log p)$ | $O(p)$ | 每起异事只激活一次，每次区间加、后缀查询各 $O(\log p)$；重建再做两次时间线 |

## 易错点总结

### 1. 区间加的方向写反

`tree1.update(idx[b], n, w)`（`tree2` 同理）加的是「所有离岛时刻不小于 $b$ 的叶子」，因为异事 $[a,b]$ 只有在 $R\ge b$ 时才被完整罩住。若写成 `update(0, idx[b] + 1, w)`，叶子 $j$ 会把 $b>\text{times}[j]$ 的异事也算进来，短停留凭空拿到后面事件的功力。样例 2 上 $T$ 会被算大，重建时再也找不到满足 `net + cont == T` 的首段，程序在 `i1, j1, net1 = start_i` 处抛 `TypeError: cannot unpack non-iterable NoneType object`。

### 2. `ssuf` 用了非严格后缀

`ssuf[i] = run` 必须写在 `run = max(run, single[i])` 之前，这样 `ssuf[i]` 只包含「从更晚时刻进入」的停留。若两行调换，`ssuf[i]` 会包含从 `times[i]` 进入的同一段，第二段就能从第一段的离开时刻原地开始，同一段功力被算两遍。样例 4（`2 1000000000` / `7 7 5` / `8 9 1`）正确输出 `5` 和 `7,7`；调换后先输出 $10$，再在 `i2, j2 = second` 处抛同样的 `TypeError`。

### 3. 后缀查询把左端点写成 `i + 1`

`tree1.query(i, n)` 和 `tree2.query(i, n)` 的左端是 `i`，因为题面允许 `L == R`，离岛时刻可以正好等于进入时刻。若写成 `query(i + 1, n)`（认为「离开必须晚于进入」），就丢掉了 `L == R` 这个零扣分的选项：单点异事 $[t,t]$ 只能靠更长的停留去罩，多付的扣分可能把它由正变负。样例 4 里的异事 $[7,7]$ 正是如此，正确输出 `5` 和 `7,7`，写成 `i + 1` 后没有任何正的停留，输出退化成 `0` 和 `NA`。

## 扩展思考

把「至多两段」放宽到至多 $k$ 段，可以把 `ssuf` 这一层重复 $k$ 次：每一层都用上一层的后缀最大做叶子附加值，时间多乘 $k$，重建时按「每一段各贪一次」的顺序继续找下去即可。这与「最大子段和 + 线段树维护区间加/最大值」是同一套骨架，只是把一段换成了可拼接的多段。
