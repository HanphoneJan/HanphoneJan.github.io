# P5456. 聚餐汇合最短

> 场次：2026年9月16日-非AI方向 · 来源：[CodeFun2000 P5456](https://codefun2000.com/p/P5456)

## 题目描述

小红约了 $q$ 名同伴，打算在城里某一家馆子碰头。

路网里既有只准单向走的路段（行人车辆都受此限），也有可以来回走的路段。小红驾车按每公里 $2$ 分钟行进，同伴步行按每公里 $10$ 分钟行进。

已知小红出发路口、馆子所在路口，以及每名同伴所在路口。小红可以：
1. 径直把车开到馆子
2. 先绕去接上若干同伴，再一同抵达
3. 没接到的同伴则自己走过去

每名同伴只能二选一：坐小红的车，或全程步行，中途不许改主意。

请算出一种安排，让所有人抵达馆子的时刻尽可能早（以最晚到达的那人为准）。

## 输入格式

首行给出四个整数 $p, e, a, b$
- $p$: 全城路口一共有多少个（$1 \le p \le 10^{3}$）
- $e$: 路段一共有多少条（$1 \le e \le 10^{3}$）
- $a$: 小红开车起步的路口（$1 \le a \le p$）
- $b$: 馆子对应的路口（$1 \le b \le p$）

随后 $e$ 行，每行四个整数 $x, y, c, z$：路口 $x$、$y$ 之间铺着一条 $c$（$1 \le c \le 10^{2}$）公里长的路；$z=0$ 表示只能从 $x$ 开向 $y$，$z=1$ 表示两端都能走。

再下一行一个整数 $q$（$0 \le q \le 15$），即同伴人数。

再下一行 $q$ 个整数，即各同伴所在路口。

## 输出格式

输出一个整数：所有人抵达馆子的最短时间（分钟）。

## 示例

### 示例 1

**输入：**

```
4 4 1 4
1 2 3 1
2 4 4 1
1 3 5 1
3 4 2 1
2
2 3
```

**输出：**

```
20
```

**说明：**

四个路口、四条双向路。小红在 $1$，馆子在 $4$，两名同伴在 $2$、$3$。

- 只接路口 $2$：车程 $1 \to 2 \to 4$，共 $7$ 公里、$14$ 分钟；路口 $3$ 的同伴步行 $3 \to 4$，共 $2$ 公里、$20$ 分钟。汇合时刻 $20$
- 两人都接上：车程更长，汇合时刻大于 $20$
- 因此最短为 $20$

### 示例 2

**输入：**

```
3 3 1 3
1 2 10 1
2 3 10 1
1 3 2 1
1
2
```

**输出：**

```
40
```

**说明：**

小红在 $1$，馆子在 $3$，一名同伴在 $2$。

- 直接去馆子再让同伴步行：$2 \to 3$ 为 $10$ 公里、$100$ 分钟
- 绕去路口 $2$ 再开到 $3$：车程 $20$ 公里、$40$ 分钟
- 因此最短为 $40$

## 提示

1. 车子能装多少人不设上限
2. 同一条路、同一个点都可以走多次
3. 数据保证每个人都能抵达馆子

## 解题思路

### 判定标准：先写死每个人的到达方式

汇合时刻由最晚到的人定义，而每个人只有两种命运，到达时刻的构成随之固定：上车的同伴跟着车走，到馆子的时刻就是车到 $b$ 的时刻；没上车的同伴全程步行，时刻是 $10\times\text{km}(f\to b)$，只与他位置到馆子的最短公里数有关。于是方案由两件事决定：接人集合 $S$ 与车串起 $S$ 中同伴的顺序，目标写成

$$\operatorname{ans}(S)=\max\bigl(2\times\text{车程公里}(S),\ \max_{f\notin S} 10\times\text{km}(f\to b)\bigr),\qquad \text{答案}=\min_S \operatorname{ans}(S)$$

步行侧与「接谁、什么顺序」无关，是常量；要算的只有每个接人集合的车程。

### 路网侧：只对关键点做最短路

车与步行走同一张有向图（$z=0$ 的路谁都不能逆行），计时只是公里数的倍率。真正影响答案的只有 $a$、$b$ 与 $q$ 名同伴所在路口这 $q+2\le17$ 个关键点之间的最短公里数——中途怎么绕都折叠在「相邻关键点之间的最短路」里。对每个关键点各跑一次 Dijkstra（按公里计），得到两两最短公里表；$p,e\le10^3$，开销无足轻重。

### 顺序侧：$15!$ 压成 $2^q\times q^2$

接人顺序直接枚举排列是 $q!$，$q=15$ 时约 $1.3\times10^{12}$，不可行。但「已接到哪些同伴 + 车此刻停在谁那里」只有 $2^q\times q$ 种状态，这是旅行商问题的状压形态：

$$dp[\text{mask}][i] = \text{从 } a \text{ 出发、已接到 mask 中的同伴、车停在 } i \text{ 处的最短公里数}$$

转移是 $dp[\text{mask}\mid 2^j][j] = \min\bigl(dp[\text{mask}][i] + \text{km}(i\to j)\bigr)$；评估集合 $\text{mask}$ 的车程公里时再补末段 $\text{km}(i\to b)$。$2^{15}$ 状态、每次 $O(q^2)$ 转移，Python 秒级完成。

### 实现落点

- 建图按 $z$ 分流：$z=0$ 只挂 `adj[x]`，$z=1$ 才对称挂 `adj[y]`——车与步行共用这同一张图。
- Dijkstra 的权重是**公里**；2 与 10 两个倍率在最后合成时刻时才乘上，最短路本身按交通方式共用。
- 步行基线用 `wmax` 数组维护：$wmax[s]$ 是把集合 $s$ 里的同伴全部留下步行时的最晚到达，用「去掉最低位」的递推一行完成，评估时取补集 $wmax[full\oplus mask]$。
- 同伴可以同位（自测第 7 组），$a$、$b$ 也可能与同伴重合；去重的只是 Dijkstra 的源点表，同伴名单保持独立，好让位压一位一人。

## 完整代码实现

```python
"""
P5456. 聚餐汇合最短 - Dijkstra + 状压枚举接人集合

路网里有单向路（z=0，只准 x 驶向 y）与双向路（z=1），行人和车辆
都受同样的方向限制。小红驾车按每公里 2 分钟行进，同伴步行按每公里
10 分钟。小红从 a 出发去馆子 b，可以顺路接若干同伴（每人只能在
自己所在路口上车），没接到的同伴按步行全程走过去；每人上车或步行
二选一，中途不改。求「最晚到达的人」最早是多少分钟。
车子不限载量，路与点都可以重复走。

输入格式：
- 第 1 行：p e a b（路口数 <= 1e3，路段数 <= 1e3，起点、馆子）；
- 随后 e 行：x y c z，一条 c 公里的路（c <= 1e2），z=0 单向、z=1 双向；
- 再一行：q（同伴数 0 <= q <= 15）；
- 再一行：q 个整数，各同伴所在路口。

输出格式：
- 一个整数：最晚到达时刻的最小值（分钟）。

核心思路：
1. 只有起终关键点之间的最短距离会影响答案。对 a、b 与 q 名同伴所在
   的路口（去重后 <= 17 个）各做一次 Dijkstra（按公里计），得到
   关键点两两之间的最短公里数。车与步行同走一张图，只是计时系数不同：
   车程 = 2 * 公里数，步行 = 10 * 公里数。
2. 接谁、按什么顺序接：q <= 15，用状压 DP 枚举而非排列。
   dp[mask][i] = 从 a 出发、已接到 mask 中全部同伴、此刻停在同伴 i
   处的最短公里数（i ∈ mask）。转移
   dp[mask | 1<<j][j] = min(dp[mask][i] + km(i -> j))。
3. 对每个接人集合 mask 评估方案：车程公里 = mask 为空时 km(a -> b)，
   否则 min over i∈mask 的 dp[mask][i] + km(i -> b)；到达时刻 =
   max(2 * 车程公里, 未接到同伴步行时间的最大值)。答案取全程最小。

时间复杂度：O(K * (p + e) log p + 2^q * q^2)，K = 关键点数 <= q + 2
空间复杂度：O(2^q * q + (p + e))
"""

# https://codefun2000.com/p/P5456
import heapq
import sys

# @sample-start
"""
样例输入 1:
4 4 1 4
1 2 3 1
2 4 4 1
1 3 5 1
3 4 2 1
2
2 3

样例输出 1:
20
"""
# @sample-end

# @sample-start
"""
样例输入 2:
3 3 1 3
1 2 10 1
2 3 10 1
1 3 2 1
1
2

样例输出 2:
40
"""
# @sample-end

INF = float("inf")


def dijkstra(adj, src, n):
    """单源最短路（按公里），返回 dist 数组，下标 1..n。"""
    dist = [INF] * (n + 1)
    dist[src] = 0
    pq = [(0, src)]
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist[u]:
            continue
        for v, c in adj[u]:
            nd = d + c
            if nd < dist[v]:
                dist[v] = nd
                heapq.heappush(pq, (nd, v))
    return dist


def solve():
    """读入路网与同伴位置，枚举接人集合求最早汇合时刻。"""
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    p = int(next(it))
    e = int(next(it))
    a = int(next(it))
    b = int(next(it))

    adj = [[] for _ in range(p + 1)]
    for _ in range(e):
        x = int(next(it))
        y = int(next(it))
        c = int(next(it))
        z = int(next(it))
        adj[x].append((y, c))
        if z == 1:
            adj[y].append((x, c))

    q = int(next(it))
    friends = [int(next(it)) for _ in range(q)]

    # 关键点：起点、馆子、各同伴所在路口（去重后逐个跑 Dijkstra）
    key_nodes = sorted(set([a, b] + friends))
    dist = {node: dijkstra(adj, node, p) for node in key_nodes}

    km_a_b = dist[a][b]
    km_a_friend = [dist[a][f] for f in friends]
    km_friend_friend = [[dist[friends[i]][friends[j]] for j in range(q)] for i in range(q)]
    km_friend_b = [dist[f][b] for f in friends]

    # 步行是每名「未接到」同伴的固定代价；wmax[S] = S 集合里步行时间最大值
    walk = [10 * km_friend_b[j] for j in range(q)]
    wmax = [0] * (1 << q)
    for s in range(1, 1 << q):
        low = s & -s
        j = low.bit_length() - 1
        wmax[s] = max(wmax[s ^ low], walk[j])

    # dp[mask][i]：已接到 mask 里的同伴、车停在同伴 i 处的最短公里数
    dp = [[INF] * q for _ in range(1 << q)]
    for i in range(q):
        dp[1 << i][i] = km_a_friend[i]
    for mask in range(1, 1 << q):
        row = dp[mask]
        for i in range(q):
            if row[i] == INF or not (mask >> i & 1):
                continue
            base = row[i]
            for j in range(q):
                if mask >> j & 1:
                    continue
                cand = base + km_friend_friend[i][j]
                nm = mask | (1 << j)
                if cand < dp[nm][j]:
                    dp[nm][j] = cand

    ans = INF
    for mask in range(1 << q):
        if mask == 0:
            car_km = km_a_b
        else:
            car_km = min(
                dp[mask][i] + km_friend_b[i]
                for i in range(q)
                if mask >> i & 1
            )
        arrive = max(2 * car_km, wmax[(1 << q) - 1 ^ mask])
        if arrive < ans:
            ans = arrive
    print(ans)


def run_tests():
    """运行官方样例与边界用例，方便本地自测。"""
    import io

    test_cases = [
        # 官方样例 1：只接路口 2，同伴 3 步行 20 分钟
        (
            "4 4 1 4\n1 2 3 1\n2 4 4 1\n1 3 5 1\n3 4 2 1\n2\n2 3\n",
            "20",
        ),
        # 官方样例 2：绕路接人（40 分钟）优于让同伴步行（100 分钟）
        (
            "3 3 1 3\n1 2 10 1\n2 3 10 1\n1 3 2 1\n1\n2\n",
            "40",
        ),
        # q=0：直接看车程
        (
            "2 1 1 2\n1 2 5 1\n0\n",
            "10",
        ),
        # 同伴已在馆子：步行时间 0，只看车程
        (
            "2 1 1 2\n1 2 5 1\n1\n2\n",
            "10",
        ),
        # 单向路 z=0：车开不进同伴路口，只能让他步行 2->1->3（120 分钟）
        (
            "3 2 1 3\n2 1 10 0\n1 3 2 1\n1\n2\n",
            "120",
        ),
        # 接人顺序：先接远的（20 分钟就近端顺序 24 分钟）
        (
            "4 3 1 4\n1 2 1 1\n2 3 1 1\n3 4 8 1\n2\n2 3\n",
            "20",
        ),
        # 两人同在路口 2：接一次等于接两人
        (
            "3 2 1 3\n1 2 2 1\n2 3 6 1\n2\n2 2\n",
            "16",
        ),
        # 同伴起点即小红出发路口：上车 0 公里，只看车程
        (
            "2 1 1 2\n1 2 9 1\n1\n1\n",
            "18",
        ),
        # 绕路接人代价高于步行：单向路 1->3 要 6 公里，
        # 接人车程 14 分钟，不如让同伴沿 3->2 步行 10 分钟
        (
            "3 3 1 2\n1 2 2 1\n1 3 6 0\n3 2 1 0\n1\n3\n",
            "10",
        ),
    ]

    for i, (inp, expected) in enumerate(test_cases, 1):
        old_stdin, old_stdout = sys.stdin, sys.stdout
        sys.stdin = io.TextIOWrapper(io.BytesIO(inp.encode("utf-8")))
        sys.stdout = io.StringIO()
        try:
            solve()
            output = sys.stdout.getvalue().strip()
        finally:
            sys.stdin, sys.stdout = old_stdin, old_stdout

        status = "✓" if output == expected else "✗"
        print(f"样例 {i}: 期望={expected}, 实际={output} {status}")


if __name__ == "__main__":
    if len(sys.argv) > 1 and sys.argv[1] == "--test":
        run_tests()
    else:
        solve()
```

## 示例推演

### 样例 1：接一个、放走一个

四条路全双向。关键点两两最短公里：$\text{km}(1,2)=3$、$\text{km}(1,3)=5$、$\text{km}(1,4)=\min(3{+}4,\ 5{+}2)=7$、$\text{km}(2,3)=\min(3{+}5,\ 4{+}2)=6$、$\text{km}(2,4)=4$、$\text{km}(3,4)=2$。

| 接人集合 | 车程（分钟） | 未接同伴的步行 | 汇合时刻 |
| ---- | ---- | ---- | ---- |
| $\varnothing$ | $2\times7=14$ | $\max(40,20)=40$ | 40 |
| $\{2\}$ | $2\times(3+4)=14$ | 同伴 3 步行 $2\times10=20$ | 20 |
| $\{3\}$ | $2\times(5+2)=14$ | 同伴 2 步行 $4\times10=40$ | 40 |
| $\{2,3\}$ | 走 $1{\to}2{\to}3{\to}4$：$3+6+2=11$ 公里 → 22；走 $1{\to}3{\to}2{\to}4$：$5+6+4=15$ 里 → 30 | — | 22 |

最小值落在 $\{2\}$ 行，输出 20。表中 $\{2,3\}$ 行的两条顺序正是状压 DP 要比的事：同样的接人集合，顺序不同，车程真的不同（11 对 15），状态里「车停在谁处」那一维不能省。

### 样例 2：绕路的代价不对称

直接去馆子 $2\times\text{km}(1,3)=2\times2=4$ 分钟，但同伴步行 $2\to3$ 要 $10\times10=100$ 分钟；接上同伴再走 $1\to2\to3$ 共 20 公里、40 分钟，远好于 100。输出 40——绕 18 公里去接一个人，比让他走 100 分钟便宜，这正是枚举接人集合的意义。

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| ---- | ---------- | ---------- | ---- |
| 枚举接人集合 + 每种排列 | $O(2^q \cdot q! \cdot q)$ | $O(K^2)$ | $q=10$ 起排列数失控，不可行 |
| 关键点 Dijkstra + 状压 DP（最优） | $O(K(p{+}e)\log p + 2^q q^2)$ | $O(2^q q + p + e)$ | $K\le17$、$q\le15$、$p,e\le10^3$ 均宽裕 |

Dijkstra 以关键点为源共 $K\le17$ 次；状压部分每层做「已接集合 × 最后一站 × 未接候选」次松弛，总量级约 $1.7\times10^6$（$q=15$ 时实测亚秒级）。

## 易错点总结

### 1. 单向路的 $z$ 建成双向

$z=0$ 的边只准 $x$ 驶向 $y$，行人与车一律受此限制（题面「行人车辆都受此限」）。建图时无条件补一条反向边，最短公里表整体失真。自测第 5 组即为此设：路网只有 $2\to1$（单向 10 公里）与 $1\to3$（双向 2 公里），车根本开不进同伴所在的路口 2，只能让他沿 $2\to1\to3$ 步行 12 公里、120 分钟；当成双向图会给出 40 分钟的错值。

### 2. 状压丢掉「车此刻在哪」一维

只对 mask 记一格最短公里数，等于把到达顺序压没了。同一接人集合的不同走法终点各不相同，末段 $\text{km}(i\to b)$ 必须配到「与途中走法同一个终点」上；一维状态把两者拆开了，只能瞎配对，配错就拼出图上不存在的路线，输出比真实最优偏小。以样例 1 的全接集合为证：途中最短的 9 公里走法（$1{\to}2{\to}3$）终点在 3 号，正确的完整路线拿它的末段 $\text{km}(3,4)=2$ 合成 11 公里；一维写法一旦把 9 与 $\text{km}(2,4)=4$ 相配，就凑出 13 公里这种不存在组合。代码里 `dp = [[INF] * q ...]` 与转移中第二维的位置就是为终点服务的。

## 扩展思考

- 题面「点与路都可重复走」把问题折算成关键点度量；若允许中途下车或换乘，状态里「已接」与「已送达」要拆成两份掩码，骨架不变。
- 还要输出方案（谁坐车、按什么顺序接）时，状压里另存一个决策来源数组即可。
