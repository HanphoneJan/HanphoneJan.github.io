# P5520. 分割使方差和最大

> 场次：2026年10月20日-非AI方向 · 来源：[CodeFun2000 P5520](https://codefun2000.com/p/P5520)
>
> 题面为 CodeFun2000 会员内容，本文依据官方题解与公开信息整理；输入输出格式以原题为准，示例为说明性示例。

## 题目描述

给定一个长度为 $n$ 的数列 $a_1, a_2, \dots, a_n$。

选择一个位置 $k$（$1 \le k < n$），在 $a_k$ 与 $a_{k+1}$ 之间把数列切成左右两段：左段是 $a_1, \dots, a_k$，右段是 $a_{k+1}, \dots, a_n$。

对每一段分别计算它的**方差**：段内每个数与这段平均值的差的平方，再求平均，即

$$\operatorname{Var}(X)=\frac{1}{|X|}\sum_{x\in X}\left(x-\bar{x}\right)^2$$

把左右两段的方差相加。请选一个使这个和最大的切割位置，输出该最大值。

## 输入格式

第一行一个整数 $n$（$n \ge 2$）。

第二行 $n$ 个整数，以空格分隔，依次是 $a_1$ 到 $a_n$。

## 输出格式

输出一个实数，表示两段方差之和的最大值，保留 $6$ 位小数。

## 示例

下面两组是说明性示例（非官方样例），输出由本文代码实际运行得到。

### 示例 1

**输入：**

```
4
1 2 3 4
```

**输出：**

```
0.666667
```

**说明：** 在 $k=1$ 或 $k=3$ 处切开时最大：$k=1$ 时左段 $[1]$ 方差为 $0$，右段 $[2,3,4]$ 方差为 $2/3$，和为 $0.666667$。

### 示例 2

**输入：**

```
3
2 7 9
```

**输出：**

```
6.250000
```

**说明：** 在 $k=2$ 处切开：左段 $[2,7]$ 的方差是 $6.25$，右段 $[9]$ 的方差是 $0$，和为 $6.25$。

## 解题思路

### 判定标准：两个「总体方差」相加，除以段长而不是段长减一

先把这个「方差」钉死：题面用的是**总体方差**，除以段内元素个数 $|X|$，不是样本方差的 $|X|-1$。这一个分母决定了单元素段的方差是 $0$——单点没有任何离散度，这一点在切分位置贴着两端时会频繁出现。

于是问题的判定标准很直白：枚举每个合法的 $k \in [1, n-1]$，算出

$$\operatorname{Var}(a_1..a_k) + \operatorname{Var}(a_{k+1}..a_n)$$

取最大值，按 $6$ 位小数输出。没有次级目标，也没有字典序要求，只要这个和最大。

### 方差只需要三个数：长度、元素和、平方和

把方差的定义展开，会得到一个只用「和」与「平方和」就能算的形式。设段内有 $m$ 个元素，和为 $S$，平方和为 $S_2$，平均值 $\mu = S/m$：

$$
\begin{aligned}
\operatorname{Var}
&= \frac{1}{m}\sum (x_i-\mu)^2 \\
&= \frac{1}{m}\sum x_i^2 - \frac{2\mu}{m}\sum x_i + \frac{1}{m}\sum \mu^2 \\
&= \frac{S_2}{m} - 2\mu\cdot\frac{S}{m} + \mu^2 \\
&= \frac{S_2}{m} - 2\mu^2 + \mu^2 \\
&= \frac{S_2}{m} - \mu^2
\end{aligned}
$$

第二步到第三步用了 $\sum x_i = S$（所以 $\frac{1}{m}\sum x_i = \mu$），最后一步把 $\mu = S/m$ 代回去。结果是

$$\operatorname{Var} = \frac{S_2}{m} - \left(\frac{S}{m}\right)^2$$

也就是「平方的平均」减去「平均的平方」。写成一个函数：

```python
def var(lo, hi):
    """下标区间 [lo, hi) 的总体方差。"""
    length = hi - lo
    s = pre[hi] - pre[lo]          # 段内元素和
    s2 = pre2[hi] - pre2[lo]       # 段内平方和
    mean = s / length
    return max(0.0, s2 / length - mean * mean)   # 浮点抵消可能给出 -0.0
```

末尾的 `max(0.0, ...)` 是给浮点抵消留的余地：数学上方差不可能为负，但两个相近的大数相减会掉出 $-10^{-16}$ 这样的尾巴，扣在答案上就会变成 `-0.000000`。

### 前缀和把每个切割点压到 O(1)

上面的函数要「段内元素和」与「段内平方和」。如果每个切割点都从头累加一遍，光求和就是 $O(n)$，$n$ 个切割点合起来是 $O(n^2)$——同一批前缀被反复相加，全是重复劳动。

把这两样都做成前缀数组即可：

```python
pre = [0] * (n + 1)      # 前缀和
pre2 = [0] * (n + 1)     # 前缀平方和
for i, v in enumerate(a, 1):
    pre[i] = pre[i - 1] + v
    pre2[i] = pre2[i - 1] + v * v
```

之后任意一段 $[lo, hi)$ 的和是 `pre[hi] - pre[lo]`，平方和是 `pre2[hi] - pre2[lo]`，两次减法都是 $O(1)$。切割点 $k$ 把数组分成 $[0,k)$ 与 $[k,n)$，一次循环就能把所有位置试完：

```python
best = -1.0
for k in range(1, n):                        # 左段 [0, k)，右段 [k, n)
    cur = var(0, k) + var(k, n)
    if cur > best:
        best = cur
```

`best` 初值取 $-1$：方差和非负，任何合法切法都会把它顶上去，省掉「是不是第一个」的判断。

**为什么要用前缀和而不是直接存浮点方差**：前缀和全是整数的累加，$10^9$ 量级的元素加几千项也不掉精度；只在最后除以长度时才转成浮点。如果一开始就用浮点累加前缀，误差会随项数线性增长，大数相减时尤其明显。

### 输出：`f"{best:.6f}"` 才是「6 位小数」

题目要的是固定 6 位，包括末尾的 0。`round(best, 6)` 只做四舍五入、不做补零，`6.25` 会原样打印成 `6.25`；`f"{best:.6f}"` 才会给出 `6.250000`。

```python
print(f"{best:.6f}")
```

### 实现落点

- `pre` / `pre2` 是长度 $n+1$ 的数组，`pre[0] = pre2[0] = 0`，方便区间做差；
- `var(lo, hi)` 用半开区间，左段传 `(0, k)`、右段传 `(k, n)`，边界不用单独处理；
- 分割点循环是 `range(1, n)`：`k = 0` 与 `k = n` 都会让某一段长度为 $0$，既不是合法切法，也会让 `var` 里出现除以 $0$；
- 只有一处的浮点运算发生在 `var` 内部，比较与输出都用同一个 `best`，不会再引入第二份误差。

## 完整代码实现

```python
"""
P5520. 分割使方差和最大 - 前缀和 + 前缀平方和

把一个数列在下标 k（1 <= k < n）处切成左右两段，求两段方差之和的最大值，
保留 6 位小数输出。方差取总体方差：
Var(X) = (1/|X|) * Σ(x_i - mean)^2 = E[x^2] - (E[x])^2。

输入格式：
- 第 1 行：整数 n（n >= 2）；
- 第 2 行：n 个整数（空格分隔）。

输出格式：
- 一个实数，保留 6 位小数。

核心思路：
方差只需要「长度、元素和、平方和」三样东西：
    Var = S2 / len - (S / len)^2
两段分别用前缀和与前缀平方和做差即可 O(1) 求出。枚举 n-1 个分割点，
取方差和的最大值。前缀和都用整数存，只在算方差时转成浮点，
既能保住大整数相加的精度，也不用为每个分割点重扫一遍数组。
"""

# https://codefun2000.com/p/P5520
import sys

# @sample-start
"""
样例输入 1:
4
1 2 3 4

样例输出 1:
0.666667
"""
# @sample-end

# @sample-start
"""
样例输入 2:
3
2 7 9

样例输出 2:
6.250000
"""
# @sample-end


def solve():
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    n = int(data[0])
    a = list(map(int, data[1 : 1 + n]))

    pre = [0] * (n + 1)      # 前缀和
    pre2 = [0] * (n + 1)     # 前缀平方和
    for i, v in enumerate(a, 1):
        pre[i] = pre[i - 1] + v
        pre2[i] = pre2[i - 1] + v * v

    def var(lo, hi):
        """下标区间 [lo, hi) 的总体方差。"""
        length = hi - lo
        s = pre[hi] - pre[lo]
        s2 = pre2[hi] - pre2[lo]
        mean = s / length
        return max(0.0, s2 / length - mean * mean)   # 浮点抵消可能给出 -0.0

    best = -1.0
    for k in range(1, n):                        # 左段 [0, k)，右段 [k, n)
        cur = var(0, k) + var(k, n)
        if cur > best:
            best = cur
    print(f"{best:.6f}")


def run_tests():
    """运行嵌入的示例与边界用例，方便本地自测。"""
    import io

    cases = [
        # 示例 1：k=1 或 k=3 时最大，2/3 ≈ 0.666667
        ("4\n1 2 3 4\n", "0.666667"),
        # 示例 2：k=2 时 [2,7] 方差 6.25，[9] 方差 0
        ("3\n2 7 9\n", "6.250000"),
        # 两个元素：两段都是单点，方差和恒为 0
        ("2\n7 9\n", "0.000000"),
        # 全相等：任何切法都是 0
        ("5\n5 5 5 5 5\n", "0.000000"),
        # 左段 [-4,4] 均值 0、方差 16，右段 [4] 方差 0
        ("3\n-4 4 4\n", "16.000000"),
        # 大数：平方和到 1e18 量级，检验整数前缀和的精度
        ("3\n1000000000 1000000000 1000000000\n", "0.000000"),
    ]

    for i, (inp, expected) in enumerate(cases, 1):
        old_stdin, old_stdout = sys.stdin, sys.stdout
        sys.stdin = io.TextIOWrapper(io.BytesIO(inp.encode("utf-8")))
        sys.stdout = io.StringIO()
        try:
            solve()
            output = sys.stdout.getvalue().strip()
        finally:
            sys.stdin, sys.stdout = old_stdin, old_stdout
        status = "✓" if output == expected else "✗"
        print(f"用例 {i}: 期望={expected}, 实际={output} {status}")


if __name__ == "__main__":
    if len(sys.argv) > 1 and sys.argv[1] == "--test":
        run_tests()
    else:
        solve()
```

## 示例推演

### 示例 1：$a = [1,2,3,4]$

前缀和 $pre = [0,1,3,6,10]$，前缀平方和 $pre2 = [0,1,5,14,30]$。三个切割点逐个算：

| $k$ | 左段 $[0,k)$ | 左段方差 | 右段 $[k,4)$ | 右段方差 | 和 |
| --- | ------------ | -------- | ------------ | -------- | -- |
| $1$ | $[1]$，$m{=}1,S{=}1,S_2{=}1$ | $1/1-1^2=0$ | $[2,3,4]$，$m{=}3,S{=}9,S_2{=}29$ | $29/3-(9/3)^2=2/3$ | $0.666667$ |
| $2$ | $[1,2]$，$m{=}2,S{=}3,S_2{=}5$ | $5/2-(3/2)^2=0.25$ | $[3,4]$，$m{=}2,S{=}7,S_2{=}25$ | $25/2-(7/2)^2=0.25$ | $0.5$ |
| $3$ | $[1,2,3]$，$m{=}3,S{=}6,S_2{=}14$ | $14/3-(6/3)^2=2/3$ | $[4]$ | $16/1-16=0$ | $0.666667$ |

方差和最大是 $2/3 \approx 0.666667$，在 $k=1$ 与 $k=3$ 两处同时取到。注意 $k=2$ 反而最小：把数列对半分，两段各自都太「整齐」，离散度没有集中到一边。

### 示例 2：$a = [2,7,9]$

前缀和 $pre = [0,2,9,18]$，前缀平方和 $pre2 = [0,4,53,130]$。

| $k$ | 左段 | 左段方差 | 右段 | 右段方差 | 和 |
| --- | ---- | -------- | ---- | -------- | -- |
| $1$ | $[2]$ | $0$ | $[7,9]$，$m{=}2,S{=}16,S_2{=}130$ | $130/2-8^2=1$ | $1.0$ |
| $2$ | $[2,7]$，$m{=}2,S{=}9,S_2{=}53$ | $53/2-4.5^2=6.25$ | $[9]$ | $0$ | $6.25$ |

最大值 $6.25$，按 $6$ 位小数输出 `6.250000`。

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| ---- | ---------- | ---------- | ---- |
| 每个切割点重扫两段求和与平方和 | $O(n^2)$ | $O(1)$ | 同一批前缀被反复累加，$n$ 大时超时 |
| 前缀和 + 前缀平方和（最优） | $O(n)$ | $O(n)$ | 两次前缀各扫一遍，之后每个切割点 $O(1)$ |

前缀数组各占 $n+1$ 个整数，其余只有常数级变量。

## 易错点总结

### 1. 方差第二项少除了一次长度

把 `s2 / length - mean * mean` 写成 `s2 / length - s * s / length`（也就是误把 $S^2/m$ 当成 $(S/m)^2$），第二项整整少了 $m$ 倍。示例 1 的三行会算成 $-17.333$、$-14$、$-7.333$，因为 `max(0.0, ...)` 会把它压成 $0$，页面输出 `0.000000`，与正确答案 $0.666667$ 完全不是一回事。写之前先把 $S^2/m^2$ 与 $S^2/m$ 在纸上分清楚。

### 2. 分割点范围写成 `range(0, n)` 或 `range(1, n + 1)`

`for k in range(1, n)` 才是全部合法位置。写成 `range(0, n)` 时 $k=0$ 会让左段长度变成 $0$，`var(0, 0)` 里 `length = 0`，`s / length` 直接抛 `ZeroDivisionError`；写成 `range(1, n + 1)` 则是右段长度为 $0$，同样除零。

### 3. 用 `round(best, 6)` 输出

`round` 只管四舍五入不管补零。示例 2 的最大值是 $6.25$，`print(round(best, 6))` 输出 `6.25`，而题目要求的是 6 位小数 `6.250000`。判定用数值也好、按文本比也好，这一处都会被判错。
