# P5427. 质因数跳跃

> 场次：2026年9月11日-非AI方向 · 来源：[CodeFun2000 P5427](https://codefun2000.com/p/P5427)

## 题目描述

有一个非空正整数序列 $seq$，长度记为 $m$。一开始位置 $p$ 停在下标 $0$。随后 $p$ 可以跳到 $p+d$ 或 $p-d$，但必须满足 $p+d \le m-1$ 且 $p-d \ge 0$。这里的 $d$ 取当前格子 $seq_p$ 的质因数；若该格子为 $1$，则不存在可用的 $d$，位置无法再跳。问能否按这条规则让 $p$ 恰好落到最后一个下标。

质因数：某个正整数的因数里那些质数。整数 $1$ 不含于任何数的质因数集合。

举例来说，$12$ 可以分解出质因数 $2$、$3$。

## 输入格式

一行若干正整数，用空格隔开，即整个序列，例如

```
1 2 3 4
```

满足 $1 \le m \le 10^{4}$，$1 \le seq_p \le 10^{3}$。

## 输出格式

若位置能够落到序列末位，输出 `true`

否则输出 `false`

## 示例

### 示例 1

**输入：**

```
4 1 1 9
```

**输出：**

```
false
```

**说明：**

起点为 $4$，质因数只有 $2$，只能跳到下标 $2$；该处为 $1$，无法再跳，到不了下标 $3$。

### 示例 2

**输入：**

```
10 1 4 9 1
```

**输出：**

```
true
```

**说明：**

$10$ 的质因数是 $2$ 与 $5$。从下标 $0$ 沿 $2$ 跳到下标 $2$（值为 $4$）。

$4$ 的质因数是 $2$，再沿 $2$ 跳到最后一个下标。

### 示例 3

**输入：**

```
1 6 8
```

**输出：**

```
false
```

**说明：**

起点为 $1$，没有质因数，位置无法离开下标 $0$，而末位是下标 $2$。

## 解题思路

### 判定标准里两处容易被读漏的口子

第一处是末位：要求「恰好落到最后一个下标」，但到达后的格子值是多少**无关紧要**——样例 2 里末位的值是 1，跳跃照常判定为 `true`。第二处是「恰好」的对面：`m = 1` 时起点就是最后一个下标，一步都不用跳，答案也是 `true`（哪怕是值 1 的格子，虽然它无出边，但人已经站在终点）。这两条把输出的全部语义固定下来：从下标 0 出发在允许的边里走，问 `m-1` 是否可达。

### 关键观察：出边只由下标处的值决定，问的是可达性

从点 `p` 出发能到 `p±d`，`d` 取 `seq[p]` 的**互异质因数**；值为 1 的格子没有出边。这一步与「怎么走到 p 的」完全无关——所以整张图是 `m` 个点、边由格子值静态决定的图，问题就是 0 到 `m-1` 的连通性，BFS 一遍即可，每个点至多入队一次。

数据范围把写法压得很轻：`m <= 1e4`、值 `<= 1e3`。2×3×5×7×11×13 已经大于 1000，所以任何 `1000` 以内的数至多有 4 个互异质因数，出边是常数级——没有任何一个格子会带来长边列表。质因数用最小质因数筛预处理，同一值的分解结果再缓存一份，整题 `O(1000 + m)`。

### 到实现上的映射

- `smallest_prime_factors`：筛法本体，筛出每个数的最小质因数，供「除净式分解」逐层剥因子。
- `distinct_prime_factors`：除到 1 为止、用集合去重后排序缓存；`seq[p] = 1` 时循环体一次都不进，自然得到空列表——值为 1 无出边由同一份代码给出。
- `solve`：起点入队即标记 visited；出队先查是否终点（覆盖 `m=1`），生成邻居时做 `0 <= q < m` 的双向检查，命中终点当场返回。数组全为同一质数的链（如全 3）在 `m=1e4` 上也只是 3334 步的最短链。

## 完整代码实现

```python
"""
P5427. 质因数跳跃 - 隐式图 BFS 可达性

题面要点：
- 序列 seq 长 m，位置 p 初始在下标 0；每步取 d = seq[p] 的某个质因数
 （互异的最大只有几个），跳到 p+d 或 p-d，且必须 0 <= p-d 与 p+d <= m-1。
- seq[p] = 1 时没有质因数，该格没有出边；质因数指质数因子（1 不是）。
- 问能否恰好到达最后一个下标 m-1。输出 true / false。

输入格式：一行若干正整数（1 <= m <= 1e4，1 <= seq[p] <= 1e3）。

输出格式：true 或 false。

核心思路（为什么是 BFS）：
1. 「下标 + 现在在哪」没有别的状态：格子值只决定出边，不随路径变化，
   所以这就是一张 m 个点的隐式图，问 0 到 m-1 的可达性——搜索一遍即可。
2. 数据范围把搜索写法定下来：m <= 1e4、值 <= 1e3。每个值的互异质因数
   很少（2*3*5*7*11*13 = 30030，1000 以内至多 4 个），出边常数级，
   BFS 的 O(m) 完全够；质因数用 1000 以内的最小质因数筛预处理后去重可查。
3. 熟知的几个坑都对应边界：m=1 时起点即终点（true）；值为 1 无出边；
   步长是质因数不是任意因子（4、8、9 不行）；走回头路靠 visited 挡住。

时间复杂度：O(1000 + m * k)（k 为单值互异质因数个数上限 4）
空间复杂度：O(m)
"""

# https://codefun2000.com/p/P5427
import sys
from collections import deque

# @sample-start
"""
样例输入 1:
4 1 1 9

样例输出 1:
false
"""
# @sample-end

# @sample-start
"""
样例输入 2:
10 1 4 9 1

样例输出 2:
true
"""
# @sample-end

# @sample-start
"""
样例输入 3:
1 6 8

样例输出 3:
false
"""
# @sample-end


def smallest_prime_factors(limit):
    """埃尔拉托式最小质因数筛，spf[x] 是 x 的最小质因数（x >= 2）。"""
    spf = list(range(limit + 1))
    i = 2
    while i * i <= limit:
        if spf[i] == i:
            for j in range(i * i, limit + 1, i):
                if spf[j] == j:
                    spf[j] = i
        i += 1
    return spf


def distinct_prime_factors(spf, cache, x):
    """x 的互异质因数列表；x = 1 时为空（1 不含质因数）。"""
    if x not in cache:
        factors = set()
        v = x
        while v > 1:
            f = spf[v]
            factors.add(f)
            while v % f == 0:
                v //= f
        cache[x] = sorted(factors)
    return cache[x]


def solve():
    """从下标 0 出发按质因数步长搜索，判断能否到达 m-1。"""
    seq = list(map(int, sys.stdin.buffer.read().split()))
    m = len(seq)
    if m == 0:
        print("false")
        return
    if m == 1:
        # 起点就是最后一个下标，不需要任何跳跃。
        print("true")
        return

    spf = smallest_prime_factors(max(seq))
    cache = {}

    target = m - 1
    visited = [False] * m
    visited[0] = True
    queue = deque([0])
    while queue:
        p = queue.popleft()
        if p == target:
            print("true")
            return
        for d in distinct_prime_factors(spf, cache, seq[p]):
            for q in (p + d, p - d):
                if 0 <= q < m and not visited[q]:
                    if q == target:
                        print("true")
                        return
                    visited[q] = True
                    queue.append(q)
    print("false")


def run_tests():
    """运行嵌入的官方样例与自加用例，方便本地自测。"""
    import io

    def run(stdin_text):
        old_stdin, old_stdout = sys.stdin, sys.stdout
        # solve() 用 sys.stdin.buffer 快速读取，这里提供带 buffer 的文本流。
        sys.stdin = io.TextIOWrapper(io.BytesIO(stdin_text.encode("utf-8")))
        sys.stdout = io.StringIO()
        try:
            solve()
            return sys.stdout.getvalue().strip()
        finally:
            sys.stdin, sys.stdout = old_stdin, old_stdout

    test_cases = [
        # 官方样例 1：跳到值 1 的格子后无出边
        ("4 1 1 9\n", "false"),
        # 官方样例 2：10 有两个质因数，沿 2 两次到末位；末位是 1 也能到
        ("10 1 4 9 1\n", "true"),
        # 官方样例 3：起点值为 1，无质因数无法离开
        ("1 6 8\n", "false"),
        # m=1：起点即最后一个下标，值为 1 也是 true
        ("1\n", "true"),
        ("5\n", "true"),
        # 步长可以是质数本身：7 是质数，质因数只有 7，一步直达
        ("7 1 1 1 1 1 1 1\n", "true"),
        # 复数因子不是步长：6 的质因数是 2、3，不是 1、6
        ("2 1 1 9 5\n", "false"),
        # m=9 三步一步长 3 的链：0->3->6 后 6+3 越界、6-3 回走己访问，false
        ("3 1 1 1 1 1 1 1 1\n", "false"),
        # 有环也能停住：0(6)->2(4)->4(6)->6 即终点，visited 防止往返死循环
        ("6 4 6 4 6 4 6\n", "true"),
        # 回头跳也允许：0 被 2 送到 2，2 的 4 只能回 0 或去 4；终点 5
        # 需要经过 2(值6, d=3) -> 5
        ("4 1 6 9 1 1\n", "true"),
    ]

    failures = 0
    for i, (inp, expected) in enumerate(test_cases, 1):
        output = run(inp)
        ok = output == expected
        if not ok:
            failures += 1
        print(f"样例 {i}: 期望={expected}, 实际={output} {'✓' if ok else '✗'}")

    # 极端规模：m=10000 全 3 的链，0->3->6->...->9999 共 3334 步可达，
    # 必须秒级返回 true
    import time

    n = 10000
    big = "3 " * n + "\n"
    start = time.time()
    output = run(big)
    cost = time.time() - start
    ok = output == "true" and cost < 5
    if not ok:
        failures += 1
    print(f"规模 10000: 实际={output} 耗时 {cost:.2f}s {'✓' if ok else '✗'}")

    if failures:
        raise SystemExit(1)


if __name__ == "__main__":
    if len(sys.argv) > 1 and sys.argv[1] == "--test":
        run_tests()
    else:
        solve()
```

## 示例推演

以官方样例 2 为例，`seq = [10, 1, 4, 9, 1]`，`m = 5`，终点是下标 4。

| 队列状态 | 出队 | 出边 | 新入队 |
| -------- | ---- | ---- | ------ |
| [0] | 0（值 10，质因数 {2, 5}） | 0+2=2；0-2 越界；0+5=5 越界 | 2 |
| [2] | 2（值 4，质因数 {2}） | 2+2=4 命中终点 | — |

输出 `true`。注意 0+5=5 这条边被 `q < m` 挡掉，5、9 ∈ {10 的质因数} 里较大那个在这里帮不上忙——越界的不用，这正是入队前的边界检查在起作用。

官方样例 1 走一遍就停在死角：`seq = [4, 1, 1, 9]`，从 0 只能沿质因数 2 跳到下标 2，值为 1 的格子无出边——队列耗尽，输出 `false`。若错误地把合数因子 4 也当步长，`0+4` 一步就越过了终点判定，同样的布局会错判成 `true`，这正是筛出的必须是**质**因数的原因。

官方样例 3 是一个前缀确认：起点值为 1，`distinct_prime_factors` 返回空列表，队列里只有 0，出队后无邻居，输出 `false`。而输入只有 `1` 一个数时走的是另一条分支：`m == 1` 直接 `true`——起点即终点。

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| ---- | ---------- | ---------- | ---- |
| 逐次访问重新试除分解当前格 | $O(m \cdot \sqrt{a_p})$ | $O(m)$ | 能过，但同一值反复分解，常数偏大 |
| 值域筛最小质因数 + 分解结果缓存（最优） | $O(1000 + m)$ | $O(m)$ | 筛一次、每值分解一次、BFS 每点入队一次，本题采用 |

## 易错点总结

### 1. 合数因子被当成步长

质因数只收质数。`distinct_prime_factors` 的除净式循环里每一层只把 `spf[v]`（一定是最小的、必然是质数的因子）放入集合；若顺手把「除净一次得到的商再分解出的所有因子」连同 4、6、9 一起收下，步长就超出了题意。官方样例 1 在布局稍变（如 `4 1 9 1`）时会从 `false` 变成 `true`，这类假通路在同布局的合法步长下并不存在。

### 2. 负下标的 Python 回绕

出队生成邻居时必须先做 `0 <= q < m` 再访问数组。Python 的 `seq[q]` 对负 `q` 会回绕到数组尾部、`visited[q]` 会直接改写**终点下标**的标记——一次 `p - d` 越界访问就足以把 `false` 的局面标成 `true`，且不抛任何异常。

## 扩展思考

出边由当前格静态决定，是「隐式图」里最轻的一类：状态就是下标本身。若题意加一条「最多跳 k 次」，把队列元素换成 `(位置, 已跳次数)` 分层即可得到最短步数；若询问从任意起点出发的可达情况，从所有下标各跑一次 BFS 或对无入边的点缩点后一次正反遍历都能覆盖。本题的筛法与分解缓存，在同类「值域决定花费」的图问题上同样通用。
