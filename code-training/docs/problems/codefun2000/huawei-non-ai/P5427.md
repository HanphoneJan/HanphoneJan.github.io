# P5427. 质因数跳跃

> 场次：2026年9月11日-非AI方向 · 来源：[CodeFun2000 P5427](https://codefun2000.com/p/P5427)

## 题目描述

有一个非空正整数序列 $seq$，长度记为 $m$。一开始位置 $p$ 停在下标 $0$。随后 $p$ 可以跳到 $p+d$ 或 $p-d$，但必须满足 $p+d \le m-1$ 且 $p-d \ge 0$。这里的 $d$ 取当前格子 $seq_p$ 的质因数；若该格子为 $1$，则不存在可用的 $d$，位置无法再跳。问能否按这条规则让 $p$ 恰好落到最后一个下标。

质因数：某个正整数的因数里那些质数。整数 $1$ 不含于任何数的质因数集合。

举例来说，$12$ 可以分解出质因数 $2$、$3$。

## 输入格式

一行若干正整数，用空格隔开，即整个序列，例如

```
1 2 3 4
```

满足 $1 \le m \le 10^{4}$，$1 \le seq_p \le 10^{3}$。

## 输出格式

若位置能够落到序列末位，输出 `true`

否则输出 `false`

## 示例

### 示例 1

**输入：**

```
4 1 1 9
```

**输出：**

```
false
```

**说明：**

起点为 $4$，质因数只有 $2$，只能跳到下标 $2$；该处为 $1$，无法再跳，到不了下标 $3$。

### 示例 2

**输入：**

```
10 1 4 9 1
```

**输出：**

```
true
```

**说明：**

$10$ 的质因数是 $2$ 与 $5$。从下标 $0$ 沿 $2$ 跳到下标 $2$（值为 $4$）。

$4$ 的质因数是 $2$，再沿 $2$ 跳到最后一个下标。

### 示例 3

**输入：**

```
1 6 8
```

**输出：**

```
false
```

**说明：**

起点为 $1$，没有质因数，位置无法离开下标 $0$，而末位是下标 $2$。

## 解题思路

### 输出只看「到没到」，末位的值不参与判定

先钉死判定标准：问的是从下标 $0$ 出发能否走到下标 $m-1$。**到达之后末位格子写的是什么无所谓**——样例 2 的末位是 $1$（本身没有出边），照样判 `true`；$m=1$ 时起点就是末位，一步不跳也算到。所以输出只有 `true` / `false`，不需要路径、步数或任何代价。

### 关键观察一：这张图是**有向**的，不能当无向图连

从 $p$ 出发的步长取自 $seq_p$ 的质因数：$d \mid seq_p$ 才允许跳 $p \pm d$。可站在 $p+d$ 上时，步长改由 $seq_{p+d}$ 决定，$d$ 不一定还留在里面。边 $p \to p+d$ **不保证**反向存在：

```text
seq = [2, 1, 3, 1, 2]   # m = 5，终点是下标 4
0  --(d=2，来自 seq[0]=2)-->  2
2  --(seq[2]=3，只有步长 3)-->  2+3=5 越界、2-3=-1 越界，走不动
```

正确答案是 `false`。若把边当成无向的、用并查集把 0 与 2 连起来，下标 4（值为 2，质因数 2）又会与 2 连上，于是 0 与 4「连通」——输出 `true`。方向性一丢，答案就反了。**必须从下标 0 正向搜。**

### 关键观察二：出边是常数条，一遍搜索就是 O(m)

每个点有多少条出边？值不超过 $10^3$，互异质因数至多 4 个（$2\cdot3\cdot5\cdot7=210$，再乘 $11$ 就是 $2310>10^3$），正反两个方向算上也不过 8 条。$m \le 10^4$，总边数 $\le 8m$，搜索一遍绰绰有余。

状态也只有「现在在下标几」这一项：出边由当前格的值静态决定，与怎么走到这里无关。

```python
visited = [False] * m
visited[0] = True
queue = deque([0])
while queue:
    p = queue.popleft()
    for d in prime_factors(seq[p]):      # 只取互异质因数
        for q in (p + d, p - d):         # 两个方向都试
            if 0 <= q < m and not visited[q]:
                if q == target:          # 命中末位就收工
                    return True
                visited[q] = True
                queue.append(q)
return False
```

`visited` 在**入队那一刻**置位，同一下标不会进队两次。这不只是为了快：$p \to p+d \to p$ 的来回是常态（值为 $6$ 的格子用 $3$ 跳过去，对面若是 $3$ 又用 $3$ 跳回来），没有这层去重，队列永远清不空。

质因数分解用试除就够，不必上筛法。写成生成器更省事：分解到第几个质数，就立刻把它交出去试跳，不必先攒一个列表。

```python
def prime_factors(x):
    d = 2
    while d * d <= x:          # 试到 sqrt(x)；剩下的部分若仍 > 1，它自己就是质数
        if x % d == 0:
            yield d
            while x % d == 0:  # 除净：保证冒出来的都是质数，也不会重复
                x //= d
        d += 1
    if x > 1:
        yield x
```

`x = 1` 时循环一次不进、`x > 1` 不成立，一个质数都不产出——「值为 1 的格子没有出边」由这段代码自然给出，不用单独写分支。

单个值最多试除 $\lfloor\sqrt{1000}\rfloor = 31$ 次；一个值在一次 BFS 里可能被分解多次，但可取的数只有 $1\sim10^3$ 种、访问总量 $m\le10^4$，最坏 $3\times10^5$ 次取模，与 BFS 本身同量级。缓存和线性筛省下来的常数，在这个数据范围里看不出来。

### 为什么用 BFS 而不是递归 DFS

可达性用 DFS 也是对的，两者复杂度同为 $O(m\cdot k)$。但递归 DFS 的深度等于路径长度：全 $3$ 的链 $0\to3\to6\to\dots$ 在 $m=10^4$ 时最坏要走 $3334$ 层，远超 Python 默认的递归上限 $1000$，直接 `RecursionError`。改成显式栈能绕开，可队列本来就是 BFS 的原生结构，没必要再手搓一个栈。

BFS 还留了后手：出队顺序就是「步数由小到大」，题目若改问「最少跳几跳到达」，把队列元素换成 `(位置, 步数)` 即可，骨架不动。

### 实现映射

- `can_reach(seq)`：整个搜索，返回布尔值；`m == 1` 的捷径也在这里；
- `prime_factors(x)`：试除式分解，顺带把「1 没有质因数」这条规则落成「一个都不产出」；
- `solve()`：把整行整数读成序列交给 `can_reach`，再把布尔值打印成小写的 `true` / `false`。

## 完整代码实现

```python
"""
P5427. 质因数跳跃 - 隐式图 BFS 可达性

题面要点：
- 序列 seq 长 m，位置 p 初始在下标 0；每步取 d = seq[p] 的某个质因数
  （互异的质数因子，1 不含质因数），跳到 p+d 或 p-d，
  且必须满足 0 <= p-d 与 p+d <= m-1。
- seq[p] = 1 时没有质因数，该格没有出边。
- 问能否恰好到达最后一个下标 m-1。输出 true / false。

输入格式：一行若干正整数（1 <= m <= 1e4，1 <= seq[p] <= 1e3）。

输出格式：true 或 false。

核心思路（为什么是 BFS）：
1. 状态只有「现在在下标几」：格子值只决定出边，不随路径变化，
   所以这是一张 m 个点的有向隐式图，问 0 到 m-1 的可达性。
   边是有向的：p -> p+d 用 seq[p] 的质因数，反向不一定成立。
2. 数据范围把写法钉死：m <= 1e4、值 <= 1e3，每个值的互异质因数至多 4 个，
   出边常数条，BFS 的 O(m) 足够；试除分解最多 31 次取模，不必上筛法。
3. 边界：m=1 时起点即终点（true）；值为 1 无出边；步长是质因数不是任意
   因子（4、8、9 不行）；visited 防住来回跳造成的死循环。

时间复杂度：O(m * (sqrt(A) + k))，A 为最大格值、k <= 4
空间复杂度：O(m)
"""

# https://codefun2000.com/p/P5427
import sys
from collections import deque

# @sample-start
"""
样例输入 1:
4 1 1 9

样例输出 1:
false
"""
# @sample-end

# @sample-start
"""
样例输入 2:
10 1 4 9 1

样例输出 2:
true
"""
# @sample-end

# @sample-start
"""
样例输入 3:
1 6 8

样例输出 3:
false
"""
# @sample-end


def can_reach(seq):
    """从下标 0 出发按质因数步长搜索，判断能否到达末位。"""
    m = len(seq)
    if m == 1:
        # 起点就是最后一个下标，不需要任何跳跃。
        return True

    target = m - 1
    visited = [False] * m
    visited[0] = True
    queue = deque([0])
    while queue:
        p = queue.popleft()
        for d in prime_factors(seq[p]):
            # 两个方向都要试，出界的一侧直接跳过
            for q in (p + d, p - d):
                if 0 <= q < m and not visited[q]:
                    if q == target:
                        return True
                    visited[q] = True
                    queue.append(q)
    return False


def prime_factors(x):
    """逐个产出 x 的互异质因数；x = 1 时一个都不产出（1 不含质因数）。"""
    d = 2
    while d * d <= x:
        if x % d == 0:
            yield d
            while x % d == 0:  # 除净，保证冒出来的都是质数
                x //= d
        d += 1
    if x > 1:  # 剩下的大于 1 的因子本身是质数
        yield x


def solve():
    seq = [int(x) for x in sys.stdin.buffer.read().split()]
    if seq:
        print("true" if can_reach(seq) else "false")


def run_tests():
    """运行嵌入的官方样例与自加用例，方便本地自测。"""
    import io
    import random
    import time

    def run(stdin_text):
        old_stdin, old_stdout = sys.stdin, sys.stdout
        # solve() 用 sys.stdin.buffer 快速读取，这里提供带 buffer 的文本流。
        sys.stdin = io.TextIOWrapper(io.BytesIO(stdin_text.encode("utf-8")))
        sys.stdout = io.StringIO()
        try:
            solve()
            return sys.stdout.getvalue().strip()
        finally:
            sys.stdin, sys.stdout = old_stdin, old_stdout

    def closure(seq):
        """参照实现：反复扫描直到没有新格子被标记，与 BFS 完全独立的写法。"""
        m = len(seq)
        reach = [False] * m
        reach[0] = True
        changed = True
        while changed:
            changed = False
            for p in range(m):
                if not reach[p]:
                    continue
                for d in prime_factors(seq[p]):
                    for q in (p + d, p - d):
                        if 0 <= q < m and not reach[q]:
                            reach[q] = True
                            changed = True
        return reach[m - 1]

    test_cases = [
        # 官方样例 1：跳到值 1 的格子后无出边
        ("4 1 1 9\n", "false"),
        # 官方样例 2：10 的质因数是 2 和 5，沿 2 两次即到末位（末位是 1 也算到）
        ("10 1 4 9 1\n", "true"),
        # 官方样例 3：起点值为 1，没有质因数，离不开下标 0
        ("1 6 8\n", "false"),
        # m=1：起点即末位，值为 1 或 5 都是 true
        ("1\n", "true"),
        ("5\n", "true"),
        # 7 是质数，一步直接落到末位
        ("7 1 1 1 1 1 1 1\n", "true"),
        # 合数因子不能当步长：4 的质因数只有 2，落到下标 2 后格子是 1
        ("4 1 1 1 1\n", "false"),
        # 有向性：2 只能把 0 送到下标 2，而 2 的步长 3 出界，回不去也到不了 4
        ("2 1 3 1 2\n", "false"),
        # 来回跳：0(值 6) 与 3(值 3) 互相可达，visited 挡住才不会死循环
        ("6 1 1 3 1\n", "false"),
        # 全 3 的链：0 -> 3 -> 6，之后 +3 越界、-3 已访问
        ("3 1 1 1 1 1 1 1 1\n", "false"),
        # 末位值不参与判定：0(6) -> 2(6) -> 4(6) -> 6 命中终点
        ("6 4 6 4 6 4 6\n", "true"),
    ]

    failures = 0
    for i, (inp, expected) in enumerate(test_cases, 1):
        output = run(inp)
        ok = output == expected
        if not ok:
            failures += 1
        print(f"样例 {i}: 期望={expected}, 实际={output} {'✓' if ok else '✗'}")

    # 随机对拍：小规模下与「反复扫描直到稳定」的参照实现比对
    rng = random.Random(20260911)
    bad = 0
    for _ in range(300):
        m = rng.randint(1, 9)
        seq = [rng.randint(1, 12) for _ in range(m)]
        inp = " ".join(map(str, seq)) + "\n"
        got = run(inp) == "true"
        want = closure(seq)
        if got != want:
            bad += 1
            print(f"对拍失败: seq={seq}, 期望={want}, 实际={got}")
    print("随机对拍:", "全部通过" if bad == 0 else f"{bad} 组不一致")
    failures += bad

    # 极端规模：m=10000 全 3 的链，0->3->6->...->9999 共 3334 步
    n = 10000
    start = time.time()
    output = run("3 " * n + "\n")
    cost = time.time() - start
    ok = output == "true" and cost < 5
    if not ok:
        failures += 1
    print(f"规模 10000: 实际={output} 耗时 {cost:.2f}s {'✓' if ok else '✗'}")

    if failures:
        raise SystemExit(1)


if __name__ == "__main__":
    if len(sys.argv) > 1 and sys.argv[1] == "--test":
        run_tests()
    else:
        solve()
```

## 示例推演

样例 2，`seq = [10, 1, 4, 9, 1]`，$m=5$，终点是下标 $4$：

| 出队 | 该格的值 | 质因数 | 试跳 | 结果 |
| ---- | -------- | ------ | ---- | ---- |
| 0 | 10 | `{2, 5}` | $0+2=2$；$0-2=-2$；$0+5=5$；$0-5=-5$ | 只有 $2$ 合法，入队 |
| 2 | 4 | `{2}` | $2+2=4$；$2-2=0$ | $4$ 正是终点，`return True` |

输出 `true`。$10$ 的另一个质因数 $5$ 在这里一次也没用上——越界的那条边在 `0 <= q < m` 处就被挡掉了，这也说明「质因数多」不等于「能跳到」。

样例 1，`seq = [4, 1, 1, 9]`：只有下标 0 入队。值为 $4$，质因数 `{2}`，$0+2=2$ 合法、$0-2$ 越界，于是下标 2 入队；该格值为 $1$，质因数为空表，循环体一次不进。队列清空，输出 `false`。末位的 $9$ 全程没被读过——它离得太远，而中间那格是死路。

样例 3，`seq = [1, 6, 8]`：起点值为 $1$，`prime_factors(1)` 返回空表，队列里只有下标 0 且立刻耗尽，输出 `false`。

## 复杂度分析

设 $A$ 为各格值的上界（$\le 10^3$），$k$ 为单值互异质因数个数（$\le 4$）。

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| ---- | ---------- | ---------- | ---- |
| 递归 DFS + 逐点试除分解 | $O(m(\sqrt{A}+k))$ | $O(m)$ | 复杂度与 BFS 同级，但链状数据递归深度可达 $m=10^4$，超过 Python 默认上限 $1000$，`RecursionError` |
| BFS + 逐点试除分解（最优） | $O(m(\sqrt{A}+k))$ | $O(m)$ | 每点至多出队一次、至多 $2k$ 条边；`visited` 让总边数被 $8m$ 封顶 |

两项主因：访问量是 $m$ 个点，分解是每个点至多 $31$ 次取模。没有缓存与线性筛的位置——可取的数只有 $1000$ 种，省下的常数淹没在同一量级里。

## 易错点总结

### 1. 合数因子被当成步长

`prime_factors` 里 `yield d` 后面那句 `while x % d == 0: x //= d` 不能省：不除净时 $x$ 不缩小，试除循环到 $\sqrt{x}$ 就停下，末尾 `if x > 1: yield x` 会把没分解完的合数整个交出去（$4$ 产出 `2, 4`，$12$ 产出 `2, 3, 12`）；直接把所有因子收下的写法同理。合数一旦进了步长表，输入 `4 1 1 1 1`（$m=5$）就会从正确的 `false` 变成 `true`——$0$ 一步跨到 $4$，而按质因数只能到下标 $2$，那里是值为 $1$ 的死格。

### 2. 先查 `visited[q]` 再判越界

`if 0 <= q < m and not visited[q]` 的顺序不能换。`visited[q]` 写在前面时，$q<0$ 会被当成负下标：落在长度以内就悄悄改到别的格子上（比如把终点标记成已访问），超出长度就直接抛异常。输入 `1000 1`（$m=2$，$1000$ 的质因数 `{2, 5}`）时 $q=-5$，程序不是输出 `false`，而是 `IndexError: list index out of range`。

### 3. 漏掉 `visited` 的置位

`visited[q] = True` 必须发生在入队之前，且两个方向都要经过它。漏掉之后，两条边能互相到达的格子会你来我往地把对方重新入队：输入 `2 1 2 1 2 1`（下标 2 与 4 的值都是 2，$2+2=4$、$4-2=2$）时，$2 \leftrightarrow 4$ 往返不停，队列永远清不空，程序既不输出也不报错，看起来就是「卡住了」。

## 扩展思考

状态就是下标本身，这是隐式图里最轻的一类。若题意加一条「最多跳 $k$ 次」，把队列元素换成 `(位置, 已跳次数)` 就能得到最短步数；若问「哪些起点能到末位」，从末位在**反向图**上跑一次 BFS 即可（反向边仍然要按出边规则逐条建，不能假设对称）。这里的「值域筛出因子、再在图上游走」也是同类题的通用套路。
