# P5347. 时序数据修复与加权特征评分

> 场次：2026年9月4日 · 来源：[CodeFun2000 P5347](https://codefun2000.com/p/P5347)

## 题目描述

某数据采集系统按时间顺序获取了 $n$ 条记录，每条记录包含时间戳 $t_i$、数值 $v_i$ 和质量标记 $q_i$。

其中，质量标记用于表示数据状态：当 $q_i$ 为 $0$ 时表示数据有效，当 $q_i$ 为 $1$ 时表示数据存在可疑情况，当 $q_i$ 为 $2$ 时表示数据无效。系统需要按照无效数据修复、局部异常处理、标准化以及评分计算的顺序依次完成数据处理流程。

**阶段一：无效数据修复**

对每个满足 $q_i=2$ 的位置 $i$，分别寻找其左侧和右侧最近的满足 $q=0$ 的有效数据下标，记为 $l$ 和 $r$。如果不存在，则对应下标视为未找到。

- 若 $l$ 和 $r$ 均存在，则按时间戳做线性插值：
  $a_i=v_l+\dfrac{(v_r-v_l)(t_i-t_l)}{t_r-t_l}$。
- 若只存在 $l$，则 $a_i=v_l$。
- 若只存在 $r$，则 $a_i=v_r$。
- 若 $l$ 和 $r$ 均不存在，则 $a_i=v_i$。

其余非无效数据的值保持不变，即 $a_i=v_i$。完成本阶段后得到序列 $a$。

**阶段二：局部异常处理**

设 $w$ 为奇数，令半径 $h=\frac{w-1}{2}$。对每个位置 $i$，定义窗口下标范围 $[L_i,R_i]$，其中 $L_i=\max(1,i-h)$，$R_i=\min(n,i+h)$。边界处不补值，因此实际窗口大小允许小于 $w$。

对位置 $i$，基于该窗口内第一阶段结果 $a$ 计算：

- 窗口均值 $\mu_i=\frac{1}{R_i-L_i+1}\sum_{j=L_i}^{R_i}a_j$；
- 窗口标准差 $\sigma_i=\sqrt{\frac{1}{R_i-L_i+1}\sum_{j=L_i}^{R_i}(a_j-\mu_i)^2}$。

如果 $|a_i-\mu_i|>k\sigma_i$，则将当前值替换为窗口均值，即 $b_i=\mu_i$；否则保持 $b_i=a_i$。本阶段所有窗口统计量均基于阶段一结束后的序列 $a$，不随本阶段的替换而改变。

**阶段三：z-score 标准化**

对阶段二得到的序列 $b$ 的全部 $n$ 个值，计算全局均值 $\bar{x}$ 和全局标准差 $s$：

$\bar{x}=\frac{1}{n}\sum_{i=1}^{n}b_i$

$s=\sqrt{\frac{1}{n}\sum_{i=1}^{n}(b_i-\bar{x})^2}$

每个位置的标准化值为 $z_i=\frac{b_i-\bar{x}}{s}$。特别地，如果 $s=0$，则最终分数直接定义为 `0`。

**阶段四：最终评分**

根据质量标记定义质量权重 $p_i$：

- 若 $q_i=0$，则 $p_i=1$；
- 若 $q_i=1$，则 $p_i=0.5$；
- 若 $q_i=2$，则 $p_i=0.25$。

取第二阶段结果 $b_i$ 的绝对值，定义原始值权重：

$w_i=\dfrac{p_i|b_i|}{\sum_{j=1}^{n}p_j|b_j|}$

如果分母为 `0`，则最终分数直接定义为 `0`。

综合得到特征分数：

$S=\sum_{i=1}^{n}w_i|z_i|$

最终输出将 $S$ 乘以 `100` 后四舍五入得到的整数。

约束条件

- 记录条数 $n$ 满足 $1\le n\le 10000$。
- 窗口大小 $w$ 满足 $1\le w\le n$，且 $w$ 为奇数。
- 标准差倍数 $k$ 满足 $1\le k\le 10$。
- 数值 $v_i$ 满足 $-10^9\le v_i\le 10^9$。
- 时间戳 $t_i$ 满足 $1\le t_i\le 10^9$，且严格递增。
- 质量标记 $q_i$ 只取 `0`、`1`、`2` 中的一种。
- 至少存在一个 $q_i=0$ 的有效数据记录。

## 输入格式

第一行包含三个整数 $n$、$w$、$k$，分别表示记录数量、移动窗口大小和异常判断使用的标准差倍数。

接下来包含 $n$ 行，其中第 $i$ 行包含三个整数 $t_i$、$v_i$、$q_i$，依次表示第 $i$ 条记录的时间戳、数值和质量标记。

## 输出格式

输出一个整数，表示特征分数 $S$ 乘以 `100` 并四舍五入后的结果。

## 示例

### 示例 1

**输入：**

```
1 1 1
1 5 0
```

**输出：**

```
0
```

**说明：**

只有 `1` 条记录，窗口大小 $w=1$。无效数据修复阶段没有无效记录，因此 $a_1=v_1=5$。

局部异常处理时窗口只包含自身，均值 $\mu_1=5$，标准差 $\sigma_1=0$。由于 $|a_1-\mu_1|=0$，不满足替换条件，所以 $b_1=5$。

第三阶段全局标准差 $s=0$，根据规则最终分数直接定义为 `0`。

### 示例 2

**输入：**

```
3 1 1
1 1 0
2 2 1
3 3 2
```

**输出：**

```
102
```

**说明：**

第一阶段，第 `3` 条记录 $q_3=2$。它左侧最近的 $q=0$ 记录是第 `1` 条，右侧不存在，因此 $a_3=v_1=1$。其余位置保持不变，得到 $a=[1,2,1]$。

第二阶段 $w=1$，每个窗口只包含当前位置，窗口均值等于当前值，标准差为 `0`，因此所有位置均保持原值，$b=[1,2,1]$。

第三阶段全局均值 $\bar{x}=\frac{4}{3}$，全局标准差 $s=\frac{\sqrt{2}}{3}$。

第四阶段质量权重为 $p_1=1$，$p_2=0.5$，$p_3=0.25$。计算分母 $\sum_{j=1}^{3}p_j|b_j|=2.25$。三个位置的 $|z_i|$ 分别为 $\frac{\sqrt{2}}{2}$、$\sqrt{2}$、$\frac{\sqrt{2}}{2}$。加权求和得到 $S\approx1.0214$，乘以 `100` 并四舍五入为 `102`。

### 示例 3

**输入：**

```
3 3 1
1 0 0
2 0 0
3 1 0
```

**输出：**

```
141
```

**说明：**

三条记录均为有效数据，因此无需无效数据修复，$a=[0,0,1]$。

窗口大小 $w=3$，每个位置的窗口都覆盖全部 `3` 条记录，窗口均值 $\mu=\frac{1}{3}$，标准差 $\sigma=\frac{\sqrt{2}}{3}$。位置 `1` 和位置 `2` 的偏差绝对值均为 $\frac{1}{3}$，不大于 $\sigma$，保持原值。位置 `3` 的偏差绝对值为 $\frac{2}{3}$，大于 $\sigma$，因此 $b_3=\mu=\frac{1}{3}$。得到 $b=[0,0,\frac{1}{3}]$。

第三阶段全局均值 $\bar{x}=\frac{1}{9}$，全局标准差 $s=\frac{\sqrt{2}}{9}$。

第四阶段所有 $q_i=0$，所以 $p_i=1$。分母 $\sum p_j|b_j|=\frac{1}{3}$，只有第 `3` 条记录的权重非零。其 $|z_3|=\sqrt{2}$，因此 $S=\sqrt{2}$，乘以 `100` 并四舍五入为 `141`。

## 解题思路

### 第一步：理解问题本质

这道题不需要想算法，需要**严格按公式执行四个阶段**。真正容易出错的地方不在“难”，而在“每个阶段到底用哪条序列”。

把数据处理链路画出来：

| 阶段 | 输入 | 输出 | 关键规则 |
| --- | --- | --- | --- |
| 一、无效数据修复 | 原始 $v$ | 序列 $a$ | 只处理 $q_i=2$，用最近的 $q=0$ 插值 |
| 二、局部异常处理 | 序列 $a$ | 序列 $b$ | 窗口统计量全部来自 $a$，同时写入 $b$ |
| 三、z-score 标准化 | 序列 $b$ | $z_i$ | 用 $b$ 的全局均值与全局标准差 |
| 四、加权评分 | $b$、$z$、原始 $q$ | 一个整数 | 权重用 $q$，绝对值用 $b$ |

三条“不能混”的边界：

1. 阶段二的窗口统计量基于 $a$，**不是**边算边替换之后的 $b$；
2. 阶段三的标准差是**全局**的（对整条序列），不是窗口的；
3. 阶段四的质量权重 $p_i$ 来自**原始质量标记** $q_i$，而不是修复后的状态。

另外两个容易忽略的约定：

- 标准差一律是**总体标准差**：除以元素个数 $m$（或 $n$），不是除以 $m-1$；
- 边界处的窗口**不补值**，实际窗口大小可以小于 $w$。

### 第二步：暴力解法——按定义逐位置重扫窗口

最直白的写法是：每个位置都把窗口里的数重新取出来，算均值和标准差。

```python
import math

half = (w - 1) // 2
b = [0.0] * n
for i in range(n):
    lo = max(0, i - half)
    hi = min(n - 1, i + half)
    window = a[lo:hi + 1]
    m = len(window)
    mu = sum(window) / m
    var = sum((x - mu) ** 2 for x in window) / m
    sigma = math.sqrt(var)
    b[i] = mu if abs(a[i] - mu) > k * sigma else a[i]
```

阶段一如果也照定义做——对每个 $q_i=2$ 的位置分别向左、向右扫到第一个 $q=0$——那一步是 $O(n^2)$；阶段二是 $O(nw)$。本题 $n\le10^4$、$w\le n$，最坏情况下 $10^8$ 次浮点运算，Python 会超时。

两处都能优化掉：阶段一左右各扫一遍就能预处理出每个位置的“最近有效点”，阶段二用前缀和在 $O(1)$ 内拿到窗口的和与平方和。

### 第三步：阶段一与阶段二降到线性

**阶段一：预处理最近的有效点。**

从左往右扫一遍，维护“上一个 $q=0$ 的位置”；每个位置先记录当前值，再看自己是不是 $q=0$，这样得到的自然是**严格左侧**最近的有效点。右侧同理，从右往左扫一遍。

有了这两张表，每个 $q_i=2$ 的位置都能 $O(1)$ 拿到插值端点：

$$
a_i =
\begin{cases}
v_l + \dfrac{(v_r-v_l)(t_i-t_l)}{t_r-t_l}, & l,r \text{ 都存在}\\[4pt]
v_l, & \text{只有 } l\\[2pt]
v_r, & \text{只有 } r\\[2pt]
v_i, & \text{都不存在}
\end{cases}
$$

注意分母是**时间戳之差** $t_r-t_l$，不是下标之差——题目按时间插值，时间戳严格递增所以不会除零。

**阶段二：前缀和求窗口统计量。**

令 $S_1(j)=\sum_{p<j}x_p$、$S_2(j)=\sum_{p<j}x_p^2$，那么窗口 $[lo,hi]$ 内

$$
\sum x = S_1(hi+1)-S_1(lo),\qquad \sum x^2 = S_2(hi+1)-S_2(lo)
$$

于是

$$
\mu=\frac{\sum x}{m},\qquad \sigma^2=\frac{\sum x^2}{m}-\mu^2
$$

这里有一个数值上的坑：如果数值本身很大（例如都接近 $10^9$）而彼此只差一点点，$\sum x^2$ 会把有效数字挤掉，相减得到的方差就不可信。所以先把整条序列平移一个参考值（代码里取 $a_0$）再算前缀和，平方和只涉及“差异”，量级小得多。

还有两处保护：

- 浮点相减可能得到极小的负数，开方前夹回 $0$；
- 比较条件是**严格大于** $k\sigma$，等于阈值时不替换。

### 第四步：阶段三、四与收尾细节

**阶段三**：对 $b$ 求全局均值和总体标准差。若标准差为 $0$（等价于 $b$ 中所有值相同），题目规定最终分数直接为 $0$。

判断“全相等”时用 `max(b) == min(b)`，而不是判断算出来的方差是否等于 $0$：均值本身是浮点累加的结果，可能存在 $10^{-17}$ 量级的抖动，用极值比较既精确又直观。

**阶段四**：质量权重按原始标记取 $1$、$0.5$、$0.25$，然后

$$
w_i=\frac{p_i|b_i|}{\sum_j p_j|b_j|},\qquad S=\sum_i w_i|z_i|
$$

分母为 $0$ 时（所有 $b_i$ 都是 $0$）同样直接输出 $0$。

**四舍五入**：题目要求四舍五入，而 Python 的 `round()` 是“四舍六入五成双”（银行家舍入），`round(0.5)` 得到 `0`。所以用

```python
int(math.floor(S * 100 + 0.5 + 1e-9))
```

末尾的 $10^{-9}$ 是为了让“理论值恰好是 $x.5$”的情况不被浮点误差压到下半区。

**累加精度**：阶段三、四都是对整条序列求和，用 `math.fsum` 做精确求和，比 `sum` 更稳。

## 完整代码实现

```python
"""
P5347. 时序数据修复与加权特征评分 - 四阶段按公式模拟

输入格式：
- 第 1 行：三个整数 n、w、k（w 为奇数）；
- 接下来 n 行：每行三个整数 t_i、v_i、q_i。

输出格式：
- 一个整数，即 S 乘以 100 后四舍五入的结果。

时间复杂度：O(n)
空间复杂度：O(n)
"""

import math
import sys


def solve():
    data = sys.stdin.buffer.read().split()
    if not data:
        return

    it = iter(data)
    n = int(next(it))
    window = int(next(it))
    k = float(next(it))

    times = [0] * n
    values = [0] * n
    quality = [0] * n
    for i in range(n):
        times[i] = int(next(it))
        values[i] = int(next(it))
        quality[i] = int(next(it))

    # ---------------- 阶段一：无效数据修复 ----------------
    # 左边最近的 q=0：先记录再看自己，保证是“严格左侧”
    left_valid = [-1] * n
    last_valid = -1
    for i in range(n):
        left_valid[i] = last_valid
        if quality[i] == 0:
            last_valid = i

    right_valid = [-1] * n
    next_valid = -1
    for i in range(n - 1, -1, -1):
        right_valid[i] = next_valid
        if quality[i] == 0:
            next_valid = i

    a = [0.0] * n
    for i in range(n):
        if quality[i] != 2:
            a[i] = float(values[i])   # 有效数据和可疑数据都原样保留
            continue

        left = left_valid[i]
        right = right_valid[i]
        if left >= 0 and right >= 0:
            # 两端都有：按时间戳线性插值
            v_left = float(values[left])
            v_right = float(values[right])
            a[i] = v_left + (v_right - v_left) * (times[i] - times[left]) / (
                times[right] - times[left]
            )
        elif left >= 0:
            a[i] = float(values[left])
        elif right >= 0:
            a[i] = float(values[right])
        else:
            a[i] = float(values[i])

    # ---------------- 阶段二：局部异常处理 ----------------
    half = (window - 1) // 2

    # 先整体平移 a[0]，再算前缀和：避免“数值很大、差异很小”时
    # 平方和相减丢失有效数字
    reference = a[0]
    diff = [x - reference for x in a]
    prefix = [0.0] * (n + 1)
    prefix_square = [0.0] * (n + 1)
    for i in range(n):
        d = diff[i]
        prefix[i + 1] = prefix[i] + d
        prefix_square[i + 1] = prefix_square[i] + d * d

    b = [0.0] * n
    for i in range(n):
        # 边界处不补值：窗口下标直接截断
        low = i - half
        if low < 0:
            low = 0
        high = i + half
        if high > n - 1:
            high = n - 1
        count = high - low + 1

        sum_d = prefix[high + 1] - prefix[low]
        sum_square = prefix_square[high + 1] - prefix_square[low]

        mean_d = sum_d / count
        variance = sum_square / count - mean_d * mean_d
        if variance < 0.0:
            variance = 0.0          # 浮点相减可能出现极小负数
        sigma = math.sqrt(variance)

        mean = reference + mean_d
        # 严格大于才替换；统计量全部来自 a，不随替换改变
        if abs(a[i] - mean) > k * sigma:
            b[i] = mean
        else:
            b[i] = a[i]

    # ---------------- 阶段三：z-score 标准化 ----------------
    # 全相等 <=> 全局标准差为 0，用极值比较更稳
    if max(b) == min(b):
        print(0)
        return

    mean = math.fsum(b) / n
    variance = math.fsum((x - mean) * (x - mean) for x in b) / n
    std = math.sqrt(variance)

    # ---------------- 阶段四：加权评分 ----------------
    weights = []
    for q in quality:
        if q == 0:
            weights.append(1.0)
        elif q == 1:
            weights.append(0.5)
        else:
            weights.append(0.25)

    denominator = math.fsum(p * abs(x) for p, x in zip(weights, b))
    if denominator == 0.0:
        print(0)
        return

    score = math.fsum(
        (p * abs(x) / denominator) * (abs(x - mean) / std)
        for p, x in zip(weights, b)
    )

    # 四舍五入：round() 是银行家舍入，这里用 floor(x + 0.5)
    print(int(math.floor(score * 100 + 0.5 + 1e-9)))


if __name__ == "__main__":
    solve()
```

### NumPy 版本

> 以下版本使用 NumPy。只有在评测环境允许第三方库时才能提交；CodeFun2000 的普通 Python 环境不一定安装 NumPy。

思路与纯 Python 版完全一致，四个阶段都改成对整条序列的运算：阶段一用 `np.searchsorted` 在有效点下标表上一次定位左右端点；阶段二用 `np.cumsum` 的前缀和、前缀平方和取窗口统计量；阶段三、四都是整数组的广播运算。

```python
"""
P5347. 时序数据修复与加权特征评分 - NumPy 版

四个阶段全部改成对整条序列的向量化运算：
- 阶段一用 np.searchsorted 在“有效点下标表”上一次定位左右端点，再按三种情形取值；
- 阶段二用 np.cumsum 求前缀和/前缀平方和，窗口均值与标准差由切片相减直接得到；
- 阶段三、四都是整数组的广播运算。

时间复杂度：O(n)；空间复杂度：O(n)。
"""

import sys

import numpy as np


def solve():
    data = sys.stdin.buffer.read().split()
    if not data:
        return

    n = int(data[0])
    window = int(data[1])
    k = float(data[2])

    table = np.array(list(map(int, data[3:3 + 3 * n])), dtype=np.int64).reshape(n, 3)
    times = table[:, 0].astype(np.float64)     # 时间戳：阶段一按它插值
    values = table[:, 1].astype(np.float64)
    quality = table[:, 2]

    # ---------------- 阶段一：无效数据修复 ----------------
    # 有效点（q=0）的下标表；对每个 q=2 的位置二分，得到“右侧最近”和“左侧最近”
    valid = np.flatnonzero(quality == 0)
    broken = np.flatnonzero(quality == 2)
    a = values.copy()

    if broken.size and valid.size:
        pos = np.searchsorted(valid, broken, side="left")   # 第一个 >= 自己的有效点
        has_left = pos > 0
        has_right = pos < valid.size
        # q=2 的位置本身不在有效点表里，所以 valid[pos] 严格在右侧、valid[pos-1] 严格在左侧
        left = valid[np.maximum(pos - 1, 0)]
        right = valid[np.minimum(pos, valid.size - 1)]

        v_left = values[left]
        v_right = values[right]
        both = has_left & has_right
        # 两端都有：按时间戳线性插值（分母是时间戳之差，不是下标之差）。
        # 单边存在时显式把分母置 1，避免算出 0 除的 inf/nan（那些位置随后会被丢弃）。
        span = np.where(both, times[right] - times[left], 1.0)
        interp = v_left + (v_right - v_left) * (times[broken] - times[left]) / span
        a[broken] = np.where(
            both,
            interp,
            np.where(has_left, v_left, np.where(has_right, v_right, values[broken])),
        )

    # ---------------- 阶段二：局部异常处理 ----------------
    half = (window - 1) // 2

    # 先整体平移 a[0] 再算前缀和：数值都很大、彼此差异很小时，平方和相减才不会丢有效数字
    reference = a[0]
    diff = a - reference
    prefix = np.zeros(n + 1, dtype=np.float64)
    np.cumsum(diff, out=prefix[1:])
    prefix_square = np.zeros(n + 1, dtype=np.float64)
    np.cumsum(diff * diff, out=prefix_square[1:])

    index = np.arange(n)
    low = np.maximum(index - half, 0)          # 边界处不补值，窗口直接截断
    high = np.minimum(index + half, n - 1)
    count = (high - low + 1).astype(np.float64)

    sum_diff = prefix[high + 1] - prefix[low]
    sum_square = prefix_square[high + 1] - prefix_square[low]

    mean_diff = sum_diff / count
    variance = np.maximum(sum_square / count - mean_diff * mean_diff, 0.0)
    sigma = np.sqrt(variance)                  # 总体标准差，除以元素个数

    mean = reference + mean_diff
    # 严格大于才替换；统计量全部来自 a，不随本阶段的替换而改变
    b = np.where(np.abs(a - mean) > k * sigma, mean, a)

    # ---------------- 阶段三：z-score 标准化 ----------------
    if b.max() == b.min():                     # 全相等 <=> 全局标准差为 0
        print(0)
        return

    mean_b = b.mean()
    std_b = b.std()                            # numpy 的 std 默认 ddof=0，即总体标准差
    # 说明：numpy 的 mean/std/sum 用成对求和，与 math.fsum 的差异在 1e-16 量级，
    # 只要输入不是恰好落在 x.5 的舍入边界上，最终整数完全一致。

    # ---------------- 阶段四：加权评分 ----------------
    # 质量权重来自原始质量标记：q=0 -> 1，q=1 -> 0.5，q=2 -> 0.25
    weights = np.where(quality == 0, 1.0, np.where(quality == 1, 0.5, 0.25))

    numerator = weights * np.abs(b)
    denominator = numerator.sum()
    if denominator == 0.0:
        print(0)
        return

    # 逐项 (p_i|b_i|/分母) * |z_i| 再求和，与公式逐字对应
    score = (numerator / denominator * (np.abs(b - mean_b) / std_b)).sum()

    # 四舍五入：floor(x + 0.5)，末尾 1e-9 防止 x.5 被浮点误差压到下半区
    print(int(np.floor(score * 100 + 0.5 + 1e-9)))


if __name__ == "__main__":
    solve()
```

### 示例 1

$n=1$、$w=1$、$k=1$，唯一记录是 $(t_1,v_1,q_1)=(1,5,0)$。

- 阶段一：没有 $q=2$ 的记录，$a=[5]$；
- 阶段二：$h=0$，窗口只有自己，$\mu=5$、$\sigma=0$，$|a_1-\mu|=0$ 不满足严格大于，$b=[5]$；
- 阶段三：只有一个值，全局标准差 $s=0$，按规则直接输出 $0$。

```text
0
```

### 示例 2

$n=3$、$w=1$、$k=1$，记录为 $(1,1,0)$、$(2,2,1)$、$(3,3,2)$。

**阶段一**：第 3 条 $q=2$，它左边最近的 $q=0$ 是第 1 条，右边没有，所以 $a_3=v_1=1$。第 2 条是 $q=1$（可疑但保留原值），所以

$$
a=[1,\ 2,\ 1]
$$

**阶段二**：$w=1$ 所以 $h=0$，每个窗口只有自己：$\mu_i=a_i$、$\sigma_i=0$，偏差为 $0$ 不满足严格大于，全部保持原值：

$$
b=[1,\ 2,\ 1]
$$

**阶段三**：

$$
\bar x=\frac{1+2+1}{3}=\frac43,\qquad
s=\sqrt{\frac{(1-\frac43)^2+(2-\frac43)^2+(1-\frac43)^2}{3}}
=\sqrt{\frac{2}{9}}=\frac{\sqrt2}{3}
$$

三个 $|z_i|$ 分别是

$$
|z_1|=\frac{1/3}{\sqrt2/3}=\frac{\sqrt2}{2},\quad
|z_2|=\frac{2/3}{\sqrt2/3}=\sqrt2,\quad
|z_3|=\frac{\sqrt2}{2}
$$

**阶段四**：$q=[0,1,2]$，所以 $p=[1,\ 0.5,\ 0.25]$，$|b|=[1,2,1]$，

$$
\sum_j p_j|b_j|=1\times1+0.5\times2+0.25\times1=2.25
$$

三个权重分别是 $1/2.25$、$1/2.25$、$0.25/2.25$，于是

$$
S=\frac{1}{2.25}\cdot\frac{\sqrt2}{2}
+\frac{1}{2.25}\cdot\sqrt2
+\frac{0.25}{2.25}\cdot\frac{\sqrt2}{2}
\approx 1.0214
$$

$S\times100\approx102.14$，四舍五入为 `102`。

### 示例 3

$n=3$、$w=3$、$k=1$，三条记录都是 $q=0$，值为 $[0,0,1]$，所以 $a=[0,0,1]$。

**阶段二**：$h=(3-1)/2=1$，每个位置的窗口按 $[L_i,R_i]=[\max(1,i-h),\min(3,i+h)]$ 截断（下标从 1 起）：

| 位置 | 窗口 | 窗口均值 $\mu$ | 标准差 $\sigma$ | $\lvert a_i-\mu\rvert$ | 是否 $>k\sigma$ | $b_i$ |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | $[1,2]$ | $0$ | $0$ | $0$ | 否 | $0$ |
| 2 | $[1,3]$ | $1/3$ | $\sqrt2/3\approx0.4714$ | $1/3\approx0.3333$ | 否 | $0$ |
| 3 | $[2,3]$ | $1/2$ | $1/2$ | $1/2$ | 否（严格大于才替换） | $1$ |

所以 $b=[0,0,1]$。

**阶段三**：

$$
\bar x=\frac{0+0+1}{3}=\frac13,\qquad
s=\sqrt{\frac{1/9+1/9+4/9}{3}}=\sqrt{\frac{2}{9}}=\frac{\sqrt2}{3}
$$

$|z_1|=|z_2|=\frac{\sqrt2}{2}$，$|z_3|=\sqrt2$。

**阶段四**：所有 $q_i=0$，所以 $p_i=1$；$\sum p_j|b_j|=1$。只有第 3 条的 $|b_i|$ 非零，因此它的权重是 $1$，另外两条是 $0$：

$$
S=1\times\sqrt2=\sqrt2\approx1.41421
$$

$S\times100\approx141.42$，四舍五入为 `141`。

> 说明：题面的示例说明把三个窗口都描述成覆盖全部记录；按形式化定义（“边界处不补值”），位置 1 和位置 3 的窗口会截断成 2 个元素。两种口径都得到 $S=\sqrt2$：因为截断口径下的 $b=[0,0,1]$ 与整窗口径下的 $b=[0,0,\frac13]$ 只差一个全局缩放系数，而 $z_i$ 和权重都对统一的缩放不敏感。实现以形式化定义为准。

## 易错点总结

### 1. 阶段二边算边改

题目说得很清楚：本阶段所有窗口统计量都基于阶段一结束后的 $a$。如果一边替换 $a_i$ 一边算后面的窗口，后面的窗口就会混入被替换过的值，误差会沿着序列一路传播。正确做法是**读 $a$、写 $b$**，两个数组分开。

### 2. 边界窗口没有截断

$L_i=\max(1,i-h)$、$R_i=\min(n,i+h)$，所以两端的窗口会变窄，窗口大小小于 $w$。若补零或补边界值凑满 $w$，均值与标准差都会被拉偏。

### 3. 把标准差算成样本标准差

题目公式里分母是元素个数（$1/(R_i-L_i+1)$ 和 $1/n$），是**总体**标准差。写成 $m-1$ 或 $n-1$（样本标准差）会让阈值和 $z_i$ 都发生偏移。

### 4. 阶段一找的是“最近的有效点”，不是“最近的记录”

$q=1$ 的记录是可疑数据，**不能**用来插值；只有 $q=0$ 才是插值端点。同时 $q=1$ 自身的值保持不变（$a_i=v_i$），它既不参与修复别人，也不被别人修复。

### 5. 插值用下标差除

$t_i$、$t_l$、$t_r$ 是**时间戳**，不是下标。时间戳可能间隔很不均匀（例如 $1,2,1000$），按下标插值会得到完全不同的结果。分母是 $t_r-t_l$。

### 6. 阶段四的权重与绝对值取错来源

- 质量权重 $p_i$ 来自**原始** $q_i$，不是修复后的状态；
- $w_i$ 里用的是阶段二结果 $b_i$ 的绝对值，不是 $a_i$，也不是 $v_i$。

### 7. 忘记两条“直接输出 0”

- 全局标准差 $s=0$：所有 $b_i$ 相同；
- 分母 $\sum p_j|b_j|=0$：所有 $b_i$ 都是 $0$。

这两种情况都要在除法之前短路，否则会除零或得到 `nan`。

### 8. 用 `round()` 做四舍五入

Python 的 `round` 采用银行家舍入，`round(2.5)=2`、`round(3.5)=4`。题目要的是通常意义的四舍五入，应使用 `floor(x + 0.5)`。

### 9. 方差用 $\mathbb{E}[x^2]-\mathbb{E}[x]^2$ 时不做保护

当前缀和相减得到极小的负数时，`math.sqrt` 会抛 `ValueError: math domain error`。开方前夹回 $0$；数值量级很大时先把序列平移一个参考值，减少有效数字损失。

### 10. 判断“标准差为 0”用浮点等值

直接写 `if s == 0` 依赖均值累加的精确性。用 `max(b) == min(b)` 判断“所有值相同”更可靠，也正好等价于数学上的 $s=0$。

## 扩展思考

- **更稳健的异常判定**：均值和标准差本身会被异常值拉偏（掩蔽效应）。工程上常用中位数与 MAD（中位数绝对偏差）代替，或者用滑动中位数，判断逻辑仍然是“偏差超过 $k$ 倍尺度”。
- **流式数据**：如果记录是一条条到达的，阶段二的窗口可以用双端队列 + 增量维护和与平方和，做到 $O(1)$ 摊还；但要注意增量更新会累积浮点误差，必要时定期重算。
- **统一缩放不变性**：$z_i$ 对 $b$ 的平移和缩放都不敏感，权重 $w_i$ 对统一缩放也不敏感。所以真正影响 $S$ 的只有 $b$ 的**相对形状**。这解释了示例 3 中两种窗口口径为什么给出同一个答案。
- **精确算术**：本题的输入都是整数，理论上插值后的值是有理数，可以用 `fractions.Fraction` 精确计算，再用 `decimal` 做最后的舍入。代价是速度慢很多，只适合对边界舍入极度敏感的场合。
- **多通道时序**：如果每条记录带多个数值通道，四个阶段都要对每个通道分别执行，最后再把各通道的分数加权合并。
