# P5347. 时序数据修复与加权特征评分

> 场次：2026年9月4日 · 来源：[CodeFun2000 P5347](https://codefun2000.com/p/P5347)

## 题目描述

某数据采集系统按时间顺序获取了 $n$ 条记录，每条记录包含时间戳 $t_i$、数值 $v_i$ 和质量标记 $q_i$。

其中，质量标记用于表示数据状态：当 $q_i$ 为 $0$ 时表示数据有效，当 $q_i$ 为 $1$ 时表示数据存在可疑情况，当 $q_i$ 为 $2$ 时表示数据无效。系统需要按照无效数据修复、局部异常处理、标准化以及评分计算的顺序依次完成数据处理流程。

**阶段一：无效数据修复**

对每个满足 $q_i=2$ 的位置 $i$，分别寻找其左侧和右侧最近的满足 $q=0$ 的有效数据下标，记为 $l$ 和 $r$。如果不存在，则对应下标视为未找到。

- 若 $l$ 和 $r$ 均存在，则按时间戳做线性插值：
  $a_i=v_l+\dfrac{(v_r-v_l)(t_i-t_l)}{t_r-t_l}$。
- 若只存在 $l$，则 $a_i=v_l$。
- 若只存在 $r$，则 $a_i=v_r$。
- 若 $l$ 和 $r$ 均不存在，则 $a_i=v_i$。

其余非无效数据的值保持不变，即 $a_i=v_i$。完成本阶段后得到序列 $a$。

**阶段二：局部异常处理**

设 $w$ 为奇数，令半径 $h=\frac{w-1}{2}$。对每个位置 $i$，定义窗口下标范围 $[L_i,R_i]$，其中 $L_i=\max(1,i-h)$，$R_i=\min(n,i+h)$。边界处不补值，因此实际窗口大小允许小于 $w$。

对位置 $i$，基于该窗口内第一阶段结果 $a$ 计算：

- 窗口均值 $\mu_i=\frac{1}{R_i-L_i+1}\sum_{j=L_i}^{R_i}a_j$；
- 窗口标准差 $\sigma_i=\sqrt{\frac{1}{R_i-L_i+1}\sum_{j=L_i}^{R_i}(a_j-\mu_i)^2}$。

如果 $|a_i-\mu_i|>k\sigma_i$，则将当前值替换为窗口均值，即 $b_i=\mu_i$；否则保持 $b_i=a_i$。本阶段所有窗口统计量均基于阶段一结束后的序列 $a$，不随本阶段的替换而改变。

**阶段三：z-score 标准化**

对阶段二得到的序列 $b$ 的全部 $n$ 个值，计算全局均值 $\bar{x}$ 和全局标准差 $s$：

$\bar{x}=\frac{1}{n}\sum_{i=1}^{n}b_i$

$s=\sqrt{\frac{1}{n}\sum_{i=1}^{n}(b_i-\bar{x})^2}$

每个位置的标准化值为 $z_i=\frac{b_i-\bar{x}}{s}$。特别地，如果 $s=0$，则最终分数直接定义为 `0`。

**阶段四：最终评分**

根据质量标记定义质量权重 $p_i$：

- 若 $q_i=0$，则 $p_i=1$；
- 若 $q_i=1$，则 $p_i=0.5$；
- 若 $q_i=2$，则 $p_i=0.25$。

取第二阶段结果 $b_i$ 的绝对值，定义原始值权重：

$w_i=\dfrac{p_i|b_i|}{\sum_{j=1}^{n}p_j|b_j|}$

如果分母为 `0`，则最终分数直接定义为 `0`。

综合得到特征分数：

$S=\sum_{i=1}^{n}w_i|z_i|$

最终输出将 $S$ 乘以 `100` 后四舍五入得到的整数。

约束条件

- 记录条数 $n$ 满足 $1\le n\le 10000$。
- 窗口大小 $w$ 满足 $1\le w\le n$，且 $w$ 为奇数。
- 标准差倍数 $k$ 满足 $1\le k\le 10$。
- 数值 $v_i$ 满足 $-10^9\le v_i\le 10^9$。
- 时间戳 $t_i$ 满足 $1\le t_i\le 10^9$，且严格递增。
- 质量标记 $q_i$ 只取 `0`、`1`、`2` 中的一种。
- 至少存在一个 $q_i=0$ 的有效数据记录。

## 输入格式

第一行包含三个整数 $n$、$w$、$k$，分别表示记录数量、移动窗口大小和异常判断使用的标准差倍数。

接下来包含 $n$ 行，其中第 $i$ 行包含三个整数 $t_i$、$v_i$、$q_i$，依次表示第 $i$ 条记录的时间戳、数值和质量标记。

## 输出格式

输出一个整数，表示特征分数 $S$ 乘以 `100` 并四舍五入后的结果。

## 示例

### 示例 1

**输入：**

```
1 1 1
1 5 0
```

**输出：**

```
0
```

**说明：**

只有 `1` 条记录，窗口大小 $w=1$。无效数据修复阶段没有无效记录，因此 $a_1=v_1=5$。

局部异常处理时窗口只包含自身，均值 $\mu_1=5$，标准差 $\sigma_1=0$。由于 $|a_1-\mu_1|=0$，不满足替换条件，所以 $b_1=5$。

第三阶段全局标准差 $s=0$，根据规则最终分数直接定义为 `0`。

### 示例 2

**输入：**

```
3 1 1
1 1 0
2 2 1
3 3 2
```

**输出：**

```
102
```

**说明：**

第一阶段，第 `3` 条记录 $q_3=2$。它左侧最近的 $q=0$ 记录是第 `1` 条，右侧不存在，因此 $a_3=v_1=1$。其余位置保持不变，得到 $a=[1,2,1]$。

第二阶段 $w=1$，每个窗口只包含当前位置，窗口均值等于当前值，标准差为 `0`，因此所有位置均保持原值，$b=[1,2,1]$。

第三阶段全局均值 $\bar{x}=\frac{4}{3}$，全局标准差 $s=\frac{\sqrt{2}}{3}$。

第四阶段质量权重为 $p_1=1$，$p_2=0.5$，$p_3=0.25$。计算分母 $\sum_{j=1}^{3}p_j|b_j|=2.25$。三个位置的 $|z_i|$ 分别为 $\frac{\sqrt{2}}{2}$、$\sqrt{2}$、$\frac{\sqrt{2}}{2}$。加权求和得到 $S\approx1.0214$，乘以 `100` 并四舍五入为 `102`。

### 示例 3

**输入：**

```
3 3 1
1 0 0
2 0 0
3 1 0
```

**输出：**

```
141
```

**说明：**

三条记录均为有效数据，因此无需无效数据修复，$a=[0,0,1]$。

窗口大小 $w=3$，每个位置的窗口都覆盖全部 `3` 条记录，窗口均值 $\mu=\frac{1}{3}$，标准差 $\sigma=\frac{\sqrt{2}}{3}$。位置 `1` 和位置 `2` 的偏差绝对值均为 $\frac{1}{3}$，不大于 $\sigma$，保持原值。位置 `3` 的偏差绝对值为 $\frac{2}{3}$，大于 $\sigma$，因此 $b_3=\mu=\frac{1}{3}$。得到 $b=[0,0,\frac{1}{3}]$。

第三阶段全局均值 $\bar{x}=\frac{1}{9}$，全局标准差 $s=\frac{\sqrt{2}}{9}$。

第四阶段所有 $q_i=0$，所以 $p_i=1$。分母 $\sum p_j|b_j|=\frac{1}{3}$，只有第 `3` 条记录的权重非零。其 $|z_3|=\sqrt{2}$，因此 $S=\sqrt{2}$，乘以 `100` 并四舍五入为 `141`。

## 解题思路

### 一张数据流图先立起来

四个阶段的公式一个比一个长，但决定成败的不是公式本身，而是**每个公式从哪条序列取数**。把链路钉死，写程序就是翻译：

$$v \longrightarrow a \longrightarrow b \longrightarrow z, \qquad S \text{ 由 } b \text{ 的绝对值加权 } |z_i| \text{ 合成，权重来自原始 } q$$

各阶段的取数口径：

| 阶段 | 读 | 写 | 关键口径 |
| --- | --- | --- | --- |
| 一、无效修复 | 原始 $v$、$q$ | $a$ | 插值端点只能是 $q=0$；$q=1$ 原样保留、不外借 |
| 二、局部异常 | $a$ | $b$ | 窗口统计量全部来自 $a$，读 $a$ 写 $b$ |
| 三、z-score | $b$ | $z$ | 全局均值、**总体**标准差；$s=0$ 直接输出 0 |
| 四、加权评分 | $b$、原始 $q$ | $S$ | 权重 $p$ 按原始 $q$；绝对值取自 $b$ |

两条容易被扫过去的约定也属于这一层：所有标准差都除以元素个数（总体标准差，不是 $m-1$）；窗口在边界处不补值，实际大小允许小于 $w$。

### 数据范围给出的阶梯：两处平方级都能消掉

$n\le10^4$、$w$ 可以到 $n$。完全按定义写：阶段一给每个 $q=2$ 的位置往左、往右各扫到第一个有效点，最坏 $O(n^2)$；阶段二每个位置重取窗口算均值方差，$O(nw)$，最坏 $10^8$ 次浮点运算，Python 必超时。这两个平方级不需要换公式，只需要换个取数方式：

- 阶段一的「左侧最近的 $q=0$」对**全部位置**一次扫描就能得到：维护「上一个有效点」，先记录给当前位置、再检查自己，得到的就是严格左侧；反向扫一遍同理。这样每个无效点 $O(1)$ 拿到两端端点。插值分母是 $t_r-t_l$（时间戳差，输入保证严格递增所以不会除零），不是下标差。
- 阶段二为整条 $a$ 预扫出前缀和 $\sum x$ 与前缀平方和 $\sum x^2$，每个窗口 $O(1)$ 内取 $\mu$ 与 $\sigma^2=\frac{\sum x^2}{m}-\mu^2$。

### 三个浮点保护是真实决策，不是装饰

输入在 $10^9$ 量级，浮点实现的每一步都得能报出理由：

1. **先平移再做前缀平方和**（代码 `reference = a[0]`）。数值巨大而彼此只差一点时，平方和相减会把有效数字挤光，方差整个不可信；平移后平方项只剩「差异部分」，量级骤降。
2. **方差负值夹回 0 再开方**：$\frac{\sum x^2}{m}-\mu^2$ 浮点相减可能出现 $10^{-17}$ 量级的负数，`sqrt` 直接抛异常；比较时**严格大于**才替换，等于阈值不换。
3. **四舍五入不用 `round()`**：Python 的 `round` 是四舍六入五成双（`round(2.5)==2`）。用 `floor(x+0.5+1e-9)`，末尾的 $10^{-9}$ 护住「理论值恰好落在 $x.5$」时被浮点误差压到下半区；整条序列的全局求和交给 `math.fsum`。

两个「直接输出 0」的短路都放在除法之前：全局标准差为 0 等价于 $b$ 全相等，用 `max(b) == min(b)` 判断，比「算出的方差是否等于 0」更稳；阶段四分母 $\sum_j p_j|b_j|$ 为 0 时同理。

## 完整代码实现

```python
"""
P5347. 时序数据修复与加权特征评分 - 四阶段按公式模拟

输入格式：
- 第 1 行：三个整数 n、w、k（w 为奇数）；
- 接下来 n 行：每行三个整数 t_i、v_i、q_i。

输出格式：
- 一个整数，即 S 乘以 100 后四舍五入的结果。

时间复杂度：O(n)
空间复杂度：O(n)
"""

import math
import sys


def solve():
    data = sys.stdin.buffer.read().split()
    if not data:
        return

    it = iter(data)
    n = int(next(it))
    window = int(next(it))
    k = float(next(it))

    times = [0] * n
    values = [0] * n
    quality = [0] * n
    for i in range(n):
        times[i] = int(next(it))
        values[i] = int(next(it))
        quality[i] = int(next(it))

    # ---------------- 阶段一：无效数据修复 ----------------
    # 左边最近的 q=0：先记录再看自己，保证是“严格左侧”
    left_valid = [-1] * n
    last_valid = -1
    for i in range(n):
        left_valid[i] = last_valid
        if quality[i] == 0:
            last_valid = i

    right_valid = [-1] * n
    next_valid = -1
    for i in range(n - 1, -1, -1):
        right_valid[i] = next_valid
        if quality[i] == 0:
            next_valid = i

    a = [0.0] * n
    for i in range(n):
        if quality[i] != 2:
            a[i] = float(values[i])   # 有效数据和可疑数据都原样保留
            continue

        left = left_valid[i]
        right = right_valid[i]
        if left >= 0 and right >= 0:
            # 两端都有：按时间戳线性插值
            v_left = float(values[left])
            v_right = float(values[right])
            a[i] = v_left + (v_right - v_left) * (times[i] - times[left]) / (
                times[right] - times[left]
            )
        elif left >= 0:
            a[i] = float(values[left])
        elif right >= 0:
            a[i] = float(values[right])
        else:
            a[i] = float(values[i])

    # ---------------- 阶段二：局部异常处理 ----------------
    half = (window - 1) // 2

    # 先整体平移 a[0]，再算前缀和：避免“数值很大、差异很小”时
    # 平方和相减丢失有效数字
    reference = a[0]
    diff = [x - reference for x in a]
    prefix = [0.0] * (n + 1)
    prefix_square = [0.0] * (n + 1)
    for i in range(n):
        d = diff[i]
        prefix[i + 1] = prefix[i] + d
        prefix_square[i + 1] = prefix_square[i] + d * d

    b = [0.0] * n
    for i in range(n):
        # 边界处不补值：窗口下标直接截断
        low = i - half
        if low < 0:
            low = 0
        high = i + half
        if high > n - 1:
            high = n - 1
        count = high - low + 1

        sum_d = prefix[high + 1] - prefix[low]
        sum_square = prefix_square[high + 1] - prefix_square[low]

        mean_d = sum_d / count
        variance = sum_square / count - mean_d * mean_d
        if variance < 0.0:
            variance = 0.0          # 浮点相减可能出现极小负数
        sigma = math.sqrt(variance)

        mean = reference + mean_d
        # 严格大于才替换；统计量全部来自 a，不随替换改变
        if abs(a[i] - mean) > k * sigma:
            b[i] = mean
        else:
            b[i] = a[i]

    # ---------------- 阶段三：z-score 标准化 ----------------
    # 全相等 <=> 全局标准差为 0，用极值比较更稳
    if max(b) == min(b):
        print(0)
        return

    mean = math.fsum(b) / n
    variance = math.fsum((x - mean) * (x - mean) for x in b) / n
    std = math.sqrt(variance)

    # ---------------- 阶段四：加权评分 ----------------
    weights = []
    for q in quality:
        if q == 0:
            weights.append(1.0)
        elif q == 1:
            weights.append(0.5)
        else:
            weights.append(0.25)

    denominator = math.fsum(p * abs(x) for p, x in zip(weights, b))
    if denominator == 0.0:
        print(0)
        return

    score = math.fsum(
        (p * abs(x) / denominator) * (abs(x - mean) / std)
        for p, x in zip(weights, b)
    )

    # 四舍五入：round() 是银行家舍入，这里用 floor(x + 0.5)
    print(int(math.floor(score * 100 + 0.5 + 1e-9)))


if __name__ == "__main__":
    solve()
```

## 示例推演

### 样例 2：四个阶段走完一遍

输入 $n=3,w=1,k=1$，记录 $(1,1,0),(2,2,1),(3,3,2)$。

**阶段一**：只有第 3 条无效。左侧最近的 $q=0$ 是第 1 条，右侧不存在，$a_3=v_1=1$；$q=1$ 的第 2 条原样保留。$a=[1,2,1]$。

**阶段二**：$w=1$，每个窗口只有自身，$\mu_i=a_i$、$\sigma_i=0$，偏差 0 不大于阈值，$b=[1,2,1]$。

**阶段三**：

$$
\bar x=\frac{1+2+1}{3}=\frac43,\qquad
s=\sqrt{\frac{2}{9}}=\frac{\sqrt2}{3},\qquad
|z_i| = \frac{\sqrt2}{2},\ \sqrt2,\ \frac{\sqrt2}{2}
$$

**阶段四**：$p=[1,\ 0.5,\ 0.25]$，分母 $\sum p_j|b_j|=1\times1+1\times2+0.25\times1=2.25$，

$$
S=\frac{1}{2.25}\cdot\frac{\sqrt2}{2}
+\frac{1}{2.25}\cdot\sqrt2
+\frac{0.25}{2.25}\cdot\frac{\sqrt2}{2}
\approx 1.0214
$$

$S\times100\approx102.14$，四舍五入输出 `102`。

### 样例 3：异常替换与边界窗口

三条记录都是 $q=0$，$a=[0,0,1]$；$h=1$。每个位置的窗口边界截断后为：

| 位置 | 窗口 | $\mu$ | $\sigma$ | $\lvert a_i-\mu\rvert$ | 是否超过 $k\sigma$ | $b_i$ |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | $[1,2]$ | $0$ | $0$ | $0$ | 否 | $0$ |
| 2 | $[1,3]$ | $1/3$ | $\sqrt2/3$ | $1/3$ | 否 | $0$ |
| 3 | $[2,3]$ | $1/2$ | $1/2$ | $1/2$ | 否（等于阈值不替换） | $1$ |

得到 $b=[0,0,1]$。全局 $\bar x=\frac13$、$s=\frac{\sqrt2}{3}$；只有第 3 条 $|b_i|$ 非零，权重为 1，$S=\sqrt2\approx1.4142$，输出 `141`。

> 题面的示例说明把位置 1、3 的窗口写成覆盖全部记录；按「边界不补值」的形式化定义，窗口会截断成 2 个元素。两种口径殊途同归：截断口径的 $b=[0,0,1]$ 与整窗口径的 $b=[0,0,\frac13]$ 只差一个全局缩放系数，而 $z_i$ 与权重 $w_i$ 都对统一缩放不敏感，$S$ 相同。实现以形式化定义为准。

### 样例 1：短路分支的样例

只有一条记录且无失效点：$a=[5]$，窗口只含自身不替换，$b=[5]$，全局标准差为 0，直接输出 `0`——验证的就是「$s=0$ 短路」这条规则。

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| ---- | ---------- | ---------- | ---- |
| 完全按定义（阶段一逐点往回扫 + 阶段二重取窗口） | $O(n^2+nw)$ | $O(n)$ | $n=10^4$、$w\approx n$ 时约 $10^8$ 次浮点运算，Python 超时 |
| 双向预扫最近有效点 + 前缀和窗口统计（最优） | $O(n)$ | $O(n)$ | 四个阶段全部线性，瓶颈只剩输入解析与浮点求和 |

$n\le10^4$，线性做法约 $10^5$ 量级运算，轻松通过。

## 易错点总结

### 1. 阶段二边算边改

阶段二先对**整条 $a$** 建前缀和，再逐位置写出 $b_i$（代码里 `prefix`/`prefix_square` 与 `b` 分属两段）。若把替换出的均值直接写回序列继续算后面的窗口，后续窗口统计量就不再是题面要求的「基于 $a$」，异常点判定会越算越偏，且答案随实现顺序漂移。

### 2. 插值端点写错来源

位置在 `if quality[i] == 0: last_valid = i`——只有 $q=0$ 能登记为插值端点。若顺手把 $q=1$（可疑）也算进来，修复出的 $a_i$ 就取错了值，后面的阈值判断跟着错。可疑记录的定位是「值原样保留、不修复别人、也不被别人修复」。

### 3. 用 `round()` 做四舍五入

位置在 `int(math.floor(score * 100 + 0.5 + 1e-9))`。Python 的 `round` 是银行家舍入，恰好落在 $x.5$ 边界的分数会向下舍，输出比正确答案少 1；样例 2 的 $102.14$ 离边界远，体现不出差异，压界的输入只会来自极端构造的数据。

## 扩展思考

- 均值与标准差本身会被离群值拉偏（掩蔽效应），工程上常用中位数与 MAD（中位数绝对偏差）替换这两个统计量，判断逻辑仍是「偏差超过 $k$ 倍尺度」。
- 流式到达的数据可以用双端队列 + 增量维护和与平方和，摊还 $O(1)$；增量更新会积累浮点误差，必要时定期重算。
