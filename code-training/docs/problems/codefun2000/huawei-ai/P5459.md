# P5459. 骨干网管理域划分

> 场次：2026年9月16日 · 来源：[CodeFun2000 P5459](https://codefun2000.com/p/P5459)

## 题目描述

某省骨干网中部署了多台核心路由器。为提升运维效率，要把这些地理位置分散的设备在逻辑上划成 $N$ 个管理域，并尽量让同一域内的设备彼此靠近，便于统一调度。

划分采用 Bi-K-means（二分 K-means）：一开始把全部设备看成一个簇 $C_0$，之后反复分裂当前最适合的簇，直到簇的个数等于 $N$。

SSE（误差平方和）定义为

$$SSE(C)=\sum_{p\in C}\lVert p-\mu\rVert^2,$$

其中 $\mu$ 是簇 $C$ 的质心（各点坐标的算术平均）。将一个父簇裂成两个子簇时，SSE 下降量为

$$SSE\_Grad=SSE(C_{\mathrm{parent}})-(SSE(C_{\mathrm{child1}})+SSE(C_{\mathrm{child2}})).$$

每一次从当前簇集合里选出一个簇，对其做 $K=2$ 的 K-means 分裂，规则如下：

1. 优先选择 $SSE\_Grad$ 最大的簇；若下降量相同，选择设备数更多的簇；若设备数也相同，选择生成时间更早的簇。初始簇 $C_0$ 的生成时间最早；每次分裂得到的两个子簇按「先归入 $x$ 最小初始质心一侧、后归入 $x$ 最大初始质心一侧」依次生成，且都晚于其父簇。
2. 对选中的簇做 2-means 时，必须取该簇内 $x$ 坐标最小和 $x$ 坐标最大的两个设备作为初始质心，禁止随机初始化。
3. 若某设备到两个质心的欧氏距离相等，则划入 $x$ 坐标较小的那个初始质心所在簇。
4. 2-means 在下列任一条件成立时停止：两个新质心的最大偏移量（欧氏距离）小于 $1e-6$；或所有设备的簇归属不再变化。
5. 外层分裂进行到簇数等于 $N$ 为止。第 $0$ 次结果是尚未分裂的初始簇。

## 输入格式

第一行一个整数 $N$，表示期望得到的管理域（簇）个数，满足 $1\le N\le 20$。

第二行一个整数 $L$，表示核心路由器台数，满足 $1\le L\le 100$。

随后 $L$ 行，每行两个整数 $x$ $y$，表示一台路由器的二维坐标（经度、纬度）。坐标均为整数，满足 $0\le x,y\le 1000$，且不同路由器的 $x$ 坐标互不相同。

## 输出格式

输出 Bi-K-means 每一轮分裂后，当前各簇设备数的降序序列。初始簇 $C_0$ 的设备数作为第 $0$ 次的结果。共输出 $N$ 行，第 $i$ 行对应已经得到 $i+1$ 个簇时的规模列表（同一行内以空格分隔）。

4

```

**输出：**

```

**说明：**

$4$ 个点要划成 $3$ 个管理域。

第 $1$ 次：对 $C_0$ 做 2-means，初始质心取 $x$ 最小的 $(0,0)$ 与 $x$ 最大的 $(9,1)$。归属稳定后得到两个规模为 $2$ 的簇：$\lbrace(0,0),(1,0)\rbrace$ 与 $\lbrace(8,0),(9,1)\rbrace$，降序为 $2\ 2$。

## 解题思路

### 题面给出的就是全部算法：确定性的两级流程

本题的题眼不在「想算法」而在「钉规则」。普通 K-means 依赖随机初始化，同一份输入可能得到不同划分；机考要求唯一答案，于是每一步的选择都被题面写死：裂哪个簇按「$SSE\_Grad$ 最大 → 设备数多 → 生成时间早」三级定夺；怎么裂用初始化固定的 2-means（初始质心取簇内 $x$ 最小与 $x$ 最大的两个设备，距离相等归 $x$ 小那侧，两个停止条件任一成立即停）。这些不是练习题的装饰，是实现不可偏离的规格。

有一处对照值得记下：把 $m$ 个点裂成两个非空子集，真正的最优二分要枚举 $2^{m-1}-1$ 种划分、每种算两个子簇的 SSE 再取最小。题面用固定初始化的 2-means 把这个指数项换成一个确定的小迭代——不保证最优，但每一步可复现，而且 $L\le100$ 时枚举那条路（$2^{99}$）根本走不通。所以正确的姿态不是「找一个更聪明的算法」，而是把规则一项项执行到位。

### 数据范围决定了「每轮全量重算」是最稳的实现

$N\le20$、$L\le100$。第 $i$ 轮一共 $i+1$ 个候选簇，对每个可分裂簇完整跑一遍 2-means（每次迭代把成员扫一遍，$O(m)$；迭代次数通常个位数），单轮工作量在万级以内。这个预算让「不缓存」成为显然的选择：每一轮把全部候选重算，就不存在「父簇成员变了、缓存还停在旧值」这类错误的空间；省重算的缓存优化在这个量级只增加风险。

### 规则到代码的映射

各组规则都能在代码里指出落点：

1. **初始质心取 $x$ 最小/最大的设备**：建簇时把成员按 $x$ 升序排好（`sorted(..., key=lambda i: points[i][0])`），`two_means` 直接取首尾两个下标。升序还顺带保证两个初始质心不同、两侧初始都非空，迭代不会一上来退化；分裂得到的子簇继承这个顺序，后续轮次继续成立。
2. **距离相等归 $x$ 较小侧**：判断写成 `da <= db`，且 $x$ 较小的质心固定在 `a` 侧。
3. **停止条件是「或」**：`shift < CENTROID_EPS or new_labels == labels`，两个条件盯的是不同信号（质心微动、归属定住），任一成立即停。
4. **三级平局**：`solve()` 里的三段比较依次是 `gain` 更大（带 `GRAD_EPS` 容差）、并列看成员数、再并列看 `born` 更早。容差不是防御性摆设：两个理论上相等的 $SSE\_Grad$ 可能因浮点求和顺序差出 $10^{-16}$，没有它就永远轮不到后两级规则出场。
5. **生成时间**：`clock` 计数器，$C_0$ 为 $0$；每次分裂先给 $x$ 较小侧的子簇 `clock`、再给 $x$ 较大侧 `clock+1`，然后 $+2$。`two_means` 的返回顺序固定「先小侧、后大侧」，正是为了让调用方照抄就不错。
6. **输出**：每轮把当前各簇规模**降序**排列；第 0 行是还没分裂时的 $L$。

还有一个位置必须指出：SSE_Grad 要等 2-means 真正收敛后算（`split_gain` 先调 `two_means`，再对停止时刻的两个子簇求 SSE）。下降量等于父簇 SSE 减两个子簇 SSE，而子簇划分由停止时刻的归属决定；只跑一轮分配、或拿「父簇 SSE 的一半」近似，得到的下降量都与真实不同——候选簇一多，排序就可能颠倒，从选错那一轮起每行规模列表全错。

## 完整代码实现

```python
import math
import sys

# 2-means 的质心偏移阈值，题面规定为 1e-6。
CENTROID_EPS = 1e-6

# SSE_Grad 的并列判定容差。浮点累加会有末位误差，直接用 == 比较会把
# “本来相等”的两个下降量判成不等，从而破坏“同分看设备数 / 生成时间”的规则。
GRAD_EPS = 1e-12


def squared_distance(p, q):
    """两点欧氏距离的平方。比较远近时不必开方，避免多余误差。"""
    dx = p[0] - q[0]
    dy = p[1] - q[1]
    return dx * dx + dy * dy


def sse_of(points, indices, center):
    """簇内所有点到给定质心的距离平方和。"""
    return sum(squared_distance(points[i], center) for i in indices)


def mean_point(points, indices):
    """簇内所有点坐标的算术平均，即质心。"""
    sx = sum(points[i][0] for i in indices)
    sy = sum(points[i][1] for i in indices)
    n = len(indices)
    return (sx / n, sy / n)


def two_means(points, indices):
    """
    对已按 x 升序排列的下标列表做 2-means，返回两个子簇的下标列表。

    返回值顺序固定：第 1 个子簇对应“x 最小的初始质心”，
    第 2 个子簇对应“x 最大的初始质心”，这样调用方可以直接按题面规则
    给它们分配生成时间。
    """
    # 初始质心必须取簇内 x 最小、x 最大的两个设备。
    centroid_a = points[indices[0]]
    centroid_b = points[indices[-1]]

    def assign(center_a, center_b):
        """按最近的质心分配；距离相等时归入 a（a 的初始质心 x 更小）。"""
        labels = []
        for idx in indices:
            p = points[idx]
            da = squared_distance(p, center_a)
            db = squared_distance(p, center_b)
            # 用 <= 保证“距离相等归入 x 较小的一侧”。
            labels.append(0 if da <= db else 1)
        return labels

    labels = assign(centroid_a, centroid_b)

    while True:
        group_a = [idx for idx, lab in zip(indices, labels) if lab == 0]
        group_b = [idx for idx, lab in zip(indices, labels) if lab == 1]

        # 若某一侧为空，保留旧质心。正常数据下初始质心分别是首尾两个不同的点，
        # 不会出现空簇，这里只是防御性处理。
        new_a = mean_point(points, group_a) if group_a else centroid_a
        new_b = mean_point(points, group_b) if group_b else centroid_b

        # 两个新质心的最大欧氏偏移量。
        shift = max(
            math.sqrt(squared_distance(new_a, centroid_a)),
            math.sqrt(squared_distance(new_b, centroid_b)),
        )

        new_labels = assign(new_a, new_b)

        # 两个终止条件任一成立就停：质心基本不动，或归属不再变化。
        if shift < CENTROID_EPS or new_labels == labels:
            centroid_a, centroid_b = new_a, new_b
            labels = new_labels
            break

        centroid_a, centroid_b = new_a, new_b
        labels = new_labels

    group_a = [idx for idx, lab in zip(indices, labels) if lab == 0]
    group_b = [idx for idx, lab in zip(indices, labels) if lab == 1]
    return group_a, group_b


def split_gain(points, indices):
    """
    计算对一个簇做 2-means 分裂的 SSE_Grad。

    SSE_Grad = SSE(父簇) - SSE(子簇1) - SSE(子簇2)。
    """
    parent_center = mean_point(points, indices)
    parent_sse = sse_of(points, indices, parent_center)

    group_a, group_b = two_means(points, indices)

    child_sse = 0.0
    if group_a:
        child_sse += sse_of(points, group_a, mean_point(points, group_a))
    if group_b:
        child_sse += sse_of(points, group_b, mean_point(points, group_b))

    return parent_sse - child_sse, group_a, group_b


def solve():
    """读取点集，按题意反复分裂，输出每一轮的簇规模列表。"""
    data = sys.stdin.buffer.read().split()
    if len(data) < 2:
        return

    it = iter(data)
    target_clusters = int(next(it))
    total_points = int(next(it))

    points = []
    for _ in range(total_points):
        x = int(next(it))
        y = int(next(it))
        points.append((x, y))

    if total_points == 0 or target_clusters <= 0:
        return

    # 全局生成序号：C0 为 0，之后每分裂一次就分配两个更大的序号。
    # 用序号代替真实时间，比较“谁更早”就是比较序号大小。
    create_clock = 1

    # 每个簇保存成员下标与生成时间。成员按 x 升序，two_means 依赖这个顺序
    # 取首尾作为初始质心。
    clusters = [{
        "members": sorted(range(total_points), key=lambda i: points[i][0]),
        "born": 0,
    }]

    # 第 0 次结果：尚未分裂，只有一个簇。
    lines = [str(total_points)]

    while len(clusters) < target_clusters:
        best_index = -1
        best_gain = -1.0
        best_size = -1
        best_born = 0
        best_groups = None

        for pos, cluster in enumerate(clusters):
            members = cluster["members"]
            # 只有一个点的簇无法再分裂（此时总点数不足，属于越界输入）。
            if len(members) < 2:
                continue

            gain, group_a, group_b = split_gain(points, members)

            # 依次比较：下降量更大 > 成员更多 > 生成时间更早。
            if (gain > best_gain + GRAD_EPS
                    or (abs(gain - best_gain) <= GRAD_EPS
                        and len(members) > best_size)
                    or (abs(gain - best_gain) <= GRAD_EPS
                        and len(members) == best_size
                        and cluster["born"] < best_born)):
                best_index = pos
                best_gain = gain
                best_size = len(members)
                best_born = cluster["born"]
                best_groups = (group_a, group_b)

        # 所有簇都只剩一个点，无法继续分裂。属于 N > L 的越界输入，
        # 直接按当前规模补齐剩余行，避免死循环。
        if best_index == -1:
            current = sorted((len(c["members"]) for c in clusters), reverse=True)
            while len(lines) < target_clusters:
                lines.append(" ".join(map(str, current)))
            break

        group_a, group_b = best_groups

        # 先归入 x 最小初始质心一侧的子簇，再归入 x 最大一侧的子簇。
        child_a = {"members": group_a, "born": create_clock}
        child_b = {"members": group_b, "born": create_clock + 1}
        create_clock += 2

        clusters[best_index:best_index + 1] = [child_a, child_b]

        current = sorted((len(c["members"]) for c in clusters), reverse=True)
        lines.append(" ".join(map(str, current)))

    print("\n".join(lines))


if __name__ == "__main__":
    solve()
```

## 示例推演

### 样例 1

$N=3$、$L=4$，四个点是 $(0,0),(1,0),(8,0),(9,1)$。

**第 0 行**：还没有分裂，输出 `4`。

**第 1 轮**：对 $C_0$ 跑 2-means，初始质心取簇内 $x$ 最小与最大的 $(0,0)$、$(9,1)$：

| 点 | 到 $(0,0)$ 距离平方 | 到 $(9,1)$ 距离平方 | 归属 |
| -- | ------------------ | ------------------- | ---- |
| $(0,0)$ | 0 | 82 | 左 |
| $(1,0)$ | 1 | 65 | 左 |
| $(8,0)$ | 64 | 2 | 右 |
| $(9,1)$ | 82 | 0 | 右 |

新质心 $(0.5,0)$、$(8.5,0.5)$，最大偏移 $\max(0.5,\ 0.7071)>10^{-6}$；用新质心重新分配，四个点归属不变，第二个停止条件触发，迭代结束。两簇各 $2$ 个点，输出 `2 2`。

**第 2 轮**：对现有两个簇各算一次分裂，比较下降量。

- 左簇 $\{(0,0),(1,0)\}$：质心 $(0.5,0)$，$SSE=0.25+0.25=0.5$；裂成两个单点后子簇 SSE 全 $0$，$SSE\_Grad=0.5$。
- 右簇 $\{(8,0),(9,1)\}$：质心 $(8.5,0.5)$，两点各贡献 $0.25+0.25$，$SSE=1.0$；裂开后同样归 $0$，$SSE\_Grad=1.0$。

右簇胜出，分裂后规模 `2 1 1`。此时已有 $3=N$ 个簇，完整输出：

```text
4
2 2
2 1 1
```

### 样例 2

$N=1$：一次都不裂，直接输出初始簇规模 `3`。

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| ---- | ---------- | ---------- | ---- |
| 枚举全部二分 | $O(2^L\cdot L)$ | $O(L)$ | 仅作对照；$L=100$ 时 $2^{99}$ 种划分不可计算 |
| 每轮全量重算 2-means（最优） | $O(N\cdot K\cdot L\cdot I)$ | $O(L+K)$ | $K\le20$ 为簇数、$L\le100$、$I$ 为 Lloyd 迭代次数（个位数） |

最坏情况的乘积大约是 $20\times20\times100\times$ 个位数次迭代，算下来十万级基本操作，量级很小。

## 易错点总结

### 1. SSE_Grad 要等 2-means 收敛后再算

`split_gain` 里先 `two_means`，再对停止时刻的两个子簇求 SSE。只做一轮分配、或用「父簇 SSE 的一半」近似，得到的下降量都与真实不同；多个候选簇的排序可能因此颠倒，从选错的那一轮起，每一行的规模列表全部跟着错。

### 2. 距离相等走 `<=`，不是 `<`

`labels.append(0 if da <= db else 1)`——比较用的平方距离没有开方，相等是精确事件：整数坐标、对称布局、以及质心落在 $0.5$ 这类可精确表示的分数上，都让「横在两个质心正中间」的点真实出现。写成 `<` 会把它划到 $x$ 较大的一侧，两个子簇的规模立刻多一少一，从这一轮起每一行的规模列表都不同。

### 3. 并列判定要在浮点上留容差

`solve()` 的第一段比较是 `gain > best_gain + GRAD_EPS`，并列用 `abs(gain - best_gain) <= GRAD_EPS`。$SSE\_Grad$ 是一串浮点减法加总的，两个理论上相等的值可能因求和顺序差出 $10^{-16}$；直接用 `>` 会让这种假差距压过后两级平局规则，「同分看设备数、再看生成时间」名存实亡。内嵌自测样例 4（四个等距共线点）到了分裂第 2 轮时，两个 2 点簇的下降量完全相等，正是后两级规则的用武之地。

## 扩展思考

- Bi-K-means 的确定性来自把每一步的自由度收走：固定初始化、固定平局规则、固定生成顺序。这一思路在其它需要唯一输出的聚类题里可直接搬用。
- K-means 一族只能找到凸的、球状的簇，环形、月牙形分布要换 DBSCAN、谱聚类；分裂判据改成「半径最大」「点数最多」时得到的是另一种风格的簇，两级流程本身不变。
