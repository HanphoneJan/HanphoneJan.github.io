# P5467. 全局位与窗口注意力

> 场次：2026年9月18日 · 来源：[CodeFun2000 P5467](https://codefun2000.com/p/P5467)

## 题目描述

给定三个整数矩阵 $Q$、$K$、$V$，尺寸均为 $L\times D$，以及 $G$ 个全局位置，它们构成集合 $P$。

对位置 $i$，先确定可参与注意力的下标集合 $C_i$：

$$
C_i=
\begin{cases}
\{0,1,\ldots,L-1\}, & i\in P\\
P\cup\{j\mid 0\le j<L,\ |i-j|\le W\}, & i\notin P
\end{cases}
$$

集合内同一位置只计一次。

对 $j\in C_i$，注意力分数定义为

$$
score(i,j)=\sum_{x=0}^{D-1}Q[i][x]\cdot K[j][x]
$$

只保留满足 $score(i,j)>0$ 的位置，再从中选出至多 $T$ 个分数最大的候选，得到 $A_i$。分数相同时，下标 $j$ 较小者优先。若正分数候选个数不超过 $T$，则全部保留。

输出矩阵 $O$：当 $A_i$ 非空时

$$
O[i][x]=\sum_{j\in A_i}score(i,j)\cdot V[j][x]\qquad(0\le x<D)
$$

当 $A_i$ 为空时，$O[i]$ 的每一维都是 $0$。

请输出最终的 $L\times D$ 矩阵 $O$。

## 输入格式

第一行五个整数：

```text
L D G W T
```

依次为序列长度、特征维数、全局位置个数、局部窗口半径、每个位置最多保留的候选数。

若 $G>0$，下一行 $G$ 个互不相同的整数：

```text
p1 p2 ... pG
```

表示全局位置，下标从 $0$ 开始。

若 $G=0$，则没有这一行，接下来直接读矩阵 $Q$。

随后 $L$ 行，每行 $D$ 个整数，为矩阵 $Q$。

随后 $L$ 行，每行 $D$ 个整数，为矩阵 $K$。

随后 $L$ 行，每行 $D$ 个整数，为矩阵 $V$。

## 输出格式

输出 $L$ 行，每行 $D$ 个整数，表示矩阵 $O$。

同一行相邻整数之间用一个空格分隔。

## 示例

### 示例 1

**输入：**

```text
5 2 2 1 2
0 3
1 0
1 0
2 0
0 1
1 1
2 0
1 0
3 0
0 2
-1 1
1 1
2 2
3 3
4 4

```

**输出：**

```text
11 11
11 11
22 22
13 13
10 10
```

**说明：**

全局位置集合为 $P=\{0,3\}$。

对 $i=1$（非全局）：$C_1=\{0,1,2,3\}$，分数为 $2,1,3,0$。丢掉非正分数后，按 $T=2$ 取位置 $2$ 与 $0$：

$$
O[1]=3\times[3,3]+2\times[1,1]=[11,11]
$$

对全局位置 $i=3$：$C_3=\{0,1,2,3,4\}$，正分数只有 $2$（对应 $j=3$）和 $1$（对应 $j=4$）：

$$
O[3]=2\times[4,4]+1\times[5,5]=[13,13]
$$

对 $i=4$：$C_4=\{0,3,4\}$，分数为 $2,2,0$。$0$ 被丢掉，两个分数 $2$ 并列时先取较小下标 $0$，再取 $3$：

$$
O[4]=2\times[1,1]+2\times[4,4]=[10,10]
$$

$1\le L\le 10000$

$1\le D\le 64$

$0\le G\le \min(L,32)$

$1\le T\le \min(L,16)$

$0\le p_i<L$

矩阵与序列下标均从 $0$ 开始。

中间结果和最终结果均在 $64$ 位有符号整数范围内。

## 解题思路

### 输出行由哪三条规则决定

这题长着一张标准注意力的脸：拿 $Q[i]$ 与各个 $K[j]$ 打点积分，再用分数加权 $V[j]$。真正决定代码长什么样的是它附加在输出上的三条小规则，每一条都对应实现里的一处硬性判断：

- 分数只保留**严格大于 $0$** 的：`score > 0`，$0$ 也算非正，要丢；
- 至多留 $T$ 个：多了按「分数从大到小、同分下标小者先」截断，不足 $T$ 个就全留；
- 一条正分都没有时，整行输出 $D$ 个 $0$（$D>1$ 时是 $D$ 个，不是一个）。

三条汇成一个结论：每一行要做的事，就是从一小堆 `(score, j)` 里挑出排序后的前 $T$ 个。候选记录因此只需要 `(分数, 下标)` 二元组；排序键写 `(-score, j)`，升序排完恰好是题面要的顺序，并列规则白送。

### 数据范围把算法钉在「按行模拟」上

看题后的第一反应是把每个位置与全部 $L$ 个 key 打分，那是不可行的反应：点积总数 $L^2$ 再乘 $D=64$，$L=10^4$ 时约 $6.4\times10^9$ 次乘加，若再存一张 $L\times L$ 分数表还得 $10^8$ 个数，Python 里毫无希望。

$C_i$ 的定义其实已把该算的分数写明了。全局位置只有 $G\le32$ 个，它们才需要扫全序列，合计 $G\cdot L$ 个点积；其余 $L-G$ 个非全局位置，每个只看「窗口 $\cup$ 全局位」——窗口 $2W+1\le257$ 个，并上 $G$ 个全局位，至多 $289$ 个。总点积约 $(L-G)(2W+1+G)+G\cdot L\approx2.9\times10^6$，是完整注意力（$L^2=10^8$ 个）的三十分之一。这就是本题可行与不可行的分界：不需要更聪明的公式，**只算感受野内的分数**，逐行模拟就能过。

还有一处值得先想清：分数**不能跨行复用**。滑动窗口注意力里可以增量维护窗口内的分数，可这里每换一行 query 就整个换掉，所有旧点积全部作废。优化方向只能压在「每行少算候选」上，行间共享这条路是死的。

### 从定义到代码的四处映射

**输入按 token 流读。** $G=0$ 时全局位置那一行不存在，按行号解析会整体错位。`sys.stdin.buffer.read().split()` 把全部数字拉平成一条流，之后顺序消费（代码里的 `pos` 指针），行结构消失，两种情况共用同一段解析。

**窗口用左闭右开区间。** `lo = max(0, i - W)`、`hi = min(L, i + W + 1)`：右端开，所以在 $i$ 上加 $1$；窗口在序列两端自然截短，靠近边界的行不需要任何特判。

**并集去重用「补窗口外」而不是 set。** 非全局行的候选是「窗口 $\cup$ 全局位」，而全局位完全可能同时落在窗口里。先扫窗口、再只补窗口外的全局位（`j < lo or j >= hi`），等效于两个有序段求并，比把候选灌进 set 便宜；不去重的话，同一位置的分数会被加进 $O[i]$ 两倍。

**点积是唯一热点。** 全部时间都花在 `dot(qi, K[j])` 上。`math.sumprod` 是 Python 3.12 起的 C 实现，比手写 `sum(map(mul, a, b))` 快约一倍；代码用 `try/except` 退化到等价写法，主体逻辑不关心用的是哪一份。

## 完整代码实现

```python
import sys

try:
    # Python 3.12 起标准库提供了 C 实现的点积，比手写循环快将近一倍
    from math import sumprod as dot
except ImportError:                     # 旧版本 Python 的等价写法
    from operator import mul

    def dot(a, b):
        """返回两个等长向量的点积。"""
        return sum(map(mul, a, b))


def solve():
    tokens = sys.stdin.buffer.read().split()
    if not tokens:
        return

    pos = 0
    L = int(tokens[pos])
    D = int(tokens[pos + 1])
    G = int(tokens[pos + 2])
    W = int(tokens[pos + 3])
    T = int(tokens[pos + 4])
    pos += 5

    # is_global 用布尔数组存，判断「i 是不是全局位置」是 O(1)；
    # global_pos 保存原始下标列表，非全局行要把它们补进候选集合。
    is_global = bytearray(L)
    global_pos = []
    for _ in range(G):
        p = int(tokens[pos])
        pos += 1
        is_global[p] = 1
        global_pos.append(p)

    def read_matrix(rows):
        """从 token 流中读出 rows 行、每行 D 个整数的矩阵。"""
        nonlocal pos
        mat = []
        for _ in range(rows):
            mat.append([int(x) for x in tokens[pos:pos + D]])
            pos += D
        return mat

    Q = read_matrix(L)
    K = read_matrix(L)
    V = read_matrix(L)
    # 三个矩阵已经转换成整数，token 列表不再需要，提前释放可以省下大量内存。
    del tokens

    output_lines = []
    for i in range(L):
        qi = Q[i]
        candidates = []          # 只放正分候选，元素为 (分数, 下标)

        if is_global[i]:
            # 全局位置的感受野是整条序列
            for j in range(L):
                score = dot(qi, K[j])
                if score > 0:
                    candidates.append((score, j))
        else:
            # 窗口在序列两端会被截断，而不是补零
            lo = i - W
            if lo < 0:
                lo = 0
            hi = i + W + 1
            if hi > L:
                hi = L

            for j in range(lo, hi):
                score = dot(qi, K[j])
                if score > 0:
                    candidates.append((score, j))

            # 全局位置可能落在窗口内，那它已经在上面被算过一次，
            # 这里只补窗口外的那些，避免同一位置被重复计入。
            for j in global_pos:
                if j < lo or j >= hi:
                    score = dot(qi, K[j])
                    if score > 0:
                        candidates.append((score, j))

        if not candidates:
            # 没有正分候选时整行为 0，这是题目明确规定的
            output_lines.append(" ".join(["0"] * D))
            continue

        if len(candidates) > T:
            # 分数降序、分数相同时下标升序：升序排序键 (-score, j) 正好表达这个顺序
            candidates.sort(key=lambda pair: (-pair[0], pair[1]))
            candidates = candidates[:T]

        row = [0] * D
        for score, j in candidates:
            vj = V[j]
            # O[i][x] += score(i,j) * V[j][x]
            for x in range(D):
                row[x] += score * vj[x]

        output_lines.append(" ".join(map(str, row)))

    sys.stdout.write("\n".join(output_lines))


if __name__ == "__main__":
    solve()
```

### NumPy 版本

> 以下版本使用 NumPy。只有在评测环境允许第三方库时才能提交；CodeFun2000 的普通 Python 环境不一定安装 NumPy。

```python
import sys

import numpy as np


def solve():
    """带全局位置的窗口注意力：候选筛选照旧，点积与加权求和全部交给 NumPy。"""
    tokens = sys.stdin.buffer.read().split()
    if not tokens:
        return

    L, D, G, W, T = (int(t) for t in tokens[:5])
    cursor = 5

    # G = 0 时输入里没有全局位置那一行；按 token 流顺序消费，天然不受行结构影响
    if G > 0:
        global_pos = np.fromiter(map(int, tokens[cursor:cursor + G]),
                                 dtype=np.int64, count=G)
        cursor += G
    else:
        global_pos = np.empty(0, dtype=np.int64)

    # Q、K、V 一次性读成一条扁平数组再 reshape：比逐行切片快得多，
    # 也避免 Python 层出现 3L 次 int() 转换。
    total = L * D
    flat = np.fromiter(map(int, tokens[cursor:cursor + 3 * total]),
                       dtype=np.int64, count=3 * total)
    Q = flat[:total].reshape(L, D)
    K = flat[total:2 * total].reshape(L, D)
    V = flat[2 * total:].reshape(L, D)
    # Q、K、V 是同一块扁平数组的三个视图，reshape/切片都不复制数据
    del tokens          # token 列表不再需要，提前释放

    # 是否全局位置摊成一个布尔掩码，逐行判断就是一次数组取值
    is_global = np.zeros(L, dtype=bool)
    is_global[global_pos] = True

    all_pos = np.arange(L)
    out = np.zeros((L, D), dtype=np.int64)   # 没有正分候选的行保持全 0

    def weighted_row(cand, scores):
        """丢掉非正分数，取分数最大的前 T 个，用它们加权求和得到一行 O[i]。"""
        keep = scores > 0                    # 0 也要丢掉，条件是严格大于 0
        if not keep.any():
            return None
        cand = cand[keep]
        scores = scores[keep]
        if scores.size > T:
            # lexsort 以最后一个键为主键：先按 -score（即分数降序），
            # 同分再按下标升序，与纯 Python 版的排序键 (-score, j) 完全等价。
            order = np.lexsort((cand, -scores))[:T]
            cand = cand[order]
            scores = scores[order]
        # 一次矩阵向量乘完成 O[i] = Σ score(i,j) * V[j]
        return scores @ V[cand]

    for i in range(L):
        if is_global[i]:
            # 全局位置的感受野是整条序列
            cand = all_pos
        else:
            lo = max(0, i - W)
            hi = min(L, i + W + 1)           # 左闭右开，右端记得 +1
            window = np.arange(lo, hi)
            # 只补窗口外的全局位置：窗口内的已经在上面算过一次，
            # 重复计入会把它的分数加两遍。
            extra = global_pos[(global_pos < lo) | (global_pos >= hi)]
            cand = np.concatenate((window, extra))

        row = weighted_row(cand, K[cand] @ Q[i])   # 候选行的点积一次算完
        if row is not None:
            out[i] = row

    sys.stdout.write("\n".join(" ".join(map(str, row)) for row in out.tolist()))


if __name__ == "__main__":
    solve()
```

## 示例推演

### 样例 1（主线）：感受野、去重与并列

$L=5$、$D=2$、$G=2$、$W=1$、$T=2$，全局位置 $P=\{0,3\}$。矩阵各行为：

| 下标 | $Q$ | $K$ | $V$ |
| :--- | :--- | :--- | :--- |
| 0 | `[1, 0]` | `[2, 0]` | `[1, 1]` |
| 1 | `[1, 0]` | `[1, 0]` | `[2, 2]` |
| 2 | `[2, 0]` | `[3, 0]` | `[3, 3]` |
| 3 | `[0, 1]` | `[0, 2]` | `[4, 4]` |
| 4 | `[1, 1]` | `[-1, 1]` | `[5, 5]` |

逐行按「确定 $C_i$ → 打分 → 丢非正 → 取前 $2$」走（并列时下标小者先）：

| $i$ | 全局? | $C_i$（去重后） | 各候选分数 | 入选 | $O[i]$ |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 0 | 是 | $\{0,1,2,3,4\}$ | $2,1,3,0,-1$ | $j{=}2\,(3),\;j{=}0\,(2)$ | $3{\times}[3,3]+2{\times}[1,1]=[11,11]$ |
| 1 | 否 | $\{0,1,2,3\}$ | $2,1,3,0$ | $j{=}2\,(3),\;j{=}0\,(2)$ | $[11,11]$ |
| 2 | 否 | $\{0,1,2,3\}$ | $4,2,6,0$ | $j{=}2\,(6),\;j{=}0\,(4)$ | $6{\times}[3,3]+4{\times}[1,1]=[22,22]$ |
| 3 | 是 | $\{0,1,2,3,4\}$ | $0,0,0,2,1$ | $j{=}3\,(2),\;j{=}4\,(1)$ | $2{\times}[4,4]+1{\times}[5,5]=[13,13]$ |
| 4 | 否 | $\{0,3,4\}$ | $2,2,0$ | $j{=}0\,(2),\;j{=}3\,(2)$ | $2{\times}[1,1]+2{\times}[4,4]=[10,10]$ |

三个最容易走岔的步骤单独核对：

- **$i=1$ 的感受野拼法**：窗口是 $\{0,1,2\}$，并上全局位 $\{0,3\}$；$0$ 已在窗口里，去重后 $C_1=\{0,1,2,3\}$。$j=4$ 不在感受野里，它那记 $-1$ 分根本不会被算到。
- **$i=4$ 的去重与并列**：窗口 $\{3,4\}$ 并上 $\{0,3\}$，$3$ 重复即舍，得 $\{0,3,4\}$。分数 $2,2,0$：$0$ 被丢，剩下的两个 $2$ 并列，按下标小者先取 $j=0$、$j=3$。
- **$i=0$ 是全局行**：$C_0$ 是整条序列、没有窗口概念；去掉 $0$ 与 $-1$ 两记分数后，$(3,j=2)$ 与 $(2,j=0)$ 入选。

五行合起来正是样例输出：

```text
11 11
11 11
22 22
13 13
10 10
```

### 样例 2：$G=0$ 与整行为零

$L=3$、$D=1$、$G=0$、$W=0$、$T=1$：$Q=[1,2,-1]$，$K=[-2,3,1]$，$V=[10,20,30]$。$G=0$ 意味着输入里**没有**全局位置那一行；$W=0$ 让每个位置的窗口只含自己。三记分数为 $-2,6,-1$，非正的全部清场，只有 $i=1$ 留下：$O[1]=6\times20=120$。输出 `0 / 120 / 0`。

## 复杂度分析

记非全局行的候选数为 $|C_i|\le(2W+1)+G$，全局行为 $L$。

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| :--- | :--- | :--- | :--- |
| 完整 $L\times L$ 注意力 | $O(L^2 D)$ | $O(L^2)$ | $L=10^4$、$D=64$ 时约 $6.4\times10^9$ 次乘加，还要存整张分数表 |
| 按感受野模拟，排序取前 $T$（最优） | $O\!\left(L\,\lvert C\rvert\,D + L\,\lvert C\rvert\log\lvert C\rvert\right)$ | $O(LD)$ | $\lvert C\rvert\le289$，点积约 $2.9\times10^6$，排序占比很小；本题采用 |
| 按感受野模拟，堆维护前 $T$ | $O\!\left(L\,\lvert C\rvert\,D\right)$ | $O(LD)$ | 大小 $T$ 的小顶堆把排序项降到 $\lvert C\rvert\log T$，本题 $T\le16$ 用不上 |

## 易错点总结

### 1. 全局位落进窗口后被算两次

非全局行的候选是「窗口 $\cup$ 全局位」，而全局位可能恰好就在窗口里（样例 1 的 $i=4$，全局位 $3$ 就在窗口 $\{3,4\}$ 内）。若扫完窗口再把 `global_pos` 原样补一遍，这个点积出现两次、分数计入 $O[i]$ 两倍——不报错，只是数值错了。代码用 `if j < lo or j >= hi` 只补窗口外的全局位。

### 2. 窗口右端是开区间

窗口的代码形态是 `lo = i - W` 截到 $0$、`hi = i + W + 1` 截到 $L$。把 $hi$ 抄成 `i + W` 的话，恰好压在窗口右边缘的 $j=i+W$ 被漏掉，它的正分进不了 $A_i$，输出行偏小；越靠近序列右端的行越先暴露。

## 扩展思考

- 全局位是 Longformer、BigBird 这类稀疏注意力的标准件：绝大多数 token 只看带状窗口，少数 global token 看整条序列，把 $O(L^2)$ 的注意力压成「带 + 若干整行」，同时保住远距离通路。纯滑动窗口（P5337）没有这条捷径，远距离信息要靠多层堆叠传递。
- 本题 $T\le16$、$|C_i|\le289$，直接排序毫无压力；候选数与 $T$ 都大时才换成堆。真正的常数瓶颈在点积——`sumprod` 这类 C 实现与纯 Python 双重循环差一个数量级。
