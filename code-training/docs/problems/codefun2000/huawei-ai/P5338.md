# P5338. 整数缩放因子下的全整型矩阵乘积

> 场次：2026年9月2日 · 来源：[CodeFun2000 P5338](https://codefun2000.com/p/P5338)

## 题目描述

在模型量化中，常需要把高精度浮点数转换为低位整数。对于实数 $r$ 与缩放因子 $s$，线性量化定义为 $q=\operatorname{round}(r/s)$，反量化则恢复为 $r=sq$。在 $n$ 比特量化下，缩放因子通常取 $s=\frac{\max(|r_{\min}|,|r_{\max}|)}{2^{n-1}-1}$。矩阵可以按行或按列分别量化，并为每一行或每一列保存一个缩放因子。

为了进一步避免缩放因子参与浮点运算，可以把缩放因子 $s$ 写成两个整数 $a,b$ 的比值：$s=\frac{a}{2^b}$。这样，两个缩放因子相乘时可以表示为
$$
\frac{a_1}{2^{b_1}}\times\frac{a_2}{2^{b_2}}
=\frac{a_1a_2}{2^{b_1+b_2}}.
$$

本题要求在这种全整数缩放因子表示下完成矩阵乘法。给定已经按行完成量化的矩阵 $A$，以及尚未量化的浮点矩阵 $B$。矩阵 $A$ 的大小为 $m\times k$，矩阵 $B$ 的大小为 $k\times n$。需要计算矩阵乘积 $C=A\times B$，并以全整型量化形式输出 $C$ 的每个元素。

矩阵 $A$ 的每一行已经附加了缩放因子 $s_A=\frac{a_A}{2^{b_A}}$。矩阵 $B$ 需要按列进行 `8` 比特量化：对第 $j$ 列，先取该列所有元素绝对值的最大值，令该列缩放因子 $s_B=\frac{\max(|B_{1,j}|,\dots,|B_{k,j}|)}{127}$，然后按量化公式得到该列整数表示，并裁剪到 `[-127,127]`；同时将 $s_B$ 表示为 $\frac{a_B}{2^{b_B}}$ 的形式。

对于结果矩阵 $C$ 中第 $i$ 行第 $j$ 列的元素，其量化值为 $A$ 第 $i$ 行量化整数与 $B$ 第 $j$ 列量化整数的点积。其缩放因子为两个缩放因子的乘积：
$$
\frac{a_A}{2^{b_A}}\times\frac{a_B}{2^{b_B}}
=\frac{a_Aa_B}{2^{b_A+b_B}}.
$$
因此该元素需要输出三个整数：点积结果、$a_Aa_B$、$b_A+b_B$。点积结果不需要限制在 `[-127,127]` 内，缩放因子也无需约分。

约束条件：
- 矩阵 $A$ 每行给出的已量化整数以及矩阵 $B$ 量化后的整数均在 `-127` 到 `127` 之间。
- 缩放因子中，$a$ 的取值范围为 `0` 到 `127`，$b$ 的取值范围为 `0` 到 `30`。
- 矩阵 $B$ 使用 `8` 比特量化，量化后的整数范围为 `-127` 到 `127`。

## 输入格式

第一行包含三个整数 `m`、`k`、`n`，依次表示矩阵 $A$ 的行数、矩阵 $A$ 的列数（也是矩阵 $B$ 的行数）、矩阵 $B$ 的列数。

接下来 `m` 行，每行包含 `k+2` 个整数。前 `k` 个整数是矩阵 $A$ 当前行已经量化的整数；最后两个整数依次为该行缩放因子的 `a` 和 `b`。

再接下来 `n` 行，每行包含 `k` 个浮点数。这些行按矩阵 $B$ 的转置给出，其中第 `i` 行表示矩阵 $B$ 的第 `i` 列。

## 输出格式

输出共 `m` 行。每一行对应矩阵 $C$ 的一行，包含 $n$ 个结果元素。每个结果元素由三个整数依次组成：量化值、缩放因子的 `a`、缩放因子的 `b`。同一行内所有整数之间用空格分隔。

## 示例

### 示例 1

**输入：**

```
2 3 2
1 2 3 1 0
10 -5 4 3 2
127.0 0.0 -127.0
0.0 127.0 64.0
```

**输出：**

```
-254 64 6 446 64 6
762 192 8 -379 192 8
```

**说明：**

矩阵 $A$ 第 `1` 行的缩放因子为 $1/2^0$，即 $a_A=1,b_A=0$；第 `2` 行的缩放因子为 $3/2^2$，即 $a_A=3,b_A=2$。

矩阵 $B$ 两列的最大绝对值均为 `127`，因此 $s_B=127/127=1$。将 $1$ 表示为 $a_B/2^{b_B}$ 时，四舍五入得到 $a_B=64,b_B=6$。

计算点积如下：
- 第 `1` 行第 `1` 列：$1\times127+2\times0+3\times(-127)=-254$。
- 第 `1` 行第 `2` 列：$1\times0+2\times127+3\times64=446$。
- 第 `2` 行第 `1` 列：$10\times127+(-5)\times0+4\times(-127)=762$。
- 第 `2` 行第 `2` 列：$10\times0+(-5)\times127+4\times64=-379$。

结果缩放因子：
- 第 `1` 行：$a_A a_B=1\times64=64$，$b_A+b_B=0+6=6$。
- 第 `2` 行：$a_A a_B=3\times64=192$，$b_A+b_B=2+6=8$。

因此输出如样例输出所示。

### 示例 2

**输入：**

```
1 1 1
5 1 0
0.0
```

**输出：**

```
0 0 0
```

**说明：**

矩阵 $B$ 唯一列的元素为 $[0.0]$，最大绝对值为 `0`，因此 $s_B=0/127=0$，量化后整数仍为 `0`，缩放因子表示为 $0/2^0$，即 $a_B=0,b_B=0$。

矩阵 $A$ 的唯一量化整数为 `5`，缩放因子为 $1/2^0$。点积为 $5\times0=0$。结果缩放因子为 $a_A a_B=1\times0=0$，$b_A+b_B=0+0=0$。

因此输出 `0 0 0`。

### 示例 3

**输入：**

```
1 2 1
5 -3 2 3
1.0 -2.0
```

**输出：**

```
701 130 15
```

**说明：**

矩阵 $B$ 唯一列的元素为 $[1.0,-2.0]$，最大绝对值为 `2`，所以 $s_B=2/127$。

量化时：
- $1.0/(2/127)=63.5$，四舍五入为 `64`；
- $-2.0/(2/127)=-127$，四舍五入为 `-127`。

缩放因子 $2/127$ 按照 $a_B/2^{b_B}$ 表示并四舍五入，得到 $a_B=65,b_B=12$。

矩阵 $A$ 的量化整数为 $[5,-3]$，缩放因子为 $2/2^3$。点积为 $5\times64+(-3)\times(-127)=701$。结果缩放因子为 $a_A a_B=2\times65=130$，$b_A+b_B=3+12=15$。

因此输出 `701 130 15`。

## 解题思路

### 第一步：理解问题本质

量化把浮点数 $r$ 压成整数 $q$：

$$
q=\operatorname{round}(r/s),\qquad r\approx sq
$$

其中 $s$ 是缩放因子。本题要求缩放因子本身也**不用浮点表示**，而是写成两个整数：

$$
s=\frac{a}{2^b}
$$

这样做的好处是缩放因子之间的乘法完全变成整数运算：

$$
\frac{a_1}{2^{b_1}}\times\frac{a_2}{2^{b_2}}=\frac{a_1a_2}{2^{b_1+b_2}}
$$

于是结果矩阵 $C$ 的元素可以拆成三部分独立计算：

1. **量化值**：$A$ 第 $i$ 行的量化整数与 $B$ 第 $j$ 列的量化整数做点积，全程整数；
2. **分子** $a_C=a_A\cdot a_B$；
3. **指数** $b_C=b_A+b_B$。

注意题面要求“缩放因子无需约分”，所以 $a_C$ 就是两个分子直接相乘，不要除以最大公约数。

### 第二步：暴力解法——先反量化，再浮点相乘

最符合直觉的做法是：

```python
# 1. 用 s_A 把 A 的量化整数还原成浮点
A_float = [[q * (a_A / 2 ** b_A) for q in row] for row in A]

# 2. 对 B 的每一列做 8 比特量化，再反量化
B_float = [[q * (a_B[j] / 2 ** b_B[j]) for q in col] for col in B_quant]

# 3. 普通浮点矩阵乘法得到 C
C = [[sum(A_float[i][t] * B_float[t][j] for t in range(k))
      for j in range(n)] for i in range(m)]
```

这个做法能算出大致正确的数值，但**得不到题目要的输出**：

- 输出要求的是“点积、$a_Aa_B$、$b_A+b_B$”三个整数，而不是 $C$ 的浮点值；
- 反量化再相乘会引入浮点误差，$a_C$ 与 $b_C$ 还要再从浮点值反推，容易在取整上差 1；
- 缩放因子一旦反量化成浮点，就丢失了“不约分”的信息。

所以正确路线不是“还原浮点”，而是**把整数表示一路保持到底**。

### 第三步：优化解法——按列量化 B，用整数点积

矩阵 $A$ 已经是量化好的整数，缩放因子也直接给出，所以只需要处理 $B$。

**B 的量化必须按列进行。** 第 $j$ 列取

$$
M_j=\max_i |B_{i,j}|,\qquad s_j=\frac{M_j}{127}
$$

然后

$$
q_{i,j}=\operatorname{clip}\bigl(\operatorname{round}(B_{i,j}/s_j),\ -127,\ 127\bigr)
$$

代入 $s_j=M_j/127$，量化公式可以少做一次除法：

$$
B_{i,j}/s_j=B_{i,j}\cdot\frac{127}{M_j}
$$

代码里直接用 `value * 127 / max_abs`，避免先算出 $s_j$ 再除带来的额外舍入。

**缩放因子 $s_j$ 转成 $a/2^b$。** 这里的关键是 $b$ 取多少。已知 $a$ 必须是 $0\sim127$ 的整数，而 $b$ 最多 $30$。直观上希望分母 $2^b$ 尽量大（精度更高），但不能让分子超过 $127$：

$$
\max\ b\ \text{使得}\ \operatorname{round}\Bigl(s_j\cdot 2^b\Bigr)\le 127
$$

例如样例 3 中 $s_B=2/127\approx0.0157480$：

| $b$ | $s_B\cdot2^b$ | 四舍五入后的 $a$ | 是否可用 |
| --- | ------------- | ---------------- | -------- |
| $11$ | $32.2519$ | $32$ | 可以，但分母偏小 |
| $12$ | $64.5039$ | $65$ | 可以，且是最大的可用 $b$ |
| $13$ | $129.0079$ | $129$ | 超过 $127$，不可用 |

所以取 $a_B=65$、$b_B=12$。

**结果矩阵。** 对每个 $(i,j)$：

$$
\text{dot}_{i,j}=\sum_{t=0}^{k-1}q^A_{i,t}\cdot q^B_{t,j},\qquad
a=a_A[i]\cdot a_B[j],\qquad b=b_A[i]+b_B[j]
$$

点积是纯整数运算，不会有任何误差；题面明确说点积**不需要**裁剪到 $[-127,127]$。

### 第四步：完整实现细节

几个必须单独处理的情况：

1. **整列为 0**：$M_j=0$，$s_j=0/127=0$，此时不能做除法。规定量化值全为 $0$，缩放因子写成 $0/2^0$，即 $a_B=b_B=0$（与样例 2 一致）。
2. **四舍五入的方向**：Python 内置的 `round` 是“银行家舍入”（`round(63.5) == 64`、`round(64.5) == 64`），与题面的四舍五入不一致。需要一个 `.5` 时**远离 0** 的取整函数：

   ```python
   def round_half_away(value):
       if value >= 0:
           return int(math.floor(value + 0.5))
       return int(math.ceil(value - 0.5))
   ```

   样例 3 里 $1.0/(2/127)=63.5$ 必须得到 $64$。
3. **B 是按列给出的**：输入的后 $n$ 行，每行是矩阵 $B$ 的一个**列**，不是一行。读进来时不要再转置一次。
4. **$a_A$ 可能为 $0$**：$A$ 那一行的缩放因子分子为 $0$ 时，结果的 $a_C=0$，但 $b_C$ 仍然要把 $b_A$ 加上，不能直接输出 `0 0 0`。
5. **输出格式**：共 $m$ 行，每行 $n$ 组 “点积 $a$ $b$”，组与组之间用一个空格分隔。

## 完整代码实现

```python
import math
import sys

# 8 比特量化，缩放因子的分子上限。
MAX_QUANT = 127
# 缩放因子的指数上限，题面给出 0 <= b <= 30。
MAX_SHIFT = 30


def round_half_away(value: float) -> int:
    """四舍五入（.5 向远离 0 的方向取整）。"""
    if value >= 0:
        return int(math.floor(value + 0.5))
    return int(math.ceil(value - 0.5))


def quantize_column(values, max_abs):
    """
    把一列浮点数量化成 [-127, 127] 内的整数。

    s_B = max_abs / 127，所以 value / s_B = value * 127 / max_abs。
    直接用乘法再除，避免先算出 s_B 引入一次额外的舍入。
    """
    if max_abs == 0.0:
        # 整列都是 0：缩放因子退化为 0，量化值也只能是 0。
        return [0] * len(values)

    result = []
    for value in values:
        q = round_half_away(value * MAX_QUANT / max_abs)
        # 理论上 |value| <= max_abs 已经保证 |q| <= 127，
        # 这里再裁剪一次，挡住浮点误差带来的 128 / -128。
        if q > MAX_QUANT:
            q = MAX_QUANT
        elif q < -MAX_QUANT:
            q = -MAX_QUANT
        result.append(q)
    return result


def column_scale(max_abs: float):
    """
    把 s_B = max_abs / 127 表示成 a / 2^b。

    b 取“四舍五入后的 a 不超过 127”的最大值：b 越大，分母越细，
    表示精度越高；直到 a 再往上就会越过 8 比特缩放因子的上限。
    """
    if max_abs == 0.0:
        # 与样例 2 一致：0 表示为 0 / 2^0。
        return 0, 0

    scale = max_abs / MAX_QUANT

    # 从大到小找第一个满足 a <= 127 的 b，找到即可返回。
    for shift in range(MAX_SHIFT, -1, -1):
        a = round_half_away(scale * (1 << shift))
        if a <= MAX_QUANT:
            return a, shift

    # 防御性分支：s_B 大到即使 b = 0 也超过 127（题面约束下不会出现）。
    return MAX_QUANT, 0


def solve():
    """读入 A、B，按列量化 B，输出 C 的每个元素与对应缩放因子。"""
    data = sys.stdin.buffer.read().split()
    if len(data) < 3:
        return

    it = iter(data)
    m = int(next(it))
    k = int(next(it))
    n = int(next(it))

    # A 的每行：k 个量化整数 + 缩放因子的 a、b。
    quant_a = []
    scale_a = []
    for _ in range(m):
        row = [int(next(it)) for _ in range(k)]
        a = int(next(it))
        b = int(next(it))
        quant_a.append(row)
        scale_a.append((a, b))

    # B 按列给出：第 j 行就是 B 的第 j 列。
    quant_b = []
    scale_b = []
    for _ in range(n):
        values = [float(next(it)) for _ in range(k)]
        max_abs = max(abs(v) for v in values)
        quant_b.append(quantize_column(values, max_abs))
        scale_b.append(column_scale(max_abs))

    lines = []
    for i in range(m):
        row_a = quant_a[i]
        a_a, b_a = scale_a[i]
        parts = []
        for j in range(n):
            col_b = quant_b[j]
            # 全整型点积：两个量化整数数组逐项相乘再求和。
            dot = sum(row_a[t] * col_b[t] for t in range(k))
            a_b, b_b = scale_b[j]
            # 缩放因子相乘：分子相乘，指数相加，绝不约分。
            parts.append(f"{dot} {a_a * a_b} {b_a + b_b}")
        lines.append(" ".join(parts))

    print("\n".join(lines))


if __name__ == "__main__":
    solve()
```

## 示例推演

### 样例 1

输入 $m=2$、$k=3$、$n=2$。

**整理 A：**

| 行 | 量化整数 | $a_A$ | $b_A$ | 缩放因子 |
| -- | -------- | ----- | ----- | -------- |
| 1 | $1,2,3$ | $1$ | $0$ | $1/2^0=1$ |
| 2 | $10,-5,4$ | $3$ | $2$ | $3/2^2=0.75$ |

**按列整理 B**（输入已经是列）：

| 列 | 元素 | $M_j$ | $s_j=M_j/127$ |
| -- | ---- | ----- | ------------- |
| 1 | $127.0,\ 0.0,\ -127.0$ | $127$ | $1$ |
| 2 | $0.0,\ 127.0,\ 64.0$ | $127$ | $1$ |

两列的 $M_j$ 都是 $127$，所以 $s_j=1$，量化值就是原来的整数：

- 第 1 列：$(127,\ 0,\ -127)$；
- 第 2 列：$(0,\ 127,\ 64)$。

**求 $a_B,b_B$：**

| $b$ | $1\cdot2^b$ | 四舍五入 | 是否可用 |
| --- | ----------- | -------- | -------- |
| $6$ | $64$ | $64$ | 可用 |
| $7$ | $128$ | $128$ | 超过 $127$ |

所以 $a_B=64$、$b_B=6$。

**点积：**

- 第 1 行第 1 列：$1\times127+2\times0+3\times(-127)=127-381=-254$；
- 第 1 行第 2 列：$1\times0+2\times127+3\times64=254+192=446$；
- 第 2 行第 1 列：$10\times127+(-5)\times0+4\times(-127)=1270-508=762$；
- 第 2 行第 2 列：$10\times0+(-5)\times127+4\times64=-635+256=-379$。

**缩放因子：**

- 第 1 行：$a=1\times64=64$，$b=0+6=6$；
- 第 2 行：$a=3\times64=192$，$b=2+6=8$。

按“点积 $a$ $b$”拼接：

```text
-254 64 6 446 64 6
762 192 8 -379 192 8
```

### 样例 2

$B$ 唯一的列是 $[0.0]$，$M=0$，于是 $s=0$，量化值 $q=0$，缩放因子写作 $0/2^0$，即 $a_B=0,b_B=0$。

点积为 $5\times0=0$，$a=1\times0=0$，$b=0+0=0$，输出：

```text
0 0 0
```

### 样例 3

$B$ 唯一的列是 $[1.0,-2.0]$，$M=2$，所以 $s_B=2/127$。

**量化：**

- $1.0\times127/2=63.5$，远离 0 取整得 $64$；
- $-2.0\times127/2=-127$，取整得 $-127$。

**缩放因子：** 前面已经算过，$b=12$ 时 $a=\operatorname{round}(64.5039)=65$，$b=13$ 时 $a=129>127$，所以 $a_B=65,b_B=12$。

**点积：** 用 $A$ 的量化整数 $[5,-3]$：

$$
5\times64+(-3)\times(-127)=320+381=701
$$

**结果缩放因子**：$a_A=2,b_A=3$，于是

$$
a=2\times65=130,\qquad b=3+12=15
$$

输出：

```text
701 130 15
```

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| ---- | ---------- | ---------- | ---- |
| 反量化为浮点再矩阵乘 | $O(nk+mnk)$ | $O(mk+nk)$ | 结果不是题目要求的整数三元组 |
| 按列量化 + 整数点积 | $O(nk+mnk)$ | $O(mk+nk)$ | 本题采用；无浮点累积误差 |
| 逐元素输出 | $O(mn)$ | $O(1)$ | 与矩阵乘同阶，可忽略 |

其中 $nk$ 用于量化 $B$ 的每一列（每列求一次最大值、$k$ 次量化），$mnk$ 用于 $m\times n$ 个点积。主循环里 `b` 的搜索最多 $31$ 次，是常数。

## 易错点总结

### 1. B 是按列给出的

输入的后 $n$ 行，每行就是矩阵 $B$ 的**一个列向量**。不要把它当成行再转置一次，否则量化时求的是“行的最大绝对值”，结果全错。

### 2. 量化时除以的是 $s_B=M/127$

等价于乘以 $127/M$。写成 `value / (max_abs / 127)` 与 `value * 127 / max_abs` 在数学上相同，但后者少一次中间舍入，推荐后者。

### 3. `.5` 要远离 0 取整

Python 的 `round` 是银行家舍入：`round(64.5) == 64`。本题要求四舍五入，$63.5$ 必须变成 $64$，$-63.5$ 必须变成 $-64$。必须自己实现 `round_half_away`。

### 4. 量化值要裁剪，点积不要裁剪

$B$ 的量化结果要 `clip` 到 $[-127,127]$；而 $C$ 的点积是累加结果，题面明确说不需要限制在 $[-127,127]$。样例 1 的 $762$ 就超过了 $127$。

### 5. $b_B$ 不是固定值

不能写死 $b_B=7$ 或 $b_B=30$。正确做法是取“使四舍五入后的 $a_B$ 不超过 $127$ 的最大 $b$”。样例 1 得到 $6$，样例 3 得到 $12$。

### 6. $M_j=0$ 时不能做除法

整列都是 $0$ 时 $s_B=0$，除法会抛异常。此时量化值全为 $0$，且按样例 2 的约定输出 $a_B=0,b_B=0$。

### 7. $a_A=0$ 时 $b$ 仍要相加

结果的分子是 $a_A\cdot a_B$，只要有一个为 $0$ 就是 $0$；但指数是 $b_A+b_B$，与分子是否为 $0$ 无关。写成“$a=0$ 就直接输出 `0 0 0`”是错的。

### 8. 缩放因子不要约分

$192=3\times64$ 不能约成 $3$ 或 $48$，$b$ 也不能跟着减。题面明确要求“缩放因子也无需约分”。

### 9. 输出格式是“三个整数一组”

每个结果元素占三个数：点积、$a$、$b$。同一行的 $n$ 组之间用空格分隔，共输出 $m$ 行。

## 扩展思考

- **为什么 $a$ 限制在 $127$ 以内**：$a$ 与量化值共享同一个 8 比特整数范围，便于用 `int8` 或定点指令打包存储；$a=127$ 对应最大精度。
- **$b$ 的上限为什么是 $30$**：$b$ 表示分母的二进制指数，$2^{30}$ 已经能覆盖常见的动态范围；再大就需要更宽的整数类型。
- **量化误差**：对称量化的最大绝对误差是 $s/2$，相对误差与数值大小有关。整列为 0 时不需要缩放因子，这也是要单独处理的原因。
- **非对称量化**：如果数据整体偏移（例如全为正的大数），可以引入零点 $z$，用 $q=\operatorname{round}(r/s)+z$，在同样比特数下精度更高。
- **更省算力的做法**：若 $b_A+b_B$ 固定，可以把点积结果直接右移相应位数得到近似的浮点值；本题要求保留原始三元组，所以不做移位。
- **批量矩阵乘**：实际推理框架会把多个 $(a,b)$ 打包成向量化指令，一次算完整行；本题只需要按定义逐个元素输出。
