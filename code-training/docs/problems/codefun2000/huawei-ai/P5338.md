# P5338. 整数缩放因子下的全整型矩阵乘积

> 场次：2026年9月2日 · 来源：[CodeFun2000 P5338](https://codefun2000.com/p/P5338)

## 题目描述

在模型量化中，常需要把高精度浮点数转换为低位整数。对于实数 $r$ 与缩放因子 $s$，线性量化定义为 $q=\operatorname{round}(r/s)$，反量化则恢复为 $r=sq$。在 $n$ 比特量化下，缩放因子通常取 $s=\frac{\max(|r_{\min}|,|r_{\max}|)}{2^{n-1}-1}$。矩阵可以按行或按列分别量化，并为每一行或每一列保存一个缩放因子。

为了进一步避免缩放因子参与浮点运算，可以把缩放因子 $s$ 写成两个整数 $a,b$ 的比值：$s=\frac{a}{2^b}$。这样，两个缩放因子相乘时可以表示为
$$
\frac{a_1}{2^{b_1}}\times\frac{a_2}{2^{b_2}}
=\frac{a_1a_2}{2^{b_1+b_2}}.
$$

本题要求在这种全整数缩放因子表示下完成矩阵乘法。给定已经按行完成量化的矩阵 $A$，以及尚未量化的浮点矩阵 $B$。矩阵 $A$ 的大小为 $m\times k$，矩阵 $B$ 的大小为 $k\times n$。需要计算矩阵乘积 $C=A\times B$，并以全整型量化形式输出 $C$ 的每个元素。

矩阵 $A$ 的每一行已经附加了缩放因子 $s_A=\frac{a_A}{2^{b_A}}$。矩阵 $B$ 需要按列进行 `8` 比特量化：对第 $j$ 列，先取该列所有元素绝对值的最大值，令该列缩放因子 $s_B=\frac{\max(|B_{1,j}|,\dots,|B_{k,j}|)}{127}$，然后按量化公式得到该列整数表示，并裁剪到 `[-127,127]`；同时将 $s_B$ 表示为 $\frac{a_B}{2^{b_B}}$ 的形式。

对于结果矩阵 $C$ 中第 $i$ 行第 $j$ 列的元素，其量化值为 $A$ 第 $i$ 行量化整数与 $B$ 第 $j$ 列量化整数的点积。其缩放因子为两个缩放因子的乘积：
$$
\frac{a_A}{2^{b_A}}\times\frac{a_B}{2^{b_B}}
=\frac{a_Aa_B}{2^{b_A+b_B}}.
$$
因此该元素需要输出三个整数：点积结果、$a_Aa_B$、$b_A+b_B$。点积结果不需要限制在 `[-127,127]` 内，缩放因子也无需约分。

约束条件：
- 矩阵 $A$ 每行给出的已量化整数以及矩阵 $B$ 量化后的整数均在 `-127` 到 `127` 之间。
- 缩放因子中，$a$ 的取值范围为 `0` 到 `127`，$b$ 的取值范围为 `0` 到 `30`。
- 矩阵 $B$ 使用 `8` 比特量化，量化后的整数范围为 `-127` 到 `127`。

## 输入格式

第一行包含三个整数 `m`、`k`、`n`，依次表示矩阵 $A$ 的行数、矩阵 $A$ 的列数（也是矩阵 $B$ 的行数）、矩阵 $B$ 的列数。

接下来 `m` 行，每行包含 `k+2` 个整数。前 `k` 个整数是矩阵 $A$ 当前行已经量化的整数；最后两个整数依次为该行缩放因子的 `a` 和 `b`。

再接下来 `n` 行，每行包含 `k` 个浮点数。这些行按矩阵 $B$ 的转置给出，其中第 `i` 行表示矩阵 $B$ 的第 `i` 列。

## 输出格式

输出共 `m` 行。每一行对应矩阵 $C$ 的一行，包含 $n$ 个结果元素。每个结果元素由三个整数依次组成：量化值、缩放因子的 `a`、缩放因子的 `b`。同一行内所有整数之间用空格分隔。

## 示例

### 示例 1

**输入：**

```
2 3 2
1 2 3 1 0
10 -5 4 3 2
127.0 0.0 -127.0
0.0 127.0 64.0
```

**输出：**

```
-254 64 6 446 64 6
762 192 8 -379 192 8
```

**说明：**

矩阵 $A$ 第 `1` 行的缩放因子为 $1/2^0$，即 $a_A=1,b_A=0$；第 `2` 行的缩放因子为 $3/2^2$，即 $a_A=3,b_A=2$。

矩阵 $B$ 两列的最大绝对值均为 `127`，因此 $s_B=127/127=1$。将 $1$ 表示为 $a_B/2^{b_B}$ 时，四舍五入得到 $a_B=64,b_B=6$。

计算点积如下：
- 第 `1` 行第 `1` 列：$1\times127+2\times0+3\times(-127)=-254$。
- 第 `1` 行第 `2` 列：$1\times0+2\times127+3\times64=446$。
- 第 `2` 行第 `1` 列：$10\times127+(-5)\times0+4\times(-127)=762$。
- 第 `2` 行第 `2` 列：$10\times0+(-5)\times127+4\times64=-379$。

结果缩放因子：
- 第 `1` 行：$a_A a_B=1\times64=64$，$b_A+b_B=0+6=6$。
- 第 `2` 行：$a_A a_B=3\times64=192$，$b_A+b_B=2+6=8$。

因此输出如样例输出所示。

### 示例 2

**输入：**

```
1 1 1
5 1 0
0.0
```

**输出：**

```
0 0 0
```

**说明：**

矩阵 $B$ 唯一列的元素为 $[0.0]$，最大绝对值为 `0`，因此 $s_B=0/127=0$，量化后整数仍为 `0`，缩放因子表示为 $0/2^0$，即 $a_B=0,b_B=0$。

矩阵 $A$ 的唯一量化整数为 `5`，缩放因子为 $1/2^0$。点积为 $5\times0=0$。结果缩放因子为 $a_A a_B=1\times0=0$，$b_A+b_B=0+0=0$。

因此输出 `0 0 0`。

### 示例 3

**输入：**

```
1 2 1
5 -3 2 3
1.0 -2.0
```

**输出：**

```
701 130 15
```

**说明：**

矩阵 $B$ 唯一列的元素为 $[1.0,-2.0]$，最大绝对值为 `2`，所以 $s_B=2/127$。

量化时：
- $1.0/(2/127)=63.5$，四舍五入为 `64`；
- $-2.0/(2/127)=-127$，四舍五入为 `-127`。

缩放因子 $2/127$ 按照 $a_B/2^{b_B}$ 表示并四舍五入，得到 $a_B=65,b_B=12$。

矩阵 $A$ 的量化整数为 $[5,-3]$，缩放因子为 $2/2^3$。点积为 $5\times64+(-3)\times(-127)=701$。结果缩放因子为 $a_A a_B=2\times65=130$，$b_A+b_B=3+12=15$。

因此输出 `701 130 15`。

## 解题思路

### 输出要求什么，路线就被它定了

先认清输出。$C$ 的每个元素输出的不是值本身，而是一组「量化点积、$a_Aa_B$、$b_A+b_B$」——把 $C_{i,j}\approx \dfrac{a_Aa_B\cdot\text{dot}}{2^{\,b_A+b_B}}$ 拆开后的三个整数成分。这条要求直接排除掉最直觉的路线：把 $A$、$B$ 反量化回浮点做矩阵乘，算得出浮点的 $C$，却拿不出三元组——分子与指数得再从浮点量反推，取整差之毫厘，「缩放因子无需约分」这一题面要求与浮点表示还天然冲突（约分信息一反量化就丢了）。

另一头，三元组的三个成分全是整数算术：点积是整数的积和，$a$ 是乘积，$b$ 是加和；点积按题面**不做** $[-127,127]$ 裁剪（样例 1 的 762 是正常输出），缩放因子**不做**约分。于是整道题的工程目标只有一句：让量化信息（量化整数与 $a,b$）从读入到输出全程保持整数形态，浮点只在量化比值那一步进一次。

### B 的两步量化：比值用乘法，b 取「最大可用的」

矩阵 $A$ 的量化整数与行缩放因子 $(a_A,b_A)$ 题面直接给，读进来就用。需要对 $B$ 逐列做的量化是两件事：

**量化整数**。第 $j$ 列取 $M_j=\max_i|B_{i,j}|$，缩放因子 $s_j=M_j/127$，把除法换成乘法一次完成：

$$
q_{i,j} = \operatorname{round}\bigl(B_{i,j}\times 127 / M_j\bigr)
$$

`value * MAX_QUANT / max_abs` 比「先算出 $s_j$ 再除」少一次中间舍入，两式的数学值相同、浮点结果可以不同。结果裁剪到 $[-127,127]$——理论上 $|B_{i,j}|\le M_j$ 已保证，裁剪挡的是浮点误差意外抛出的 $\pm128$。整列全 0 时 $M_j=0$，没有除法可做：量化值全 0，缩放因子按样例 2 记作 $0/2^0$。

**缩放因子的 $b$ 怎么取。** 题面只给了约束 $0\le a\le127$、$0\le b\le30$，选法要自己定；定法藏在样例里：$b$ 越大分母 $2^b$ 越细、表示越准，但要保证四舍五入后的分子不越过 127。所以约定是——

$$
b = \max\{\,b':\ \operatorname{round}(s\cdot2^{b'})\le127\,\}
$$

`column_scale` 从 $b=30$ 往下找第一个满足的，找到即返回：样例 1 的 $s=1$ 在 $b=6$ 拿到 $a=64$（$b=7$ 就是 128），样例 3 的 $s=2/127$ 在 $b=12$ 拿到 $a=65$（$b=13$ 是 129）。

### 取整口径：`.5` 远离 0

题面的「四舍五入」按字面是 `.5` 远离 0；Python 内置 `round` 是银行家舍入，在 `64.5`、`-62.5` 这类值上给出 64、−62，而远离 0 应为 65、−63。自定义的 `round_half_away` 让量化整数与缩放因子的分子走同一条取整路径——错在这一步的值，从点积到 $a$ 全部跟着错。

### 组装与输出

- 输入的后 $n$ 行**每行就是 $B$ 的一个列**（题面按转置给出）。实现把第 $j$ 行直接存为第 $j$ 列，点积按 `row_a[t] * col_b[t]` 对位——转置是理解题意时完成的，不是数据操作。
- 输出循环对每个 $(i,j)$ 算 `dot = Σ row_a[t]*col_b[t]`，然后 `f"{dot} {a_a*a_b} {b_a+b_b}"`。分子哪怕算出 0（例如 $a_A=0$ 或整列 $B$ 为 0），指数 $b$ 也照加不误。

## 完整代码实现

```python
import math
import sys

# 8 比特量化，缩放因子的分子上限。
MAX_QUANT = 127
# 缩放因子的指数上限，题面给出 0 <= b <= 30。
MAX_SHIFT = 30


def round_half_away(value: float) -> int:
    """四舍五入（.5 向远离 0 的方向取整）。"""
    if value >= 0:
        return int(math.floor(value + 0.5))
    return int(math.ceil(value - 0.5))


def quantize_column(values, max_abs):
    """
    把一列浮点数量化成 [-127, 127] 内的整数。

    s_B = max_abs / 127，所以 value / s_B = value * 127 / max_abs。
    直接用乘法再除，避免先算出 s_B 引入一次额外的舍入。
    """
    if max_abs == 0.0:
        # 整列都是 0：缩放因子退化为 0，量化值也只能是 0。
        return [0] * len(values)

    result = []
    for value in values:
        q = round_half_away(value * MAX_QUANT / max_abs)
        # 理论上 |value| <= max_abs 已经保证 |q| <= 127，
        # 这里再裁剪一次，挡住浮点误差带来的 128 / -128。
        if q > MAX_QUANT:
            q = MAX_QUANT
        elif q < -MAX_QUANT:
            q = -MAX_QUANT
        result.append(q)
    return result


def column_scale(max_abs: float):
    """
    把 s_B = max_abs / 127 表示成 a / 2^b。

    b 取“四舍五入后的 a 不超过 127”的最大值：b 越大，分母越细，
    表示精度越高；直到 a 再往上就会越过 8 比特缩放因子的上限。
    """
    if max_abs == 0.0:
        # 与样例 2 一致：0 表示为 0 / 2^0。
        return 0, 0

    scale = max_abs / MAX_QUANT

    # 从大到小找第一个满足 a <= 127 的 b，找到即可返回。
    for shift in range(MAX_SHIFT, -1, -1):
        a = round_half_away(scale * (1 << shift))
        if a <= MAX_QUANT:
            return a, shift

    # 防御性分支：s_B 大到即使 b = 0 也超过 127（题面约束下不会出现）。
    return MAX_QUANT, 0


def solve():
    """读入 A、B，按列量化 B，输出 C 的每个元素与对应缩放因子。"""
    data = sys.stdin.buffer.read().split()
    if len(data) < 3:
        return

    it = iter(data)
    m = int(next(it))
    k = int(next(it))
    n = int(next(it))

    # A 的每行：k 个量化整数 + 缩放因子的 a、b。
    quant_a = []
    scale_a = []
    for _ in range(m):
        row = [int(next(it)) for _ in range(k)]
        a = int(next(it))
        b = int(next(it))
        quant_a.append(row)
        scale_a.append((a, b))

    # B 按列给出：第 j 行就是 B 的第 j 列。
    quant_b = []
    scale_b = []
    for _ in range(n):
        values = [float(next(it)) for _ in range(k)]
        max_abs = max(abs(v) for v in values)
        quant_b.append(quantize_column(values, max_abs))
        scale_b.append(column_scale(max_abs))

    lines = []
    for i in range(m):
        row_a = quant_a[i]
        a_a, b_a = scale_a[i]
        parts = []
        for j in range(n):
            col_b = quant_b[j]
            # 全整型点积：两个量化整数数组逐项相乘再求和。
            dot = sum(row_a[t] * col_b[t] for t in range(k))
            a_b, b_b = scale_b[j]
            # 缩放因子相乘：分子相乘，指数相加，绝不约分。
            parts.append(f"{dot} {a_a * a_b} {b_a + b_b}")
        lines.append(" ".join(parts))

    print("\n".join(lines))


if __name__ == "__main__":
    solve()
```

## 示例推演

样例 1：$m=2$，$k=3$，$n=2$。$A$ 第 1 行缩放因子 $1/2^0$（$a=1,b=0$），第 2 行 $3/2^2$（$a=3,b=2$）；两列 $B$ 的最大绝对值都是 127，$s_B=127/127=1$，量化值与原值相同（$127,0,-127$ 与 $0,127,64$）。缩放因子从 $b=30$ 向下搜，首个满足 $\operatorname{round}(s\cdot2^b)\le127$ 的是 $b=6$（$a=64$；$b=7$ 时已是 128）。

| 位置 | 点积 | 结果 $a$ | 结果 $b$ |
| ---- | ---- | -------- | -------- |
| $C_{1,1}$ | $1\times127+2\times0+3\times(-127)=-254$ | $1\times64=64$ | $0+6=6$ |
| $C_{1,2}$ | $1\times0+2\times127+3\times64=446$ | $64$ | $6$ |
| $C_{2,1}$ | $10\times127+(-5)\times0+4\times(-127)=762$ | $3\times64=192$ | $2+6=8$ |
| $C_{2,2}$ | $10\times0+(-5)\times127+4\times64=-379$ | $192$ | $8$ |

```text
-254 64 6 446 64 6
762 192 8 -379 192 8
```

注意 $762$ 超过了 127——点积不做裁剪，这是题面明说的。

样例 3 把两条细则都照了出来。列 $[1.0,-2.0]$ 的 $M=2$，$s=2/127$：量化 $1.0\times127/2=63.5$ 远离 0 得 $64$，$-2.0\times127/2=-127$；缩放因子 $s\cdot2^{12}=64.504\to65$ 可用、$b=13$ 时 129 超限，得 $a_B=65,b_B=12$。点积 $5\times64+(-3)\times(-127)=701$，结果 $a=2\times65=130$、$b=3+12=15$，输出 `701 130 15`。

样例 2 的列是 $[0.0]$：$M=0$，量化值全 0，缩放因子记 $0/2^0$；点积 $5\times0=0$，$a=1\times0=0$、$b=0+0=0$，输出 `0 0 0`——分子为 0 不改变 $b$ 照加的规则。

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| ---- | ---------- | ---------- | ---- |
| 反量化为浮点再做矩阵乘 | $O(nk+mnk)$ | $O(mk+nk)$ | 算得出浮点的 $C$，拿不出题面要的整数三元组 |
| 按列量化 + 全整型点积（最优） | $O(nk+mnk)$ | $O(mk+nk)$ | 浮点只出现在量化比值一步，其余全整数；本题采用 |

全部 $m\times n$ 个 $k$ 维点积合计 $mnk$ 次乘法；`column_scale` 的 $b$ 搜索每次至多 31 轮，是常数。

## 易错点总结

### 1. `.5` 要远离 0，不能用内置 `round`

Python 的 `round` 是银行家舍入：`round(64.5) == 64`、`round(-62.5) == -62`，而题面的四舍五入要的是 65、−63。量化整数（`round_half_away(value * MAX_QUANT / max_abs)`）与缩放因子的分子（`round_half_away(scale * (1 << shift))`）都必须走自写的 `round_half_away`；用了内置 round，落在 `.5` 上的值差 1，而错在量化源头，点积与结果的 $a$ 全部被带偏。

### 2. 缩放因子的 b 不能写死

$b$ 是「使 round$(s\cdot2^b)\le127$ 的最大值」，随各列的最大绝对值变化：样例 1 得 6，样例 3 得 12。写死任何常数都会在某列算出超过 127 的分子（违反 $0\le a\le127$），或凭空损失精度——样例 1 的 $a_B=64$ 会立即对不上。`column_scale` 里从 $b=30$ 倒着找第一个满足的分支就是这条约定。

### 3. 整列为 0 时不能做除法

列全 0 时 $M_j=0$、$s_j=0$，`value * MAX_QUANT / max_abs` 的除法直接抛 `ZeroDivisionError`，整组测试一无所出。`quantize_column` 与 `column_scale` 各自把 `max_abs == 0.0` 放在分支最前面：量化值全 0、缩放因子记 $0/2^0$，口径来自样例 2。

## 扩展思考

- 结果的 $b=b_A+b_B$ 会随逐层相乘不断增大；真正推理引擎通常按「右移足量位数后重新量化」回收指数。本题按题面保留原始三元组，不做移位。
- 对称量化的误差上界是 $s/2$，与数值本身的大小无关；数据整体偏移时，可引入零点 $z$ 做非对称量化，同样位宽下精度更高。
