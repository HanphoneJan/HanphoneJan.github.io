# P5458. 编码器层前向计算

> 场次：2026年9月16日 · 来源：[CodeFun2000 P5458](https://codefun2000.com/p/P5458)

## 题目描述

实现一层标准的 Transformer Encoder Layer。该层依次包含两个子层：

- 多头自注意力（Multi-Head Self-Attention, MHSA）
- 逐位置前馈网络（Position-wise Feed-Forward Network, FFN）

每个子层的计算完成之后，立刻做残差连接，再做层归一化（Post-LN）：

$$\mathrm{SublayerOut}=\mathrm{LayerNorm}\bigl(x+\mathrm{Sublayer}(x)\bigr)$$

整层顺序为：先对输入做 MHSA 子层（残差 + LN），再对结果做 FFN 子层（残差 + LN）。

### 固定设定

为使评测结果唯一，按下述约定实现，不要自行改成 Pre-LN 或改权重。

- 输入张量 $x$ 的形状为 $(\textit{batch},\textit{seq},\textit{d\_model})=(1,2,4)$。
- 头数 $h=2$，因此每头维度 $d_k=d_{\textit{model}}/h=2$。
- 注意力与输出投影、FFN 的权重均为 $4\times 4$ 单位矩阵：$W_Q=W_K=W_V=W_O=W_1=W_2=I$。
- FFN 偏置 $b_1=b_2=\mathbf{0}$。
- 层归一化的 $\gamma=\mathbf{1}$，$\beta=\mathbf{0}$，$\varepsilon=10^{-5}$。均值与方差都在最后一个维度上统计，方差用总体方差（除以 $d_{\textit{model}}$，不要除以 $d_{\textit{model}}-1$）。

### 公式

缩放点积注意力（每个头内独立计算，在序列维上做 softmax）：

$$\mathrm{Attention}(Q,K,V)=\mathrm{softmax}\left(\frac{QK^{\top}}{\sqrt{d_k}}\right)V$$

多头拼接后再乘输出投影：

$$\mathrm{MultiHead}(Q,K,V)=\mathrm{Concat}(\textit{head}_1,\ldots,\textit{head}_h)W_O$$

切分方式：把最后一维按长度 $d_k$ 切成 $h$ 段，第 $t$ 个头取特征区间 $[t\cdot d_k,(t+1)\cdot d_k)$。

层归一化：

$$\mathrm{LayerNorm}(x)=\frac{x-\mathbb{E}[x]}{\sqrt{\mathrm{Var}[x]+\varepsilon}}\cdot\gamma+\beta$$

FFN（ReLU）：

$$\mathrm{FFN}(x)=\max(0,xW_1+b_1)W_2+b_2$$

softmax 在实现时先减去当前行最大值再 $\exp$，避免溢出。

## 输入格式

一行 $8$ 个实数，按行优先给出 $x$，即

$$x[0,0,0],\ x[0,0,1],\ x[0,0,2],\ x[0,0,3],\ x[0,1,0],\ x[0,1,1],\ x[0,1,2],\ x[0,1,3]$$

## 输出格式

一行 $8$ 个实数，把形状为 $(1,2,4)$ 的输出按同样顺序平铺。每个数四舍五入到小数点后 $2$ 位。

## 数据范围

$8$ 个分量均满足 $|x_i|\le 50$。

## 示例

### 示例 1

**输入：**

```
2.00 0.00 0.00 0.00 0.00 2.00 0.00 0.00
```

**输出：**

```
1.73 -0.55 -0.59 -0.59 -0.55 1.73 -0.59 -0.59
```

**说明：**

两个位置分别是 $(2,0,0,0)$ 与 $(0,2,0,0)$。

第 $0$ 个头上，$Q=K=V$ 为 $\bigl[(2,0),\ (0,2)\bigr]$，缩放后得分矩阵对角线为 $4/\sqrt{2}=2\sqrt{2}\approx 2.828$，另一侧为 $0$。softmax 后约 $\bigl[(0.944,0.056),\ (0.056,0.944)\bigr]$，该头输出约 $\bigl[(1.888,0.112),\ (0.112,1.888)\bigr]$。第 $1$ 个头全 $0$，拼接后与 $x$ 相加再 LN、ReLU、残差、LN，得到上述输出。

若把残差拿掉，或改成 Pre-LN，第一维不会落到 $1.73$。

### 示例 2

**输入：**

```
1.00 0.00 1.00 0.00 0.00 1.00 0.00 1.00
```

**输出：**

```
1.00 -1.00 1.00 -1.00 -1.00 1.00 -1.00 1.00
```

**说明：**

两个位置为 $(1,0,1,0)$ 与 $(0,1,0,1)$，两个头的 $Q,K,V$ 相同。MHSA 后与 $x$ 相加，每个位置都是两个 $1.670$ 与两个 $0.330$ 交错；第一次 LN 已把它们变成 $\pm 1$。ReLU 只保留正分量，第二次 LN 后仍是 $\pm 1.00$ 的交错图案。
