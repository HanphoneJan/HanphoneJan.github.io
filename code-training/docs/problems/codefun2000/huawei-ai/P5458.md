# P5458. 编码器层前向计算

> 场次：2026年9月16日 · 来源：[CodeFun2000 P5458](https://codefun2000.com/p/P5458)

## 题目描述

实现一层标准的 Transformer Encoder Layer。该层依次包含两个子层：

- 多头自注意力（Multi-Head Self-Attention, MHSA）
- 逐位置前馈网络（Position-wise Feed-Forward Network, FFN）

每个子层的计算完成之后，立刻做残差连接，再做层归一化（Post-LN）：

$$\mathrm{SublayerOut}=\mathrm{LayerNorm}\bigl(x+\mathrm{Sublayer}(x)\bigr)$$

整层顺序为：先对输入做 MHSA 子层（残差 + LN），再对结果做 FFN 子层（残差 + LN）。

### 固定设定

为使评测结果唯一，按下述约定实现，不要自行改成 Pre-LN 或改权重。

- 输入张量 $x$ 的形状为 $(\textit{batch},\textit{seq},\textit{d\_model})=(1,2,4)$。
- 头数 $h=2$，因此每头维度 $d_k=d_{\textit{model}}/h=2$。
- 注意力与输出投影、FFN 的权重均为 $4\times 4$ 单位矩阵：$W_Q=W_K=W_V=W_O=W_1=W_2=I$。
- FFN 偏置 $b_1=b_2=\mathbf{0}$。
- 层归一化的 $\gamma=\mathbf{1}$，$\beta=\mathbf{0}$，$\varepsilon=10^{-5}$。均值与方差都在最后一个维度上统计，方差用总体方差（除以 $d_{\textit{model}}$，不要除以 $d_{\textit{model}}-1$）。

### 公式

缩放点积注意力（每个头内独立计算，在序列维上做 softmax）：

$$\mathrm{Attention}(Q,K,V)=\mathrm{softmax}\left(\frac{QK^{\top}}{\sqrt{d_k}}\right)V$$

多头拼接后再乘输出投影：

$$\mathrm{MultiHead}(Q,K,V)=\mathrm{Concat}(\textit{head}_1,\ldots,\textit{head}_h)W_O$$

切分方式：把最后一维按长度 $d_k$ 切成 $h$ 段，第 $t$ 个头取特征区间 $[t\cdot d_k,(t+1)\cdot d_k)$。

层归一化：

$$\mathrm{LayerNorm}(x)=\frac{x-\mathbb{E}[x]}{\sqrt{\mathrm{Var}[x]+\varepsilon}}\cdot\gamma+\beta$$

FFN（ReLU）：

$$\mathrm{FFN}(x)=\max(0,xW_1+b_1)W_2+b_2$$

softmax 在实现时先减去当前行最大值再 $\exp$，避免溢出。

## 输入格式

一行 $8$ 个实数，按行优先给出 $x$，即

$$x[0,0,0],\ x[0,0,1],\ x[0,0,2],\ x[0,0,3],\ x[0,1,0],\ x[0,1,1],\ x[0,1,2],\ x[0,1,3]$$

## 输出格式

一行 $8$ 个实数，把形状为 $(1,2,4)$ 的输出按同样顺序平铺。每个数四舍五入到小数点后 $2$ 位。

## 数据范围

$8$ 个分量均满足 $|x_i|\le 50$。

## 示例

### 示例 1

**输入：**

```
2.00 0.00 0.00 0.00 0.00 2.00 0.00 0.00
```

**输出：**

```
1.73 -0.55 -0.59 -0.59 -0.55 1.73 -0.59 -0.59
```

**说明：**

两个位置分别是 $(2,0,0,0)$ 与 $(0,2,0,0)$。

第 $0$ 个头上，$Q=K=V$ 为 $\bigl[(2,0),\ (0,2)\bigr]$，缩放后得分矩阵对角线为 $4/\sqrt{2}=2\sqrt{2}\approx 2.828$，另一侧为 $0$。softmax 后约 $\bigl[(0.944,0.056),\ (0.056,0.944)\bigr]$，该头输出约 $\bigl[(1.888,0.112),\ (0.112,1.888)\bigr]$。第 $1$ 个头全 $0$，拼接后与 $x$ 相加再 LN、ReLU、残差、LN，得到上述输出。

若把残差拿掉，或改成 Pre-LN，第一维不会落到 $1.73$。

### 示例 2

**输入：**

```
1.00 0.00 1.00 0.00 0.00 1.00 0.00 1.00
```

**输出：**

```
1.00 -1.00 1.00 -1.00 -1.00 1.00 -1.00 1.00
```

**说明：**

两个位置为 $(1,0,1,0)$ 与 $(0,1,0,1)$，两个头的 $Q,K,V$ 相同。MHSA 后与 $x$ 相加，每个位置都是两个 $1.670$ 与两个 $0.330$ 交错；第一次 LN 已把它们变成 $\pm 1$。ReLU 只保留正分量，第二次 LN 后仍是 $\pm 1.00$ 的交错图案。

## 解题思路

### 题面把自由度全部收走，实现是一场忠实执行

这道题没有「选算法」这一步：形状 $(1,2,4)$、头数 $h=2$、全部权重是单位矩阵、FFN 偏置为零、$\gamma=1$、$\beta=0$、$\varepsilon=10^{-5}$、Post-LN、总体方差——能把输出变得不同的位置全被题面钉死。把钉死项过一遍，工作量自己浮现出来：

- $W_Q=W_K=W_V=I$：投影消失，$Q=K=V=x$。第 $t$ 个头就是最后一维上的特征区间 $[t\cdot d_k,(t+1)\cdot d_k)$，本题第 0 头拿第 $0,1$ 维、第 1 头拿第 $2,3$ 维——**按区间切，不是交错取**；
- $W_O=I$：多头拼接之后不需要再做输出投影；
- $W_1=W_2=I$、$b_1=b_2=\mathbf 0$：$\mathrm{FFN}(y)=\mathrm{ReLU}(y)$，两次矩阵乘化成一次逐元素截断。

整层真正要计算的只剩三件事：每个头内 $(2,2)$ 的缩放点积打分、序列维上的 softmax、夹在两次残差相加之间的最后一维层归一化。剩下的工作是把这些算子按 Post-LN 摆正：$\mathrm{first}=\mathrm{LN}(x+\mathrm{MHSA}(x))$，$\mathrm{second}=\mathrm{LN}(\mathrm{first}+\mathrm{ReLU}(\mathrm{first}))$——先残差相加再 LN，而不是反过来。

这些钉死项在样例上各有验收点：切头方式若错按奇偶交错取维，第 0 个头拿到的两个位置就从 $(2,0),(0,2)$ 变成 $(2,0),(0,0)$，内容全变，样例 1 的输出不再一致；Post-LN 与残差的顺序，题面在示例说明里直接给了判据——「拿掉残差，或改成 Pre-LN，第一维不会落到 $1.73$」。边写边用样例钉住每一个犹豫点，比写完再排查省力得多。

### 剩下属于实现自己的两个决定

其一，按固定形状写。$seq=2$、$d_{model}=4$ 都是常数：照公式直译一套通用三维张量乘也能算对，但代码里会多一些为通用性服务的下标换算，容易在 batch 维、头维上出错；按固定形状写，每个算子就是几行算术，数据流一眼见底，这也是把本题写「对」最省力的路径。

其二，保住数值稳定的 softmax。本题 $|x_i|\le50$，单头点积最大约 $2\times50^2/\sqrt2\approx3535$，$\exp(3535)$ 必然溢出；先减去该行最大值再取指数，分布不变，这一步由数据范围直接推出，不是可选项。

其余实现选择在代码里都有落点：`layer_norm` 三行把「方差除以 $n$、$\varepsilon$ 在根号内」钉住；`encoder_layer` 用两个列表推导式表达两次「残差 + LN」，子层函数分别是 MHSA 与 ReLU；`format_number` 负责两位小数与浮点翻出的 `-0.00`。

输入输出的形状也要对得上题面：$8$ 个实数按行优先平铺，前 $4$ 个是位置 $0$、后 $4$ 个是位置 $1$，读入后切成 $(seq,d_{model})$ 的二维表，输出按同样顺序平铺。文件头的常量组（`SEQ_LEN`、`D_MODEL`、`NUM_HEADS`、`D_K`、`LAYER_NORM_EPS`）逐条注释与题面对照，作用是让每个钉死值都有名字，写算子时不必回头翻题面。

## 完整代码实现

```python
import math
import sys

# 题目固定的模型设定。写成常量而不是魔法数字，便于对照题面。
SEQ_LEN = 2          # 序列长度
D_MODEL = 4          # 每个位置的特征维度
NUM_HEADS = 2        # 头数
D_K = D_MODEL // NUM_HEADS  # 每头维度 = 2
LAYER_NORM_EPS = 1e-5


def layer_norm(vector):
    """在最后一维上做层归一化（gamma = 1，beta = 0，总体方差）。"""
    n = len(vector)
    mean = sum(vector) / n

    # 题目明确要求总体方差：除以 n，而不是 n - 1。
    variance = sum((v - mean) ** 2 for v in vector) / n

    # eps 放在根号里面，和题面公式 sqrt(Var + eps) 完全一致。
    std = math.sqrt(variance + LAYER_NORM_EPS)
    return [(v - mean) / std for v in vector]


def multi_head_attention(x):
    """多头自注意力。权重矩阵都是单位矩阵，所以 Q = K = V = x。"""
    scale = math.sqrt(D_K)
    output = [[0.0] * D_MODEL for _ in range(SEQ_LEN)]

    # 按特征区间 [t*d_k, (t+1)*d_k) 逐个处理每个头。
    for head in range(NUM_HEADS):
        lo = head * D_K
        hi = lo + D_K

        for i in range(SEQ_LEN):
            # 第 i 个位置在该头内的 query 与所有位置的 key 做点积并缩放。
            scores = []
            for j in range(SEQ_LEN):
                dot = 0.0
                for t in range(lo, hi):
                    dot += x[i][t] * x[j][t]
                scores.append(dot / scale)

            # 减行最大值只改变数值稳定性，不改变 softmax 的结果。
            max_score = max(scores)
            exp_scores = [math.exp(s - max_score) for s in scores]
            total = sum(exp_scores)

            # 用注意力权重对本头的 V 加权求和，写回拼接结果的对应区间。
            for j in range(SEQ_LEN):
                weight = exp_scores[j] / total
                for t in range(lo, hi):
                    output[i][t] += weight * x[j][t]

    return output


def encoder_layer(x):
    """Post-LN 编码器层：MHSA 子层 + FFN 子层，各带残差与层归一化。"""
    # 子层 1：多头自注意力。W_O 是单位矩阵，所以拼接结果直接就是输出。
    attention = multi_head_attention(x)
    first = [
        layer_norm([x[i][d] + attention[i][d] for d in range(D_MODEL)])
        for i in range(SEQ_LEN)
    ]

    # 子层 2：W_1 = W_2 = I、b_1 = b_2 = 0，因此 FFN(y) = ReLU(y)。
    ffn = [[max(0.0, v) for v in row] for row in first]
    second = [
        layer_norm([first[i][d] + ffn[i][d] for d in range(D_MODEL)])
        for i in range(SEQ_LEN)
    ]

    return second


def format_number(value: float) -> str:
    """保留两位小数，并把极其接近 0 的负数归零，避免输出 -0.00。"""
    if abs(value) < 0.005:
        value = 0.0
    return f"{value:.2f}"


def solve():
    """读取 8 个实数，输出编码器层前向计算结果。"""
    tokens = sys.stdin.buffer.read().split()
    if len(tokens) < SEQ_LEN * D_MODEL:
        return

    values = [float(t) for t in tokens[:SEQ_LEN * D_MODEL]]

    # 按行优先还原成 (seq, d_model) 的二维表：前 4 个是位置 0，后 4 个是位置 1。
    x = [values[i * D_MODEL:(i + 1) * D_MODEL] for i in range(SEQ_LEN)]

    result = encoder_layer(x)

    # 输出同样按行优先平铺，同一个位置的分量挨在一起。
    flat = [format_number(v) for row in result for v in row]
    print(" ".join(flat))


if __name__ == "__main__":
    solve()
```

## 示例推演

### 样例 1

两个位置是 $x_0=(2,0,0,0)$、$x_1=(0,2,0,0)$。

**第 0 个头**（区间 $[0,2)$）：$Q=K=V=\bigl[(2,0),(0,2)\bigr]$，缩放后分数矩阵的对角线为 $4/\sqrt2\approx2.828427$、另一侧为 $0$；每行 softmax 得权重 $(0.944193,\ 0.055807)$，加权求和：

$$\text{head}_0=\begin{pmatrix}1.888386 & 0.111614\\ 0.111614 & 1.888386\end{pmatrix}$$

**第 1 个头**（区间 $[2,4)$）：两个位置在该区间上都是 $(0,0)$，分数全 $0$，softmax 得 $(0.5,0.5)$，但 $V$ 也是 $0$，输出全 $0$。拼接后（$W_O=I$ 不再变换）：

$$\text{attn}=\begin{pmatrix}1.888386 & 0.111614 & 0 & 0\\ 0.111614 & 1.888386 & 0 & 0\end{pmatrix}$$

**残差 + 第一次 LN**：第一行 $x+\text{attn}=(3.888386,\ 0.111614,\ 0,\ 0)$，均值 $\mu=1$，偏差 $(2.888386,\ -0.888386,\ -1,\ -1)$，

$$\mathrm{Var}=\frac{2.888386^2+0.888386^2+1^2+1^2}{4}=2.783000,\qquad \sigma=\sqrt{2.783+10^{-5}}\approx1.668235$$

$$\mathrm{LN}_1=(1.731401,\ -0.532530,\ -0.599436,\ -0.599436)$$

第二行是前两维互换的镜像，结果对称。

**FFN = ReLU**：只留正分量，$\mathrm{ReLU}(\mathrm{LN}_1)=(1.731401,\ 0,\ 0,\ 0)$。

**残差 + 第二次 LN**：第一行变成 $(3.462801,\ -0.532530,\ -0.599436,\ -0.599436)$，均值 $0.432850$，方差 $3.060950$，标准差 $1.749557$：

$$\mathrm{LN}_2=(1.731837,\ -0.551785,\ -0.590026,\ -0.590026)$$

第二行镜像，完整输出：

```text
1.73 -0.55 -0.59 -0.59 -0.55 1.73 -0.59 -0.59
```

值得盯住第二维：第一次 LN 给它是 $-0.53$，最终输出却是 $-0.55$。ReLU 掐掉三个分量之后，残差行的均值、方差都变了，这一维被重新标准化了一次——第二次 LN 不是走过场，每个分量都要重算。

### 样例 2

两个位置 $(1,0,1,0)$、$(0,1,0,1)$：两个头的内容相同，分数对角线 $1/\sqrt2\approx0.707107$，softmax 权重 $(0.669762,\ 0.330238)$。残差相加后每个位置是 $(1.669762,\ 0.330238,\ 1.669762,\ 0.330238)$，均值恰为 $1$、四个偏差绝对值都是 $0.669762$，第一次 LN 把它们压成 $\pm1$；ReLU 只留正分量，第二次 LN 后仍是 $\pm1$ 的交错图案，输出：

```text
1.00 -1.00 1.00 -1.00 -1.00 1.00 -1.00 1.00
```

两个样例的分数都不大，softmax 处在温和区间。自测里还有一组把样例 1 放大 $25$ 倍：头 0 的缩放分数涨到约 $442$，softmax 彻底退化成「只看自己」，注意力输出恰好等于 $x$ 本身；这时两个位置在一次 LN、ReLU、第二次 LN 之后的方差与均值完全一样，输出的差别只剩前两维的镜像互换。这也从数值上验证了「减去行最大值不改变 softmax 的分布」。

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| ---- | ---------- | ---------- | ---- |
| 通用公式直译 | $O(seq^2\cdot d_{model}+seq\cdot d_{model}^2)$ | $O(seq\cdot d_{model})$ | 写通用矩阵乘与三维下标，要处理拼接与输出投影 |
| 消掉单位矩阵、按区间切头（最优） | $O(seq^2\cdot d_{model})$ | $O(seq\cdot d_{model})$ | 只算注意力主体；常数更小、下标更少 |

形状固定为 $(2,4)$，两种写法的绝对运算量都只有几十次浮点操作，差别落在代码的可读性上下。

## 易错点总结

### 1. Post-LN 的顺序：先残差相加，再 LN

`first = layer_norm([x[i][d] + attention[i][d] ...])`。写成 $\mathrm{MHSA}(\mathrm{LN}(x))+x$ 就是 Pre-LN，数值完全不同；漏掉残差一样翻车。两处错误都被样例 1 当场检举：第一维落不到 $1.73$。

### 2. 方差除以 $d_{model}$（不是 $d_{model}-1$），$\varepsilon$ 在根号里面

`variance = sum((v - mean) ** 2) / n` 要除以 $4$：惯性写成样本方差（除以 $3$）时，样例 1 第一次 LN 的标准差从 $1.668$ 变成约 $1.926$，第一位小数就错。$\varepsilon$ 则要放进 `math.sqrt(variance + LAYER_NORM_EPS)`——公式是 $\sqrt{\mathrm{Var}+\varepsilon}$，写到根号外或漏掉，会在第二位小数上露馅。

### 3. softmax 减行最大值、按行（序列维）归一化

`max_score = max(scores)` 之后逐项 `exp(s - max_score)`，再用**同一行**的 `total` 归一化。分数矩阵的每一行是「一个 query 对所有 key」的分布，按列或整张矩阵归一化都会让权重和偏离 $1$，输出整体失真；不减最大值则在大分数上溢出成 `inf`。两步都在 `multi_head_attention` 的同一段里，改一处别忘了另一处。

## 扩展思考

- 换成 Pre-LN 只动 `encoder_layer` 的两行顺序：$x\leftarrow x+\mathrm{MHSA}(\mathrm{LN}(x))$、$x\leftarrow x+\mathrm{FFN}(\mathrm{LN}(x))$，数值立刻不同——这本身就是一个现成的对照实验。
- 权重换成非单位矩阵时，在切头前补 $xW_Q,xW_K,xW_V$、拼接后补乘 $W_O$、FFN 补两次矩阵乘即可，算子顺序完全不变。
