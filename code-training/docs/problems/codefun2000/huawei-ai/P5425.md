# P5425. 语义邻域可达

> 场次：2026年9月11日 · 来源：[CodeFun2000 P5425](https://codefun2000.com/p/P5425)

## 题目描述

文档检索系统需要判断片段是否相关。本题将每个文档片段视为平面上的一个点。为提高检索效率，要判定两个片段是否属于同一语义簇：若它们密度相连，则认为语义相近。

### 概念说明

给定一组点，以及两个参数：邻域半径 $\varepsilon$、最小点数 $MinPts$。

- $\varepsilon$-邻域：点 $p$ 的 $\varepsilon$-邻域是所有到 $p$ 的距离不超过 $\varepsilon$ 的点（含 $p$ 自身）。距离取欧氏距离
  $$dist(p,q)=\sqrt{(x_1-x_2)^2+(y_1-y_2)^2}$$
- 核心点：若点 $p$ 的 $\varepsilon$-邻域内至少有 $MinPts$ 个点，则 $p$ 是核心点。
- 密度相连：点 $p$ 与点 $q$ 密度相连，当且仅当存在核心点 $o$，从 $o$ 出发能分别沿着核心点的“路径”走到 $p$ 和 $q$，路径上的每一步，都必须从一个核心点走到其 $\varepsilon$-邻域内的某个点。

几个直接推论：

- 同一簇内的点彼此密度相连
- 噪声点（未落入任何核心点的 $\varepsilon$-邻域）不与任何点密度相连
- 两个边界点（位于某核心点邻域内、自身却不是核心点）若被同一个核心点覆盖，则密度相连

## 输入格式

第一行四个数：$N$、$M$、$\varepsilon$、$MinPts$

- $N$：点的数量
- $M$：询问数量
- $\varepsilon$：邻域半径
- $MinPts$：成为核心点所需的最少邻域点数

接下来 $N$ 行：每行两个浮点数 $x_i$、$y_i$，按顺序给出编号为 $0$ 到 $N-1$ 的点的坐标。

接下来 $M$ 行：每行两个整数 $a$、$b$，询问点 $a$ 与点 $b$ 是否密度相连。

## 数据范围

- $1 \le N,M \le 1000$
- $0 < \varepsilon \le 1000$
- $2 \le MinPts \le N$
- $-10000 \le$ 坐标值 $\le 10000$

## 输出格式

共 $M$ 行，每行一个整数：

- $1$ 表示密度相连
- $0$ 表示不密度相连

## 提示

提示：可按密度聚类 / 密度可达来做判定。

## 示例

### 示例 1

**输入：**

```
6 4 2.0 3
0.0 0.0
1.2 0.0
0.4 1.0
12.0 0.0
12.5 0.4
6.0 6.0
0 2
0 3
3 4

```

**输出：**

```

0
0

```

**说明：**

$\varepsilon=2.0$，$MinPts=3$。

点 $0,1,2$ 两两距离分别为 $1.2$、$\sqrt{1.16}\approx 1.077$、$\sqrt{1.64}\approx 1.281$，均不超过 $2.0$，每个点的邻域大小都是 $3$，因此都是核心点，彼此密度相连。

点 $3$ 与点 $4$ 相距 $\sqrt{0.41}\approx 0.640\le 2.0$，但各自邻域只有 $2$ 个点，不是核心点，也没有核心点能走到它们，因此是噪声点，彼此不密度相连。

点 $5$ 邻域只有自身，同样是噪声点。

点 $3$ 与点 $4$ 分属不同簇，不密度相连。点 $7$ 是噪声点。

## 解题思路

### 先把「密度相连」翻译成集合问题

定义里真正起作用的是「每一步都**从一个核心点**走到它 $\varepsilon$-邻域内的某个点」。这一句把三种点的角色钉死了：

- 核心点能当中转站，路径可以一核心点接一核心点地接力下去；
- 边界点（自身不是核心，但落在某个核心点邻域里）只能当终点，走到它就停；
- 噪声点连终点都当不上，它与任何点都不密度相连，**包括它自己**。

把距离不超过 $\varepsilon$ 且都是核心点的点对连边，每个连通分量称为一个**核心连通块**；一个块的可达点集，是块内所有核心点邻域的并集。于是判定等价于：

> 存在某个核心连通块，它的可达点集同时包含 $a$ 和 $b$。

注意是「存在**某一个**」，不是「各有一个」：$a$ 只被块 $A$ 覆盖、$b$ 只被块 $B$ 覆盖时，两者虽然各有核心能达到，却没有任何一个核心点能同时走到它们，答案仍是 $0$。所以每个点记录的是「能覆盖它的块的集合」，询问查的是集合交集。

这份集合不是过渡设计，一个反例足以说明。取 $\varepsilon=5$、$MinPts=4$，七个点横排成一行：

```text
   点1 (0,4)          点4 (10,4)

   点0 (0,0) ---- 点6 (5,0) ---- 点3 (10,0)

   点2 (0,-4)         点5 (10,-4)
```

点 $0$ 覆盖 $\{0,1,2,6\}$、点 $3$ 覆盖 $\{3,4,5,6\}$，都是核心点；两点相距 $10>\varepsilon$，分属两个核心连通块 $A$、$B$。点 $6$ 的邻域 $\{0,3,6\}$ 只有 $3$ 个点，是边界点，恰好被左右两块同时覆盖。正确结论是：$0$ 与 $3$ **不**相连——从 $0$ 到 $3$ 的路径必须以 $6$ 作中转，而 $6$ 没有中转资格；$6$ 却与**两边**都相连。

实现走两条捷径都会在这里翻车。把「核心点与邻域内的点」直接 `union` 进并查集，块 $A$、$B$ 会被 $6$ 粘成一个，$0$ 与 $3$ 判成 $1$；每个点只记一个块编号，$6$ 与 $3$ 又判成 $0$。集合交把两条都拦住：$\text{groups}[6]=\{A,B\}$，$\text{groups}[0]\cap\text{groups}[3]=\varnothing$，而 $\text{groups}[6]\cap\text{groups}[3]=\{B\}$。

集合表示还顺手处理了两个特例：噪声点挂空集，$\varnothing\cap\varnothing=\varnothing$，自询输出 $0$；边界点自询输出 $1$，因为有核心能走到它。这两个特例都不需要单独写判断。

### 数据范围：预处理一次，询问只查交集

$N,M\le1000$。全部点对约 $5\times10^5$，用平方距离逐对比较，这样的扫描做上几遍也只是千万级浮点运算，付得起。撑不起的是把判定搬进询问里：每组询问最坏要从核心点出发搜一遍，$O(N^2)$，$M$ 组共约 $10^9$ 次基本操作，必超时。

好在核心身份、核心点之间的连通性、每个点能挂到哪些块，全部与询问无关——只需算一次。于是整体结构定为「两遍 $O(N^2)$ 扫描做预处理 + 每组询问一次集合求交」，总复杂度 $O(N^2\alpha(N)+M)$。数据范围在这里是真实线索：它说明 $O(N^2)$ 的预处理付得起，也说明逐询问搜索付不起。

### 两遍扫描在代码里的分工

第一遍数邻域。`counts` 初始化为 $1$——题面写明邻域含 $p$ 自身；枚举只取 $i<j$ 的点对，因为邻域关系对称，一次比较同时给两个计数加一。随后 `core[i] = counts[i] >= MinPts`。

接着一次并查集，只在 `(i, j)` 都是核心点且距离不超过 $\varepsilon$ 时合并。整道题决策位置最高的就是这两处 `if not core: continue`：块由核心点诱导出来，边界点在这里被排除出「粘合」的资格，只剩下被覆盖时挂靠的待遇。

第二遍为每个非核心点收集覆盖它的核心所在的块（`found.add(find(j))`），核心点挂 `find(i)`；噪声点得到空集。

最后一处实现选择在距离比较：不开方，直接比较 $dx^2+dy^2$ 与 $\varepsilon^2$，并给 $\varepsilon^2$ 乘上 $(1+10^{-9})$ 的相对容差。$1.2^2+0.9^2$ 在二进制浮点下会算成 $2.2500000000000004$，而 $\varepsilon^2=2.25$——数学上「恰好等于 $\varepsilon$」的邻居会被判到邻域外，它挂靠的核心关系整条丢失。省下 $5\times10^5$ 次开方本身收益有限，真正的考量是平方比较让「恰好相等」的样例浮出水面：容差就是为了这一类边界样例留的。

## 完整代码实现

```python
"""
P5425. 语义邻域可达 - DBSCAN 密度相连判定
"""

import sys


def solve():
    """读入点集与询问，按 DBSCAN 的定义逐条回答是否密度相连。"""
    data = sys.stdin.buffer.read().split()
    if not data:
        return

    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    eps = float(next(it))
    min_pts = int(next(it))

    xs = [0.0] * n
    ys = [0.0] * n
    for i in range(n):
        xs[i] = float(next(it))
        ys[i] = float(next(it))

    queries = [(int(next(it)), int(next(it))) for _ in range(m)]

    # 用平方距离比较，省掉 N^2 次开方；末尾的极小容差让“恰好等于 eps”
    # 的点不被浮点误差挡在门外（如 eps = 1.5 时 (0,0) 到 (1.2,0.9)）。
    eps2 = eps * eps * (1.0 + 1e-9)

    # ---------- 第一遍：数每个点 eps-邻域内有多少个点（含自身） ----------
    counts = [1] * n
    for i in range(n):
        xi = xs[i]
        yi = ys[i]
        cnt = counts[i]
        for j in range(i + 1, n):
            dx = xs[j] - xi
            dy = ys[j] - yi
            if dx * dx + dy * dy <= eps2:
                # 邻域关系对称，一次比较同时给两边计数
                cnt += 1
                counts[j] += 1
        counts[i] = cnt

    core = [cnt >= min_pts for cnt in counts]

    # ---------- 并查集：合并互相连通的核心点 ----------
    parent = list(range(n))
    size = [1] * n

    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x

    def union(a, b):
        ra, rb = find(a), find(b)
        if ra == rb:
            return
        if size[ra] < size[rb]:
            ra, rb = rb, ra
        parent[rb] = ra
        size[ra] += size[rb]

    # 只在核心点之间连边：边界点不能当中转站，
    # 否则“被两个簇同时覆盖的边界点”会把两个无关的簇粘在一起。
    for i in range(n):
        if not core[i]:
            continue
        xi = xs[i]
        yi = ys[i]
        for j in range(i + 1, n):
            if not core[j]:
                continue
            dx = xs[j] - xi
            dy = ys[j] - yi
            if dx * dx + dy * dy <= eps2:
                union(i, j)

    # ---------- 第二遍：算出每个点能挂到哪些核心连通块 ----------
    groups = [None] * n
    for i in range(n):
        if core[i]:
            groups[i] = {find(i)}

    for i in range(n):
        if core[i]:
            continue
        found = set()
        xi = xs[i]
        yi = ys[i]
        for j in range(n):
            if not core[j]:
                continue
            dx = xs[j] - xi
            dy = ys[j] - yi
            if dx * dx + dy * dy <= eps2:
                found.add(find(j))
        # 噪声点的 found 为空集：它不与任何点密度相连（包括它自己）
        groups[i] = found

    out = []
    for a, b in queries:
        # 两个集合有交集 <=> 存在一个核心点能同时走到 a 和 b
        out.append("1" if groups[a] & groups[b] else "0")

    sys.stdout.write("\n".join(out))
    if out:
        sys.stdout.write("\n")


if __name__ == "__main__":
    solve()
```

## 示例推演

### 样例 1

$\varepsilon=2.0$、$MinPts=3$。第一遍数出的邻域：

| 点 | 坐标 | 邻域内的点 | 邻域大小 | 是否核心点 |
| -- | ---- | ---------- | -------- | ---------- |
| 0 | $(0,0)$ | $\{0,1,2\}$ | 3 | 是 |
| 1 | $(1.2,0)$ | $\{0,1,2\}$ | 3 | 是 |
| 2 | $(0.4,1)$ | $\{0,1,2\}$ | 3 | 是 |
| 3 | $(12,0)$ | $\{3,4\}$ | 2 | 否 |
| 4 | $(12.5,0.4)$ | $\{3,4\}$ | 2 | 否 |
| 5 | $(6,6)$ | $\{5\}$ | 1 | 否 |

点 $0,1,2$ 两两距离为 $1.2$、$\sqrt{1.16}\approx1.077$、$\sqrt{1.64}\approx1.281$，都不超过 $2.0$，互相连边并成一个核心连通块，记作 $A$。点 $3$、$4$ 相距 $\sqrt{0.41}\approx0.64\le2.0$，但各自邻域只有 $2$ 个点，不是核心；它们也不在任何核心点的邻域里，是噪声点。点 $5$ 同理。

第二遍挂靠后：

| 点 | groups |
| -- | ------ |
| 0、1、2 | $\{A\}$ |
| 3、4、5 | $\varnothing$ |

- $0,2$：$\{A\}\cap\{A\}=\{A\}$，输出 $1$；
- $0,3$、$1,5$：核心块对空集，交集为空，输出 $0$；
- $3,4$：两个噪声点 $\varnothing\cap\varnothing=\varnothing$，输出 $0$。

### 样例 2

$\varepsilon=2.0$、$MinPts=3$：

| 点 | 坐标 | 邻域内的点 | 邻域大小 | 是否核心点 |
| -- | ---- | ---------- | -------- | ---------- |
| 0 | $(0,0)$ | $\{0,1,2\}$ | 3 | 是 |
| 1 | $(1.5,0)$ | $\{0,1,2,3\}$ | 4 | 是 |
| 2 | $(0.3,1.4)$ | $\{0,1,2\}$ | 3 | 是 |
| 3 | $(3.2,0.2)$ | $\{1,3\}$ | 2 | 否 |
| 4 | $(8,8)$ | $\{4,5,6\}$ | 3 | 是 |
| 5 | $(8.6,8.2)$ | $\{4,5,6\}$ | 3 | 是 |
| 6 | $(8.3,9.5)$ | $\{4,5,6\}$ | 3 | 是 |
| 7 | $(0,8)$ | $\{7\}$ | 1 | 否 |

点 $0,1,2$ 连成核心连通块 $A$；点 $4,5,6$ 两两距离约 $0.632$、$1.529$、$1.334$，都是核心点，连成块 $B$；点 $3$ 到核心点 $1$ 的距离 $\sqrt{1.7^2+0.2^2}=\sqrt{2.93}\approx1.71\le2.0$，自身邻域只有 $2$ 个点，是边界点，挂到 $A$；点 $7$ 是噪声。

| 点 | groups |
| -- | ------ |
| 0、1、2、3 | $\{A\}$ |
| 4、5、6 | $\{B\}$ |
| 7 | $\varnothing$ |

- $0,2$：同属 $A$，输出 $1$；
- $0,3$：核心点与边界点都在 $A$ 的可达点集里，输出 $1$——「边界点只作终点」的待遇在这里兑现；
- $4,5$：同属 $B$，输出 $1$；
- $3,4$：$\{A\}\cap\{B\}=\varnothing$，输出 $0$。

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| ---- | ---------- | ---------- | ---- |
| 逐询问 BFS | $O(MN^2)$ | $O(N^2)$ | 判定留在询问里做，$N=M=1000$ 时约 $10^9$ 次操作 |
| 并查集 + 块集合（最优） | $O(N^2\alpha(N)+M)$ | $O(N+M)$ | 与询问无关的部分只算一次，每组询问一次集合求交 |

两遍 $O(N^2)$ 扫描共约 $1.5\times10^6$ 次距离比较，纯 Python 下远不到 0.2 秒。

## 易错点总结

### 1. 块集合必须是集合，边界点也不能被粘进并查集

两条错路对应同一个「边界点只是终点」：漏掉合并阶段的 `if not core: continue`，把核心点与邻域内的点直接 `union`，共享边界点会把两个无关簇粘死，本该是 $0$ 的询问变 $1$；反过来把第二遍的 `groups[i] = found` 改成只记一个块编号，被两个块同时覆盖的边界点丢掉一半信息，它另一侧的询问误出 $0$。内嵌自测样例 5（共享边界点，$\varepsilon=5$、$MinPts=4$）把两种错法各钉一条：前者让询问 $(0,3)$ 从 $0$ 变 $1$，后者让询问 $(6,3)$ 从 $1$ 变 $0$——跑 `--test` 当场就能抓住。

### 2. 邻域计数从 1 开始

`counts = [1] * n` 的初值来自「邻域含 $p$ 自身」。写成 $0$ 时，所有邻域大小集体少 $1$，凡「真实邻域大小恰好等于 $MinPts$」的簇整片失去核心身份——样例 1 的三点簇（大小 $3=MinPts$）全军覆没，没有任何核心点，四个询问全部输出 $0$。

### 3. 比较用平方距离，并给 $\varepsilon^2$ 乘相对容差

`eps2 = eps * eps * (1.0 + 1e-9)`。平方比较省掉约 $5\times10^5$ 次开方；而不带容差时，「数学上恰好等于 $\varepsilon$」的点可能被浮点末位误差挡在邻域外——$\varepsilon=1.5$ 时 $(0,0)$ 与 $(1.2,0.9)$ 的距离正好是 $1.5$，平方和却可能算出 $2.2500000000000004$。被挡掉的邻居会让挂靠在它身上的块关系整个落空，相关询问跟着出错。

## 扩展思考

- 与普通「连通分量」的差别正是本题考点：普通连通只看有没有路径，本题限制路径的中转站必须是核心点，所以「核心点诱导子图求连通 + 边界点挂靠」两步缺一不可。
- 若 $N$ 升到 $10^5$，逐对建邻域不可行，要换网格散列只比较可能落在 $\varepsilon$ 内的点对；「预处理一次 + 询问查交集」的结构不变。
