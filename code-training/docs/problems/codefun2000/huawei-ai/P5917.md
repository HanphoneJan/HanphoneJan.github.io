# P5917. 用 CART 分类树预测客户是否购房

> 场次：2026年10月14日-AI方向 · 来源：[CodeFun2000 P5917](https://codefun2000.com/p/P5917)

## 题目描述

CART（Classification and Regression Trees）分类树通过二元切分，递归地把样本划入不纯度更低的子集。分裂特征和切分点由基尼指数（Gini Index）算出，得到一棵二叉树；离散取值和连续取值都可以参与分裂。
本题用这棵 CART 分类树预测客户是否购房。根据训练集建出二叉决策树，每个节点按基尼指数选择特征和切分点，再对测试样本给出预测。

**划分规则：** 对每一个特征，把它所有可能的取值逐一当作切分点，当前节点的样本分成左子集和右子集：
* 左子集：特征值 = 切分点
* 右子集：特征值 ≠ 切分点

### 数据集说明

每条记录包含 4 个特征和 1 个标签，输入时全部写成整数枚举。
* **特征1：** 年龄段（0：18-30岁；1：31-40岁；2：41-55岁；3：56岁及以上）
* **特征2：** 婚姻状况（0：单身；1：恋爱；2：已婚）
* **特征3：** 是否有房（0：无；1：有）
* **特征4：** 是否有工作（0：无；1：有）
* **标签：** 购房结果（0：否；1：是）

### 基尼指数计算公式

数据集里若有 \(K\) 个类别，\(p_k\) 表示第 \(k\) 类样本所占比例：
\[
Gini(D) = 1 - \sum_{k=1}^{K} p_k^2
\]

**加权基尼指数**
特征 \(A\) 以取值 \(v\) 为切分点时，\(D\) 被分成 \(D_1(A=v)\) 与 \(D_2(A \neq v)\)：
\[
Gini(D, A, v) = \frac{|D_1|}{|D|} \times Gini(D_1) + \frac{|D_2|}{|D|} \times Gini(D_2)
\]

### 预测规则

叶子节点输出该节点中人数最多的类别；若两个类别人数相同，输出编号较小的类别。

### 停止分裂条件

下面任一条件成立，节点即停止分裂：
1. 节点内全部样本的标签相同
2. 节点内的样本数小于 2
3. 不存在使基尼指数降低的切分点

### 平局处理规则

1. 按特征编号从小到大遍历（特征1 → 特征2 → 特征3 → 特征4）
2. 对当前特征，按取值从小到大遍历全部可能切分点
3. 计算各切分点的加权基尼指数，保留其中最小的切分
4. 若若干特征的加权基尼指数同为最小，取编号较小的特征
5. 若同一特征上若干取值的加权基尼指数同为最小，取较小取值作为切分点（左子集是该特征等于这个较小值的样本）

### 解答要求

* 时间限制：C/C++ 1000ms，其他语言 2000ms
* 内存限制：C/C++ 512MB，其他语言 1024MB

## 输入格式

第一行给出整数 \(N\)，表示训练集的客户人数（\(4 \le N \le 20\)）。
随后 \(N\) 行，每行 5 个整数，依次是 4 个特征和 1 个标签，整数之间以空格分隔。
第 \(N+2\) 行给出整数 \(M\)，表示待预测的样本人数（\(1 \le M \le 10\)）。
随后 \(M\) 行，每行 4 个整数，依次是 4 个特征，整数之间以空格分隔。

## 输出格式

输出一行，共 \(M\) 个整数，依次为 \(M\) 个测试样本在所建 CART 树上的预测结果，整数之间以空格分隔。

## 示例

### 示例 1

**输入：**
```text
8
0 0 0 0 0
1 1 0 1 0
2 2 0 0 0
3 1 0 1 0
0 1 1 0 1
1 2 1 1 1
2 0 1 0 1
3 2 1 1 1
4
2 1 0 1
0 2 1 0
3 0 0 0
1 1 1 1
```

**输出：**
```text
0 1 0 1
```

**说明：**
1. 根节点共 8 名客户，标签 0（否）与标签 1（是）各 4 人，所以
\[
Gini(D) = 1 - (4/8)^2 - (4/8)^2 = 0.5
\]

2. 选取加权基尼指数最小的切分。特征3（是否有房）取切分点 0 时，左子集 4 人标签全为 0，右子集 4 人标签全为 1，加权基尼指数为 0。取切分点 1 只是左右对调，加权基尼指数同样为 0。二者并列，按平局规则保留较小取值 0，左子集为「是否有房 = 0」。
其余切分的加权基尼指数都大于 0。例如特征2（婚姻状况）取切分点 1 时，左子集 3 人里有 2 个 0、1 个 1，右子集 5 人里有 2 个 0、3 个 1，加权基尼指数为 \(7/15\)；特征4（是否有工作）取 0 或 1 时，两侧都是 2 个 0 与 2 个 1，加权基尼指数为 \(1/2\)。

3. 左右子集的标签都已相同，停止分裂。左叶子预测 0，右叶子预测 1。

4. 四个测试样本的特征3依次为 0、1、0、1。等于切分点的进入左子树，不等于的进入右子树，预测为 0 1 0 1。

## 解题思路

### 判分标准：预测结果完全由"那棵树"说了算

本题没有需要解题者设计的成分：切分怎么打分（基尼）、候选按什么顺序试、什么时候停、叶子输出什么，题面逐条给定。输出就是 $M$ 个样本沿建好的树下降的结果——正确性等价于**把每条规则读准**。其中与常见 CART 写法不同的两条要先抠出来：

- **切分是"等于 $v$ / 其余"**，不是阈值 $A\le v\ /\ A>v$。左子集只收"该特征恰好取 $v$"的样本，其余全归右子树；预测时同样只看相等与否（代码里 `sample[feature] == value` 走左）。
- **停止条件三是"不存在使基尼指数降低的切分"**：加权基尼**等于**父节点的候选不算更优。节点内某特征只剩一个取值时，无论切分点取多少，左子集等于全体、右子集为空，加权基尼与父节点相同——这类候选若被当成"可分裂"，节点会被左右两边原样交还给自己，递归在同一点上打转、永不终止。代码里的守门语句是 `best[0] >= parent_gini` 就返回叶子，它同时是递归能停下来的保证。

### 数据范围把性能卸掉，剩下的难点全在比较的精度

$N\le20$：每个节点的候选至多 $4$ 特征 $\times$ 节点内不同取值数（$\le N$）个，每个候选一次 $O(N)$ 的计数扫描，树高不超过 $N$，全树约 $4\times20\times20\times20\approx3\times10^4$ 次基本操作。这题不考核任何剪枝技巧，考核点是**平局判定的精度**。题面给的 $\frac{7}{15}$、$\frac{1}{2}$ 都是分数：加权基尼是有理数，而浮点比较时两个数学上相等的候选可能差 $10^{-16}$，"并列"被误读成"后者更小"——平局规则（小编号特征、其上最小的取值）依赖的恰恰是"等于"的判定。所以基尼一律按计数精确表示：

$$
Gini=1-\frac{\sum_k c_k^2}{T^2},\qquad
\text{加权}=\frac{|D_1|}{|D|}G_1+\frac{|D_2|}{|D|}G_2
$$

代码里写成 `1 - Fraction(square_sum, total * total)`，加权式两项分别是 `Fraction(left_size, total) * gini(left_counts)` 这类整数比，比较全程交给 `Fraction`，不丢一位。

递归的收缩结构也值得过一遍：节点只持有"落在自己身上的样本下标"，选中的切分保证左子集非空，所以左右两侧的样本数都严格小于父节点——就算没有停止条件 1、3，"样本数逐层至少减一"本身也注定了树深不超过 $N$。停止条件 2（样本数小于 2）是与这条收缩直接配套的：一个样本切不出两个非空子集，必须成为叶子；等到左右两侧各自只有一个样本时，条件 2 就在下一层等着。

### 平局规则为什么不需要单独写

候选按特征 $1\to4$、特征内取值升序枚举，更新最优时只用**严格小于**（`score < best[0]`）。并列时后到的候选不替换先到的，最终留下的天然是"编号最小的特征、其上最小的取值"——题面的两级平局规则由"枚举顺序 + 严格小于"免费实现，没有任何显式的平局比较。

### 算法到实现的映射

- **每候选 $O(N)$ 计数**：一次遍历同时累加左、右两侧的标签计数（`left_counts` / `right_counts`），不构造子集列表，也不按类别重扫；加权基尼由计数直接算出。
- **候选只取节点内出现过的取值**：节点里没出现过的 $v$ 切出空左集、右集等于全体，加权基尼恒等于父节点，永远不可能胜出，枚举它纯属浪费；附带的好处是左集必非空，唯一可能空的是右集，`gini({})` 返回 $0$ 即可（它的权重本来就是 $0$）。
- **叶子判定**：以 `(-人数, 标签)` 为键取 `min`，人数多者胜、平票取编号小的标签。
- **节点表示**：切分节点是 `("split", 特征下标, 切分点, 左子树, 右子树)` 的五元组，叶子是 `("leaf", 标签)` 的二元组——预测时只需沿 `while node[0] == "split"` 往下走，比较逻辑写在 `predict` 里，与建树完全解耦。
- **预测**：沿树下降，等于切分点走左、其余一律走右——只判相等，不比大小。

综上，整套实现是"递归收缩 + 精确分数 + 严格小于"三件事撑起来的，每一件都对应一条题面规则。

## 完整代码实现

```python
import sys
from fractions import Fraction

FEATURES = 4   # 每条记录的特征个数，标签在它后面一位


def gini(counts):
    """按标签计数算基尼指数 Gini = 1 - sum(p_k^2)，用分数保证精确。"""
    total = sum(counts.values())
    if total == 0:
        return Fraction(0)      # 空集合没有不纯度，且它的权重也是 0
    square_sum = sum(count * count for count in counts.values())
    return 1 - Fraction(square_sum, total * total)


def majority_label(counts):
    """人数最多的标签；人数相同时取编号较小的标签。"""
    return min(counts, key=lambda label: (-counts[label], label))


def build(indices, rows):
    """递归建造 CART 分类树。

    节点表示：
    - ("leaf", 标签)
    - ("split", 特征下标, 切分点, 左子树, 右子树)
    """
    counts = {}
    for i in indices:
        label = rows[i][FEATURES]
        counts[label] = counts.get(label, 0) + 1

    # 停止条件 1、2：标签已纯，或样本数不足 2
    if len(indices) < 2 or len(counts) == 1:
        return ("leaf", majority_label(counts))

    total = len(indices)
    parent_gini = gini(counts)
    best = None    # (加权基尼, 特征下标, 切分点)

    for feature in range(FEATURES):
        # 候选只取本节点出现过的取值：没出现过的取值切不出样本，
        # 加权基尼与父节点相同，永远不可能更优
        for value in sorted({rows[i][feature] for i in indices}):
            left_counts, right_counts = {}, {}
            left_size = 0

            # 一次遍历同时统计左右两侧的标签计数
            for i in indices:
                label = rows[i][FEATURES]
                if rows[i][feature] == value:
                    left_counts[label] = left_counts.get(label, 0) + 1
                    left_size += 1
                else:
                    right_counts[label] = right_counts.get(label, 0) + 1
            right_size = total - left_size

            # 加权基尼指数：两侧按人数占比加权
            score = (Fraction(left_size, total) * gini(left_counts)
                     + Fraction(right_size, total) * gini(right_counts))

            # 只用严格更小更新：候选按特征升序、取值升序枚举，
            # 于是平局时留下的是编号更小的特征、更小的切分点
            if best is None or score < best[0]:
                best = (score, feature, value)

    # 停止条件 3：没有任何切分能让基尼指数严格下降
    if best is None or best[0] >= parent_gini:
        return ("leaf", majority_label(counts))

    _, feature, value = best
    left = [i for i in indices if rows[i][feature] == value]
    right = [i for i in indices if rows[i][feature] != value]
    return ("split", feature, value, build(left, rows), build(right, rows))


def predict(tree, sample):
    """沿树下降：等于切分点走左子树，否则走右子树。"""
    node = tree
    while node[0] == "split":
        _, feature, value, left, right = node
        node = left if sample[feature] == value else right
    return node[1]


def solve():
    tokens = sys.stdin.buffer.read().split()
    if not tokens:
        return

    pos = 0
    n = int(tokens[pos])
    pos += 1

    rows = []
    for _ in range(n):
        rows.append([int(tokens[pos + k]) for k in range(FEATURES + 1)])
        pos += FEATURES + 1

    m = int(tokens[pos])
    pos += 1

    tree = build(list(range(n)), rows)

    answers = []
    for _ in range(m):
        sample = [int(tokens[pos + k]) for k in range(FEATURES)]
        pos += FEATURES
        answers.append(str(predict(tree, sample)))

    print(" ".join(answers))


if __name__ == "__main__":
    solve()
```

## 示例推演

### 样例 1：根节点是怎么被平局规则钉住的

8 条记录 0/1 各 4 条，根节点 $Gini(D)=1-(4/8)^2-(4/8)^2=1/2$。

**逐特征试切分**。对每个候选 $(A,v)$，左子集收「特征 $A$ 恰好取 $v$」的样本，其余进右子集，加权基尼按两侧人数占比加权。

**特征 1（年龄段）**——每个取值上恰好各有一个 0 类与一个 1 类样本（样本 1/5、2/6、3/7、4/8 成对）：

| 切分点 | 左子集（人数，0 类 / 1 类） | 右子集 | 加权基尼 |
| --- | --- | --- | --- |
| 0 | 2（1/1） | 6（3/3） | $1/2$ |
| 1 | 2（1/1） | 6（3/3） | $1/2$ |
| 2 | 2（1/1） | 6（3/3） | $1/2$ |
| 3 | 2（1/1） | 6（3/3） | $1/2$ |

**特征 2（婚姻状况）**——以切分点 1 演示一次完整计算：左子集是样本 2、4、5，标签 $0,0,1$，$Gini_1=1-(2/3)^2-(1/3)^2=4/9$；右子集是样本 1、3、6、7、8，标签 $0,0,1,1,1$，$Gini_2=1-(2/5)^2-(3/5)^2=12/25$；加权得 $\frac38\cdot\frac49+\frac58\cdot\frac{12}{25}=\frac7{15}$。三个切分点合在一张表里：

| 切分点 | 左子集（人数，0 类 / 1 类） | 右子集 | 加权基尼 |
| --- | --- | --- | --- |
| 0 | 2（1/1） | 6（3/3） | $1/2$ |
| 1 | 3（2/1） | 5（2/3） | $7/15$ |
| 2 | 3（1/2） | 5（3/2） | $7/15$ |

**特征 3（是否有房）**——两个切分点都把数据**完全切开**：

| 切分点 | 左子集（人数，0 类 / 1 类） | 右子集 | 加权基尼 |
| --- | --- | --- | --- |
| 0 | 4（4/0），全为 0 | 4（0/4），全为 1 | $0$ |
| 1 | 4（0/4），全为 1 | 4（4/0），全为 0 | $0$ |

**特征 4（是否有工作）**——两个切分点的两侧都是"4 人里 2 个 0 与 2 个 1"，加权基尼都是 $1/2$。

**平局规则定根**：全场最小值 $0$ 只有特征 3 取到，而它的 0 与 1 并列，按取值较小者取 $0$，根节点判「是否有房 = 0」。左子集（样本 1–4）标签全 0、右子集（样本 5–8）全 1，两个节点都满足停止条件 1，各自成为叶子：左叶 0、右叶 1。

并列的裁决在这里分两级：特征编号一级（只有特征 3 取到 $0$）已由上文给出；其上取值一级靠"取值升序 + 严格小于"分出先后——切分点 0 先以 $0$ 坐上 `best`，切分点 1 同为 $0$ 但不再更小，于是被丢弃。若更新条件写成 `<=`，根节点会反过来判「是否有房 = 1」，左右叶子对调，四个测试样本的预测就翻成 `1 0 1 0`。至于特征 1、2、4 那些并列于 $1/2$ 或 $7/15$ 的候选，因为始终大于 $0$，本例轮不到它们说话——但换一组数据，同一个比较规则会在更深层的节点上做出同样的裁决。

**预测**：四个测试样本的是否有房依次为 0、1、0、1，等于切分点走左、不等于走右，输出 `0 1 0 1`。

最终的树只有一层切分：

```text
根：是否有房 = 0 ?
├─ 左（有房 = 0）：叶，预测 0
└─ 右（有房 ≠ 0）：叶，预测 1
```

对两个类的纯集合，基尼恒为 $0$，这也是"一次切分足够，之后全是叶子"的判分读法：停止条件 1 在样例里拦在真正起作用的位置上。

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| ---- | ---------- | ---------- | ---- |
| 逐候选重建左右子集、按定义算基尼 | $O(F\cdot V\cdot N^2)$ 全树 | $O(N)$ | 每候选先切两份再数类别；候选含节点外取值时还要白算 |
| 一遍计数 + Fraction 精确比较（最优） | $O(F\cdot V\cdot N^2)$ 全树 | $O(N)$ | 每候选一次 $O(N)$ 计数；渐进与上一行相同，省下的是常数与"平局判定不出错"的保障 |

其中 $F=4$、$V$ 是节点内不同取值个数（$\le N$）、树高不超过 $N$；每节点 $O(F\cdot V\cdot N)$、全树即 $O(F\cdot V\cdot N^2)$。$N\le20$ 时约 $3\times10^4$ 次基本操作，远低于 2 秒时限。

空间上三个来源都是 $O(N)$：样本表本身、当前节点持有的下标列表（两层同时存在时是 depth 次叠加，depth $\le N$）与建出的树（切分节点至多 $N-1$ 个、叶子至多 $N$ 个）。

## 易错点总结

### 1. 停止条件的比较方向

「并列不算更优」由 `best[0] >= parent_gini` 返回叶子实现。把它写弱（例如改成只在 `best[0] > parent_gini` 时返回叶子，或干脆按"存在不同候选就分裂"处理），单值特征产生"左子集 = 全体、右子集为空"的无效切分就会被执行，节点被原样交给自己的左右两边，递归永不终止，报 `RecursionError`。

### 2. 基尼比较不许走浮点

$\frac{7}{15}$、$\frac{1}{2}$ 这类分数在二进制浮点里不精确，两个数学上相等的加权基尼可能差 $10^{-16}$，`score < best[0]` 就会把"并列"拆开、送出一个本不该胜出的候选——平局规则失效，树形漂移，部分测试样本的预测随之翻转（就样例而言，被推上首位的是特征 3 的切分点 1，输出仍可能翻成 `1 0 1 0`）。代码用 `Fraction(square_sum, total * total)` 与加权式保持全分数运算。

### 3. "等于切分"写成了阈值切分

左子集条件必须是 `feature == value`，build 与 predict 两处都是。把左子集写成 `feature <= value` 之后候选集与树形都变了：特征 3 只有 0/1 两个取值时等值与阈值切分侥幸一致，但取值有三个以上的特征上，一次切分会把"等于 $v$ 之外、小于 $v$"的样本也卷进左子树，与题面规则偏离，并级联影响后续每个节点的划分。

## 扩展思考

- **连续特征的版本**：标准 CART 对连续特征用 $A\le v\ /\ A>v$、候选点取相邻取值的中点；本题的"等于/其余"是离散枚举版的规则。换回归目标（均方误差替代基尼）时框架不变。
- **过拟合与森林**：本题不剪枝，训练集上会把每个节点尽可能切纯，真实数据上会过拟合，工业实现之后接代价复杂度剪枝（CCP）；随机森林里每棵树的核心，正是这里"按基尼选切分"这一段。
- **递归的形状**：整段 build 是"把一个问题交给两个更小的自己"，与 [递归](../../../patterns/recursion.md) 一节的通用描述完全同构；这里的"更小"由基尼指数挑出，而递归的终点由三条停止条件共同守门。
