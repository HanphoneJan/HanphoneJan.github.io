# P5312. 模域双向循环注意力网络前向计算

> 场次：2026年8月26日 · 来源：[CodeFun2000 P5312](https://codefun2000.com/p/P5312)

## 题目描述

需要在模 $MOD$ 的整数域中，完成一个由多层双向循环神经网络和多头自注意力组成的网络的一次前向计算。

输入序列共有 $N$ 个位置，位置 $t$ 的原始输入向量记为 $x_t$，其维度为 $F$。网络先经过 $S$ 层双向 RNN 编码，再进行包含 $A$ 个注意力头的多头自注意力计算，之后通过残差连接，最后使用线性输出层得到 $C$ 维向量 $y_t$。

所有向量均视为行向量，矩阵乘法均采用“行向量乘矩阵”的方式。所有输入参数均为满足 $0\le x<MOD$ 的非负整数。每次完成向量加法、点积或矩阵乘法后，都需要将结果对 $MOD$ 取模。

1. **多层双向 RNN 编码**

对于双向 RNN 的第 $l$ 层，位置 $t$ 的输入记为 $a_t^{(l)}$。第一层直接使用原始输入，即 $a_t^{(1)}=x_t$。

每一层的输入维度记作 $d_l$，其中 $d_l=\begin{cases}F,&l=1\\2R,&l>1\end{cases}$。

这里，$R$ 是单个方向的隐藏状态维度。因此，一层双向 RNN 在每个位置都会分别产生一个 $R$ 维正向状态和一个 $R$ 维反向状态。

第 $l$ 层正向计算所使用的参数为 $U_f^{(l)}$、$V_f^{(l)}$、$c_f^{(l)}$，其规模依次为 $d_l\times R$、$R\times R$、$1\times R$。该方向的给定初始状态为 $p_0^{(l)}$，规模为 $1\times R$。

正向状态从位置 $1$ 开始，按照 $1,2,\dots,N$ 的顺序计算。对于每个 $t$，有 $p_t^{(l)}=\left(a_t^{(l)}U_f^{(l)}+p_{t-1}^{(l)}V_f^{(l)}+c_f^{(l)}\right)\bmod MOD$。

同一层的反向计算使用 $U_b^{(l)}$、$V_b^{(l)}$、$c_b^{(l)}$，规模分别为 $d_l\times R$、$R\times R$、$1\times R$。反向方向的给定初始状态为 $r_{N+1}^{(l)}$，其规模为 $1\times R$。

反向状态的计算次序与正向相反，从位置 $N$ 开始依次处理到位置 $1$。对于每个 $t$，有 $r_t^{(l)}=\left(a_t^{(l)}U_b^{(l)}+r_{t+1}^{(l)}V_b^{(l)}+c_b^{(l)}\right)\bmod MOD$。

当第 $l$ 层的两个方向均计算完成后，把同一位置上的正向状态放在前、反向状态放在后进行拼接。若 $l<S$，该结果作为下一层对应位置的输入，即 $a_t^{(l+1)}=\left[p_t^{(l)}\parallel r_t^{(l)}\right]$。

因此，从第 $2$ 层开始，每个 $a_t^{(l)}$ 的维度均为 $2R$。

经过全部 $S$ 层双向 RNN 后，取最后一层在位置 $t$ 的两个方向状态，并定义 $e_t=\left[p_t^{(S)}\parallel r_t^{(S)}\right]$。

此时 $e_t\in\mathbb{Z}_{MOD}^{2R}$，它将作为后续多头自注意力部分的输入。

2. **多头自注意力**

多头自注意力共有 $A$ 个注意力头，注意力头编号为 $h=0,1,\dots,A-1$，每个头的维度为 $Q$。

本题使用未归一化的点积注意力，不进行缩放、不使用 softmax，也不存在 mask。

对于任意注意力头 $h$，均给定三个规模为 $2R\times Q$ 的矩阵 $Q_h$、$K_h$、$V_h$。在位置 $t$，分别计算 $q_t^{(h)}=e_tQ_h\bmod MOD$、$k_t^{(h)}=e_tK_h\bmod MOD$、$v_t^{(h)}=e_tV_h\bmod MOD$。

上述三个向量均为 $Q$ 维，即 $q_t^{(h)},k_t^{(h)},v_t^{(h)}\in\mathbb{Z}_{MOD}^{Q}$。

接下来，对于位置 $t$ 和位置 $s$，利用 $q_t^{(h)}$ 与 $k_s^{(h)}$ 的点积计算第 $h$ 个注意力头的注意力分数：

$\beta_{t,s}^{(h)}=\left(\sum_{j=0}^{Q-1}q_t^{(h)}[j]\cdot k_s^{(h)}[j]\right)\bmod MOD$。

得到位置 $t$ 对所有位置的注意力分数后，对每个分量 $j=0,1,\dots,Q-1$ 计算：

$c_t^{(h)}[j]=\left(\sum_{s=1}^{N}\beta_{t,s}^{(h)}\cdot v_s^{(h)}[j]\right)\bmod MOD$。

由此得到第 $h$ 个注意力头在位置 $t$ 的 $Q$ 维输出 $c_t^{(h)}$。

对于同一个位置 $t$，将各注意力头的结果按照编号 $0,1,\dots,A-1$ 的顺序拼接，得到 $c_t=\left[c_t^{(0)}\parallel c_t^{(1)}\parallel\dots\parallel c_t^{(A-1)}\right]$。

拼接后的向量满足 $c_t\in\mathbb{Z}_{MOD}^{AQ}$。

3. **残差连接**

多头自注意力产生的 $AQ$ 维向量 $c_t$ 需要通过投影矩阵 $W_p$ 映射到 $2R$ 维。

其中，$W_p$ 的规模为 $AQ\times 2R$，偏置 $c_p$ 的规模为 $1\times 2R$。

投影结果与同一位置的编码结果 $e_t$ 进行残差相加，得到 $u_t=\left(c_tW_p+c_p+e_t\right)\bmod MOD$。

4. **输出层**

残差连接后的 $u_t$ 通过最后的线性层得到位置 $t$ 的输出。

输出层包含规模为 $2R\times C$ 的矩阵 $W_y$ 和规模为 $1\times C$ 的偏置 $c_y$，计算方式为 $y_t=\left(u_tW_y+c_y\right)\bmod MOD$。

最终得到 $y_t\in\mathbb{Z}_{MOD}^{C}$。需要计算输入序列全部 $N$ 个位置对应的最终输出向量。

## 输入格式

第一行给出 $8$ 个整数 $N$、$F$、$R$、$C$、$S$、$A$、$Q$、$MOD$，分别表示序列长度、输入维度、单向隐藏状态维度、输出维度、双向 RNN 层数、注意力头数量、每个注意力头的维度以及模数。

数据范围为：

$1\le N\le 10,\ 1\le F\le 5,\ 1\le R\le 5$。

$1\le C\le 5,\ 1\le S\le 3,\ 1\le A\le 4,\ 1\le Q\le 4$。

$2\le MOD\le 97$。

随后给出原始输入序列，共 $N$ 行。第 $t$ 行包含 $F$ 个整数，表示位置 $t$ 的向量 $x_t$。

原始输入之后是 $S$ 层双向 RNN 的参数，各层按照 $l=1,2,\dots,S$ 的顺序给出。对于当前层 $l$，输入维度为 $d_l=\begin{cases}F,&l=1\\2R,&l>1\end{cases}$。

每一层内部的参数输入顺序固定如下：

1. $U_f^{(l)}$：输入 $d_l$ 行，每行包含 $R$ 个整数；
2. $V_f^{(l)}$：输入 $R$ 行，每行包含 $R$ 个整数；
3. $c_f^{(l)}$：输入 $1$ 行，包含 $R$ 个整数；
4. $U_b^{(l)}$：输入 $d_l$ 行，每行包含 $R$ 个整数；
5. $V_b^{(l)}$：输入 $R$ 行，每行包含 $R$ 个整数；
6. $c_b^{(l)}$：输入 $1$ 行，包含 $R$ 个整数；
7. $p_0^{(l)}$：输入 $1$ 行，包含 $R$ 个整数；
8. $r_{N+1}^{(l)}$：输入 $1$ 行，包含 $R$ 个整数。

全部 $S$ 层双向 RNN 参数之后，依次给出 $A$ 个注意力头的参数。注意力头按照 $h=0,1,\dots,A-1$ 的编号顺序输入，每个头依次包含：

1. $Q_h$：输入 $2R$ 行，每行包含 $Q$ 个整数；
2. $K_h$：输入 $2R$ 行，每行包含 $Q$ 个整数；
3. $V_h$：输入 $2R$ 行，每行包含 $Q$ 个整数。

所有注意力头的参数结束后，剩余参数按照 $W_p$、$c_p$、$W_y$、$c_y$ 的顺序给出：

1. $W_p$：输入 $AQ$ 行，每行包含 $2R$ 个整数；
2. $c_p$：输入 $1$ 行，包含 $2R$ 个整数；
3. $W_y$：输入 $2R$ 行，每行包含 $C$ 个整数；
4. $c_y$：输入 $1$ 行，包含 $C$ 个整数。

所有输入矩阵均按照从上到下、逐行的顺序给出。

## 输出格式

按照位置 $1,2,\dots,N$ 的顺序输出计算结果，共输出 $N$ 行。

第 $t$ 行包含 $C$ 个非负整数，依次表示最终输出向量 $y_t$ 的各个分量，相邻整数之间使用一个空格分隔。

$c_1 W_p = [3 \cdot 1, 3 \cdot 4] \bmod 5 = [3,2]$。

$u_1 = ([3,2]+[2,1]+[3,2]) \bmod 5 = [3,0]$。
输出层计算
$y_1 = (3 \cdot 2 + 0 \cdot 1 + 0) \bmod 5 = 6 \bmod 5 = 1$。

最终输出为 `1`。

## 解题思路

### 这道题考的不是想出算法，而是不抄错四段流水线

先看数据范围：$N\le10$，各维度 $\le5$，$S\le3$，$A,Q\le4$，$MOD\le97$。按公式直接计算的做法都远远够用——这道题没有更快的算法可找，也没有可供剪枝的结构。它的难度全部压在另一处：四段计算（双向 RNN 编码 → 多头注意力 → 投影残差 → 输出层）里，每段的维度、递推方向、拼接规则都不相同，任何一处抄错都不会报错，只会让输出系统性全错。所以正确的策略是让实现尽量「笨」：维数与顺序从公式直接照抄，能参数化的一律参数化。

先在纸上顺着数据流走一遍，把题面的每个记号钉在具体的形状上：

- 输入 $x_t$ 是 $F$ 维，它就是第一层的输入（$d_1=F$）；从第二层起换成上一层正反状态拼接出的 $2R$ 维——这是全题唯一一次维度跳变，实现里对应 `d = F if layer == 0 else 2 * R` 这一行条件。
- 每层正向 $p_t$ 从 $p_0$ 起按 $1..N$ 递推，反向 $r_t$ 从 $r_{N+1}$ 起按 $N..1$ 递推，两条递推式唯一的差别是「用后一个状态还是前一个状态」。
- 一层算完按 $[p_t\parallel r_t]$ 拼接；**最后一层**的拼接 $e_t$ 是注意力的输入，也是后面残差相加的对象。
- 每个头独立算 $q_t,k_t,v_t$（各 $Q$ 维）、分数 $\beta_{t,s}=q_t\cdot k_s$、加权输出 $c_t$，再**按头编号**顺序拼成 $AQ$ 维。
- 投影 $c_tW_p$ 之后做残差，加的是 $e_t$；最后 $y_t=u_tW_y+c_y$。

### 实现上的两处设计

**读入时就把形状标注全。** 参数多达十几个矩阵，逐行人肉记顺序迟早错位。代码里 `read_matrix(rows, cols)` 按题面给定的行数、列数直接切块，每个矩阵的形状照公式抄：$U_f$ 是 $d\times R$、三个注意力矩阵是 $2R\times Q$、$W_p$ 是 $AQ\times 2R$。层的参数固定为 8 块（$U_f,V_f,c_f,U_b,V_b,c_b,p_0,r_{N+1}$），按顺序 `read` 无一遗漏。第一层与后续层复用同一个读入器，只有行数 $d$ 不同——维度上唯一的例外收敛在一处。

**全题只有时间轴上有依赖。** 除两条 RNN 递推必须按位置顺序推进（正向 `for t in range(N)`、反向 `for t in range(N-1, -1, -1)`，反向取的是刚算完的 $r_{t+1}$，即变量 `nxt`）之外，其余都是「一批位置各做同样的向量×矩阵」：$q,k,v$、残差、输出层逐位置独立。所以值得抽的唯一公共件是行向量乘矩阵 `vec_mat`。行向量约定直接决定它的写法：结果第 $j$ 个分量是向量与矩阵第 $j$ **列**的点积，结果维数等于矩阵的列数。

### 模域纪律与下标约定

数值上没有悬念：所有量都在 $[0,MOD)$，一次点积累加最多 $N\times MOD^2<10^5$，任何整数类型都装得下。纪律在两处：

- 题面位置是 $1$ 起始，代码统一 $0$ 起始。正向 `p[0]` 从 $p_0$ 来、反向 `r[N-1]` 从 $r_{N+1}$ 来，两处 off-by-one 都集中在递推循环的边界上，实现后对照样例确认各一次即可。
- 读参数时顺手 `% MOD`（`read_matrix` 里那一行）。题面虽保证输入已在 $[0,MOD)$，这一步让后面所有表达式只需在自己的末尾记一个 `%`，递推、拼接、残差处都不用再想取模的事。

## 完整代码实现

```python
import sys


def solve():
    # 本题所有输入都是整数，一次性读入后按顺序取用即可。
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return

    # 头部 8 个整数：序列长度、输入维度、隐藏维度、输出维度、
    # RNN 层数、注意力头数、每个头的维度、模数。
    pos = 0
    N, F, R, C, S, A, Q, MOD = data[pos:pos + 8]
    pos += 8

    def read_matrix(rows, cols):
        """从当前位置读取 rows x cols 的整数矩阵。"""
        nonlocal pos
        mat = []
        for _ in range(rows):
            # 输入保证 0 <= x < MOD，这里仍然统一取模，避免手误。
            row = data[pos:pos + cols]
            pos += cols
            mat.append([x % MOD for x in row])
        return mat

    def read_vector(size):
        """从当前位置读取一个长度为 size 的整数向量。"""
        return read_matrix(1, size)[0]

    def vec_mat(vec, mat):
        """行向量乘矩阵：result[j] = sum_i vec[i] * mat[i][j]。"""
        cols = len(mat[0])
        return [
            sum(vec[i] * mat[i][j] for i in range(len(vec))) % MOD
            for j in range(cols)
        ]

    # a 表示“当前 RNN 层的输入序列”：
    # - 第 1 层：a 是原始输入，形状 N x F；
    # - 第 2 层开始：a 是上一层正向/反向状态的拼接，形状 N x 2R。
    a = read_matrix(N, F)

    # 逐层计算双向 RNN
    for layer in range(S):
        # 第 1 层的输入维度是 F，之后每层都是 2R。
        d = F if layer == 0 else 2 * R

        # 正向参数：U_f (d x R)、V_f (R x R)、c_f (1 x R)
        U_f = read_matrix(d, R)
        V_f = read_matrix(R, R)
        c_f = read_vector(R)

        # 反向参数：U_b (d x R)、V_b (R x R)、c_b (1 x R)
        U_b = read_matrix(d, R)
        V_b = read_matrix(R, R)
        c_b = read_vector(R)

        # 正向初始状态 p_0 和反向初始状态 r_{N+1}
        p_prev = read_vector(R)
        r_next = read_vector(R)

        # 正向递推：p_t = a_t U_f + p_{t-1} V_f + c_f
        p = [None] * N
        prev = p_prev
        for t in range(N):
            cur = [
                (sum(a[t][i] * U_f[i][j] for i in range(d))
                 + sum(prev[i] * V_f[i][j] for i in range(R))
                 + c_f[j]) % MOD
                for j in range(R)
            ]
            p[t] = cur
            prev = cur

        # 反向递推：r_t = a_t U_b + r_{t+1} V_b + c_b
        # 从最后一个位置 N-1 开始，向前推到位置 0。
        r = [None] * N
        nxt = r_next
        for t in range(N - 1, -1, -1):
            cur = [
                (sum(a[t][i] * U_b[i][j] for i in range(d))
                 + sum(nxt[i] * V_b[i][j] for i in range(R))
                 + c_b[j]) % MOD
                for j in range(R)
            ]
            r[t] = cur
            nxt = cur

        # 正向状态在前、反向状态在后，拼接成下一层的输入。
        # 拼接后每个位置的维度是 R + R = 2R。
        a = [p[t] + r[t] for t in range(N)]

    # 全部 RNN 层结束后，a 就是编码结果 e_t。
    e = a

    # 多头自注意力：每个头都有自己的一套 Q_h、K_h、V_h。
    head_outputs = []
    for _ in range(A):
        # 每个矩阵的形状都是 2R x Q，因为 e_t 是 2R 维。
        Q_h = read_matrix(2 * R, Q)
        K_h = read_matrix(2 * R, Q)
        V_h = read_matrix(2 * R, Q)

        # 对每个位置 t，分别计算 Q、K、V 投影。
        q = [vec_mat(e[t], Q_h) for t in range(N)]
        k = [vec_mat(e[t], K_h) for t in range(N)]
        v = [vec_mat(e[t], V_h) for t in range(N)]

        # beta[t][s] = q_t · k_s，表示位置 t 对位置 s 的注意力分数。
        beta = [
            [
                sum(q[t][j] * k[s][j] for j in range(Q)) % MOD
                for s in range(N)
            ]
            for t in range(N)
        ]

        # c_t[j] = sum_s beta[t][s] * v_s[j]，
        # 即用注意力分数对所有位置的 V 做加权求和。
        c = [
            [
                sum(beta[t][s] * v[s][j] for s in range(N)) % MOD
                for j in range(Q)
            ]
            for t in range(N)
        ]
        head_outputs.append(c)

    # 按头编号拼接：c_t = [c_t^(0) || c_t^(1) || ... || c_t^(A-1)]。
    # 拼接后每个位置是 AQ 维。
    c = [
        [head_outputs[h][t][j] for h in range(A) for j in range(Q)]
        for t in range(N)
    ]

    # 投影 + 残差：
    # W_p 是 AQ x 2R，c_p 是 2R 维，e_t 也是 2R 维。
    # u_t = c_t W_p + c_p + e_t。
    W_p = read_matrix(A * Q, 2 * R)
    c_p = read_vector(2 * R)
    u = [
        [
            (sum(c[t][i] * W_p[i][j] for i in range(A * Q))
             + c_p[j] + e[t][j]) % MOD
            for j in range(2 * R)
        ]
        for t in range(N)
    ]

    # 输出层：W_y 是 2R x C，c_y 是 C 维。
    # y_t = u_t W_y + c_y。
    W_y = read_matrix(2 * R, C)
    c_y = read_vector(C)
    y = [
        [
            (sum(u[t][i] * W_y[i][j] for i in range(2 * R)) + c_y[j]) % MOD
            for j in range(C)
        ]
        for t in range(N)
    ]

    for row in y:
        print(*row)


if __name__ == "__main__":
    solve()
```

## 示例推演

样例 1 一路走完四个阶段：$N=F=R=C=S=A=Q=1$，$MOD=5$。

1. **双向 RNN**：正向 $p_1=(2\cdot3+4\cdot4+1)\bmod5=3$；反向从 $r_{N+1}=[0]$ 起，$r_1=(2\cdot2+0\cdot1+3)\bmod5=2$。$e_1=[3,2]$。
2. **注意力**：$q_1=e_1Q_0=3$，$k_1=e_1K_0=2$，$v_1=(3\cdot4+2\cdot3)\bmod5=3$；$\beta_{1,1}=3\cdot2\bmod5=1$；$c_1=1\cdot3=3$。
3. **投影残差**：$c_1W_p=[3,2]$，加 $c_p=[2,1]$ 与 $e_1=[3,2]$，$u_1=([3,2]+[2,1]+[3,2])\bmod5=[3,0]$。
4. **输出层**：$y_1=(3\cdot2+0\cdot1+0)\bmod5=1$。

样例 3 在第 2 阶段换成两个头：$c_1^{(0)}=3$、$c_1^{(1)}=4$，按头编号拼成 $[3,4]$，其余阶段照旧，$y_1=2$。这一组对照同时钉住两件事：多头结果是按编号 0、1 的顺序拼接的；投影后相加的是编码 $e_1$——拼接顺序或残差对象错一处，输出就不再是 2。

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| ---- | ---------- | ---------- | ---- |
| 双向 RNN 编码 | $O(S\cdot N\cdot R\cdot(F+R))$ | $O(NR)$ | 每层正反各扫一遍序列 |
| 多头注意力 | $O(A\cdot N^2\cdot Q)$ | $O(ANQ)$ | 分数矩阵 $\beta$ 与加权求和是乘法量的主体 |
| 投影与输出层 | $O(N\cdot R\cdot(AQ+C))$ | $O(NR)$ | 两次行向量线性变换 |
| 四段流水线整体（最优） | $O(SNR(F+R)+AN^2Q+NRAQ+NRC)$ | $O(NR+ANQ)$ | 数据范围极小，按公式直接照抄 |

瓶颈是多头的 $O(AN^2Q)$，但 $N\le10$ 使它约等于常数；$N$ 变大后压掉 $N^2$ 正是滑动窗口的动机，见 [P5337](P5337.md)。

## 易错点总结

### 1. 反向递推用的是「后一个位置」的状态

$r_t = a_tU_b + r_{t+1}V_b + c_b$，初值 $r_{N+1}$。实现里循环 `for t in range(N-1, -1, -1)`，当前位置加的是刚算完的 `nxt`（即 $r_{t+1}$）。顺手写成 `r[t-1]` 或复用正向的 `prev`，维度照常、程序照常跑完，但整条反向状态从最后往前全错，且本题三个样例都照不出来——$N=1$ 时没有方向可错，样例 2 的 $V_b$ 又恰好是 0。这类无报错的错误只能靠逐句对照递推式来防。

### 2. 两处拼接顺序是「正向在前、头按编号」

$e_t=[p_t\parallel r_t]$ 正向在前（`a = [p[t] + r[t] ...]` 那行），多头结果是 $[c_t^{(0)}\parallel\dots\parallel c_t^{(A-1)}]$ 按头编号（按 `for h in range(A)` 嵌套的列表组装那行）。顺序颠倒后维度全部自洽，但 $W_p$ 读到的列与它应乘的分量错位，输出系统性全错。

### 3. 残差加的是编码 $e_t$，不是别的中间量

投影公式 $u_t=c_tW_p+c_p+e_t$ 里的 $e_t$ 是**最后一层拼接出的编码结果**。写成加第一层输入或加最后一层的某个单方向状态，公式看着也顺、维度也对，但那是另一道题的答案——残差对象是 $e_t$ 这一点要在实现前想清楚。

## 扩展思考

- 模域对加减乘封闭：「每步运算后取模」与「累加完再取模」结果一致。本题在每个分量末尾记一个 `%`，是随手不易错的纪律，不是数值上的必要。
- 「向量是行向量」的约定是全部公式的地基：若换成列向量，每个矩阵的转置关系都要重写。这类题的正确姿势是把约定逐字从题面搬进代码，不做任何「显然等价」的变形。
