# P5612. K-Median 聚类

> 场次：2026年10月10日 · 来源：[CodeFun2000 P5612](https://codefun2000.com/p/P5612)

## 题目描述

K-Median 按划分做聚类：样本之间用曼哈顿距离（L1），簇中心取该簇在每一维上的中位数，因此离群点不容易把中心拉偏。

给定 n 个样本，每个样本有 d 个浮点特征。请按下列固定流程把样本分成 k 个簇，并输出簇编号、最终中心和 inertia。

初始化：取下标 0 到 k-1 的样本作为 k 个簇的初始中心。

分配：把每个样本分到曼哈顿距离最近的中心。到多个中心的距离相同时，分到编号最小的簇。

更新：若某个簇在本轮分配后没有样本，则该簇中心保持不变；否则，用簇内样本在每一维上的中位数替换该簇中心。

重复分配与更新，直到中心变化量小于 tol，或迭代次数达到 max_iter。tol 固定为 $10^{-4}$，max_iter 固定为 100。中心变化量是所有簇、所有维度上，新旧中心坐标绝对差的总和。

曼哈顿距离为

$dist(x,y)=\sum_i |x_i-y_i|$

一维中位数：将数值升序排列后，个数为奇数时取正中间的一项，个数为偶数时取正中间两项的算术平均（可以是浮点数）。例如 $[1,3,5,9]$ 的中位数是 $(3+5)/2=4$。

## 输入格式

第一行三个整数 n、d、k，依次为样本数、特征维数、簇数。

接下来 n 行，每行 d 个浮点数，表示一个样本的特征。

$1 \le n \le 5000$

$1 \le d \le 20$

$1 \le k \le \min(100, n)$

每个特征值都属于 $[-10^4, 10^4]$。

## 输出格式

第一行输出 n 个整数，为最后一轮分配得到的簇编号（从 0 到 k-1），相邻整数之间用一个空格分隔。

接下来 k 行，按簇编号从 0 到 k-1 输出本轮更新后的中心。每行 d 个浮点数，保留小数点后 6 位，相邻数之间用一个空格分隔。空簇输出被保留下来的中心。

最后一行输出 inertia，即每个样本到其所属簇中心的曼哈顿距离之和，保留小数点后 6 位。

## 示例

### 示例 1

**输入：**

```
3 2 1
2 8
6 1
4 5
```

**输出：**

```
0 0 0
4.000000 5.000000
11.000000
```

**说明：**

$k=1$ 时，初始中心就是样本 0，即 $(2,8)$。三个样本都分进簇 0。

第 1 维排序为 $2,4,6$，中位数是 4；第 2 维排序为 $1,5,8$，中位数是 5。新中心为 $(4,5)$。

再分配一次，中心不再变化，迭代停止。

inertia 为各样本到 $(4,5)$ 的曼哈顿距离之和：

$|2-4|+|8-5|=5$，$|6-4|+|1-5|=6$，$|4-4|+|5-5|=0$，合计 11。

### 示例 2

**输入：**

```
4 2 2
1 1
4 2
5 5
8 8
```

**输出：**

```
0 0 1 1
2.500000 1.500000
6.500000 6.500000
10.000000
```

**说明：**

初始中心：簇 0 为 $(1,1)$，簇 1 为 $(4,2)$。

第 1 轮分配：

- 样本 0 $(1,1)$：到簇 0 为 0，到簇 1 为 4，分到簇 0
- 样本 1 $(4,2)$：到簇 0 为 4，到簇 1 为 0，分到簇 1
- 样本 2 $(5,5)$：到簇 0 为 8，到簇 1 为 4，分到簇 1
- 样本 3 $(8,8)$：到簇 0 为 14，到簇 1 为 10，分到簇 1

簇 0 只有一个样本，中心仍是 $(1,1)$。簇 1 的第 1 维为 $4,5,8$，中位数 5；第 2 维为 $2,5,8$，中位数 5。变化量为 $|5-4|+|5-2|=4$。

第 2 轮，中心为 $(1,1)$ 与 $(5,5)$：

- 样本 0：距离 0 与 8，分到簇 0
- 样本 1：距离 $|4-1|+|2-1|=4$ 与 $|4-5|+|2-5|=4$，相等，取编号更小的簇 0
- 样本 2：距离 8 与 0，分到簇 1
- 样本 3：距离 14 与 6，分到簇 1

簇 0 含 $(1,1)$、$(4,2)$，中位数为 $((1+4)/2,(1+2)/2)=(2.5,1.5)$。簇 1 含 $(5,5)$、$(8,8)$，中位数为 $(6.5,6.5)$。变化量为 $|2.5-1|+|1.5-1|+|6.5-5|+|6.5-5|=5$。

第 3 轮，中心为 $(2.5,1.5)$ 与 $(6.5,6.5)$：

- 样本 0：距离 2 与 11，分到簇 0
- 样本 1：距离 2 与 7，分到簇 0
- 样本 2：距离 6 与 3，分到簇 1
- 样本 3：距离 12 与 3，分到簇 1

划分和中心都不再变化，迭代停止。簇编号为 `0 0 1 1`。

inertia：

$|1-2.5|+|1-1.5|=2$，$|4-2.5|+|2-1.5|=2$，$|5-6.5|+|5-6.5|=3$，$|8-6.5|+|8-6.5|=3$，合计 10。

## 解题思路

### 判分对象是一次模拟的终点，不是更好的划分

题面把 K-Median 的每一个环节都写死了：初始中心取下标 0 到 k-1 的样本、分配按最近的曼哈顿距离、平局归编号最小的簇、空簇保留旧中心、变化量逐簇逐维求和、降到 $10^{-4}$ 以下或迭代满 100 轮即停。没有任何环节留给解题者发挥，题意不是"做聚类"，而是"把这套流程原样跑出来"。难点于是集中在三处判定与两处循环形状上。

判定里的第一条：**输出锚定在哪一轮**。每次迭代都是"用当前中心分配 → 用新分配更新中心 → 累计变化量 → 视变化量决定去留"。停下的那一轮，簇编号来自它的**分配结果**，中心来自它的**更新结果**，inertia 用这一对算出。代码里 `kmedian` 的 `return labels, centers` 就写在同一次迭代的末尾，`solve()` 再用 `centers[labels[idx]]` 把两者配对；这个对应一旦错开，输出全错——示例 1 里误用初始中心 $(2,8)$ 算 inertia 会得到 $16$ 而不是 $11$。

第二条：**变化量**是所有簇、所有维度上新旧坐标绝对差的总和（代码里 `delta` 的双重循环），不是最大位移，也不只统计非空簇；空簇新旧中心相同，贡献为 $0$。终止判定用严格小于 `delta < 1e-4`，外层再套 `range(100)` 兜住不收敛的情形。

### 为什么是中位数配曼哈顿距离，这个配对又如何落到循环上

L1 距离按维拆开是 $d$ 个非负项之和 $\sum_t |x_t-c_t|$，每一维互相独立；而一维上让 $\sum_i |x_i-c|$ 最小的取值就是中位数——$c$ 落在排序后的中间位置时，往左或往右挪一格，减少的距离与增加的距离恰好抵消；偶数个样本时中间两点之间取值同等优，题目取中间两项的算术平均（因此中位数常是 $.5$）。题面开头说"离群点不容易把中心拉偏"，依据就是这一点：一维取值 $0,0,0,0,100$，中位数是 $0$，均值被离群点拉到 $20$。

"逐维独立"决定了更新步的形状：对簇内样本**按列**取值，每列单独排序、取中间（代码里 `median_of([row[t] for row in group]) for t in range(dims)`）。这里没有"对整个向量求平均"式的操作，也因此中位数函数对偶数个取值直接返回浮点结果，避免把 $.5$ 截掉。

### 平局与剪枝长在同一段距离循环里

分配步每轮 $O(n\cdot k\cdot d)$，而 $n\le5000$、$k\le100$、$d\le20$、迭代至多 100 轮，最坏逼近 $10^9$ 次浮点加法——纯 Python 按这个量级直写有超时风险。计算量省在 L1 的形状上：非负项逐项相加，**部分和单调上升**，一旦加到不小于当前最优距离，后面几维只会让它更大、绝无反超可能：

```python
for t in range(dims):
    dist += abs(x[t] - c[t])
    if dist >= best_dist:    # 部分和已不小于最优，剩下的维度只会更大
        break
else:
    best_dist = dist         # 完整算完且严格更小，才接受这个候选
    best = j
```

绝大多数候选中心在前两三维就被排除，实际累加的维度数远小于 20。剪枝不改变最坏复杂度，但它把"最坏上界"与"实际可跑"之间的距离压掉了——数据范围在这道题里是真实的性能判据，不是装饰。

同一个循环还免费处理了平局：候选中心按 $j$ 从小到大枚举（簇 0 先以全距离坐上 `best`），只有**严格更小**才替换；部分和一旦 `>=`（含相等）立即弃权。于是距离并列时留下的自然是编号最小的簇，平局规则没有单独的比较代码。

其余实现决定都是小件：初始化中心用 `samples[i][:]` 复制一份，后续整体替换不会改到样本表；更新前先按标签把样本收进 `members`，空簇在代码里即空列表，原样保留旧中心参与下一轮分配；inertia 在迭代全部结束后用最终分配与最终中心算一次，运算过程中逐轮累加毫无意义（中心和分配一直在变）；`format_float` 把 $|v|<5\times10^{-7}$ 的值归零，避免浮点残差 $-0.0$ 被打成 `-0.000000`。

## 完整代码实现

```python
import sys

TOL = 1e-4       # 中心变化量的收敛阈值
MAX_ITER = 100   # 迭代次数上限


def median_of(values):
    """一维中位数：奇数个取正中间一项，偶数个取中间两项的算术平均。"""
    ordered = sorted(values)
    m = len(ordered)
    mid = m // 2
    if m % 2 == 1:
        return float(ordered[mid])
    # 偶数个：中间两项求和后除以 2，结果是 .0 或 .5，double 可以精确表示
    return (ordered[mid - 1] + ordered[mid]) / 2.0


def l1_distance(x, y, dims):
    """曼哈顿距离：逐维取绝对差再求和。"""
    total = 0.0
    for t in range(dims):
        total += abs(x[t] - y[t])
    return total


def kmedian(samples, k, dims):
    """按题面流程迭代，返回 (最后一轮的分配, 本轮更新后的中心)。"""
    n = len(samples)

    # 初始化中心：直接取前 k 个样本的副本，后面会整体替换，不能和样本共用列表
    centers = [samples[i][:] for i in range(k)]
    labels = [0] * n

    for _ in range(MAX_ITER):
        # ---------- 分配 ----------
        for idx in range(n):
            x = samples[idx]
            best = 0
            best_dist = l1_distance(x, centers[0], dims)

            for j in range(1, k):
                c = centers[j]
                dist = 0.0
                for t in range(dims):
                    dist += abs(x[t] - c[t])
                    # 距离只会越加越大，一旦不严格小于当前最优，
                    # 就不可能再成为更近的簇，直接放弃这个候选
                    if dist >= best_dist:
                        break
                else:
                    # 只有严格更小才替换：距离相等时保留编号更小的簇，
                    # 因为 j 是从小到大枚举的，先到者即为编号最小者
                    best_dist = dist
                    best = j

            labels[idx] = best

        # ---------- 更新 ----------
        # 按簇收集样本，空簇在这里表现为空列表
        members = [[] for _ in range(k)]
        for idx in range(n):
            members[labels[idx]].append(samples[idx])

        new_centers = []
        for j in range(k):
            group = members[j]
            if not group:
                # 空簇没有样本可算中位数，题目要求保留原中心
                new_centers.append(centers[j])
                continue
            # 每一维单独取中位数，所以按列取值后排序
            new_centers.append(
                [median_of([row[t] for row in group]) for t in range(dims)]
            )

        # 中心变化量：所有簇、所有维度上新旧坐标绝对差的总和
        delta = 0.0
        for j in range(k):
            old, new = centers[j], new_centers[j]
            for t in range(dims):
                delta += abs(new[t] - old[t])

        centers = new_centers
        if delta < TOL:
            break

    return labels, centers


def format_float(value):
    """保留 6 位小数，并把 -0.000000 归一成 0.000000。"""
    if abs(value) < 5e-7:
        value = 0.0
    return f"{value:.6f}"


def solve():
    """读取输入、完成聚类并按要求输出。"""
    tokens = sys.stdin.buffer.read().split()
    if not tokens:
        return

    n = int(tokens[0])
    d = int(tokens[1])
    k = int(tokens[2])
    if n <= 0 or d <= 0 or k <= 0:
        return

    # 样本按行切分：每 d 个数是一个样本
    values = list(map(float, tokens[3:3 + n * d]))
    samples = [values[i * d:(i + 1) * d] for i in range(n)]

    labels, centers = kmedian(samples, k, d)

    # 第一行：最后一轮分配的簇编号
    print(" ".join(str(x) for x in labels))

    # 接下来 k 行：本轮更新后的中心
    for center in centers:
        print(" ".join(format_float(v) for v in center))

    # 最后一行：inertia = 每个样本到自己所属簇中心的曼哈顿距离之和
    inertia = 0.0
    for idx in range(n):
        inertia += l1_distance(samples[idx], centers[labels[idx]], d)
    print(format_float(inertia))


if __name__ == "__main__":
    solve()
```

## 示例推演

### 样例 2：两簇轮转，并出现一次距离平局

初始中心：簇 0 = 样本 0 $(1,1)$，簇 1 = 样本 1 $(4,2)$。

**第 1 轮分配**：

| 样本 | 坐标 | 到簇 0 | 到簇 1 | 分到 |
| --- | --- | --- | --- | --- |
| 0 | $(1,1)$ | 0 | 4 | 0 |
| 1 | $(4,2)$ | 4 | 0 | 1 |
| 2 | $(5,5)$ | 8 | 4 | 1 |
| 3 | $(8,8)$ | 14 | 10 | 1 |

**第 1 轮更新**：簇 0 只含 $(1,1)$，中位数即 $(1,1)$；簇 1 第 1 维为 $4,5,8$、第 2 维为 $2,5,8$，中位数得 $(5,5)$。变化量 $|5-4|+|5-2|=4\ge10^{-4}$，继续。

**第 2 轮分配**（中心为 $(1,1)$、$(5,5)$）：

| 样本 | 到簇 0 | 到簇 1 | 分到 |
| --- | --- | --- | --- |
| 0 | 0 | 8 | 0 |
| 1 | 4 | 4 | 0（平局取编号更小） |
| 2 | 8 | 0 | 1 |
| 3 | 14 | 6 | 1 |

**第 2 轮更新**：簇 0 含 $(1,1)$、$(4,2)$，两维都是两个数取平均，中心 $(2.5,1.5)$；簇 1 含 $(5,5)$、$(8,8)$，中心 $(6.5,6.5)$。变化量 $1.5+0.5+1.5+1.5=5$，继续。

**第 3 轮分配**：用中心 $(2.5,1.5)$、$(6.5,6.5)$，四个样本到两中心的距离依次为 $2/11$、$2/7$、$6/3$、$12/3$，分配仍是 `0 0 1 1`。

**第 3 轮更新**：成员与上一轮完全相同，中位数不变，变化量 $0<10^{-4}$，停止。

**inertia**（最终分配配最终中心）：$2+2+3+3=10$。

样例 1 的完整过程在题面说明里已逐步演过：$k=1$ 时中心被中位数拉到 $(4,5)$，inertia $=5+6+0=11$，而误用初始中心 $(2,8)$ 算出的是 $16$——这两个数之差就是"输出锚定在停机那一轮"的直观证据。

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| ---- | ---------- | ---------- | ---- |
| 每个候选中心算满 $d$ 维 | $O(iter\cdot n\cdot k\cdot d)$ | $O(n\cdot d+k\cdot d)$ | 直写正确；$5000\times100\times20\times100$ 是 $10^9$ 量级，纯 Python 直写有超时风险 |
| 逐维部分和提前剪枝（最优） | $O(iter\cdot(n\cdot k\cdot d+n\cdot d\log n))$ | $O(n\cdot d+k\cdot d)$ | 部分和非负单调，达标即弃；绝大多数候选在前几维出局 |

两行的**最坏**复杂度相同——数据确实难区分时，每个候选都得算满 $d$ 维；剪枝压缩的是典型输入的常数。$n\,d\log n$ 一项来自更新步的逐列排序取中位数，相对分配步很小。迭代上限 100 由题面给定，无论收敛与否都封死轮数。

## 易错点总结

### 1. 平局判定由两个动作共同保证

「编号小的簇胜出」= 候选按 $j$ 递增枚举 + 只接受**严格更小**的距离（剪枝判据用 `>=`，同样把相等挡在门外）。两处任一改弱——替换写成 `<=`、剪枝写成 `>`——平局都会翻给编号更大的簇。示例 2 第 2 轮里样本 1 到两个中心的距离同为 $4$，必须落进簇 0；一旦落进簇 1，两个簇的中位数、标签、inertia 级联全变。

### 2. 输出的三个数必须来自同一轮

簇编号 = 最后一轮的分配，中心 = 本轮更新后的结果，inertia = 用这一对算出。用更新后的中心重新分配一次再输出、或拿上一轮中心配本轮标签，都会错位：示例 1 用初始中心 $(2,8)$ 时 inertia 变成 $0+11+5=16$（正确配对 $5+6+0=11$）。代码把 `labels` 与 `centers` 从同一个 `return` 里交出，就是锁住这个对应。

### 3. 浮点负零要压掉

中位数取平均与逐维求和都会留下 $-0.0$ 这类残渣，直接输出成 `-0.000000` 就判错。`format_float` 在格式化前把 $|v|<5\times10^{-7}$ 的值归零。

## 扩展思考

- **为什么一定会停**：中心不变时"分到最近簇"只会让每个样本更近或不变，中位数又是使簇内逐维 L1 和最小的取值点，所以 inertia 单调不增、逐轮变化量被压向 $0$。"变化量小于阈值即停"能成为正确的停止条件，靠的就是这层单调性。
- **与 K-Means 的对照**：同一个"分配→更新"交替框架，把中位数换成均值、L1 换成平方欧氏就是 K-Means；L1 配中位数对离群点稳健，源头就在第三节那段一维推导里。
- **更狠的剪枝**：三角不等式 $dist(x,b)\ge dist(a,b)-dist(x,a)$ 能用上一轮的距离给每个候选造下界（K-Means 里的 Elkan 算法用的正是它），可以把实际要算的距离从 $k$ 个压到个位数；本题规模下部分和剪枝已经足够。
