# P5434. 整除最少操作

> 场次：2026年9月12日 · 来源：[CodeFun2000 P5434](https://codefun2000.com/p/P5434)

## 题目描述

有两个正整数 $n$、$m$。每一次操作，从二者中任选一个，将其加一或减一；操作结束后该数仍须为正整数。

求最少操作次数，使得最终有 $n \mid m$（即 $m$ 能被 $n$ 整除）。

## 输入格式

每个测试文件包含多组测试数据。第一行输入一个整数 $T$（$1 \le T \le 10^4$），表示数据组数。每组测试数据如下：

一行两个正整数 $n$、$m$（$1 \le n, m \le 10^6$）。

## 输出格式

对每组数据输出一行一个整数，表示使 $n$ 整除 $m$ 的最少操作次数。

## 示例

### 示例 1

**输入：**

```
4
4 15
11 25
7 7
10 7
```

**输出：**

```
1
2
0
3
```

**说明：**

- $4,15$：把 $m$ 加到 $16$，则 $4 \mid 16$，共 $1$ 次。把 $n$ 改成 $3$ 或 $5$ 同样只需 $1$ 次。
- $11,25$：把 $n$ 改成 $12$、$m$ 改成 $24$，则 $12 \mid 24$，共 $2$ 次。只把 $m$ 减到 $22$ 要 $3$ 次，更差。
- $7,7$：已有 $7 \mid 7$，答案为 $0$。
- $10,7$：把两者都改成 $7$（或都改成 $10$）需要 $3$ 次；更少次数无法整除。

## 解题思路

### 把答案写成终态的函数

「$n$ 整除 $m$」只有这两种终态：最终的 $n$ 记作 $x$（$x\ge1$），最终的 $m$ 是 $x$ 的正倍数 $kx$（$k\ge1$）。最少操作次数就是

$$\text{cost}(x,k)=|x-n|+|kx-m|$$

最少操作次数等于这个二元函数的全局最小值。直接枚举 $(x,k)$ 是乘积级的——$n,m$ 可达 $10^6$，扫不动。

### 数据范围给出的分界：S² 封顶

先用两件「永远是备选」的事给答案定一个上界 $U$：

1. 把 $n$ 改成 $1$，代价 $n-1$；$1$ 整除一切 $m$。
2. 把 $m$ 改成 $n$（$k=1$，$x=n$），代价 $|n-m|$。

任何更优方案的代价都不超过 $U$，所以它的每一项也都不超过 $U$，于是终态的 $km$ 值 $kx\le m+U$。$m+U$ 的全局上限是 $2\times10^6-1$（$n\ge m$ 时 $m+U\le n\le10^6$；$n<m$ 时 $m+U<2m\le2\times10^6$）。取 $S=1500$，则 $S^2=2.25\times10^6$ 大于这个上限——**最优解不可能同时满足 $x>S$ 且 $k>S$**，否则 $kx>S^2>m+U$，自相矛盾。所以只需枚举两个三角部分：

$$\{x\le S,\ k\text{ 任意}\}\ \cup\ \{k\le S,\ x\text{ 任意}\}$$

每组 $T\le10^4$ 的总工作量约为 $10^4\times2S=3\times10^7$ 次常数操作——这就是「根号分治」在构造类题里的样子：一个量吃下小额那一侧，另一个量用数学把大额那一侧化成常数次求值。

### 两个部分里「就近对齐」的求值

**部分 1（$x\le S$）**：固定 $x$ 后，把 $m$ 就近归到 $x$ 的正倍数上。设 $m=qx+r$（$q,r\ge0$），下面的倍数 $qx$（$q\ge1$ 时可用）与上面的 $(q+1)x$ 代价分别是 $r$ 与 $x-r$，取小者；$q=0$（即 $x>m$）时正倍数只有 $x$ 本身，代价是 $x-m$。总代价加上 $|x-n|$。顺带一个剪枝：$x>n$ 之后 $\text{cost}\ge x-n$ 随 $x$ 单调变大，一旦 $x-n\ge\text{best}$ 就可以整段退出。

**部分 2（$k\le S$）**：固定 $k$ 后 $f(x)=|x-n|+|kx-m|$ 是关于 $x$ 的凸折线，断点只有 $x=n$ 与 $x=m/k$。两侧斜率是 $\pm1\pm k$：$k\ge2$ 时恒不为零，实数最小值必落在断点上；$k=1$ 时中间段斜率为零，但最小值也在端点 $x=n$ 或 $x=m$ 处取到。整数上取断点的整数邻点即可——候选集合就是 $\{n,\ \lfloor m/k\rfloor,\ \lfloor m/k\rfloor+1\}$，每个 $k$ 只做三次求值。

对照一下被否决的起步方案：对每个 $x$ 枚举**全部**倍数、或对每个 $k$ 枚举全部 $x$，都要 $O(m)$ 一组，$10^4$ 组乘起来不可行；凸性把「倍数」这一根枚举轴压掉，只剩最近的几个点。

### 实现映射

`best_ops` 里三段对应上面三件事：初始 `best = min(n-1, |m-n|)` 是 $U$；第一个循环扫 $x\le S$，`divmod` 得 $(q,r)$，`q == 0` 分支给出 $x-m$，否则 `min(r, x-r)`；第二个循环扫 $k\le S$，对候选三元组逐点求值。全程没有数组，$O(1)$ 空间。

## 完整代码实现

```python
"""
P5434. 整除最少操作 - 有界枚举（终态拆解 + 双部分枚举）

两个正整数 n、m，每次操作把其中一个加一或减一（保持为正），求最少操作
次数使得最终的 n 整除 m（m % (改后 n) == 0）。

输入格式：
- 第一行组数 T；
- 接下来 T 行，每行两个正整数 n、m（1 <= n, m <= 1e6）。

输出格式：
- 每组一行，最少操作次数。

核心思路：设最终的 n 为 x（x>=1），最终的 m 为 x 的 k 倍（k>=1），
代价为 |x - n| + |k*x - m|。直接枚举 (x, k) 是乘积级的大数，必须先
缩范围。两个天然上界给出答案 U：
1. 把 n 改成 1：代价 n-1，任何 m 都被 1 整除；
2. 把 m 改成 n：代价 |m-n|（k=1，x=n）。
设 S 满足 S^2 > 1e6 + U_max。U_max <= m + |m-n| <= 2e6 - 1，取
S = 1500（S^2 = 2250000）即封顶。若 x > S 且 kx > S^2*... 若 x > S 且
k > S，则 k*x > S^2 > m + U，与 x*k <= m + U 矛盾（k*x 超出上界的
方案不可能优于初始上界，随后剪枝也不会选中它）。所以最优 x 与 k
至少有一个不超过 S，分两个部分枚举：
- 部分 1（x <= S）：对每个 x，m 就近写成正倍数，代价 |x-n| +
  min(m%x, x - m%x)（x > m 时只有 x 本身这个倍数可选）；
- 部分 2（k <= S）：固定 k 后 |x-n| + |k*x-m| 是关于 x 的凸折线，
  最小值只可能落在断点 x = n 或 x = m/k 附近，取整数候选
  {m//k, m//k+1, n} 三个点求值即可。

复杂度：每组 O(S) 次转移（S=1500），T 组总量 O(T*S)。
"""

# https://codefun2000.com/p/P5434
# @sample-start
"""
样例输入 1:
4
4 15
11 25
7 7
10 7

样例输出 1:
1
2
0
3

# @sample-end

import sys

S = 1500  # S^2 = 2250000 > 2e6 - 1 = max(m) + max(U)，双部分枚举的分界


def best_ops(n, m):
    # 初始上界：m 改成 n（k=1），或 n 改成 1
    best = abs(m - n)
    if n - 1 < best:
        best = n - 1
    if best == 0:
        return 0

    # 部分 1：终态 x 取小值（x = 1..S），m 就近写成 x 的倍数
    for x in range(1, S + 1):
        if x > n and x - n >= best:
            break  # x 再大，光改 n 的代价就已不低于当前答案
        k, r = divmod(m, x)
        if k == 0:
            d = x - m  # 倍数只剩下 x 本身（k=1）
        else:
            d = r if r <= x - r else x - r
        cost = abs(x - n) + d
        if cost < best:
            best = cost

    # 部分 2：倍数系数 k 取小值（k = 1..S），终态 x 被 |x-n|+|k*x-m| 决定，
    # 凸性保证最小值在 x=n 或 x=m/k 的整数邻点处取到
    for k in range(1, S + 1):
        fl = m // k
        for x in (fl, fl + 1, n):
            if x < 1:
                continue
            cost = abs(x - n) + abs(k * x - m)
            if cost < best:
                best = cost
    return best


def solve():
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    t = int(next(it))
    out = []
    for _ in range(t):
        n = int(next(it))
        m = int(next(it))
        out.append(str(best_ops(n, m)))
    sys.stdout.write("\n".join(out) + "\n")


def run_tests():
    import io
    import random
    import time

    def run_case(inp):
        old_stdin, old_stdout = sys.stdin, sys.stdout
        sys.stdin = io.TextIOWrapper(io.BytesIO(inp.encode("utf-8")))
        sys.stdout = io.StringIO()
        try:
            solve()
            output = sys.stdout.getvalue().strip()
        finally:
            sys.stdin, sys.stdout = old_stdin, old_stdout
        return "\n".join(output.split("\n"))

    def brute(n, m):
        """小值域精确参照：在 [1, 60]^2 的状态图上 BFS，逐状态判整除。"""
        from collections import deque

        cap = 60
        dist = [[-1] * (cap + 1) for _ in range(cap + 1)]
        dist[n][m] = 0
        queue = deque([(n, m)])
        while queue:
            a, b = queue.popleft()
            if b % a == 0:
                return dist[a][b]
            for da, db in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                na, nb = a + da, b + db
                if 1 <= na <= cap and 1 <= nb <= cap and dist[na][nb] == -1:
                    dist[na][nb] = dist[a][b] + 1
                    queue.append((na, nb))
        return None

    test_cases = [
        # 官方样例（4 组一次读入）
        ("4\n4 15\n11 25\n7 7\n10 7\n", "1\n2\n0\n3"),
        # 官方说明逐组拆出来的等价单组：11 -> 12、25 -> 24
        ("1\n11 25\n", "2"),
    ]
    for i, (inp, expected) in enumerate(test_cases, 1):
        output = run_case(inp)
        status = "✓" if output == expected else "✗"
        print(f"样例 {i}: {'通过' if output == expected else '失败'} {status}")
        assert output == expected, f"样例 {i} 期望 {expected}，实际 {output}"

    # 官方只有 1 组样例，先做小值域全对拍（n、m<=40，与右侧 DP/BFS 精确对照）。
    pairs = [(n, m) for n in range(1, 13) for m in range(1, 13)]
    lines = "\n".join(f"{n} {m}" for n, m in pairs)
    outs = run_case(f"{len(pairs)}\n{lines}\n").strip().split("\n")
    for (n, m), line in zip(pairs, outs):
        want = brute(n, m)
        assert want is not None
        assert int(line) == want, f"对拍失败 n={n} m={m}: 期望 {want}，实际 {line}"
    print(f"对拍用例 {len(pairs)} 组（n,m<=12 全枚举）：通过")

    # 随机大值对拍：与「枚举 x 的全部邻近倍数」的更宽暴力对照（复杂版本）。
    rng = random.Random(20260912)
    rand_pairs = []
    for _ in range(60):
        n = rng.randint(1, 1000000)
        m = rng.randint(1, 1000000)
        rand_pairs.append((n, m))
    lines = "\n".join(f"{n} {m}" for n, m in rand_pairs)
    outs = run_case(f"{len(rand_pairs)}\n{lines}\n").strip().split("\n")

    def wide_brute(n, m):
        """宽松枚举（必须覆盖上面的两部分）：x 与 k 的范围都放大到 2200，
        再各补一个邻域，输出只会不高于两次部分枚举的结果。"""
        best = min(n - 1, abs(n - m))
        for x in range(1, 2201):
            k, r = divmod(m, x)
            d = x - m if k == 0 else (r if r <= x - r else x - r)
            best = min(best, abs(x - n) + d)
        for k in range(1, 2201):
            fl = m // k
            for x in (fl, fl + 1, fl + 2, n - 2, n - 1, n, n + 1, n + 2):
                if x >= 1:
                    best = min(best, abs(x - n) + abs(k * x - m))
        return best

    for (n, m), line in zip(rand_pairs, outs):
        want = wide_brute(n, m)
        assert int(line) == want, f"随机对拍失败 n={n} m={m}: 期望 {want}，实际 {line}"
    print(f"对拍用例 {len(rand_pairs)} 组（随机大值，宽邻域枚举）：通过")

    # 边界用例：n=1 整除一切；n=m 零次；m 是 n 倍数零次。
    edges = [(1, 1000000), (999999, 999999), (500000, 1000000), (2, 999999)]
    lines = "\n".join(f"{n} {m}" for n, m in edges)
    outs = [int(x) for x in run_case(f"{len(edges)}\n{lines}\n").strip().split("\n")]
    assert outs == [0, 0, 0, 1], f"边界用例异常: {outs}"
    print(f"边界用例 {(1, 1000000)}, {(999999, 999999)}, {(500000, 1000000)}, {(2, 999999)}: 通过")

    # 性能上限：一组 (1e6 - 素数附近对)，验证两次部分枚举在最坏主界内时限完成。
    t0 = time.perf_counter()
    rng2 = random.Random(1)
    worst = []
    for _ in range(500):
        worst.append((rng2.randint(990000, 1000000), rng2.randint(990000, 1000000)))
    lines = "\n".join(f"{n} {m}" for n, m in worst)
    run_case(f"{len(worst)}\n{lines}\n")
    elapsed = time.perf_counter() - t0
    print(f"压力用例 500 组 (n,m~1e6)：用时 {elapsed:.2f}s")


if __name__ == "__main__":
    if len(sys.argv) > 1 and sys.argv[1] == "--test":
        run_tests()
    else:
        solve()
```

## 示例推演

以官方第 2 组 $n=11,\ m=25$ 为例。初始上界 $U=\min(10,\ 14)=10$。

**部分 1**（$x$ 从 $1$ 往上扫）里几个关键点：

| $x$ | $m=qx+r$ | $q\ge1$ ? | $d=\min(r,\ x-r)$ | $|x-11|+d$ |
| --- | --- | --- | --- | --- |
| 5 | $25=5\times5+0$ | 是 | $0$ | $6+0=6$ |
| 8 | $25=3\times8+1$ | 是 | $1$ | $3+1=4$ |
| 11 | $25=2\times11+3$ | 是 | $3$ | $0+3=3$ |
| 12 | $25=2\times12+1$ | 是 | $1$ | $1+1=\mathbf{2}$ |
| 13 | $25=1\times13+12$ | 是 | $1$ | $2+1=3$ |

$x=12$ 处取到 $2$：把 $n$ 从 $11$ 改到 $12$（1 次）、$m$ 从 $25$ 改到 $24=2\times12$（1 次）。

**部分 2** 再核对一遍同一方案：$k=2$ 时候选 $x\in\{m//2=12,\ 13,\ n=11\}$——$x=12$ 给 $|12-11|+|24-25|=2$，$x=11$ 给 $3$，$x=13$ 给 $|13-11|+|26-25|=3$。两个部分在 $2$ 处会师，输出 `2`。若候选里漏掉 $x=\lfloor m/k\rfloor$，只按 $x=n$ 求值就会错拿 $3$。

其余三组的落点：

- $4,15$：部分 1 的 $x=4$，$15=3\times4+3$，$d=\min(3,1)=1$，$|4-4|+1=1$；
- $7,7$：初始 $U=0$，直接返回 `0`；
- $10,7$：初始 $U=\min(9,3)=3$，各处($x=7$ 时 $7=1\times7$，$d=0$，$|7-10|=3$)各候选都停在 $3$，输出 `3`——其中 $x=9>7$ 走的是 $q=0$ 分支（$9$ 的正倍数只有 $9$ 本身，$d=2$），与 $k$ 取近邻的选法等效。

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| ---- | ---------- | ---------- | ---- |
| 状态图 BFS（对每对 $\pm1$ 松弛） | $O(V\cdot E)$，状态值域 $10^6\times10^6$ | $O(V)$ | 只适合值域几十的小输入对拍 |
| 直接枚举 $(x,k)$ 全部组合 | $O(n\cdot m)$ | $O(1)$ | 乘积级，$10^{12}$ 次起步 |
| 双部分枚举 $x\le S$ / $k\le S$（最优） | $O(S)$ | $O(1)$ | $S=1500$；$T$ 组总量 $O(T\cdot S)\approx3\times10^7$ 次常数操作 |

## 易错点总结

### 1. `q == 0` 分支不能并入 `min(r, x - r)`

部分 1 里 `divmod(m, x)` 之后，$x>m$ 时商 $q=0$：正倍数里只有 $k=1$ 的 $x$ 本身可选，代价是 `x - m`。若不分分支直接对 `min(r, x - r)` 求值，$x>2m$ 时 `x - r = x - m` 会大于 $r=m$，公式反而返回 $m$——那对应「$kx=0$」这种非法终态，给出的假代价比真实答案还小。现象：$m$ 远小于候选 $x$ 的数据组输出**偏小**（WA 而不是超时），小值域全对拍在若干组上会与状态图 BFS 对不上。

### 2. 分界 $S$ 要按 $S^2 > m + U$ 的上限取

$S$ 取 $1500$ 是因为 $S^2=2.25\times10^6>2\times10^6-1\ge m+U$，这保证「$x$ 与 $k$ 同时超过 $S$」的最优解不存在。把 $S$ 写成 $1000$（$S^2=10^6$ 不再封顶）时，$x$、$k$ 都落在 $(1000, 1500]$ 圈乘积高达 $2.25\times10^6>m+U$ 的那一小段最优解会被漏掉，极端数据组答案偏大——这个缺口不会被样例暴露，收缩 $S$ 之前必须重算上界。

## 扩展思考

- 双部分枚举是「根号分治」在构造类题上的形态：一侧用小值穷举兜住结构，另一侧用局部凸性/单调性把每一步压成常数次求值。同一骨架适用于「两个量乘起来要落在某个界内」（如枚举约数对、成对交换方案）这类题。
- 若要求输出**操作序列**而不只是次数，两个部分各记下取到 `best` 的 $(x,k)$，沿终态回放 $\pm1$ 的方向即可，框架不变。
