# P5447. 巷道穿梭

> 场次：2026年9月15日 · 来源：[CodeFun2000 P5447](https://codefun2000.com/p/P5447)

## 题目描述

质检员小柯在城南自动化立库核对巷道穿梭车的行程日志。巷道是一条长度为 $L$ 的直线导轨，穿梭车抵达 $0$ 端或 $L$ 端时，限位器会立刻使其掉头。

已知穿梭车的初始位置 $s$ 与初始朝向 $d$，随后依次执行 $n$ 条调度指令。每条指令要求沿当前朝向行驶距离 $a_i$，途中允许反复撞限位并掉头。请根据日志计算限位触发总次数、最终位置与最终朝向。

若初始时 $s = 0$ 且 $d = L$，则视为执行第一条指令前已完成掉头，初始朝向按 $R$ 处理；若初始时 $s = L$ 且 $d = R$，则初始朝向按 $L$ 处理。该初始修正不计入触发次数，仅在执行指令的行驶过程中抵达端点时计一次。

## 输入格式

第一行输入四个整数 $n$（$1 \le n \le 2 \times 10^5$）、$L$（$1 \le L \le 10^9$）、$s$（$0 \le s \le L$），以及朝向字符 $d \in \{L,R\}$。

第二行输入 $n$ 个非负整数 $a_i$（$0 \le a_i \le 10^{12}$）。

## 输出格式

输出限位触发总次数、最终位置与最终朝向。

## 示例

### 示例 1

**输入：**

```
4 8 2 L
3 6 10 4
```

**输出：**

```
3 5 R
```

**说明：**

初始位置为 $2$，朝向为 $L$，巷道长 $8$。

- 行驶 $3$：向左先走 $2$ 抵达 $0$ 端并掉头（计 $1$ 次），再向右走 $1$，停在 $1$，朝向 $R$。
- 行驶 $6$：向右走 $6$，未碰端点，停在 $7$，朝向 $R$。
- 行驶 $10$：向右先走 $1$ 抵达 $8$ 端并掉头（第 $2$ 次），再向左走 $8$ 抵达 $0$ 端并掉头（第 $3$ 次），再向右走 $1$，停在 $1$，朝向 $R$。
- 行驶 $4$：向右走 $4$，停在 $5$，朝向 $R$。

因此输出 `3 5 R`。

## 解题思路

### 结论被拆成三个数，一处一样的小机关

输出三件事：限位触发总次数、最终位置、最终朝向。判定标准里埋着两处容易看漏的设定：触发次数只统计**指令行驶过程中抵达端点**的时刻——出发时车若正停在端点且朝外（$s=0$ 且 $d=L$，或 $s=L$ 且 $d=R$），把它看成出发前已经完成的一次掉头，不计入答案；行驶距离恰好落在端点上的那次是算的（抵达即弹开，落在哪一端，朝向就是哪一端回内侧的方向）。

### 为什么必须折叠

一条指令的行程最多 $10^{12}$，指令条数 $2\times10^5$——按单位距离逐步模拟要 $2\times10^{17}$ 步，行不通。数触发次数、算落点必须对每条指令 $O(1)$ 完成。

折叠的办法是把往返运动「摊直」：造一个参数 $y$ 在**周期 $2L$ 的圆**上沿行驶方向匀速前进，真实位置取 $y$ 的三角波 $\text{tri}(y)=L-|L-(y\bmod 2L)|$（值沿 $0\to L\to 0\to \cdots$ 绕行）。这样常速前进 $a$ 距离就是 $y\mapsto y+a$，而**每跨过一个 $L$ 的倍数恰好对应撞一次限位**——次次数得清清楚楚。

构造映射只需两行：朝右停在 $p$ 处记 $y=p$；朝左停在 $p$ 处记 $y=2L-p$。两个端点的静止状态让它自然闭合：$0$ 朝右与 $0$ 朝左（弹开后）都映射到 $y\equiv0\pmod{2L}$，$L$ 朝左对应 $y\equiv L$。执行指令前先修正出发朝向（不计次数），把「停在端点朝外」翻成朝内，之后每条指令都从「朝内或位于内部」的状态出发。

### 一条指令的三个读数

设指令前参数为 $y_0$，行程 $a$：

- **触发次数**：区间 $(y_0,\ y_0+a]$ 内 $L$ 的倍数个数，即 $\lfloor (y_0+a)/L\rfloor - \lfloor y_0/L\rfloor$。用左开右闭是为了不把出发时的静止端点再计一次——那次掉头在「当初抵达时」已经记过账；
- **落点**：$y=(y_0+a)\bmod 2L$，物理位置由三角波还原：$y\le L$ 取 $y$，其余取 $2L-y$；
- **朝向**：$y\in[0,L)$ 记 `R`，$y\in[L,2L)$ 记 `L`——恰好停在 $L$ 端是弹开后的 `L`、停在 $0$ 端是弹开后的 `R`。

三个读数全部由整数除法与取余给出，Python 的大整数天然处理 $10^{17}$ 级的中间量，C++ 思路相同但要开 64 位。

### 实现映射

`simulate` 前 8 行做初始修正与映射（两个 `if` 翻转朝外状态，随后按朝向选 $y=p$ 或 $y=2L-p$）；主循环里 `hits += y // L - (y - a) // L` 这一行对应触发计数，`y %= 2 * L` 对应折叠；结尾按 $y$ 的区间还原落点与朝向。没有模拟循环，没有优先队列——被折进整数运算的往返运动不需要它们。

## 完整代码实现

```python
"""
P5447. 巷道穿梭 - 往复运动折叠（O(1) 数学模拟）

长度 L 的直线导轨 [0, L]，车碰 0 端或 L 端立即掉头。初始位置 s、
初始朝向 d（L/R），随后 n 条指令依次行驶 a_i 距离（途中可以反复撞限位
后掉头）。求限位触发总次数、最终位置与最终朝向。若出发时车正停在端点
且朝外（s=0 且 d=L，或 s=L 且 d=R），视为出发前已完成一次不计入的掉头。

输入格式：
- 第一行四个整数 n、L、s 与朝向字符 d；
- 第二行 n 个非负整数 a_i（0 <= a_i <= 1e12）。

输出格式：
- 一行三个值：触发总次数、最终位置、最终朝向字符。

核心思路：逐步按单位距离模拟会达到 O(sum a) = 2e17，必须对每条指令
O(1) 折叠。把运动展开成「周期 2L 的圆」：圆上参数 y 沿行驶方向匀速
前进，真实位置是 y 的三角波 tri(y)（0..L..0），y 增加 L 恰对应撞一次
限位并掉头。构造映射：朝右停 p 处记 y=p，朝左停 p 处记 y=2L-p
（mod 2L）。行驶 a 就是 y -> (y + a) mod 2L：
- 触发次数 = (y+a)//L - y//L，即区间 (y, y+a] 内跨过多少个 L 的倍数；
  起点若是端点（静止朝内）不自计——那次掉头在「抵达时」已计过。
- 终点位置 = tri((y+a) mod 2L)；朝向由 (y+a) mod 2L 落在 [0,L) 还是
  [L,2L) 决定（恰停在 L 端记 L，恰停在 0 端记 R，均是刚弹开的状态）。

复杂度：每条指令 O(1)，总计 O(n)；输入输出 O(n)。
"""

# https://codefun2000.com/p/P5447
# @sample-start
"""
样例输入 1:
4 8 2 L
3 6 10 4

样例输出 1:
3 5 R
"""
# @sample-end

import sys


def simulate(n, L, s, d, distances):
    if s == 0 and d == "L":
        d = "R"      # 出发前已完成的掉头，不计次数
    elif s == L and d == "R":
        d = "L"
    # (位置, 朝向) -> 展开圆上的参数 y，且规定 y 沿行驶方向单调前进
    if d == "R":
        y = s
    else:
        y = 2 * L - s if s != 0 else 0
    hits = 0
    for a in distances:
        y = y + a
        hits += y // L - (y - a) // L
        y %= 2 * L
    # 终态：y mod L 是「刚弹开」的相位
    r = y % L
    if r == 0:
        pos = 0 if y % (2 * L) == 0 else L
        return hits, pos, "R" if y % (2 * L) == 0 else "L"
    if y <= L:
        return hits, y, "R"
    return hits, 2 * L - y, "L"


def solve():
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    n = int(data[0])
    L = int(data[1])
    s = int(data[2])
    d = data[3].decode() if isinstance(data[3], bytes) else data[3]
    distances = [int(x) for x in data[4 : 4 + n]]
    hits, pos, nd = simulate(n, L, s, d, distances)
    print(f"{hits} {pos} {nd}")


def run_tests():
    import io
    import random

    def run_case(inp):
        old_stdin, old_stdout = sys.stdin, sys.stdout
        sys.stdin = io.TextIOWrapper(io.BytesIO(inp.encode("utf-8")))
        sys.stdout = io.StringIO()
        try:
            solve()
            output = sys.stdout.getvalue().strip()
        finally:
            sys.stdin, sys.stdout = old_stdin, old_stdout
        return output

    def brute(n, L, s, d, distances):
        """按单位距离逐步模拟：小规模下作为精确参照。"""
        if s == 0 and d == "L":
            d = "R"
        elif s == L and d == "R":
            d = "L"
        pos, hits = s, 0
        for a in distances:
            step = 1 if d == "R" else -1
            for _ in range(a):
                nxt = pos + step
                if nxt == L and step == 1 or nxt == 0 and step == -1:
                    hits += 1  # 抵达端点即触发并掉头
                    step = -step
                pos = nxt
            d = "R" if step == 1 else "L"
        return f"{hits} {pos} {d}"

    test_cases = [
        # 官方样例 1
        ("4 8 2 L\n3 6 10 4\n", "3 5 R"),
        # 官方说明逐条拆开的等价新样本：单独跑第一条指令
        ("1 8 2 L\n3\n", "1 1 R"),
    ]
    for i, (inp, expected) in enumerate(test_cases, 1):
        output = run_case(inp)
        status = "✓" if output == expected else "✗"
        print(f"样例 {i}: {'通过' if output == expected else '失败'} {status}")
        assert output == expected, f"样例 {i} 期望 {expected}，实际 {output}"

    # 官方只有 1 组样例：小规模全量对拍折叠公式与逐步模拟。
    rng = random.Random(20260915)
    small = []
    for _ in range(300):
        L = rng.randint(1, 7)
        n = rng.randint(1, 4)
        s = rng.randint(0, L)
        d = rng.choice("LR")
        distances = [rng.choice([0, 1, L, L + 1, L + 2, 2 * L, 2 * L + 1]) for _ in range(n)]
        small.append((n, L, s, d, distances))
    lines = "\n".join(
        f"{n} {L} {s} {d}\n{' '.join(map(str, ds))}" for n, L, s, d, ds in small
    )
    inp_preview = lines  # 展示性变量：逐组独立调用 solve() 便于对拍定位
    for n, L, s, d, ds in small:
        got = run_case(f"{n} {L} {s} {d}\n{' '.join(map(str, ds))}\n")
        want = brute(n, L, s, d, ds)
        assert got == want, f"对拍失败 n={n} L={L} s={s} d={d} a={ds}: 期望 {want}，实际 {got}"
    print(f"对拍用例 {len(small)} 组（L<=7 极限分段，逐步模拟参照）：通过")

    # 关键角落用例（直接断言语义）：初始端点朝外的修正不计数。
    got = run_case("1 5 0 L\n0\n").strip()
    assert got == "0 0 R", f"初始修正失败: {got}"      # 修正朝向 R 后不走，停 0、朝 R
    got = run_case("1 5 5 R\n0\n").strip()
    assert got == "0 5 L", f"初始修正失败: {got}"
    got = run_case("1 5 0 L\n5\n").strip()
    assert got == "1 5 L", f"行程恰触 L 端失败: {got}"  # 走 5：0->5 触发 1 次，停在 5 朝 L
    got = run_case("1 5 5 L\n10\n").strip()
    assert got == "2 5 L", f"双倍程折返失败: {got}"     # 5->0->5 触发 2 次，停 5 朝 L
    got = run_case("2 5 0 R\n4 1\n").strip()
    assert got == "1 5 L", f"跨指令端点失败: {got}"     # 4->5，1->0：共 1 次，停 5 朝 L
    print("角落用例 5 组（端点静止修正、恰达端点、跨指令端点）：通过")

    # 极端规模：a_i=1e12、L=1、纯 Python 折叠不超时。
    import time
    t0 = time.perf_counter()
    big = [10**12 - i for i in range(200000)]
    got = run_case(f"200000 1 0 R\n{' '.join(map(str, big))}\n")
    elapsed = time.perf_counter() - t0
    # L=1 时每次行驶的触发次数恰为行驶距离本身
    assert got.split()[0] == str(sum(big)), f"大数触发次数不符: {got[:50]}"
    print(f"压力用例 n=200000、a_i~1e12、L=1：用时 {elapsed:.2f}s，输出 {got}")


if __name__ == "__main__":
    if len(sys.argv) > 1 and sys.argv[1] == "--test":
        run_tests()
    else:
        solve()
```

## 示例推演

沿用官方样例：$n=4$，$L=8$，初始 $s=2$、朝向 `L`（不在端点，无需修正）。映射：$y=2L-s=16-2=14$（朝左停在 $2$）。

| 指令 $a$ | $y_0$ | $(y_0+a)$ | `y//8` 之差（触发） | $y\bmod16$ | 物理状态 |
| -------- | ----- | --------- | -------------------- | ---------- | -------- |
| 3 | 14 | 17 | $2-1=1$ | 1 | $1$ 朝 `R` |
| 6 | 1 | 7 | $0$ | 7 | $7$ 朝 `R` |
| 10 | 7 | 17 | $2-0=2$ | 1 | $1$ 朝 `R` |
| 4 | 1 | 5 | $0$ | 5 | $5$ 朝 `R` |

四次的差值合计 $1+0+2+0=3$，落点 $5$、朝向 `R`，输出 `3 5 R`，与官方说明逐条对上：行驶 $3$ 时 $y$ 从 $14$ 跨过 $16$（一个 $L=8$ 的倍数触发一次）到达 $y=1$，恰好是「撞 $0$ 端折回来走 $1$」；行驶 $10$ 时 $17$ 连跨 $8$、$16$ 两个倍数，对应「撞 $L$ 端、再撞 $0$ 端」两次触发。

补一张端点静止的账（自测对照用例）：$L=5$，$s=0$、朝向 `L`——按题面修正为 `R`，此时 $y=0$；若不修正、按「从 $0$ 向左」展开则 $y$ 同样取 $2L-0=0$，但参数却记成了「行驶负方向」，第一条指令就会把出发前的掉头多计一次。修正后的指令 $a=5$：$y_0=0\to5$，$\lfloor 5/5\rfloor-\lfloor0/5\rfloor=1$ 次触发，落点 $y=5$、朝 `L`，输出 `1 5 L`。

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| ---- | ---------- | ---------- | ---- |
| 按单位距离逐步模拟 | $O(\sum a_i)$ 至 $10^{17}$ | $O(1)$ | 上限远超可行，直接报废 |
| 每次撞限位处理一段（撞一次消一段） | $O(\text{每条指令的触发数})$ | $O(1)$ | 触发数本身可达 $10^{12}$，同样不可行 |
| 三角波折叠 + 整除计数（最优） | $O(n)$ | $O(1)$ | 每条指令一次除法、一次取模 |

## 易错点总结

### 1. 触发计数是左开右闭，不是左闭

`hits += y // L - (y - a) // L` 统计的是 $(y_0,\ y_0+a]$ 内 $L$ 的倍数个数。若写成从 $y_0$ 闭起（比如把 $y_0$ 先对齐到倍数再数），相邻指令停在端点上时，第二次出发会把「出发时的静止端点」计成一次重复触发——右端恰在端点的区间被算两次。用断言 `1 5 0 L\n5 → 1 5 L` 与 `2 5 0 R\n4 1 → 1 5 L` 可以固定这一点：这两组中都有一条指令恰好停在端点上，多计一次就会读到 $2$ 与 $2$。

### 2. 初始端点朝外的修正翻方向，不是翻参数

$s=0$ 且 $d=L$ 的修正必须把**朝向**改成 `R`（随后按朝右映射取 $y=s$）。若只想到「停在 $0$ 端映射出 $y=0$」而保留朝向 `L`，状态会被解释成「即将向左行驶」，第一条指令立刻把出发前那次已注销的掉头补计进答案。断言 `1 5 0 L\n0 → 0 0 R` 直接钉住：零距离指令不该产生任何触发，且朝向按弹开后的 `R` 输出。

## 扩展思考

- 「折叠成周期圆上的匀速参数」是一维往复运动的标准镜面展开，旋转门、台球反弹、蚂蚁相遇掉头等题都是同构——互相等价的物理过程换参数表示后往往只剩一次取模。
- 若指令改为「行驶 $a_i$ 或直到被限位拦截」这类中途停止，折叠框架仍适用，只是触发计数变成部分区间上的天花板函数，仍可 $O(1)$。
