# P5447. 巷道穿梭

> 场次：2026年9月15日 · 来源：[CodeFun2000 P5447](https://codefun2000.com/p/P5447)

## 题目描述

质检员小柯在城南自动化立库核对巷道穿梭车的行程日志。巷道是一条长度为 $L$ 的直线导轨，穿梭车抵达 $0$ 端或 $L$ 端时，限位器会立刻使其掉头。

已知穿梭车的初始位置 $s$ 与初始朝向 $d$，随后依次执行 $n$ 条调度指令。每条指令要求沿当前朝向行驶距离 $a_i$，途中允许反复撞限位并掉头。请根据日志计算限位触发总次数、最终位置与最终朝向。

若初始时 $s = 0$ 且 $d = L$，则视为执行第一条指令前已完成掉头，初始朝向按 $R$ 处理；若初始时 $s = L$ 且 $d = R$，则初始朝向按 $L$ 处理。该初始修正不计入触发次数，仅在执行指令的行驶过程中抵达端点时计一次。

## 输入格式

第一行输入四个整数 $n$（$1 \le n \le 2 \times 10^5$）、$L$（$1 \le L \le 10^9$）、$s$（$0 \le s \le L$），以及朝向字符 $d \in \{L,R\}$。

第二行输入 $n$ 个非负整数 $a_i$（$0 \le a_i \le 10^{12}$）。

## 输出格式

输出限位触发总次数、最终位置与最终朝向。

## 示例

### 示例 1

**输入：**

```
4 8 2 L
3 6 10 4
```

**输出：**

```
3 5 R
```

**说明：**

初始位置为 $2$，朝向为 $L$，巷道长 $8$。

- 行驶 $3$：向左先走 $2$ 抵达 $0$ 端并掉头（计 $1$ 次），再向右走 $1$，停在 $1$，朝向 $R$。
- 行驶 $6$：向右走 $6$，未碰端点，停在 $7$，朝向 $R$。
- 行驶 $10$：向右先走 $1$ 抵达 $8$ 端并掉头（第 $2$ 次），再向左走 $8$ 抵达 $0$ 端并掉头（第 $3$ 次），再向右走 $1$，停在 $1$，朝向 $R$。
- 行驶 $4$：向右走 $4$，停在 $5$，朝向 $R$。

因此输出 `3 5 R`。
