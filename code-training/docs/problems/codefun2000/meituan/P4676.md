# P4676. 守望塔对

> 场次：2026年3月28日-开发岗 · 来源：[CodeFun2000 P4676](https://codefun2000.com/p/P4676)

## 题目描述

你是一名通信工程师，正在部署一排线性的守望塔。共有 $n$ 座守望塔，从西到东依次编号为 $1$ 到 $n$。第 $i$ 座塔的高度记为 $h_i$。

对于两座塔 $i$ 和 $j$（$1 \le i < j \le n$），如果它们的高度之和大于它们之间所有塔（包括 $i$ 和 $j$）的最高高度，即满足

$$h_i + h_j > \max_{i \le k \le j} h_k$$

则称这一对塔可以互相通信。请统计所有可以互相通信的塔对 $(i, j)$ 的数量。

数据范围：塔的数量 $n$ 满足 $1 \le n \le 10^5$，每座塔的高度 $h_i$ 满足 $1 \le h_i \le 10^6$。

## 输入格式

第一行输入一个整数 $n$，表示塔的数量。
第二行输入 $n$ 个整数 $h_1, h_2, \dots, h_n$，依次表示每座塔的高度。

## 输出格式

输出一个整数，表示可以互相通信的塔对的数量。

## 示例

### 示例 1

**输入：**

```
1
5
```

**输出：**

```
0
```

**说明：**

当只有一座塔时，不存在编号 $i < j$ 的两座塔，因此无法形成任何塔对，答案为 `0`。

### 示例 2

**输入：**

```
2
1 2
```

**输出：**

```
1
```

**说明：**

唯一的一对是 $(1,2)$。$h_1 + h_2 = 1 + 2 = 3$，区间最大值为 $\max(1,2) = 2$。由于 $3 > 2$，该对满足条件，总数为 `1`。

### 示例 3

**输入：**

```
3
1 5 2
```

**输出：**

```
2
```

**说明：**

三座塔的可能对：
- 对 $(1,2)$：$1+5=6 > \max(1,5)=5$，满足。
- 对 $(2,3)$：$5+2=7 > \max(5,2)=5$，满足。
- 对 $(1,3)$：$1+2=3 \le \max(1,5,2)=5$，不满足。
所以共有 `2` 对满足条件。

### 示例 4

**输入：**

```
4
5 1 3 2
```

**输出：**

```
5
```

**说明：**

所有对的分析：
- $(1,2)$: $5+1=6 > \max(5,1)=5$，满足。
- $(1,3)$: $5+3=8 > \max(5,1,3)=5$，满足。
- $(1,4)$: $5+2=7 > \max(5,1,3,2)=5$，满足。
- $(2,3)$: $1+3=4 > \max(1,3)=3$，满足。
- $(2,4)$: $1+2=3 \le \max(1,3,2)=3$，不满足。
- $(3,4)$: $3+2=5 > \max(3,2)=3$，满足。
满足的对为除了 $(2,4)$ 以外的 `5` 对。

## 解题思路

### 无效对价的真身

判定标准 $h_i + h_j > \max_{i \le k \le j} h_k$：由于每座塔至少高 $1$，$h_i + h_j$ 恒大于 $h_i$ 也恒大于 $h_j$，所以**两端点无论是谁当区间最大值，这一对都自动通信**。通信失败只剩下一种情形——开区间 $(i, j)$ 里立着一座比两端之和还高的塔。直接逐对枚举是 $O(n^2)$，$n \le 10^5$ 放不下，于是把目光移到"哪座塔杀死了哪些对"上。

### 每个无效对只欠一座塔：最左最大值

对每个无效对 $(i, j)$，取其区间最大值**最左出现**的位置 $m$，归因给它。设

$$L_m = \text{$m$ 左侧最近的高度} \ge h_m \text{ 的塔位（无则 } -1\text{）}, \quad R_m = \text{$m$ 右侧最近的高度} > h_m \text{ 的塔位（无则 } n\text{）}.$$

左侧取弱邻界、右侧取严格邻界，两条性质同时成立：

1. **不漏**：$m$ 是 $(i,j)$ 的最左最大值时，$[i, m)$ 内全部严格小于 $h_m$（$L_m$ 在 $i$ 左边），$(m, j]$ 内全部不超过 $h_m$（$R_m$ 在 $j$ 右边），且 $h_i + h_j \le h_m$；
2. **不重**：若同一对同时满足两个塔 $m_1 < m_2$ 的归因条件，$m_1$ 会落在 $[i, m_2)$ 里从而 $h_{m_1} < h_{m_2}$，而 $m_2$ 落在 $m_1$ 的归因区间里从而 $h_{m_2} \le h_{m_1}$，矛盾。等高的塔靠这一弱一严互为边界，不会互相争抢。

于是**无效对总数**恰好等于每个塔的"左右两片峡谷"里的跨塔配对数之和：

$$\#\text{invalid} = \sum_{m} \#\bigl\{ i \in (L_m, m),\; j \in (m, R_m) : h_i + h_j \le h_m \bigr\},$$

通信对数 = 全部 $\binom{n}{2}$ 对减去它。峡谷里的塔都严格矮于 $h_m$，这个计数就退化成一次纯数值条件，是整道题从结构问题变成数据结构问题的那一步。

### 枚举小峡谷、离线回大峡谷

每个塔若把两个峡谷都排序再双指针，最坏（山峰层层嵌套的输入）会退化成平方；改为**只枚举较小峡谷的每个值 $v$**，其对 $h_m - v$ 的跨配对数是一次"位置后缀 + 高度阈值"的窗口计数：

$$\#\{p : X < p,\; h_p \le h_m - v\}$$

窗口 $(m, R_m)$ 或 $(L_m, m)$ 是两个后缀之差，两者都用同一款查询表达。全部查询离线：按位置阈值 $X$ 降序排序，激活指针从最右塔往左走，塔位一过阈值就把它的离散高度挂进树状数组，再对高度阈值做前缀计数。归因唯一保证每个无效对恰被计数一次，激活是从单侧递进的，指针整体只走 $O(n)$。

## 完整代码实现

```python
"""
P4676. 守望塔对 - 单调栈找支配区间 + 离线值域树状数组

题面要点：塔高 h_1..h_n（每座 ≥ 1）。塔对 (i, j)（i < j）可以互相通信
当且仅当 h_i + h_j > max(h_i..h_j)。n ≤ 1e5，统计这样的塔对数量。

输入：第一行 n，第二行 n 个高度。
输出：一个整数。

核心思路：
1. 每座塔高 ≥ 1，h_i + h_j 恒大于 h_i 与 h_j，所以「不能通信」当且仅当
   开区间 (i, j) 内存在高度 ≥ h_i + h_j 的塔——这样的塔必然比两端都高。
2. 给每个无效对 (i, j) 唯一归因：m = 该区间最大值的最左出现位置。
   记 L_m = m 左侧最近的高度 ≥ h_m 的塔位（没有记为 −1），
      R_m = m 右侧最近的高度 >  h_m 的塔位（没有记为 n），
   则「m 是 (i, j) 的最左最大值」恰好等价于 i ∈ (L_m, m) 且 j ∈ (m, R_m)；
   这时该对无效 ⟺ h_i + h_j ≤ h_m。左侧用 ≥、右侧用 > 的邻界取法让等高的
   塔互为边界，保证归因既不重复也不遗漏（等高塔出现在 (m, R_m) 内不会
   抢走 m 的最左最大地位，也不会双计）。
   于是：无效对总数 = Σ_m #{i ∈ (L_m, m), j ∈ (m, R_m) : h_i + h_j ≤ h_m}。
3. 每个塔只对「较小 gap」逐值枚举：枚举 v 的一次贡献是
   「位置 > X 且高度 ≤ h_m − v 的塔数」的窗口差（一个后缀减另一个后缀）。
4. 所有查询离线批量回答：按位置阈值降序排序指针从右往左把塔逐座激活，
   用高度离散值作坐标的树状数组做前缀计数。归因唯一的性质保证每个无效对
   恰好被统计一次，总方案 = 全部塔对数 − 无效对数。

时间复杂度：O((n + Q) log maxH)，Q = Σ 每个塔上较小 gap 的大小
空间复杂度：O(n + Q)
"""

def _prefix(tree, r):
    """树状数组前缀和：坐标 ≤ r 的元素个数。"""
    s = 0
    while r > 0:
        s += tree[r]
        r -= r & -r
    return s


def answer_suffix_value_queries(n, h, queries):
    """求 Σ sign · #{p: 位置阈值 X < p, h_p ≤ T}。

    queries 是 (X, T, sign) 的列表，X ∈ [−1, n−1)。
    离线：按 X 降序处理；激活指针从最右塔往左走，位置过线即入树状数组，
    高度阈值 T 经离散坐标做前缀计数。
    """
    if not queries:
        return 0
    coords = sorted(set(h) | {t for _, t, _ in queries})
    size = len(coords)
    tree = [0] * (size + 1)
    rank_h = [bisect_right(coords, x) for x in h]

    order = sorted(queries, key=lambda q: -q[0])
    ptr = n - 1        # 下一个激活的塔位（0 起，从右往左）；已激活区间 = (ptr, n-1]
    total = 0
    for x, t, sign in order:
        while ptr > x:
            r = rank_h[ptr]
            while r <= size:
                tree[r] += 1
                r += r & -r
            ptr -= 1
        r = bisect_right(coords, t)
        s = 0
        while r > 0:
            s += tree[r]
            r -= r & -r
        total += sign * s
    return total


def count_pairs(h):
    """返回可以互相通信的塔对数量。h 为 0 起下标的塔高序列。"""
    n = len(h)
    if n < 2:
        return 0

    # L[m]：m 左侧最近的高度 >= h_m 的塔位（弱邻界），没有记为 −1
    # R[m]：m 右侧最近的高度 >  h_m 的塔位（严格邻界），没有记为 n
    L = [-1] * n
    R = [n] * n
    stack = []
    for i in range(n):
        while stack and h[stack[-1]] < h[i]:
            stack.pop()
        L[i] = stack[-1] if stack else -1
        stack.append(i)
    stack = []
    for i in range(n - 1, -1, -1):
        while stack and h[stack[-1]] <= h[i]:
            stack.pop()
        R[i] = stack[-1] if stack else n
        stack.append(i)

    queries = []
    add_q = queries.append
    for m in range(n):
        left_len = m - L[m] - 1
        right_len = R[m] - m - 1
        if left_len == 0 or right_len == 0:
            continue          # gap 空的一侧没有任何 i（或 j）可归因
        cap = h[m]
        rm = R[m]
        lm = L[m]
        if left_len <= right_len:
            # 枚举左 gap 的每个值：跨 gap 塔 = 位置 (m, R_m) 上的塔
            for i in range(lm + 1, m):
                t = cap - h[i]
                add_q((m, t, 1))          # p > m 且 h_p ≤ cap − v
                add_q((rm - 1, t, -1))    # 再去掉 p ≥ R_m 的部分
        else:
            # 枚举右 gap 的每个值：跨 gap 塔 = 位置 (L_m, m) 上的塔
            for j in range(m + 1, rm):
                t = cap - h[j]
                add_q((lm, t, 1))         # p > L_m 且 h_p ≤ cap − w
                add_q((m - 1, t, -1))     # 再去掉 p ≥ m 的部分

    invalid = answer_suffix_value_queries(n, h, queries)
    return n * (n - 1) // 2 - invalid


def solve():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    h = [int(x) for x in data[1:1 + n]]
    print(count_pairs(h))


def _brute(h):
    """O(n^2) 暴力计数，供对拍使用。"""
    n = len(h)
    cnt = 0
    for i in range(n):
        cur_max = h[i]
        for j in range(i + 1, n):
            if h[j] > cur_max:
                cur_max = h[j]
            if h[i] + h[j] > cur_max:
                cnt += 1
    return cnt


def run_tests():
    """官方样例 + 形状边界 + 随机暴力对拍 + 规模冒烟。"""
    import io
    import random
    import time

    test_cases = [
        # 官方样例 1：只有一座塔，没有塔对
        ("1\n5\n", "0"),
        # 官方样例 2：相邻两塔恒可通信
        ("2\n1 2\n", "1"),
        # 官方样例 3：隔山对 (1,3) 被内部最高塔 5 压死
        ("3\n1 5 2\n", "2"),
        # 官方样例 4：六对中只有 (2,4) 不通信
        ("4\n5 1 3 2\n", "5"),
        # 两座等高塔：和 > 最大值，通信
        ("2\n7 7\n", "1"),
        # 全等高：区间最大值就是端点值，全部通信
        ("5\n3 3 3 3 3\n", "10"),
        # 严格递增 / 递减：端点是最大值，全部通信
        ("5\n1 2 3 4 5\n", "10"),
        ("5\n5 4 3 2 1\n", "10"),
        # 高塔居中：自身参与的 4 对都通信，两侧小塔两两隔山不通信
        ("5\n1 1 100 1 1\n", "6"),
        # 全对可通信：谷底两小塔靠右端点当最大值
        ("4\n3 1 1 2\n", "6"),
    ]

    for i, (inp, expected) in enumerate(test_cases, 1):
        old_stdin, old_stdout = sys.stdin, sys.stdout
        sys.stdin = io.TextIOWrapper(io.BytesIO(inp.encode("utf-8")))
        sys.stdout = io.StringIO()
        try:
            solve()
            output = sys.stdout.getvalue().strip()
        finally:
            sys.stdin, sys.stdout = old_stdin, old_stdout

        status = "✓" if output == expected else "✗"
        print(f"样例 {i}: 期望={expected}, 实际={output} {status}")

    # 随机暴力对拍：小 n 多轮，覆盖低值域碰撞、两极分化、有序、全值域
    rng = random.Random(20260328)
    ok = True
    for case in range(600):
        n = rng.randint(1, 24)
        style = case % 4
        if style == 0:
            h = [rng.randint(1, 8) for _ in range(n)]           # 低值域重碰撞
        elif style == 1:
            h = [rng.choice([1, 100]) for _ in range(n)]        # 两极分化
        elif style == 2:
            h = sorted(rng.randint(1, 50) for _ in range(n))    # 升/降有序
            if rng.random() < 0.5:
                h.reverse()
        else:
            h = [rng.randint(1, 1000000) for _ in range(n)]     # 全值域
        got = count_pairs(h)
        want = _brute(h)
        if got != want:
            ok = False
            print(f"对拍失败: h={h} got={got} want={want}")
            break
    print(f"随机暴力对拍 600 组: {'✓' if ok else '✗'}")

    # 规模冒烟：n = 1e5 的多种形态，只计时不校验值
    for name, h in (
        ("随机", [rng.randint(1, 10**6) for _ in range(100000)]),
        ("严格递增", list(range(1, 100001))),
        ("锯齿交替", [(10**6 if k % 2 else rng.randint(1, 10**6))
                      for k in range(100000)]),
        ("阶梯塔", [x if k % 2 == 0 else 1 for k, x in
                    enumerate(rng.sample(range(1, 10**6), 50000) * 1)]),
        ("大平台", [1000] * 100000),
        ("双层峰", [(10**6 if k % 1000 == 500 else
                     max(10**6 - k // 500, 1)) for k in range(100000)]),
    ):
        t0 = time.time()
        cnt = count_pairs(h)
        print(f"冒烟 n=1e5 {name}: pairs={cnt} 用时 {time.time() - t0:.2f}s")


if __name__ == "__main__":
    if len(sys.argv) > 1 and sys.argv[1] == "--test":
        run_tests()
    else:
        solve()
```

## 示例推演

样例 4：$h = [5, 1, 3, 2]$，先用两个单调栈求出邻界（0 起下标）：

| $m$ | $h_m$ | $L_m$ | $R_m$ | 左峡谷 | 右峡谷 |
| --- | --- | --- | --- | --- | --- |
| $0$ | $5$ | $-1$ | $4$ | $\varnothing$ | $\{1,2,3\}$ |
| $1$ | $1$ | $0$ | $2$ | $\varnothing$ | $\varnothing$ |
| $2$ | $3$ | $0$ | $4$ | $\{1\}$ | $\{3\}$ |
| $3$ | $2$ | $2$ | $4$ | $\varnothing$ | $\varnothing$ |

只有 $m=2$ 两个峡谷都非空：左枚举 $v = 1$，阈值 $3 - 1 = 2$；查询"位置 $> 2$ 且 $h_p \le 2$"得 $p = 3$（$h=2$ ✓）共 $1$，再减去"位置 $\ge R_m = 4$"的 $0$，归因 $1$ 对。总无效 $= 1$，通信对数 $= \binom{4}{2} - 1 = 5$，与官方样例一致——被杀死的正是 $(1, 3)$（0 起的 $(1, 3)$，$1 + 2 = 3 \le 3$）。

再走样例 3 验证"弱左邻界"：$h = [1, 5, 2]$。塔 $m=1$（高 $5$）左峡谷 $\{0\}$、右峡谷 $\{2\}$，枚举 $v = 1$：阈值 $4$；"位置 $> 2$ 且 $h_p \le 4$"有 $p = 2$ 共 $1$，无效 $1$，通信 $= 3 - 1 = 2$。隔山对 $(0, 2)$ 被 $h_2 = 1+2 = 3 \le 5$ 压死，正是归因条件该抓的对。

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| ---- | ---------- | ---------- | ---- |
| 逐对枚举 $O(n^2)$ | $O(n^2)$ | $O(1)$ | $n = 10^5$ 时 $10^{10}$ 步，不可行 |
| 单调栈归因 + 离线值域树状数组（最优） | $O((n + Q)\log n)$ | $O(n + Q)$ | $Q$ = 各塔较小峡谷大小之和；本题采用 |

两个单调栈各一趟 $O(n)$；查询按阈值排序 $O(Q \log Q)$、逐条树状数组 $O(\log n)$。等高、严格单调、大平台、锯齿等极限形态在本文件 `run_tests` 的规模冒烟里均在秒级内完成。

## 易错点总结

### 1. 两个邻界一个用错了强度

左邻界必须"弱"（高度 $\ge$ 才挡）、右邻界必须"严"（高度 $>$ 才挡），对应 `while stack and h[stack[-1]] < h[i]` 与 `while stack and h[stack[-1]] <= h[i]` 两条弹栈条件。两侧取同一强度时等高的塔会相互争抢归因：全取弱邻界，`[5, 5]` 里第二座塔的左峡谷被第一座封死（无所谓），但像 `[3, 1, 2]` 这样 $h_2 \ge h_0$ 的输入会把 $m_2$ 的归因区间截错，随机对拍中表现为部分含等高的用例多算或漏算无效对。

### 2. 离线激活多走或少走一座塔

激活语义是"已激活塔位 = 位置阈值以右的全部塔"。实现里 `ptr` 起点为 $n-1$，循环 `while ptr > x` 内先 `add(rank_h[ptr])` 再 `ptr -= 1`：若把"先减后加"写成"先加后减"或者把循环条件写成 `ptr > x + 1`，激活集合会整体偏移一位。现象是某座恰好压线的塔没进统计，样例 3 的隔山对 $(0, 2)$ 就少扣 $1$，答案输出 $3$ 而不是 $2$——这类错既不影响其余查询也不抛异常，只能靠官方样例钉住。

## 扩展思考

- "每个结构对（区间）唯一归因到它的最左最大值，再把对每对的条件压成对单塔的区间条件"是处理此类"区间极值约束计数"问题的通用拆法；同一套框架换掉 $h_i + h_j$ 的条件就能数别的量。
- 枚举小的一侧、大的一侧丢给离线值域结构，是"两侧都可能很大"时的标准混合：以归因唯一性担保不重不漏，以双侧邻界强度互补担保等高无歧义。
