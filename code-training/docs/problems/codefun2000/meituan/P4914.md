# P4914. 最长质量稳定段

> 场次：2026年5月9日-开发岗 · 来源：[CodeFun2000 P4914](https://codefun2000.com/p/P4914)

## 题目描述

某工厂的质量检测系统在生产线上连续记录 $n$ 件产品的重量。称重结果依次为 $w_1, w_2, \dots, w_n$，并给定一个允许的最大波动值 $D$。

定义一段连续生产的产品区间 $[l, r]$ 是一个“质量稳定段”，当且仅当对于其中的每一个 $i \in [l, r-1]$ 都满足 $|w_{i+1} - w_i| \le D$。即相邻两件产品的重量波动幅度不超过 $D$。

请你找出所有质量稳定段中最长的一段长度。

数据范围：产品个数 $n$ 不超过 $2 \times 10^5$，所有测试组 $n$ 的总和也不超过 $2 \times 10^5$。允许的最大波动值 $D$ 为 $0$ 到 $10^9$ 之间的整数。每个产品重量的绝对值不超过 $10^9$。

## 输入格式

第一行包含一个整数 $T$，表示测试数据组数。
接下来每组数据占两行：
第一行包含两个整数 $n$ 和 $D$，分别表示当前组的产品数量与允许的最大重量波动值。
第二行包含 $n$ 个整数 $w_1, w_2, \dots, w_n$，依次表示每个产品的重量。

## 输出格式

对于每组测试数据，输出一行一个整数，表示该组数据中最长质量稳定段的长度。

## 示例

### 示例 1

**输入：**

```
1
7 1
1 2 3 2 5 6 7
```

**输出：**

```
4
```

**说明：**

数组为 `1 2 3 2 5 6 7`，最大允许波动 $D = 1$。从左到右扫描：
- $|2-1| = 1 \le 1$，当前段长度变为 `2`；
- $|3-2| = 1 \le 1$，长度变为 `3`；
- $|2-3| = 1 \le 1$，长度变为 `4`；
- $|5-2| = 3 > 1$，当前段断开，重新从 `5` 开始，长度变为 `1`；
- $|6-5| = 1 \le 1$，长度变为 `2`；
- $|7-6| = 1 \le 1$，长度变为 `3`。
扫描过程中最大长度为 `4`，对应稳定段 $[1, 4]$。

### 示例 2

**输入：**

```
1
4 0
5 5 5 6
```

**输出：**

```
3
```

**说明：**

$D = 0$ 要求相邻产品重量必须完全相等。数组 `5 5 5 6` 中：
前两个 `5` 差值为 $|5-5| = 0 \le 0$，继续延伸；
第二个和第三个 `5` 差值也为 $0$，当前段长度变为 `3`；
第三个 `5` 到 `6` 的差值为 $|6-5| = 1 > 0$，因此从 `6` 重新开始一段。
最长稳定段由前三个连续的 `5` 组成，长度为 `3`。

### 示例 3

**输入：**

```
2
3 1000000000
-1000000000 0 1000000000
2 0
1 2
```

**输出：**

```
3
1
```

**说明：**

第一组数据：$n = 3$，$D = 10^9$。重量为 `-1000000000`、`0`、`1000000000`。相邻波动分别为 $|0 - (-1000000000)| = 10^9 \le D$ 和 $|1000000000 - 0| = 10^9 \le D$，整个序列为一个稳定段，长度为 `3`。
第二组数据：$n = 2$，$D = 0$。重量为 `1`、`2`，差值为 $|2-1| = 1 > 0$，无法组成长度超过 `1` 的稳定段，因此输出 `1`。

## 解题思路

### 判定标准落在每一对相邻元素上

题目要的不是段内极差、也不是什么累计量：区间 $[l, r]$ 合法当且仅当对每个 $i \in [l, r-1]$ 都有 $|w_{i+1} - w_i| \le D$。这条判定只用到相邻两件，与段里离得远的元素无关，也不关心差值的正负（`abs` 把方向吸收掉）。于是「最长稳定段」可以换一种说法：**把每对相邻元素看成一条边，边合法就叫「通」，稳定段就是这些边切出来的连通块。**

### 扫一遍边：通则延长，断则另起一段

既然合法性逐边独立，就不需要任何区间结构，扫边即可：

```python
best = cur = 1                    # cur：以当前件结尾的稳定段有几件
for i in range(1, n):
    if abs(w[i] - w[i - 1]) <= d_limit:
        cur += 1                  # 这条边通，段延长一件
    else:
        cur = 1                   # 这条边断，当前件另起一段
    best = max(best, cur)
```

`cur` 记的是**件数**而不是**边数**，这是本题唯一需要小心的口径：第 1 件前面没有边，它自己就是一个长度 1 的段，所以 `cur`、`best` 的初值都是 1；一条通边让件数加 1（4 件对应 3 条通边）。$n=1$ 时循环一次不进，答案仍是 1；$D=0$ 只是把「通」收紧成「相邻全等」，不需要单独分支。

### 为什么是 $O(n)$：数据范围把区间枚举挡在外面

$n \le 2\times10^5$，所有测试组的 $n$ 之和同样 $\le 2\times10^5$。若枚举全体区间再逐段校验，是 $O(n^2)$：$n = 2\times10^5$ 时约 $2\times10^{10}$ 次相邻差判定，超过一秒能做的量级。而扫边对每条边只判定一次，总量 $\sum (n-1) \le 2\times10^5$，这同时是本题的下界——每条边都得看一眼才知道通不通。

输入量也在同一量级，所以按整块读入、逐组推进游标，不必为每组单独调用一次 `input()`：

```python
data = sys.stdin.buffer.read().split()
t, pos = int(data[0]), 1
for _ in range(t):
    n, d_limit = int(data[pos]), int(data[pos + 1])
    pos += 2
    w = [int(x) for x in data[pos:pos + n]]
    pos += n
```

（差值最大 $|10^9 - (-10^9)| = 2\times10^9$，仍在 32 位有符号整数范围内；Python 的整数更是任意精度，`abs` 之后直接比即可。）

## 完整代码实现

```python
"""
P4914. 最长质量稳定段 - 线性扫描（模拟）

题意：给定 n 件产品的重量 w_1..w_n 与波动上限 D。一段连续区间 [l, r] 是
「质量稳定段」，当且仅当每对相邻产品都满足 |w_{i+1} - w_i| <= D。
求所有稳定段中最长的一段长度。

判定标准很直接：稳定段由「相邻差都不超 D」这一局部条件决定，
因此一个段的合法性由它的每一条相邻边独立决定——从左到右扫描，
遇到一条满足条件的相邻边就延长当前段，遇到不满足的就重新开段。
段与段之间只通过「断点」分割，没有跨段的全局约束，所以一遍线性扫描即可，
不需要任何二分或 DP。

输入格式：
- 第 1 行：测试组数 T；
- 每组两行：第一行 n 和 D，第二行 n 个整数 w_1..w_n。

输出格式：
- 每组一行，输出最长稳定段的长度。

时间复杂度：O(n)（所有组的 n 总和不超过 2*10^5）
空间复杂度：O(n)
"""

# https://codefun2000.com/p/P4914
import sys

# @sample-start
"""
样例 1:
1
7 1
1 2 3 2 5 6 7
->
4
"""
# @sample-end

# @sample-start
"""
样例 2:
1
4 0
5 5 5 6
->
3
"""
# @sample-end

# @sample-start
"""
样例 3:
2
3 1000000000
-1000000000 0 1000000000
2 0
1 2
->
3
1
"""
# @sample-end


def solve():
    """对每组数据线性扫描，输出最长稳定段长度。"""
    data = sys.stdin.buffer.read().split()
    pos = 1
    t = int(data[0])
    out = []
    for _ in range(t):
        n = int(data[pos])
        d_limit = int(data[pos + 1])
        pos += 2
        w = data[pos:pos + n]
        pos += n
        w = [int(x) for x in w]

        # cur 维护「以当前元素结尾的稳定段长度」：
        # 相邻差 <= D 时前一段延长 1；否则从当前元素重新开段（长度 1）。
        # 相邻差的合法性只取决于这一条边，所以逐边判定就足够。
        best = 1
        cur = 1
        for i in range(1, n):
            if abs(w[i] - w[i - 1]) <= d_limit:
                cur += 1
            else:
                cur = 1
            if cur > best:
                best = cur
        out.append(str(best))
    sys.stdout.write("\n".join(out) + "\n")


def run_tests():
    """运行嵌入的官方样例与自加的边界/变形用例。"""
    import io
    import random

    def run_once(inp):
        old = sys.stdin, sys.stdout
        sys.stdin = io.TextIOWrapper(io.BytesIO(inp.encode("utf-8")))
        sys.stdout = io.StringIO()
        try:
            solve()
            return sys.stdout.getvalue().rstrip("\n")
        finally:
            sys.stdin, sys.stdout = old

    def brute(w, d_limit):
        """参照实现：枚举全部区间逐条相邻边校验，O(n^2)。"""
        n = len(w)
        best = 0
        for l in range(n):
            for r in range(l, n):
                ok = all(abs(w[i + 1] - w[i]) <= d_limit for i in range(l, r))
                if ok:
                    best = max(best, r - l + 1)
        return best

    cases = [
        # 官方样例 1：段在 |5-2|=3 处断开，最长 [1,4] 长 4
        ("1\n7 1\n1 2 3 2 5 6 7\n", "4"),
        # 官方样例 2：D=0 要求相邻相等，最长等于相同值的连续个数
        ("1\n4 0\n5 5 5 6\n", "3"),
        # 官方样例 3：两组数据，第二组 n=2 且 D=0 时无任何稳定相邻边
        ("2\n3 1000000000\n-1000000000 0 1000000000\n2 0\n1 2\n", "3\n1"),
        # 边界：n=1，没有任何相邻边，答案只能是 1
        ("1\n1 0\n42\n", "1"),
        # 边界：单元素组混在多组里
        ("2\n1 5\n-3\n2 1\n7 8\n", "1\n2"),
        # 全部相等且 D=0：整条序列是一个稳定段
        ("1\n6 0\n9 9 9 9 9 9\n", "6"),
        # 交替序列且 D=1：每对相邻差都是 1，整条都是稳定段（差可为负方向）
        ("1\n5 1\n5 4 5 4 5\n", "5"),
        # D=0 且相邻差全为 1：每两个就断开，答案 1
        ("1\n5 0\n1 2 3 4 5\n", "1"),
        # 段的方向不影响：3 2 1 且 D=1 整条稳定
        ("1\n3 1\n3 2 1\n", "3"),
    ]

    for i, (inp, expected) in enumerate(cases, 1):
        got = run_once(inp)
        status = "✓" if got == expected else "✗"
        print(f"样例 {i}: 期望={expected!r}, 实际={got!r} {status}")

    # 随机对拍：小规模下与 O(n^2) 参照实现逐组比对
    rng = random.Random(20260509)
    ok = True
    for trial in range(200):
        n = rng.randint(1, 20)
        d_limit = rng.choice([0, 1, 2, 3, 10])
        w = [rng.randint(-5, 5) for _ in range(n)]
        inp = "1\n%d %d\n%s\n" % (n, d_limit, " ".join(map(str, w)))
        got = run_once(inp)
        want = str(brute(w, d_limit))
        if got != want:
            ok = False
            print(f"对拍失败: n={n}, D={d_limit}, w={w}, 期望={want}, 实际={got}")
    print("随机对拍:", "全部通过" if ok else "存在失败")


if __name__ == "__main__":
    if len(sys.argv) > 1 and sys.argv[1] == "--test":
        run_tests()
    else:
        solve()
```

## 示例推演

样例 1（`1 2 3 2 5 6 7`，$D=1$），逐边走一遍：

| 相邻边 | 判定 | `cur` | 动作 |
| ------ | ---- | ----- | ---- |
| $\|2-1\|=1$ | 通 | 2 | 延长 |
| $\|3-2\|=1$ | 通 | 3 | 延长 |
| $\|2-3\|=1$ | 通 | 4 | 延长 |
| $\|5-2\|=3$ | 断 | 1 | 从 5 重开 |
| $\|6-5\|=1$ | 通 | 2 | 延长 |
| $\|7-6\|=1$ | 通 | 3 | 延长 |

`best` 在第三步到 4 后再未刷新，输出 4。$[1,4]$ 那段「上坡后折返」是靠 $|2-3| \le D$ 通过的——差值方向不影响符号，判定式里的 `abs` 把它吸收掉。

样例 2（$D=0$）把「通」收紧成「相邻全等」：`5 5 5 6` 的前两条边通（`cur` 到 3），第三条断，输出 3。

样例 3 第一组（$D=10^9$）两条边差都恰好等于 $10^9$，整条序列是一个段，输出 3——`-1000000000` 到 `1000000000` 是首尾极值仍被放行；第二组（`1 2`、$D=0$）全无合法边，`cur` 每步回 1，`best` 保持 1，输出 1——这也是答案的下界情形。

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| ---- | ---------- | ---------- | ---- |
| 枚举全体区间并增量校验 | $O(n^2)$ | $O(1)$ | 每个左端点向右延伸时只看新增的一条边；$n = 2\times10^5$ 时约 $2\times10^{10}$ 次判定，不可行 |
| 一次扫描逐边判定（最优） | $O(n)$ | $O(n)$ | 每条相邻边看一次，`cur` 延长或归一，本题采用 |

所有组的 $n$ 总和 $\le 2\times10^5$，扫描总量就是 $10^5$ 级的边数；空间里最重的开销是一次性读入每组的重量数组。

---

## 易错点总结

### 1. 把段长记成「合法边数」会普遍少 1

`best = cur = 1` 这一行的口径必须是「以当前件结尾的段有几件」：初值 1、合法延长加 1、断开回 1。若把口径记在边上（初值 0，断开回 0），稳定段里的件数比合法边数恒多 1：样例 1 的 $[1,4]$ 段（4 件、3 条合法边）会输出 3；$n=1$ 的组没有边可看，按边计数会输出 0，按件才是 1。样例 2 的输出 3（3 件、2 条边）能直接分辨两种口径。

### 2. 判定要和「上一件」比，不能和段的起点比

`abs(w[i] - w[i - 1])` 的锚点是紧邻的前一件。若把 `w[i - 1]` 换成段首，条件就悄悄变成了「段内每件都离段首不超过 $D$」。以 `0 2 1 3` 配 $D=2$ 为例：三条边 $|2-0|=2$、$|1-2|=1$、$|3-1|=2$ 全部合法，正确答案是 4；锚到段首的写法在最后一件算 $|3-0|=3>2$，把整段截成 3。样例 1 探不到这处差别，因为 $|5-2| = |5-1| = 3$，两种锚点恰在同一处断开。

## 扩展思考

判定若改成「段内最大重量减最小重量 $\le D$」，合法条件不再逐边独立，单遍扫描失效，需要滑动窗口配合单调双端队列维护窗口极值。本题的规则恰好只牵涉每条边，线性扫描就是复杂度下限。
