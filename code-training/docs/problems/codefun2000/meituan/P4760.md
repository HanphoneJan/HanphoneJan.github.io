# P4760. 跳转指令的开销

> 场次：2026年4月11日-开发岗 · 来源：[CodeFun2000 P4760](https://codefun2000.com/p/P4760)

## 题目描述

有一个特殊的程序，包含 `n` 条指令，编号为 `1` 到 `n`。程序在执行时会按照一个固定的跳转规则移动：执行完指令 `i` 后，一定会跳转到指令 $next_i$，其中 $1 \le next_i \le n$。

每次执行指令 `i` 时，如果这是该指令在程序运行过程中第 `t` 次被执行，那么这一次就会产生 $t \times i$ 的计算开销。注意这里的 `t` 是对每一条指令独立计数的，即只统计该指令自身被执行的次数。

现在有 `q` 次询问。每次询问给定一个起始指令 `p` 和一个整数 `k`，表示程序从指令 `p` 开始执行，并且一共执行 `k` 条指令（包含起始的那一次）。对于每个询问，你需要输出程序在这 `k` 条指令的执行过程中产生的总开销，结果对 $10^9+7$ 取模。

数据范围：指令数量 `n` 与询问数量 `q` 均不超过 `2×10^5`；跳转目标 $next_i$ 均为 `1` 到 `n` 之间的整数；对于每个询问，起始指令 `p` 满足 $1 \le p \le n$，执行次数 `k` 满足 $1 \le k \le 10^9$。

## 输入格式

第一行输入两个整数 `n` 和 `q`，分别表示指令条数和询问个数。
第二行输入 `n` 个整数 $next_1, next_2, \dots, next_n$，其中 $next_i$ 表示执行指令 `i` 后跳转到的指令编号。
此后 `q` 行，每行输入两个整数 `p` 和 `k`，表示从指令 `p` 开始执行、一共执行 `k` 次（含起始那次）的一组询问。

## 输出格式

对于每个询问，输出一行一个整数，表示这 `k` 次执行产生的总开销对 $10^9+7$ 取模后的结果。

## 示例

### 示例 1

**输入：**

```
1 2
1
1 1
1 5
```

**输出：**

```
1
15
```

**说明：**

只有一条指令 $1$，每次执行产生的开销为 $t \times 1$。
对于查询 `1 1`，$k=1$，总开销为第 $1$ 次执行 $1$ 的开销 $1$。
对于查询 `1 5`，$k=5$，连续执行第 $1$ 至第 $5$ 次，总开销为 $1+2+3+4+5=15$。

### 示例 2

**输入：**

```
2 3
2 1
1 1
1 4
2 3
```

**输出：**

```
1
9
7
```

**说明：**

指令 $1$ 和 $2$ 构成长度为 $2$ 的环，跳转规则为 $1 \to 2$，$2 \to 1$。
- 查询 `1 1`：仅执行指令 $1$ 一次，开销 $1 \times 1 = 1$。
- 查询 `1 4`：执行序列 $1,2,1,2$。指令 $1$ 执行了第 $1,2$ 次，产生开销 $1 \times 1 + 2 \times 1 = 3$；指令 $2$ 执行了第 $1,2$ 次，产生开销 $1 \times 2 + 2 \times 2 = 6$；总和为 $9$。
- 查询 `2 3`：执行序列 $2,1,2$。指令 $2$ 执行了第 $1,2$ 次，开销 $1 \times 2 + 2 \times 2 = 6$；指令 $1$ 执行了第 $1$ 次，开销 $1 \times 1 = 1$；总和为 $7$。

### 示例 3

**输入：**

```
5 4
2 3 4 2 4
1 2
1 8
5 4
5 10
```

**输出：**

```
3
34
14
59
```

**说明：**

图结构：环为 $2 \to 3 \to 4 \to 2$，长度 $L=3$。指令 $1$ 指向 $2$（距环 $1$ 步），指令 $5$ 指向 $4$（距环 $1$ 步）。
- 查询 `1 2`：执行 $1,2$，开销 $1 + 1 \times 2 = 3$。
- 查询 `1 8`：先执行树边部分 $1$（开销 $1$），再在环上执行 $7$ 次（完整两轮余 $1$ 次）。序列 $1,2,3,4,2,3,4,2$，各指令计数与开销：$1$ 一次 $1$；$2$ 三次 $2+4+6=12$；$3$ 两次 $3+6=9$；$4$ 两次 $4+8=12$；合计 $34$。
- 查询 `5 4`：执行 $5,4,2,3$，各执行一次，开销 $5+4+2+3=14$。
- 查询 `5 10`：先执行一次 $5$（开销 $5$），环上执行 $9$ 次（完整三轮）。$4,2,3$ 各执行三次，开销分别为 $4+8+12=24$，$2+4+6=12$，$3+6+9=18$，总和 $5+24+12+18=59$。

## 解题思路

### 执行序列长什么样：函数图是唯一的拆解入口

每条指令执行完必须跳到 $next_i$，且 $1 \le next_i \le n$——每个点出度恰好为 1，这样的图只能由「若干棵树挂向环」和「若干个独立的环」拼成。于是不管从哪个点 $p$ 出发，执行序列必然是：先沿一条不重复的 tail 链走 $d$ 步（记 $d$ 为 $p$ 到第一个环点的步数），然后进入一个环，把环上的点一圈一圈循环。题面把开销定为「第 $t$ 次执行产生 $t \times i$」之后，tail 与环的处境立刻不同：tail 上的点每次被经过时都是第一次，贡献 $1 \times i$；环上的点每绕一圈，各自的 $t$ 加一。

数据范围把解法圈死了：$k \le 10^9$ 且 $q \le 2 \times 10^5$，逐条模拟一次询问就可能走 $10^9$ 步，任何逐步方案都不可行；一次询问必须给出与 $k$ 大小无关的闭式计算。

### 环上一段执行的开销可以按圈拆开

进环后，从入口点在环中的位置 $start$ 起共执行 $c = k - d$ 条。把环记为序列 $w_0, w_1, \dots, w_{L-1}$，第 $r$ 条执行落在环点 $(start + r) \bmod L$ 上，此刻它自身的历史执行次数是 $\lfloor r/L \rfloor + 1$——次数只随 $r$ 除以 $L$ 的商增长。把商与余拆开：$c = \text{full} \times L + rem$，则

$$
\text{环开销} = \underbrace{\frac{\text{full}(\text{full}+1)}{2}}_{\text{每点权重和}} \times \underbrace{\sum w_i}_{\text{环点编号和}} + (\text{full}+1) \times \underbrace{\sum_{i=0}^{rem-1} w_{(start+i) \bmod L}}_{\text{从 } start \text{ 起前 } rem \text{ 个点}}
$$

第一项的来历：每个环点都蹲满了 $\text{full}$ 圈，它的执行次数依次取 $1,2,\dots,\text{full}$，权重和是三角形数；第二项：最后 $rem$ 条执行挂在从 $start$ 数起的点上，落在第 $\text{full}+1$ 圈，权重再各拿一次 $\text{full}+1$。整条式子与 $k$ 具体多大无关。

「从任意 $start$ 起取 $rem$ 个点的编号和」每次询问都不同，每次重算是 $O(L)$。把环序列重复两遍做一次前缀和 $\text{pre2}$，任意窗口变成一次作差 $\text{pre2}[start+rem] - \text{pre2}[start]$：每个环建一次 $O(L)$，此后每次询问 $O(1)$。

### tail 部分只有两类情况

- $k > d$：进环前 $d$ 个点各执行一次，开销就是它们的编号和。对每个点预处理后缀和 $F[p] = p + F[next_p]$（到达环处归零），一次查表。
- $k \le d$：执行序列还没碰到环，$k$ 个点各执行一次，开销 $= F[p] - F[\text{从 } p \text{ 跳 } k \text{ 步的所在点}]$。「跳 $k$ 步」不能线性走——最坏一步就是 $O(n)$，$q$ 个询问撑不住；倍增表把 $k$ 拆成二进制位，$O(\log n)$ 完成。深度的取值范围 $d \le n$ 决定了倍增层数 $O(\log n)$ 就够。

整理成代码的落点：对图做一次迭代染色（每个点归入「环内」或「tail」，回填 $depth$、$F$、$entry$ 与环内位置），同时给每个环填 $pre2$；倍增表 $O(n \log n)$ 建好。之后每次询问要么查一次 $F$ 差，要么合并三个闭式项，全程在 $10^9+7$ 下取模。

## 完整代码实现

```python
"""
P4760. 跳转指令的开销 - 函数图染色 + 环前缀和

题意：n 条指令，从 i 执行完必跳到 next_i（每个点出度为 1 的函数图）。
第 i 条指令每次被第 t 次执行时产生 t*i 的开销（t 对每条指令独立计数）。
q 次询问：从 p 开始执行 k 条指令（含起始那次），求总开销模 1e9+7。

结构观察：每个点出度为 1，图是「若干棵树挂向环 + 若干个环」的函数图。
从 p 出发的执行序列必先走完 tail 链（tail 链上的点各只被执行一次），
然后进入环内循环。设 d = depth(p)（p 走到第一个环点需要 d 步）：
- k <= d：全程没进环，k 个点各执行一次，开销 = 这 k 个点编号之和；
- k > d：tail 部分（d 个点，各一次）开销为编号和；环上执行 c = k - d 条，
  从入口点在环中的位置 start 起，第 r 条代价是 (r // L + 1)，
  其中 L 是环长——每绕一圈同一批点各自的历史执行次数加一。
  把 c 拆成 full 圈 + 剩 rem 条：每个环点先被执行 full 次（权重 1..full），
  从 start 起的前 rem 个点再多一次执行（权重 full+1）。于是

    环开销 = full*(full+1)/2 * (环上点的编号和)
           + (full+1) * (从 start 出发 rem 个环点编号的前缀和)。

实现映射：
- 用一次迭代染色的 DFS（非递归）标记每个点：所在环编号、环内位置、
  tail 深度 d、tail 编号后缀和 F（进环之前所有点各一次的编号和）、
  以及进环的入口点 entry；
- 每个环存「环点编号和」与「环序列重复两遍的前缀和 pre2」，
  从任意 start 取 rem 个的前缀和用 pre2[start+rem]-pre2[start] 在 O(1) 得到；
- k <= d 的分支要走到路径上第 k 个点：q 次询问各自跳 k 步不能线性走，
  用倍增表 O(log n) 完成。k 本身可达 1e9，但 c = k - d 的环内循环部分
  由上面的闭式给出，不需要逐条模拟。

输入格式：
- 第 1 行：n 和 q；
- 第 2 行：next_1 .. next_n；
- 接下来 q 行：每行 p 和 k。

输出格式：
- 每个询问一行，总开销对 1e9+7 取模。

时间复杂度：O(n log n + q log n)（染色与前后缀预处理 O(n)，倍增表 O(n log n)，
环内询问 O(1)，进 tail 分支的询问 O(log n)）
空间复杂度：O(n log n)
"""

import sys

MOD = 10**9 + 7

def solve():
    """函数图染色 + 环前缀和，逐询问输出取模开销。"""
    data = sys.stdin.buffer.read().split()
    it = iter(data)
    n = int(next(it))
    q = int(next(it))
    nxt = [0] * (n + 1)
    for v in range(1, n + 1):
        nxt[v] = int(next(it))

    queries = []
    for _ in range(q):
        p = int(next(it))
        k = int(next(it))
        queries.append((p, k))

    LOG = max(1, max(n, 1).bit_length())

    # 倍增表：只服务 k <= depth(p) 的「走 k 步还在 tail 上」的分支。
    up = [nxt[:]]
    for lv in range(1, LOG):
        prev = up[-1]
        up.append([prev[prev[v]] for v in range(n + 1)])

    # 迭代染色：0 未访问，1 在当前路径上，2 已归属。
    color = [0] * (n + 1)
    on_path = [0] * (n + 1)
    depth = [0] * (n + 1)   # tail 上还需走多少步进环（环点为 0）
    f_tail = [0] * (n + 1)  # tail 点编号后缀和：自己 + 链上后续 tail 点
    entry = [0] * (n + 1)   # 沿链走到的第一个环点
    cyc_id = [0] * (n + 1)
    cyc_pos = [0] * (n + 1)
    cyc_data = []           # 每个环: (L, 编号和, 重复两遍的前缀和)

    for s in range(1, n + 1):
        if color[s]:
            continue
        path = []
        u = s
        while color[u] == 0:
            color[u] = 1
            on_path[u] = len(path) + 1
            path.append(u)
            u = nxt[u]

        if color[u] == 1:
            # u 在当前路径上 -> 找到新环
            ci = on_path[u] - 1
            cyc = path[ci:]
            cid = len(cyc_data)
            L = len(cyc)
            total = 0
            pre2 = [0] * (2 * L + 1)
            acc = 0
            for i in range(2 * L):
                acc = (acc + cyc[i % L]) % MOD
                pre2[i + 1] = acc
            total = pre2[L]
            cyc_data.append((L, total, pre2))
            for i, v in enumerate(cyc):
                color[v] = 2
                depth[v] = 0
                f_tail[v] = 0
                entry[v] = v
                cyc_id[v] = cid
                cyc_pos[v] = i
            for j in range(ci - 1, -1, -1):
                v = path[j]
                nxtv = path[j + 1]
                color[v] = 2
                depth[v] = depth[nxtv] + 1
                f_tail[v] = (v + f_tail[nxtv]) % MOD
                entry[v] = entry[nxtv]
        else:
            # u 已归属既有环：当前路径全是 tail 点
            for j in range(len(path) - 1, -1, -1):
                v = path[j]
                nxtv = path[j + 1] if j + 1 < len(path) else u
                color[v] = 2
                depth[v] = depth[nxtv] + 1
                f_tail[v] = (v + f_tail[nxtv]) % MOD
                entry[v] = entry[nxtv]

    out = []
    for p, k in queries:
        d = depth[p]
        if k <= d:
            # 前 k 条全部在 tail 上且各执行一次：开销 = 前 k 个点的编号和。
            # 用 F[p] - F[第 k 步的点] 得到这 k 个编号之和。
            v = p
            step = k
            for lv in range(LOG - 1, -1, -1):
                if step >= (1 << lv):
                    step -= 1 << lv
                    v = up[lv][v]
            out.append(str((f_tail[p] - f_tail[v]) % MOD))
        else:
            tail_cost = f_tail[p]
            c = k - d  # 环上执行的条数（>=1）
            entry_node = entry[p]
            L, total, pre2 = cyc_data[cyc_id[entry_node]]
            start = cyc_pos[entry_node]
            full, rem = divmod(c, L)
            # 每个环点先被执行 full 次（权重 1..full），
            # 再有 从 start 数起前 rem 个点各多一次（权重 full+1）。
            base = (full * (full + 1) // 2) % MOD
            cyc_cost = base * total % MOD
            if rem:
                cyc_cost = (cyc_cost + (full + 1) * (pre2[start + rem] - pre2[start])) % MOD
            out.append(str((tail_cost + cyc_cost) % MOD))

    sys.stdout.write("\n".join(out) + "\n")


def run_tests():
    """运行嵌入的官方样例与自加的边界/变形用例。"""
    import io
    import random

    def run_once(inp):
        old = sys.stdin, sys.stdout
        sys.stdin = io.TextIOWrapper(io.BytesIO(inp.encode("utf-8")))
        sys.stdout = io.StringIO()
        try:
            solve()
            return sys.stdout.getvalue().rstrip("\n")
        finally:
            sys.stdin, sys.stdout = old

    def ref_cost(nxt, p, k):
        """独立参照：k 小于阈值时逐条模拟；大 k 以「首次重复 + 从环入口
        一整圈」为检查点——此后每一整圈，各环点的历史执行次数各 +1，
        权重随圈数增长（第 j 圈贡献 w0 + j*环点编号和），再补不足一圈的
        s 步。与 solve() 的 pre2 闭式是两套思路，可互验。"""
        if k <= 5000:
            cnt = {}
            u = p
            total = 0
            for _ in range(k):
                cnt[u] = cnt.get(u, 0) + 1
                total += cnt[u] * u
                u = nxt[u]
            return total % MOD
        # 走到第一次重复：路径上每个点恰好执行一次，u 指向环入口
        cnt = {}
        u = p
        total = 0
        seen = set()
        while u not in seen:
            seen.add(u)
            cnt[u] = cnt.get(u, 0) + 1
            total += cnt[u] * u
            u = nxt[u]
        entry = u
        # 从环入口起完整一圈（这一圈里环点各 +1 次执行）
        ring = []
        v = entry
        while True:
            ring.append(v)
            L = len(ring)
            cnt[v] = cnt.get(v, 0) + 1
            total += cnt[v] * v
            v = nxt[v]
            if v == entry:
                break
        steps = len(seen) + L  # 已执行条数
        rest = k - steps
        m, s = divmod(rest, L)
        w0 = sum(cnt[v] * v for v in ring)  # 检查点处环点的权重和
        ring_sum = sum(ring)
        # 第 j 圈（j=1..m）：各环点执行次数再 +1，贡献 w0 + j*ring_sum
        total += m * w0 + ring_sum * m * (m + 1) // 2
        for v in ring:
            cnt[v] += m  # 虚拟跑过 m 圈后，环点计数补上
        # 再走 s 步（不足一圈），从 entry 起，每步权重 cnt+1
        u = entry
        for _ in range(s):
            cnt[u] = cnt.get(u, 0) + 1
            total += cnt[u] * u
            u = nxt[u]
        return total % MOD

    cases = [
        # 官方样例 1：自环，1+2+...+15 的模意义总开销
        ("1 2\n1\n1 1\n1 5\n", "1\n15"),
        # 官方样例 2：1<->2 两个点的环
        ("2 3\n2 1\n1 1\n1 4\n2 3\n", "1\n9\n7"),
        # 官方样例 3：环 2->3->4->2，1 和 5 各是 1 步 tail
        ("5 4\n2 3 4 2 4\n1 2\n1 8\n5 4\n5 10\n", "3\n34\n14\n59"),
        # 边界：k 恰好等于 depth(p)，k 条全走 tail（编号和分支）
        ("3 1\n2 3 3\n2 1\n", "2"),
        # 边界：k = depth + 1：tail 一个点 + 环上一条
        ("3 1\n2 3 3\n1 2\n", "3"),
        # 自环从自身出发跑 3 轮：1+2+3
        ("1 1\n1\n1 3\n", "6"),
    ]

    for i, (inp, expected) in enumerate(cases, 1):
        got = run_once(inp)
        status = "✓" if got == expected else "✗"
        print(f"样例 {i}: 期望={expected!r}, 实际={got!r} {status}")

    # 随机对拍：小图、大 k，与独立参照（模拟/检查点外推）比对
    rng = random.Random(20260411)
    ok = True
    for trial in range(120):
        n = rng.randint(1, 12)
        nxt = [0] + [rng.randint(1, n) for _ in range(n)]
        qs = []
        for _ in range(8):
            p = rng.randint(1, n)
```

## 示例推演

样例 3 的图：环是 $2 \to 3 \to 4 \to 2$，从点 2 起环序列记 $[2,3,4]$（$L=3$，$\text{pos}(2)=0,\text{pos}(3)=1,\text{pos}(4)=2$，编号和 $9$）；点 1 与点 5 各挂一步（$\text{depth}(1)=1,\ \text{entry}(1)=2$；$\text{depth}(5)=1,\ \text{entry}(5)=4$）。

**查询 `1 8`**：$k=8 > d=1$。tail 项 $F[1] = 1$。环上执行 $c = 8 - 1 = 7$ 条，从 $\text{pos}(2)=0$ 起。$7 = 2 \times 3 + 1$，即 $\text{full}=2,\ rem=1$：

- 完整圈项：$\frac{2 \times 3}{2} \times (2+3+4) = 3 \times 9 = 27$。拆开看：2 被执行的次数是第 1、4、7 次（权重和 $1+2+3$），3 与 4 也是 3 次，三项权重和合并就是 $3 \times (2+3+4)$；
- 尾缀项：$(\text{full}+1) = 3$，从 $start=0$ 数 $rem=1$ 个点，只有 $w_0 = 2$，贡献 $3 \times 2 = 6$；
- 合计 $1 + 27 + 6 = 34$，与官方输出一致。直接逐条核对：$1$ 一次 $1$、$2$ 三次共 $12$、$3$ 两次 $9$、$4$ 两次 $12$，四项相加正是 34。

**查询 `5 10`**：tail 项 $F[5] = 5$；$c=9$，从 $\text{pos}(4)=2$ 起。$9 = 3 \times 3$：完整圈项 $\frac{3 \times 4}{2} \times 9 = 54$，尾缀项为 0。合计 $5 + 54 = 59$。独立核对：从 4 起环序列 $4,2,3$ 各执行 3 次，$4(1+2+3) + 2(1+2+3)\times 2 + 3(1+2+3)\times 3$ 展开正是 $24+12+18+5 = 59$。

**查询 `5 4`**：tail 项 $5$；$c=3$ 恰一整圈：$\frac{1 \times 2}{2} \times 9 = 9$；合计 14。

**查询 `1 2`**：$c=1$：完整圈项 0，尾缀项 $1 \times w_0 = 2$，加 tail 1 得 3。

tail 分支用自造小图演示：`next = [2, 3, 3]`（点 3 成自环）。查询 `2 1`：$\text{depth}(2)=1$，$k=1 \le d$，执行的只有点 2 自己，输出 $F[2] - F[3] = 2 - 0 = 2$。查询 `1 2`：$k=2 > d=1$，tail 项 $1+2=3$，环上一条 $w_0=3$，合计 6。

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| ---- | ---------- | ---------- | ---- |
| 逐条模拟 | $O(q \cdot k)$ | $O(n)$ | $k \le 10^9$，单次询问就能走 $10^9$ 步，不可行 |
| 函数图染色 + 环前缀和 + 倍增（最优） | $O(n \log n + q \log n)$ | $O(n \log n)$ | 染色与预处理 $O(n)$；环内部分闭式合并 $O(1)$，tail 分支 $O(\log n)$ 跳倍增，本题采用 |

$n, q$ 都是 $2 \times 10^5$ 时总运算量约 $10^7$ 量级；全部求和取模 $10^9+7$，中间量（如 $\text{full}(\text{full}+1)/2$）先归约再相乘，避免大数相乘的常数。

## 易错点总结

### 1. 环窗口的起点必须用入口点在环中的位置，不能默认 0

$\text{pre2}[start+rem] - \text{pre2}[start]$ 里的 $start$ 取自 $entry[p]$ 在环里的坐标。起点写成 0 之后，从非环首出发的整段执行全部按环首起算：样例 2 里查询 `2 3`（入口是点 2，环序列 $[1,2]$，$\text{pos}(2)=1$）会按 $1,2$ 的顺序对点记账，输出 9 而不是 7；样例 3 查询 `5 10` 同样把从点 4 起的三轮写成从点 2 起的三轮，59 变成 57。

### 2. 尾缀权重是 full + 1，不是 full

完整圈项是 $\frac{\text{full}(\text{full}+1)}{2} \times \text{总}$，尾缀那一段执行发生在第 $\text{full}+1$ 圈，权重是 $\text{full}+1$。尾缀权重写成 `full` 时，$k$ 很小的询问（$\text{full}=0, rem=1$）环项干脆为零——样例 1 查询 `1 1` 会输出 0 而不是 1，样例 3 查询 `1 2` 输出 1 而不是 3，官方样例就能拦住。

### 3. $k \le d$ 的 tail 编号和要扣掉跳过之后的部分

两个分支共用 $F$：$k > d$ 时直接取 $F[p]$（进环前的 $d$ 个点）；$k \le d$ 时是 $F[p] - F[\text{跳 } k \text{ 步的点}]$。第二个分支若也照第一个写 $F[p]$，没执行到的 tail 点被一并收进开销。官方样例三组都落在 $k > d$ 上探不到，`next = [2, 3, 3]`、查询 `2 1` 这类自造数据是现成的检验：正确输出 2，漏减 $F$ 会输出 5。

## 扩展思考

- 「tail 后缀和 + 环重复两遍前缀和」是函数图上行走类问题的通用闭式组合：对访问历史做聚合（计数、平方和、加权和）都能组织成同形的两项相加。与倍增跳点互补——倍增管进环前的短前缀，闭式管进环后的长循环。
- 计数口径换成全局量（同一个 $t$ 贯穿全图、每条指令共享）会让 tail 与环互相勾连，圈分解随之失效；本题恰好允许每条指令独立计次，环上才能推得出闭式。
