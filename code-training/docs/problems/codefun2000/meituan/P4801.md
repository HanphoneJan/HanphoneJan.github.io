# P4801. 脉冲同步

> 场次：2026年4月18日-开发岗 · 来源：[CodeFun2000 P4801](https://codefun2000.com/p/P4801)

## 题目描述

两座信号塔各自记录了一段脉冲信号，每段信号都是一个长度为 $n$ 的排列，即由 `1` 到 `n` 这 $n$ 个整数按某种顺序排列而成，每个整数恰好出现一次。工程师希望提取出两段信号中共同存在的最长脉冲序列，称为“同步序列”。若有多个长度相同的最长同步序列，则选择在字典序意义下最大的那一个，以便后续处理。

【排列】长度为 $n$ 的排列是指由 $1,2,\dots,n$ 每个整数恰好出现一次构成的序列。
【子序列】从一个序列中删除零个或多个元素（保持原有顺序）后得到的新序列。
【同步序列】若某个序列 $C$ 既是序列 $A$ 的子序列，也是序列 $B$ 的子序列，则称 $C$ 为 $A$ 与 $B$ 的一个同步序列。
【字典序比较】对于两个等长序列 $X$ 和 $Y$，找到最小的下标 $i$ 使得 $X_i \neq Y_i$：若 $X_i > Y_i$，则 $X$ 字典序大于 $Y$；若 $X_i < Y_i$，则 $X$ 字典序小于 $Y$；若所有位置均相等，则 $X$ 与 $Y$ 相等。

现在给定两段脉冲信号（排列），请你分别求出每一对信号中最长同步序列的长度，并输出字典序最大的那一条同步序列。

排列的长度 $n$ 满足 $2 \le n \le 2 \times 10^5$。测试数据的组数 $T$ 满足 $1 \le T \le 10^5$，且所有测试数据中 $n$ 的总和不超过 $2 \times 10^5$。

## 输入格式

第一行包含一个整数 $T$，表示测试数据的组数。
接下来每组数据由三行组成：
- 第一行包含一个整数 $n$，表示两段脉冲信号（排列）的长度。
- 第二行包含 $n$ 个整数，表示第一段脉冲信号（排列），包含 $1$ 到 $n$ 各恰好一次。
- 第三行包含 $n$ 个整数，表示第二段脉冲信号（排列），包含 $1$ 到 $n$ 各恰好一次。

## 输出格式

对于每组测试数据，分两行输出结果：
- 第一行输出一个整数 $k$，表示最长同步序列的长度。
- 第二行输出 $k$ 个整数，用空格分隔，表示字典序意义下最大的最长同步序列。

## 示例

### 示例 1

**输入：**

```
1
5
1 2 3 4 5
5 4 3 2 1
```

**输出：**

```
1
5
```

**说明：**

序列 $q$ 完全逆序，任何两个不同数字在 $p$ 中的顺序与在 $q$ 中的顺序无法同时保持递增，因此最长同步序列的长度只能为 `1`。在所有长度为 `1` 的同步序列中，字典序最大的是仅由数字 $5$ 构成的序列。

### 示例 2

**输入：**

```
1
6
1 3 2 4 6 5
1 2 3 4 5 6
```

**输出：**

```
4
1 3 4 6
```

**说明：**

$q$ 是升序排列，因此要求在 $p$ 中选出的子序列必须也是升序的。在 $p$ 中的升序子序列有 `1 3 4 6`、`1 2 4 6`、`1 3 4 5` 等，它们的最长长度均为 `4`。在长度为 `4` 的同步序列中，字典序最大的为 `1 3 4 6`（优先比较首位数字，其次比较第二位数字，以此类推；`1 3 4 6` 的首位与其余序列相同，第二位 `3` 大于 `2`，故胜出）。

### 示例 3

**输入：**

```
1
2
2 1
1 2
```

**输出：**

```
1
2
```

**说明：**

$n = 2$ 的最小边界情况。$p$ 为 `2 1`，$q$ 为 `1 2`，两排列的最长公共子序列长度仅为 `1`。在所有长度为 `1` 的同步序列中，字典序最大的是 `2`。

## 解题思路

### 把公共子序列翻译成「两维同增的链」

两段信号都是 $1..n$ 的排列，被选中的那批数必须「在 $A$ 中按某顺序出现，且在 $B$ 中也按同一顺序出现」。把每个数 $v$ 映射成一对坐标 $\big(\text{posA}(v),\ \text{posB}(v)\big)$，合法子序列就是一条**两个坐标都严格递增的链**。这条翻译落在实现上最简约的形式是：令 $C[i] = \text{posB}[A[i]]$，那么「从 $A$ 中选一条合法子序列」与「$C$ 的一条上升子序列」一一对应——选出元素在 $B$ 中也要依次出现，等价于它们的 $\text{posB}$ 依次变大。

于是最大长度有了经典判据：$K = C$ 的最长上升子序列（LIS）长度。$n \le 2 \times 10^5$、所有组 $\sum n \le 2 \times 10^5$ 的规模允许 $O(n \log n)$，$O(n^2)$ 的经典 LCS 表（$4 \times 10^{10}$ 量级）则不可行——方格式的双重约束在这里被「位置映射」压成了一维序列问题，LIS 这个算法就是因此入选的。

### 字典序最大：每个数只会在唯一的一格里被选

输出的判定标准多了一层：所有长度 $K$ 的同步序列里取字典序最大的。对 $A$ 的每个下标 $i$ 定义

$$
f(i) = 1 + \max\{\, f(j) : j > i,\ C[j] > C[i] \,\}
$$

即从 $i$ 出发（含自身）还能接出的最长链长，从右往左配树状数组一次可以 $O(n \log n)$ 算完。任何一条长度为 $K$ 的链，其第 $t$ 个元素必须满足 $f = K - t + 1$：下界来自「后面还要接满剩余的个数」，上界来自 $f$ 的定义——链上排它后面的元素都落在它的查询域里，顶多贡献 $f-1$。于是每个数只属于唯一的一个 $f$ 值，把它称作这个数的「格」；一条最长的链恰好从格 $K, K-1, \dots, 1$ 里各取一个数。

构造因此按格进行：把同一 $f$ 值的数收进一个桶并按值降序排好，$\text{rem}$ 从 $K$ 逐层降到 $1$，每层在 `bucket[rem]` 里只问一件事——这个数的位置 $\text{posA}$ 与 $\text{posB}$ 是否还都大于当前已选末位的两个坐标（链必须继续往右上方长）。第一个满足的数就是本层的最优选：本层任意满足条件的数都能保证选上后仍可凑满 $K$，取值最大的那个自然给出字典序最优。坐标条件失败的数不会再有第二次机会——末位的两个坐标只会往右上方走、永不回退，而且每层只被访问一次。链的存在性保证每层不会扑空：上一格选中的数既然 $f=rem$，它的延伸链里必有一个 $f=rem-1$ 的后继在本层候选之列。

整段构造 $O(\sum n)$，加上映射与 $f$ 计算的 $O(n \log n)$，全部组合计不超规模。

## 完整代码实现

```python
"""
P4801. 脉冲同步 - 位置映射 + 顺序关系 DP（最长链 + 字典序最大构造）

题意：两段长度为 n 的排列 A、B，求最长公共子序列的长度，并在所有最长
公共子序列中输出字典序最大的那条。

关键观察 1（把公共子序列变成「链」）：两段都是 1..n 的排列，每个数恰好
出现一次。选中的这批数，在 A 中按某种顺序出现、在 B 中也要按同样的顺序
出现——所以一条公共子序列就是数集 {1..n} 上的这样一组数：把每个数 v 映射
到它在两段中的出现位置构成一对坐标，被选中的数必须让两维坐标同时严格递增。
构造数组 C[i] = posB[A[i]]，则「从 A 中选出合法子序列」与「C 的上升子序列」
一一对应（选出的数在 B 中也要依次出现，等价于它们的 posB 依次增大）。
最长公共子序列长度 = C 的最长上升子序列（LIS）长度 K。

关键观察 2（字典序最大怎样贪）：可以在值域上做贪心。先对 A 的每个下标 i
算出 f(i) = 从 i 出发（含自身）还能接出的最长链长（C 的后缀 LIS），任何
一条长度为 K 的链，第 t 个选中元素必须恰好满足 f = K-t+1：下界来自
「后面还要接满剩余的个数」，上界来自 f(i) 的定义（链上排它后面的元素
最多只能贡献 f(i)-1）。于是每个数只属于唯一的一个 f 值，把它称作这个
数的「格」；一条最长的链恰好从格 K, K-1, ..., 1 里各取一个数。构造按格
进行：同一 f 值的数收进一个桶并按值降序排好，rem 从 K 逐层降到 1，每层
在 bucket[rem] 里找第一个「A 位置在已选末位之后、posB 也在末位之后」的
数——第一个满足的就是本层最优选（本层任意满足条件的数都能凑满 K，取
值最大者为字典序最优）；坐标条件失败的数，随着已选末位只会往右上收紧，
此格以后永远没资格被再看一次。

实现映射：
- f(i) 用「从右往左 + 树状数组上取前缀最大值」在 O(n log n) 内算出：
  把 C 值反转成 n-C 后，C[j] > C[i] 的查询变成一段前缀最大值查询；
- 把带相同 f 的值收集进桶 bucket[r]，桶内按值降序排好；
- 贪心时 rem 从 K 递减到 1，每次只在 bucket[rem] 里按值降序找第一个
  「A 位置与 posB 都已越过已选末位」的数。

输入格式：
- 第 1 行：测试组数 T；
- 每组三行：n、排列 A（n 个数）、排列 B（n 个数）。

输出格式：
- 每组两行：K 与字典序最大的最长同步序列。

时间复杂度：O(sum(n log n))，n 的总和不超过 2*10^5
空间复杂度：O(n)
"""

import sys

def solve():
    """位置映射 + 后缀 LIS + 按值降序贪心，输出长度与序列。"""
    data = sys.stdin.buffer.read().split()
    pos = 1
    t = int(data[0])
    out = []
    for _ in range(t):
        n = int(data[pos])
        pos += 1
        arr = [int(x) for x in data[pos:pos + n]]
        pos += n
        brr = [int(x) for x in data[pos:pos + n]]
        pos += n

        # 每个值在 B 中的位置（0 基）
        pos_b = [0] * (n + 1)
        for j, v in enumerate(brr):
            pos_b[v] = j
        # A 下标 i 处上的值的 posB，构成 C
        c = [pos_b[v] for v in arr]

        # f[i] = 1 + max{ f[j] : j>i, C[j] > C[i] }，从右往左用树状数组求前缀最大。
        # 把 C 值 m 映射到 m' = n - m 后，"C[j] > C[i]" 变成
        # "m' < n - C[i]"，即前缀 [1 .. n - C[i]] 的最大值。
        fen = [0] * (n + 1)  # 1 基，存前缀最大值

        def query(i):
            best = 0
            while i > 0:
                if fen[i] > best:
                    best = fen[i]
                i -= i & (-i)
            return best

        def update(i, v):
            while i <= n:
                if v > fen[i]:
                    fen[i] = v
                i += i & (-i)

        f = [0] * n
        buckets = [[] for _ in range(n + 2)]
        k = 0
        for i in range(n - 1, -1, -1):
            fi = 1 + query(n - c[i])
            f[i] = fi
            update(n - c[i] + 1, fi)
            if fi > k:
                k = fi
            # 桶里同时记录值与它的两个坐标（A 中的位置、posB），供贪心使用
            buckets[fi].append((arr[i], i, c[i]))

        # f 的填充按 A 下标从右往左进行，桶内顺序不是值序；
        # 贪心要求「值大者优先」，按值降序排一次（值在排列里互不相同）。
        for r in range(1, k + 1):
            buckets[r].sort(reverse=True)

        # 贪心：rem 从 K 降到 1，在 bucket[rem] 里找第一个
        # 「A 位置在已选末位之后、posB 也在末位之后」的数（值已降序）。
        # 位置/posB 的下界只增不减，单次扫不过的数后续也无望，直接略过。
        ans = []
        last_a = -1
        last_b = -1
        rem = k
        for r in range(k, 0, -1):
            bv = buckets[r]
            for v, ia, ib in bv:  # 已按值降序
                if ia > last_a and ib > last_b:
                    ans.append(v)
                    last_a = ia
                    last_b = ib
                    break
            rem -= 1

        out.append(str(k))
        out.append(" ".join(map(str, ans)))
    sys.stdout.write("\n".join(out) + "\n")


def run_tests():
    """运行嵌入的官方样例与自加的边界/变形用例。"""
    import io
    import random

    def run_once(inp):
        old = sys.stdin, sys.stdout
        sys.stdin = io.TextIOWrapper(io.BytesIO(inp.encode("utf-8")))
        sys.stdout = io.StringIO()
        try:
            solve()
            return sys.stdout.getvalue().rstrip("\n")
        finally:
            sys.stdin, sys.stdout = old

    def brute_two(a, b):
        """参照实现：枚举 A 的全部子序列，取为双方公共子序列的最长者，
        同长中取值序列字典序最大，O(2^n) 可承受 n<=8。"""
        from itertools import combinations

        def is_sub(vals, t):
            it = iter(t)
            return all(v in it for v in vals)

        for m in range(len(a), 0, -1):
            best = None
            for comb in combinations(range(len(a)), m):
                vals = tuple(a[i] for i in comb)
                if is_sub(vals, b):
                    if best is None or vals > best:
                        best = vals
            if best is not None:
                return m, list(best)
        return 0, None

    cases = [
        # 官方样例 1：完全逆序，只能选一个数，取 5
        ("1\n5\n1 2 3 4 5\n5 4 3 2 1\n", "1\n5"),
        # 官方样例 2：B 升序，在 A 中挑最长上升子序列，字典序最大 1 3 4 6
        ("1\n6\n1 3 2 4 6 5\n1 2 3 4 5 6\n", "4\n1 3 4 6"),
        # 官方样例 3：n=2 逆序对，取 2
        ("1\n2\n2 1\n1 2\n", "1\n2"),
        # 两段完全相同：最长同步序列是整段，本身就是字典序最大（排列递增）
        ("1\n6\n3 1 4 2 6 5\n3 1 4 2 6 5\n", "6\n3 1 4 2 6 5"),
        # B 逆序、A 升序：K=1，取 n
        ("1\n7\n1 2 3 4 5 6 7\n7 6 5 4 3 2 1\n", "1\n7"),
        # 字典序最大在首个元素就分高下：值 3 与 1 都能当链首，应取 3
        ("1\n3\n3 1 2\n1 3 2\n", "2\n3 2"),
        # 最后一层的 posB 坐标检查：值 2 在 B 里位于 4、5 之前，不能接在尾巴上
        ("1\n5\n3 4 5 1 2\n2 4 3 5 1\n", "3\n4 5 1"),
        # 多组数据混排
        ("2\n2\n1 2\n2 1\n3\n1 2 3\n3 2 1\n", "1\n2\n1\n3"),
    ]

    for i, (inp, expected) in enumerate(cases, 1):
        got = run_once(inp)
        status = "✓" if got == expected else "✗"
        print(f"样例 {i}: 期望={expected!r}, 实际={got!r} {status}")

    # 随机对拍（n<=8）：长度用 BFS 式参考、序列用「是双方子序列 + 字典序最大」双重验证
    rng = random.Random(20260418)
    ok = True
    for trial in range(200):
        n = rng.randint(2, 8)
        a = list(range(1, n + 1))
        rng.shuffle(a)
        b = list(range(1, n + 1))
        rng.shuffle(b)
        got = run_once("1\n%d\n%s\n%s\n" % (n, " ".join(map(str, a)), " ".join(map(str, b))))
        lines = got.split("\n")
        k = int(lines[0])
        seq = list(map(int, lines[1].split())) if k else []
        # 长度与参照实现一致
        blen, bseq = brute_two(a, b)
        # 声称的序列必须是两段的公共子序列，且长度正确
        def is_sub(s, t):
            it = iter(t)
            return all(v in it for v in s)
        # 参照实现给出的也必须是字典序 <= 我们的
        if k != blen or not is_sub(seq, a) or not is_sub(seq, b) or bseq is not None and seq < bseq:
            ok = False
            print(f"对拍失败: A={a} B={b} 期望长={blen} 参照序列={bseq} 实际长={k} 实际序列={seq}")
    print("随机对拍:", "全部通过" if ok else "存在失败")


if __name__ == "__main__":
    if len(sys.argv) > 1 and sys.argv[1] == "--test":
        run_tests()
    else:
        solve()
```

## 示例推演

样例 2：$A = 1\ 3\ 2\ 4\ 6\ 5$，$B = 1\ 2\ 3\ 4\ 5\ 6$（$B$ 的位置映射是恒等的，$C = 1\ 3\ 2\ 4\ 6\ 5$，即 $A$ 本身）。从右往左算 $f$：

| $i$（1 基） | $C[i]$ | $f(i)$ | 理由 |
| ---- | ---- | ---- | ---- |
| 6 | 5 | 1 | 后面没有更长的 |
| 5 | 6 | 1 | 同上 |
| 4 | 4 | 2 | 后面接 5 或 6 → 链长 2 |
| 3 | 2 | 3 | 接 $f(4)=2$ 的 4 → 链长 3 |
| 2 | 3 | 3 | 接 4、6 → 链长 3 |
| 1 | 1 | 4 | 接 $f(2)$ 或 $f(3)$（=3）→ 链长 4 |

$K = 4$，各数按 $f$ 进桶：$\text{bucket}[4]=\{1\}$，$\text{bucket}[3]=\{3,2\}$，$\text{bucket}[2]=\{4\}$，$\text{bucket}[1]=\{6,5\}$（桶内按值降序排列）。逐层构造，已选末位的两个坐标记作 $(\text{last}_A, \text{last}_B)$，初始 $(0,0)$：

- $rem=4$：`bucket[4]` 只有值 1（坐标 $(1,1)$），坐标条件满足 → 选 1，末位变 $(1,1)$；
- $rem=3$：`bucket[3]` 先看值 3（坐标 $(2,3)$）：$2>1,\ 3>1$ 都成立 → 选 3，末位变 $(2,3)$；
- $rem=2$：`bucket[2]` 只有值 4（坐标 $(4,4)$）→ 选 4，末位变 $(4,4)$；
- $rem=1$：`bucket[1]` 先看值 6（坐标 $(5,6)$）：$5>4,\ 6>4$ → 选 6。

输出 `4` 与 `1 3 4 6`，与官方一致。四个被选的值正好每层一个，且每层给出的都是本层候选中坐标条件仍允许、值又最大的那个。

「格」的归属从反面也能看清：第二位若硬想取更大的值 6（$f=1$）或值 4（$f=2$），从这里再接最长分别只有 $1+1$、$1+2$ 层，总长掉出 $K$——它们被排除不是因为值不够大，而是各自所属的格不对。

样例 3（$A=2\ 1,\ B=1\ 2$）：$\text{posB}(2)=2, \text{posB}(1)=1$，即 $C = [2,1]$，全无上升对，$K=1$。$rem=1$ 时 `bucket[1]` 按值降序先看值 2（坐标 $(1,2)$）→ 选 2，输出首行 `1`、次行 `2`。

样例 1（完全逆序对）：$C$ 全程递减，$f \equiv 1$，$K=1$。$rem=1$ 的桶按值降序第一个就是 5，输出 `5`——全体单点子序列里字典序最大者。

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| ---- | ---------- | ---------- | ---- |
| 经典 LCS 方格 DP | $O(n^2)$ | $O(n^2)$ | $n = 2\times10^5$ 时状态数 $4\times10^{10}$，不可行 |
| 位置映射 + LIS + 桶内降值贪心（最优） | $O(n \log n)$ | $O(n)$ | 映射把双重坐标约束压成一维 LIS；字典序构造退化为一次降值扫描，本题采用 |

所有组 $\sum n \le 2\times10^5$，树状数组与桶操作合计百万量级；单组最坏要对 $2\times10^5$ 个下标各做一次 $O(\log n)$ 的后缀最大查询。

## 易错点总结

### 1. 进了桶但没按值降序排，给出的就不是字典序最大的

$f$ 的填充按 $A$ 下标从右往左进行，桶内的初始顺序是 $A$ 下标的**逆序**，不是值的降序。漏掉一次 `buckets[r].sort(reverse=True)`，样例 2 会输出 `1 2 4 5` 而不是官方的 `1 3 4 6`——$f=3$ 的桶里值 2 被（下标更先的）值 3 挡在后头，贪心第一眼看到的是谁，输出的第二位就是谁。

### 2. 位置的递增性要在 $A$、$B$ 两边同时检查

贪心资格条件是 $\text{posA}(v) > \text{last}_A$ **且** $\text{posB}(v) > \text{last}_B$。少了 $\text{posB}$ 这一半，「上升链」退化成「$A$ 内递增子序列」。构造 `A = 3 4 5 1 2, B = 2 4 3 5 1`（$\text{posB}$：$2\!\to\!0,\ 4\!\to\!1,\ 3\!\to\!2,\ 5\!\to\!3,\ 1\!\to\!4$）能一步定位：正确输出 `3` 与 `4 5 1`——最后一层 `bucket[1]` 里值 2 先被按值降序扫到，但它的 $\text{posB}=0$ 不大于上个已选值 5 的 $\text{posB}=3$，被坐标条件拦下，改选排在后头但坐标合格的值 1；漏检查时值 2 凭 $\text{posA}$ 胜出，输出变成 `3` 与 `4 5 2`，而 2 在 $B$ 里排在 4、5 之前，这个「同步序列」根本不是 $B$ 的子序列。

---

### 3. 映射方向写反会让 $f$ 全线失真

$C[i]$ 必须是 $\text{posB}[A[i]]$（$A$ 的下标作外层）。写反成 $\text{posA}[B[i]]$ 后，树状数组查询的域随之换成另一维，$f$ 的值不再保证「后缀链长」，桶按错误的 $f$ 聚类，$K$ 本身就可能算错。方向的自检方法：外层扫描只能沿 $A$ 的下标走（$f$ 的「后面」指 $A$ 中的后面），内层那个才是被压进树状数组的维度。

## 扩展思考

- «位置映射 + LIS» 是排列场景把双重序约束压成一维的标准手法，除了公共子序列还出现在把两排列的交错结构当序列检查的场景；它成立的前提是**每个元素两处都恰好出现一次**，推广到「存在重复元素」则需要严格增的去重或带平手策略的 LIS 变体。
- «$f$ 分桶 + 逆序扫描» 可以推广到一般的 DAG：只要每个节点有「最长延伸长度」$\ell(v)$ 且同 $\ell$ 的节点互相不可替代，字典序最优链都能在每格一次的降序扫描中构造出来。
