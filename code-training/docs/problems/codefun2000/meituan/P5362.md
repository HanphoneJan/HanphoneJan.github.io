# P5362. 转盘配色

> 场次：2026年9月5日 · 来源：[CodeFun2000 P5362](https://codefun2000.com/p/P5362)

## 题目描述

装配线上有一只圆形转盘，沿圆周均布 $2m$ 个卡槽。每个卡槽里已经放好一块色片，黑色记为 `0`，白色记为 `1`，两种色片恰好各 $m$ 块。机械臂只能交换**相邻**两个卡槽里的色片；转盘是圆的，编号为 `0` 的卡槽与编号为 $2m-1$ 的卡槽也算相邻。

质检要求沿圆周看过去必须黑白严格交错，也就是任意两个相邻卡槽颜色都不同。色片只能靠相邻交换挪动，不能取出或替换。

请计算：最少交换多少次，才能让转盘变成严格交错。

约束：
- `1` $\le$ $m$ $\le$ `200000`
- 色片串长度为 $2m$，只含 `0` 和 `1`，且两种字符各出现 $m$ 次

## 输入格式

第一行一个整数 $m$（`1` $\le$ $m$ $\le$ `200000`），表示每种颜色的块数。

第二行一个长度为 $2m$ 的字符串 $d$，只含字符 `0` 和 `1`，表示沿圆周依次写下的色片颜色。保证 `0` 与 `1` 的个数都是 $m$。

## 输出格式

输出一个整数，表示最少相邻交换次数。

## 解题思路

### 先看清交换在「保持」什么

最少交换次数的题，第一步永远是看清一路交换下来什么东西不变。相邻交换换的是两个位置上的色片：交换两块同色片毫无意义，交换异色片时，**同类色片沿圆周的循环次序保持不变**——两块 0 之间夹着几块 1，交换结束后仍然夹着几块 1（交换的是 0 与它旁边的 1，两块 0 的相对位置关系原封不动）。因此第 $i$ 个 `0`（按出现顺序数）最终必然落在目标图案的**第 $i$ 个零位**上，这正是答案可以按「一个 $\to$ 一个对齐」逐项计算的原因。

### 目标家族与代价

固定环上的一个缺口，把目标图案写成序列。严格交错的环形图案不止两种外观——`0101…` 转一格看起来就是 `1010…`，再转一格又回到 `0101…`。把「图案本身的两种奇偶」和「环上的整体旋转」合起来，零位序列是

$$t_i = \text{start} + 2i,\qquad i = 0,\dots,m-1,\ \text{start}\in\mathbb Z$$

$\text{start}$ 取偶数对应 `0` 落偶位、取奇数对应 `0` 落奇位；$\text{start}$ 的平移就是接待上旋转。这里 $\text{start}$ 必须取**全体整数**而不是 $0\sim 2m-1$：环形匹配允许某块 `0` 跨过缺口落位（样例 2 交换的正是 5 号与 0 号这对环形相邻），「跑到下一圈的同余位置」就藏在整数值的平移里。

第 $i$ 个 `0` 从位置 $p_i$ 到目标 $t_i$ 的代价是 $|p_i - (\text{start}+2i)|$，总代价

$$\sum_i |p_i-\text{start}-2i| = \sum_i |b_i-\text{start}|,\qquad b_i = p_i-2i$$

这是「绝对值和关于 $\text{start}$ 求最小」的标准形状：$\text{start}$ 取 $b_i$ 的**中位数**时代价最小。于是整道题收成三步——收集 `0` 的下标、算 $b$ 并排序、对中位数求绝对差和。

数据范围也坐实了这个方向：$m\le2\times10^5$，$O(m^2)$ 的任何做法（比如对每个候选 $\text{start}$ 逐项求和）都要 $10^{10}$ 级别的运算，而排序加一次求和是 $O(m\log m)$，稳稳落在限内。

### m 为偶数时的取法

$|b_i-\text{start}|$ 的和是取值区间 $[b_{\lfloor(m-1)/2\rfloor},\, b_{\lceil{m/2}\rceil}]$ 上的常函数——中间区间里随便取哪个整数代价都相同。代码取 `bs[m // 2]` 即可；取区间外的值（比如取 $b$ 的平均值再取整）代价只会更大。

### 实现映射

`min_swaps` 里三行对应上面三步：零下标收集（只扫一遍字符串）、`bs = sorted(p_i - 2*i)`（一次 $O(m\log m)$ 排序，代替在全部 $\text{start}$ 上做二重循环）、`sum(abs(x - median))`（一次线性求和）。没有额外数组，也没有对环做任何模拟——环性完全被整数化的 $\text{start}$ 吸收。

## 完整代码实现

```python
"""
P5362. 转盘配色 - 环上最小相邻交换（目标枚举 + 中位数）

圆周上 2m 个卡槽各放一块色片，0 与 1 各 m 块；每次交换相邻两格
（含 0 号与 2m-1 号这对环形相邻），要求最终黑白严格交错，求最少交换次数。

输入格式：
- 第一行整数 m；
- 第二行长度 2m 的字符串 d，只含 0/1，两种字符各 m 个。

输出格式：
- 一个整数，最少相邻交换次数。

核心思路：相邻交换不改变同类色片的循环次序，因此第 i 个 0 最终必然落在
目标交错图案的「第 i 个 0 位」上。目标和它在环上的整体旋转合起来是
一个等差目标序列 start + 2i（start 取遍全体整数，偶数起点对应 0 落偶位、
奇数起点对应 0 落奇位）。把起点吃进差值：b_i = p_i - 2i，总代价为
sum |b_i - start|，对 start 的最优值就是 b 的（加权）中位数——绝对值
和的中位数定理在环情形通过 start 的整数范围自然成立。
答案 = sum |b_i - median(b)|。

复杂度：给 0 的下标列表排序 O(m log m)，求和 O(m)。
"""

# https://codefun2000.com/p/P5362
# @sample-start
"""
样例输入 1:
2
1100

样例输出 1:
1
"""
# @sample-end

# @sample-start
"""
样例输入 2:
3
110100

样例输出 2:
1
"""
# @sample-end

# @sample-start
"""
样例输入 3:
1
10

样例输出 3:
0
"""
# @sample-end

import sys


def min_swaps(m, colors):
    zero_pos = [i for i, ch in enumerate(colors) if ch == "0"]
    # 第 i 个零槽若与「start + 2i」这一目标对齐，代价项是
    # |zero_pos[i] - start - 2i| = |b_i - start|，start 取遍整数。
    bs = sorted(zero_pos[i] - 2 * i for i in range(m))
    median = bs[m // 2]
    return sum(abs(x - median) for x in bs)


def solve():
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    m = int(data[0])
    colors = data[1].decode() if isinstance(data[1], bytes) else data[1]
    print(min_swaps(m, colors))


def run_tests():
    import io
    import random
    import time
    from collections import deque

    def run_case(inp):
        old_stdin, old_stdout = sys.stdin, sys.stdout
        sys.stdin = io.TextIOWrapper(io.BytesIO(inp.encode("utf-8")))
        sys.stdout = io.StringIO()
        try:
            solve()
            output = sys.stdout.getvalue().strip()
        finally:
            sys.stdin, sys.stdout = old_stdin, old_stdout
        return output

    is_ring_alternating = lambda s: all(
        s[i] != s[(i + 1) % len(s)] for i in range(len(s))
    )

    def bfs_min_swaps(m, start):
        """小规模圈上 BFS：状态数为 C(2m, m)，给出精确答案。"""
        if is_ring_alternating(start):
            return 0
        n = 2 * m
        seen = {start}
        queue = deque([(start, 0)])
        while queue:
            state, dist = queue.popleft()
            chars = list(state)
            for i in range(n):
                j = (i + 1) % n
                if chars[i] == chars[j]:
                    continue
                chars[i], chars[j] = chars[j], chars[i]
                nxt = "".join(chars)
                if nxt not in seen:
                    if is_ring_alternating(nxt):
                        return dist + 1
                    seen.add(nxt)
                    queue.append((nxt, dist + 1))
                chars[i], chars[j] = chars[j], chars[i]
        return -1

    def brute_over_starts(m, colors):
        """直接对全部整数起点求最小 sum|b_i - start|，验证中位数取法。"""
        zero_pos = [i for i, ch in enumerate(colors) if ch == "0"]
        bs = [zero_pos[i] - 2 * i for i in range(m)]
        best = min(
            sum(abs(b - start) for b in bs)
            for start in range(-2 * m - 2, 2 * m + 3)
        )
        return best

    test_cases = [
        # 官方样例 1：交换中间相邻的 1 与 0
        ("2\n1100\n", "1"),
        # 官方样例 2：首尾两槽相邻，交换位置 0 与 5
        ("3\n110100\n", "1"),
        # 官方样例 3：本身已交错
        ("1\n10\n", "0"),
    ]
    for i, (inp, expected) in enumerate(test_cases, 1):
        output = run_case(inp)
        status = "✓" if output == expected else "✗"
        print(f"样例 {i}: {'通过' if output == expected else '失败'} {status}")
        assert output == expected, f"样例 {i} 期望 {expected}，实际 {output}"

    # 官方样例都很小，先用圈上 BFS 对拍模型：m=1..4 的全部合法字符串。
    from itertools import combinations

    model_cases = 0
    for m in range(1, 5):
        for zero_idx in combinations(range(2 * m), m):
            chars = ["1"] * (2 * m)
            for p in zero_idx:
                chars[p] = "0"
            line = "".join(chars)
            want = bfs_min_swaps(m, line)
            got = min_swaps(m, line)
            assert got == want, f"BFS 对拍失败 m={m} s={line}: 期望 {want}，实际 {got}"
            model_cases += 1
    print(f"对拍用例 {model_cases} 组（m=1..4 全字符串，圈上 BFS）：通过")

    # 中位数取法检验：随机中等规模字符串，与暴力扫描全部整数起点对照。
    rng = random.Random(20260905)
    scan_cases = 20
    for _ in range(scan_cases):
        m = rng.randint(2, 60)
        idx = rng.sample(range(2 * m), m)
        chars = ["0"] * (2 * m)
        for p in idx:
            chars[p] = "1"
        colors = "".join(chars)
        want = brute_over_starts(m, colors)
        got = min_swaps(m, colors)
        assert got == want, f"暴力对拍失败 m={m}: 期望 {want}，实际 {got}"
    print(f"对拍用例 {scan_cases} 组（随机 m<=60，按整数起点穷举）：通过")

    # 极端规模：m=200000，验证线性排序方案在时限内完成。
    m = 200000
    colors = "1" * m + "0" * m
    t0 = time.perf_counter()
    ans = run_case(f"{m}\n{colors}\n")
    elapsed = time.perf_counter() - t0
    assert int(ans) > 0
    print(f"压力用例 m={m}（先全 1 后全 0）：答案 {ans}，用时 {elapsed:.2f}s")


if __name__ == "__main__":
    if len(sys.argv) > 1 and sys.argv[1] == "--test":
        run_tests()
    else:
        solve()
```

## 示例推演

以官方样例 2 为例：$m=3$，环长 $6$，字符串 `110100`。`0` 的下标为

$$p_0=2,\quad p_1=4,\quad p_2=5$$

算差值序列 $b_i=p_i-2i$：

$$b_0=2-0=2,\quad b_1=4-2=2,\quad b_2=5-4=1$$

排序得 $[1,2,2]$，中位数取 $\text{bs}[1]=2$。答案

$$|1-2|+|2-2|+|2-2| = 1$$

中位数 $2$ 反解出目标序列 $\text{start}=2$：$t_0=2$、$t_1=4$、$t_2=6$——而环形刻度上 $6$ 就是 $0$ 号槽。也就是说前两个 `0` 不动，第三个 `0` **跨过缺口**从 $5$ 号槽挪到 $0$ 号槽，一次交换即成 `010101`，与样例说明的「交换位置 0 与 5」完全一致。

样例 1：$m=2$，`1100`，`0` 在 $p_0=2$、$p_1=3$，$b=[2,1]$ 排序 $[1,2]$，中位数区间里的每个整数代价都相同，代码取 $\text{bs}[1]=2$：目标序列 $2,4\equiv0$，$3$ 号槽的 `0` 跨过缺口到 $0$ 号槽，代价 $1$；取 $\text{start}=1$ 对应目标 $1,3$，是同一答案的另一种走法（交换 $1,2$ 两格得到 `1010`）。两种目标都合规，输出均为 `1`。

样例 3：$m=1$，`10`：$b_0=0-0=0$，中位数 $0$，代价 $0$——已经交错，不动。

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| ---- | ---------- | ---------- | ---- |
| 圈上状态图 BFS | $O(C(2m,m)\cdot m)$ | $O(C(2m,m))$ | 状态数在 $m=200000$ 时天文数字，只适合小输入对拍 |
| 对每个候选 start 逐项求和 | $O(m^2)$ | $O(m)$ | $\text{start}$ 要扫 $O(m)$ 个候选位，每个候选再求 $m$ 项和 |
| 排序 + 中位数一次求和（最优） | $O(m\log m)$ | $O(m)$ | 绝对值和对 $\text{start}$ 的最小值在 $b$ 的中位数处取到 |

## 易错点总结

### 1. 环形旋转要靠「全体整数」的 start 表达

$\text{start}$ 若只在 $0\sim 2m-1$ 内枚举、且每块 `0` 的代价按 $|p_i-t_i|$ 的环形距离算，会漏掉「零片跨过缺口落进下一圈同余位」的最优搭配——`bs` 这一处正是用 $b_i=p_i-2i$ 的整体整数平移来覆盖跨界情形。漏做之后，像样例 2 那种合理走法只剩「跨缺口交换一次」的输入会给大：输出比正确值多出一次甚至数不清的交换。可拿样例 2 自检：跨界交换是唯一代价为 1 的路径之一，少了整数起点集合就推不出来。

### 2. 最小值点必须取中位数，不能取均值

`sum(abs(x - median))` 的 $\text{median}$ 来自排序后的 `bs[m // 2]`。写成「$b$ 的平均值取整」时，极偏的 $b_i$（如 $b=[1,2,100]$）会把最优点拉离真实区间，输出普遍偏大；测试里 `brute_over_starts` 对每个整数逐一求最小，就是为了给这一行兜底。

### 3. 答案可能超过 32 位整数

答案量级约 $m^2/2$：$m=2\times10^5$ 时接近 $10^{10}$，`1` 段加 `0` 段的极端输入即可触发。Python 整数不受影响，转写成 C++/JS 时求和变量要开 64 位，否则大数据点输出截断值。

## 扩展思考

- 「保持同色片循环次序、按出现顺序对齐目标」这个论证对所有「最小相邻交换达到某环形排布」的问题通用，目标序列换成别的等差即可复用同一套中位数计算。
- 若题面改成允许任意交换（不只是相邻），代价就不再是关于位移的绝对值和，答案要用二分图匹配重新建模——限製条件本身就是复杂度的来源。
