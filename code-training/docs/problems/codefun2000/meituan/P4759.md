# P4759. 纯净之力

> 场次：2026年4月11日-开发岗 · 来源：[CodeFun2000 P4759](https://codefun2000.com/p/P4759)

## 题目描述

定义一个由小写字母组成的字符串的纯净子串为：所有字符互不相同的子串。
字符串的纯净力定义为：该字符串中长度最大的纯净子串的数量（按起始位置计数，不同起始位置视为不同子串）。

现在给定两个正整数 $L$ 和 $M$，请你构造一个长度恰好为 $L$ 的、仅由小写字母组成的字符串，使其纯净力恰好等于 $M$。如果无法构造，请输出 $-1$。

数据范围：$L$ 不超过 $10^5$，$M$ 不超过 $L$，所有数均为正整数。

## 输入格式

输入仅一行，包含两个整数 $L$ 和 $M$，中间用空格隔开。

## 输出格式

若存在满足要求的字符串，输出该字符串；否则输出 $-1$。答案不唯一时，输出任意一个合法字符串即可。

## 示例

### 示例 1

**输入：**

```
1 1
```

**输出：**

```
a
```

**说明：**

字符串长度 $L=1$，纯净力要求 $M=1$，此时 $L=M$。

构造全 `'a'` 字符串 `"a"`，其所有子串均为 `"a"`，最大纯净子串长度为 `1`，且只有 `1` 个这样的子串，纯净力恰好为 `1`。

这是最小的边界情况。

### 示例 2

**输入：**

```
6 6
```

**输出：**

```
aaaaaa
```

**说明：**

字符串长度 $L=6$，纯净力 $M=6$，满足 $L=M$。

构造全 `'a'` 字符串 `"aaaaaa"`，所有字符相同，任意子串均不包含两个不同字符，因此最大纯净子串长度为 `1`。长度为 `1` 的纯净子串共有 `6` 个，起始位置分别为 `1~6`，纯净力等于 `6`。

当 $L=M$ 时，全相同字符是最直接的构造。

### 示例 3

**输入：**

```
5 2
```

**输出：**

```
abaaa
```

**说明：**

字符串长度 $L=5$，纯净力 $M=2$，这里 $M < L$。

先交替放置前 $M+1=3$ 个字符，得到 `"aba"`；剩余 $L-(M+1)=2$ 个字符全部用最后一个字符 `'a'` 填充，最终得到 `"abaaa"`。

该字符串中最大纯净子串的长度为 `2`（只有 `'a'` 和 `'b'` 两种字母）。相邻不同字符的对有：位置 `1` 的 `"ab"` 和位置 `2` 的 `"ba"`，共 `2` 个长度为 `2` 的纯净子串。因此纯净力为 `2`，符合要求。

### 示例 4

**输入：**

```
4 3
```

**输出：**

```
abab
```

**说明：**

字符串长度 $L=4$，纯净力 $M=3$，$M < L$ 且 $M+1 = L$。

交替放置前 $M+1=4$ 个字符，得到 `"abab"`，正好用完所有长度。此时相邻不同字符对为：`"ab"`（位置 `1`）、`"ba"`（位置 `2`）、`"ab"`（位置 `3`），共 `3` 个长度为 `2` 的纯净子串。

最大纯净子串的长度为 `2`，数目恰好为 `3`，纯净力等于 $M$。

## 解题思路

### 先把「纯净力」翻译成一个可数的量

纯净子串是字符互不相同的子串，纯净力是**最长那一档**纯净子串的个数（按起始位置计）。所以目标不是单让某一段变长，而是同时控制两件事：最长的纯净子串有多长、这个长度恰好出现在几个起点上。构造必须把「上限」钉死，再让「计数」停在我们想要的位置。

### 关键观察：只用一个字母或两个字母，最长档位就被钉死

- **全用 `'a'`**：任何长度 $\ge 2$ 的子串都有重复字符，最长纯净长度 $=1$；长度为 $1$ 的子串每个起点各一个，共 $L$ 个 → 纯净力 $=L$。
- **只用 `'a'`、`'b'`**：长度 3 的窗口里两个字母要填三个位置，必有一个重复 → 最长纯净长度 $\le 2$；只要存在一对相邻异字符，这个长度就是 $2$。此时「长度 2 的纯净子串」就是「相邻两字符不同的位置」，个数 $=$ 相邻异字符对数。

这两条把纯净力压成了可数的量，而 $M \le L$ 只把输入分成两挡形状：$M=L$ 走第一种，$M<L$ 走第二种。

### $M = L$：全 `'a'`，让每个起点都算最长档

```python
if M == L:
    return "a" * L
```

最长档位是 1，$L$ 个起点个个都贡献一个，计数自然是 $L$。若在这里改用交替串，长度 2 的纯净子串只有 $L-1$ 个（$L$ 个起点里最后一格后面没有邻居），永远差一个。

### $M < L$：交替写 $M+1$ 个字符，尾部抄交替段的收尾

要让相邻异字符对恰好 $M$ 个，最直接的办法是把前 $M+1$ 个位置写成 `abab…`：段内有 $M$ 条相邻边，条条异字符。剩下的 $L-M-1$ 个位置必须**不新增异字符对**，于是全部填交替段最后一个字符——这样边界、尾巴内部都是同字符：

```python
core = ("ab" * ((M + 2) // 2))[:M + 1]   # 长度 M+1 的 abab…
return core + core[-1] * (L - M - 1)     # 尾部与 core 末字符相同
```

`(M + 2) // 2` 正是 $\lceil (M+1)/2 \rceil$：`"ab"` 重复这么多次再切片，正好得到 $M+1$ 个字符。

收尾抄 `core[-1]` 是这处构造的支点：$M$ 为奇数时 `core` 以 `'b'` 结束，若固定补 `'a'`，边界 $(b,a)$ 又多出一个长度 2 的纯净子串，纯净力变成 $M+1$。

头尾是对称的——把填充放在前面、`core` 放在后面同样合法，因为此时边界是 $(a,a)$，而 `core` 总是以 `'a'` 开头：

```python
return "a" * (L - M - 1) + core          # 另一种合法写法
```

填充字符只需与**相邻那一端**的字符相同，这就是两版都成立的原因。

### 为什么 $M \le L$ 时一定有解

两挡覆盖了全部合法输入：$M=L$ 走全 `'a'`，$M<L$ 走交替段加尾部。$M > L$ 时长度为 $L$ 的串只有 $L$ 个起点，纯净力不可能超过 $L$，代码里 `if M > L: return None` 输出 $-1$；按题面约束这条分支不会触发，保留是为了与题面「无法构造输出 $-1$」对应。

时间上也没有更快的余地：输出本身就是 $L$ 个字符，构造与输出同阶，$L \le 10^5$ 时就是一次字符串拼接。

## 完整代码实现

```python
"""
P4759. 纯净之力 - 构造

题面要点：一个字符串的「纯净力」= 把所有字符互不相同的子串按起始位置
计数后，最长的那一波的数量。给 L 和 M，构造长度恰好为 L 的小写串使纯净力
恰好为 M，构造不出输出 -1。

输入：一行两个整数 L M。
输出：合法串或 -1。

核心思路：
1. M = L：全 'a'，最长纯净子串长度 1，个数恰为 L。
2. M < L：交替写 M+1 个字符 'abab…'（相邻字符两两不同），尾部全部填
   交替段的最后一个字符。这样整串只用 'a'/'b' 两个字母：
   - 最长纯净子串长度为 2（三个字符里必有一个重复）；
   - 长度为 2 的纯净子串 = 相邻两字符不同的位置对，交替段贡献 M 个，
     且尾部首字符与交替段末字符相同，边界处不额外产生 → 纯净力 = M。
   尾部字符必须抄交替段末字符，否则 M 为奇数时边界会多出一个 (b,a) 对。

约束给的是 M ≤ L；若 M > L 则不可能，输出 -1。

时间复杂度：O(L)
空间复杂度：O(L)
"""

# https://codefun2000.com/p/P4759
import sys

# @sample-start
"""
样例输入 1:
1 1

样例输出 1:
a
"""
# @sample-end

# @sample-start
"""
样例输入 2:
6 6

样例输出 2:
aaaaaa
"""
# @sample-end

# @sample-start
"""
样例输入 3:
5 2

样例输出 3:
abaaa
"""
# @sample-end

# @sample-start
"""
样例输入 4:
4 3

样例输出 4:
abab
"""
# @sample-end


def build(L, M):
    """返回一个纯净力恰为 M 的长度 L 小写串；无解返回 None。"""
    if M > L:
        return None
    if M == L:
        return "a" * L
    # M < L：交替段 M+1 个字符，尾部抄交替段末字符
    core = ("ab" * ((M + 1 + 1) // 2))[: M + 1]
    return core + core[-1] * (L - M - 1)


def purity(s):
    """按题面定义计算纯净力：最长纯串的数量（按起始位置）。"""
    n = len(s)
    # 以每个起点为始的最长全不同子串长（双指针）
    best = 0
    starts = []
    seen = set()
    left = 0
    for right, ch in enumerate(s):
        while ch in seen:
            seen.discard(s[left])
            left += 1
        seen.add(ch)
        length = right - left + 1
        if length > best:
            best = length
            starts = [left]
        elif length == best:
            starts.append(left)
    return len(starts)


def solve():
    L, M = (int(x) for x in sys.stdin.read().split())
    res = build(L, M)
    sys.stdout.write(res if res is not None else "-1")
    sys.stdout.write("\n")


def run_tests():
    """官方样例 + 构造正确性校验（用 purity 反验每个输出）。"""
    import io

    test_cases = [
        # 官方样例 1~4
        ("1 1\n", "a"),
        ("6 6\n", "aaaaaa"),
        ("5 2\n", "abaaa"),
        ("4 3\n", "abab"),
        # M < L 的奇数 M：边界不能多出 (b,a) 对
        ("6 3\n", "abab" + "b" + "b"),
        # M=1：交替段长度 2
        ("4 1\n", "ab" + "b" + "b"),
        # 极端：M=L=1 与 M=2,L=2
        ("2 2\n", "aa"),
        # M=1, L=2：交替段本身就占满长串
        ("2 1\n", "ab"),
    ]

    for i, (inp, expected) in enumerate(test_cases, 1):
        old_stdin, old_stdout = sys.stdin, sys.stdout
        sys.stdin = io.TextIOWrapper(io.BytesIO(inp.encode("utf-8")))
        sys.stdout = io.StringIO()
        try:
            solve()
            output = sys.stdout.getvalue().strip()
        finally:
            sys.stdin, sys.stdout = old_stdin, old_stdout

        # expected 里写的是构造意图时，用 purity 反验
        if expected is None:
            expected = output
        status = "✓" if output == expected else "✗"
        print(f"样例 {i}: 期望={expected}, 实际={output} {status}")

    # 程序性的通盘校验：对一批 (L, M) 跑 build 并用 purity 复核 = M
    import random

    rng = random.Random(20260328)
    ok = True
    for case in range(500):
        L = rng.randint(1, 60)
        M = rng.randint(1, L)  # 约束里 M ≤ L
        s = build(L, M)
        if s is None or len(s) != L or purity(s) != M:
            ok = False
            print(f"构造失败: L={L} M={M} s={s} purity={None if not s else purity(s)}")
            break
    print(f"随机构造自检 500 组: {'✓' if ok else '✗'}")

    # M > L 无解
    print("M > L:", build(3, 5))


if __name__ == "__main__":
    if len(sys.argv) > 1 and sys.argv[1] == "--test":
        run_tests()
    else:
        solve()

```

## 示例推演

样例 3（$L=5$，$M=2$，$M<L$）：交替段长 $M+1=3$，得 `"aba"`；尾部 $L-M-1=2$ 个 `core[-1]='a'`，拼出 `"abaaa"`。

| 相邻边 | 字符对 | 异字符？ | 累计对数 |
|---|---|---|---|
| 1–2 | `(a,b)` | 是 | 1 |
| 2–3 | `(b,a)` | 是 | 2 |
| 3–4 | `(a,a)` | 否 | 2 |
| 4–5 | `(a,a)` | 否 | 2 |

异字符对共 $2$。三字符窗口 `"aba"`、`"baa"`、`"aaa"` 里都有重复字符，所以最长纯净长度就是 $2$；最长档落在起点 $1$、$2$ 上，纯净力 $=2=M$。

样例 4（$L=4$，$M=3$）：交替段长 $4$ 恰好用满、尾部为空，得到 `"abab"`。三条相邻边全部异字符，对数为 $3$；最长纯净长度 $2$，纯净力 $3$。

奇数 $M$ 的边界：$L=6$、$M=3$。交替段 `"abab"`（4 字符），尾部抄 `'b'` 得 `"ababbb"`：异字符对仍只有段内的 $(1,2)$、$(2,3)$、$(3,4)$ 共 $3$ 个，$(4,5)$、$(5,6)$ 都是 `(b,b)`。若尾部错补 `'a'` 得 `"ababaa"`，$(4,5)$ 的 `(b,a)` 会把纯净力顶到 $4$。

$M=L$ 的边界：$L=6$、$M=6$ 全 `'a'` 得 `"aaaaaa"`，最长纯净长度 $1$，起点 $1\sim6$ 共 $6$ 个；若误走交替分支，`"ababab"` 的异字符对只有 $5$ 个（$L-1$），纯净力凑不到 $6$。

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| ---- | ---------- | ---------- | ---- |
| 搜索长度为 $L$ 的小写串 | $O(26^L \cdot L)$ | $O(L)$ | 构造题的搜索空间；$L$ 到 $10^5$ 时连第一个分支都走不完 |
| 两挡直接构造（最优） | $O(L)$ | $O(L)$ | 交替段加尾部拼接，本题采用；时间已经等于输出的长度 |

## 易错点总结

### 1. 尾部补固定字符，而不是交替段的收尾字符

`core + core[-1] * (L - M - 1)` 里若把 `core[-1]` 写成固定的 `'a'`，$M$ 为奇数时 `core` 以 `'b'` 结尾，边界 $(b,a)$ 会多出一个长度 2 的纯净子串：$L=6, M=3$ 得到 `"ababaa"`，纯净力是 $4$ 而不是 $3$。$M$ 为偶数时 `core` 本来以 `'a'` 结尾，同一个错误不显形——所以这个 bug 只在奇数 $M$ 上暴露。

### 2. `M == L` 的分支漏掉，或写在交替构造之后

`if M == L: return "a" * L` 必须排在 `return core + ...` 前面。漏掉后 $M=L$ 会走交替分支：$L=6, M=6$ 得到 `"ababab"`，异字符对只有 $5$ 个，输出的是一个纯净力 $L-1$ 的串。样例 2（`6 6`）就是这条输入，`aaaaaa` 与 `ababab` 的差别一眼可见。

## 扩展思考

- "把目标量恰好做成 $M$，同时不许其它更强指标冒头"是构造题的通式：本题靠把字符表压到两枚、让更强的指标（长度 3+ 的纯净子串）在结构上不可能出现来锁定上限。
- 若字母表允许更多字母，构造手段更多（三种字母就能造长度 3 的纯净段），但"数量恰好"的约束同样要求人为制造重复——设计重复，比避开重复更难。
