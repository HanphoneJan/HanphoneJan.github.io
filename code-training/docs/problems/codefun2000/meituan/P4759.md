# P4759. 纯净之力

> 场次：2026年4月11日-开发岗 · 来源：[CodeFun2000 P4759](https://codefun2000.com/p/P4759)

## 题目描述

定义一个由小写字母组成的字符串的纯净子串为：所有字符互不相同的子串。
字符串的纯净力定义为：该字符串中长度最大的纯净子串的数量（按起始位置计数，不同起始位置视为不同子串）。

现在给定两个正整数 $L$ 和 $M$，请你构造一个长度恰好为 $L$ 的、仅由小写字母组成的字符串，使其纯净力恰好等于 $M$。如果无法构造，请输出 $-1$。

数据范围：$L$ 不超过 $10^5$，$M$ 不超过 $L$，所有数均为正整数。

## 输入格式

输入仅一行，包含两个整数 $L$ 和 $M$，中间用空格隔开。

## 输出格式

若存在满足要求的字符串，输出该字符串；否则输出 $-1$。答案不唯一时，输出任意一个合法字符串即可。

## 示例

### 示例 1

**输入：**

```
1 1
```

**输出：**

```
a
```

**说明：**

字符串长度 $L=1$，纯净力要求 $M=1$，此时 $L=M$。

构造全 `'a'` 字符串 `"a"`，其所有子串均为 `"a"`，最大纯净子串长度为 `1`，且只有 `1` 个这样的子串，纯净力恰好为 `1`。

这是最小的边界情况。

### 示例 2

**输入：**

```
6 6
```

**输出：**

```
aaaaaa
```

**说明：**

字符串长度 $L=6$，纯净力 $M=6$，满足 $L=M$。

构造全 `'a'` 字符串 `"aaaaaa"`，所有字符相同，任意子串均不包含两个不同字符，因此最大纯净子串长度为 `1`。长度为 `1` 的纯净子串共有 `6` 个，起始位置分别为 `1~6`，纯净力等于 `6`。

当 $L=M$ 时，全相同字符是最直接的构造。

### 示例 3

**输入：**

```
5 2
```

**输出：**

```
abaaa
```

**说明：**

字符串长度 $L=5$，纯净力 $M=2$，这里 $M < L$。

先交替放置前 $M+1=3$ 个字符，得到 `"aba"`；剩余 $L-(M+1)=2$ 个字符全部用最后一个字符 `'a'` 填充，最终得到 `"abaaa"`。

该字符串中最大纯净子串的长度为 `2`（只有 `'a'` 和 `'b'` 两种字母）。相邻不同字符的对有：位置 `1` 的 `"ab"` 和位置 `2` 的 `"ba"`，共 `2` 个长度为 `2` 的纯净子串。因此纯净力为 `2`，符合要求。

### 示例 4

**输入：**

```
4 3
```

**输出：**

```
abab
```

**说明：**

字符串长度 $L=4$，纯净力 $M=3$，$M < L$ 且 $M+1 = L$。

交替放置前 $M+1=4$ 个字符，得到 `"abab"`，正好用完所有长度。此时相邻不同字符对为：`"ab"`（位置 `1`）、`"ba"`（位置 `2`）、`"ab"`（位置 `3`），共 `3` 个长度为 `2` 的纯净子串。

最大纯净子串的长度为 `2`，数目恰好为 `3`，纯净力等于 $M$。

---

## 解题思路

### 两挡答案：最长纯串要么 1 要么 2

纯净力是"最长纯净子串"（字符互不相同）按起始位置计的数量。构造只用两个字母就够：**只有 'a'、'b' 两种字符时，长度为 3 的窗口必有两个字符相同**，所以任何两字母串的最长纯净子串长度不超过 $2$；相邻字符一旦不同，这个长度就是 $2$，且"长度为 2 的纯净子串个数"恰好等于**相邻字符不同的位置对数**。

于是按 $M$ 与 $L$ 的关系分两挡：

- $M = L$：受不了长度 $2$ 的纯净子串超过个数，直接全 'a'（`"a" * L`）。最长纯净子串长度 $1$，个数恰为 $L$。
- $M < L$：前 $M+1$ 个字符交替 `abab…`，产生恰好 $M$ 个相邻异字符对；尾部全部填**交替段的最后一个字符**。两字母保证没有长度 $3$ 以上的纯净子串，尾部首字符与交替段末字符相同保证边界上不再多出一对，纯净力恰为 $M$。

尾部字符必须"抄"交替段的收尾——$M$ 为奇数时交替段以 'b' 结尾，若还是补 'a'，边界 $(b, a)$ 又多出一个长度 2 的纯净子串，纯净力变成 $M+1$。

约束给的是 $M \le L$；若输入越过这条线（$M > L$），长度 $L$ 的串连 $M$ 那么多的起位都摆不下，直接输出 $-1$。

实现上交替段直接 `("ab" * ((M + 1 + 1) // 2))[: M + 1]` 裁出，尾部用 `core[-1]` 复制；都不依赖任何查找或回溯。

## 完整代码实现

```python
"""
P4759. 纯净之力 - 构造

题面要点：一个字符串的「纯净力」= 把所有字符互不相同的子串按起始位置
计数后，最长的那一波的数量。给 L 和 M，构造长度恰好为 L 的小写串使纯净力
恰好为 M，构造不出输出 -1。

输入：一行两个整数 L M。
输出：合法串或 -1。

核心思路：
1. M = L：全 'a'，最长纯净子串长度 1，个数恰为 L。
2. M < L：交替写 M+1 个字符 'abab…'（相邻字符两两不同），尾部全部填
   交替段的最后一个字符。这样整串只用 'a'/'b' 两个字母：
   - 最长纯净子串长度为 2（三个字符里必有一个重复）；
   - 长度为 2 的纯净子串 = 相邻两字符不同的位置对，交替段贡献 M 个，
     且尾部首字符与交替段末字符相同，边界处不额外产生 → 纯净力 = M。
   尾部字符必须抄交替段末字符，否则 M 为奇数时边界会多出一个 (b,a) 对。

约束给的是 M ≤ L；若 M > L 则不可能，输出 -1。

时间复杂度：O(L)
空间复杂度：O(L)
"""

# https://codefun2000.com/p/P4759
import sys

# @sample-start
"""
样例输入 1:
1 1

样例输出 1:
a
"""
# @sample-end

# @sample-start
"""
样例输入 2:
6 6

样例输出 2:
aaaaaa
"""
# @sample-end

# @sample-start
"""
样例输入 3:
5 2

样例输出 3:
abaaa
"""
# @sample-end

# @sample-start
"""
样例输入 4:
4 3

样例输出 4:
abab
"""
# @sample-end


def build(L, M):
    """返回一个纯净力恰为 M 的长度 L 小写串；无解返回 None。"""
    if M > L:
        return None
    if M == L:
        return "a" * L
    # M < L：交替段 M+1 个字符，尾部抄交替段末字符
    core = ("ab" * ((M + 1 + 1) // 2))[: M + 1]
    return core + core[-1] * (L - M - 1)


def purity(s):
    """按题面定义计算纯净力：最长纯串的数量（按起始位置）。"""
    n = len(s)
    # 以每个起点为始的最长全不同子串长（双指针）
    best = 0
    starts = []
    seen = set()
    left = 0
    for right, ch in enumerate(s):
        while ch in seen:
            seen.discard(s[left])
            left += 1
        seen.add(ch)
        length = right - left + 1
        if length > best:
            best = length
            starts = [left]
        elif length == best:
            starts.append(left)
    return len(starts)


def solve():
    L, M = (int(x) for x in sys.stdin.read().split())
    res = build(L, M)
    sys.stdout.write(res if res is not None else "-1")
    sys.stdout.write("\n")


def run_tests():
    """官方样例 + 构造正确性校验（用 purity 反验每个输出）。"""
    import io

    test_cases = [
        # 官方样例 1~4
        ("1 1\n", "a"),
        ("6 6\n", "aaaaaa"),
        ("5 2\n", "abaaa"),
        ("4 3\n", "abab"),
        # M < L 的奇数 M：边界不能多出 (b,a) 对
        ("6 3\n", "abab" + "b" + "b"),
        # M=1：交替段长度 2
        ("4 1\n", "ab" + "b" + "b"),
        # 极端：M=L=1 与 M=2,L=2
        ("2 2\n", "aa"),
        # M=1, L=2：交替段本身就占满长串
        ("2 1\n", "ab"),
    ]

    for i, (inp, expected) in enumerate(test_cases, 1):
        old_stdin, old_stdout = sys.stdin, sys.stdout
        sys.stdin = io.TextIOWrapper(io.BytesIO(inp.encode("utf-8")))
        sys.stdout = io.StringIO()
        try:
            solve()
            output = sys.stdout.getvalue().strip()
        finally:
            sys.stdin, sys.stdout = old_stdin, old_stdout

        # expected 里写的是构造意图时，用 purity 反验
        if expected is None:
            expected = output
        status = "✓" if output == expected else "✗"
        print(f"样例 {i}: 期望={expected}, 实际={output} {status}")

    # 程序性的通盘校验：对一批 (L, M) 跑 build 并用 purity 复核 = M
    import random

    rng = random.Random(20260328)
    ok = True
    for case in range(500):
        L = rng.randint(1, 60)
        M = rng.randint(1, L)  # 约束里 M ≤ L
        s = build(L, M)
        if s is None or len(s) != L or purity(s) != M:
            ok = False
            print(f"构造失败: L={L} M={M} s={s} purity={None if not s else purity(s)}")
            break
    print(f"随机构造自检 500 组: {'✓' if ok else '✗'}")

    # M > L 无解
    print("M > L:", build(3, 5))


if __name__ == "__main__":
    if len(sys.argv) > 1 and sys.argv[1] == "--test":
        run_tests()
    else:
        solve()

```

## 示例推演

样例 3：$L = 5$，$M = 2$。交替段长 $M+1 = 3$，是 `"aba"`；尾部 $L - M - 1 = 2$ 个 `core[-1] = 'a'`，拼出 `"abaaa"`。相邻异字符对：$(1,2)$ 的 `"ab"`、$(2,3)$ 的 `"ba"`，共 $2$ 个；$(3,4)$、$(4,5)$ 都是 `(a,a)`，不计。最长纯净长度：三字符窗口 `"aba"` 内 $a$ 重复，所以最长的就是 $2$，纯净力 $= 2 = M$。

样例 4：$L = 4$，$M = 3$，交替段长 $4$ 恰好用满，`"abab"`，异字符对 $(1,2), (2,3), (3,4)$ 共 $3$ 个，纯净力 $3$。

奇数 $M$ 的边界：$L = 6$，$M = 3$。交替段 `"abab"`（4 字符），尾部抄 `'b'` 得 `"ababbb"`：异字符对仍只有段内的 $(1,2), (2,3), (3,4)$ 共 $3$；若尾部错补 `'a'` 得 `"ababaa"`，$(4,5)$ 的 $(b, a)$ 会把纯净力顶到 $4$。

$M = L$ 的边界：$L = 6$，$M = 6$ 全 'a' 得 `"aaaaaa"`，最长纯净子串长 $1$、个数 $6$；若误走交替分支，`"ababab"` 的纯净力只有 $5$（异字符对数 $= L - 1$），凑不到 $6$。

## 易错点总结

### 1. 尾部补字符不抄交替段收尾

$M$ 为奇数时交替段以 'b' 收尾，尾部若固定补 'a'，边界 $(b, a)$ 额外产生一个长度 2 的纯净子串，纯净力从 $M$ 顶到 $M+1$。`core[-1] * (L - M - 1)` 这一行的"抄收尾"是构造正确性的隐形条件；用 $L=6, M=3$ 对照 `"ababbb"` 与 `"ababaa"` 即可验证。

### 2. $M = L$ 时误走交替分支

交替长 $L$ 的异字符对只有 $L - 1$ 个，永远差 $1$；只有全 'a' 把最长纯净长度压到 $1$ 才能让个数等于 $L$。`if M == L: return "a" * L` 的提前返回必须在交替分支之前；漏掉后 $M = L$ 的输入会稳定输出"纯净力 $= L - 1$"的串（如 $L=6, M=6$ 时 `"ababab"` 只有 $5$）。

## 扩展思考

- "把目标量恰好做成 $M$，同时不许其它更强指标冒头"是构造题的通式：本题靠把字符表压到两枚、让更强的指标（长度 3+ 的纯净子串）在结构上不可能出现来锁定上限。
- 若字母表允许更多字母，构造手段更多（三种字母就能造长度 3 的纯净段），但"数量恰好"的约束同样要求人为制造重复——设计重复，比避开重复更难。
