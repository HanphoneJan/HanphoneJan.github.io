# P4916. 最少生产批次

> 场次：2026年5月9日-开发岗 · 来源：[CodeFun2000 P4916](https://codefun2000.com/p/P4916)

## 题目描述

工厂需要处理 $n$ 个精密零件，每个零件都有一个参数值。在开始分配之前，你可以对这些零件进行任意重新排序。

你需要将所有零件分配到若干个生产批次中。每个批次至少包含 $1$ 个零件，至多包含 $K$ 个零件。对于一个恰好包含 $t$ 个零件的批次，记该批次中零件参数的最大值为 $M$，最小值为 $m$，则必须满足

$$M - m \le D + E \times (t-1)$$

每个零件必须且只能属于一个批次。你的目标是使用尽可能少的批次来处理所有零件，请计算最少需要的批次数。

所有测试数据中，$n$ 的总和不超过 $2 \times 10^5$。$D, E$ 的取值范围均为 $0$ 到 $10^9$。$K$ 的取值范围为 $1$ 到 $n$。所有零件的参数均为不超过 $10^9$ 的非负整数。

## 输入格式

第一行包含一个整数 $T$ ($1 \le T \le 10^5$)，表示测试数据组数。
接下来每组测试数据按以下格式给出：
第一行包含四个整数 $n, D, E, K$ ($1 \le n \le 2 \times 10^5$，$0 \le D, E \le 10^9$，$1 \le K \le n$)，含义如上述。
第二行包含 $n$ 个整数，表示每个零件的参数（均为不超过 $10^9$ 的非负整数）。

## 输出格式

对于每组测试数据，输出一行一个整数，表示最少需要的批次数。

## 示例

### 示例 1

**输入：**

```
1
5 0 0 2
1 1 2 2 2
```

**输出：**

```
3
```

**说明：**

将零件排序后为 `[1, 1, 2, 2, 2]`。
由于 $D=0, E=0$，条件变为 $M - m \le 0$，即每批内部所有零件参数必须完全相同。每批最多包含 $K=2$ 个零件。
`1` 有 `2` 个，正好组成一批；`2` 有 `3` 个，最多每批 `2` 个，因此至少需要两批（例如一批两个 `2`，另一批一个 `2`）。总共至少需要 `3` 批，这也是可以达到的最优方案。

### 示例 2

**输入：**

```
1
4 5 2 3
10 12 15 20
```

**输出：**

```
2
```

**说明：**

排序后的序列为 `[10, 12, 15, 20]`。
由于 $K=3$，所有 `4` 个零件无法放入同一个批次。
考察一种合法分批：
- 第一批 `[10, 12, 15]`：包含 $t=3$ 个零件，最大值与最小值之差 $M-m = 15-10 = 5$，条件要求 $5 \le D + E \times (t-1) = 5 + 2 \times 2 = 9$，满足。
- 第二批 `[20]`：$t=1$，$M-m=0$，自然满足。
因此 `2` 批即可完成。由于不可能用 `1` 批完成（零件数超过 $K$），最小批次数为 `2`。

### 示例 3

**输入：**

```
1
6 2 1 4
3 5 6 10 12 13
```

**输出：**

```
2
```

**说明：**

零件排序后为 `[3, 5, 6, 10, 12, 13]`。
约束为 $D=2, E=1, K=4$。
一种最优方案：
- 第一批 `[3, 5, 6]`：$t=3$，$M-m=3$，需满足 $3 \le 2 + 1 \times 2 = 4$，合法。
- 第二批 `[10, 12, 13]`：$t=3$，$M-m=3$，同样合法。
总批次数为 `2`。
若尝试用更多零件组成一批，例如 `[3, 5, 6, 10]`，则 $t=4$，$M-m=7$，条件 $7 \le 2 + 1 \times 3 = 5$ 不满足；且无法在一批内放下所有零件（$K=4$ 但极差超限）。因此最少批次为 `2`。

### 示例 4

**输入：**

```
1
1 10 10 1
100
```

**输出：**

```
1
```

**说明：**

只有一个零件，参数为 `100`。
该零件必须单独构成一个批次，且该批次显然满足任何 $D, E, K$ 约束。最小批次数即为 `1`。

## 解题思路

### 一、一批是否合法只由「两端 + 个数」决定

输出只有一个整数：最少批次数。而一批是否合法，只看三个量：这批的最小值 $m$、最大值 $M$、零件个数 $t$，要求

$$M - m \le D + E \times (t-1), \qquad 1 \le t \le K.$$

中间那些零件具体取多大完全不进入判定。这一点决定了后面的所有简化：一个批次可以被压缩成「排序数组上的一段区间加上它的长度」。

### 二、排序后可以只看连续分段

题目允许在分配前任意重排，所以先排序。排序之后有一条结构性结论（标准的交换论证）：**存在一个最优方案，每一批恰好是排序数组上连续的一段。**

直观理由：如果两批的取值在大小上交错——一批同时含很小的值和很大的值，而中间的值被另一批拿走——把这两批的零件并起来、按大小重新切成连续的两段，不会让批次数变多，也不会让某一批的极差超出它按个数能拿到的额度。反复消除交错，就得到连续分段的方案。于是只需考虑「把有序数组切成若干连续段」这一族方案。

这一步把问题变成：把排序后的数组 $a_0 \le a_1 \le \dots \le a_{n-1}$ 切成若干连续段，每段长度不超过 $K$，且极差不超过 $D + E(t-1)$，求最少段数。代码第 48 行的 `values.sort()` 就是利用「可以任意重排」。

### 三、把长度从极差条件里消掉：令 $b_x = a_x - E \cdot x$

设一段是下标 $[j, i-1]$，长度 $t = i-j$。合法性是

$$a_{i-1} - a_j \le D + E(i-1-j).$$

把含 $i$ 的项和含 $j$ 的项分开：

$$a_{i-1} - E(i-1) \le a_j - E j + D.$$

令 $b_x = a_x - E \cdot x$，条件就变成

$$b_j \ge b_{i-1} - D.$$

原来「跨度加长度」两个量，现在只剩一个逐下标算出的 $b$ 值：长度约束只体现为下标窗口 $j \ge i-K$，极差约束只体现为 $b$ 的一个下界。代码第 51 行一次算出整个 $b$ 数组。

要注意 $b$ 并不随下标单调：$a$ 相邻两项的差可能小于 $E$，$b$ 就会上下起伏。正因如此，后面不能简单地用双指针收缩。

### 四、DP 的两个条件：位置窗口按时间过期，$b$ 阈值按值过滤

定义 $f[i]$ 为前 $i$ 个零件的最少批次数，$f[0]=0$。枚举最后一段的起点 $j$：

$$f[i] = 1 + \min\{\, f[j] \;:\; \max(0, i-K) \le j \le i-1,\; b_j \ge b_{i-1} - D \,\}.$$

为什么不能贪心？因为 $f$ 不是单调的。取 $a=[3,17,19,23,26]$、$D=5$、$E=7$、$K=3$：前两个零件极差 $14 > 5$，要 2 批；再加进 19 后长度变成 3，额度涨到 $5+7\times 2=19$，极差 16 反而能装进一批，于是 $f[2]=2$ 而 $f[3]=1$。同一组数据在 $i=5$ 时，最早能接上的合法前驱是 $j=2$（$f[2]=2$，得 3 批），最优前驱却是 $j=3$（$f[3]=1$，得 2 批）。所以每一步都必须在「窗口内且 $b$ 达标」的所有 $j$ 里取真正的最小值，既不能只看最靠左的合法前驱，也不能只看窗口里 $f$ 最小的那个（它可能 $b$ 不达标）。

实现上要同时处理两个条件：

- 位置条件 $j \in [i-K, i-1]$ 是滑动窗口：循环开始前插入下标 0；第 $i$ 步先把 $i-K-1$ 过期（若不小于 0），本步结束时再插入 $i$（第 137–149 行）；
- 值条件 $b_j \ge b_{i-1}-D$ 是对 $b$ 的后缀过滤：把 $b$ 离散化后，查询「$b$ 的排名不小于某个下界的所有下标中的最小 $f$」（第 143–145 行）。

两者合起来用一棵值域线段树：叶子 $r$ 表示「$b$ 恰好等于第 $r$ 小的不同值」，存当前窗口里该值的所有下标的 $\min f$；内部结点存子树最小值，于是查询就是后缀最小值。

每个叶子上的下标按位置先后进入、按位置先后过期，是一个 FIFO 队列，所以每个叶子挂一个单调队列：新下标进来时从队尾弹掉 $f$ 不比它小的旧下标（旧下标更早过期、$f$ 又更大，之后不可能再赢），过期时从队头弹出已经出窗的下标，队头就是该叶子的当前最小值（第 88–115 行）。每次插入或过期只摊还 $O(1)$ 次队列操作，外加一次线段树更新 $O(\log n)$；每次查询 $O(\log n)$。

为什么是这个算法：所有组的 $n$ 之和不超过 $2\times 10^5$，而 $K$ 最大可以等于 $n$。朴素地枚举窗口内每个 $j$ 是 $O(nK)$，最坏约 $2\times 10^{10}$ 次比较，必然超时；$O(n\log n)$ 在总规模 $2\times 10^5$ 上很宽裕。

## 完整代码实现

```python
"""
P4916. 最少生产批次 - 排序分段 DP（阈值变换 + 值域线段树）

n 个零件参数可以任意重排；批次数最少。每批 t 个零件允许的最大极差为
D + E*(t-1)，且每批至多 K 个。

核心思路：
1. 一个批次只关心它的最小值、最大值和零件个数，与中间零件无关；又因为
   可以任意重排，最优方案总可以调整为排序数组上的连续分段（若两批交叉，
   交换交叉的零件只会让两批的极差同时变小或不变）。
2. 排序后设 a[0..n-1]。批量 [i, j]（0 基、含端点）合法当且仅当
   length = j-i+1 <= K 且 a[j] - a[i] <= D + E*(j-i)。令 b[x] = a[x] - E*x，
   第二条变成 b[j] - b[i] <= D：
       a[j] - E*j <= a[i] - E*i + D
   极差约束被压成同一坐标系下两个标尺值之差，长度约束只是下标上下限。
3. 设 f[i] 为前 i 个零件（排序后）的最少批次数，f[0] = 0：
       f[i] = 1 + min{ f[j] : max(0, i-K) <= j <= i-1 且 b[j] >= b[i-1] - D }
   注意 f 不单调：E>0 时从批次尾部删件，极差变小但允许额度 D+E*(t-1) 也
   缩水，前缀可行性不保持（如 3,17,19,23,26 在 D=5,E=7,K=3 下 f[3]=1 而
   f[2]=2）。所以每一步都要在「滑动窗口 ∩ b 达标」这批下标里取真的最小值。
4. 窗口按位置 FIFO 过期（每步恰好过期一个 p = i-K-1），达标条件是对 b 值的
   下确界过滤。做法：把 b 压缩到值域，每格值域叶子挂一个按位置进队的单调
   队列（队头是叶内现行最小 f，过期即从队头弹出），值域线段树维护各叶子
   最小值；查询就是 b 值 >= 阈值那段后缀的最小值。每步 1 插入 + 1 过期 +
   1 查询，各 O(log n)。

输入格式：
- 第 1 行：T；
- 每组：第一行 n、D、E、K；第二行 n 个零件参数。

输出格式：
- 每组一行一个整数：最少批次数。

时间复杂度：单组 O(n log n)
空间复杂度：O(n)
"""

# https://codefun2000.com/p/P4916
import io
import sys
from bisect import bisect_left

INF = float("inf")


def min_batches(values, big_d, e, k):
    """排序后做分段 DP，返回最少批次数。"""
    values.sort()
    n = len(values)
    # b[x] = a[x] - E*x：把 "极差 <= D + E*(t-1)" 变成 "b[j] - b[i] <= D"
    b = [values[i] - e * i for i in range(n)]

    uniq = sorted(set(b))
    u = len(uniq)
    rank = {}
    for idx, val in enumerate(uniq):
        rank[val] = idx
    rk = [rank[x] for x in b]

    # 值域线段树：叶子 r 存「b 值恰好为 uniq[r] 且仍在窗口里的下标」的最小 f。
    size = 1
    while size < u:
        size <<= 1
    tree = [INF] * (2 * size)

    # 每个值域叶子一个单调队列：队列内 (下标, f) 按 f 从队头到队尾递增；
    # 插入时从队尾弹掉 f 更大（且更早过期）的元素，过期从队头弹出。
    queues = [None] * u
    heads = [0] * u

    def set_leaf(r, val):
        """更新值域叶子并向上维护最小值。"""
        pos = size + r
        if tree[pos] == val:
            return
        tree[pos] = val
        pos >>= 1
        while pos:
            new_min = tree[pos + pos]
            right = tree[pos + pos + 1]
            if right < new_min:
                new_min = right
            if tree[pos] == new_min:
                break
            tree[pos] = new_min
            pos >>= 1

    def insert(j, r, fv):
        """下标 j 进入窗口：挂到值域叶子 r 的单调队列。"""
        q = queues[r]
        if q is None:
            q = queues[r] = []
        while len(q) > heads[r] and q[-1][1] >= fv:
            q.pop()
        q.append((j, fv))
        set_leaf(r, q[heads[r]][1])

    def expire(j, step):
        """窗口左沿越过下标 j：回到值域叶子，弹出所有已过期队头。"""
        r = rk[j]
        q = queues[r]
        if q is None:
            return
        h = heads[r]
        deadline = j + k + 1
        # 队头按位置从早到晚，若它过期于当前 step 之前则弹出
        while len(q) > h and q[h][0] + k + 1 <= step:
            h += 1
        heads[r] = h
        if len(q) > h:
            set_leaf(r, q[h][1])
        else:
            # 该叶子现行下标全部出窗
            if tree[size + r] != INF:
                set_leaf(r, INF)

    def suffix_min(r):
        """b 值下标 >= r 的窗口内最小 f。"""
        res = INF
        lo = size + r
        hi = size + u - 1
        while lo < hi:
            if lo & 1:
                if tree[lo] < res:
                    res = tree[lo]
                lo += 1
            if hi & 1:
                hi -= 1
                if tree[hi] < res:
                    res = tree[hi]
            lo >>= 1
            hi >>= 1
        if lo == hi and tree[lo] < res:
            res = tree[lo]
        return res

    f = [0] * (n + 1)
    insert(0, rk[0], 0)  # 空前缀：整段作为最后一批，代价 0
    for i in range(1, n + 1):
        expired = i - k - 1
        if expired >= 0:
            expire(expired, i)
        threshold = b[i - 1] - big_d
        r = bisect_left(uniq, threshold)
        best = suffix_min(r)  # i-1 本身必达标，best 一定是有限值
        f[i] = best + 1
        if i < n:
            insert(i, rk[i], f[i])
    return f[n]


def solve():
    data = sys.stdin.buffer.read().split()
    it = iter(data)
    t = int(next(it))
    out = []
    for _ in range(t):
        n = int(next(it))
        big_d = int(next(it))
        e = int(next(it))
        k = int(next(it))
        values = [int(next(it)) for _ in range(n)]
        out.append(str(min_batches(values, big_d, e, k)))
    sys.stdout.write("\n".join(out) + "\n")


def run_tests():
    """运行嵌入的样例、边界用例，并用暴力区间 DP 对拍随机数据。"""
    import random

    test_cases = [
        # 官方样例 1：D=E=0 -> 每批必须全等，且每批至多 K=2 个
        ("1\n5 0 0 2\n1 1 2 2 2\n", "3"),
        # 官方样例 2：K=3 放不下 4 个，拆成 [10,12,15] 与 [20]
        ("1\n4 5 2 3\n10 12 15 20\n", "2"),
        # 官方样例 3：两段各 3 个
        ("1\n6 2 1 4\n3 5 6 10 12 13\n", "2"),
        # 官方样例 4：单零件必为一批
        ("1\n1 10 10 1\n100\n", "1"),
        # K=1：每批只能 1 个
        ("1\n3 5 5 1\n1 2 3\n", "3"),
        # E 很大：长批的极差额度随之变大，能一路合并
        ("1\n5 0 100 5\n1 100 200 300 400\n", "1"),
        # D > 极差且 K 够：全部一批
        ("1\n4 1000 0 4\n5 7 9 11\n", "1"),
        # 极差恰好压线：D + E*(t-1) 与极差相等也算合法
        ("1\n3 2 3 3\n0 2 8\n", "1"),
        # 回归用例：f 不单调，贪"最左合法前驱"会得 3，正解 2
        ("1\n5 5 7 3\n3 23 19 26 17\n", "2"),
        # 同上另一组：前缀不可分的 1 批被第 3 个救回来
        ("1\n3 0 3 3\n0 5 6\n", "1"),
    ]

    for i, (inp, expected) in enumerate(test_cases, 1):
        old_stdin, old_stdout = sys.stdin, sys.stdout
        sys.stdin = io.TextIOWrapper(io.BytesIO(inp.encode("utf-8")))
        sys.stdout = io.StringIO()
        try:
            solve()
            output = sys.stdout.getvalue().strip()
        finally:
            sys.stdin, sys.stdout = old_stdin, old_stdout

        status = "✓" if output == expected else "✗"
        print(f"样例 {i}: 期望={expected}, 实际={output} {status}")

    # 暴力对拍：区间 DP 直接用原始条件 a[j]-a[i] <= D + E*(j-i)
    def brute(values, big_d, e, k):
        v = sorted(values)
        n = len(v)
        f = [10 ** 9] * (n + 1)
        f[0] = 0
        for i in range(1, n + 1):
            for j in range(max(0, i - k), i):
                if v[i - 1] - v[j] <= big_d + e * (i - 1 - j):
                    if f[j] + 1 < f[i]:
                        f[i] = f[j] + 1
        return f[n]

    random.seed(20261027)
    fail = None
    for case_no in range(1, 4001):
        n = random.randint(1, 12)
        values = [random.randint(0, 30) for _ in range(n)]
        big_d = random.choice([0, 0, 1, 2, 3, 5, 10])
        e = random.choice([0, 0, 1, 2, 3, 7, 20])
        k = random.randint(1, n)
        got = min_batches(values[:], big_d, e, k)
        want = brute(values, big_d, e, k)
        if got != want:
            fail = (values, big_d, e, k, want, got)
            break
    print("暴力对拍 4000 组随机数据：" + ("全部一致" if fail is None else f"失败 {fail}"))
    if fail is not None:
        return

    # 极端规模走一遍，确认没有死循环/性能塌方（不核对数值）
    big_values = [(i * 37) % 10 ** 9 for i in range(200000)]
    big_values[0] = 10 ** 9
    res = min_batches(big_values, 10 ** 9, 1, 99999)
    print(f"极端规模 n=200000 跑通，结果={res}")


if __name__ == "__main__":
    if len(sys.argv) > 1 and sys.argv[1] == "--test":
        run_tests()
    else:
        solve()
```

## 示例推演

用官方样例 3：$n=6$，$D=2$，$E=1$，$K=4$，排序后 $a=[3,5,6,10,12,13]$。先算 $b_x = a_x - x$，得到 $b=[3,4,4,7,8,8]$。窗口要求 $j \ge i-4$，阈值是 $b_{i-1}-2$。

| $i$ | 窗口内 $j$ | 阈值 | 达标的 $j$（$b_j$, $f[j]$） | 最小 $f[j]$ | $f[i]$ | 最后一段 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | 0 | 1 | 0（3, 0） | 0 | 1 | `[3]` |
| 2 | 0, 1 | 2 | 0（3, 0）、1（4, 1） | 0 | 1 | `[3, 5]` |
| 3 | 0, 1, 2 | 2 | 0（3, 0）、1（4, 1）、2（4, 1） | 0 | 1 | `[3, 5, 6]` |
| 4 | 0, 1, 2, 3 | 5 | 只有 3（7, 1） | 1 | 2 | `[10]` |
| 5 | 1, 2, 3, 4（0 过期） | 6 | 3（7, 1）、4（8, 2） | 1 | 2 | `[10, 12]` |
| 6 | 2, 3, 4, 5（1 过期） | 6 | 3（7, 1）、4（8, 2）、5（8, 2） | 1 | 2 | `[10, 12, 13]` |

逐步核对每一段是否合法：

- $i=1$：单零件，极差 0，合法；
- $i=2$：$a_1-a_0=2 \le 2+1\times 1=3$，合法；
- $i=3$：$a_2-a_0=3 \le 2+1\times 2=4$，合法；
- $i=4$：窗口里 $j=0,1,2$ 的 $b$ 值分别是 3、4、4，都小于阈值 5，被过滤掉。只能从 $j=3$ 开新段，$f[4]=f[3]+1=2$。这一步最能说明「位置在窗口里」不等于「极差达标」：下标 0 到 3 的距离只有 3，长度完全够，但 $10-3=7$ 超过了 $2+1\times 3=5$；
- $i=5$：$j=0$ 已出窗（长度会是 5，超过 $K=4$）。在剩下的 $j$ 里，$j=3$ 对应段 `[10,12]`，极差 $2 \le 2+1=3$，合法，$f[5]=f[3]+1=2$；
- $i=6$：$j=1$ 出窗。选 $j=3$ 得段 `[10,12,13]`，极差 $3 \le 2+1\times 2=4$，合法，$f[6]=f[3]+1=2$。

答案 $f[6]=2$，与示例输出一致，对应分批 `[3,5,6]` 和 `[10,12,13]`。另外两组可以快速核对：样例 2 中 $K=3$ 装不下 4 个零件，答案至少 2，而 `[10,12,15]` 与 `[20]` 正好达到 2；样例 4 只有一个零件，$f[1]=1$。

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| ---- | ---------- | ---------- | ---- |
| 按定义枚举前驱的区间 DP | $O(nK)$，最坏 $O(n^2)$ | $O(n)$ | 每步扫窗口内全部 $j$；$K=n$ 时约 $2\times 10^{10}$ 次比较 |
| 排序 + 阈值变换 + 线段树（最优） | $O(n\log n)$ | $O(n)$ | 排序后每步一次插入、一次过期、一次后缀查询，各 $O(\log n)$ |

单组的主要开销是 $O(n\log n)$ 的排序；线段树建树 $O(u)$（$u \le n$ 是不同 $b$ 值的个数），每个下标最多入队一次、出队一次。按 $\sum n \le 2\times 10^5$ 计算，总操作量在千万级以内。

## 易错点总结

### 1. 窗口过期写得太晚，长度为 $K+1$ 的批次会混进来

第 140 行的 `expired = i - k - 1` 是「第 $i$ 步必须已经离开窗口的最大下标」。合法前驱要求 $j \ge i-K$，所以 $i-K-1$ 必须过期。把它改成 `i - k - 2`（过期得太晚），$j=i-K-1$ 会继续留在树里，程序就允许长度 $K+1$ 的段：样例 1（$K=2$，`1 1 2 2 2`）会输出 2 而不是 3，因为三个 2 被塞进了同一批；样例 2（$K=3$，四个零件）更会把全部零件塞进一批，输出 1 而不是 2。

### 2. 阈值方向写反，$D>0$ 时第一步就无解

第 143–144 行是 `threshold = b[i-1] - D` 配合 `bisect_left`。把减号写成加号后，条件变成 $b_j \ge b_{i-1}+D$，而 $D>0$ 时连 $j=i-1$ 自己都达不到这个下界，`best` 取到 `INF`，`f[i]` 变成 `inf`。样例 2（$D=5$）第一步就会输出 `inf`，而不是 2。若把 `bisect_left` 换成 `bisect_right`，恰好等于阈值的下标会被排除，$D=0$ 时同样连 $j=i-1$ 都取不到，样例 1 会输出 `inf`。

### 3. 用「最早合法前驱」代替后缀最小值，$f$ 非单调时会多算一批

第 145 行 `best = suffix_min(r)` 取的是所有达标前驱里 $f$ 的最小值。若按直觉从窗口左端往右找第一个合法 $j$ 就停（让最后一段尽量长），在 $a=[3,17,19,23,26]$、$D=5$、$E=7$、$K=3$ 上，$i=5$ 找到的第一个合法前驱是 $j=2$、$f[2]=2$，得到 3 批；正确选择是 $j=3$、$f[3]=1$，得到 2 批。原因就是加进 19 后额度涨得比极差快，短前缀反而批次数更少。

## 扩展思考

- $E=0$ 时 $b_x = a_x$ 随下标单调不减，$b_j \ge b_{i-1}-D$ 等价于一个随 $i$ 单调右移的下标边界，滑动窗口最小值就够，可以做到 $O(n)$；只有 $E>0$ 让 $b$ 失去单调性，才需要按值建树。
- 「连续分段」这条引理的证明只用到了「合法条件只看极差和个数，且随极差单调放宽」，换成别的批次代价函数仍然成立。
