# P4758. 奇偶之选

> 场次：2026年4月11日-开发岗 · 来源：[CodeFun2000 P4758](https://codefun2000.com/p/P4758)

## 题目描述

探险家发现了一排共 $n$ 个宝箱，从左到右编号为 $1$ 到 $n$，第 $i$ 个宝箱内装有价值为 $a_i$ 的宝石。探险家需要按顺序将这些宝箱两两划为一组：第 $1$ 和 $2$ 个宝箱为第一组，第 $3$ 和 $4$ 个宝箱为第二组，以此类推。若 $n$ 为奇数，则最后一个宝箱单独成为一组。

探险家计划恰好打开 $x$ 组宝箱，并从每一组被打开的两个（或一个）宝箱中，挑选恰好一个宝箱取出其中的宝石。他的目标是让所有取出的宝石的总价值为奇数。

请你判断是否存在一种选择方案，使得总价值为奇数。

约束条件：

- 测试数据组数 $t$ 满足 $1 \le t \le 10^4$。
- 每组数据中宝箱个数 $n$ 满足 $1 \le n \le 2 \times 10^5$，需要打开的小组数 $x$ 满足 $1 \le x \le \lceil n/2 \rceil$。
- 宝箱内宝石的价值 $a_i$ 满足 $0 \le a_i \le 10^9$。
- 所有测试数据的 $n$ 之和不超过 $2 \times 10^5$。

## 输入格式

第一行输入一个整数 $t$，表示测试数据组数。
接下来对于每组测试数据，按以下格式给出：
第一行包含两个整数 $n$ 和 $x$，分别表示宝箱数量与需要打开的小组数量。
第二行包含 $n$ 个整数 $a_1, a_2, \dots, a_n$，表示每个宝箱内宝石的价值。

## 输出格式

对于每组测试数据，输出一行，若存在一种方案使得取出宝石的总价值为奇数，输出 "Yes"，否则输出 "No"。

## 示例

### 示例 1

**输入：**

```
4
4 2
1 2 3 4
4 2
1 3 2 4
4 2
1 3 5 7
1 1
2
```

**输出：**

```
Yes
Yes
No
No
```

**说明：**

第一组数据：$n=4$，$x=2$，宝箱价值为 `1 2 3 4`。按顺序分组为 $(1,2)$ 和 $(3,4)$。每组内两个宝箱的奇偶性均不相同（一个奇数一个偶数），属于灵活盒子（mix）。只要存在灵活盒子，就可以通过调整选择来改变总和的奇偶性，因此必定能选出奇数总和，输出 `Yes`。

第二组数据：宝箱价值为 `1 3 2 4`。分组为 $(1,3)$ 和 $(2,4)$。第一组两个奇数（odd），第二组两个偶数（even），没有灵活盒子。需要打开 $x=2$ 组，设选择 odd 组的数量为 $k$。总和奇偶性只取决于 $k$ 的奇偶性，因此 $k$ 必须为奇数。由 $x=2$ 和 even 组个数为 `1`，可得 $k \ge 2-1=1$，且 $k \le \min(2,1)=1$，因此 $k$ 只能取 `1`，恰为奇数，方案存在，输出 `Yes`。

第三组数据：宝箱价值为 `1 3 5 7`。两组均为奇数，odd=`2`，even=`0`。打开 $x=2$ 组需要选 $k$ 个 odd 组。此时 $k$ 只能取 `2`（偶数），无法得到奇数个 odd 组，总和必定为偶数，输出 `No`。

第四组数据：$n=1$，$x=1$，唯一宝箱价值为 `2`（偶数）。只能选择该偶数，总和为偶数，无法得到奇数，输出 `No`。

## 解题思路

### 只看奇偶：和的具体数值全部作废

要判定的只是「取出宝石的总价值是不是奇数」，所以 $a_i \le 10^9$ 的数值只留最低位（`int(x) & 1`）。分组由下标固定：$(1,2), (3,4), \ldots$，$n$ 为奇数时最后一只单独成组。每个组按它能贡献的奇偶分三类（题目说明里把第一类写作「灵活盒子（mix）」）：

| 组型 | 组内奇偶 | 取一只得到的奇偶 |
|---|---|---|
| 灵活组 | 一奇一偶 | 由人选，奇、偶都能给 |
| 奇数组 | 两奇 | 恒为奇 |
| 偶数组 | 两偶 | 恒为偶 |

一遍配对扫描就能把三个计数点出来，单件组把 `q` 复制成 `p`，自然落进「同奇偶」的两个分支：

```python
for start in range(0, n, 2):
    p = int(data[pos + start]) & 1
    q = (int(data[pos + start + 1]) & 1) if start + 1 < n else p
    if p != q:
        mix_cnt += 1
    elif p:
        odd_cnt += 1
    else:
        even_cnt += 1
```

### 有灵活组：一定 Yes

选要开的 $x$ 组时把某个灵活组 $F$ 算进去（$1 \le x \le \lceil n/2 \rceil$ 保证凑得齐）。其余被打开的组取哪只都是定值，把它们的和记作 $S$；$F$ 里两只一奇一偶，取哪只决定总和的奇偶：$S$ 为偶就取奇数那只，$S$ 为奇就取偶数那只，两种目标都能凑出来。所以 `mix_cnt > 0` 直接输出 `Yes`——灵活组只要存在一个就够，它同时提供「奇」「偶」两种贡献，其余组怎么选都不用管。

### 没有灵活组：能取到的奇数组个数是一段连续整数

全是奇/偶组时，每组取哪只都不影响奇偶，**唯一自由的是「开哪 $x$ 组」**。设奇数组 $o$ 个、偶数组 $e$ 个；若开出的 $x$ 组里含 $k$ 个奇数组，则

$$\max(0,\; x - e) \;\le\; k \;\le\; \min(o,\; x).$$

下界来自「偶数组不够 $x$ 个时只能拿奇数组补」，上界来自「奇数组和总组数都不能超」。总和为奇 ⟺ $k$ 为奇，而可行的 $k$ 是连续整数，所以只需取「不小于下界的最小奇数」和上界比一比：

```python
lo = max(0, x - even_cnt)
hi = min(odd_cnt, x)
lo_odd = lo | 1             # lo 为偶时加 1，为奇时不变
answer = "Yes" if lo_odd <= hi else "No"
```

`lo | 1` 一步就是「向上取到奇数」：`2 | 1 = 3`、`3 | 1 = 3`。只检查下界本身的奇偶是不够的，区间里可能恰好有更大的奇数（见示例推演里的端点例子）。

### 为什么不用枚举：真正的爆点在组合数那一侧

照题面直做是「先选开哪 $x$ 组，再从每组里挑一只」，方案数 $\binom{G}{x}\cdot 2^x$（$G = \lceil n/2 \rceil$）。$n = 2\times10^5$ 时 $G$ 到 $10^5$，这个量级完全跑不动。而上面的推导说明**决策只剩「奇数组开几个」这一个自由度**，它被夹在一条与具体组无关的区间里，于是每组只需 $O(1)$ 记三个计数，$O(n)$ 扫完，$O(1)$ 判定。

数据范围也支持这个口径：$t \le 10^4$、$\sum n \le 2\times10^5$，所有组加起来只扫 $2\times10^5$ 个元素；$a_i \le 10^9$ 只用到最低位，不参与任何数值运算。

## 完整代码实现

```python
"""
P4758. 奇偶之选 - 奇偶曼哈顿分类判定

题面要点：把下标按 (1,2), (3,4), … 顺序配对；n 为奇数时最后一只宝箱
单独成组。要恰好打开 x 个组，且从每个被打开的组里恰好取出一只宝箱，
问取出的宝石总价值能否为奇数。

输入：第一行 T；每组第一行 n x，第二行 n 个价值。
输出：每组一行 "Yes" / "No"。

核心思路（只看奇偶）：
1. 组分三类——「灵活组」（组内一奇一偶，取哪只都行，贡献奇偶可选）、
   「奇数组」（怎么取都是奇）、「偶数组」（怎么取都是偶）。
2. 存在灵活组时必 Yes：它自己让总和的奇偶可自由翻转。
3. 全是奇/偶组时，设奇数组有 o 个、偶数组有 e 个，凑出恰好 x 组需要
   选 k 个奇数组：k ∈ [max(0, x−e), min(o, x)]；总和是奇 ⟺ k 为奇数，
   区间里存在奇数即 Yes。

时间复杂度：每组 O(n)
空间复杂度：O(1)（边读边数）
"""

# https://codefun2000.com/p/P4758
import sys

# @sample-start
"""
样例输入 1:
4
4 2
1 2 3 4
4 2
1 3 2 4
4 2
1 3 5 7
1 1
2

样例输出 1:
Yes
Yes
No
No
"""
# @sample-end


def solve():
    data = sys.stdin.buffer.read().split()
    pos = 0
    t = int(data[pos])
    pos += 1
    out = []
    for _ in range(t):
        n, x = int(data[pos]), int(data[pos + 1])
        pos += 2
        odd_cnt = even_cnt = mix_cnt = 0
        for start in range(0, n, 2):
            p = int(data[pos + start]) & 1
            q = (int(data[pos + start + 1]) & 1) if start + 1 < n else p
            # q 复制成与 p 同值时，该单件组的判定走「同奇偶」分支
            if p != q:
                mix_cnt += 1
            elif p:
                odd_cnt += 1
            else:
                even_cnt += 1
        pos += n

        if mix_cnt > 0:
            # 灵活组自由翻转奇偶，一定能拼出奇数
            out.append("Yes")
        else:
            # 恰好开 x 组须挑 k 个奇数组：k ∈ [max(0, x−even), min(odd, x)]
            lo = max(0, x - even_cnt)
            hi = min(odd_cnt, x)
            lo_odd = lo | 1          # 不小于 lo 的最小奇数
            out.append("Yes" if (lo <= hi and lo_odd <= hi) else "No")
    sys.stdout.write("\n".join(out) + "\n")


def run_tests():
    """官方样例 + 分类边界 + 随机暴力对拍。"""
    import io

    test_cases = [
        # 官方样例（四组合并）
        (
            "4\n4 2\n1 2 3 4\n4 2\n1 3 2 4\n4 2\n1 3 5 7\n1 1\n2\n",
            "Yes\nYes\nNo\nNo",
        ),
        # 有灵活组但 x 超过其它组数量：灵活组反复起作用
        (
            "1\n6 3\n1 2 3 4 1 2\n",
            None,  # 下面手动算
        ),
        # 全是偶数组且 x 为奇数个组：必 No
        (
            "1\n4 1\n2 4 6 8\n",
            "No",
        ),
        # 全是奇数组且只开 1 组：必 Yes
        (
            "1\n2 1\n1 3\n",
            "Yes",
        ),
        # 全是奇数组开 3 组：k=3 奇 -> Yes
        (
            "1\n6 3\n1 3 5 7 9 11\n",
            "Yes",
        ),
        # 奇数组 2 个 + 偶数组 1 个，x=2：k ∈ [1,2]，k=1 有奇 -> Yes
        (
            "1\n6 2\n1 3 2 4 5 7\n",
            "Yes",
        ),
        # 奇数组 2 个 + 偶数组 0 个，x=4：k 只能 4 -> No
        (
            "1\n8 4\n1 3 5 7 9 11 13 15\n",
            "No",
        ),
        # 0 也是偶数：单件 0 的组是偶组
        (
            "1\n1 1\n0\n",
            "No",
        ),
    ]

    for i, case in enumerate(test_cases, 1):
        inp, expected = case
        if expected is None:
            # 6 3 | 1 2 3 4 1 2：组 (1,2)mix (3,4)mix (1,2)mix，全灵活 -> Yes
            expected = "Yes"
        old_stdin, old_stdout = sys.stdin, sys.stdout
        sys.stdin = io.TextIOWrapper(io.BytesIO(inp.encode("utf-8")))
        sys.stdout = io.StringIO()
        try:
            solve()
            output = sys.stdout.getvalue().strip()
        finally:
            sys.stdin, sys.stdout = old_stdin, old_stdout

        status = "✓" if output == expected else "✗"
        print(f"样例 {i}: 期望={expected}, 实际={output} {status}")

    # 随机暴力对拍：小 n 枚举「开哪些组 + 每组取哪一只」全部方案
    import itertools
    import random

    rng = random.Random(20260411)
    ok = True
    for case in range(400):
        n = rng.randint(1, 7)
        a = [rng.randint(0, 9) for _ in range(n)]
        x = rng.randint(1, (n + 1) // 2)
        groups = [a[k:k + 2] for k in range(0, n, 2)]
        m = len(groups)
        brute = False
        for pick in itertools.combinations(range(m), x):
            combos = [g for g in (groups[k] for k in pick)]
            for take in itertools.product(*combos):
                if sum(take) % 2 == 1:
                    brute = True
                    break
            if brute:
                break

        # 期望逻辑同 solve
        odd_cnt = even_cnt = mix_cnt = 0
        for g in groups:
            parities = {v & 1 for v in g}
            if len(parities) > 1:
                mix_cnt += 1
            elif 1 in parities:
                odd_cnt += 1
            else:
                even_cnt += 1
        if mix_cnt:
            expect = True
        else:
            lo = max(0, x - even_cnt)
            hi = min(odd_cnt, x)
            expect = lo <= hi and (lo | 1) <= hi
        if expect != brute:
            ok = False
            print(f"对拍失败: n={n} a={a} x={x} 结论={expect} 暴力={brute}")
            break
    print(f"随机暴力对拍 400 组: {'✓' if ok else '✗'}")


if __name__ == "__main__":
    if len(sys.argv) > 1 and sys.argv[1] == "--test":
        run_tests()
    else:
        solve()

```

## 示例推演

样例 1 的第一组 `1 2 3 4`、$x=2$ 是「有灵活组」的形态：两组 $(1,2)$、$(3,4)$ 都是一奇一偶，`mix_cnt = 2`，直接输出 `Yes`。手动核对这份自由度：两组都开，取值组合为 $1+3=4$、$1+4=5$、$2+3=5$、$2+4=6$，奇偶都出现过——同一个组集合就能把总和调成奇数。

样例 2 `1 3 2 4`、$x=2$ 没有灵活组，逐组分类：

| 组 | 组内 | 组型 | 计数 |
|---|---|---|---|
| $(1,3)$ | 奇, 奇 | 奇数组 | $o=1$ |
| $(2,4)$ | 偶, 偶 | 偶数组 | $e=1$ |

$k$ 的可行区间是 $[\,\max(0,\,2-1),\ \min(1,\,2)\,] = [1, 1]$，不小于下界的最小奇数是 $1 \le 1$，存在 $k=1$，输出 `Yes`——开 1 个奇数组、1 个偶数组，总和拿到奇数组贡献的那个奇。

样例 3 `1 3 5 7`、$x=2$：两组全奇，$o=2$、$e=0$，区间 $[\max(0,2), \min(2,2)] = [2,2]$，不小于 $2$ 的最小奇数是 $3 > 2$，输出 `No`——开满两组只能拿到两个奇，和为偶。

样例 4 $n=1$、$a=[2]$：单件组被复制成 `q = p = 0`，落进偶数组，$o=0$、$e=1$、$x=1$。区间 $[\max(0,1-1),\ \min(0,1)] = [0,0]$，最小奇数 $1 > 0$，输出 `No`——只有一个偶数可选。

端点陷阱的具象：$o=3$、$e=1$、$x=3$ 时区间是 $[2,3]$。下界 $2$ 是偶数，只检查下界奇偶会把这组误判成 `No`，而 $k=3$ 恰可行；这正是 `lo | 1` 那行存在的理由。

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| ---- | ---------- | ---------- | ---- |
| 枚举开哪些组、每组取哪只 | $O\!\left(\binom{G}{x} 2^x\right)$ | $O(x)$ | $G = \lceil n/2 \rceil$ 可到 $10^5$，组合级枚举不可行 |
| 三分类 + 可行区间奇偶判定（最优） | $O(n)$ | $O(1)$ | 每组只累加三个计数器，本题采用；整块读入的输入另计 $O(\sum n)$ |

## 易错点总结

### 1. 单件组被读越界，或被整组漏掉

$n$ 为奇数时最后一组只有一只宝箱。`q = (int(data[pos + start + 1]) & 1) if start + 1 < n else p` 里的条件不能省：`range(0, n, 2)` 的最后一轮 `start = n-1`，`data[pos + start + 1]` 已经越过这一组的数据，在最末一组上直接抛 `IndexError`（样例 1 的第四组 $n=1$ 就是这种输入）。反过来把 `range(0, n, 2)` 写成 `range(0, n - 1, 2)` 不会崩，但最后一组根本没进统计：$n=1$、$x=1$、宝箱为 `3` 的输入会把 `Yes` 判成 `No`。

### 2. 只检查区间下界的奇偶

可行区间 `[lo, hi]` 是连续整数段，判断「里面有奇数」必须找**不小于 `lo` 的最小奇数**再与 `hi` 比较（`lo_odd = lo | 1`）。只写 `lo % 2 == 1` 时，$o=3, e=1, x=3$ 的输入（区间 $[2,3]$，$k=3$ 可行）会误判成 `No`；这个形态在「奇数组比偶数组恰好多一个」的数据里很容易出现。

## 扩展思考

- 同款判定可迁移到"部分和的可达奇偶"这类问题：自由翻转源（灵活组）存在即全通，否则退化成对可行计数区间做定性的检查。
- 若把"恰好 $x$ 组"改成"至多 $x$ 组"，判定会再软一层——不足额时上下界同时放宽；本题"恰好"使两类组的数量都参与夹逼。
