# P5562. 双次读数乘积的最大约数个数

> 场次：2026年9月23日 · 来源：[CodeFun2000 P5562](https://codefun2000.com/p/P5562)

## 题目描述

产线上有 $n$ 个待测器件，第 $i$ 个器件的标定参数为 $a_i$。质检员需要从参数列表中读取两次（两次可以读同一个器件），把两次读到的数相乘，希望乘积的正约数个数尽可能大。请给出这个最大值。

## 输入格式

第一行一个整数 $n$（$2 \le n \le 1000$）。

第二行 $n$ 个整数 $a_1,a_2,\dots,a_n$（$1 \le a_i \le 10^9$）。

## 输出格式

输出一个正整数，表示最大的正约数个数。

## 示例

### 示例 1

**输入：**

```
4
12 18 7 5
```

**输出：**

```
16
```

**说明：**

读取 $12$ 与 $18$，乘积 $216=2^3\cdot 3^3$，正约数个数为 $16$。

两次都读 $12$ 时乘积 $144$ 只有 $15$ 个正约数，不如前者。

## 解题思路

### 输出是一个最大值，判定却卡在「约数个数不服从分配律」

答案是在全部两次读数组合上的最大值——组合共 $n(n+1)/2$ 种，**允许 $i=j$**（两次读同一个器件），此时乘积是 $a_i^2$。真正决定做法形状的是约数个数本身的规律：

$$d(N)=\prod_k (e_k+1),\qquad N=\prod_k p_k^{e_k}$$

两数相乘时**公共**质因子的指数相加：$12=2^2\cdot3$、$18=2\cdot3^2$，乘积 $216=2^3\cdot3^3$ 的约数个数是 $(3+1)(3+1)=16$，而不是 $d(12)\cdot d(18)=6\times6=36$——除了两数互质这类特例，分配律不成立。所以「对每个约数计数函数连乘」的捷径是错的，必须先把乘积的完整指数表拼出来。

### 为什么要按「分解输入」而不是「分解乘积」

$a_i\le10^9$，两张读数乘起来可达 $10^{18}$：对乘积逐个试除要到 $10^9$ 量级才收敛，单次就不可行。分开来看每个 $a_i$：试除只需扫到 $\sqrt{10^9}\approx31623$，用预筛的素数表每个数至多几千次除法就能拆干净。拆完的指数表各自不超过 9 项（$2\cdot3\cdot5\cdot7\cdot11\cdot13\cdot17\cdot19\cdot23$ 已超 $10^9$），把两份 9 项的指数表归并求和，代价可以忽略。

数据范围把第三件事直接砸实：$n\le1000$，成对组合恰好 $5\times10^5$ 上下，每对的合并又是常数级——全体 $O(n^2)$ 枚举是**被数据范围允许**的做法，不需要任何候选剪枝。

### 实现映射

三个部件在代码里一一对应：`build_primes` 筛到 $31623$ 是「试除的上限预算」；`factorize` 逐素数试除，循环条件 `p * p > x` 里的 $x$ 是**除到当前剩下的残余**——这样大素数余项在 `x > 1` 时作为最后一项追加（漏掉这一步，质数与半素数读数的指数表直接残缺）；`merged_divisor_count` 把两份升序指数表做双指针归并，公共质数指数相加后 $+1$ 相乘，独占质数单独置 $e+1$——同一下标 $i=j$ 的情形就用同一张表自乘一次得到 $d(a_i^2)$。外层 `best_pair_divisors` 恰是 $i\le j$ 的双层循环。

## 完整代码实现

```python
"""
P5562. 双次读数乘积的最大约数个数 - 质因数合并不二枚举

n 个待测器件的标定参数 a_i，允许读两次（可读同一个），把两次读到的数
相乘，最大化乘积的正约数个数并输出这个最大值。
n <= 1000，a_i <= 1e9，乘积可达 1e18，必须按指数合并而非试除乘积。

输入格式：
- 第一行整数 n；
- 第二行 n 个整数 a_i。

输出格式：
- 一个整数，最大的正约数个数。

核心思路：正约数个数对乘法没有分配律——d(a*b) ≠ d(a)·d(b)，除非两数
互质；共有的质因子指数要相加。所以先把每个 a_i 独立试除分解
（素数表上界 sqrt(1e9) ≈ 31623），再对全部 n(n+1)/2 对下标（含 i=j）
按「同质数指数相加、不同质数各自翻倍」的规则合并指数表，用
prod (e_a + e_b + 1) 出答案，取最大。

复杂度：预处理 O(n * sqrt(A)) 试除（素数筛选后约 n * 3400 次）；
成对合并 O(n^2 * 指数个数)，a_i <= 1e9 时每份指数表至多 9 项。
"""

# https://codefun2000.com/p/P5562
# @sample-start
"""
样例输入 1:
4
12 18 7 5

样例输出 1:
16
"""
# @sample-end

import sys

# sqrt(1e9) 取整；所有 <= 1e9 的数试除到 sqrt(当前剩余) 为止已足够
PRIME_BUDGET = 31623


def build_primes(budget):
    sieve = bytearray([1]) * (budget + 1)
    sieve[0:2] = b"\x00\x00"
    for p in range(2, int(budget**0.5) + 1):
        if sieve[p]:
            sieve[p * p : budget + 1 : p] = b"\x00" * len(range(p * p, budget + 1, p))
    return [i for i in range(2, budget + 1) if sieve[i]]


def factorize(x, primes):
    """用素数表试除 x，返回按素数升序的 [(p, e), ...]（x=1 时为空表）。"""
    factors = []
    for p in primes:
        if p * p > x:
            break
        if x % p == 0:
            e = 0
            while x % p == 0:
                x //= p
                e += 1
            factors.append((p, e))
    if x > 1:
        factors.append((x, 1))
    return factors


def merged_divisor_count(fa, fb):
    """合并两份升序指数表，返回 prod (e_a + e_b + 1)。"""
    ans = 1
    i = j = 0
    la, lb = len(fa), len(fb)
    while i < la and j < lb:
        pa, ea = fa[i]
        pb, eb = fb[j]
        if pa == pb:
            ans *= ea + eb + 1
            i += 1
            j += 1
        elif pa < pb:
            ans *= ea + 1
            i += 1
        else:
            ans *= eb + 1
            j += 1
    while i < la:
        ans *= fa[i][1] + 1
        i += 1
    while j < lb:
        ans *= fb[j][1] + 1
        j += 1
    return ans


def best_pair_divisors(values, primes):
    factors = [factorize(v, primes) for v in values]
    best = 1  # 至少读两个 1，约数个数也是 1
    for i in range(len(values)):
        fi = factors[i]
        # i=j：同一枚读两次，指数自乘后再与自身合并
        best = max(best, merged_divisor_count(fi, fi))
        for j in range(i + 1, len(values)):
            best = max(best, merged_divisor_count(fi, factors[j]))
    return best


def solve():
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    n = int(data[0])
    values = [int(x) for x in data[1 : 1 + n]]
    print(best_pair_divisors(values, build_primes(PRIME_BUDGET)))


def run_tests():
    import io
    import random
    import time
    from itertools import combinations_with_replacement

    def run_case(inp):
        old_stdin, old_stdout = sys.stdin, sys.stdout
        sys.stdin = io.TextIOWrapper(io.BytesIO(inp.encode("utf-8")))
        sys.stdout = io.StringIO()
        try:
            solve()
            output = sys.stdout.getvalue().strip()
        finally:
            sys.stdin, sys.stdout = old_stdin, old_stdout
        return output

    def exact_divisor_count(x):
        """独立参照：从 1 数到 sqrt(x) 逐步数约数（不依赖因数分解）。"""
        cnt = 0
        d = 1
        while d * d <= x:
            if x % d == 0:
                cnt += 2 if d * d != x else 1
            d += 1
        return cnt

    primes = build_primes(PRIME_BUDGET)
    test_cases = [
        # 官方样例 1：12*18 = 216 = 2^3*3^3 -> (3+1)*(3+1) = 16
        ("4\n12 18 7 5\n", "16"),
        # 官方说明里的次优对照：读两次 12，144 = 2^4*3^2 -> 5*3 = 15
        ("1\n12\n", "15"),
    ]
    for i, (inp, expected) in enumerate(test_cases, 1):
        output = run_case(inp)
        status = "✓" if output == expected else "✗"
        print(f"样例 {i}: {'通过' if output == expected else '失败'} {status}")
        assert output == expected, f"样例 {i} 期望 {expected}，实际 {output}"

    # 官方样例很弱：小值域全枚举对拍（素数幂、公因子、同值双读全覆盖）。
    pool = list(range(1, 61))
    rng = random.Random(20260923)
    trials = 0
    for _ in range(40):
        values = rng.sample(pool, 12)
        want = 1
        for a, b in combinations_with_replacement(values, 2):
            want = max(want, exact_divisor_count(a * b))
        got = run_case(f"{len(values)}\n{' '.join(map(str, values))}\n")
        assert int(got) == want, f"对拍失败 values={values}: 期望 {want}，实际 {got}"
        trials += 1
    print(f"对拍用例 {trials} 组（随机 1..60 池，逐对试除参照）：通过")

    # 直接端到端抽查若干含公因子组合的小数组（好构造的陷阱用例）。
    trap_cases = [
        ("2\n4 2\n", "5"),     # 最大来自 4*4 = 16 -> 5 个约数（不是 4*2）
        ("2\n2 2\n", "3"),     # 2*2 = 4 -> 3 个约数
        ("3\n6 6 4\n", "9"),   # 6*6 = 36 -> 9 个；6*4 = 24 -> 8 个
        ("4\n1 1 1 1\n", "1"),
        ("2\n999999937 999999937\n", "3"),  # 读两次同一个大素数，平方后仍只有 3 个约数
    ]
    for i, (inp, expected) in enumerate(trap_cases, 1):
        got = run_case(inp)
        assert got == expected, f"陷阱用例 {i} 期望 {expected}，实际 {got}"
    print(f"陷阱用例 {len(trap_cases)} 组（同值重复/公因子/大素数平方）：通过")

    # 极端规模：n=1000 全 1e9 内随机值，端到端限时检查。
    t0 = time.perf_counter()
    values = [rng.randint(1, 10**9) for _ in range(1000)]
    got = run_case(f"1000\n{' '.join(map(str, values))}\n")
    elapsed = time.perf_counter() - t0
    assert int(got) >= 1
    print(f"压力用例 n=1000（随机 a_i<=1e9）：答案 {got}，用时 {elapsed:.2f}s")


if __name__ == "__main__":
    if len(sys.argv) > 1 and sys.argv[1] == "--test":
        run_tests()
    else:
        solve()
```

## 示例推演

官方样例 1：数组 `12 18 7 5`。四份指数表：

| $a_i$ | 指数表 |
| ----- | ------ |
| 12 | $(2,2),\ (3,1)$ |
| 18 | $(2,1),\ (3,2)$ |
| 7 | $(7,1)$ |
| 5 | $(5,1)$ |

归并 12 与 18：质数 $2$ 两表共有，指数 $2+1=3$，贡献 $3+1=4$；质数 $3$ 两表共有，指数 $1+2=3$，贡献 $4$；无独占项。合计 $4\times4=16$——这正是 $216=2^3\cdot3^3$ 的约数个数。

归并 12 与 12（$i=j$ 自乘）：$2$ 的指数 $2+2=4$ 贡献 $5$，$3$ 的指数 $1+1=2$ 贡献 $3$，合计 $15$，对应 $144=2^4\cdot3^2$。$15<16$，所以答案是 $16$，与官方说明逐字吻合。

再取一对含独占项的组合看归并器怎么处理不齐的两张表：12（$(2,2),(3,1)$）与 7（$(7,1)$）——公共质数一个都没有，四处每项各自贡献 $(e+1)$：$3\times2\times2=12$，恰是 $84=2^2\cdot3\cdot7$ 的约数个数 $(2+1)(1+1)(1+1)$。独占项在归并的两条收尾 `while` 里被消化，不参与「相加」。

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| ---- | ---------- | ---------- | ---- |
| 对每对直接试除乘积 $a_i\cdot a_j$ | $O(n^2\cdot\sqrt{a_i a_j})$ | $O(1)$ | $\sqrt{10^{18}}\approx3.2\times10^9$ 次除法起步，不可行 |
| 每对按 $d(a_i)\cdot d(a_j)$ 速乘 | $O(n^2)$ | $O(1)$ | 公共质因子重合时 $(e_a{+}1)(e_b{+}1)\neq e_a{+}e_b{+}1$，结果整体虚高，而本题求最大 |
| 分解输入 + 逐对指数表归并（最优） | $O(n\sqrt{A}+n^2\omega)$ | $O(n\omega)$ | $\omega$ 是 $a_i$ 的不同质因子个数（$\le9$），每对合并常数级 |

$n=1000$ 时归并总量约 $5\times10^5$ 对 $\times$ 十步上下，与预处理持平，整体在秒级。

## 易错点总结

### 1. 读同一枚的 $i=j$ 不能只靠「读法同值」涵盖

两次读数允许相同——这道题的答案在不少数据上恰好来自 $d(a_i^2)$：`4 2` 里最优是 $4\times4=16$（5 个约数），压过 $4\times2=8$（4 个）。枚举若只写 `for j in range(i + 1, ...)`，必须像 `best_pair_divisors` 里那样在进入内层前先对 `fi` 与它自身归并一次。漏掉后输出偏小，官方两组样例都是异值组合，照样全绿——这个缺口只会在以平方占优的用例上现形。

### 2. 试除收尾的残余项别丢

`factorize` 的循环只扫到 $p^2>x$，此时大于 $\sqrt{x}$ 的那个余下因子（若 $x>1$）是质数，必须以 `factors.append((x, 1))` 追加，否则像 `999999937`（大素数）这样的读数会分解成空表，两次读它算出的约数个数错误地变成 $1$ 而不是 $3$。官方样例里 $7$、$5$ 虽然也带大余项，但最优组合用不到它们，丢项照样全绿——同样属于样例照过、数据现形的潜伏错。

## 扩展思考

- 约数个数、$\gcd$、$\text{lcm}$ 共享同一套「指数视角」：对应质数的指数分别在乘法下**相加**、$\gcd$ 下取 $\min$、$\text{lcm}$ 下取 $\max$。把一道题的运算翻译到指数坐标上，公式常会自动对齐。
- 允许读 $k$ 次的推广仍是同一框架：$k$ 份指数表逐个并进一张运行表，答案 $\prod(e+1)$，只是组合数变成 $O(n^k)$，得靠剪枝或指数上界收紧。
