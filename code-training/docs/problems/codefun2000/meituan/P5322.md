# P5322. 区间最大公约数和

> 场次：2026年8月29日 · 来源：[CodeFun2000 P5322](https://codefun2000.com/p/P5322)

## 题目描述

运维侧做容量水位分析时，两条整型指标序列在偏移 $i$ 处的读数分别为 $x+i$ 与 $y+i$。定义对齐公约
$$h(i)=\gcd(x+i,\,y+i)$$
其中 $\gcd$ 表示最大公因数。例如 $8$ 与 $12$ 的正公约数有 $1,2,4$，故 $\gcd(8,12)=4$。现要对连续偏移窗口做汇总：求
$$h(s)+h(s+1)+\cdots+h(t)$$
即 $\displaystyle\sum_{i=s}^{t}\gcd(x+i,\,y+i)$。结果可能很大，对 $1000000007$ 取模后写出。

## 输入格式

第一行一个整型 $k$（$1 \le k \le 120$），表示随后有 $k$ 行询问。

接下来 $k$ 行，每行四个整型 $x,y,s,t$（$1 \le x,y \le 100000$，$0 \le s \le t \le 1\times 10^{18}$）。

请对每个询问逐一计算上述和模 $1000000007$。

## 输出格式

共写出 $k$ 行。对每一个询问，写出一个非负整型，即该窗口公约和模 $1000000007$ 的结果。

## 示例

### 示例 1

**输入：**

```
3
8 14 0 2
5 5 1 3
3 9 0 4
```

**输出：**

```
7
21
13
```

**说明：**

三个询问依次为：$\gcd(8,14)+\gcd(9,15)+\gcd(10,16)=2+3+2=7$；两路读数相同，和为 $6+7+8=21$；$\gcd(3,9)+\gcd(4,10)+\gcd(5,11)+\gcd(6,12)+\gcd(7,13)=3+2+1+6+1=13$。

### 示例 2

**输入：**

```
2
2 10 0 0
7 11 2 5
```

**输出：**

```
2
8
```

**说明：**

第一问窗口只有 $i=0$，$\gcd(2,10)=2$。第二问 $i=2$ 到 $5$：$\gcd(9,13)+\gcd(10,14)+\gcd(11,15)+\gcd(12,16)=1+2+1+4=8$。

## 解题思路

### 输出是什么：一个长度可达 1e18 的窗口里的 gcd 和

对每个询问，输出 $\sum_{i=s}^{t}\gcd(x+i,y+i)$ 模 $1000000007$。$t-s$ 最大到 $10^{18}$，逐项枚举一定超时；但另一组参数很小：$x,y\le 10^5$，询问数 $k\le 120$。也就是说，窗口很长，而两个序列的起点很小，秘密在两者的差上。

### 关键观察：gcd 只看差，差小就意味着周期

由 $\gcd(a,b)=\gcd(a,b-a)$，

$$
\gcd(x+i,y+i)=\gcd(x+i,\,|y-x|).
$$

记 $d=|y-x|$。

- 若 $d=0$，两项完全相同，$h(i)=x+i$，窗口和是等差数列，直接用公式。
- 若 $d>0$，$h(i)$ 只依赖 $(x+i)\bmod d$，所以它是以 $d$ 为周期的序列。更关键的是 $d\le 10^5-1$：周期很短，而窗口可以很长。

于是整段求和被拆成「完整周期」和「首尾两截余数」。只要能在 $O(\tau(d))$ 的时间里求出一个周期内任意连续段的 $\gcd$ 和，就不必关心窗口有多长。

### 一个周期内的和：用欧拉函数把 gcd 摊到因子上

直接枚举 $0..d-1$ 逐个求 $\gcd$ 是 $O(d)$，对每个询问做一遍在 $k=120$、$d=10^5$ 时也偏慢。利用恒等式

$$
n=\sum_{m\mid n}\varphi(m),
$$

把 $\gcd(r,d)$ 写成「所有同时整除 $r$ 与 $d$ 的 $m$ 的 $\varphi(m)$ 之和」：

$$
\gcd(r,d)=\sum_{m\mid d,\;m\mid r}\varphi(m).
$$

交换求和顺序，区间 $[lo,hi)$ 上的和变成

$$
\sum_{r=lo}^{hi-1}\gcd(r,d)=\sum_{m\mid d}\varphi(m)\cdot\#\{r\in[lo,hi):m\mid r\}.
$$

$[lo,hi)$ 内 $m$ 的倍数个数是 `(hi - 1) // m - (lo - 1) // m`。$lo=0$ 时 Python 的 `(-1)//m` 等于 $-1$，公式恰好把 $r=0$ 也算进去，不需要特判。

整个周期的和也有闭式：按 $\gcd$ 的取值 $m$ 分组，$\gcd(r,d)=m$ 的 $r$ 有 $\varphi(d/m)$ 个，于是

$$
G(d)=\sum_{r=0}^{d-1}\gcd(r,d)=\sum_{m\mid d}m\,\varphi(d/m).
$$

代码的 `period_info(d)` 一次算出 $G(d)$、因子表和每个因子的 $\varphi$，并按 $d$ 缓存；`gcd_sum_block` 用上面的倍数计数求任意块，`partial_from_r0` 负责「从余数 $r_0$ 开始、跨过周期末尾」的绕回。

### 前缀和：长窗口拆成整周期加两段余数

定义 $P(N)=\sum_{i=0}^{N-1}h(i)$。因为每 $d$ 项恰好遍历一遍全部余数，

$$
P(N)=\left\lfloor\frac{N}{d}\right\rfloor G(d)+\text{从 }r_0=(x\bmod d)\text{ 开始连续 }N\bmod d\text{ 项的和}.
$$

区间 $[s,t]$ 的答案就是 $P(t+1)-P(s)$。

`window_sum` 里的 `prefix(n)` 就是这条式子；`partial_from_r0` 在余数不够走到周期末尾时直接取一段，否则拆成 $[r_0,d)$ 与 $[0,\text{剩余})$ 两段。整个计算用 Python 大整数保留精确值，最后在 `solve` 里才 `% MOD`：前缀相减必须精确，提前取模会让 $P(t+1)-P(s)$ 变成负数或错值。

数据范围支撑这个做法：$d\le 10^5$，试除法分解与枚举因子都很快，且询问数只有 120，同一 $d$ 还会被缓存复用。

## 完整代码实现

```python
"""
P5322. 区间最大公约数和 - gcd 恒等式 + 欧拉函数 + 周期归约

两条整型指标序列在偏移 i 处为 x+i 与 y+i，h(i) = gcd(x+i, y+i)。
求 Σ_{i=s}^{t} h(i)，对 1000000007 取模。t-s 可达 1e18，逐项枚举必挂。

核心思路：
1. gcd(x+i, y+i) = gcd(x+i, |y-x|)：两数之差固定，公因子只能整除差。
   记 d = |y-x|，h(i) 只依赖 r = (x+i) mod d。
2. d = 0（x=y）时 h(i) = x+i，窗口和是等差数列，直接取模输出。
3. d > 0 时 h 以 d 为周期。整周期内的和是个数论常数：
       G(d) = Σ_{r=0}^{d-1} gcd(r, d) = Σ_{m | d} m·φ(d/m)
   ——把 0..d-1 按 gcd 值分组，gcd(r,d)=m 的 r 形如 m·c 且
   gcd(c, d/m)=1，恰有 φ(d/m) 个（r=0 归到 gcd=d 那一组，对应 φ(1)=1）。
4. 部分和尾部 Σ gcd(r, d) 用另一个恒等式直接算，不需要预处理数组：
       Σ_{r=a}^{b-1} gcd(r, d)   （a <= b <= d）
     = Σ_{m | d} m·(#r∈[a,b): m | r)
     = Σ_{m | d} m·( (b-1)//m - (a-1)//m )   （a=0 时后者取 0，
       准确写法是 (b//m) 的边界提醒：计数公式为 (x-1)//m，x>=1）
   前缀 P(N) = Σ_{i=0}^{N-1} h(i) = 整周期数·G(d) + 首段余数的前缀和，
   答案 = P(t+1) - P(s)，全程大整数乘法、最后取模。
5. 试除法求 φ；同一 d 的 G 与因子表缓存复用。

输入格式：
- 第 1 行：k（询问数）；
- 接下来 k 行：每行 x、y、s、t。

输出格式：
- 每个询问一行：公约和模 1000000007。

时间复杂度：单询问 O(τ(d)·√d)（τ 为因子个数），k·d 规模完全可控
空间复杂度：O(√d + τ(d)·缓存)
"""

# https://codefun2000.com/p/P5322
import sys

MOD = 1000000007
_period_cache = {}  # d -> (整周期和 G, 因子升序表, 每因子 φ 值表)


def euler_phi(n):
    result = n
    remaining = n
    p = 2
    while p * p <= remaining:
        if remaining % p == 0:
            while remaining % p == 0:
                remaining //= p
            result -= result // p
        p += 1
    if remaining > 1:
        result -= result // remaining
    return result


def period_info(d):
    """整周期和 G(d) = Σ_{m|d} m·φ(d/m)，以及因子表与 φ 值表。"""
    cached = _period_cache.get(d)
    if cached is not None:
        return cached
    divisors = []
    m = 1
    while m * m <= d:
        if d % m == 0:
            divisors.append(m)
            if m != d // m:
                divisors.append(d // m)
        m += 1
    divisors.sort()
    phi_of = {m: euler_phi(m) for m in divisors}
    # 按 gcd 值分组：gcd(r,d)=m 的 r 形如 m·c 且 gcd(c, d/m)=1，
    # 恰有 φ(d/m) 个；r=0 归入 gcd=d 那组，对应 φ(1)=1
    total = 0
    for m in divisors:
        total += m * euler_phi(d // m)
    _period_cache[d] = (total, divisors, phi_of)
    return total, divisors, phi_of


def gcd_sum_block(d, divisors, phi_of, lo, hi):
    """Σ_{r=lo}^{hi-1} gcd(r, d)，要求 0 <= lo <= hi <= d。

    用 n = Σ_{m|n} φ(m)：gcd(r, d) = Σ_{m|d 且 m|r} φ(m)，故
    Σ gcd(r,d) = Σ_{m|d} φ(m)·#{r∈[lo,hi): m|r}。
    [0,hi) 内 m 的倍数有 (hi-1)//m + 1 个，r=0 一格自动并入，
    其贡献恰好是 Σ_{m|d} φ(m) = d = gcd(0,d)，不需要特判。
    """
    if lo >= hi:
        return 0
    total = 0
    for m in divisors:
        count = (hi - 1) // m - (lo - 1) // m  # lo=0 时 (−1)//m = −1
        total += phi_of[m] * count
    return total


def partial_from_r0(d, divisors, phi_of, r0, rem):
    """从 r0 开始连续 rem 个 gcd((r0+j) mod d, d) 之和。"""
    if rem <= 0:
        return 0
    to_end = d - r0
    if rem <= to_end:
        return gcd_sum_block(d, divisors, phi_of, r0, r0 + rem)
    total = gcd_sum_block(d, divisors, phi_of, r0, d)
    total += gcd_sum_block(d, divisors, phi_of, 0, rem - to_end)
    return total


def window_sum(x, y, s, t):
    """Σ_{i=s}^{t} gcd(x+i, y+i)，未取模。"""
    d = abs(y - x)
    if d == 0:
        # x = y：每项就是 x+i
        length = t - s + 1
        return length * x + (s + t) * length // 2

    period_sum, divisors, phi_of = period_info(d)
    r0 = x % d

    # P(N)：从偏移 0 开始连续 N 项之和
    def prefix(n):
        if n <= 0:
            return 0
        full = n // d
        rem = n % d
        return full * period_sum + partial_from_r0(d, divisors, phi_of, r0, rem)

    return prefix(t + 1) - prefix(s)


def solve():
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    k = int(next(it))
    out = []
    for _ in range(k):
        x = int(next(it))
        y = int(next(it))
        s = int(next(it))
        t = int(next(it))
        out.append(str(window_sum(x, y, s, t) % MOD))
    sys.stdout.write("\n".join(out) + "\n")


def run_tests():
    """官方样例 + 对拍小窗口 + 周期边界 + 大偏移平移不变性。"""
    import io
    import random
    from math import gcd

    test_cases = [
        # 官方样例 1
        ("3\n8 14 0 2\n5 5 1 3\n3 9 0 4\n", "7\n21\n13"),
        # 官方样例 2
        ("2\n2 10 0 0\n7 11 2 5\n", "2\n8"),
        # x=y 且窗口起点不为 0：等差数列 gcd(6,6)+gcd(7,7)+gcd(8,8)=21
        ("1\n4 4 2 4\n", "21"),
    ]

    for i, (inp, expected) in enumerate(test_cases, 1):
        old_stdin, old_stdout = sys.stdin, sys.stdout
        sys.stdin = io.TextIOWrapper(io.BytesIO(inp.encode("utf-8")))
        sys.stdout = io.StringIO()
        try:
            solve()
            output = sys.stdout.getvalue().strip()
        finally:
            sys.stdin, sys.stdout = old_stdin, old_stdout

        status = "✓" if output == expected else "✗"
        print(f"样例 {i}: 期望={expected}, 实际={output} {status}")

    def brute(x, y, s, t):
        total = 0
        for i in range(s, t + 1):
            total += gcd(x + i, y + i)
        return total

    random.seed(20261027)
    fail = None
    for case_no in range(1, 3001):
        x = random.randint(1, 200)
        y = random.randint(1, 200)
        s = random.randint(0, 40)
        t = s + random.randint(0, 60)
        got = window_sum(x, y, s, t)
        want = brute(x, y, s, t)
        if got != want:
            fail = (x, y, s, t, want, got)
            break
    print("对拍 3000 组小窗口：" + ("全部一致" if fail is None else f"失败 {fail}"))
    if fail is not None:
        return

    # 周期边界：窗口起点掠过 0、掠过整周期端点；x mod d 落在不同余数段
    bad = None
    for d in (1, 2, 3, 7, 9973, 99991):
        for base in (0, 1, d - 5, d - 1, d, 2 * d - 6):
            for width in (3, 7):
                s = max(0, base)
                t = s + width - 1
                x = d + 3
                y = x + d
                got = window_sum(x, y, s, t)
                want = brute(x, y, s, t)
                if got != want:
                    bad = (d, base, width, want, got)
                    break
            if bad:
                break
        if bad:
            break
    print("周期边界 36 组：" + ("全部一致" if bad is None else f"失败 {bad}"))

    # 大偏移自洽：1e18 级窗口，平移整周期不变
    x, d = 12345, 99991
    y = x + d
    s, t = 10 ** 18 - 3, 10 ** 18 + 4
    base = window_sum(x, y, s, t)
    check1 = window_sum(x, y, s + d, t + d) == base
    check2 = window_sum(x, y, s + 777 * d, t + 777 * d) == base
    # 整周期自洽：恰一个完整周期的窗口和应为 G(d)；恰 5 个周期应为 5·G(d)
    one_period = window_sum(x, y, s + 5 * d, s + 5 * d + d - 1)
    five_period = window_sum(x, y, s + 5 * d, s + 5 * d + 5 * d - 1)
    period_sum_g = period_info(d)[0]
    print(
        f"1e18 偏移平移不变性: {check1}/{check2}, "
        f"1 个周期 == G: {one_period == period_sum_g}, "
        f"5 个周期 == 5·G: {five_period == 5 * period_sum_g}"
    )


if __name__ == "__main__":
    if len(sys.argv) > 1 and sys.argv[1] == "--test":
        run_tests()
    else:
        solve()
```

## 示例推演

用示例 1 的三个询问逐个走一遍。

**询问 1：`x=8, y=14, s=0, t=2`。** 差 $d=6$，$x\bmod 6=2$。$6$ 的因子是 $1,2,3,6$，对应 $\varphi$ 值为 $1,1,2,2$。整周期和

$$
G(6)=1\cdot\varphi(6)+2\cdot\varphi(3)+3\cdot\varphi(2)+6\cdot\varphi(1)=2+4+3+6=15.
$$

窗口只有 3 项，不构成整周期：$\lfloor 3/6\rfloor=0$，余数 3 项从 $r_0=2$ 开始，没走到周期末尾，所以取块 $[2,5)$。逐个因子数倍数：

- $m=1$：`4//1 - 1//1 = 3` 个，贡献 $1\times3=3$；
- $m=2$：`4//2 - 1//2 = 2` 个，贡献 $1\times2=2$；
- $m=3$：`4//3 - 1//3 = 1` 个，贡献 $2\times1=2$；
- $m=6$：`4//6 - 1//6 = 0` 个，贡献 0。

合计 $3+2+2=7$，与 $\gcd(8,14)+\gcd(9,15)+\gcd(10,16)=2+3+2$ 一致。

**询问 2：`x=5, y=5, s=1, t=3`。** $d=0$，每项 $h(i)=5+i$。长度为 3，首项 6、末项 8：

$$
3\times5+\frac{(1+3)\times3}{2}=15+6=21.
$$

**询问 3：`x=3, y=9, s=0, t=4`。** $d=6$，$x\bmod6=3$。窗口 5 项，先算 $P(5)$：$\lfloor5/6\rfloor=0$，余数 5 项从 $r_0=3$ 开始。$3$ 到周期末尾还有 3 格（余数 $3,4,5$），剩下 2 格绕回开头（余数 $0,1$），拆成 $[3,6)$ 与 $[0,2)$ 两块。

$[3,6)$：

- $m=1$：`5//1 - 2//1 = 3`，贡献 3；
- $m=2$：`5//2 - 2//2 = 1`，贡献 1；
- $m=3$：`5//3 - 2//3 = 1`，贡献 $2\times1=2$；
- $m=6$：`5//6 - 2//6 = 0`，贡献 0。

合计 $6$，对应 $\gcd(3,6)+\gcd(4,6)+\gcd(5,6)=3+2+1$。

$[0,2)$：

- $m=1$：`1//1 - (-1)//1 = 2`，贡献 2；
- $m=2$：`1//2 - (-1)//2 = 1`，贡献 1；
- $m=3$：`1//3 - (-1)//3 = 1`，贡献 $2\times1=2$；
- $m=6$：`1//6 - (-1)//6 = 1`，贡献 $2\times1=2$。

合计 $7$，对应 $\gcd(0,6)+\gcd(1,6)=6+1$。于是 $P(5)=6+7=13$，$P(0)=0$，答案为 13，与逐项相加 $3+2+1+6+1$ 一致。

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| ---- | ---------- | ---------- | ---- |
| 逐项枚举 | 每个询问 $O(t-s+1)$ | $O(1)$ | 窗口长度可达 $10^{18}$，不可行 |
| 周期加欧拉函数（最优） | 每个新 $d$ 为 $O\big(\sqrt d+\tau(d)\sqrt d\big)$，同一 $d$ 之后每个询问 $O(\tau(d))$ | $O(\tau(d))$，按 $d$ 缓存，最多 120 组 | 枚举因子加倍数计数，本题采用 |

$\tau(d)$ 是 $d$ 的因子个数，$d\le 10^5$ 时最多 128 个。每个询问只做两次前缀计算，每次至多两段块求和，每一段遍历一遍因子表，所以单个询问在首次分解之后只有几遍长度不超过 128 的循环。

## 易错点总结

### 1. d=0 必须单独处理，否则取模直接崩

代码 `if d == 0` 分支返回等差数列。若删掉这个分支，下一行 `r0 = x % d` 会抛 `ZeroDivisionError`。示例 1 的第二个询问 `5 5 1 3` 就是 $x=y$ 的情形，程序不是算错而是直接异常；自测里 `4 4 2 4` 这类只有 $x=y$ 才会走的分支也会一起失效。

### 2. 倍数计数要减 1 再整除，不能用 hi//m - lo//m

`count = (hi - 1) // m - (lo - 1) // m` 数的是 $[lo,hi)$ 内的倍数。若写成 `hi // m - lo // m`，区间右端会被多算、左端会被漏算，最明显的是 $r=0$ 这一格。示例 1 询问 3 的 $[0,2)$ 块会从 7 变成 3，总答案从 13 变成 9。

### 3. 前缀的余数要从 x mod d 开始，不能从 0 开始

`partial_from_r0(d, divisors, phi_of, r0, rem)` 的第三个实参是窗口起点落在周期里的位置。若换成 0，等于假设每个窗口都从余数 0 开始。示例 1 询问 1 会取块 $[0,3)$，得到 $\gcd(0,6)+\gcd(1,6)+\gcd(2,6)=6+1+2=9$，输出 9 而不是 7。

## 扩展思考

- 若 $x,y$ 放大到 $10^{18}$，差 $d$ 也会很大，试除法分解不够用，需要 Pollard-Rho 一类算法；本题能做，前提正是 $x,y\le10^5$ 把周期压小了。
- 若有很多询问共享同一个 $d$，可以把 $d\le10^5$ 的整周期和 $G(d)$ 全部预处理出来：线性筛求 $\varphi$，再按因子倍数累加，总代价 $O(N\log N)$，之后每个询问只剩 $O(\tau(d))$ 的块求和。
