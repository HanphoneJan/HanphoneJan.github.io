# P4674. 最优折扣组合

> 场次：2026年3月28日-开发岗 · 来源：[CodeFun2000 P4674](https://codefun2000.com/p/P4674)

## 题目描述

你是一家商店的经理，商店内共有 $n$ 件商品，第 $i$ 件商品的标价为 $p_i$。你手中有两种不同类型的优惠券：

- “半价券”：对一件商品使用后，该商品的价格变为 $\lfloor p_i / 2 \rfloor$（即除以 $2$ 并向下取整）。
- “固定减免券”：对一件商品使用后，该商品的价格变为 $p_i - k$（价格允许变为负数）。

每件商品最多可以被使用一次半价券，最多使用一次固定减免券（两种券可以同时用在同一种商品上）。你总共有 $a$ 张半价券和 $b$ 张固定减免券。

请你合理分配这些优惠券，使得所有商品的最终价格之和达到最小，并输出这个最小值。

**约束条件**

- 商品数量 $n$ 不超过 $2 \times 10^5$。
- 半价券数量 $a$ 和固定减免券数量 $b$ 均不超过 $n$。
- 减免额度 $k$ 不超过 $10^9$。
- 每件商品的初始标价 $p_i$ 不超过 $10^9$。
- 一个测试输入中所有测试数据的 $n$ 之和不超过 $4 \times 10^5$。

## 输入格式

第一行包含一个整数 $T$（$1 \le T \le 2 \times 10^5$），表示测试数据的组数。

接下来对于每组测试数据：

第一行包含四个整数 $n, a, b, k$，含义如上所述。

第二行包含 $n$ 个整数 $p_1, p_2, \dots, p_n$，表示各商品的初始标价。

## 输出格式

对于每组测试数据，输出一行一个整数，表示经过最优使用优惠券后，所有商品的最终价格之和的最小值（该值可能为负数）。

## 示例

### 示例 1

**输入：**

```
1
4 2 1 5
10 3 8 12
```

**输出：**

```
17
```

**说明：**

该组商品初始总价为 `10 + 3 + 8 + 12 = 33`。
对每件商品使用半价券可减少 $\lceil p_i / 2 \rceil$，各商品半价收益分别为：`10` 减少 `5`，`3` 减少 `2`，`8` 减少 `4`，`12` 减少 `6`。我们有 `a = 2` 张半价券，应选择收益最大的两件商品：`12` 和 `10`，共减少 `6 + 5 = 11`。
我们还有 `b = 1` 张固定减免券，减少 `k = 5`。
因此最终价格总和为 `33 - 11 - 5 = 17`。

### 示例 2

**输入：**

```
1
3 0 2 4
7 8 9
```

**输出：**

```
16
```

**说明：**

该组没有半价券（`a = 0`），只能使用固定减免券。
初始总价为 `7 + 8 + 9 = 24`。
使用 `b = 2` 张固定减免券，每张减少 `k = 4`，共减少 `8`。
最终价格总和为 `24 - 8 = 16`。

### 示例 3

**输入：**

```
2
1 1 1 100
50
2 0 0 10
100 200
```

**输出：**

```
-75
300
```

**说明：**

第一组：只有一件价格为 `50` 的商品。半价券收益为 $\lceil 50/2 \rceil = 25$，固定减免券收益为 `k = 100`。最终价格为 `50 - 25 - 100 = -75`。
第二组：有两件商品，但没有优惠券（`a = 0，b = 0`）。初始总价 `100 + 200 = 300`，无法减免，最终总和仍为 `300`。

### 示例 4

**输入：**

```
1
2 2 1 1
1 1
```

**输出：**

```
-1
```

**说明：**

两件商品价格均为 `1`。半价券收益为 $\lceil 1/2 \rceil = 1$，用满 `a = 2` 张共减少 `2`。固定减免券一张，减少 `k = 1`。初始总价为 `2`，最终总和为 `2 - 2 - 1 = -1`。
该样例展示了最终总和可以为负数。

## 解题思路

### 两类券的贡献互相独立

输出判定标准只有一句：所有商品的最终价格之和最小。把一张券单独拿出来算"收益"就看清了整道题的形状——

- 半价券用在标价 $p$ 的商品上，价格从 $p$ 变成 $\lfloor p/2 \rfloor$，收益恒为 $p - \lfloor p/2 \rfloor = \lceil p/2 \rceil$，只与商品自己的标价有关，与这件商品有没有再叠一张减免券无关（减免只是再减常数 $k$）；
- 固定减免券收益恒为 $k$，与用在哪件商品上无关，而 $b \le n$ 保证 $b$ 张总能落在互不相同的商品上，减免总量固定是 $b\cdot k$。

所以整道题被拆成两个互不干扰的挑选：减免总量直接写死为 $b k$；半价券在 $n$ 个收益值 $\lceil p_i/2 \rceil$ 里挑最大的 $a$ 个。答案为

$$\sum_{i=1}^{n} p_i \; - \; b\cdot k \; - \; \bigl(\text{前 } a \text{ 大的 } \lceil p_i/2 \rceil \text{ 之和}\bigr).$$

题面说价格允许减成负数，这一句恰恰保证了"减免总量与商品是谁"解耦得干净：不用考虑 $k$ 把某件商品减到 $0$ 以下的浪费。若价格必须夹在 $0$ 以上，两张券抢同一件商品时就要掂量分配，问题立刻变成另一种题。

### 数据范围把做法钉在排序上

$\sum n \le 4\times10^5$、$T \le 2\times10^5$：对每组收益数组整体排序取前 $a$ 个是 $O(\sum n\log n)$，绰绰有余；对"每张券用在哪件商品"做子集枚举则是 $2^n$ 级别，数据范围直接否定。这里没有"先想到暴力再优化"的真实阶梯——两类券一旦看出互相独立，剩下的就是把"挑最大 $a$ 个"这件事做对，所以直接从判定标准走到实现：

数组 `half[i] = p - p // 2` 就是 $\lceil p/2 \rceil$；每组现建现排序，取前 $a$ 个求和。多组数据在 `solve()` 里一次性读入全部整数、用下标 `pos` 游标推进，省掉逐组 `input()` 的解析开销。

## 完整代码实现

```python
"""
P4674. 最优折扣组合 - 贪心

题面要点：n 件商品标价 p_i，两种券——半价券（该商品价格变为 ⌊p/2⌋）与
固定减免券（价格变为 p − k，允许减成负数）。每件商品最多各用一张两类券
（可叠加在同一个商品上），手中共有 a 张半价券、b 张固定减免券。
最小化最终价格总和。

输入：第一行 T；每组第一行 n a b k，第二行 n 个价格。
输出：每组一行，最小价格总和。

核心思路：
1. 两种券的收益互相独立，且与"用在哪"几乎无关：
   - 固定减免券的收益恒为 k（b <= n 保证总能在不同商品上各用一张），
     所以总减免就是 b*k；
   - 半价券在商品 i 上的收益恒为 p_i − ⌊p_i/2⌋ = ⌈p_i/2⌉，与该商品是否
     再叠一张减免券无关，所以挑 ⌈p_i/2⌉ 最大的 a 个商品即可。
2. 答案 = Σp_i − b*k − (最大的 a 个 ⌈p_i/2⌉ 之和)。

时间复杂度：O(Σn log n)（每组一次排序）
空间复杂度：O(n)
"""

# https://codefun2000.com/p/P4674
import sys

# @sample-start
"""
样例输入 1:
1
4 2 1 5
10 3 8 12

样例输出 1:
17
"""
# @sample-end

# @sample-start
"""
样例输入 2:
1
3 0 2 4
7 8 9

样例输出 2:
16
"""
# @sample-end

# @sample-start
"""
样例输入 3:
2
1 1 1 100
50
2 0 0 10
100 200

样例输出 3:
-75
300
"""
# @sample-end

# @sample-start
"""
样例输入 4:
1
2 2 1 1
1 1

样例输出 4:
-1
"""
# @sample-end


def solve():
    """逐组读入，输出每组使用优惠券后的最小价格总和。"""
    data = sys.stdin.buffer.read().split()
    pos = 0
    t = int(data[pos])
    pos += 1
    out = []
    for _ in range(t):
        n, a, b, k = (int(data[pos]), int(data[pos + 1]),
                      int(data[pos + 2]), int(data[pos + 3]))
        pos += 4
        total = 0
        half = [0] * n
        for i in range(n):
            p = int(data[pos])
            pos += 1
            total += p
            half[i] = p - p // 2      # 半价收益 = ⌈p/2⌉
        half.sort(reverse=True)
        total -= b * k + sum(half[:a])
        out.append(str(total))
    sys.stdout.write("\n".join(out) + "\n")


def run_tests():
    """官方样例 + 边界/变形用例一网打尽。"""
    import io

    test_cases = [
        # 官方样例 1：半价券挑收益最大的两件（12 与 10）
        (
            "1\n4 2 1 5\n10 3 8 12\n",
            "17",
        ),
        # 官方样例 2：没有半价券，只有两张减免券
        (
            "1\n3 0 2 4\n7 8 9\n",
            "16",
        ),
        # 官方样例 3：两组，第一组减成负数，第二组无券可用
        (
            "2\n1 1 1 100\n50\n2 0 0 10\n100 200\n",
            "-75\n300",
        ),
        # 官方样例 4：总和可以为负
        (
            "1\n2 2 1 1\n1 1\n",
            "-1",
        ),
        # 半价券用满 a=n，k 很大把总和减成负数：7 - (2+2) - 1000 = -997
        (
            "1\n2 2 1 1000\n3 4\n",
            "7 - (2 + 2) - 1000",
        ),
        # 半价券挑 top-a：sum=12，收益 4+2=6，再减 b*k=2 → 4
        (
            "1\n3 2 1 2\n8 1 3\n",
            "12 - (4 + 2) - 2",
        ),
        # 收益相同的多件商品选哪件都一样（平局不影响总和）：sum=20 - (3+3)
        (
            "1\n4 2 0 0\n5 5 5 5\n",
            "20 - (3 + 3)",
        ),
    ]

    for i, (inp, expected) in enumerate(test_cases, 1):
        old_stdin, old_stdout = sys.stdin, sys.stdout
        sys.stdin = io.TextIOWrapper(io.BytesIO(inp.encode("utf-8")))
        sys.stdout = io.StringIO()
        try:
            solve()
            output = sys.stdout.getvalue().strip()
        finally:
            sys.stdin, sys.stdout = old_stdin, old_stdout

        # 期望值写成算式（单行、含空格）的条目在这里求值
        if expected and "\n" not in expected and not expected.lstrip("-").isdigit():
            expected = str(eval(expected))
        status = "✓" if output == expected else "✗"
        print(f"样例 {i}: 期望={expected}, 实际={output} {status}")

    # 随机小规模暴力对拍：枚举半价券的每种使用组合与穷举对比
    import itertools
    import random

    rng = random.Random(20260328)
    ok = True
    for case in range(300):
        n = rng.randint(1, 6)
        p = [rng.randint(1, 20) for _ in range(n)]
        a = rng.randint(0, n)
        b = rng.randint(0, n)
        k = rng.randint(0, 30)
        base = sum(p) - b * k
        best = base - sum(sorted((x - x // 2 for x in p), reverse=True)[:a])
        # 暴力：逐个尝试半价券的所有用法
        brute = base
        for pick in itertools.combinations(range(n), a):
            gain = sum(p[i] - p[i] // 2 for i in pick)
            brute = min(brute, base - gain)
        if best != brute:
            ok = False
            print(f"对拍失败: n={n} p={p} a={a} b={b} k={k} "
                  f"贪心={best} 暴力={brute}")
            break
    print(f"随机暴力对拍 300 组: {'✓' if ok else '✗'}")


if __name__ == "__main__":
    if len(sys.argv) > 1 and sys.argv[1] == "--test":
        run_tests()
    else:
        solve()

```

## 示例推演

样例 1：标价 $10, 3, 8, 12$，$a=2$、$b=1$、$k=5$。半价收益 $\lceil p/2 \rceil$ 分别是 $5, 2, 4, 6$，排序后取前两个：$6+5=11$；减免总量 $b\cdot k = 5$；初始总价 $33$。答案 $33 - 11 - 5 = 17$。

样例 3 的第一组体验"减成负数"：单件 $50$，$a=1$、$b=1$、$k=100$。半价收益 $\lceil 50/2\rceil = 25$，减免 $100$，总价 $50 - 25 - 100 = -75$。若按直觉把价格夹在 $0$，这组就会从 $-75$ 算成 $0$——两种收益能否自由叠加，正是这题解耦成立的前提。

样例 4 体验"券多商品少"：两件商品都是 $1$，$a=2$、$b=1$、$k=1$。半价收益各 $1$，取满 $a=2$ 张共减 $2$；再减 $k=1$；总价 $2 - 2 - 1 = -1$。

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| ---- | ---------- | ---------- | ---- |
| 枚举每张半价券落在哪件商品 | $O(2^n \cdot n)$ | $O(n)$ | $n$ 到 $2\times10^5$ 时完全不可行 |
| 逐张扫描选最大收益 | $O(n \cdot a)$ | $O(n)$ | $a$ 可达 $n$，退化成平方级 |
| 每组一次排序取前 $a$ 个（最优） | $O(\sum n\log n)$ | $O(n)$ | 本题采用；$\sum n \le 4\times10^5$ 毫无压力 |

---

## 易错点总结

### 1. 半价收益算成 $\lfloor p/2 \rfloor$

收益是"从 $p$ 降到 $\lfloor p/2 \rfloor$"省下的钱，即 $p - \lfloor p/2 \rfloor = \lceil p/2 \rceil$，在 `half[i] = p - p // 2` 这一行。若错写成 $\lfloor p/2 \rfloor$，样例 1 会从 $33$ 里减 $5+4=9$ 而不是 $6+5=11$，输出 $19$ 而不是 $17$；奇数标价越多，误差积累得越厉害。

### 2. 依照"价格不为负"的直觉去封顶

题面明确说减完可以变成负数，`total -= b * k + sum(half[:a])` 是一次性的线性减免。若给每件商品的价格减完后 `max(0, ...)`，样例 3 的第一组会算成 $0$ 而不是 $-75$——而这一组恰恰是题目放在那里检验这条设定的。

## 扩展思考

- 本题是"贡献分离 + 各自贪心"的模板：能证明每张券的收益与其它券的使用无关时，问题就退化成若干个独立的 top-k 挑选。若改成"减免后不能再半价"，收益不再可分离，排序贪心立刻失效。
- 多组数据 $\sum n$ 有限时，所有组共享一次整块读入是机考的通用提速习惯；单组 `input()` 在 $T = 2\times10^5$ 时可能先超在 IO 上。
