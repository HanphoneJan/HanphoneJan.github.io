# P4957. 闪耀之塔

> 场次：2026年5月16日-开发岗 · 来源：[CodeFun2000 P4957](https://codefun2000.com/p/P4957)

## 题目描述

在一座珍宝工坊中，有一排从左到右放置的展示盒，初始为空。工匠需要依次将 $n$ 个宝石放入盒子中。每个宝石都有一个闪耀值，按照放入顺序编号为 $1$ 到 $n$。放置规则如下：
- 从最左侧的盒子开始向右检查；
- 若当前盒子为空，或盒内最上层宝石的闪耀值严格大于当前宝石的闪耀值，则将当前宝石叠放到该盒子顶部；
- 否则继续检查下一个盒子；
- 若检查完所有非空盒子后仍未放入，则在最右侧新建一个展示盒，并将当前宝石放入其中。

每次放入一个宝石后，记录每个盒子中宝石的数量（称为层数）。请你求出每次放入后所有盒子层数的异或和，并依次输出。

数据范围：输入包含多组测试数据，组数 $T$ 满足 $1 \le T \le 2 \times 10^5$。所有测试数据中宝石的总数（即 $\sum n$）不超过 $4 \times 10^5$。单个测试用例中的宝石数量 $n$ 满足 $1 \le n \le 4 \times 10^5$。每个宝石的闪耀值为正整数，且不超过 $10^9$。

## 输入格式

第一行包含一个整数 $T$，表示测试数据组数。接下来对于每组数据：第一行包含一个整数 $n$，表示该组宝石的数量；第二行包含 $n$ 个整数，依次表示每个宝石的闪耀值，整数之间以空格分隔。

## 输出格式

对于每组数据，输出一行 $n$ 个整数，用空格分隔，第 $i$ 个整数表示放入前 $i$ 个宝石后所有盒子层数的异或和。

## 示例

### 示例 1

**输入：**

```
1
5
5 4 3 2 1
```

**输出：**

```
1 2 3 4 5
```

**说明：**

初始无任何展示盒。放入第 `1` 个宝石（闪耀值 `5`），创建盒子 `1`，高度为 `1`，当前所有盒子层数的异或和为 $1$。

放入第 `2` 个宝石（闪耀值 `4`），第一个盒子顶部为 `5`，严格大于 `4`，因此放入该盒，高度由 `1` 变为 `2`，异或和变为 $1 \oplus 1 \oplus 2 = 2$。

同理，后续宝石 `3`、`2`、`1` 均放入唯一的盒子中，使其高度依次变为 `3`、`4`、`5`，每次异或和即为当前高度。最终输出序列为 `1 2 3 4 5`。

### 示例 2

**输入：**

```
1
6
3 5 2 4 2 1
```

**输出：**

```
1 0 3 0 1 0
```

**说明：**

初始无盒子。

- 放入 `3`：新建盒子，高度 `1`，异或和 $1$。
- 放入 `5`：无盒子顶部严格大于 `5`，新建第二个盒子，高度 `1`，异或和 $1 \oplus 1 = 0$。
- 放入 `2`：第一个盒子顶部 `3` 严格大于 `2`，放入后高度由 `1` 变为 `2`，异或和 $0 \oplus 1 \oplus 2 = 3$。
- 放入 `4`：当前顶部为 $[2,5]$，第二个盒子顶部 `5` 严格大于 `4`，放入后高度由 `1` 变为 `2`，异或和 $3 \oplus 1 \oplus 2 = 0$。
- 放入 `2`：顶部变为 $[2,4]$，第一个严格大于 `2` 的是第二个盒子（顶部 `4`），放入后高度由 `2` 变为 `3`，异或和 $0 \oplus 2 \oplus 3 = 1$。
- 放入 `1`：第一个盒子顶部 `2` 严格大于 `1`，高度由 `2` 变为 `3`，异或和 $1 \oplus 2 \oplus 3 = 0$。

依次输出每次操作后的异或和：`1 0 3 0 1 0`。

### 示例 3

**输入：**

```
1
4
10 10 10 10
```

**输出：**

```
1 0 1 0
```

**说明：**

所有宝石的闪耀值均为 `10`。

放入第 `1` 个宝石：新建盒子 `1`，高度为 `1`，异或和 $1$。

放入第 `2` 个宝石：当前唯一盒子的顶部为 `10`，并不严格大于 `10`，因此无法放入，只能新建盒子 `2`，高度为 `1`，此时两个高度 `1` 的盒子异或和变为 $1 \oplus 1 = 0$。

放入第 `3` 个宝石：依然无法放入已有盒子，新建盒子 `3`，高度 `1`，异或和变为 $0 \oplus 1 = 1$。

放入第 `4` 个宝石：继续新建盒子 `4`，异或和回到 $0$。

由此可见，当所有闪耀值相等时，每次均会新建盒子，异或和序列在 `1` 与 `0` 之间交替。最终输出 `1 0 1 0`。

## 解题思路

### 一、输出是每一步的异或和，盒子只需记住「层数」和「盒顶」

每组输出 $n$ 个整数，第 $i$ 个是放完前 $i$ 颗宝石后所有盒子层数的异或和。判断一颗新宝石能否放进某个盒子时，规则只看该盒最上层那颗宝石的闪耀值，所以盒内更下面的宝石从此不再参与任何判断。每个盒子只要维护两个量：层数 `height`（进入异或和）和盒顶值 `top`（参与放置判断）。代码里就是两个平行数组 `top` 和 `height`（第 39–40 行）。

### 二、关键观察：盒顶序列始终非递减，于是「第一个严格大于 x」= `bisect_right`

按规则，盒子从左到右建立；每次要么在最右侧追加一个新盒子，要么改某一个盒子的盒顶。可以归纳证明 `top` 数组始终非递减：

- 初始为空，成立；
- 新建盒子时，说明所有盒顶都 $\le x$（没有任何一个严格大于 $x$），把 $x$ 追加到末尾仍然非递减；
- 放进第 `pos` 个盒子时，`pos` 是第一个满足 `top[pos] > x` 的位置，所以左边（如果有）有 `top[pos-1] <= x`，右边有 $x <$ 原来的 `top[pos]`。把 `top[pos]` 改成 $x$ 后，它与左边的 `top[pos-1]`、右边的 `top[pos+1]`（如果有）之间仍然有序，非递减性保持。

既然 `top` 有序，「第一个盒顶严格大于 $x$ 的盒子」就是「盒顶 $\le x$ 的盒子个数」，即 `bisect_right(top, x)`：它跳过所有等于 $x$ 的盒顶，返回第一个严格大于 $x$ 的位置；返回值等于盒子个数时表示要新建（第 44–49 行）。「严格」二字决定了必须用 `bisect_right` 而不是 `bisect_left`。

为什么是这个算法：单组 $n$ 最多 $4\times 10^5$，所有组的 $n$ 之和也不超过 $4\times 10^5$，而组数 $T$ 可以到 $2\times 10^5$。如果每颗宝石都从最左边的盒子开始线性扫描，严格递增的输入会让每颗宝石都新建盒子、每步扫过全部已有盒子，总代价 $O(n^2)$；$n=4\times 10^5$ 时约 $1.6\times 10^{11}$ 次比较，跑不完。二分把每次定位压到 $O(\log n)$，总代价 $O(n\log n)$。

### 三、异或和只改动一个盒子，可以在线增量维护

设当前异或和为 `cur`。放一颗宝石只会改变一个盒子的层数：

- 放进第 `pos` 个盒子：层数 $h \to h+1$。异或和里要把旧值 $h$ 换成 $h+1$，利用 $u \oplus u = 0$，执行 `cur ^= h ^ (h + 1)` 即可（第 51–54 行）；
- 新建盒子：多了一个层数 1，执行 `cur ^= 1`（第 49 行）。

每步只做常数次异或，不需要重新扫所有盒子求异或和。`top[pos] = x` 的原地赋值（第 56 行）之所以不破坏有序性，正是上一条归纳里验证过的：$x$ 落在 `top[pos-1]` 和原来的 `top[pos]` 之间。

## 完整代码实现

```python
"""
P4957. 闪耀之塔 - 盒顶数组 + 二分（模拟）

n 个宝石按闪耀值依次放入一排盒子：从左往右找第一个「盒顶严格大于当前
宝石」的盒子叠上去；找不到就在最右侧新建盒子。每次放完记录所有盒子
层数的异或和。

核心思路：
1. 只需维护每个盒子的盒顶值 top[]。盒子一旦放过宝石就永不为空，所以
   放置规则就是「第一个 top 严格大于 x 的盒子，没有就新建」。
2. 关键观察：top[] 始终非递减。归纳：选中盒子 i 时它是第一个严格大于
   x 的位置，即 top[i-1] <= x < top[i]；替换后新的 top[i] = x 落在
   [top[i-1], top[i]) 里，且 x < 原来的 top[i] <= top[i+1]，非递减不变；
   新建盒子时所有盒顶都 <= x，把 x 追加在末尾同样有序。
   于是「第一个严格大于 x 的位置」就是 bisect_right(top, x)，二分完成，
   选中后直接原地赋值即可，数组仍有序。
3. 异或和增量维护：选中第 i 个盒子时层数 h 变为 h+1，异或和
   X ^= h ^ (h+1)；新建盒子时 X ^= 1。

输入格式：
- 第 1 行：T；
- 每组：第一行 n；第二行 n 个闪耀值。

输出格式：
- 每组一行 n 个整数，第 i 个是放入前 i 个宝石后的层层数异或和。

时间复杂度：单组 O(n log n)（bisect 在 C 层）
空间复杂度：O(n)
"""

# https://codefun2000.com/p/P4957
import io
import sys
from bisect import bisect_right


def tower_xors(seq):
    """依次放入 seq 的宝石，返回每一步的层数异或和。"""
    top = []      # 各盒子盒顶闪耀值，始终非递减
    height = []   # 各盒子层数
    cur = 0       # 当前所有盒子层数的异或和
    res = []
    for x in seq:
        pos = bisect_right(top, x)  # 第一个盒顶严格大于 x 的盒子
        if pos == len(top):
            # 没有盒子能放：最右侧新建
            top.append(x)
            height.append(1)
            cur ^= 1
        else:
            h = height[pos]
            # 层数 h -> h+1，异或和先去掉旧值再加上新值
            cur ^= h ^ (h + 1)
            height[pos] = h + 1
            # x >= top[pos-1] 且 x < 原来的 top[pos]，原地赋值仍有序
            top[pos] = x
        res.append(cur)
    return res


def solve():
    data = sys.stdin.buffer.read().split()
    it = iter(data)
    t = int(next(it))
    out = []
    for _ in range(t):
        n = int(next(it))
        seq = [int(next(it)) for _ in range(n)]
        out.append(" ".join(map(str, tower_xors(seq))))
    sys.stdout.write("\n".join(out) + "\n")


def run_tests():
    """运行嵌入的官方样例，并用逐盒暴力模拟对拍随机序列。"""
    import random

    test_cases = [
        # 官方样例 1：一路叠进唯一的盒子
        ("1\n5\n5 4 3 2 1\n", "1 2 3 4 5"),
        # 官方样例 2：找第一个盒顶严格大于当前宝石的盒子
        ("1\n6\n3 5 2 4 2 1\n", "1 0 3 0 1 0"),
        # 官方样例 3：全部相等 -> 「严格大于」不成立，每步都新建
        ("1\n4\n10 10 10 10\n", "1 0 1 0"),
        # 单个宝石
        ("1\n1\n7\n", "1"),
        # 严格递增：每次都新建，异或和 1,0,1,0,...
        ("1\n5\n1 2 3 4 5\n", "1 0 1 0 1"),
        # n=1 组数组相邻（T 组循环边界）
        ("2\n1\n7\n1\n7\n", "1\n1"),
    ]

    for i, (inp, expected) in enumerate(test_cases, 1):
        old_stdin, old_stdout = sys.stdin, sys.stdout
        sys.stdin = io.TextIOWrapper(io.BytesIO(inp.encode("utf-8")))
        sys.stdout = io.StringIO()
        try:
            solve()
            output = sys.stdout.getvalue().strip()
        finally:
            sys.stdin, sys.stdout = old_stdin, old_stdout

        status = "✓" if output == expected else "✗"
        print(f"样例 {i}: 期望={expected}, 实际={output} {status}")

    # 暴力对拍：老实维护每个盒子的栈，找第一个严格大于的盒子
    def brute(seq):
        tops = []   # 每盒只有盒顶有意义
        out = []
        cur = 0
        heights = []
        for x in seq:
            placed = False
            for bi in range(len(tops)):
                if tops[bi] > x:
                    cur ^= heights[bi] ^ (heights[bi] + 1)
                    heights[bi] += 1
                    tops[bi] = x
                    placed = True
                    break
            if not placed:
                tops.append(x)
                heights.append(1)
                cur ^= 1
            out.append(cur)
        return out

    random.seed(20261027)
    fail = None
    for case_no in range(1, 1501):
        n = random.randint(1, 40)
        seq = [random.randint(0, 12) for _ in range(n)]
        got = tower_xors(seq)
        want = brute(seq)
        if got != want:
            fail = (seq, want, got)
            break
    print("暴力对拍 1500 组随机序列：" + ("全部一致" if fail is None else f"失败 {fail}"))
    if fail is not None:
        return

    # 断言「top 非递减」的归纳不变量确实被代码保持
    random.seed(99)
    for case_no in range(1, 501):
        n = random.randint(1, 60)
        seq = [random.randint(0, 30) for _ in range(n)]
        top = []
        for x in seq:
            pos = bisect_right(top, x)
            if pos == len(top):
                top.append(x)
            else:
                top[pos] = x
            if any(top[i] > top[i + 1] for i in range(len(top) - 1)):
                print(f"不变量破坏: seq={seq} top={top}")
                return
    print("top 非递减不变量 500 组随机校验通过")


if __name__ == "__main__":
    if len(sys.argv) > 1 and sys.argv[1] == "--test":
        run_tests()
    else:
        solve()
```

## 示例推演

样例 2：`3 5 2 4 2 1`。

| 步 | 宝石 $x$ | `bisect_right(top, x)` | 操作 | 盒顶 `top` | 层数 `height` | 异或和 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | 3 | 0（等于盒子数） | 新建盒子 1 | `[3]` | `[1]` | 1 |
| 2 | 5 | 1（等于盒子数） | 新建盒子 2 | `[3, 5]` | `[1, 1]` | $1 \oplus 1 = 0$ |
| 3 | 2 | 0 | 盒子 1：层数 1→2 | `[2, 5]` | `[2, 1]` | $0 \oplus 1 \oplus 2 = 3$ |
| 4 | 4 | 1 | 盒子 2：层数 1→2 | `[2, 4]` | `[2, 2]` | $3 \oplus 1 \oplus 2 = 0$ |
| 5 | 2 | 1 | 盒子 2：层数 2→3 | `[2, 2]` | `[2, 3]` | $0 \oplus 2 \oplus 3 = 1$ |
| 6 | 1 | 0 | 盒子 1：层数 2→3 | `[1, 2]` | `[3, 3]` | $1 \oplus 2 \oplus 3 = 0$ |

逐步解释两个关键位置：

- 第 3 步：`top = [3, 5]`，`bisect_right` 在 2 上返回 0，因为第一个盒顶 3 就严格大于 2，宝石落在盒子 1，盒顶从 3 变成 2，`top` 仍是 `[2, 5]`；
- 第 5 步：`top = [2, 4]`，`bisect_right` 在 2 上返回 1。第一个盒顶 2 并不严格大于 2，必须跳过；第二个盒顶 4 才满足。若这里误用了 `bisect_left`，就会返回 0、错误地压进盒子 1。

输出序列为 `1 0 3 0 1 0`，与示例一致。样例 3 是另一个极端：四颗宝石都是 10，`bisect_right` 每次都返回当前盒子数，于是每步都新建盒子，异或和在 1 和 0 之间交替，输出 `1 0 1 0`。

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| ---- | ---------- | ---------- | ---- |
| 逐盒线性扫描 | $O(n^2)$ | $O(n)$ | 每颗宝石从最左盒子顺序比较；严格递增输入每步都要扫过全部盒子 |
| 有序盒顶 + 二分（最优） | $O(n\log n)$ | $O(n)$ | 每次 `bisect_right` 定位 $O(\log n)$，改盒顶与更新异或和 $O(1)$ |

按 $\sum n \le 4\times 10^5$ 计算，二分的比较次数在千万级；`top` 与 `height` 各占 $O(n)$ 空间。

## 易错点总结

### 1. 「严格大于」必须用 `bisect_right`，不能用 `bisect_left`

第 44 行的 `bisect_right(top, x)` 跳过所有等于 $x$ 的盒顶，才对应「盒顶严格大于当前宝石」。换成 `bisect_left` 后，盒顶等于 $x$ 的盒子会被误判为可放：样例 3（四颗宝石全为 10）会把它们都堆进第一个盒子，输出 `1 2 3 4`，而正确输出是 `1 0 1 0`。

### 2. 改完层数忘记把新盒顶写回，非递减性被破坏

第 56 行 `top[pos] = x` 是维持有序数组的关键。删掉这一行，`top` 里留下的还是旧盒顶，下一次 `bisect_right` 会指向错误的盒子：样例 2 的最后一步（宝石 1）会落进已经有三层的第一个盒子，把它变成 4 层，末位输出 6，整行变成 `1 0 3 0 1 6`，而正确结果是 `1 0 3 0 1 0`。

### 3. 异或和只加新值、忘记消掉旧层数

第 53 行 `cur ^= h ^ (h + 1)` 把旧层数 $h$ 和新层数 $h+1$ 一起异或，等价于「从异或和里去掉 $h$、加入 $h+1$」。只写 `cur ^= h + 1` 的话，旧层数会一直留在异或和里：样例 2 第 3 步得到 $0 \oplus 2 = 2$（正确是 3），之后整行都跟着错。

## 扩展思考

- 这串盒顶就是「耐心排序」里的牌堆顶。把规则里的「严格大于」换成「大于等于」，只需把查询从 `bisect_right` 改成 `bisect_left`，非递减性的证明一字不变。
- 如果题目要的是盒子个数而不是异或和，维护 `len(top)` 即可；要的是最大层数，则用一个变量跟着 `height[pos]` 更新。
