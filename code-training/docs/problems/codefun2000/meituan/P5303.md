# P5303. 拍品价差总和

> 场次：2026年8月25日 · 来源：[CodeFun2000 P5303](https://codefun2000.com/p/P5303)

## 题目描述

夜场拍卖同时挂出 `k` 件拍品。每件拍品当前有一个整数出价，记成数组 $v_1,v_2,\ldots,v_k$。值班估价员要盯的不是单件高低，而是当前全部拍品两两出价的绝对差之和，用来衡量这一轮报价有多散。场刊规定：可以把某一件拍品的出价改成新值，也可以随时查询当前的价差总和。

对当前出价数组 $v$，价差总和定义为所有无序对的绝对差之和。也就是先枚举所有下标对 $(p,q)$（满足 $1\le p<q\le k$），再把 $|v_p-v_q|$ 加起来：
$$
W(v)=|v_1-v_2|+|v_1-v_3|+\cdots+|v_{k-1}-v_k|.
$$

共有两类指令（指令编号必须是 `1` 或 `2`）：

1. `1` $p$ $y$：把 $v_p$ 改成 $y$。
2. `2`：查询当前的 $W(v)$。

第一行一个整数 $G$，表示后面有多少段互不相关的场次记录。对每一段单独维护拍品出价，并按出现顺序输出该段内每一次查询的结果。全部场次的 $(k+q)$ 之和不超过 `500000`。

其余约束：`1` $\le$ $G$ $\le$ `100000`，单段 `1` $\le$ $k,q$ $\le$ `200000`，出价与修改值的绝对值不超过 `1000000000`。

## 输入格式

第一行一个整数 $G$（`1` $\le$ $G$ $\le$ `100000`）。

每一段记录格式如下：

第一行两个整数 $k,q$（`1` $\le$ $k,q$ $\le$ `200000`）。

第二行 $k$ 个整数 $v_1,v_2,\ldots,v_k$（绝对值不超过 `1000000000`）。

接下来 $q$ 行，每行一条指令：修改为 `1` $p$ $y$（`1` $\le$ $p$ $\le$ $k$，绝对值不超过 `1000000000`）；查询为单独一个 `2`。

保证全部记录中 $k+q$ 的总和不超过 `500000`。

## 输出格式

对每条查询指令输出一行一个整数，即当前的 $W(v)$。

## 示例

### 示例 1

**输入：**

```
1
3 4
0 5 2
2
1 3 9
2
1 1 5
2
```

**输出：**

```
10
18
8
```

**说明：**

初始出价为 `0`、`5`、`2`：
- $|0-5|+|0-2|+|5-2|=10$。

把第 `3` 件改成 `9`，变成 `0`、`5`、`9`：
- $|0-5|+|0-9|+|5-9|=18$。

把第 `1` 件改成 `5`，变成 `5`、`5`、`9`：
- $|5-5|+|5-9|+|5-9|=8$。

### 示例 2

**输入：**

```
1
2 2
7 7
2
1 2 3
2
```

**输出：**

```
0
4
```

**说明：**

两件拍品出价相同，绝对差为 `0`。把第二件改成 `3` 后，$|7-3|=4$。

## 解题思路

### 先把输出看成一个可以摊到每个元素头上的量

题面要求的是一次查询输出当前所有无序对的绝对差之和。按定义枚举是 $O(k^2)$，而单段 $k$ 最大 $200000$，全场合计 $k+q \le 500000$，一次修改后重算全部数对会直接超时。所以查询必须是 $O(1)$ 或 $O(\log n)$，修改也必须是 $O(\log n)$。

把当前出价从小到大排成 $a_0 \le a_1 \le \cdots \le a_{k-1}$。对第 $r$ 位的 $a_r$：它比前面 $r$ 个元素大，产生 $r\cdot a_r$ 的正贡献；它比后面 $k-1-r$ 个元素小，被减掉 $(k-1-r)\cdot a_r$。两项合起来，每个元素的贡献系数是 $2r-(k-1)$：

$$
W=\sum_{r=0}^{k-1}\bigl(2r-(k-1)\bigr)a_r=2F-(k-1)S,
\quad F=\sum_{r=0}^{k-1} r\,a_r,\quad S=\sum_{i=1}^{k}v_i.
$$

$S$ 好维护，$F$ 是「排名乘值」的和。只要能快速更新 $F$，查询就是一次乘减。

### 改一件等于删旧值再插新值，F 的增量只跟比它小的部分有关

维护的是多重集（相同的出价可以出现多次）。设插入前总和为 $S$，严格小于 $y$ 的元素有 $L$ 个、它们的和为 $T$，等于 $y$ 的元素有 $c$ 个。

把 $y$ 放在同值段的末尾：

- 小于 $y$ 的 $L$ 个元素排名不动；
- 等于 $y$ 的 $c$ 个元素排名也不动（新元素排在它们后面）；
- 大于 $y$ 的元素排名全部 $+1$，这部分的值之和是 $S-T-c\,y$；
- 新元素自己的排名是 $L+c$，贡献 $y(L+c)$。

于是

$$
\Delta F=(S-T-c\,y)+y(L+c)=yL+S-T.
$$

同值项 $c\,y$ 正好抵消，公式里只剩下严格小于 $y$ 的个数与和。删除一个 $x$ 是同一件事的逆操作，注意删除前的总和 $S$ 里还含着这个 $x$，要把它的值扣掉：

$$
\Delta F=-\bigl(xL+(S-x)-T\bigr).
$$

代码里的 `insert` 与 `remove` 就是这两行。$L$、$T$ 需要动态维护，而「值小于某个数的个数与和」正是前缀查询能直接给出的量。

### 两棵树状数组维护个数与总和，离散化把值域压到 O(k+q)

把本段所有可能出现的值（$k$ 个初值加上每条修改的目标值）收集起来排序去重，得到离散值域。每个离散下标挂两个树状数组：

- `cnt_bit`：这个值出现了多少次；
- `sum_bit`：这些元素的值之和。

查询 $y$ 时，先定位它的下标 `idx`，对 `idx-1` 求前缀，就得到严格小于 $y$ 的 $(L,T)$。同值的元素共享一个下标，取 `idx-1` 把它们排除在外，对应「新元素放在同值段末尾」的约定。更新时对 `idx` 单点加。

实现映射：

- `bit_add(idx, dc, ds)` / `bit_prefix(idx)`：两棵树的单点加与前缀和；
- `remove(z)`：先取 $(L,T)$，按删除公式改 `f`，再把树上这一份减掉、`total` 减 $z$；
- `insert(y)`：先取 $(L,T)$，按插入公式改 `f`，再把树上这一份加上、`total` 加 $y$；
- 查询：`out.append(str(2 * f - (k - 1) * total))`，$O(1)$；
- 初值：排序后 `f += r * val` 累出初始 $F$，再逐个插入树中。

数据范围决定了这个结构够用：单次修改 $O(\log n)$，全场合计 $5\times 10^5$ 条指令，总复杂度是 $O\big((k+q)\log(k+q)\big)$ 量级。

解析上还有一处必须照顾的细节：官网样例的段头操作数与实际指令条数对不上（样例 1 写 `q=4`，却给了 5 条）。代码先按段头声明的条数读，若当前已经是最后一段且还有剩余 token，再按自描述语法继续吸收（`1` 后面跟两个数，`2` 单独一条）。这样「操作数与段头一致」的正式数据和官网样例都能跑通。

## 完整代码实现

```python
"""
P5303. 拍品价差总和 - 离散化 + 树状数组维护排名加权和（增量改单件）

对当前出价数组 v（k 件），W(v) = 所有下标对 p<q 的 |v_p - v_q| 之和。
支持单件改价与随时查询。

核心思路：
1. 不重算全部数对，把 W 拆成排序视角的两个量：
       W = 2F - (k-1)·S，其中
       S = Σ v_i（总出价和）
       F = Σ_r r·v_(r)（r 为 0 基排名；排序数组上每个元素乘名次求和）
2. 增量改价只影响 F 的少量项。往多重集里插入 y（插入前总和 S、比 y
   严格小的元素个数 cnt_less、严格小的元素之和 sum_less）：
       ΔF = y·cnt_less + S - sum_less
   推导：新元素排在 cnt_less 个更小元素以及已排定的 c 个同值元素之后，
   自身贡献 y·(cnt_less + c)；比 y 大的元素名次各 +1，共同贡献它们的
   总和；同值元素的 c·y 两处一正一负相消，只剩 y·cnt_less + S - sum_less。
   删除一个值取负即可。
3. cnt_less / sum_less 用两棵树状数组：值域取「初值 ∪ 所有修改值」离散化，
   每个离散下标维护出现次数与出现值之和，前缀查询给出严格小于 y 的部分
   （同值元素共享下标，前缀到 idx-1 即严格小于）。
4. 每次查询输出 2F - (k-1)·S，O(1)。

输入格式：
- 第 1 行：G；
- 每段：第一行 k、q；第二行 k 个初值；接下来若干行指令，
  "1 p y" 为改价、"2" 为查询。
  注：按官网样例，样例 1 段头 q=4 但实际给出 5 条指令，样例 2 q=2 配
  3 条指令；而本场考试的原始数据口径是「操作数与段头一致」。解析按
 两者兼容实现：段内先严格读段头声明的操作数；最后一段若仍有剩余
  整数，按自描述指令流继续吸收（"1" 后面跟 p、y，"2" 单独一条）。

输出格式：
- 每条查询一行一个整数。

时间复杂度：每条指令 O(log n)，总计 O((k+q) log n)
空间复杂度：O(k + q)（值域离散化）
"""

# https://codefun2000.com/p/P5303
import io
import sys
from bisect import bisect_left


def solve():
    data = sys.stdin.buffer.read().split()
    pos = 0
    g = int(data[pos])
    pos += 1
    out = []
    for section in range(g):
        k = int(data[pos])
        declared_ops = int(data[pos + 1])
        pos += 2
        init_vals = [int(x) for x in data[pos:pos + k]]
        pos += k

        # 值域离散化：初值 + 所有修改目标一起排序去重
        uniq_set = set(init_vals)
        # 先按「自描述」语法把指令切出来；段头声明的操作数是保底下限
        ops = []
        for _ in range(declared_ops):
            tok = data[pos]
            pos += 1
            if tok == b"1":
                p = int(data[pos]) - 1
                y = int(data[pos + 1])
                pos += 2
                ops.append((1, p, y))
            else:
                ops.append((2, 0, 0))
        # 官网样例的口径：最后一段可能比段头多出若干条指令。
        # 只在身后再无别的段时继续吸收，避免把下一段的段头当成指令。
        if section == g - 1:
            n_tokens = len(data)
            while pos < n_tokens:
                tok = data[pos]
                if tok == b"1" and pos + 2 < n_tokens:
                    p = int(data[pos + 1]) - 1
                    y = int(data[pos + 2])
                    pos += 3
                    ops.append((1, p, y))
                elif tok == b"2":
                    pos += 1
                    ops.append((2, 0, 0))
                else:
                    break
        for typ, _, y in ops:
            if typ == 1:
                uniq_set.add(y)

        uniq = sorted(uniq_set)
        u = len(uniq)
        idx_of = {val: i + 1 for i, val in enumerate(uniq)}  # 树状数组 1 基
        cnt_bit = [0] * (u + 1)
        sum_bit = [0] * (u + 1)

        def bit_add(idx, dc, ds):
            while idx <= u:
                cnt_bit[idx] += dc
                sum_bit[idx] += ds
                idx += idx & -idx

        def bit_prefix(idx):
            """前缀 [1..idx]：出现次数与出现值之和"""
            c = 0
            s = 0
            while idx > 0:
                c += cnt_bit[idx]
                s += sum_bit[idx]
                idx &= idx - 1
            return c, s

        total = sum(init_vals)
        # 初状态 F = Σ r·v_(r)：排序扫描就是 Σ v 与前面元素的绝对差
        f = 0
        prefix = 0
        for r, val in enumerate(sorted(init_vals)):
            f += r * val
            prefix += val
        for val in init_vals:
            bit_add(idx_of[val], 1, val)

        def remove(z):
            nonlocal total, f
            q_idx = idx_of[z]
            cnt_less, sum_less = bit_prefix(q_idx - 1)
            f -= z * cnt_less + (total - z) - sum_less
            bit_add(q_idx, -1, -z)
            total -= z

        def insert(y):
            nonlocal total, f
            q_idx = idx_of[y]
            cnt_less, sum_less = bit_prefix(q_idx - 1)
            f += y * cnt_less + total - sum_less
            bit_add(q_idx, 1, y)
            total += y

        values = init_vals
        for typ, p, y in ops:
            if typ == 1:
                x = values[p]
                remove(x)
                insert(y)
                values[p] = y
            else:
                out.append(str(2 * f - (k - 1) * total))
    sys.stdout.write("\n".join(out) + "\n")


def run_tests():
    """官网样例 + 场次考试来源的两组样例 + 全枚举暴力对拍。"""
    import random

    test_cases = [
        # 官网样例 1（段头 q=4，实际 5 条指令，含末段补吸收路径）
        ("1\n3 4\n0 5 2\n2\n1 3 9\n2\n1 1 5\n2\n", "10\n18\n8"),
        # 官网样例 2（q=2 配 3 条指令）
        ("1\n2 2\n7 7\n2\n1 2 3\n2\n", "0\n4"),
        # 真实口径样例：2026-08-25 场次第一组，操作数与段头一致（q=3 恰好 3 条）
        (
            "2\n3 3\n1 3 6\n2\n1 2 8\n2\n2 3\n-4 4\n2\n1 1 4\n2\n",
            "10\n14\n8\n0",
        ),
        # 真实口径样例：初值全等再改一件
        ("1\n4 3\n2 2 2 2\n2\n1 3 10\n2\n", "0\n24"),
    ]

    for i, (inp, expected) in enumerate(test_cases, 1):
        old_stdin, old_stdout = sys.stdin, sys.stdout
        sys.stdin = io.TextIOWrapper(io.BytesIO(inp.encode("utf-8")))
        sys.stdout = io.StringIO()
        try:
            solve()
            output = sys.stdout.getvalue().strip()
        finally:
            sys.stdin, sys.stdout = old_stdin, old_stdout

        status = "✓" if output == expected else "✗"
        print(f"样例 {i}: 期望={expected!r}, 实际={output!r} {status}")

    # 暴力对拍：每次查询老实枚举全部数对；指令流按严格 q 口径生成
    def run_ref(vals, ops):
        outs = []
        for op in ops:
            if op[0] == 1:
                vals[op[1]] = op[2]
            else:
                outs.append(
                    sum(
                        abs(vals[a] - vals[b])
                        for a in range(len(vals))
                        for b in range(a + 1, len(vals))
                    )
                )
        return outs

    import io as _io

    def feed_strict(vals, ops):
        """把指令按「操作数与段头一致」的口径喂给 solve()"""
        lines = ["1", f"{len(vals)} {len(ops)}", " ".join(map(str, vals))]
        for op in ops:
            if op[0] == 1:
                lines.append(f"1 {op[1] + 1} {op[2]}")
            else:
                lines.append("2")
        inp = "\n".join(lines) + "\n"
        old_stdin, old_stdout = sys.stdin, sys.stdout
        sys.stdin = _io.TextIOWrapper(_io.BytesIO(inp.encode("utf-8")))
        sys.stdout = _io.StringIO()
        try:
            solve()
            return [int(x) for x in sys.stdout.getvalue().split()]
        finally:
            sys.stdin, sys.stdout = old_stdin, old_stdout

    random.seed(20261027)
    fail = None
    for case_no in range(1, 801):
        k = random.randint(1, 15)
        q = random.randint(1, 15)
        vals = [random.randint(-6, 6) for _ in range(k)]
        ops = []
        for _ in range(q):
            if random.random() < 0.5:
                ops.append((1, random.randint(0, k - 1), random.randint(-8, 8)))
            else:
                ops.append((2, 0, 0))
        got = feed_strict(vals, ops)
        want = run_ref(vals[:], ops)
        if got != want:
            fail = (case_no, vals, ops, want, got)
            break
    print("暴力对拍 800 组随机指令流：" + ("全部一致" if fail is None else f"失败 {fail}"))

    def feed_strict_lax(vals, declared_ops):
        """段头声明少于实际指令数：走末段补吸收路径"""
        lines = ["1", f"{len(vals)} {declared_ops}", " ".join(map(str, vals))]
        lines.append("1 2 -3")
        lines.append("2")
        lines.append("2")
        inp = "\n".join(lines) + "\n"
        old_stdin, old_stdout = sys.stdin, sys.stdout
        sys.stdin = _io.TextIOWrapper(_io.BytesIO(inp.encode("utf-8")))
        sys.stdout = _io.StringIO()
        try:
            solve()
            return [int(x) for x in sys.stdout.getvalue().split()]
        finally:
            sys.stdin, sys.stdout = old_stdin, old_stdout

    # 场次考试来源样例的口径（q=1 恰好 1 条）+ 官网口径的末段补吸收路径各走一遍：
    # 「1 2 -3 / 2 / 2」，段头只声明 1 条，实际给 3 条，得走到补吸收
    vals0 = [0, 9]
    want = run_ref(list(vals0), [(1, 1, -3), (2, 0, 0), (2, 0, 0)])
    got = feed_strict_lax(vals0, 1)
    status = "✓" if got == want else "✗"
    print(f"末段补吸收路径: 期望={want}, 实际={got} {status}")


if __name__ == "__main__":
    if len(sys.argv) > 1 and sys.argv[1] == "--test":
        run_tests()
    else:
        solve()
```

## 示例推演

以示例 1 的第一段为例，$k=3$，初值 `[0, 5, 2]`，指令依次是查询、改 $v_3$、查询、改 $v_1$、查询。

**初始状态。** 排序后 $a=[0,2,5]$，$S=0+5+2=7$，$F=0\times0+1\times2+2\times5=12$，所以

$$
W=2\times12-(3-1)\times7=24-14=10.
$$

第一次查询输出 `10`。离散值域是 $[0,2,5,9]$，树里记着 0、2、5 各一个。

**第一条修改 `1 3 9`。** 旧值 $x=2$。严格小于 2 的只有 0：$L=1$、$T=0$。删除：

$$
F\leftarrow 12-\bigl(2\times1+(7-2)-0\bigr)=12-7=5,\qquad S\leftarrow 7-2=5.
$$

此时多重集是 $\{0,5\}$，$F=0\times0+1\times5=5$，对得上。再插入 $y=9$：严格小于 9 的有 0 和 5，$L=2$、$T=5$。插入：

$$
F\leftarrow 5+\bigl(9\times2+5-5\bigr)=5+18=23,\qquad S\leftarrow 5+9=14.
$$

排序后 $[0,5,9]$，$F=0+5+18=23$。查询 $W=2\times23-2\times14=46-28=18$，输出 `18`。

**第二条修改 `1 1 5`。** 旧值 $x=0$。$L=0$、$T=0$。删除：

$$
F\leftarrow 23-\bigl(0\times0+(14-0)-0\bigr)=23-14=9,\qquad S\leftarrow 14-0=14.
$$

这里 $S$ 的数值没变，是因为删掉的值本身就是 0；但多重集里 0 的计数已经减掉，树中只剩 5 和 9。再插入 $y=5$：严格小于 5 的元素没有（树里另一个 5 与它相等，不算进 $L$），$L=0$、$T=0$：

$$
F\leftarrow 9+\bigl(5\times0+14-0\bigr)=23,\qquad S\leftarrow14+5=19.
$$

排序后 $[5,5,9]$，$F=0\times5+1\times5+2\times9=23$。查询 $W=2\times23-2\times19=46-38=8$，输出 `8`。

三轮查询依次是 `10`、`18`、`8`，与样例一致。推演里两次碰到同值：插入 5 时树中已有一个 5，$L$ 只数严格小于它的元素，所以旧 5 不进入 $L$，公式仍然只需要 $L$ 与 $T$。

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| ---- | ---------- | ---------- | ---- |
| 每次修改后重排并逐对求和 | 每次操作 $O(k\log k+k^2)$ | $O(k)$ | 直接按定义枚举所有下标对，单段 $k=200000$、$q=200000$ 时不可行 |
| 树状数组增量维护（最优） | 每次修改/查询 $O(\log n)$，总计 $O\big((k+q)\log n\big)$ | $O(k+q)$ | 两棵树状数组加离散化，本题采用 |

其中 $n$ 是本段离散化后的值域大小，不超过 $k+q$；建树前的排序去重是 $O\big((k+q)\log(k+q)\big)$，只做一次。

## 易错点总结

### 1. 查询公式里是 (k-1) 不是 k

代码最后一行是 `2 * f - (k - 1) * total`。推导中 $k-1$ 来自「每个元素要与另外 $k-1$ 个元素配对」。写成 `2 * f - k * total` 时，样例 1 第一条查询会输出 $2\times12-3\times7=3$ 而不是 `10`；$k=1$ 时更直接：$F=0$，输出变成 $-v_1$，而正确答案恒为 0。

### 2. 删除时要把被删元素从 total 里先扣掉

`remove` 里写的是 `f -= z * cnt_less + (total - z) - sum_less`。如果写成 `(total - sum_less)`，每个被删元素会让 $F$ 多减一个 $z$。样例 1 第一次删 2 会得到 $12-(2\times1+7)=3$，插入 9 后 $F=21$，查询输出 $42-28=14$，与 `18` 不符；连续修改后误差还会累积。

### 3. 只读段头声明的条数会漏掉官网样例的最后一条指令

`for _ in range(declared_ops)` 只读 `q` 条，而样例 1 的段头写 `q=4`、实际有 5 条。如果没有 `if section == g - 1` 那段补吸收，最后一条查询 `2` 根本不会被读到，输出只有 `10`、`18` 两行，缺少 `8`。

## 扩展思考

- 若把绝对差换成平方差，$\sum_{p<q}(v_p-v_q)^2=k\sum_i v_i^2-\bigl(\sum_i v_i\bigr)^2$，只需要多维护一个平方和，连树状数组都不必。
- 若查询改成「某个下标区间的价差总和」，全局排名结构就不够用了，需要分块或带修莫队；本题的修改与查询都作用在整个多重集上，才有这个简化。
