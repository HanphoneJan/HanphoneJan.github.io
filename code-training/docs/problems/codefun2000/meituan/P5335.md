# P5335. 小美的三角形图游走

> 场次：2026年9月1日 · 来源：[CodeFun2000 P5335](https://codefun2000.com/p/P5335)

## 题目描述

层台景区把观景栈道按三角形分层铺设。封园前巡检组必须从指定台位出发，把每一段栈道恰好走一遍后再回到起点，才能确认廊道全部可通行。栈道的接法由园方巡检规程固定：同层相邻台位之间有栈道，相邻两层之间再按小三角补上两条斜向栈道。在本题给出的层数范围内，这样的巡回路线一定存在。

巡检区域共有 $h$ 层。第 $r$ 层有 $r$ 个台位，从左到右编号依次为
$\frac{r(r-1)}{2}+1,\ \frac{r(r-1)}{2}+2,\ \ldots,\ \frac{r(r-1)}{2}+r$。

当 $2 \le r \le h$ 时，对每个 $1 \le c < r$，下列三段栈道都存在（无向）：

- 同层相邻：编号为 $\frac{r(r-1)}{2}+c$ 与 $\frac{r(r-1)}{2}+c+1$ 的台位之间；
- 连向上一层：编号为 $\frac{r(r-1)}{2}+c$ 与 $\frac{(r-1)(r-2)}{2}+c$ 的台位之间；
- 另一条斜向：编号为 $\frac{r(r-1)}{2}+c+1$ 与 $\frac{(r-1)(r-2)}{2}+c$ 的台位之间。

请给出一条从台位 $s$ 出发、每段栈道恰好经过一次、并回到 $s$ 的巡回。若有多种走法，输出任意一种即可。

层数满足 $2 \le h \le 10^3$，出发台位满足 $1 \le s \le h(h+1)/2$。一次输入中任务数 $k$ 满足 $1 \le k \le 5 \times 10^1$，且所有任务的 $h$ 之和不超过 $10^3$。

## 输入格式

第一行一个整数 $k$（$1 \le k \le 50$），表示随后的巡检任务数量。

接下来 $k$ 行，每行两个整数 $h$、$s$（$2 \le h \le 10^3$，$1 \le s \le h(h+1)/2$），表示该次任务的层数和出发台位。

保证所有任务的 $h$ 之和不超过 $10^3$。

## 输出格式

对每个任务输出一行，包含 $3 \times h \times (h-1)/2+1$ 个整数，依次给出巡回经过的台位编号（第一个和最后一个都必须是 $s$）。

若存在多种合法路线，输出任意一种即可。评测会判定路线是否走遍每段栈道恰好一次。

## 示例

### 示例 1

**输入：**

```
1
2 3
```

**输出：**

```
3 2 1 3
```

**说明：**

只有 `2` 层，三个台位 `1`、`2`、`3` 构成一个三角形，共 `3` 段栈道。从 `3` 出发，依次走 $3\to 2$、$2\to 1$、$1\to 3$，每段恰好一次并回到起点。路径上应有 $3\times 2\times 1/2+1=4$ 个编号。

### 示例 2

**输入：**

```
1
3 4
```

**输出：**

```
4 5 2 3 5 6 3 1 2 4
```

**说明：**

`3` 层共 `9` 段栈道。从底层左侧台位 `4` 出发的一条合法巡回是
$4\to 5\to 2\to 3\to 5\to 6\to 3\to 1\to 2\to 4$。
相邻编号都是规程里的栈道，且九段各出现一次，首尾都是 `4`。

### 示例 3

**输入：**

```
2
2 2
4 7
```

**输出：**

```
2 3 1 2
7 8 4 5 2 3 5 6 9 8 5 9 10 6 3 1 2 4 7
```

**说明：**

- 第一项任务只有 `2` 层，从台位 `2` 出发，走 $2\to 3\to 1\to 2$ 即可。
- 第二项任务有 `4` 层、`18` 段栈道，从台位 `7` 出发给出一条长为 `19` 的巡回；评测只要求每段栈道恰好经过一次，不要求与该输出逐点相同。

## 解题思路

### 评测在判定什么

对每个任务输出一行台位编号序列。它合法当且仅当：相邻两个编号之间恰好是题面规程里的某一段栈道；序列共 $3\times h\times(h-1)/2+1$ 个数；首尾都等于 $s$；每一段栈道在序列的相邻对里恰好出现一次。评测逐段核对，不要求与任何参考输出逐点相同——这给了实现选择遍历顺序的自由。

### 图长什么样，欧拉性是白送的还是要证的

把台位看顶点、栈道看边。每个 $r\ge2$ 与 $1\le c<r$ 对应一个小三角形，三个顶点是 $(r,c)$、$(r,c+1)$、$(r-1,c)$；题面列的三条边（同层、连上层、斜向）正是这个小三角形的三条边，而 $(h-1)^2$ 个小三角形互不重复地覆盖整个三角形区域，边数为 $3\times(h-1)\times h/2$——与输出长度公式对上。

关键的一步是数度数：台位 $(r,c)$ 恰好属于若干个小三角形（顶角、底左、底右最多三个位置），属于 $t$ 个小三角形的台位度数恰为 $2t$，而 $t$ 的取值只有 $1$、$2$、$3$，所以**每个顶点的度数都是偶数**；图又显然连通。连通加全偶度是欧拉回路存在的充要条件——题面承诺的「巡回路线一定存在」在图结构上自动成立，不需要特殊构造。全偶度这条还顺手给出一条实现的护栏：斜向边的上层端点必须与连上层边共用同一个编号 $\frac{(r-1)(r-2)}{2}+c$（一条从 $(r,c)$ 连、一条从 $(r,c+1)$ 连），少连一条，顶层角点的度数立刻变成奇数，欧拉性就没了。

### 为什么是 Hierholzer

数据范围 $\sum h\le10^3$ 决定了边总量在 $1.5\times10^6$ 量级，任何超过 $O(E)$ 的做法都吃紧；而问题上没有可利用的贪心结构——每一步「往哪走」要靠后面有没有路兜底。这正是欧拉回路标准算法的适用场景：Hierholzer 从 $s$ 出发沿未用边随走随压栈，走到无路可走时把当前点弹出并记入答案，回头继续从未弹出的点沿剩余边出发。弹出序列拼完恰好是整条回路，均摊 $O(E)$。

对照一下两种取舍：另一种经典做法 Fleury「每次优先不走桥」更直观，但每一步都要判桥，总体 $O(E^2)$，百万边下完全跑不动；Hierholzer 不挑边、事后回填，只维护一个栈。

### 实现到代码的映射

- 邻接表按 $r$ 从小到大、同层内 $c$ 从小到大、每个 $(r,c)$ 内按 **同层 → 上层 → 斜向** 的固定顺序建边（`euler_tour` 的三层循环）。评测不挑顺序，但这个自然顺序正是官方样例输出被生成出来的顺序，对着样例调试省力。
- 无向边存两份邻接条目，走一条边时用一个全局**边号**写 `used` 标记（`used[entry >> VTX_BITS] = 1` 这一行），两个方向同时封死——按「当前方向的条目」去删会漏掉对面那份，车会顺着同一段栈道原路走回来。
- 每个点一个扫描指针 `ptr[u]`：跳过对面已用掉的条目后不再回头看，保证总扫描量均摊 $O(E)$ 而不是每次整表重扫。
- `path_rev` 收到的是回路的**逆序**（最后弹出的是起点 $s$），结束前 `reverse` 一次，读出的就是从 $s$ 开始的巡回路。

```python
"""
P5335. 小美的三角形图游走 - 欧拉回路（Hierholzer 算法）

栈道图是三角分割图：第 r 层的 r 个台位编号为 r(r-1)/2+c（c=1..r）。
对每个 r>=2 与 c<r 有三条无向边——同层相邻 (r,c)-(r,c+1)、
连向上层 (r,c)-(r-1,c)、斜向 (r,c+1)-(r-1,c)——恰好是 (h-1)^2 个
小三角形的全部三条边。每个台位恰好属于 t 个小三角形（t 取 1/2/3），
度为 2t 是偶数，图又连通，所以欧拉回路存在；题面对本数据范围同样保证。

输入格式：
- 第一行任务数 k；
- 接下来 k 行，每行两个整数 h 与出发台位 s。

输出格式：
- 每个任务一行：3*h*(h-1)/2 + 1 个整数，首尾都是 s，
  相邻两个数之间都是一段栈道，每段栈道恰好走一次。

核心思路：Hierholzer 算法。当前点没有未用过的边就弹进答案数组，
否则沿一条未用边前进并把它两个方向都标记为已用；弹栈收集到的
序列是回路的逆序，反转后从出发点读出。无向边用全局边号做已用
标记（bytearray），配一个每点一个的扫描指针实现均摊 O(E)。
边按 r 从小到大、同 r 内 c 从小到大、每个 (r,c) 内按
[同层、上层、斜向] 的顺序加入邻接表，这正是官方样例输出
所对应的遍历顺序。

复杂度：单个任务 O(h^2) 时间与空间（边数 3*h*(h-1)/2 是平方级），
全部任务之和受 sum(h) <= 1000 约束，边总量在百万级。
"""

# https://codefun2000.com/p/P5335

1

import sys
from math import isqrt

# 台位编号上限 h*(h+1)/2 <= 500500 < 2^19，邻接表元素把「边号 << 19 | 台位号」
# 编码成一个整数，省掉逐元组寻址的开销。
VTX_BITS = 19
VTX_MASK = (1 << VTX_BITS) - 1


def euler_tour(h, s):
    """返回从 s 出发走遍全部栈道的台位序列（首尾都是 s）。"""
    total = h * (h + 1) // 2          # 台位数
    edge_cnt = 3 * h * (h - 1) // 2   # 栈道数

    adj = [[] for _ in range(total + 1)]
    eid = 0
    for r in range(2, h + 1):
        cur = r * (r - 1) // 2        # 本层最左台位编号
        up = (r - 1) * (r - 2) // 2   # 上一层最左台位编号
        for c in range(1, r):
            u = cur + c
            same = u + 1              # 同层右邻
            w = up + c                # 上一层同号台位
            # 加入顺序固定：同层、上层、斜向（决定样例输出形态）
            for a, b in ((u, same), (u, w), (same, w)):
                adj[a].append((eid << VTX_BITS) | b)
                adj[b].append((eid << VTX_BITS) | a)
                eid += 1

    used = bytearray(edge_cnt)
    ptr = [0] * (total + 1)

    # Hierholzer：走到底再回填，path 收集的是回路的逆序
    stack = [s]
    path_rev = []
    push = stack.append
    pop = stack.pop
    take = path_rev.append
    while stack:
        u = stack[-1]
        aux = adj[u]
        p = ptr[u]
        last = len(aux)
        while p < last and used[aux[p] >> VTX_BITS]:
            p += 1
        ptr[u] = p
        if p < last:
            entry = aux[p]
            used[entry >> VTX_BITS] = 1
            push(entry & VTX_MASK)
        else:
            take(pop())

    path_rev.reverse()
    return path_rev


def solve():
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    k = int(next(it))
    out = []
    for _ in range(k):
        h = int(next(it))
        s = int(next(it))
        tour = euler_tour(h, s)
        out.append(" ".join(map(str, tour)))
    sys.stdout.write("\n".join(out) + "\n")


def run_tests():
    import io

    def run_case(inp):
        old_stdin, old_stdout = sys.stdin, sys.stdout
        sys.stdin = io.TextIOWrapper(io.BytesIO(inp.encode("utf-8")))
        sys.stdout = io.StringIO()
        try:
            solve()
            output = sys.stdout.getvalue()
        finally:
            sys.stdin, sys.stdout = old_stdin, old_stdout
        return output

    # 通用判题器：路线相邻两数必须是题面规程里的某段栈道，且每段恰好一次。
    def neighbors_of(h, v):
        """按题面规程给出台位 v 的全部邻台。"""
        # 定位层号 r：r(r-1)/2 < v <= r(r+1)/2
        r = isqrt(2 * v)
        while r * (r + 1) // 2 < v:
            r += 1
        while r >= 2 and (r - 1) * r // 2 >= v:
            r -= 1
        base = r * (r - 1) // 2
        c = v - base
        res = set()
        if c < r:
            res.add(v + 1)                                  # 同层右邻
        if c >= 2:
            res.add(v - 1)                                  # 同层左邻
        if r >= 2:
            upper = (r - 1) * (r - 2) // 2
            if c <= r - 1:
                res.add(upper + c)                          # 连上一层 (r,c)-(r-1,c)
            if c >= 2:
                res.add(upper + c - 1)                      # 斜向 (r,c)-(r-1,c-1)
        if r < h:
            lower = (r + 1) * r // 2
            res.add(lower + c)                              # 下层左斜 (r+1,c)
            res.add(lower + c + 1)                          # 下层：v 作为上层点两条边
        return res

    def check_tour(h, s, tokens):
        m = 3 * h * (h - 1) // 2
        assert len(tokens) == m + 1, f"路径长度 {len(tokens)} != {m + 1}"
        assert tokens[0] == s and tokens[-1] == s, "首尾必须都是出发台位"
        seen_pairs = set()
        for a, b in zip(tokens, tokens[1:]):
            assert b in neighbors_of(h, a), f"{a}->{b} 不是合法栈道"
            key = (a, b) if a < b else (b, a)
            assert key not in seen_pairs, f"栈道 {a}-{b} 走了两次"
            seen_pairs.add(key)
        assert len(seen_pairs) == m, f"只覆盖 {len(seen_pairs)} 段，应为 {m} 段"

    test_cases = [
        # 官方样例 1：h=2，从 3 出发
        ("1\n2 3\n", "3 2 1 3"),
        # 官方样例 2：h=3，从 4 出发
        ("1\n3 4\n", "4 5 2 3 5 6 3 1 2 4"),
        # 官方样例 3：多任务
        ("2\n2 2\n4 7\n", "2 3 1 2\n7 8 4 5 2 3 5 6 9 8 5 9 10 6 3 1 2 4 7"),
    ]

    for i, (inp, expected) in enumerate(test_cases, 1):
        output = run_case(inp).strip()
        status = "✓" if output == expected else "✗"
        print(f"样例 {i}: {'通过' if output == expected else '失败'} {status}")
        assert output == expected, f"样例 {i} 官方输出不符: {output}"

    # 官方只有 3 组小样例，下面用判题器验证各规模与各型出发点。
    # h=2 的三个台位轮流当出发点（三角形任何点都成回路）。
    for s in (1, 2, 3):
        out = run_case(f"1\n2 {s}\n").split()
        check_tour(2, s, [int(x) for x in out])
    # h=3..8 覆盖顶点 / 边界 / 内部三种台位（度数 2、4、6）
    small_cases = []
    for h in range(3, 9):
        total = h * (h + 1) // 2
        small_cases.append((h, 1))                    # 全图顶点
        small_cases.append((h, total))                # 最底层右端
        small_cases.append((h, (h - 1) * h // 2 + 1)) # 最底层左端
        mid = 3 + h // 2
        if 1 <= mid <= total:
            small_cases.append((h, mid))
    batch_lines = "\n".join(f"{h} {s}" for h, s in small_cases)
    outs = run_case(f"{len(small_cases)}\n{batch_lines}\n").strip().split("\n")
    for (h, s), line in zip(small_cases, outs):
        check_tour(h, s, [int(x) for x in line.split()])
    print(f"压力用例 {len(small_cases)} 组（h=3..8 各型出发点）: 通过")

    # 边规模用例：h=60（每条约 5310 段栈道）+ 多任务共享 sum(h) 上界
    stress = [(60, 1), (60, 1830)]
    batch = "\n".join(f"{h} {s}" for h, s in stress)
    outs = run_case(f"{len(stress)}\n{batch}\n").strip().split("\n")
    for (h, s), line in zip(stress, outs):
        check_tour(h, s, [int(x) for x in line.split()])
    print("压力用例 h=60 两组: 通过")

    # 极端规模：h=1000（约 150 万段栈道），判题器全量核验一次。
    out = run_case("1\n1000 500000\n").split()
    check_tour(1000, 500000, [int(x) for x in out])
    print("压力用例 h=1000: 通过")


if __name__ == "__main__":
    if len(sys.argv) > 1 and sys.argv[1] == "--test":
        run_tests()
    else:
        solve()
```

## 示例推演

以官方样例 2 为例：$h=3$，共 $9$ 段栈道、$10$ 个位置，$s=4$。先把 $9$ 条边按建表顺序编号：

| 边号 | 两端 | 来源 |
| ---- | ---- | ---- |
| 0 | 2–3 | $r=2$ 同层 |
| 1 | 1–2 | $r=2$ 上层 |
| 2 | 1–3 | $r=2$ 斜向 |
| 3 | 4–5 | $r=3,c=1$ 同层 |
| 4 | 2–4 | $r=3,c=1$ 上层 |
| 5 | 2–5 | $r=3,c=1$ 斜向 |
| 6 | 5–6 | $r=3,c=2$ 同层 |
| 7 | 3–5 | $r=3,c=2$ 上层 |
| 8 | 3–6 | $r=3,c=2$ 斜向 |

从 4 出发，每个点沿邻接表取第一条未用边（`✗` 表示已用）前进，遇到死路就弹出并记入 `path_rev`：

| 当前点 | 邻接表（顺序内扫描） | 动作 |
| ------ | -------------------- | ---- |
| 4 | 5(3)·2(4) | 4→5（边 3） |
| 5 | 4(3)✗、**2(5)**、6(6)、3(7) | 5→2（边 5） |
| 2 | **3(0)**、1(1)、4(4)✗、5(5)✗ | 2→3（边 0） |
| 3 | 2(0)✗、**1(2)**、5(7)、6(8) | 3→1（边 2） |
| 1 | 2(1)——尚未用 | 1→2（边 1） |
| 4 | 5(3)✗、2(4)✗ | 死路，弹出 4 → `path_rev=[4]` |
| 2 | 无剩余边 | 弹出 2 → `[4,2]` |
| 1 | 3(2)✗ | 弹出 1 → `[4,2,1]` |

栈顶回到 3，从中断处继续走第二批：

| 当前点 | 动作 |
| ------ | ---- |
| 3 | 3→5（边 7，上一条未用边） |
| 5 | 5→6（边 6） |
| 6 | 6→3（边 8） |
| 3 | 死路，弹出 3 → `[4,2,1,3]` |
| 6、5 | 依次弹出 → `[4,2,1,3,6,5]` |
| 3 | 又弹出一次（栈里有两个 3）→ `[4,2,1,3,6,5,3]` |
| 2 | 2→4（边 4，最后一条边）；4 死路弹出，2、5、4 接连弹出 |

`path_rev` 收满 $10$ 个数：`4 2 1 3 6 5 3 2 5 4`。它是回路的逆序，反转后：

$$4 \to 5 \to 2 \to 3 \to 5 \to 6 \to 3 \to 1 \to 2 \to 4$$

与官方输出逐点相同。检查九段：$3,5,0,1,7,6,8,2,4$ 恰好各出现一次；中途弹出 `4`、`2`、`1` 不是失败，而是 Hierholzer 的回填机制——从 3 继续走的剩余边把断开处重新接上，`path_rev` 头尾的 4 相接成整圈。

样例 1（$h=2$）：边 $0{=}2{-}3$、$1{=}1{-}2$、$2{=}1{-}3$，从 3 走 $3\to2\to1\to3$ 后整栈弹空，`path_rev=[3,1,2,3]`，反转即 `3 2 1 3`。

---

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| ---- | ---------- | ---------- | ---- |
| Fleury 算法（每步避桥） | $O(E^2)$ | $O(E)$ | 每步都要找一条非桥边，$E\approx1.5\times10^6$ 时跑不动 |
| 把每点邻接表整表重扫找未用边 | $O(V\cdot E)$ | $O(E)$ | 回头点每被重访一次就重扫一条表 |
| Hierholzer + 边号已用标记 + 扫描指针（最优） | $O(h^2)$ | $O(h^2)$ | $E=3h(h-1)/2$，均摊每条边处理一次；全部任务受 $\sum h\le10^3$ 约束 |

---

## 易错点总结

### 1. 已用标记必须按「边」封，而不是按「方向的条目」封

无向边在邻接表里存了两份（两端各一份）。走一条边时要像 `used[entry >> VTX_BITS] = 1` 这样按全局边号标一次，让两个方向同时失效；若只把当前方向的条目删掉、忘了封对面那份，从对面点回来时这段栈道会被原路再走一遍——输出长度超过 $3h(h-1)/2+1$ 或同段重复，评测判非法。按条目就地删除的实现则要注意别删错点上的那份。

### 2. 弹栈收集的是回路的逆序

`path_rev` 最后弹出的才是出发点，直接输出整条`path_rev` 是从 $s$ 出发倒着走的那半圈开局：长度、端点都对，但作为给定的序列与样例逐点对不上（评测任取一条合法回路所以在线上未必现形，可一旦做精确对拍或自建判题器就会全线红），恢复成正向要在收尾 `reverse`。

## 扩展思考

- Hierholzer 的走到底再回填与 DFS 回溯彼此同构：都靠一个栈保存「还没绕完的点」，区别只在回入时机。把本题的邻接顺序改一改，同一段代码也适用于其它保证存在欧拉回路的构造图。
- 若题面要求的是「每点恰好一次」（哈密顿）而栈道数不变，问题立刻从多项式跳进 NP——欧拉性是三角形分割这类图特有的馈赠，换图型之前先数一遍度数奇偶。
