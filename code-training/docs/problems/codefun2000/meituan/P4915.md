# P4915. 对称画布

> 场次：2026年5月9日-开发岗 · 来源：[CodeFun2000 P4915](https://codefun2000.com/p/P4915)

## 题目描述

一位数字艺术家正在创作一幅像素画，画布由 `n` 行 `m` 列的格子组成。第 `i` 行第 `j` 列的格子初始装有 $c_{i,j}$ 克颜料。

他可以任意移动颜料：从任意格子取出若干克颜料放到另一个格子中，但每个格子中的颜料量必须保持非负整数，且所有格子的颜料总量不变。

艺术家希望最终画布同时满足以下两个对称条件：
- 关于水平中轴线对称：对于所有 $1 \le i \le n, 1 \le j \le m$，有 $X_{i,j} = X_{n+1-i, j}$；
- 关于垂直中轴线对称：对于所有 $1 \le i \le n, 1 \le j \le m$，有 $X_{i,j} = X_{i, m+1-j}$。

其中 $X_{i,j}$ 表示最终第 `i` 行第 `j` 列的颜料克数。

请你判断是否存在一种合法的颜料分配方案，如果存在，请给出任意一种最终分布；否则指出不可能。

约束条件：
- 测试数据组数 $T$ 满足 $1 \le T \le 10^5$。
- 每组数据中，行数 $n$ 和列数 $m$ 满足 $1 \le n, m \le 2 \times 10^5$，初始颜料克数 $c_{i,j}$ 满足 $0 \le c_{i,j} \le 10^9$。
- 保证单个测试点内所有数据的 $n \times m$ 之和不超过 $5 \times 10^5$。

## 输入格式

第一行包含一个整数 `T`，表示测试数据组数。
接下来每组数据按以下格式给出：
第一行包含两个整数 `n` 和 `m`，分别表示画布的行数和列数。
接下来 `n` 行，每行包含 `m` 个整数，其中第 `i` 行第 `j` 个整数表示初始颜料克数 $c_{i,j}$。

## 输出格式

对于每组测试数据，若不存在满足两个对称条件的最终分布，则输出一行 `-1`。
否则输出 `n` 行，每行包含 `m` 个非负整数，表示一种合法的最终颜料克数分布 $X$。

## 示例

### 示例 1

**输入：**

```
1
3 3
1 2 3
4 5 6
7 8 9
```

**输出：**

```
0 0 0
0 45 0
0 0 0
```

**说明：**

初始矩阵总和 $S = 1+2+\dots+9 = 45$。因为 $n=3$ 和 $m=3$ 都是奇数，中心格子 $(2,2)$ 自己构成大小为 `1` 的对称轨道。可以将所有颜料集中到中心格子，颜料总量不变，并且满足水平和垂直对称条件。因此存在可行方案，输出如上的矩阵。

### 示例 2

**输入：**

```
1
2 2
4 0
0 0
```

**输出：**

```
1 1
1 1
```

**说明：**

初始矩阵总和 $S = 4$。$n=m=2$ 都是偶数，所有对称轨道的大小均为 `4`。总和 `4` 能被 `4` 整除，因此在四个角各分配 $4 / 4 = 1$ 即可使最终矩阵对称，且总量不变。输出全 `1` 矩阵为一种可行方案。

### 示例 3

**输入：**

```
1
3 2
1 1
1 1
1 1
```

**输出：**

```
0 0
3 3
0 0
```

**说明：**

初始矩阵总和 $S = 6$。$n=3$（奇数），$m=2$（偶数），存在大小为 `2` 的左右对称轨道（例如中间行的第 `1` 列和第 `2` 列）。总和 `6` 是偶数，将 $6 / 2 = 3$ 放在中间行的两个格子上，其他格子置 `0`，即可满足对称且总量不变。

### 示例 4

**输入：**

```
1
3 2
1 2
3 4
5 6
```

**输出：**

```
-1
```

**说明：**

初始矩阵总和 $S = 1+2+3+4+5+6 = 21$。$n=3$（奇数），$m=2$（偶数），所有对称轨道的大小为 `2` 或 `4`，因此最终总和必须为偶数。这里 $S=21$ 是奇数，不能被 `2` 整除，故不存在合法方案，输出 `-1`。

## 解题思路

### 题目要的输出：任意一个合法矩阵

输出有两种形状：无解时一行 `-1`；有解时 $n$ 行、每行 $m$ 个非负整数。合法的标准是三条同时成立：

- 上下对称：$X_{i,j} = X_{n+1-i,j}$；
- 左右对称：$X_{i,j} = X_{i,m+1-j}$；
- 总量不变：$\sum X_{i,j} = S = \sum c_{i,j}$。

「可以任意搬运颜料」这句话把问题削掉了一大块：只要最终矩阵每格是非负整数、总和还是 $S$，就一定能从初始矩阵搬过去——把多出来的格子里的颜料搬给不够的格子就行。初始矩阵的具体分布不影响可行性，只有总和 $S$ 有用。

### 两次反射把格子绑成轨道

上下翻一次、左右翻一次，一个格子最多牵连出四个位置：

$$(i,j),\ (n+1-i,j),\ (i,m+1-j),\ (n+1-i,m+1-j)$$

对称条件要求这四个位置最终的值全部相等（位置重合时只算一个）。这样的一组格子叫一个轨道，轨道里每个格子的最终值记作 $v$，这个轨道对总量的贡献就是「轨道大小 $\times v$」。

轨道大小只有 1、2、4 三种：

- 大小 1：格子同时在两条中轴上，只有 $n,m$ 都是奇数时才存在，就是正中心那一格；
- 大小 2：恰好一个坐标落在中轴上。比如 $n$ 奇、$m$ 偶时，中间那一行的 $(r,j)$ 和 $(r,m+1-j)$ 就是一对；
- 大小 4：两个坐标都不在中轴上，$n,m$ 都大于等于 2 时一定存在，四个角就是最典型的一组。

### 判定只需要一个除数

最终矩阵的总量可以写成 $\sum_{\text{轨道}} |\text{轨道}| \times v$，每一项都是「轨道大小」的倍数，所以 $S$ 必须能被所有可用轨道大小的最大公约数整除。轨道大小只在 $\{1,2,4\}$ 里取，于是除数只有三种：

- $n,m$ 都是奇数：有大小 1 的轨道，任何 $S$ 都行，把 $S$ 全塞进中心格；
- 恰好一个是奇数：只有大小 2 和 4 的轨道，$S$ 必须是偶数，把 $S/2$ 放进一对大小 2 的格子；
- 都是偶数：只有大小 4 的轨道，$S$ 必须是 4 的倍数，把 $S/4$ 放进四个角。

这里不需要考虑「用多个轨道拼出 $S$」：整除成立时，大小恰好等于除数的轨道一定存在（1 对应中心格，2 对应中轴上的成对格，4 对应四个角），一个轨道就能装下全部质量，其余格子写 0。这也是构造能这么短的原因。

数据范围也在支持这个做法：$T$ 可以到 $10^5$，但所有 $n \times m$ 之和不超过 $5 \times 10^5$，所以每组花 $O(nm)$ 把矩阵读进来求和是下限，判定本身是 $O(1)$，不需要模拟搬运。

### 到代码的映射

- 87~92 行算除数：两个奇数给 `g = 1`，恰好一个奇数给 `g = 2`，否则给 `g = 4`；
- 94~97 行做判定：`total % g != 0` 就只写一行 `-1`，否则交给 `build_group` 生成矩阵；
- `build_group` 的四个分支与上面的构造一一对应：52~55 行中心格放全部，56~59 行中间行首尾各放一半，60~64 行中间列上下各放一半，65~69 行四角各放四分之一；
- 98 行把所有行拼起来一次写出，组与组之间不会多出空行。

## 完整代码实现

```python
"""
P4915. 对称画布 - 轨道质量分配（构造型）

画布 n 行 m 列，初始颜料 c[i][j]。可以任意搬运颜料（总量守恒、每格非负
整数），要求最终矩阵同时满足水平中轴线对称与垂直中轴线对称。

核心思路：
1. 两个反射把格子分成「轨道」：格子 (i,j) 与 (i, m+1-j)、(n+1-i, j)、
   (n+1-i, m+1-j) 绑在一个轨道里，最终值必须相等。任何方案的总质量
   S = Σ X[i][j] = Σ (轨道大小 × 该轨道的取值)，所以 S 必须能被「可用的
   轨道大小」表出。
2. 轨道大小只有 1、2、4 三种：
   - 大小 1：i、j 都在中轴上，仅当 n、m 都是奇数时存在；
   - 大小 2：恰好一个下标在中轴上，n、m 至少一个为奇数且 ≥2 时存在；
   - 大小 4：两个下标都不在中轴上，n、m 都 ≥2 时必然存在。
3. 于是判定的 gcd 只有三种取值：
   - n、m 都是奇数：存在大小 1 轨道，S 任意都可行（把所有颜料堆到中心格）；
   - 恰好一个奇数：可用轨道大小是 {2,4}，S 为偶数才可行；
   - 都是偶数：只有大小 4 的轨道，S 能被 4 整除才可行。
   可行时把整份 S 填进一个最小轨道（其余格子置 0），天然满足对称。

输入格式：
- 第 1 行：T；
- 每组：第一行 n、m，接下来 n 行每行 m 个整数。

输出格式：
- 无解输出一行 -1；有解输出 n 行，每行 m 个非负整数。

时间复杂度：单组 O(n*m)（读入与输出主导）
空间复杂度：O(n*m)（输出缓冲）
"""

# https://codefun2000.com/p/P4915
import io
import sys


def build_group(n, m, total):
    """给定可行判定（g 整除 total），生成一行行输出字符串。"""
    zero = " ".join(["0"] * m)

    def one_row(cells):
        toks = ["0"] * m
        for col, val in cells:
            toks[col] = val
        return " ".join(toks)

    rows = [zero] * n
    n_odd = n % 2 == 1
    m_odd = m % 2 == 1

    if n_odd and m_odd:
        # 大小 1 轨道：中心格吃下全部质量
        r, c = (n - 1) // 2, (m - 1) // 2
        rows[r] = one_row([(c, str(total))])
    elif n_odd:
        # 中间行上，(r,0) 与 (r,m-1) 是一个大小 2 轨道（m 为偶数 >= 2）
        r = (n - 1) // 2
        rows[r] = one_row([(0, str(total // 2)), (m - 1, str(total // 2))])
    elif m_odd:
        # 中间列上，(0,c) 与 (n-1,c) 是一个大小 2 轨道（n 为偶数 >= 2）
        c = (m - 1) // 2
        rows[0] = one_row([(c, str(total // 2))])
        rows[n - 1] = one_row([(c, str(total // 2))])
    else:
        # 四角构成一个大小 4 轨道
        half = str(total // 4)
        rows[0] = one_row([(0, half), (m - 1, half)])
        rows[n - 1] = one_row([(0, half), (m - 1, half)])
    return rows


def solve():
    data = sys.stdin.buffer.read().split()
    pos = 1
    t = int(data[0])
    out = []
    for _ in range(t):
        n = int(data[pos])
        m = int(data[pos + 1])
        pos += 2
        total = 0
        for _ in range(n * m):
            total += int(data[pos])
            pos += 1

        if n % 2 == 1 and m % 2 == 1:
            g = 1
        elif n % 2 == 1 or m % 2 == 1:
            g = 2
        else:
            g = 4

        if total % g != 0:
            out.append("-1")
        else:
            out.extend(build_group(n, m, total))
    sys.stdout.write("\n".join(out) + "\n")


def run_tests():
    """运行嵌入的样例与自加用例，另含随机输出的对称性自检。"""
    import random

    test_cases = [
        # 官方样例 1：3x3，全部颜料堆到中心
        (
            "1\n3 3\n1 2 3\n4 5 6\n7 8 9\n",
            "0 0 0\n0 45 0\n0 0 0",
        ),
        # 官方样例 2：2x2 全偶轨道，四角均分
        (
            "1\n2 2\n4 0\n0 0\n",
            "1 1\n1 1",
        ),
        # 官方样例 3：3x2，奇+偶，S=6 为偶数可行
        (
            "1\n3 2\n1 1\n1 1\n1 1\n",
            "0 0\n3 3\n0 0",
        ),
        # 官方样例 4：3x2，S=21 为奇数，不可行
        (
            "1\n3 2\n1 2\n3 4\n5 6\n",
            "-1",
        ),
        # 边界：1x1，唯一格子就是自己的对称中心
        ("1\n1 1\n7\n", "7"),
        # 一行四列（横向对称退化为无约束，纵向对称是成对轨道）：S 偶可行
        ("1\n1 4\n1 2 3 2\n", "4 0 0 4"),
        # 一行四列，S 奇 -> 不可行
        ("1\n1 4\n1 2 3 1\n", "-1"),
        # 两行三列（行偶列奇），中列上下均分
        (
            "1\n2 3\n1 2 2\n0 0 5\n",
            "0 5 0\n0 5 0",
        ),
        # 两行两列 S=8 -> 四角各 2
        ("1\n2 2\n1 2\n2 3\n", "2 2\n2 2"),
        # 两行两列 S=2 -> 不能被 4 整除
        ("1\n2 2\n1 1\n0 0\n", "-1"),
    ]

    for i, (inp, expected) in enumerate(test_cases, 1):
        old_stdin, old_stdout = sys.stdin, sys.stdout
        sys.stdin = io.TextIOWrapper(io.BytesIO(inp.encode("utf-8")))
        sys.stdout = io.StringIO()
        try:
            solve()
            output = sys.stdout.getvalue().strip()
        finally:
            sys.stdin, sys.stdout = old_stdin, old_stdout

        status = "✓" if output == expected else "✗"
        print(f"样例 {i}: 期望={expected!r}, 实际={output!r} {status}")

    # 随机自检：输出必须满足两条对称 + 总量守恒 + 非负整数；
    # 判 -1 时必须真的无解（S 不能被可用轨道大小表出）。
    random.seed(20261027)
    for case_no in range(1, 301):
        n = random.randint(1, 6)
        m = random.randint(1, 6)
        grid = [[random.randint(0, 9) for _ in range(m)] for _ in range(n)]
        inp = "1\n{} {}\n".format(n, m) + "\n".join(
            " ".join(map(str, row)) for row in grid
        ) + "\n"
        old_stdin, old_stdout = sys.stdin, sys.stdout
        sys.stdin = io.TextIOWrapper(io.BytesIO(inp.encode("utf-8")))
        sys.stdout = io.StringIO()
        try:
            solve()
            output = sys.stdout.getvalue()
        finally:
            sys.stdin, sys.stdout = old_stdin, old_stdout

        lines = output.strip().split("\n")
        total = sum(sum(row) for row in grid)
        if n % 2 == 1 and m % 2 == 1:
            g = 1
        elif n % 2 == 1 or m % 2 == 1:
            g = 2
        else:
            g = 4
        feasible = total % g == 0

        ok = True
        if not feasible:
            ok = lines == ["-1"]
        else:
            ok = len(lines) == n and all(len(row.split()) == m for row in lines)
            if ok:
                x = [[int(v) for v in row.split()] for row in lines]
                for i in range(n):
                    for j in range(m):
                        ok = ok and (
                            x[i][j] == x[n - 1 - i][j] and x[i][j] == x[i][m - 1 - j]
                        )
                        ok = ok and x[i][j] >= 0
                ok = ok and sum(sum(row) for row in x) == total
        if not ok:
            print(f"随机用例 {case_no} 校验失败: 输入={inp!r} 输出={output!r}")
            return
    print("随机自检 300 组全部通过")


if __name__ == "__main__":
    if len(sys.argv) > 1 and sys.argv[1] == "--test":
        run_tests()
    else:
        solve()
```

## 示例推演

以样例 1 为例：$3 \times 3$ 的矩阵，总和 $S = 1+2+\cdots+9 = 45$。

1. $n=3,m=3$ 都是奇数，除数 $g=1$；$45 \bmod 1 = 0$，可行。
2. 构造走「中心格」分支：0 起下标下中心是 `(1,1)`，把它填成 45，其余格子全 0。
3. 验证：上下看，第 0 行和第 2 行都是全 0；左右看，第 1 行是 `0 45 0`，自己对称；总量 45，与输入一致。输出

```
0 0 0
0 45 0
0 0 0
```

样例 2：$2 \times 2$，$S = 4$。两个都是偶数，除数 $g=4$；$4 \bmod 4 = 0$。四角是同一个大小 4 轨道，每格放 $4/4=1$，得到全 1 矩阵，上下、左右都对称。

样例 3：$3 \times 2$，$S=6$。$n$ 是奇数、$m$ 是偶数，除数 $g=2$；$6 \bmod 2=0$。中间行是 0 起下标的第 1 行，$(1,0)$ 与 $(1,1)$ 是同一轨道，各放 $6/2=3$，其余为 0，得到

```
0 0
3 3
0 0
```

左右两格相等，第 0 行与第 2 行也相等，总量 6。

样例 4：$3 \times 2$，$S = 1+2+3+4+5+6 = 21$。除数仍是 $g=2$，但 $21 \bmod 2 = 1$，无解，输出 `-1`。这里没有大小为 1 的轨道可用，21 克颜料无论怎么摆，总量都只能是偶数。

再补一个 $1 \times 4$、$S=8$ 的情形：$n$ 奇 $m$ 偶，$g=2$，把 $(0,0)$ 与 $(0,3)$ 各放 4，输出 `4 0 0 4`；只有一行时上下对称自动成立，左右由首尾相等保证。

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| ---- | ---------- | ---------- | ---- |
| 只判断是否存在（读入求和，不构造矩阵） | $O\big(\sum n m\big)$ | $O\big(\sum n m\big)$ | 能回答可行性，但题目还要求给出具体分布；构造不增加量级 |
| 判定 + 单轨道构造（最优） | $O\big(\sum n m\big)$ | $O\big(\sum n m\big)$ | 读入是不可避免的下限；构造只在一条轨道上写数，空间主要花在输出缓冲 |

所有测试点的 $n \times m$ 之和不超过 $5 \times 10^5$，所以总时间与总输出量都是这个量级。

## 易错点总结

### 1. 两个都是偶数时除数写成 2

87~92 行的判断链，最后 `else` 分支必须给 `g = 4`。若写成 2，$2 \times 2$、总和 2 的用例（初始矩阵 `1 1` / `0 0`）会被判成可行；接着 `build_group` 的四角分支按 `total // 4` 计算，每格是 0，输出全 0 矩阵，总量从 2 变成 0——既没守住总量，也没被判成无解。

### 2. 全奇数时漏掉 `m_odd`，落到大小 2 的分支

`build_group` 的第一个条件 `if n_odd and m_odd`（52 行）如果只写 `if n_odd`，$3 \times 3$、$S=45$ 的样例会走 56~59 行：中间行首尾各放 $45 // 2 = 22$，总量只有 44，比输入少 1 克。输出看上去仍然上下、左右对称，但总量守恒已经破了。

### 3. 大小 2 的轨道只填了一个格子

56~59 行（以及 60~64 行对称的那一支）必须同时给镜像的两个格子赋值。只写 `(0, total // 2)` 而漏掉 `(m - 1, ...)`，总量只剩一半，而且 $X_{r,0} \ne X_{r,m-1}$，左右对称也不成立——样例 3 会输出 `0 0` / `3 0` / `0 0`，总量 3 而不是 6。

## 扩展思考

如果只要求水平对称，轨道大小只剩 1 和 2，除数退化成 1 或 2，判定与构造都更简单。如果题目再加一条「搬运的颜料克数最少」，就不能只把总量堆到一条轨道上，而要按轨道分别处理盈亏，问题会从判定变成运输问题。
