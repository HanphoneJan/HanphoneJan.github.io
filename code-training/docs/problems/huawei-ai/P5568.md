# P5568. NPU梯度任务均衡调度

> 场次：2026年9月23日 · 来源：[CodeFun2000 P5568](https://codefun2000.com/p/P5568)

## 题目描述

在大模型分布式训练场景下，要把若干梯度更新任务分配到多张 NPU 上。目标是让各卡的「梯度计算总耗时」尽量均衡（即最小化「最大卡总耗时」），再按学习率衰减规则汇总总训练成本。

规则如下：

1. 任务分配：将 $grad\_times$ 划分成 $k$ 个子集（一张 NPU 对应一个子集）。每个任务必须分到恰好一个子集；在所有划分中，取「子集总和的最大值」最小的那些划分。
2. 成本计算：记 $max\_time$ 为各卡总耗时的最大值，$sum\_time\_j$ 为第 $j$ 张卡的总耗时。则
   - 第 $j$ 张卡学习率：$lr\_j = base\_lr \times decay\_rate^{max\_time - sum\_time\_j}$；
   - 第 $j$ 张卡训练成本：$sum\_time\_j \times lr\_j$；
   - 总训练成本：所有卡成本之和。

## 输入格式

一行字符串，用 `;` 分成四段：梯度耗时列表;NPU数量;基础学习率;衰减系数。例如：$8,5,4,3,3,2,1;3;0.1;0.8$。

1. 梯度耗时列表（$grad\_times$）：逗号分隔的一维数组，每个元素为单个梯度更新任务的耗时（非负整数）；
2. $NPU$ 数量（$k$）：正整数，满足 $1 \le k \le len(grad\_times)$；
3. 基础学习率（$base\_lr$）：浮点数；
4. 衰减系数（$decay\_rate$）：浮点数，满足 $0 < decay\_rate < 1$。

## 输出格式

一行字符串：最小最大总耗时,总训练成本。例如：$9,2.4400$。

- 最小最大总耗时：整数；
- 总训练成本：保留 $4$ 位小数的浮点数。

## 示例

### 示例 1

**输入：**

```
8,5,4,3,3,2,1;3;0.1;0.8
```

**输出：**

```
9,2.4400
```

**说明：**

解析得 $grad\_times=[8,5,4,3,3,2,1]$，$k=3$，$base\_lr=0.1$，$decay\_rate=0.8$。

总耗时 $8+5+4+3+3+2+1=26$，理想均分约 $26/3\approx 8.67$，且最大单任务为 $8$，故最小可能的最大子集和至少为 $9$。

一组达到该下界的划分：

- NPU1：$8+1=9$
- NPU2：$5+4=9$
- NPU3：$3+3+2=8$

负载为 $9,9,8$，$max\_time=9$。

成本：

- 负载 $9$：$9\times 0.1\times 0.8^{0}=0.9$（两张）
- 负载 $8$：$8\times 0.1\times 0.8^{1}=0.64$

总成本 $0.9+0.9+0.64=2.44$，输出 $9,2.4400$。

### 示例 2

**输入：**

```
6;1;0.2;0.9
```

**输出：**

```
6,1.2000
```

**说明：**

仅 $1$ 张 NPU、一个任务，故 $max\_time=6$，$sum\_time=6$。

$lr=0.2\times 0.9^{0}=0.2$，总成本 $6\times 0.2=1.2$，输出 $6,1.2000$。
