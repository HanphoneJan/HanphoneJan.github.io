# 小美的修路

> 美团笔试编程题 · 带必选边的最小生成树

## 题目描述

地图上有 `n` 个城市，小美准备修建一些道路，使得任意两个城市之间都能通过道路到达。现在给定 `m` 个修路计划，其中有一些计划是**必选**的。请帮小美规划出最优方案：在保证所有城市连通、且包含全部必选计划的前提下，让总花费最小。

## 输入格式

第一行两个正整数 `n`、`m`，用空格隔开，代表城市数量与计划数量。

接下来 `m` 行，每行四个正整数 `u`、`v`、`w`、`required`：在城市 `u` 和 `v` 之间修一条花费为 `w` 的道路；`required` 为 1 表示该计划必选，为 0 表示可选。

## 输出格式

如果无解（无法让所有城市连通），输出 `-1`。

否则第一行输出一个正整数，代表选择的计划数量；第二行输出这些计划的编号（从 1 起），用空格隔开。只要方案连通且总花费最小即可，不要求编号升序。

## 示例

### 示例 1

**输入：**

```
3 4
1 2 3 1
1 2 2 0
1 3 1 0
2 3 3 0
```

**输出：**

```
2
1 3
```

**说明：**

计划 1（`1-2`，花费 3）必选，已经花掉 3。要让城市 3 接进来，可选的是计划 3（`1-3`，花费 1）和计划 4（`2-3`，花费 3）；选便宜的 3。计划 2 与计划 1 重复连接 `1-2`，再选只会多花钱。总花费 `3 + 1 = 4`。

## 解题思路

普通的最小生成树是「把边按花费排序，能连就选」。这题多了一样东西：必选计划。它们不是候选，而是**已经付掉的钱**——不管贵不贵、连不连通，都得出现在方案里。所以顺序是：先把必选边无条件并进并查集，再用可选边按花费升序补齐连通，最后检查是否所有城市在同一个集合里。

### 第一步：必选边无条件并入

```python
for w, req, u, v, idx in plans:
    if req == 1:
        union(u, v)          # 返回值丢掉：成环也照收
        chosen.append(idx)
```

关键在**不看 `union` 的返回值**。必选边如果两端已经连通（成环），它在生成树里是多余的，但题面要求「方案必须包含每个必选计划」，漏一条就直接判错。并查集在这里只负责记录「哪些城市已经连通」，不负责筛选必选边。

### 第二步：可选边按花费升序补齐

```python
for w, req, u, v, idx in sorted(plans):
    if req == 0 and union(u, v):
        chosen.append(idx)
```

这是标准的 Kruskal：从便宜的开始，两端已经在同一集合就跳过，否则收下这条边并合并。必选边已经并过，所以这里 `union` 返回假就说明这条可选边多余。

### 第三步：判连通

必选边可能压根连不到某些城市（比如整张图被切成两块），这时无论怎么选可选边都不够。收完所有边后，检查每个城市与城市 1 是否同根：

```python
root = find(1)
if any(find(c) != root for c in range(2, n + 1)):
    print(-1)
    return
```

无解时**只输出一行 `-1`**，不要再打计划数量那一行。

### 推演：示例 1

| 步骤 | 边 | 花费 | 必选 | 并查集状态 | 是否收下 |
| --- | --- | --- | --- | --- | --- |
| 1 | 计划 1：1-2 | 3 | 是 | `{1,2}` `{3}` | 收下（必选） |
| 2 | 计划 3：1-3 | 1 | 否 | `{1,2,3}` | 收下 |
| 3 | 计划 2：1-2 | 2 | 否 | 已连通 | 跳过 |
| 4 | 计划 4：2-3 | 3 | 否 | 已连通 | 跳过 |

可选边按花费排序后是计划 3（1）→ 计划 2（2）→ 计划 4（3）。计划 2 虽然比计划 3 便宜两倍，但它在计划 1 之后已经完全多余。最终输出 `2` 和 `1 3`，总花费 4。

## 完整代码实现

```python
import sys


def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    plans = []
    for idx in range(1, m + 1):
        u = int(next(it))
        v = int(next(it))
        w = int(next(it))
        required = int(next(it))
        plans.append((w, required, u, v, idx))

    parent = list(range(n + 1))

    def find(x: int) -> int:
        while parent[x] != x:
            parent[x] = parent[parent[x]]   # 路径压缩
            x = parent[x]
        return x

    def union(a: int, b: int) -> bool:
        ra, rb = find(a), find(b)
        if ra == rb:
            return False
        parent[ra] = rb
        return True

    chosen = []

    # 必选计划：无条件收下，成环也要收
    for w, required, u, v, idx in plans:
        if required == 1:
            union(u, v)
            chosen.append(idx)

    # 可选计划：按花费升序做 Kruskal
    for w, required, u, v, idx in sorted(plans):
        if required == 0 and union(u, v):
            chosen.append(idx)

    # 所有城市必须连通
    root = find(1)
    if any(find(city) != root for city in range(2, n + 1)):
        sys.stdout.write("-1\n")
        return

    chosen.sort()
    sys.stdout.write(str(len(chosen)) + "\n")
    sys.stdout.write(" ".join(map(str, chosen)) + "\n")


if __name__ == "__main__":
    solve()
```

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| --- | --- | --- | --- |
| 并查集 + Kruskal（最优） | O(m log m) | O(n + m) | 瓶颈是可选边的排序；并查集近似 O(1) |

## 易错点总结

### 1. 必选边也要求 `union` 成功才收

把必选那一行写成 `if required == 1 and union(u, v): chosen.append(idx)`，成环的必选边会被悄悄丢掉，方案里少一个编号，判题直接报错。样例里的必选边不成环，所以照样能过——用这组数据一试就现形：

```
3 3
1 2 1 1
2 3 1 1
1 3 1 1
```

正确输出 `3` / `1 2 3`，错误写法输出 `2` / `1 2`（城市确实连通了，但漏掉了必选计划 3）。

### 2. 计划编号从 0 开始

`for idx in range(m)` 配 `chosen.append(idx)` 会让编号整体差 1：示例 1 输出 `2` / `0 2`，判题去找「计划 0」，直接错误。读入时就用 `range(1, m + 1)`，编号与题面一致。

## 扩展思考

- 如果题面改成「选出的道路必须构成一棵树」，必选边成环时就无解——那要先检测必选边内部是否成环，再决定输出。
- 如果还要求「在最小花费下计划数量最少」，可以在 Kruskal 之外把每条边的花费和数量做成一对权重，按字典序比较。
