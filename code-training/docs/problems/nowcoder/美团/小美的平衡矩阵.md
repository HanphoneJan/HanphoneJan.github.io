# 小美的平衡矩阵

> 美团 2024-03-09 春招笔试编程题（编程题第 3 题，25 分）

## 题目描述

小美拿到了一个 n × n 的矩阵，其中每个元素是 0 或者 1。
小美认为一个矩形区域是完美的，当且仅当该区域内 0 的数量恰好等于 1 的数量。
现在，小美希望你回答：存在多少个 i × i 的完美矩形区域？
你需要回答 1 ≤ i ≤ n 的所有答案。

## 输入格式

第一行一个正整数 n，代表矩阵大小。
接下来的 n 行，每行一个长度为 n 的 01 串，用来表示矩阵。

## 输出格式

输出 n 行，第 i 行输出 i × i 的完美矩形区域的数量。

## 示例

### 示例 1

**输入：**
```
4
1010
0101
1100
0011
```

**输出：**
```
0
7
0
1
```

**说明：**
1×1 不可能平衡（只有一个元素），3×3 也不可能（9 个格子无法平分），
2×2 的完美子矩阵有 7 个，整个 4×4 矩阵恰好有 8 个 1 和 8 个 0，是唯一一个，
所以第 4 行输出 1。

---

## 解题思路

### 把「0 和 1 一样多」换成「1 的个数是面积的一半」

设区域内共有 `S` 个格子、其中 `k` 个 1，那么 0 有 `S - k` 个。

```
k = S - k   ⇔   2k = S   ⇔   k = S / 2
```

所以「0 与 1 数量相等」就是「1 的个数恰好是面积的一半」。这个改写把「分别数两种元素」
变成「只数一种」，于是问题落在**快速求任意子矩阵里 1 的个数**上。

### 二维前缀和：一次查询 O(1)

`pre[i][j]` 表示左上角 `(0,0)` 到 `(i-1, j-1)` 这个矩形里 1 的个数（行列都从 1 起，第 0 行第 0 列是哨兵）。
建表就是「上面一块 + 左边一块 - 重复算的左上角 + 当前格」：

```python
for i in range(n):
    row = grid[i]
    for j in range(n):
        pre[i + 1][j + 1] = (pre[i][j + 1] + pre[i + 1][j]
                             - pre[i][j] + (1 if row[j] == '1' else 0))
```

任意 `k × k` 子矩阵（右下角为 `(i, j)`）里 1 的个数，用同一套容斥从大块里挖出来：

```text
ones = pre[i][j] - pre[i-k][j] - pre[i][j-k] + pre[i-k][j-k]
```

四项的含义是：整个左上角大的矩形，减去**上方一条**（高 `i-k`），减去**左方一条**（宽 `j-k`），
再补回**左上角那一小块** —— 它被减了两次。漏掉最后这一项，`ones` 会偏小，
而且偏小的幅度随窗口位置变化，不是统一少 1。

`pre` 开 `(n+1) × (n+1)`、下标从 1 起用，好处是 `i - k`、`j - k` 落进 `[0, n-k]`，
正好对应哨兵行列，不必为「窗口贴着上边界/左边界」写特判。

### 奇数边长必定是 0

边长 `k` 为奇数时面积 `S = k²` 也是奇数，`k = S/2` 没有整数解，一个完美区域都不可能有。
所以只枚举偶数边长，枚举量直接减半：

```python
for k in range(2, n + 1, 2):          # 奇数边长必为 0，跳过
    half = k * k // 2
    for i in range(k, n + 1):         # 右下角行号，1 起
        for j in range(k, n + 1):     # 右下角列号，1 起
            ones = pre[i][j] - pre[i - k][j] - pre[i][j - k] + pre[i - k][j - k]
            if ones == half:
                res[k] += 1
```

`i`、`j` 从 `k` 开始、到 `n` 结束（含），正好覆盖全部 `(n-k+1)²` 个窗口。

### 为什么这样可以接受

边长 `k` 有 `(n-k+1)²` 个窗口，每个只花一次 O(1) 查询，总枚举量是

```text
Σ (k 取偶数) (n-k+1)²  ≈  n³ / 6
```

而「每个窗口现数一遍」是 O(n⁵)：同一片区域被不同的窗口反复求和。前缀和的全部意义
就是把这份重复计算压成一次建表。

## 完整代码实现

页面上的「跑样例」与逐帧可视化跑的就是这一块：

```python
import sys


def solve() -> None:
    """二维前缀和，枚举偶数边长的子矩阵"""
    data = sys.stdin.read().split()
    if not data:
        return
    n = int(data[0])
    grid = data[1:1 + n]

    pre = [[0] * (n + 1) for _ in range(n + 1)]
    for i in range(n):
        row = grid[i]
        for j in range(n):
            pre[i + 1][j + 1] = (
                pre[i][j + 1] + pre[i + 1][j] - pre[i][j]
                + (1 if row[j] == '1' else 0)
            )

    res = [0] * (n + 1)
    for k in range(2, n + 1, 2):          # 奇数边长必为 0，跳过
        half = k * k // 2
        for i in range(k, n + 1):
            for j in range(k, n + 1):
                ones = (pre[i][j] - pre[i - k][j]
                        - pre[i][j - k] + pre[i - k][j - k])
                if ones == half:
                    res[k] += 1

    sys.stdout.write("\n".join(str(res[i]) for i in range(1, n + 1)) + "\n")


if __name__ == "__main__":
    solve()
```

## 示例推演

样例矩阵（行列都按 1 起数）：

| | 列 1 | 列 2 | 列 3 | 列 4 |
|---|---|---|---|---|
| 行 1 | 1 | 0 | 1 | 0 |
| 行 2 | 0 | 1 | 0 | 1 |
| 行 3 | 1 | 1 | 0 | 0 |
| 行 4 | 0 | 0 | 1 | 1 |

先按「上 + 左 − 左上 + 当前格」把前缀和填出来：

| `pre` | j=0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| i=0 | 0 | 0 | 0 | 0 | 0 |
| 1 | 0 | 1 | 1 | 2 | 2 |
| 2 | 0 | 1 | 2 | 3 | 4 |
| 3 | 0 | 2 | 4 | 5 | 6 |
| 4 | 0 | 2 | 4 | 6 | 8 |

`pre[4][4] = 8` 就是全矩阵里 1 的个数（每行 2 个，共 4 行）。

取右下角 `(4, 4)`、边长 2 的窗口验证一次查询：行 3–4、列 3–4 这四格是 `0 0 / 1 1`，实际有 2 个 1。

```text
ones = pre[4][4] - pre[2][4] - pre[4][2] + pre[2][2]
     = 8 - 4 - 4 + 2 = 2   ✓
```

边长 2 的全部 9 个窗口：

| 行范围 | 列范围 | 窗口内容 | 1 的个数 | 面积一半 = 2 | 是否完美 |
|---|---|---|---|---|---|
| 1–2 | 1–2 | `1 0 / 0 1` | 2 | 2 | 是 |
| 1–2 | 2–3 | `0 1 / 1 0` | 2 | 2 | 是 |
| 1–2 | 3–4 | `1 0 / 0 1` | 2 | 2 | 是 |
| 2–3 | 1–2 | `0 1 / 1 1` | 3 | 2 | 否 |
| 2–3 | 2–3 | `1 0 / 1 0` | 2 | 2 | 是 |
| 2–3 | 3–4 | `0 1 / 0 0` | 1 | 2 | 否 |
| 3–4 | 1–2 | `1 1 / 0 0` | 2 | 2 | 是 |
| 3–4 | 2–3 | `1 0 / 0 1` | 2 | 2 | 是 |
| 3–4 | 3–4 | `0 0 / 1 1` | 2 | 2 | 是 |

7 个「是」。边长 1 的窗口面积是 1，要求 `k = 0.5`，不可能，答案 0；
边长 3 的面积是 9（奇数），同样不可能，答案 0；边长 4 只有整块一个窗口，`ones = 8 = 16/2`，答案 1。

合起来就是 `0 7 0 1`，与样例输出一致。

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 每个窗口现求和 | O(n⁵) | O(n²) | 同一片区域被不同窗口反复求和 |
| 二维前缀和 + 枚举偶数边长（最优） | O(n³) | O(n²) | 建表 O(n²)，总枚举量约 n³/6，每个窗口 O(1) 查询 |

## 易错点总结

1. **容斥漏掉 `+ pre[i-k][j-k]`**：写成 `pre[i][j] - pre[i-k][j] - pre[i][j-k]` 时，左上角那一小块被减了两次，
   `ones` 偏小，而且偏小的幅度随窗口位置变化。样例里边长 2 只剩 4 个窗口被判为完美
   （贴着上边界、左边界的窗口碰巧还对，中间的都错），第 2 行输出 `4` 而不是 `7`。
2. **`i`、`j` 的枚举起点抄成 0 起**：写成 `for i in range(n - k + 1)` 时，`i < k` 的那些轮次会让
   `pre[i-k]` 取到负下标（Python 从末尾取，`pre[-1]` 是最后一行），样例的输出直接变成 `0 1 0 0`；
   `k = n` 那一轮只剩 `i = 0`，整块窗口永远数不到。前缀和是 1 起，起点必须写 `k`。
3. **把每一行按整数读**：`row = int(data[i])` 之后 `row[j]` 直接抛
   `TypeError: 'int' object is not subscriptable`；改成 `int(data[i], 2)` 也不对 ——
   `0011` 转成 3，前导零连同「这一行有多长」一起丢了，逐列对齐就无从谈起。逐行按字符串读。

## 扩展思考

- 把矩阵里的 0 记成 `-1`，「0 与 1 各一半」就变成「子矩阵和为 0」。一维版本（「和为 0 的子数组个数」）
  可以用哈希表把 O(n²) 压到 O(n)，二维版本没有这个待遇。
- 若问的是任意矩形而不是正方形，「0 与 1 各半」仍需枚举两对边界，前缀和照样每查 O(1)，总量 O(n⁴)。
