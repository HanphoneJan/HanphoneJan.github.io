# 小美的排列询问

> 美团 2024 秋招笔试编程题

## 题目描述

小美拿到了一个排列。她想知道在这个排列中，数字 x 和 y 是否是相邻的。
排列是指一个长度为 n 的数组，其中 1 到 n 每个元素恰好出现一次。

## 输入格式

第一行一个正整数 n，代表排列的长度。
第二行 n 个正整数，代表排列的元素。
第三行两个正整数 x 和 y，用空格隔开。

## 输出格式

如果 x 和 y 在排列中相邻，输出 `Yes`；否则输出 `No`。

## 示例

### 示例 1

**输入：**
```
4
1 4 2 3
2 4
```

**输出：**
```
Yes
```

**说明：**
排列为 `1 4 2 3`，`4` 在第 2 位、`2` 在第 3 位，下标相差 1，相邻。

### 示例 2

**输入：**
```
5
3 4 5 1 2
3 2
```

**输出：**
```
No
```

**说明：**
`3` 在第 1 位、`2` 在第 5 位，下标相差 4，不相邻。

---

## 解题思路

### 「相邻」说的是位置相邻

排列里 1..n 各出现一次。「x 与 y 相邻」指的是它们在数组里的**下标差 1**，与 `|x - y|` 无关：
`1 4 2 3` 里 `4` 与 `2` 数值差 2，下标却差 1，答案是 `Yes`；反过来，`1` 和 `2` 数值相邻，
也可能被排在数组的两头。

于是问题被压成一句话：**x 的下标与 y 的下标相差多少**。

### 建一张「值 → 下标」的表

排列的好处是每个值只出现一次，所以「值 → 下标」是一张合法的映射：一个键唯一对应一个位置，
查它不需要扫描。一次遍历建好，之后任意值的下标都是 O(1)：

```python
pos = {}
for i, v in enumerate(a):
    pos[v] = i
sys.stdout.write("Yes\n" if abs(pos[x] - pos[y]) == 1 else "No\n")
```

`abs` 不能省：x 可能在 y 左边，也可能在右边，两种都算相邻。

### 只问一次时，两次 `index` 就够

本题只有一组询问，建表的收益体现不出来。`a.index(x)` 直接返回下标，额外空间 O(1)：

```python
i, j = a.index(x), a.index(y)
sys.stdout.write("Yes\n" if abs(i - j) == 1 else "No\n")
```

`index` 找不到会抛 `ValueError`，但排列里 x、y 一定存在，所以不用兜底。
值得建表的场合是**多组询问**：建表把每组询问从 O(n) 降到 O(1)，而两次 `index` 每组都要重扫。

## 完整代码实现

建表的版本（页面上的「跑样例」与逐帧可视化跑的就是它）：

```python
import sys


def solve() -> None:
    """记录每个值的位置，判断下标是否相差 1"""
    data = sys.stdin.read().split()
    if not data:
        return
    n = int(data[0])
    a = data[1:1 + n]
    x = data[1 + n]
    y = data[2 + n]

    pos = {}
    for i, v in enumerate(a):
        pos[v] = i
    sys.stdout.write("Yes\n" if abs(pos[x] - pos[y]) == 1 else "No\n")


if __name__ == "__main__":
    solve()
```

另一版：不建表，直接用 `index` 取两个下标，省掉 O(n) 空间。

```python
import sys


def solve() -> None:
    """单次询问：两次 index 直接取下标"""
    data = sys.stdin.read().split()
    if not data:
        return
    n = int(data[0])
    a = data[1:1 + n]
    x = data[1 + n]
    y = data[2 + n]

    sys.stdout.write("Yes\n" if abs(a.index(x) - a.index(y)) == 1 else "No\n")


if __name__ == "__main__":
    solve()
```

## 示例推演

示例 1：`n = 4`、`a = [1, 4, 2, 3]`、`x = 2`、`y = 4`。建表：

| 值 | 下标 |
|----|------|
| 1 | 0 |
| 4 | 1 |
| 2 | 2 |
| 3 | 3 |

`2` 在下标 2、`4` 在下标 1，`|2 - 1| = 1` → 输出 `Yes`。
两个数的**数值**差是 `|2 - 4| = 2`，若拿数值差来判断就会答 `No` —— 这正是本题要分开的两件事。

示例 2：`n = 5`、`a = [3, 4, 5, 1, 2]`、`x = 3`、`y = 2`，查表得

| 值 | 下标 |
|----|------|
| 3 | 0 |
| 4 | 1 |
| 5 | 2 |
| 1 | 3 |
| 2 | 4 |

`|0 - 4| = 4 ≠ 1` → 输出 `No`。这两个数一个在串首、一个在串尾，位置上离得最远。

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 两次 `index`（最优） | O(n) | O(1) | 本题只问一次，扫两遍就够，不必先建表 |
| 值 → 下标映射 | O(n) | O(n) | 建表 O(n) 一次，查询 O(1)；多组询问时才是必需的那一种 |

## 易错点总结

1. **`pos` 的键和查询的键类型不一致**：如果把排列转成整数建表 `pos = {int(v): i for i, v in enumerate(a)}`，
   而 `x`、`y` 仍是 `split()` 出来的字符串，`pos[x]` 会直接抛 `KeyError: '2'`。
   要么三处全用字符串（首个代码块就是这样），要么读入时就统一转成 `int`。
2. **漏掉 `abs`**：写成 `pos[x] - pos[y] == 1` 时，只有 x 在 y 右边一格才会判相邻。
   示例 2 里 `3` 在第 1 位、`4` 在第 2 位（显然相邻），取 x=3、y=4 就会输出 `No`，
   交换 x、y 又变成 `Yes` —— 答案跟着参数的书写顺序飘。

---

## 扩展思考

- 若排列首尾也算相邻（环形），条件是 `abs(i - j) == 1 or abs(i - j) == n - 1`。
- 若问「x 和 y 之间隔了几个数」，答案是 `abs(i - j) - 1`。
