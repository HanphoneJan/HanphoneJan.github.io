# 小美的密码

> 美团 2024-08-10 后端笔试编程题

## 题目描述

小美准备登录美团，需要输入密码。她忘记了密码，只记得密码可能是 n 个字符串
中的一个。小美会按照密码长度从小到大依次尝试每个字符串；对于相同长度的字符串，
她会随机尝试，并且相同的密码只会尝试一次。
小美想知道，她**最少**需要尝试多少次才能登录成功，**最多**需要尝试多少次。
小美不会重新尝试已经尝试过的字符串，成功登录后会立即停止尝试。

## 输入格式

第一行一个整数 n，代表密码字符串的个数。
第二行一个只由小写字母组成的字符串 s，代表正确的密码。
接下来 n 行，每行一个字符串，代表小美记得的密码。

## 输出格式

在一行上输出两个整数，表示最少和最多尝试次数。

## 示例

### 示例 1

**输入：**
```
4
ab
abc
ab
ac
ac
```

**输出：**
```
1 2
```

**说明：**
正确密码是 `ab`（长度 2）。长度为 2 的不同密码有 `ab`、`ac` 两个。

- 最少：随机顺序里第一个就试到 `ab` → 1 次；
- 最多：先试 `ac` 再试 `ab` → 2 次。

注意 `ac` 出现了两次，但相同的密码只试一次；长度 3 的 `abc` 不会被试到。

---

## 解题思路

### 先看清尝试顺序把候选切成了两段

密码按长度从小到大试，同长度内顺序随意。于是任何一次尝试序列都能切成两段：

1. **长度比 `|s|` 短的密码**：它们都不是正确密码，无论顺序如何，**全部**都会被试一遍。
   记这段的条数为 `step`；
2. **长度恰好等于 `|s|` 的密码**：正确密码在这一层里，她在这里成功并停止。

长度比 `|s|` 大的密码一次都轮不到。所以答案只剩两个数：

- 最少 = `step + 1`（这一层第一个就中）；
- 最多 = `step + d`，`d` 是这一层里**不同**密码的个数（正确密码排在最后）。

`step` 对两种运气是同一个数，两种运气的差别只在第二段取 `1` 还是取 `d`。

### 去重必须和「按长度分组」一起做

「相同的密码只会尝试一次」意味着第二段数的是**不同字符串**，不是输入行数：
`ac` 写了两遍，最多也只多试一次。所以统计单位是「每个长度下的不同字符串」，用 `set`：

```python
by_len = defaultdict(set)
for w in words:
    by_len[len(w)].add(w)     # set：重复的密码在这里被吃掉
```

`set` 还让「正确密码在不在这一层」变成 `s in group`，O(1) 判定。

### 长度从小到大走，走到 `|s|` 就停

`step` 的定义是「比 `|s|` 短的层」，所以必须按长度从小到大累加，遇到含 `s` 的那一层当场算答案并停下：

```python
step = 0
for length in sorted(by_len):
    group = by_len[length]
    if s in group:
        mn, mx = step + 1, step + len(group)
        break
    step += len(group)        # 这一层全错，整层计入 step
```

`step += len(group)` 在 `if` **之后**：含正确密码的那一层自己不属于「比 `|s|` 短」，
把它算进 `step` 会让答案整体偏大。

### 其实只有两种长度有用：不排序的写法

上面排序的是「不同长度」这个集合，最多 n 个元素。但回看第一段的分析，答案只用到两样东西：
**比 `|s|` 短的不同密码个数**、**和 `|s|` 等长的不同密码个数**。别的长度连数都不用数，
于是可以一遍分桶，不排序、不 `break`：

```python
shorter, same = set(), set()
for w in words:
    if len(w) < len(s):
        shorter.add(w)
    elif len(w) == len(s):
        same.add(w)
print(len(shorter) + 1, len(shorter) + len(same))
```

答案与排序版完全一致，这一版少一次排序，也少一个「找到之后要记得停」的隐藏状态。

## 完整代码实现

按长度分组、排序后逐层走的版本（页面上的「跑样例」与逐帧可视化跑的就是它）：

```python
import sys
from collections import defaultdict


def solve() -> None:
    """按长度分组去重，统计比正确密码短的个数"""
    data = sys.stdin.read().split()
    if not data:
        return
    n = int(data[0])
    s = data[1]
    words = data[2:2 + n]

    by_len = defaultdict(set)
    for w in words:
        by_len[len(w)].add(w)

    step = 0
    mn = mx = -1
    for length in sorted(by_len):
        group = by_len[length]
        if s in group:
            mn = step + 1
            mx = step + len(group)
            break
        step += len(group)

    sys.stdout.write(f"{mn} {mx}\n")


if __name__ == "__main__":
    solve()
```

不排序的一遍版本，逻辑更短：

```python
import sys


def solve() -> None:
    """一遍分桶：只统计「更短」与「同长」两类不同密码"""
    data = sys.stdin.read().split()
    if not data:
        return
    n = int(data[0])
    s = data[1]

    shorter, same = set(), set()
    for w in data[2:2 + n]:
        if len(w) < len(s):
            shorter.add(w)
        elif len(w) == len(s):
            same.add(w)

    sys.stdout.write(f"{len(shorter) + 1} {len(shorter) + len(same)}\n")


if __name__ == "__main__":
    solve()
```

## 示例推演

输入 `n = 4`、`s = "ab"`，候选为 `abc`、`ab`、`ac`、`ac`。先分组去重：

| 长度 | 该长度的不同密码 | 说明 |
|------|------------------|------|
| 2 | `{ab, ac}` | 含正确密码 `ab`，会停在这一层 |
| 3 | `{abc}` | 比 `s` 长，一次都轮不到 |

按长度从小到大处理：

| 处理到 | group | `s in group` | `step` | 动作 |
|--------|-------|--------------|--------|------|
| 长度 2 | `{ab, ac}` | 是 | 0 | `mn = 0 + 1 = 1`，`mx = 0 + 2 = 2`，`break` |

输出 `1 2`，与样例一致。`ac` 出现两次但 `set` 只留一份，所以 `d = 2` 而不是 3。

这个样例里没有「比 `|s|` 短」的层，`step` 一直是 0，看不出它怎么累积。换一组输入：

```
5
cat
a
bb
cat
dog
car
```

| 处理到 | group | `s in group` | `step` | 动作 |
|--------|-------|--------------|--------|------|
| 长度 1 | `{a}` | 否 | 0 → 1 | 整层全错，累加 |
| 长度 2 | `{bb}` | 否 | 1 → 2 | 整层全错，累加 |
| 长度 3 | `{cat, dog, car}` | 是 | 2 | `mn = 2 + 1 = 3`，`mx = 2 + 3 = 5` |

答案 `3 5`：先白试 `a`、`bb` 两次；正确密码那一层里 `cat` 可能第一个中（3 次），也可能排到最后（5 次）。

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 按长度分组 + 排序长度 | O(总字符数 + L·log L) | O(总字符数) | 首个代码块；L 是不同长度的个数，排的是长度而不是字符串 |
| 一遍分桶（最优） | O(总字符数) | O(总字符数) | 只数两类长度，省掉排序和「找到即停」 |

## 易错点总结

1. **分组时用 `list` 而不是 `set`**：写成 `by_len[len(w)].append(w)`，样例 1 的长度 2 组就是 `[ab, ac, ac]`，
   `len(group)` 得 3，输出 `1 3`；正确答案是 `1 2`。重复密码只试一次，计数单位是「不同字符串」。
2. **`step += len(group)` 写在 `if s in group` 之前**：含正确密码的那一层被一起算进 `step`，
   样例 1 输出 `3 4` 而不是 `1 2`。`step` 的语义是「比 `|s|` 短的层」，当前这层永远不属于它。

## 扩展思考

- 若同一长度内改按字典序试（而不是随机），「最少」与「最多」会合并成同一个数：
  `step + s 在这一层内的字典序名次`。
- 一般形态是「候选按某个键分层，最坏情况 = 前面各层总数 + 本层总数，最好情况 = 前面各层总数 + 1」。
