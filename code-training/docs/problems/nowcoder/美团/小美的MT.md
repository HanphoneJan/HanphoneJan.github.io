# 小美的MT

> 美团 2024 春招第一场【技术】笔试编程题

## 题目描述

MT 是美团的缩写，因此小美很喜欢这两个字母。现在小美拿到了一个仅由大写字母
组成的字符串，她最多可以操作 k 次，每次可以修改任意一个字符。
小美想知道，操作结束后最多共有多少个 `M` 和 `T` 字符。

## 输入格式

第一行两个正整数 n、k，代表字符串长度和操作次数。
第二行一个长度为 n 的、仅由大写字母组成的字符串 s。

## 输出格式

输出操作结束后最多共有多少个 `M` 和 `T` 字符。

## 示例

### 示例 1

**输入：**
```
5 2
MTUAN
```

**输出：**
```
4
```

**说明：**
原来有 2 个目标字符（`M`、`T`），最多还能改 2 个字符，
把 `U`、`N` 改成 `M`、`T`，得到 `MTTAM`，共 4 个。

---

## 解题思路

### 目标是「个数」，不是「连续的 MT」

题面要的是整串里 `M` 与 `T` 的**总个数**：字符之间是否相邻、`M` 排在 `T` 前面还是后面，都不影响计数。
一次操作是把任意一个位置改成任意一个字符，所以每个位置只有两种状态：**已经是目标字符**、
**还不是**。操作有没有价值，只看它把一个位置从哪一类搬到哪一类。

### 一次操作的收益上限是 +1，而且拿得到

- 把非目标字符改成 `M` 或 `T`：目标数 +1；
- 把目标字符改成别的、或者把 `M` 改成 `T`：目标数不变甚至 -1。

所以「有用的操作」只有一种形状 —— 挑一个非目标字符，改成 `M` 或 `T`。没有哪种操作能一次赚到更多，
而这 +1 只要还有非目标字符就一定能拿到。

### 上界是 `cnt + k`，封顶是 n

设串里已有 `cnt` 个目标字符：

- 每次最多 +1，`k` 次最多 `cnt + k`；
- 整串只有 n 个位置，目标数不可能超过 n。

这两个上界都能取到，所以答案是两者的较小值：

- `cnt + k ≤ n`：非目标字符有 `n - cnt ≥ k` 个，挑 `k` 个改掉，正好 `cnt + k`；
- `cnt + k > n`：非目标字符只有 `n - cnt < k` 个，全改掉就到 n，剩下的次数用不完 ——
  题面说的是「**最多** k 次」，可以少做。

```python
cnt = sum(1 for ch in s if ch in "MT")
sys.stdout.write(str(min(n, cnt + k)) + "\n")
```

`ch in "MT"` 一次判两种字符，比 `ch == 'M' or ch == 'T'` 少一处写漏分支的机会。

## 完整代码实现

```python
import sys


def solve() -> None:
    """统计 M/T 数量，再加上最多 k 次修改"""
    data = sys.stdin.read().split()
    if not data:
        return
    n = int(data[0])
    k = int(data[1])
    s = data[2]
    cnt = sum(1 for ch in s if ch == 'M' or ch == 'T')
    sys.stdout.write(str(min(n, cnt + k)) + "\n")


if __name__ == "__main__":
    solve()
```

## 示例推演

`n = 5`、`k = 2`、`s = "MTUAN"`，逐位看：

| 位置 | 字符 | 是否 `M`/`T` | 操作 |
|------|------|--------------|------|
| 1 | M | 是 | 不动 |
| 2 | T | 是 | 不动 |
| 3 | U | 否 | 改成 `T`，目标数 3 |
| 4 | A | 否 | 2 次机会用在 `U`、`N` 上更值，这格不改 |
| 5 | N | 否 | 改成 `M`，目标数 4 |

最终串 `MTTAM`，`M`/`T` 共 4 个。代入公式：`cnt = 2`，`min(5, 2 + 2) = 4`，与输出一致。

样例没有触及封顶，因为 `2 + 2 = 4 < 5`。看一组上界真的被卡住的：
`n = 5`、`k = 3`、`s = "MMMTT"`。此时 `cnt = 5`、`cnt + k = 8 > 5`，答案取 `min(5, 8) = 5` ——
串里已经没有非目标字符，硬做三次只能把 `M`/`T` 改坏，而题面允许少做几次。

## 易错点总结

1. **少了 `min(n, ...)`**：只写 `cnt + k` 时，`n = 5`、`k = 3`、`s = "MMMTT"` 会输出 `8`，
   比字符串长度还大。样例 1 的 `2 + 2 = 4 ≤ 5` 恰好没触发，只看样例发现不了这个上界。

---

## 扩展思考

- 若把「最多 k 次」改成「**恰好** k 次」，当 `n - cnt < k` 时多出来的操作只能改坏已有目标字符，
  答案是 `n - (k - (n - cnt))`；这也说明题意里「最多」两个字是答案形状的一部分。
- 目标字符从一个集合换成一个区间（例如 `A`~`M`）时，计数仍是一次遍历，结论不变。
