# HJ26. 字符串排序

## 题目描述

编写程序，对输入的字符串按如下规则排序：

1. 英文字母按 ASCII 大小排序，但不区分大小写，且相同字母（如 A 和 a）按输入顺序保持相对位置。
2. 非字母字符保持原位不动。

## 输入格式

一行待排序的字符串（可含空格、数字、标点）。

## 输出格式

排序后的字符串。

## 示例

### 示例 1

**输入：**
```
A Famous Saying: Much Ado About Nothing (2012/8).
```

**输出：**
```
A aaAAbc dFgghh: iimM nNn oooos Sttuuuy (2012/8).
```

### 示例 2

**输入：**
```
a1b2c3
```

**输出：**
```
a1b2c3
```

---

## 解题思路

### 第一步：理解问题本质

字符串中混有字母和非字母。字母需要排序（不区分大小写），非字母原地不动。排序后字母依次填入原来字母占的位置。

### 第二步：暴力解法

为每个字母位置尝试所有字母排列，检查是否满足排序规则。组合爆炸，不可行。

### 第三步：提取字母 + 稳定排序

两步走：
1. 把所有字母提取出来，按**小写形式**排序 → 不区分大小写。
2. 稳定排序保证相同字母（如 A 和 a）保持输入顺序。
3. 遍历原字符串，遇到字母按顺序回填排序结果，遇到非字母原样保留。

### 第四步：最优解法

Python 的 `sorted` 是稳定排序，用 `key=str.lower` 即可同时实现"大小写不敏感"与"同字母稳定"：

```python
# 只把字母挑出来排序：key=str.lower 让 A 与 a 一起参与比较
letters = sorted([ch for ch in s if ch.isalpha()], key=str.lower)
res = []
idx = 0
# 再扫一遍原串，字母按排序结果依次回填，别的位置不动
for ch in s:
    if ch.isalpha():
        res.append(letters[idx]); idx += 1
    else:
        res.append(ch)
print(''.join(res))
```

## 完整代码实现

```python
import sys


def sort_string(s: str) -> str:
    # key=str.lower 实现"不区分大小写"；sorted 稳定，同字母保持输入先后
    letters = sorted([ch for ch in s if ch.isalpha()], key=str.lower)
    res = []
    idx = 0
    # 回填：是字母就取排序结果的下一项，不是字母就原样照抄
    for ch in s:
        if ch.isalpha():
            res.append(letters[idx])
            idx += 1
        else:
            res.append(ch)
    return ''.join(res)


def solve():
    # 用 readline 而不是 split：空格本身要保留，也是非字母字符
    line = sys.stdin.readline().rstrip('\n')
    print(sort_string(line))


if __name__ == "__main__":
    solve()
```

## 示例推演

以 `"aBc b A"` 为例：

**步骤 1**：提取字母 `['a','B','c','b','A']`
**步骤 2**：按小写稳定排序 → `['A','a','B','b','c']`
**步骤 3**：遍历原串回填：
- `'a'`（字母）→ `'A'`
- `'B'`（字母）→ `'a'`
- `'c'`（字母）→ `'B'`
- `' '`（非字母）→ `' '`
- `'b'`（字母）→ `'b'`
- `' '`（非字母）→ `' '`
- `'A'`（字母）→ `'c'`

**结果**：`"AaB bc"`。

## 易错点总结

1. **排序键没有转小写**：直接 `sorted(letters)` 按 ASCII 排，`A`(65) 会排到所有小写字母前面。示例 1 要求 `A`、`a`、`a` 连续出现，漏掉 `key=str.lower` 后大小写会被拆成两段。
2. **回填时按排序结果从头覆盖原串**：非字母字符的位置会被字母挤掉。必须先收集排序后的字母，再按原串顺序扫一遍，遇到字母才从 `letters` 里取下一个，非字母原样写回。

---

## 扩展思考

- 若要求严格按 ASCII 排序（区分大小写），去掉 `key=str.lower` 即可。
- 稳定排序在"先按一列排、再按另一列排"的场景非常有用（如成绩排序按总分再按姓名）。
