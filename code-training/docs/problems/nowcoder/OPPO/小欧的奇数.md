# 小欧的奇数

> OPPO 笔试真题 · 2024 秋招 · 前端岗
>
> 判题请到[牛客原题](https://www.nowcoder.com/practice/aef41039765b433998812b9e9cfe02c2)提交；本站暂只收录题面与样例。

## 题目描述

小欧有一个长度为 $n$ 的数组，现在他想挑出 3 个数，使得这 3 个数的和为奇数，如果可以挑出则输出 "YES"，否则输出 "NO"。

## 输入格式

一行一个整数 $n$，表示数组的长度。

一行 $n$ 个整数 $a_1, a_2, \dots, a_n$，表示数组的元素。

$3 \leq n \leq 10^5$

$1 \leq a_i \leq 1000$

## 输出格式

如果可以挑出 3 个数，使得这 3 个数的和为奇数，则输出 "YES"，否则输出 "NO"。

## 示例

### 示例 1

**输入：**

```text
4
1 2 3 4
```

**输出：**

```text
YES
```

**说明：**

选取 $a_1, a_2, a_4$ 即可。

### 示例 2

**输入：**

```text
4
2 4 6 8
```

**输出：**

```text
NO
```

**说明：**

无法选取 3 个数使得和为奇数。
