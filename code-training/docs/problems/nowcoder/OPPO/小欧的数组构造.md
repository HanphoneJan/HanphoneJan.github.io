# 小欧的数组构造

> OPPO 笔试真题 · 2024 秋招 · 移动端
>
> 判题请到[牛客原题](https://www.nowcoder.com/practice/7e86d90777ad41e4a59d2e937bf9afc2)提交；本站暂只收录题面与样例。

## 题目描述

小欧有一个整数数组 $a$ ，她已经忘记了 $a$ 数组的构成，但她还记得 $b$ 数组， $b$ 数组中的每一项记录的是 $a$ 数组两个相邻的数之和，也就是说 $b_i = a_i+a_{i+1}(1 \leq i \leq n-1)$ 。

小欧很喜欢正数，她想知道在原来的 $a$ 数组中最多可能有几个正数，请输出最多可能的正数个数

## 输入格式

第一行输入一个整数 $n(2 \leq n \leq 10^5)$ 表示数组长度。

第二行输入 $n-1$ 个整数表示数组 $b(-10^9 \leq b_i \leq 10^9)$ 。

## 输出格式

输出一个整数表示答案。

## 示例

### 示例 1

**输入：**

```text
3
1 2
```

**输出：**

```text
2
```

**说明：**

a数组可能是[1,0,2],[2,-1,3],[0,1,1],[-2,3,-1]等，但可以证明，正数数量最多只可能是2。
