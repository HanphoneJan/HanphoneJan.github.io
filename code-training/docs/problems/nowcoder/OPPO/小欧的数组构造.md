# 小欧的数组构造

> OPPO 笔试真题 · 2024 秋招 · 移动端 · [牛客原题](https://www.nowcoder.com/practice/7e86d90777ad41e4a59d2e937bf9afc2)

## 题目描述

小欧有一个整数数组 `a`，她已经忘记了 `a` 的构成，但她还记得 `b` 数组：`b` 的每一项记录的是 `a` 中两个相邻数之和，即 `b_i = a_i + a_{i+1}`（`1 <= i <= n-1`）。

小欧很喜欢正数，她想知道在原来的 `a` 数组中最多可能有几个正数，请输出最多可能的正数个数。

## 输入格式

第一行输入一个整数 `n`（`2 <= n <= 10^5`），表示数组长度。

第二行输入 `n-1` 个整数表示数组 `b`（`-10^9 <= b_i <= 10^9`）。

## 输出格式

输出一个整数，表示答案。

## 示例

### 示例 1

**输入：**

```
3
1 2
```

**输出：**

```
2
```

**说明：** `a` 可以是 `[1,0,2]`、`[2,-1,3]`、`[-2,3,-1]` 等，但正数个数最多只能是 2。

## 解题思路

`n-1` 个方程、`n` 个未知数，自由度是 1：只要定了 `a_1`，整条数组就唯一确定。所以问题不是「构造一个数组」，而是「选一个 `a_1`，让正数尽量多」。把 `a_i` 写成 `a_1` 的一次函数后，每个位置对 `a_1` 的要求就是一条半直线，问题变成「哪个整数被最多的半直线覆盖」。

### 每个 `a_i` 都是 `a_1` 的一次函数

设 `a_1 = x`，依次递推：

```
a_1 = x
a_2 = b_1 - x
a_3 = b_2 - a_2 = b_2 - b_1 + x
a_4 = b_3 - a_3 = b_3 - b_2 + b_1 - x
```

一般地，`a_i = c_i + (-1)^(i-1) x`，其中 `c_1 = 0`，`c_i = b_(i-1) - c_(i-1)`：

```python
c = [0] * (n + 1)              # 1 起
for i in range(2, n + 1):
    c[i] = b[i - 2] - c[i - 1]
```

于是奇数位的 `a_i = c_i + x`，偶数位的 `a_i = c_i - x`——符号交替，这就是「交替累加」的来源。

### 每个位置给出一个边界

要求 `a_i > 0`（注意是严格大于，0 不算正数）：

- `i` 为奇数：`c_i + x > 0`，即 `x >= 1 - c_i`，是一个**下界**；
- `i` 为偶数：`c_i - x > 0`，即 `x <= c_i - 1`，是一个**上界**。

第 `i` 位能被算作正数，当且仅当 `x` 落在这条半直线里。于是答案就是「同时覆盖最多半直线的整数 `x`」所对应的覆盖数。

### 只检查端点就够了

覆盖函数只在两类点发生变化：某个下界 `1 - c_i` 处多覆盖一条，某个上界 `c_i - 1` 处少覆盖一条。两段变化之间取值不变，所以最大值一定能在某个端点取到——候选集合就是全部下界与全部上界。

```python
lows = sorted(1 - c[i] for i in range(1, n + 1, 2))
highs = sorted(c[i] - 1 for i in range(2, n + 1, 2))
best = 0
for x in set(lows) | set(highs):
    cnt = bisect_right(lows, x) + (len(highs) - bisect_left(highs, x))
    best = max(best, cnt)
```

`bisect_right(lows, x)` 数的是 `lows <= x` 的个数，`len(highs) - bisect_left(highs, x)` 数的是 `highs >= x` 的个数。

### 推演：示例 1

`n = 3`，`b = [1, 2]`。

| `i` | `c_i` | `a_i` | 条件 |
| --- | --- | --- | --- |
| 1 | 0 | `x` | `x >= 1` |
| 2 | 1 | `1 - x` | `x <= 0` |
| 3 | 1 | `1 + x` | `x >= 0` |

候选 `x` 是 `{1, 0}`：

- `x = 0`：`a = [0, 1, 1]`，正数 2 个（第 1 位是 0，不算）；
- `x = 1`：`a = [1, 0, 2]`，正数 2 个。

最大是 2，与样例一致。注意 `x = 0` 那一行：`a_2 = 1` 正、`a_1 = 0` 不是正数，这正是「0 不算」这条规则在起作用。

## 完整代码实现

```python
import sys
from bisect import bisect_left, bisect_right


def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    n = int(data[0])
    b = list(map(int, data[1:1 + n - 1]))

    # c[i]：a_i 中与 x 无关的那一半，a_i = c_i + (-1)^(i-1) * x
    c = [0] * (n + 1)
    for i in range(2, n + 1):
        c[i] = b[i - 2] - c[i - 1]

    # 奇数位要 a_i = c_i + x > 0，给出下界；偶数位给出上界
    lows = sorted(1 - c[i] for i in range(1, n + 1, 2))
    highs = sorted(c[i] - 1 for i in range(2, n + 1, 2))

    best = 0
    for x in set(lows) | set(highs):
        cnt = bisect_right(lows, x) + (len(highs) - bisect_left(highs, x))
        if cnt > best:
            best = cnt

    print(best)


if __name__ == "__main__":
    solve()
```

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| --- | --- | --- | --- |
| 枚举 `a_1` 后逐个递推 | O(n · V) | O(n) | `a_1` 无界，`V` 是枚举范围，无法预先确定 |
| 通项 + 端点扫描（最优） | O(n log n) | O(n) | 排序 `O(n log n)`，每个候选 `O(log n)` 二分，候选最多 `n` 个 |

## 易错点总结

### 1. 把 0 也算成正数

偶数位的边界写成 `x <= c_i`（而不是 `c_i - 1`），等价于允许 `a_i = 0` 被计入。`n = 2`、`b = [1]` 时，`x = 1` 得到 `a = [1, 0]`，正确输出是 1，错误写法输出 2——把那个 0 当成了正数。

### 2. 只枚举非负的 `x`

`a_1` 是原数组的第一个元素，可以是负数，示例说明里的 `[-2, 3, -1]` 就来自 `x = -2`。只让 `x` 从 0 开始枚举会漏掉一整类方案：`n = 6`、`b = [3, 1, -4, -4, -6]` 时正确输出 3（`x = 3` 处取到），若同时把边界写成开区间还会得到 4——多算的那个位置实际是 0。

## 扩展思考

- 若允许重复值、或者问的是「最多几个非负数」，把每条的区间端点整体平移 1 即可，扫描骨架不变。
- 端点扫描 + 差分也能做：把每个下界记 `+1`、每个上界 `+1` 之后的位置记 `-1`，排序后一次前缀和就能求出最大覆盖数，常数比二分小，是同一算法的另一种写法。
