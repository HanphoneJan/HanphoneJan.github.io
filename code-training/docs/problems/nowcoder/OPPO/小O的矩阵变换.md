# 小O的矩阵变换

> OPPO 笔试真题 · 2024 秋招 · 研发通用岗 / 后端开发 · [牛客原题](https://www.nowcoder.com/practice/b1c40c55c4724f75a659915c6700e5ce)

## 题目描述

小O有两个 `n` 行 `n` 列的 01 方阵 `A` 和 `B`，他希望用最少的操作次数把 `A` 变成 `B`。每次操作可以选择 `A` 的一行或者一列，把这一行（或列）的所有数字反转：0 变 1，1 变 0。

输出最少操作次数；如果做不到，输出 `-1`。

## 输入格式

第一行一个整数 `T`（`1 <= T <= 10`），表示测试数据组数。每组数据：

- 第一行一个 `n`（`1 <= n <= 4`）；
- 此后 `n` 行，每行 `n` 个 0/1，表示方阵 `A`；
- 此后 `n` 行，每行 `n` 个 0/1，表示方阵 `B`。

## 输出格式

每组数据输出一行一个整数：最少操作次数，做不到则输出 `-1`。

## 示例

### 示例 1

**输入：**

```
2
2
0 1
1 0
1 0
0 1
2
0 1
1 1
0 0
0 0
```

**输出：**

```
2
-1
```

**说明：**

第一组：翻第 1 行再翻第 2 行，`A` 就变成 `B`，共 2 次。

第二组：把差异矩阵写出来是 `[[0,1],[1,1]]`，它不满足「每一行、每一列翻转的奇偶性对得上」的条件（见下），无解。

## 解题思路

先造差异矩阵 `D[i][j] = A[i][j] ^ B[i][j]`：`D` 里为 1 的格子是「必须被翻奇数次」的格子，把 `A` 变成 `B` 等价于把 `D` 清零。每次翻一整行或一整列，所以格子 `(i,j)` 被翻的次数奇偶性就是 `row[i] ^ col[j]`——`2n` 个开关只以异或的形式出现，翻两次等于没翻。

于是问题变成解 `n²` 个方程 `row[i] ^ col[j] = D[i][j]`。这组方程的自由度只有 1：定下 `col[0]`，其余 `2n-1` 个开关全被 `D` 钉死。

### 定一个开关，其余全被钉死

设 `col[0] = c`，由第一列得

```
row[i] = D[i][0] ^ c          （i = 0..n-1）
```

有了 `row[0]`，再由第一行得

```
col[j] = D[0][j] ^ row[0] = D[0][j] ^ D[0][0] ^ c
```

其它格子则要求

```
D[i][j] = row[i] ^ col[j] = D[i][0] ^ D[0][j] ^ D[0][0]
```

这条式子**不含 `c`**，所以它要么对所有格子成立，要么无论怎么翻都做不到。不成立就输出 `-1`；成立时 `c` 取 0 或 1 都是合法方案。

### 两种方案互为补集

`c = 0` 和 `c = 1` 的差别是「所有行、所有列都多翻一次」，也就是把 `2n` 个开关全部取反。于是两个方案的操作次数相加正好是 `2n`，取小的那个：

```python
ops = sum(d[i][0] for i in range(n)) + sum(d[0][j] ^ d00 for j in range(n))
answer = min(ops, 2 * n - ops)
```

`d00 = D[0][0]`。第一项是 `c = 0` 时的行开关数，第二项是列开关数（第 0 列在 `c = 0` 时不翻，贡献 0）。

### 推演：示例的两组数据

第一组 `D = [[1,1],[1,1]]`：

| 检查 | 计算 | 结果 |
| --- | --- | --- |
| 一致性 `D[1][1]` | `D[1][0] ^ D[0][1] ^ D[0][0] = 1^1^1` | 1，成立 |
| `c = 0` 的操作数 | 行 `1+1`，列 `(1^1)+(1^1)` | 2 |
| `c = 1` 的操作数 | `2n - 2` | 2 |

答案 2。这两次就是把两行都翻一次。

第二组 `D = [[0,1],[1,1]]`：

| 检查 | 计算 | 结果 |
| --- | --- | --- |
| 一致性 `D[1][1]` | `D[1][0] ^ D[0][1] ^ D[0][0] = 1^1^0` | 0，但 `D[1][1] = 1`，矛盾 |

所以无论怎么翻都达不到，输出 `-1`。

## 完整代码实现

```python
import sys


def min_ops(a, b, n):
    """返回把 a 翻成 b 的最少操作次数；无解返回 -1"""
    d00 = a[0][0] ^ b[0][0]

    # 一致性：D[i][j] 必须等于 D[i][0] ^ D[0][j] ^ D[0][0]
    for i in range(n):
        for j in range(n):
            if (a[i][j] ^ b[i][j]) != ((a[i][0] ^ b[i][0]) ^ (a[0][j] ^ b[0][j]) ^ d00):
                return -1

    # col[0] = 0 时：row[i] = D[i][0]，col[j] = D[0][j] ^ D[0][0]
    ops = 0
    for i in range(n):
        ops += a[i][0] ^ b[i][0]
    for j in range(n):
        ops += (a[0][j] ^ b[0][j]) ^ d00

    # 两种方案互补，总开关数是 2n
    return min(ops, 2 * n - ops)


def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    pos = 0
    t = int(data[pos]); pos += 1
    out = []
    for _ in range(t):
        n = int(data[pos]); pos += 1
        a = []
        for _ in range(n):
            a.append([int(x) for x in data[pos:pos + n]])
            pos += n
        b = []
        for _ in range(n):
            b.append([int(x) for x in data[pos:pos + n]])
            pos += n
        out.append(str(min_ops(a, b, n)))
    sys.stdout.write("\n".join(out) + "\n")


if __name__ == "__main__":
    solve()
```

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| --- | --- | --- | --- |
| 枚举全部 `2n` 个开关 | O(T · 4^n · n²) | O(n²) | `n = 4` 时每组 256 × 16 次，够用但没必要 |
| 定 `col[0]` 直接构造（最优） | O(T · n²) | O(1) | 只需一次一致性检查，不存差异矩阵 |

## 易错点总结

### 1. 以为「只差一个格子」翻一次就行

操作的最小单位是整行或整列。`n = 2` 时差异矩阵只有 `D[0][0] = 1`、其余为 0，正确输出是 `-1`：一致性检查在 `(1,1)` 处给出 `D[1][0] ^ D[0][1] ^ D[0][0] = 0^0^1 = 1`，而 `D[1][1] = 0`，对不上。而「数一数有几个 1」的写法会输出 1。

### 2. 跳过一致性检查，只按第一行第一列算

少了上面那个双重循环，示例 1 的第二组数据会算出 `ops = (0+1) + (0+1) = 2`，输出 2；正确答案是 `-1`。差异矩阵里的 1 摆成「一个缺角」的形状时，第一行和第一列都看不出问题，只有 `(1,1)` 这类内部格子会暴露矛盾。

## 扩展思考

- 换个角度，这题是 GF(2) 上的线性方程组：`2n` 个未知数、`n²` 个方程。本题只有 1 个自由度，所以手推两步就能解完；如果操作改成「翻任意一个子矩阵」，方程结构会完全不同。
- 若 `n` 到几百，仍然是 O(n²) 的同一套推导，只是输入和答案要开大数组——复杂度不随 `n` 爆炸。
