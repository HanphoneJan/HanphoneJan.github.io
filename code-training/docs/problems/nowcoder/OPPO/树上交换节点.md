# 树上交换节点

> OPPO 笔试真题 · 2023 秋招 · 后端岗
>
> 判题请到[牛客原题](https://www.nowcoder.com/practice/cff486989bba4f359847a8845fcc518a)提交；本站暂只收录题面与样例。

## 题目描述

给定一棵树，每个节点有一个权值。现在每次可以交换任意两个节点的权值，请问最少多少次交换可以使得每个节点的权值等于它的编号？

保证给出的权值是一个排列，也就是说保证一定有解。

## 输入格式

第一行输入一个正整数$n$，代表树上的节点数量。

第二行输入$n$个正整数$a_i$，第$i$个正整数$a_i$是$i$号节点的权值，$a_i$互不相同。

接下来的$n-1$行，每行输入两个正整数$u$和$v$，代表$u$号节点和$v$号节点有一条边相连。

$2\le n \le 1000$

$1\le u,v,a_i \le n$

## 输出格式

一个整数，代表最小的交换次数。

## 示例

### 示例 1

**输入：**

```text
4
2 1 4 3
1 2
2 3
2 4
```

**输出：**

```text
2
```

**说明：**

第一次交换1号节点和2号节点的权值，四个点的权值变成[1,2,4,3]

第二次交换3号节点和4号节点的权值，四个点的权值变成[1,2,3,4]
