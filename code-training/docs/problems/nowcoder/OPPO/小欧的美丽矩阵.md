# 小欧的美丽矩阵

> OPPO 笔试真题 · 2024 秋招 · 数据开发岗
>
> 判题请到[牛客原题](https://www.nowcoder.com/practice/c78fcff464f34fe5a6d5cfe5c43842d7)提交；本站暂只收录题面与样例。

## 题目描述

小红有一个大小为 $2 \times 2$ 的矩阵，如果对于每一行，第一个数小于第二个数，对于每一列，第一个数小于第二个数，那么这个矩阵就是美丽的。现在小红可以对矩阵顺时针旋转，她想知道，经过若干次旋转，能否得到美丽的矩阵。

一个矩阵 $[[1, 2], [3, 4]]$ 经过一次旋转过后，变成 $[[3, 1], [4, 2]]$。

## 输入格式

一行一个整数 $t$，表示数据组数。

对于每组数据，一行四个整数 $a, b, c, d$，表示矩阵为 $[[a, b], [c, d]]$。

$1 \leq t \leq 20$

$1 \leq a, b, c, d \leq 1000$

## 输出格式

对于每组数据，如果能得到美丽的矩阵，输出“Yes”，否则输出“No”。

## 示例

### 示例 1

**输入：**

```text
2
1 2 3 4
3 1 4 2
```

**输出：**

```text
Yes
Yes
```

**说明：**

第一组，本身就是一个美丽矩阵

第二组，旋转 3 次，变成$[[1, 2], [3, 4]]$，是一个美丽矩阵
