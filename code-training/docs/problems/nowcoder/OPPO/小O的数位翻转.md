# 小O的数位翻转

> OPPO 笔试真题 · 2024 秋招 · 研发通用岗 / 2024 秋招 · 后端开发
>
> 判题请到[牛客原题](https://www.nowcoder.com/practice/80a2e1aa90a24841bb153d14f13aa24a)提交。

## 题目描述

小O有一个长度为 $n$ 的数组 $a$，他现在想要选择其中一个数字进行“二进制翻转”操作，他想知道有多少种可能的选择方式，使得操作后的数组总和比不操作**更大**。

二进制翻转：指将 $x$ 的二进制翻转，翻转后去除前导 0。

（例如：$12=(1100)_2，f(12) = (0011)_2 = 3$。）

## 输入格式

第一行输入一个正整数 $n\ (1 \leq n \leq 2*10^5)$，表示数组 $a$ 的长度。

第二行输入 $n$ 个正整数 $a_1,a_2,\dots,a_n\ (1 \leq a_i \leq 10^9)$，表示数组 $a$ 的元素。

## 输出格式

在一行上输出一个整数，表示合法的方案数。

## 示例

### 示例 1

**输入：**

```text
5
11 12 11 13 12
```

**输出：**

```text
2
```

**说明：**

$(11)_{10}=(1011)_2$ ，翻转后变为 $(1101)_2$ ，大于翻转前；

$(12)_{10}=(1100)_2$ 和 $(13)_{10}=(1101)_2$ 翻转后均小于翻转前。

### 示例 2

**输入：**

```text
6
1 2 3 4 5 6
```

**输出：**

```text
0
```

## 解题思路

### 一次操作只动一个位置，所以每个元素各自为政

设原来的总和是 $S$，被选中翻转的是 $a_i$，那么操作后

$$
S' = S - a_i + f(a_i)
$$

于是

$$
S' > S \iff f(a_i) > a_i
$$

这个式子里只有 $a_i$ 自己。选中下标 $i$ 之后，其它 $n-1$ 个元素原封不动，
所以「$i$ 是不是合法选择」和别人的取值、和总和有多大都没有关系。

这一步给出的是**计数结论**，不只是化简：答案等于满足 $f(a_i) > a_i$ 的
**下标个数**。统计单位是位置，不是不同的数值 —— 示例 1 里 `11` 出现两次，
两个位置各自都合法，答案才是 2。如果先去重再数，答案会变成 1。

### 数据范围说明这题没有「选哪些元素」的问题

$n \le 2 \times 10^5$，$a_i \le 10^9 < 2^{30}$，每个数最多 30 位。逐个构造翻转值，
总运算量约 $2 \times 10^5 \times 30 = 6 \times 10^6$，用字符串也够。这题只需要
选**一个**位置，不存在子集枚举的空间，所以没有需要优化的搜索；全部工作量
就是把 $f(x)$ 算对、把判断写对。

### 怎么算 $f(x)$：把二进制串反序，再读回整数

```python
def bit_reverse(x: int) -> int:
    """把 x 的二进制表示反序（自动去掉反序后产生的前导 0）"""
    bits = bin(x)[2:]                 # 例如 12 -> '1100'
    return int(bits[::-1], 2)         # '0011' -> 3，int(..., 2) 会忽略前导 0
```

两步都不能省：

1. `bin(x)[2:]` 取的是**实际位长**，12 得到 `'1100'` 四位，而不是补到 32 位；
2. 反序之后，最高位可能是 0，`int(..., 2)` 会自动把它当不存在，
   这正是题面说的「翻转后去除前导 0」。

于是 $12 = (1100)_2 \to (0011)_2 = 3$，$11 = (1011)_2 \to (1101)_2 = 13$。

### 一遍扫描：严格大于才计数

```python
cnt = 0
for i in range(1, n + 1):
    x = int(data[i])
    if bit_reverse(x) > x:
        cnt += 1
```

判断必须是 `>`。二进制本身就是回文的数（$3=(11)_2$、$5=(101)_2$、$9=(1001)_2$）
翻转后还是自己，总和不变，题目要求「更大」所以不算。

### 同一个 $f$ 的位运算写法

不想建字符串时，可以从最低位开始一位一位地拼：

```python
def bit_reverse_bits(x: int) -> int:
    """从最低位开始取，拼出来的结果就是反序"""
    res = 0
    while x:
        res = res * 2 + (x & 1)   # 取当前最低位，接到结果末尾
        x >>= 1
    return res
```

为什么它和反序等价：循环第 $t$ 步取到的位是原数的第 $t$ 位（从低位数），
而它拼到 `res` 后面之后，位置正好是最终结果里从高位数第 $t$ 位 ——
「从低位取、往结果高位放」就是反序。以 12 为例，依次取到 0、0、1、1，
`res` 走 $0 \to 0 \to 1 \to 3$，得到 3，与字符串写法一致。

它不分配字符串，额外空间 $O(1)$，也方便照搬到别的语言。

## 完整代码实现

```python
import sys


def bit_reverse(x: int) -> int:
    """把 x 的二进制表示反序（自动去掉反序后产生的前导 0）"""
    bits = bin(x)[2:]                 # 例如 12 -> '1100'
    return int(bits[::-1], 2)         # '0011' -> 3，int(..., 2) 会忽略前导 0


def solve() -> None:
    """逐个判断 f(a_i) > a_i 是否成立，统计个数"""
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    n = int(data[0])
    cnt = 0
    for i in range(1, n + 1):
        x = int(data[i])
        if bit_reverse(x) > x:
            cnt += 1
    sys.stdout.write(str(cnt) + "\n")


if __name__ == "__main__":
    solve()
```

用位运算代替字符串的版本，判定逻辑完全相同：

```python
import sys


def bit_reverse(x: int) -> int:
    """逐位重拼：从最低位开始取，拼出来就是反序"""
    res = 0
    while x:
        res = res * 2 + (x & 1)
        x >>= 1
    return res


def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    n = int(data[0])
    cnt = sum(1 for i in range(1, n + 1) if bit_reverse(int(data[i])) > int(data[i]))
    sys.stdout.write(str(cnt) + "\n")


if __name__ == "__main__":
    solve()
```

## 示例推演

示例 1：$n = 5$，数组为 `11 12 11 13 12`。

| 下标 | $a_i$ | 二进制 | 翻转后 | $f(a_i)$ | $f(a_i) > a_i$ |
| ---- | ----- | ------ | ------ | -------- | -------------- |
| 1 | 11 | `1011` | `1101` | 13 | 是 |
| 2 | 12 | `1100` | `0011` | 3 | 否 |
| 3 | 11 | `1011` | `1101` | 13 | 是 |
| 4 | 13 | `1101` | `1011` | 11 | 否 |
| 5 | 12 | `1100` | `0011` | 3 | 否 |

下标 1 与下标 3 都满足条件，输出 2。它们的值相同，但题目问的是「选择方式」，
两个位置是两个方案，所以各算一次。

两点值得对照着看：

- 12 的二进制末尾是 0，反序后最高位变成 0，位数直接掉到两位，3 远小于 12；
- 11 与 13 是互为反序的一对数，一个变大一个变小 —— 谁大取决于从两端往中间看
  第一对不同的位偏向哪边（见「扩展思考」）。

示例 2：`1 2 3 4 5 6`。

| $a_i$ | 二进制 | 翻转后 | $f(a_i)$ | 是否变大 |
| ----- | ------ | ------ | -------- | -------- |
| 1 | `1` | `1` | 1 | 否（相等） |
| 2 | `10` | `01` | 1 | 否 |
| 3 | `11` | `11` | 3 | 否（相等） |
| 4 | `100` | `001` | 1 | 否 |
| 5 | `101` | `101` | 5 | 否（相等） |
| 6 | `110` | `011` | 3 | 否 |

一个都不满足，输出 0。这里 3、5 是回文数，翻转后与自身相等，正是判断要写
`>` 而不是 `>=` 的地方。

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| ---- | ---------- | ---------- | ---- |
| 构造翻转串（首个代码块） | $O(n \log A)$ | $O(\log A)$ | 每个数一次 `bin()` 加一次切片；$A = \max a_i \le 10^9$，不超过 30 位 |
| 逐位取模重拼（最优） | $O(n \log A)$ | $O(1)$ | 同样是每个数 30 次循环，但不分配字符串 |

$n \le 2 \times 10^5$、每个数不超过 30 位，总运算量在 $6 \times 10^6$ 次以内，
两种写法都能过。

## 易错点总结

1. **把翻转写成固定 32 位**：`bin(x)[2:].zfill(32)[::-1]` 会把 12 变成 `0xC0000000`
   = 3221225472。这样一来每个数翻转后都远大于自身，示例 1 输出 5 而不是 2。
   翻转的位长只能是 `x.bit_length()`，代码里对应 `bin(x)[2:]` 这一步。
2. **判断写成 `>=`**：`if bit_reverse(x) >= x` 会把回文数（3、5、9）也算进去，
   示例 2 输出 3 而不是 0。
3. **按值去重后再计数**：写成 `len({v for v in a if bit_reverse(v) > v})`，
   示例 1 里两个 `11` 只算一次，输出 1。题目问的是「选择方式」的个数，同一数值
   在不同下标上是不同方案。

## 扩展思考

- $f(x) > x$ 可以 $O(1)$ 判定，不必真的构造反序数：把二进制写成最高位在前，
  从两端往中间成对比较，**第一对不相同的位**决定大小 —— 靠左（高位一侧）那位
  是 0，就说明 $f(x) > x$；所有对都相同则是回文，$f(x) = x$。第一对就是最高位
  与最低位，而最高位恒为 1，所以最低位必须是 1 才有机会变大：
  $13 = (1101)_2$ 与 $11 = (1011)_2$ 互为反序、最低位都是 1，区别出在向内第二对
  （13 是「左 1 右 0」→ 变小，11 是「左 0 右 1」→ 变大）。
- 如果允许操作**任意多个**不同的位置，问最多能给总和增加多少：每个位置的收益是
  $f(a_i) - a_i$，互不影响，把正收益全部累加即可。
