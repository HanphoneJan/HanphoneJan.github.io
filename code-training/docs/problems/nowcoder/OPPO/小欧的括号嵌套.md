# 小欧的括号嵌套

> OPPO 笔试真题 · 2024 秋招 · 后端岗
>
> 判题请到[牛客原题](https://www.nowcoder.com/practice/0b461d2b82834cb1881567744effb0c1)提交。

## 题目描述

小欧想要构造一个合法的括号序列满足以下条件：

1.括号序列长度恰好为$2 \times n$。

2.括号序列的嵌套层数最大值为$r$。

括号嵌套层数是指在一个字符串中，以左括号 "(" 和右括号 ")" 形成的括号对的最大嵌套深度。

例如，在字符串 "((())())" 中，括号嵌套层数最大值为 3。

## 输入格式

一行两个整数$n, r(1 \leq r \leq n \leq 10^5)$。

## 输出格式

一行一个字符串表示括号序列。若有多种构造方案，输出任意一个即可。

## 示例

### 示例 1

**输入：**

```text
3 2
```

**输出：**

```text
()(())
```

---

## 解题思路

### 两个约束其实都在管「深度」

合法性和嵌套层数可以放在同一条曲线上看。用一个计数器 `d` 从左往右扫：遇到 `(` 加一、遇到 `)` 减一，
`d` 就是「当前还有几个没闭合的左括号」。

- 合法 ⇔ 扫的过程中 `d` 从不为负，并且结束时 `d == 0`（这自动保证了 `(` 与 `)` 各 n 个）；
- 嵌套层数 ⇔ 这条曲线上 `d` 的**最大值**。

于是题目可以改写成：画一条长 2n、起点终点都在 0、永不跌破 0 的折线，让它的最高点恰好是 r。

### 一块「深度刚好到 r」的积木

最直接的一段是 r 个左括号接 r 个右括号：

```python
block = "(" * r + ")" * r
```

深度依次是 `1, 2, ..., r, r-1, ..., 0`：先单调爬到 r、再单调落回 0。它本身就是一个合法括号序列
（前缀深度不小于 0、末尾归零），长度 2r，最高点被精确锁定在 r。

### 剩下的 n−r 对必须「横向」铺开，不能接着往上叠

还剩 n−r 对括号，有两种放法：

- **纵向叠上去**（`"(" * r + "(" * (n-r) + ")" * (n-r) + ")" * r`）：深度会一路爬到 n，`r < n` 时就超了；
- **横向铺开**：每一对自成一层、开完立刻关，即 `"()"` 重复。深度在 0 和 1 之间反复跳，最高只到 1。

因为 r ≥ 1，平铺部分的 1 压不过深度块的 r，整串的最大深度仍然是 r：

```python
ans = "(" * r + ")" * r + "()" * (n - r)
```

### 为什么拼接之后仍然合法

两段各自合法，关键在拼接处：深度块结束时深度回到 0，平铺部分从 0 重新开始，
整串的深度曲线就是两段曲线首尾相接。任何前缀的深度都不小于 0（两段各自都不小于 0），末尾也回到 0，
所以合法；长度 `2r + 2(n-r) = 2n`，最大深度 `max(r, 1) = r`。三条规定同时满足。

两段的**顺序可以互换**：`"()" * (n-r) + "(" * r + ")" * r` 同样合法，因为平铺部分也以深度 0 收尾。
把深度块放在前面只是多一个好处 —— 字典序更小：`(` 比 `)` 小，越早把 `(` 堆上去越占便宜。

### 两个极值都落在同一个式子里

`r = 1` 时深度块是 `()`，剩下的平铺，整体是 `()()...()`；`r = n` 时平铺部分是空串，整体是 `(((...)))`。
两种极值都不需要额外分支。

## 完整代码实现

深度块在前、平铺在后的版本（页面上的「跑样例」与逐帧可视化跑的就是它）：

```python
import sys


def solve() -> None:
    """先搭一个深度为 r 的块，剩下的对括号平铺"""
    data = sys.stdin.read().split()
    if not data:
        return
    n = int(data[0])
    r = int(data[1])

    # "("*r + ")"*r 深度恰好到 r；剩下的 n-r 对 "()" 深度只有 1
    ans = "(" * r + ")" * r + "()" * (n - r)
    sys.stdout.write(ans + "\n")


if __name__ == "__main__":
    solve()
```

深度块放在末尾的等价写法，用来对照「顺序无所谓」：

```python
import sys


def solve() -> None:
    """平铺部分在前、深度块在后，同样满足三个条件"""
    data = sys.stdin.read().split()
    if not data:
        return
    n = int(data[0])
    r = int(data[1])
    sys.stdout.write("()" * (n - r) + "(" * r + ")" * r + "\n")


if __name__ == "__main__":
    solve()
```

## 示例推演

输入 `n = 3, r = 2`：深度块是 `(())`，平铺部分是 `n - r = 1` 对 `()`。

| 位置 | 1 | 2 | 3 | 4 | 5 | 6 |
|------|---|---|---|---|---|---|
| 字符 | `(` | `(` | `)` | `)` | `(` | `)` |
| 深度 `d` | 1 | 2 | 1 | 0 | 1 | 0 |

最大深度 2 = r，长度 6 = 2n，`d` 从未跌破 0、最后回到 0 —— 合法。
题面给出的 `()(())` 正是「平铺在前、深度块在后」的同一构造，两个答案都通过。

再换 `n = 4, r = 2`：深度块 `(())`，平铺 2 对 `()()`，拼成 `(())()()`。

| 位置 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|------|---|---|---|---|---|---|---|---|
| 字符 | `(` | `(` | `)` | `)` | `(` | `)` | `(` | `)` |
| 深度 | 1 | 2 | 1 | 0 | 1 | 0 | 1 | 0 |

最大深度仍是 2：平铺部分只碰到 1，压不过 r。长度 8 = 2 × 4。

两个极值：

- `n = 5, r = 1`：深度块 `()`，平铺 4 对，结果是 `()()()()()`，深度只在 0、1 之间跳，最大值 1 = r；
- `n = 4, r = 4`：平铺部分为空串，结果是 `(((())))`，深度一路爬到 4 再落回 0。

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 深度块 + 平铺（最优） | O(n) | O(n) | 一次拼出 2n 个字符，O(n) 就是输出本身的长度 |
| 分段写出 + 校验 | O(n) | O(1) | 三段分别 `write`，额外只留一个深度计数器 |

## 易错点总结

1. **把 n 当成字符数**：写成 `"(" * n + ")" * n + "()" * (n - r)`，
   `n = 3, r = 2` 会输出 8 个字符的 `((()))()`，长度不是 2n（应该是 6），最大深度也变成 3 ≠ r。
   深度块的两半各是 r 个字符（r 对括号），不是 n 个。

2. **把剩下的括号纵向叠上去**：写成 `"(" * r + ")" * r + "(" * (n - r) + ")" * (n - r)`，
   `n = 5, r = 2` 得到 `(())((()))`，长度是对的（10），但后半段自己叠到深度 3，最大值变成 3 ≠ 2。
   平铺部分必须是一对一对的 `()`，开完立刻关。

3. **深度块的两半写反**：写成 `")" * r + "(" * r`，第一个字符就是 `)`，深度立刻变成 −1，不是合法序列。
   左括号必须在前。

## 扩展思考

- 字典序最小的构造就是深度块在前：`(` 比 `)` 小，越早堆上去越占便宜。
- 长度 2n 的合法括号序列总数是第 n 个卡特兰数 $\frac{1}{n+1}\binom{2n}{n}$；本题只问构造，不问计数。
- 「深度」是括号匹配、单调栈等一批题目的共同抽象：栈的最大高度就是这里的最大深度。
