# 小欧的前后缀交换

> OPPO 笔试真题 · 2024 秋招 · 移动端
>
> 判题请到[牛客原题](https://www.nowcoder.com/practice/79e1a3eb38cd4473b490172619326be2)提交；本站暂只收录题面与样例。

## 题目描述

小欧拿到了一个仅由'o'和'p'组成的字符串。

她希望将前缀尽可能多的连续'o'和后缀尽可能多的连续'p'交换一次。

你能帮帮她吗？

字符串的前缀：符号串左部的任意子串（或者说是字符串的任意首部）

字符串的后缀：符号串右部的任意子串（或者说是字符串的任意尾部）

## 输入格式

一行字符串，仅由'o'和'p'组成。

保证字符串的长度不超过100000

## 输出格式

交换后的字符串。

## 示例

### 示例 1

**输入：**

```text
ooppoopp
```

**输出：**

```text
ppppoooo
```

### 示例 2

**输入：**

```text
ooooop
```

**输出：**

```text
pooooo
```

### 示例 3

**输入：**

```text
ppppopo
```

**输出：**

```text
ppppopo
```
