# 小欧找数

> OPPO 笔试真题 · 2024 秋招 · 研发岗
>
> 判题请到[牛客原题](https://www.nowcoder.com/practice/e821e1ea74a742208a34b4588b2d78e1)提交。

## 题目描述

小欧有 2 个区间$[l_1,r_1]和[l_2,r_2]$。小欧想知道存在多少个整数$mid$可以找到两个整数$x$和$y$满足$mid = \lfloor \frac{x+y}{2} \rfloor$且$l_1 \leq x \leq r_1$，$l_2 \leq y \leq r_2$。

其中$\lfloor x \rfloor$表示对$x$下取整。

## 输入格式

一行四个整数$l_1,r_1,l_2,r_2(1 \leq l_1 \leq r_1 \leq 10^{14}, 1 \leq l_2 \leq r_2 \leq 10^{14})$。

## 输出格式

一行一个整数，表示满足条件的$mid$数量

## 示例

### 示例 1

**输入：**

```text
1 3 2 4
```

**输出：**

```text
3
```

**说明：**

当$mid = 1$时，可以找到$x = 1$,$y = 2$。

当$mid = 2$时，可以找到$x = 2$,$y = 2$。

当$mid = 3$时，可以找到$x = 3$,$y = 3$。

其他任意$mid$都无法找到满足条件的$x$和$y$。

---

## 解题思路

### 第一步：理解问题本质

题目问的不是「有多少对 $(x,y)$」，而是「有多少个不同的 $mid$」。
而 $mid = \lfloor (x+y)/2 \rfloor$ 只由 $x+y$ 决定，所以先把两个变量
收缩成一个：令 $S = x + y$，问题变成「$S$ 能取哪些值，这些值映射出的
$mid$ 有哪些」。

### 第二步：所有可能的 S 恰好铺满一段连续区间

$x$ 在 $[l_1, r_1]$ 里连续取值，$y$ 在 $[l_2, r_2]$ 里连续取值，
所以 $S$ 的最小值是 $l_1 + l_2$，最大值是 $r_1 + r_2$。

中间没有空洞：固定 $x$ 时，$y$ 从 $l_2$ 走到 $r_2$ 就已经把
$[x + l_2,\ x + r_2]$ 这一整段取遍；$x$ 增加 1，这段区间整体右移 1，
与上一段首尾相接或重叠。因此

$$
S \in [\,l_1 + l_2,\ r_1 + r_2\,]
$$

区间里的每个整数都能取到。

### 第三步：floor(S/2) 同样是一段连续区间

$S$ 每增加 1，$\lfloor S/2 \rfloor$ 要么不变、要么增加 1，绝不会跳过
某个整数。既然 $S$ 是从 $l_1+l_2$ 一格一格走到 $r_1+r_2$ 的，
$mid$ 的取值就是

$$
mid \in \left[\,\left\lfloor \frac{l_1+l_2}{2} \right\rfloor,\
\left\lfloor \frac{r_1+r_2}{2} \right\rfloor\,\right]
$$

答案即这段整数区间的长度：**右端点 − 左端点 + 1**。

### 第四步：为什么不用管奇偶

$S$ 为奇数时 $mid$ 是 $(S-1)/2$，为偶数时是 $S/2$。相邻两个 $S$ 给出的
$mid$ 最多相差 1，而 $S$ 是连续走过来的，所以每个中间整数都会被某个 $S$
命中，不需要分奇偶讨论。

## 完整代码实现

```python
import sys


def solve() -> None:
    """所有可能的 x+y 连续铺满一段区间，取两端 floor 后算长度"""
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    l1, r1, l2, r2 = (int(x) for x in data[:4])
    low = (l1 + l2) // 2      # 最小的 mid
    high = (r1 + r2) // 2     # 最大的 mid
    sys.stdout.write(str(high - low + 1) + "\n")


if __name__ == "__main__":
    solve()
```

## 示例推演

输入 $l_1=1,\ r_1=3,\ l_2=2,\ r_2=4$，于是 $S = x+y \in [3, 7]$：

| $S$ | 3 | 4 | 5 | 6 | 7 |
|-----|---|---|---|---|---|
| $\lfloor S/2 \rfloor$ | 1 | 2 | 2 | 3 | 3 |

不同的 $mid$ 只有 $\{1, 2, 3\}$，共 3 个。

用公式验证：$\lfloor (3+4)/2 \rfloor - \lfloor (1+2)/2 \rfloor + 1
= 3 - 1 + 1 = 3$，与穷举结果一致。

对应题面的三组解：

- $mid=1$：$x=1,\ y=2$；
- $mid=2$：$x=2,\ y=2$；
- $mid=3$：$x=3,\ y=3$。

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| ---- | ---------- | ---------- | ---- |
| 枚举 $x,y$ | $O((r_1-l_1+1)(r_2-l_2+1))$ | $O(1)$ | 区间可达 $10^{14}$，完全不可行 |
| 枚举 $S$ | $O(r_1+r_2-l_1-l_2)$ | $O(1)$ | 仍然会超时，但已经是「一维」思路 |
| 公式 | $O(1)$ | $O(1)$ | 直接算两端点，推荐 |

## 易错点总结

### 1. 忘记加 1

区间 $[L, R]$ 里整数个数是 $R - L + 1$，不是 $R - L$。
样例里 $3-1=2$ 会输出成 2，正好和正确答案差一。

### 2. 误以为要枚举 $x$ 和 $y$

$l, r$ 上界是 $10^{14}$，双重循环必然超时。题目只关心 $mid$ 的**个数**，
而这个个数只和两个端点的和有关。

### 3. 以为「和必须落在某个具体的奇偶位置上」

$S$ 是连续取遍的，取整之后 $mid$ 也连续，直接按区间长度算即可，不必再按奇偶拆开讨论。

### 4. 用浮点除法再去取整

`int((l1 + l2) / 2)` 在 $10^{14}$ 量级上虽然还能算对，但没必要冒精度风险，
直接用整数除法 `//` 即可（本题所有数都是正数，`//` 就是下取整）。

## 扩展思考

- 如果题目改成 $mid = \lceil (x+y)/2 \rceil$，结论同样是「连续区间」，
  只需把两个端点换成 $\lceil \cdot \rceil$：答案是
  $\lceil (r_1+r_2)/2 \rceil - \lceil (l_1+l_2)/2 \rceil + 1$。
- 如果 $x$、$y$ 的取值范围不是连续区间（比如只允许偶数），
  「$S$ 连续」这个前提就不成立了，需要重新分析取值集合。
- 更一般地，「两个连续整数区间上的线性组合的取值范围还是区间」是很多
  计数题的第一步化简，值得记住。
