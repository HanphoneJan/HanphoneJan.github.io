# 小欧找数

> OPPO 笔试真题 · 2024 秋招 · 研发岗
>
> 判题请到[牛客原题](https://www.nowcoder.com/practice/e821e1ea74a742208a34b4588b2d78e1)提交；本站暂只收录题面与样例。

## 题目描述

小欧有 2 个区间$[l_1,r_1]和[l_2,r_2]$。小欧想知道存在多少个整数$mid$可以找到两个整数$x$和$y$满足$mid = \lfloor \frac{x+y}{2} \rfloor$且$l_1 \leq x \leq r_1$，$l_2 \leq y \leq r_2$。

其中$\lfloor x \rfloor$表示对$x$下取整。

## 输入格式

一行四个整数$l_1,r_1,l_2,r_2(1 \leq l_1 \leq r_1 \leq 10^{14}, 1 \leq l_2 \leq r_2 \leq 10^{14})$。

## 输出格式

一行一个整数，表示满足条件的$mid$数量

## 示例

### 示例 1

**输入：**

```text
1 3 2 4
```

**输出：**

```text
3
```

**说明：**

当$mid = 1$时，可以找到$x = 1$,$y = 2$。

当$mid = 2$时，可以找到$x = 2$,$y = 2$。

当$mid = 3$时，可以找到$x = 3$,$y = 3$。

其他任意$mid$都无法找到满足条件的$x$和$y$。
