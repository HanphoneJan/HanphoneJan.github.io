# 单词

> OPPO 笔试真题 · 2023 秋招 · 前端岗
>
> 判题请到[牛客原题](https://www.nowcoder.com/practice/897a2519189a41dca01489aa4c1f1f6a)提交；本站暂只收录题面与样例。

## 题目描述

小欧有一些英文单词，他想知道这些单词是不是合法的。一个单词是合法的当且仅当这个单词首字母是大写的，其它字母均是小写的。你能帮帮他吗。

## 输入格式

输入包含多组数据。

第一行输入一个整数$T(1\le T \le 10^4)$，表示测试数据的组数。

接下来$T$行，每行输入一个字符串$S (1\le |S| \lt10)$，仅包含大小写英文字符。表示小欧的英文单词。

## 输出格式

对于每一组数据，如果单词是合法的，输出一行"YES"，否则输出一行"NO"。

## 示例

### 示例 1

**输入：**

```text
2
yeerV
Ophu
```

**输出：**

```text
NO
YES
```

**说明：**

yeerV的首字母是小写的，因此不是合法单词。

Ophu的首字母是大写的，其它字母都是小写的，因此是合法单词。

### 示例 2

**输入：**

```text
2
vvryuCryg
pzjiyR
```

**输出：**

```text
NO
NO
```
