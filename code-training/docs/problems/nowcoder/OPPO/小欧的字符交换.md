# 小欧的字符交换

> OPPO 笔试真题 · 2023 秋招 · 后端岗
>
> 判题请到[牛客原题](https://www.nowcoder.com/practice/e2aea9d40feb423ab33c09c0ca8cf672)提交；本站暂只收录题面与样例。

## 题目描述

小欧拿到了两个长度相等的字符串$s$和$t$。她想知道能否交换$s$中两个相邻的字符，使得$s$和$t$相等？请注意，最多只有1次交换的机会！

一共有$t$组询问。

## 输入格式

第一行输入一个正整数$q$，代表询问次数。

每组输入两行仅包含小写字母字符串，分别代表字符串$s$和字符串$t$。

$1\leq q \leq 100$

$s$和$t$的长度不超过100。

## 输出格式

对于每组询问，输出一行答案。若可以交换两个相邻字符使得$s$和$t$相等，则输出"Yes"。否则输出"No"。

## 示例

### 示例 1

**输入：**

```text
3
acb
cab
abcxz
cbaxz
wa
wa
```

**输出：**

```text
Yes
No
Yes
```

**说明：**

第一组询问，交换前两个字符即可。

第二组询问，无法进行一次“交换相邻两个字符”使得两字符串相等。

第三组询问，字符串本身相等，不需要交换。
