# 小欧的字符交换

> OPPO 笔试真题 · 2023 秋招 · 后端岗
>
> 判题请到[牛客原题](https://www.nowcoder.com/practice/e2aea9d40feb423ab33c09c0ca8cf672)提交。

## 题目描述

小欧拿到了两个长度相等的字符串$s$和$t$。她想知道能否交换$s$中两个相邻的字符，使得$s$和$t$相等？请注意，最多只有1次交换的机会！

一共有$t$组询问。

## 输入格式

第一行输入一个正整数$q$，代表询问次数。

每组输入两行仅包含小写字母字符串，分别代表字符串$s$和字符串$t$。

$1\leq q \leq 100$

$s$和$t$的长度不超过100。

## 输出格式

对于每组询问，输出一行答案。若可以交换两个相邻字符使得$s$和$t$相等，则输出"Yes"。否则输出"No"。

## 示例

### 示例 1

**输入：**

```text
3
acb
cab
abcxz
cbaxz
wa
wa
```

**输出：**

```text
Yes
No
Yes
```

**说明：**

第一组询问，交换前两个字符即可。

第二组询问，无法进行一次“交换相邻两个字符”使得两字符串相等。

第三组询问，字符串本身相等，不需要交换。

## 解题思路

### 先数差异位置：一次交换只动两个相邻格子

把 `s` 和 `t` 逐位对比，记下所有 `s[i] != t[i]` 的下标。一次相邻交换只改动 `i`、`i+1` 两个格子，
其它位置原封不动，所以差异的**个数**直接决定了有没有可能：

```python
# can_make_equal 的前半段
if s == t:
    return True                      # 「最多一次」包含 0 次
diff = [i for i in range(len(s)) if s[i] != t[i]]
if len(diff) != 2:
    return False
```

| 差异数 | 结论 | 理由 |
|--------|------|------|
| 0 | Yes | 已经相等，交换 0 次即可 |
| 1 | No | 交换要动两个位置：修好这一位的同时，必然把另一个本来正确的位置改坏 |
| 2 | 看下一节的两个条件 | 只有交换这两位才可能修好 |
| ≥3 | No | 一次交换最多消掉 2 处差异 |

### 两处不同时的两个条件

设不同的位置是 `i < j`。交换后 `s[i]` 变成原来的 `s[j]`、`s[j]` 变成原来的 `s[i]`，于是：

- **必须相邻**：`j == i + 1`，否则一次相邻交换碰不到这两个位置；
- **必须交叉相等**：`s[j]` 要顶替 `s[i]` 的位置，得有 `s[j] == t[i]`；反过来要有 `s[i] == t[j]`。

```python
i, j = diff
return j == i + 1 and s[i] == t[j] and s[j] == t[i]
```

两个条件合起来也是**充分**的：交换后 `i`、`j` 两处都对上了，其余位置本来相同且没被碰过，整串因此等于 `t`。

「两处不同」这个前提还排掉了一种退化情况：若 `s[i] == s[j]`，交叉条件 `s[j] == t[i]` 就等价于
`s[i] == t[i]`，与「这一位不同」矛盾。所以走到这里的两个字符必然不相等，交换是真的换了两样东西。

### 每组询问互不相干

`q` 组之间没有共享状态，逐组判断即可。字符串只含小写字母、不含空格，所以用 `split()`
一次拿到全部 token 后两两分组，不必关心每组占几行：

```python
pos = 1
for _ in range(q):
    s, t = data[pos], data[pos + 1]
    pos += 2
    out.append("Yes" if can_make_equal(s, t) else "No")
```

## 完整代码实现

先数差异位置、再判两个条件的版本（页面上的「跑样例」与逐帧可视化跑的就是它）：

```python
import sys


def can_make_equal(s: str, t: str) -> bool:
    """最多交换一对相邻字符，s 能否变成 t"""
    if s == t:
        return True

    diff = [i for i in range(len(s)) if s[i] != t[i]]
    if len(diff) != 2:
        return False

    i, j = diff
    # 必须相邻，且两个字符互换后正好各自对上
    return j == i + 1 and s[i] == t[j] and s[j] == t[i]


def solve() -> None:
    """逐组询问判断并输出 Yes / No"""
    data = sys.stdin.read().split()
    if not data:
        return
    q = int(data[0])
    out = []
    pos = 1
    for _ in range(q):
        s, t = data[pos], data[pos + 1]
        pos += 2
        out.append("Yes" if can_make_equal(s, t) else "No")
    sys.stdout.write("\n".join(out) + "\n")


if __name__ == "__main__":
    solve()
```

暴力枚举每一对相邻交换再整串比较的版本，正确但更慢，适合拿来对拍：

```python
import sys


def can_make_equal_brute(s: str, t: str) -> bool:
    """把每一对相邻字符各换一次，逐个和 t 比较"""
    if s == t:
        return True
    for i in range(len(s) - 1):
        if s[:i] + s[i + 1] + s[i] + s[i + 2:] == t:
            return True
    return False


def solve() -> None:
    data = sys.stdin.read().split()
    if not data:
        return
    q = int(data[0])
    out = []
    pos = 1
    for _ in range(q):
        s, t = data[pos], data[pos + 1]
        pos += 2
        out.append("Yes" if can_make_equal_brute(s, t) else "No")
    sys.stdout.write("\n".join(out) + "\n")


if __name__ == "__main__":
    solve()
```

## 示例推演

**第 1 组**：`s = "acb"`，`t = "cab"`。

| 位置 | 0 | 1 | 2 |
|------|---|---|---|
| `s` | a | c | b |
| `t` | c | a | b |
| 相同? | 否 | 否 | 是 |

`diff = [0, 1]`，个数为 2；`j == i + 1`（`1 == 0 + 1`）成立；
`s[0] = 'a' == t[1] = 'a'`、`s[1] = 'c' == t[0] = 'c'` 也成立。交换前两位得到 `cab`，输出 `Yes`。

**第 2 组**：`s = "abcxz"`，`t = "cbaxz"`。

| 位置 | 0 | 1 | 2 | 3 | 4 |
|------|---|---|---|---|---|
| `s` | a | b | c | x | z |
| `t` | c | b | a | x | z |
| 相同? | 否 | 是 | 否 | 是 | 是 |

`diff = [0, 2]`，个数为 2，但 `j - i = 2`，不相邻。一次相邻交换只能改到位置 `0/1` 或 `1/2`，
碰不到 0 与 2 这一对，输出 `No`。

**第 3 组**：`s = "wa"`，`t = "wa"`，`s == t` 直接命中提前返回，输出 `Yes`，一次都不用换。

再补两个样例没覆盖到的分支：

- `s = "ab"`、`t = "cb"`：`diff = [0]`，只有一处不同 → `No`。唯一能动到位置 0 的交换是 0/1 互换，
  得到 `ba`，与 `cb` 还是不同 —— 缺的那个字符得从别处搬来，一次交换补不上。
- `s = "ab"`、`t = "cd"`：`diff = [0, 1]`，相邻成立，但 `s[0] = 'a' != t[1] = 'd'`，交叉相等不成立 → `No`。
  实际交换只能得到 `ba`，与 `cd` 无关。

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 枚举所有相邻交换再比较 | O(q·L²) | O(L) | 每个位置换一次，每次整串比较 |
| 统计不同位置（最优） | O(q·L) | O(L) | 只扫一遍，`diff` 最多存 L 个下标 |

> `q` 是询问组数，`L` 是字符串长度。`q ≤ 100`、`L ≤ 100`，两种写法都能过，差别在思路干不干净。

---

## 易错点总结

1. **漏掉 `s == t` 的提前返回**：这时 `diff` 是空列表，`len(diff) != 2` 直接返回 `False`，
   样例第 3 组 `wa`/`wa` 会输出 `No`。题面是「最多 1 次」，0 次也算。

2. **把 `len(diff) != 2` 写成 `len(diff) > 2`**：只有一处不同时（例如 `ab` 与 `cb`），
   代码仍会走到 `i, j = diff`，抛 `ValueError: not enough values to unpack`。
   差异数必须精确等于 2 才继续往下走。

3. **只判相邻、忘了交叉相等**：把返回式写成 `j == i + 1`，
   `s = "ab"`、`t = "cd"` 会输出 `Yes`，而交换只能得到 `ba`。两处不同不代表字符能对上。

---

## 扩展思考

- 允许交换任意两个位置（不要求相邻）时，条件退化成「两处不同且交叉相等」，去掉 `j == i + 1` 即可。
- 允许最多 k 次相邻交换时，问题变成计算把 `s` 变成 `t` 所需的逆序对距离（双指针或置换环）。
- 若 `s`、`t` 的字符多重集不同，一次交换也救不回来，先比频次就能直接判 `No`。
