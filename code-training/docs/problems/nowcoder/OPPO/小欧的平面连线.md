# 小欧的平面连线

> OPPO 笔试真题 · 2023 秋招 · 研发岗
>
> 判题请到[牛客原题](https://www.nowcoder.com/practice/6c1271ba007148469ec9058ebad5066a)提交；本站暂只收录题面与样例。

## 题目描述

小欧在平面直角坐标系上有$n$个点（保证$n$是偶数），小欧想把这些点两两配对，一共可配 $\frac{n}{2}$ 对。配对的两点连一条线段。若该线段和坐标轴有一个交点，则视为有1的权值。因此，和x轴和y轴都有交点则有2的权值。（特殊的，若该线段经过原点，也视为有2的权值）。小欧希望最终的权值之和尽可能大，你能帮帮她吗？

## 输入格式

第一行输入一个正整数$n$，代表点的数量，保证是偶数。

接下来的$n$行，每行输入两个非零整数$x_i$和$y_i$。

$2\leq n \leq 10^5$

$-10^9 \leq x_i,y_i \leq 10^9$

保证$x_i,y_i$不为零。保证没有两个点坐标相同。

## 输出格式

输出一个整数，表示最大的权值。

## 示例

### 示例 1

**输入：**

```text
2
1 1
-1 -1
```

**输出：**

```text
2
```

**说明：**

只有两个点，连一条线段经过原点，有2的权值。

### 示例 2

**输入：**

```text
4
1 1
-1 1
2 1
-2 1
```

**输出：**

```text
2
```

**说明：**

第一个点和第四个点连一条线段，和y轴交于(0,1)，贡献1的权值。

第二个点和第三个点连一条线段，和y轴交于(0,1)，贡献1的权值。
