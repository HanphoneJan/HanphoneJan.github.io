# 小O的树上加边

> OPPO 笔试真题 · 2024 秋招 · AI/算法岗
>
> 判题请到[牛客原题](https://www.nowcoder.com/practice/246a42faded9456d964ddbc55a79e33c)提交。

## 题目描述

小O有一棵 $n$ 个点组成的树，树上的点从 $1$ 到 $n$ 编号，树上的边是无向的。任意一棵树都是二分图，小O想知道她最多可以给树加多少条边，使得新的图仍然是二分图。

二分图的定义：如果一个图的所有点可以被分成两个集合 $A$ 和 $B$，使得所有的边都是一端在 $A$ 中，一端在 $B$ 中，那么这个图就是二分图。

## 输入格式

第一行输入一个整数 $n\ (1 \leq n \leq 10^5 )$，表示树上的点数。

此后 $n-1$ 行，第 $i$ 行输入两个整数 $u_i$ 和 $v_i\ (1 \leq u_i, v_i \leq n )$，表示树上的一条边连接了点 $u_i$ 和点 $v_i$。保证这些边可以形成一棵树。

## 输出格式

在一行上输出一个正整数，表示最多可以给树加多少条边，使得新的图仍然是二分图。

## 示例

### 示例 1

**输入：**

```text
4
1 2
2 3
3 4
```

**输出：**

```text
1
```

**说明：**

可以添加一条边 (1, 4)，新的图仍然是二分图。

## 解题思路

### 新图还是二分图 ⇔ 新边也只能跨色

二分图的意思是存在一个划分 `(A, B)`，让**所有**边都一端在 `A`、一端在 `B`。树本身就给出这样一个划分：
从任意点出发按到该点距离的奇偶染色。

关键的一点是这个划分**唯一**：树连通，任意两点之间只有一条路径，路径上颜色只能交替，
所以 1 号点一旦定了颜色，其余每个点的颜色就被「到 1 号点的距离奇偶」钉死，
另一种合法染色只是把黑白整体互换。

新图包含这棵原树，因此它的二分划分必须沿用它（最多差一次整体互换），
于是新加的每条边也只能连接一黑一白。一旦连了两个同色点，它们和树上那条路径就拼出一个奇环，图不再是二分图。

### 上限就是完全二分图，而且能达到

跨色的点对一共 `c0 * c1` 个（`c0`、`c1` 是两类点的个数）。把这些跨色对全部连上，
得到的是**完全二分图**，它当然是二分图。所以这个上界就是答案的上界，同时又是可构造的：

```python
ans = c0 * c1 - (n - 1)      # 代码里两个计数存在 cnt[0] / cnt[1]
```

`n - 1` 是树已有的边数 —— 它们本来就都在这个完全二分图里，不能重复添加，所以要减掉。
「先定划分，再把跨色对取满」一步同时给出了上界（任何合法加边都不可能超出跨色对）和构造（取满依然合法），
这就是它最优的原因。

数据范围也排除了别的路子：`n ≤ 10^5`，而可能的加边集合有 2 的 Θ(n²) 次方种，只能靠公式一次算出。

### 用 BFS 染色数出两类点的个数

```python
color = [-1] * (n + 1)
color[1] = 0
cnt = [1, 0]                 # 起点自己先算进 0 号色

dq = deque([1])
while dq:
    u = dq.popleft()
    for w in adj[u]:
        if color[w] == -1:          # 只有首次到达才染色、才计数
            color[w] = color[u] ^ 1
            cnt[color[w]] += 1
            dq.append(w)
```

`cnt` 的初值写成 `[1, 0]` 而不是 `[0, 0]`，是因为起点 1 的颜色是直接赋上去的，
它永远不会经过 `color[w] == -1` 这一支，也就不会被计数。计数只发生在「首次发现」处，同一个点不会数两次。

遍历用 BFS 而不是递归 DFS：`n = 10^5` 的一条链会让递归深度顶到 10 万层，Python 默认递归上限是 1000。

### 两个边界

- `n = 1`：没有边，`c0 = 1`、`c1 = 0`，答案 `0 - 0 = 0`；
- 星形树（1 号点连着其余所有点）：`c0 = 1`、`c1 = n - 1`，答案 `(n-1) - (n-1) = 0`
  —— 星形树本身就是完全二分图，一条边也加不了。

题面把输出写成「正整数」，这两种情况下真实答案是 0。

## 完整代码实现

BFS 染色 + 公式（页面上的「跑样例」与逐帧可视化跑的就是它）：

```python
import sys
from collections import deque


def solve() -> None:
    """BFS 染色统计两类点数，再算完全二分图的边数"""
    data = sys.stdin.buffer.read().split()
    if not data:
        return

    n = int(data[0])
    adj = [[] for _ in range(n + 1)]
    idx = 1
    for _ in range(n - 1):
        u = int(data[idx])
        v = int(data[idx + 1])
        idx += 2
        adj[u].append(v)
        adj[v].append(u)

    color = [-1] * (n + 1)
    color[1] = 0
    cnt = [1, 0]                 # cnt[0] / cnt[1] 为两类点的数量

    dq = deque([1])
    while dq:
        u = dq.popleft()
        for w in adj[u]:
            if color[w] == -1:
                color[w] = color[u] ^ 1
                cnt[color[w]] += 1
                dq.append(w)

    sys.stdout.write(str(cnt[0] * cnt[1] - (n - 1)) + "\n")


if __name__ == "__main__":
    solve()
```

## 示例推演

输入是链 `1 - 2 - 3 - 4`。从 1 号点开始 BFS，队列与染色过程：

| 步骤 | 出队 | 看它的邻点 | 动作 | `cnt` |
|------|------|-----------|------|-------|
| 1 | 1 | 2 | `color[2] = 0 ^ 1 = 1`，入队 | `[1, 1]` |
| 2 | 2 | 1、3 | 1 已染色跳过；`color[3] = 0`，入队 | `[2, 1]` |
| 3 | 3 | 2、4 | 2 已染色跳过；`color[4] = 1`，入队 | `[2, 2]` |
| 4 | 4 | 3 | 已染色，跳过 | `[2, 2]` |

于是 `c0 = 2`（点 1、3）、`c1 = 2`（点 2、4）。跨色点对一共 `2 × 2 = 4` 个，逐个核对：

| 跨色对 | 是否已有 | 说明 |
|--------|---------|------|
| `(1, 2)` | 是 | 树边 |
| `(3, 2)` | 是 | 树边 `2 - 3` |
| `(3, 4)` | 是 | 树边 |
| `(1, 4)` | 否 | 唯一能加的边 |

答案 `4 - 3 = 1`，与说明里的 `(1, 4)` 一致。

为什么不能加 `(1, 3)` 或 `(2, 4)`：两者都是同色点，加上去会和树上的路径拼出长度为 3 的奇环
（`1 - 2 - 3 - 1` 与 `2 - 3 - 4 - 2`），图就不再二分了。

再看链 `1 - 2 - 3 - 4 - 5`：颜色依次 0、1、0、1、0，`c0 = 3`（点 1、3、5）、`c1 = 2`（点 2、4）。
完全二分图 `3 × 2 = 6` 条边，树边 `5 - 1 = 4` 条，答案 `2`。逐条核对：6 个跨色对里
`(1, 2)`、`(2, 3)`、`(3, 4)`、`(4, 5)` 是树边，可以加的正是 `(1, 4)` 与 `(2, 5)`。

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 递归 DFS 染色 | O(n) | O(n) | 链状输入递归深度到 10 万，需要手动抬高上限 |
| BFS 染色 + 公式（最优） | O(n) | O(n) | 显式队列，深度不受输入形状影响 |

## 易错点总结

1. **最后忘了减掉树边**：`c0 * c1` 是**新图的总边数**，不是「还能加几条」。
   样例里直接输出 `4`，而正确结果是 `4 - 3 = 1`。

2. **`cnt` 初值写 `[0, 0]`**：起点 1 的颜色是直接赋的，不经过 `color[w] == -1` 分支，于是它永远不被计数。
   样例链会得到 `c0 = 1`（只剩点 3）、`c1 = 2`，输出 `2 - 3 = -1`。要么把初值写成 `[1, 0]`，
   要么在起点入队时就计数。

3. **用递归 DFS 又没抬高递归上限**：`n = 10^5` 的链让调用栈到 10 万层，
   抛 `RecursionError: maximum recursion depth exceeded`（默认上限 1000）。样例只有 4 个点，看不出来。

## 扩展思考

- 输入若是森林：每棵树的划分可以独立翻转。要让 `c0 * c1` 最大，就把各棵树中较大的那一类放进同一个集合，
  答案是「各树较大颜色数之和」×「各树较小颜色数之和」，再减掉原有边数。
- 若允许删边再加边，答案就是同顶点集上边数最多的二分图：`⌊n² / 4⌋`。
- 染色判二分是奇环检测、二分图最大匹配、2-SAT 的共同前提，这个模板值得背下来。
