# 小欧的字符串判定

> OPPO 笔试真题 · 2024 秋招 · 研发岗
>
> 判题请到[牛客原题](https://www.nowcoder.com/practice/36f1cc91b5d04df2896b91f5e18fa092)提交；本站暂只收录题面与样例。

## 题目描述

小欧拿到了两个字符串$s$和$t$，她有一个目标字符串$target$。小欧希望每一位从$s$或者$t$的对应位置的字符中二选一生成$target$，你能告诉小欧她最终能达成目的吗？

## 输入格式

第一行输入一个正整数$n$，代表$s,t,target$的长度。

第二行输入一个字符串$s$。

第三行输入一个字符串$t$。

第四行输入一个字符串$target$。

$1\leq n \leq 100$

## 输出格式

如果可以达成目的，则输出"Yes"。否则输出"No"

## 示例

### 示例 1

**输入：**

```text
3
abc
bad
aac
```

**输出：**

```text
Yes
```

**说明：**

第一个、第三个字符取$s$的、第二个字符取$t$的即可。

### 示例 2

**输入：**

```text
2
ab
bb
aa
```

**输出：**

```text
No
```

**说明：**

第二个字符无论取$s$还是取$t$，都无法得到字符'a'。
