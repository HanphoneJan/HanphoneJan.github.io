# 小欧的字符串构造

> OPPO 笔试真题 · 2024 秋招 · 算法岗
>
> 判题请到[牛客原题](https://www.nowcoder.com/practice/3cf0c0aa163a44aba2ee1f7062cb8a12)提交；本站暂只收录题面与样例。

## 题目描述

小欧有一个字符串 $s$ ，她想构造一个长度为 $k$ 的字符串 $t$ ，使得 $s+t$ 或 $t+s$ 拼成的字符串是回文串。

如果可以构造，则输出 $t$ ，若无法构造，请输出 -1。

## 输入格式

第一行输入一个长度不超过 $10^5$ 的字符串 $s$。

第二行输入一个整数 $k(1 \leq k \leq 10^5)$ 。

## 输出格式

输出一个字符串表示答案。若无法构造，则输出 -1。

## 示例

### 示例 1

**输入：**

```text
abc
3
```

**输出：**

```text
cba
```

**说明：**

可以把字符串拼成abccba或cbaabc，这两个字符串都是回文串。
