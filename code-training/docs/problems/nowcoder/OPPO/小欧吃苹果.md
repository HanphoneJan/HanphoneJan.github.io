# 小欧吃苹果

> OPPO 笔试真题 · 2024 秋招 · 数据开发岗
>
> 判题请到[牛客原题](https://www.nowcoder.com/practice/1e681787c63045cdbfc26b9b09002aeb)提交；本站暂只收录题面与样例。

## 题目描述

小欧有一棵包含$n$个结点的树，每个结点有一个人，处在第$i$个结点的人想吃恰好$i$个苹果。但他手里有$a_i$个苹果，可能不够吃，也可能太多了。

他们每次传递可以向树上相邻的结点传递1个苹果，小欧想知道，让所有人都恰好获得他想吃的苹果的数量总共需要有多少次传递？

## 输入格式

第一行输入一个整数$n(1 \leq n \leq 10^5)$。

第二行输入$n$个整数$a_i$，保证所有$a_i$都为非负整数，且和恰好等于$\frac{n(n+1)}{2}$。

接下来$n-1$行，每一行输出两个整数$u,v(1 \leq u,v \leq n)$,表示结点$u$和结点$v$有一条边。

## 输出格式

一行一个整数，表示最小次数。

## 示例

### 示例 1

**输入：**

```text
4
3 1 4 2
1 2
1 3
2 4
```

**输出：**

```text
6
```

**说明：**

结点3传递1次苹果给结点1。此时苹果数量为[4,1,3,2]。

结点1传递共3次苹果给结点2。此时苹果数量为[1,4,3,2]。

结点2传递共2次苹果给结点4。此时苹果数量为[1,2,3,4]。
