# 小欧的排列交换

> OPPO 笔试真题 · 2023 秋招 · 移动端岗 · [牛客原题](https://www.nowcoder.com/practice/1875f9b665544fcfab04056444cd69e9)

## 题目描述

小欧拿到了一个长度为 `n` 的排列。她每次操作可以交换任意两个数。她希望在不超过 `n - 1` 次操作后，使得不存在两个相邻的数都是奇数，也不存在两个相邻的数都是偶数。你能帮帮她吗？

所谓排列，即 1 到 `n` 组成的数组，每个数仅出现 1 次。

## 输入格式

第一行输入一个正整数 `n`，代表排列的长度。

第二行输入 `n` 个正整数 `a_i`，代表小欧拿到的排列。

`1 <= n <= 10^5`

## 输出格式

第一行输出一个整数 `k`，代表交换的次数。

接下来的 `k` 行，每行输出两个正整数 `a_i` 和 `a_j`，代表交换这两个数。交换的是**数值**，不是下标——数组是排列，每个值只出现一次，所以按值交换没有歧义。

有多种方案时，输出任意合法方案即可。

## 示例

### 示例 1

**输入：**

```
3
3 1 2
```

**输出：**

```
1
1 2
```

**说明：** 交换值为 1 和值为 2 的两个数，数组变成 `3 2 1`，奇偶性是「奇偶奇」，没有相邻同奇偶。

## 解题思路

题面只关心奇偶性，每个位置具体放哪个数无所谓。于是把问题拆成两层：先定一张「奇偶骨架」，再让每个位置的数符合骨架的奇偶要求。骨架确定后，「该放奇数却放了偶数」和「该放偶数却放了奇数」这两种错位位置个数相等，两两交换就能一次修好两格。

### 骨架只有一种选法

`1` 到 `n` 里奇数有 `⌈n/2⌉` 个、偶数有 `⌊n/2⌋` 个。

- `n` 为奇数时奇数多一个，交替排列只能是「奇偶奇偶……奇」，奇数必须占第 `1,3,5,…` 位；
- `n` 为偶数时两种骨架都行（奇偶奇偶… 或 偶奇偶奇…），任选一种。

下面统一用「奇数位放奇数、偶数位放偶数」。

### 两类错位，个数一定相等

扫一遍数组，把位置分成两类：

- **A 类**：位置编号是奇数（要放奇数），当前放的却是偶数；
- **B 类**：位置编号是偶数（要放偶数），当前放的却是奇数。

奇数总数恰好等于奇数位的个数（`⌈n/2⌉`）。落在奇数位上的奇数有 `⌈n/2⌉ - |A|` 个，落在偶数位上的奇数有 `|B|` 个，两者相加就是全部奇数：

```
⌈n/2⌉ - |A| + |B| = ⌈n/2⌉   ⇒   |A| = |B|
```

所以两堆一样多，按顺序配对即可：A 类位置拿到 B 类位置上的奇数，B 类位置拿到 A 类位置上的偶数，一次交换修好两格。

```python
need_odd, need_even = [], []          # A 类、B 类位置
for pos in range(1, n + 1):
    want_odd = pos % 2 == 1
    is_odd = a[pos - 1] % 2 == 1
    if want_odd and not is_odd:
        need_odd.append(pos)
    elif not want_odd and is_odd:
        need_even.append(pos)

# 两堆等长，zip 不会截断；输出的是数值，不是下标
swaps = [(a[q - 1], a[p - 1]) for p, q in zip(need_odd, need_even)]
```

### 次数不会超

交换次数等于 `|A|`，最多 `⌊n/2⌋` 次，而题目允许 `n - 1` 次。`n = 2` 时两边都是 1，`n = 1` 时一次都不用换，边界自然满足。

### 输出的是数值

`a_i`、`a_j` 指的是**值**，不是下标。样例里 `1 2` 交换的是值为 1 和值为 2 的两个数，换完是 `3 2 1`；若当成下标 `1` 和 `2`，换的是第 1、2 个位置，得到 `1 3 2`，奇偶性变成「奇奇偶」，反而更糟。

### 推演：示例 1

`n = 3`，排列是 `3 1 2`。骨架是「奇偶奇」：第 1、3 位放奇数，第 2 位放偶数。

| 位置 | 当前值 | 当前奇偶 | 该放 | 是否错位 | 归类 |
| --- | --- | --- | --- | --- | --- |
| 1 | 3 | 奇 | 奇 | 否 | — |
| 2 | 1 | 奇 | 偶 | 是 | B 类 |
| 3 | 2 | 偶 | 奇 | 是 | A 类 |

A 类是位置 3，B 类是位置 2，配成一对：交换值 `1` 和 `2`。交换后数组为 `3 2 1`，第 2 位是偶数、第 3 位是奇数，奇偶性「奇偶奇」符合要求，输出 `1` 与 `1 2`。

## 完整代码实现

```python
import sys


def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    n = int(data[0])
    a = list(map(int, data[1:1 + n]))

    need_odd = []    # 该放奇数却放了偶数的位置
    need_even = []   # 该放偶数却放了奇数的位置
    for pos in range(1, n + 1):
        want_odd = pos % 2 == 1
        is_odd = a[pos - 1] % 2 == 1
        if want_odd and not is_odd:
            need_odd.append(pos)
        elif not want_odd and is_odd:
            need_even.append(pos)

    # 两堆一样多，按顺序配对：一次交换修好两格
    swaps = [(a[q - 1], a[p - 1]) for p, q in zip(need_odd, need_even)]

    out = [str(len(swaps))]
    out += [f"{x} {y}" for x, y in swaps]
    sys.stdout.write("\n".join(out) + "\n")


if __name__ == "__main__":
    solve()
```

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| --- | --- | --- | --- |
| 逐位找目标值再交换 | O(n²) | O(n) | 每次都要扫一遍数组找那个数在哪 |
| 错位位置两两配对（最优） | O(n) | O(n) | 一遍分类，一趟配对，交换按值输出 |

## 易错点总结

### 1. 输出下标而不是数值

把 `swaps.append((a[q - 1], a[p - 1]))` 写成 `(p, q)`，示例 1 会输出 `1` / `2 3`。按题面理解，这是「交换值为 2 和值为 3 的两个数」，数组变成 `2 1 3`，奇偶性「偶奇奇」——第 2、3 位相邻同奇偶，方案不合法。

### 2. `n` 为奇数时用了相反骨架

把 `want_odd = pos % 2 == 1` 写成 `pos % 2 == 0`（「偶数位放偶数」的反面骨架），奇数个数比偶数多一个的输入会有一格永远修不好。示例 1 的 `3 1 2` 在这个骨架下 `need_even` 为空，程序输出 `0` 次交换，数组原样输出，`3` 和 `1` 仍然相邻同奇偶。

## 扩展思考

- 要求交换次数最少时，配对数 `|A|` 已经是下界——每次交换最多修好两格，而 A 类每格都必须被换一次，配对法恰好达到下界。
- 若操作改成「只能交换相邻两个数」，最小次数等于把奇数（或偶数）挪到目标位置的总位移，与逆序对有关，不再是 O(n) 的构造题。
