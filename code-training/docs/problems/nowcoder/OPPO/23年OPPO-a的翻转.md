# 23年OPPO-a的翻转

> OPPO 笔试真题 · 2023 秋招 · 研发岗
>
> 判题请到[牛客原题](https://www.nowcoder.com/practice/dcce2d0cc8f740c29e0885df96c9d625)提交；本站暂只收录题面与样例。

## 题目描述

数字$a$翻转数位得到数字$b$，计算$a+b$。

## 输入格式

一个正整数$a\;(1\leqslant a \leqslant 10^9)$。保证$a$在十进制下每一位都非$0$。

## 输出格式

一个正整数表示答案。

## 示例

### 示例 1

**输入：**

```text
12
```

**输出：**

```text
33
```

**说明：**

正整数$a=12$，翻转得到$b=21$，$a+b=33$。

### 示例 2

**输入：**

```text
23
```

**输出：**

```text
55
```
