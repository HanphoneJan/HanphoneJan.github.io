# 小O的子序列最值

> OPPO 笔试真题 · 2024 秋招 · 移动开发 · [牛客原题](https://www.nowcoder.com/practice/c7e5b649799845dca44b2f9ba0f02177)

## 题目描述

小O有两个长度为 `n` 的数组，现在她想从这两个数组中分别选出一个非空**子序列**，使得从第一个数组中选出的子序列的最大值不大于从第二个数组中选出的子序列的最小值。

小O想知道两个子序列的长度之和最大是多少。

如果数组 `a` 可以通过删除数组 `b` 中的若干（可能为零或全部）元素得到，则数组 `a` 是数组 `b` 的子序列。

## 输入格式

第一行输入一个整数 `n`（`1 <= n <= 10^5`）代表数组的长度。

第二行输入 `n` 个整数 `a_1, a_2, ..., a_n`（`1 <= a_i <= 10^9`）代表第一个数组。

第三行输入 `n` 个整数 `b_1, b_2, ..., b_n`（`1 <= b_i <= 10^9`）代表第二个数组。

## 输出格式

在一行上输出一个整数，表示两个子序列的长度之和最大是多少。如果无法选出满足条件的子序列，则输出 `-1`。

## 示例

### 示例 1

**输入：**

```
4
1 2 3 4
3 4 5 6
```

**输出：**

```
7
```

**说明：** 第一个子序列取 `[1,2,3,4]`（最大值 4），第二个取 `[4,5,6]`（最小值 4），长度之和 7。

## 解题思路

两个子序列的顺序完全不参与判定——约束只有一条：第一个子序列的**最大值**不超过第二个子序列的**最小值**。所以「子序列」在这里退化成「随便挑一个非空下标集合」，问题只剩一个数：两边各自能选多少。把这个判定改写成「存在一个门槛 `v`，第一个全选 `<= v` 的，第二个全选 `>= v` 的」，两边的选择就解耦了。

### 门槛一立，两边就能全选

设门槛为 `v`：

- 第一个子序列里所有数都 `<= v`，那 `a` 中**每一个** `<= v` 的元素都可以拿进来，最大值仍然不超过 `v`；
- 第二个子序列里所有数都 `>= v`，那 `b` 中**每一个** `>= v` 的元素都可以拿进来，最小值仍然不小于 `v`。

也就是说，固定 `v` 之后没有「多选会破坏条件」的顾虑，最优选法就是全拿：

```
长度 = cnt_a(<= v) + cnt_b(>= v)
```

约束变成 `max(A) <= min(B)` 这一步用的是「`<=`」而不是「`<`」：两边等于 `v` 时仍然合法。

### 门槛只需要在 `b` 的值上枚举

取一组最优解，设第二个子序列的最小值是 `y`。`y` 必然是 `b` 里的某个元素，令 `v = y`：

- 第二个子序列里每个数都 `>= y`，所以 `cnt_b(>= v)` 至少能覆盖最优解里的那一整段；
- 第一个子序列的每个数都 `<= max(A) <= y = v`，所以 `cnt_a(<= v)` 也至少能覆盖它。

于是这个门槛算出来的长度不小于最优解，而它本身又是一个合法选法，所以恰好等于最优解。门槛只枚举 `b` 中出现过的值就够了，不需要碰 `1..10^9`。

实现上把两个数组排序，计数各用一次二分：

```python
ca = bisect_right(a_sorted, v)        # a 中 <= v 的个数
cb = n - bisect_left(b_sorted, v)     # b 中 >= v 的个数
```

### 两边都必须非空

`cnt_a(<= v) == 0` 说明第一个子序列一个数都选不出来，`cnt_b(>= v) == 0` 同理，这样的门槛直接跳过。所有门槛都不合法时输出 `-1`——比如 `a = [5]`、`b = [3]`：唯一的门槛 3 让 `a` 这边空掉，无解。

### 推演：示例 1

`a = [1,2,3,4]`、`b = [3,4,5,6]`，门槛取 `b` 的去重值。

| 门槛 `v` | `cnt_a(<= v)` | `cnt_b(>= v)` | 长度之和 |
| --- | --- | --- | --- |
| 3 | 3（1,2,3） | 4（3,4,5,6） | 7 |
| 4 | 4（1,2,3,4） | 3（4,5,6） | 7 |
| 5 | 4 | 2（5,6） | 6 |
| 6 | 4 | 1（6） | 5 |

最大值 7。`v = 3` 与 `v = 4` 都取到 7：前者把 `b` 全拿、`a` 少拿一个 4；后者 `a` 全拿、`b` 少拿一个 3。

## 完整代码实现

```python
import sys
from bisect import bisect_left, bisect_right


def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return

    n = int(data[0])
    a = sorted(map(int, data[1:1 + n]))
    b = list(map(int, data[1 + n:1 + 2 * n]))
    b_sorted = sorted(b)

    best = -1
    # 门槛只需枚举 b 中出现过的值：最优解里 b 的最小值本身就是 b 的元素
    for v in set(b):
        ca = bisect_right(a, v)              # a 中 <= v 的个数
        if ca == 0:                          # 第一个子序列必须非空
            continue
        cb = n - bisect_left(b_sorted, v)    # b 中 >= v 的个数
        if cb == 0:                          # 第二个子序列必须非空
            continue
        if ca + cb > best:
            best = ca + cb

    sys.stdout.write(str(best) + "\n")


if __name__ == "__main__":
    solve()
```

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| --- | --- | --- | --- |
| 枚举两边的下标集合 | O(4^n) | O(n) | `n = 20` 就已经是万亿级 |
| 排序 + 枚举门槛 + 二分（最优） | O(n log n) | O(n) | 排序一次，每个门槛两次二分 |

## 易错点总结

### 1. 忘了第一个子序列也要非空

只判 `cnt_b(>= v) == 0`、不判 `cnt_a(<= v) == 0`，`a = [5]`、`b = [1,3]` 会输出 `1`（门槛 1 时 `a` 一个数都选不出来），正确答案是 `-1`。

### 2. 允许相等却用了 `bisect_left`

题目是 `max(A) <= min(B)`，`a = [3]`、`b = [3]` 时两边各取一个，答案是 2。`cnt_a(<= v)` 写成 `bisect_left(a, v)` 会把等于 `v` 的元素排除掉，`ca = 0` 直接跳过这个门槛，输出 `-1`。

## 扩展思考

- 若把条件改成「最大值**严格小于**最小值」，两处的 `bisect_right` 就要换成 `bisect_left`，其余不变。
- 姊妹题《[小O的子序列最值(二)](小O的子序列最值(二).md)》把「求最大长度」换成了「求方案数」，门槛的思路仍然可用，但要按「最大值恰好为 `v`」和「最小值恰好为 `v`」分类计数。
