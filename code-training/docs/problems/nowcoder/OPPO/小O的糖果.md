# 小O的糖果

> OPPO 笔试真题 · 2024 秋招 · 移动开发
>
> 判题请到[牛客原题](https://www.nowcoder.com/practice/c090ece039314d578e51913e758ce262)提交。

## 题目描述

小O有三盒糖果，糖果数分别为 $a,b$ 和 $c$ 。

现在小O又有了 $x$ 颗糖果，他要把这 $x$ 颗糖果恰好分到新的 $k$ 个盒子里面去，保证每一个盒子里至少有一颗糖果。这样他就拥有了 $k+3$ 盒糖果，然后他会在这 $k+3$ 盒糖果中挑选出最多的那一盒糖果。

显然，$x$ 颗糖果分到 $k$ 个盒子里往往不止一种方案。小O想知道，无论他如何分配这 $x$ 颗糖果，糖果最多的那一个盒子的编号是否确定且唯一。

## 输入格式

第一行输入三个整数 $a,b$ 和 $c\ (1\leq a,b,c \leq 10^9 )$ 表示初始三盒糖果的个数。

第二行输入两个整数 $x$ 和 $k\ ( 1\leq k \leq x \leq 10^9 )$ 代表小O新获得的糖果个数，和需要新放入糖果的盒子数。

## 输出格式

如果糖果最多的那一个盒子的编号确定且唯一，输出“$\rm YES$”

，否则，输出“$\rm NO$”。

## 示例

### 示例 1

**输入：**

```text
4 2 3
2 2
```

**输出：**

```text
YES
```

### 示例 2

**输入：**

```text
5 3 6
100 2
```

**输出：**

```text
NO
```

## 解题思路

### 题目问的是「编号」是否唯一确定，不是「最多有几颗」

三盒原有的糖果数固定，编号 1、2、3；新盒子有 $k$ 个，编号 $4 \sim k+3$，
装多少完全由分配方案决定。

所以判定标准是：**在所有合法分配方案里，「糖果最多」的那个盒子的编号是不是
同一个**。这给出两种证明方式，缺一不可：

- 判 `YES` 要证明「无论怎么分，最多的都是同一个编号」；
- 判 `NO` 只要给出**两种合法分配**，让最多的落在不同编号上（或者给出一种
  分配让两个盒子并列最多 —— 并列也就谈不上唯一）。

记原有三盒的最大值为 $M$，取到 $M$ 的盒数为 $cnt$（$1 \le cnt \le 3$）。

### 新盒子能取到的范围是 $[1,\ top]$

$x$ 颗糖恰好分进 $k$ 个盒子、每盒至少 1 颗。想让某个新盒子尽量多，就把其它
$k-1$ 个盒子各留 1 颗，剩下的全给它：

$$
top = x - (k - 1) = x - k + 1
$$

这个上界是能真正取到的。而且反过来，$[1, top]$ 里的任何一个数 $t$ 都能放进
**任意指定**的新盒子：那个盒子放 $t$，其余 $k-1$ 个各放 1，总数
$t + (k-1) \le top + k - 1 = x$，合法。

最后这条性质就是「编号不确定」的全部来源：**$k \ge 2$ 时新盒子彼此对称**，
同一个数量放在 4 号盒还是 5 号盒都合法。

### 分情况讨论，只剩两个 `YES` 分支

| 情况 | 理由 | 结论 |
| ---- | ---- | ---- |
| $k = 1$ 且 $x > M$ | 唯一的新盒子必然装 $x$ 颗，比原来所有盒子都多，编号固定是 4 | YES |
| $top > M$ 且 $k \ge 2$ | 让一个盒子装 $top$：放 4 号或放 5 号是两种合法分配，最多盒编号不同 | NO |
| $top = M$ | 让某个新盒子也装 $M$，与原来的最大值并列，谈不上唯一 | NO |
| $top < M$ 且 $cnt = 1$ | 每个新盒子都 $< M$，最多的一盒只能是原来那唯一的一盒 | YES |
| $top < M$ 且 $cnt \ge 2$ | 原来就有两盒并列最多，怎么分都不会变 | NO |

$k = 1$ 时 $top = x$，所以「$top < M$ 且 $cnt = 1$」这一行也覆盖了「只有一个
新盒子、而且它不如原最大值」的情形；需要单独拿出来的只有「$k = 1$ 且
$x > M$」—— 这时新盒子成了唯一最大，但因为没有第二个新盒子可以和它互换，
编号反而是确定的。

写成代码就是两个条件：

```python
m = max(a, b, c)
cnt_m = (a == m) + (b == m) + (c == m)   # 有几盒并列最大
top = x - k + 1                          # 单个新盒子最多能装多少

if k == 1 and x > m:
    # 只有一个新盒子，它必然就是最多的那一盒，编号确定为 4
    ans = True
elif top < m and cnt_m == 1:
    # 新盒子全都比 m 小，且原来最大的那盒唯一
    ans = True
else:
    ans = False
```

### 为什么不去枚举分配方案

「$x$ 颗糖分给 $k$ 个盒子、每盒至少一颗」的方案数是隔板法给出的
$\binom{x-1}{k-1}$，$x$ 到 $10^9$ 时是天文数字。而上面那张表说明：结论只依赖
三个数 —— 原最大值 $M$、它的出现次数 $cnt$、新盒子的上界 $top$。把这三个数
算出来，$O(1)$ 就能回答。

## 完整代码实现

```python
import sys


def solve() -> None:
    """比较「原有最大值」与「新盒子可能的最大值」，分情况判断"""
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    a, b, c = int(data[0]), int(data[1]), int(data[2])
    x, k = int(data[3]), int(data[4])

    m = max(a, b, c)
    cnt_m = (a == m) + (b == m) + (c == m)   # 有几盒并列最大
    top = x - k + 1                          # 单个新盒子最多能装多少

    if k == 1 and x > m:
        # 只有一个新盒子，它必然就是最多的那一盒，编号确定为 4
        ans = True
    elif top < m and cnt_m == 1:
        # 新盒子全都比 m 小，且原来最大的那盒唯一
        ans = True
    else:
        ans = False

    sys.stdout.write(("YES" if ans else "NO") + "\n")


if __name__ == "__main__":
    solve()
```

## 示例推演

### 示例 1：`a = 4, b = 2, c = 3, x = 2, k = 2`

$M = 4$、$cnt = 1$（只有 1 号盒取到 4），$top = 2 - 2 + 1 = 1$。

新盒子只有一种分法：两个盒子各 1 颗（$2 = 1 + 1$，没法让谁多拿）。五盒是

| 编号 | 1 | 2 | 3 | 4 | 5 |
| ---- | - | - | - | - | - |
| 糖果 | 4 | 2 | 3 | 1 | 1 |

最多的是 1 号盒，所有分法都只有这一种，所以编号确定，输出 `YES`。
这也对应表里那一行「$top = 1 < M = 4$ 且 $cnt = 1$」。

### 示例 2：`a = 5, b = 3, c = 6, x = 100, k = 2`

$M = 6$、$cnt = 1$、$top = 100 - 2 + 1 = 99 > 6$，且 $k = 2 \ge 2$。

| 分配方案 | 五盒糖果 | 最多的是 |
| -------- | -------- | -------- |
| 99 + 1 | 5, 3, 6, 99, 1 | 4 号盒 |
| 1 + 99 | 5, 3, 6, 1, 99 | 5 号盒 |

两种方案都合法、最多盒的编号却不同，输出 `NO`。

### 再看三个边界

- **$top = M$**：`a = 5, b = 3, c = 6, x = 7, k = 2`，$top = 6 = M$。
  取分配 $6 + 1$ 得到 `5, 3, 6, 6, 1`，3 号盒与 4 号盒并列最多，编号不唯一，
  输出 `NO`。
- **$k = 1$ 且新盒子更大**：`a = 1, b = 1, c = 1, x = 2, k = 1`，$M = 1$，
  唯一的新盒子装 2 颗，四盒是 `1, 1, 1, 2`，最多的是 4 号盒 —— 只有一种分配，
  编号确定，输出 `YES`。
- **原最大值并列**：`a = 10, b = 10, c = 3, x = 2, k = 2`，$M = 10$、$cnt = 2$、
  $top = 1 < 10$。新盒子都很小，但 1 号与 2 号盒并列最多，编号不唯一，输出 `NO`。

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| ---- | ---------- | ---------- | ---- |
| 枚举所有分配方案再比最多盒编号 | $O(\binom{x-1}{k-1})$ | $O(k)$ | 方案数是天文数字，$x \le 10^9$ 时不可行 |
| 公式分类讨论（最优） | $O(1)$ | $O(1)$ | 只算最大值、最大值个数、新盒子上界三个数 |

## 易错点总结

1. **$k = 1$ 时漏掉「新盒子成为唯一最大」这一支**：只写 `top < m and cnt_m == 1`，
   输入 `1 1 1` / `5 1` 时 $top = 5 > M$，落到 `else` 输出 `NO`，而正确答案是
   `YES`（唯一的新盒子必然最多，编号固定是 4）。
2. **边界写成 `top <= m`**：`5 3 6` / `7 2` 时 $top = 6 = M$，可以分出一盒 6 颗与
   3 号盒并列，答案是 `NO`；写成 `<=` 会输出 `YES`。判据必须是严格小于 `top < m`。
3. **忘了检查原最大值是否唯一**：`cnt_m` 没参与判断（或少写 `cnt_m == 1`），
   `10 10 3` / `2 2` 会输出 `YES`，而 1 号与 2 号盒并列最多，编号并不唯一。

## 扩展思考

- 如果改成问「最多那一盒的糖果数可能是多少」，答案是一个区间：最小值
  $\max(M, \lceil x/k \rceil)$（尽量平均分），最大值 $\max(M, x-k+1)$（尽量集中）。
- 把三盒原有糖果换成 $n$ 盒，结论完全一样，只需要 $M$ 和 $M$ 出现的次数 ——
  这是「只保留关键统计量」的典型例子。
