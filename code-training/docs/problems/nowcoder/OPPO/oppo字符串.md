# oppo字符串

> OPPO 笔试真题 · 2024 秋招 · 数据分析岗
>
> 判题请到[牛客原题](https://www.nowcoder.com/practice/f4005d9b87984674a9a1bad7dd7d44c9)提交；本站暂只收录题面与样例。

## 题目描述

小欧有一个字符串，小欧想知道，给你一个字符串，他是不是 oppo 型字符串？

oppo 型字符串：一个长度为 4 的回文串，且第一个字符不等于第二个字符。

## 输入格式

一行一个字符串，长度为 4。

## 输出格式

若它是 oppo 型字符串，输出"Yes"(不带引号)。否则输出"No"。

## 示例

### 示例 1

**输入：**

```text
oppo
```

**输出：**

```text
Yes
```

### 示例 2

**输入：**

```text
aaaa
```

**输出：**

```text
No
```
