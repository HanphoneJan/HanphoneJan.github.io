# 圆覆盖

> OPPO 笔试真题 · 2023 秋招 · 前端岗
>
> 判题请到[牛客原题](https://www.nowcoder.com/practice/4f96afe5dfe74dad88dbe419d33f9536)提交；本站暂只收录题面与样例。

## 题目描述

在二维平面中给出 $n$ 个点，第 $i$ 个点的坐标为 $(x_i,y_i)$，其点权为 $v_i$。你可以以原点 $(0,0)$ 为圆心放置一个圆。

设圆的半径为 $r$，若某点满足 $x_i^2+y_i^2\leqq r^2$，则认为该点被圆**覆盖**。请你计算：

$\bullet$ 要使被覆盖点的权值和不少于给定整数 $S$，所需的**最小**半径 $r$ 是多少？

若无论半径多大都无法达到权值下限，则输出 $-1$。

## 输入格式

第一行输入两个整数 $n,S\left(1\leqq n\leqq10^5,\ 1\leqq S\leqq10^{14}\right)$——点的数量与要求的权值下限。

接下来 $n$ 行，第 $i$ 行输入三个整数 $x_i,y_i,v_i\ \left(-10^9\leqq x_i,y_i\leqq10^9,\ 0\leqq v_i<2^{31}\right)$，描述第 $i$ 个点的坐标与权值。

## 输出格式

若存在可行半径，在一行输出该最小半径 $r$；否则输出 $-1$。

设你的输出为 $a$，答案为 $b$。当且仅当

$\displaystyle \frac{|a-b|}{\max\bigl(1,|b|\bigr)}<10^{-6}$

时，你的答案将被判定为正确。

## 示例

### 示例 1

**输入：**

```text
5 10
0 1 2
-1 1 3
3 3 4
-4 3 1
5 -3 1
```

**输出：**

```text
5
```

**说明：**

当半径为 $5$ 时，$(0,1)$、$(-1,1)$、$(3,3)$、$(-4,3)$ 四个点被覆盖，权值和为 $2+3+4+1=10$，达到要求。

### 示例 2

**输入：**

```text
5 10
0 1 2
-1 1 3
3 3 2
-4 3 1
5 -3 1
```

**输出：**

```text
-1
```

**说明：**

权值和无法达到10
