# BISHI80. 走迷宫

## 题目描述

给定一个 n 行 m 列的网格。你从起点 s 出发，每一次可以向上、下、左、右
移动一步（不超出边界）。某些格子上存在障碍物，无法经过。
求从 s 移动到终点 t 的最少步数；若无法到达，输出 -1。

## 输入格式

第一行输入两个整数 n、m，代表网格的行数与列数。
第二行输入四个整数 x1、y1、x2、y2，代表起点与终点的坐标（行列均从 1 开始）。
此后 n 行，第 i 行输入一个长度为 m 的字符串：`*` 表示障碍物，`.` 表示可通行。
保证起点所在格子可通行。

## 输出格式

输出一个整数，表示最少移动次数；若无法到达，输出 -1。

## 示例

### 示例 1

**输入：**
```
5 5
1 1 5 5
.....
****.
.....
**.**
.....
```

**输出：**
```
12
```

**说明：**
第 2 行只有第 5 列可通行、第 4 行只有第 3 列可通行，
必须绕行，最短需要 12 步。

### 示例 2

**输入：**
```
5 5
1 1 4 5
.....
****.
.....
**.**
.....
```

**输出：**
```
-1
```

**说明：**
终点 (4,5) 被障碍物隔开，无法到达。

### 示例 3

**输入：**
```
5 5
1 1 5 5
.....
****.
.....
*****
.....
```

**输出：**
```
-1
```

**说明：**
第 4 行整行是障碍物，把上下完全隔断。

## 解题思路

### 输出是什么：每步代价都是 1 的最少移动次数

把每个可通行格子看成一个点，相邻格子之间连一条边，每条边的代价都是 1。
「最少移动几次」就是这张**单位权图**上 s 到 t 的最短距离。

这决定了算法：边权全是 1 时不需要 Dijkstra，按层扩散就够了，也就是 BFS。

### 为什么不用 DFS

DFS 也能算出正确答案：枚举所有 s→t 的路径，取最短的那条。但它没有「先到就是最短」的性质，
必须把所有路径都比一遍才能确定答案。网格上每格有 4 个方向，路径条数随规模指数增长，
再加「当前长度 ≥ 已知最短就回头」的剪枝也只能救回一部分。

BFS 的优势不是「常数小」，而是它**天然按距离分层**：第 0 层是 s，第 1 层是走 1 步能到的所有格子，
第 k 层恰好是所有「距离恰好为 k」的格子。层一旦建立，最短距离就已经知道了。

### 为什么第一次到达就是最短距离

BFS 靠一条不变量工作：

> 出队时，格子 `u` 的 `dist` 已经等于它到起点的最短距离，且出队顺序的距离单调不减。

用归纳法看：设当前出队的 `u` 距离为 `d`，它是由某个距离 `d-1` 的格子扩展来的（第 0 层由起点自己入队）。
于是存在一条长度为 `d` 的路径，真实最短距离 `d* ≤ d`。

假设 `d* < d`。在一条长度为 `d*` 的最短路径上，`u` 的前一个格子 `w` 满足 `dist(w) = d* - 1 < d - 1`，
所以 `w` 一定在 `u` 之前就被处理过。`w` 处理时会检查四个邻居，那时 `u` 还没被访问过
（否则 `u` 早就带着更小的距离入队了），于是 `u` 会被赋成 `d*` —— 与「`u` 的距离是 `d`」矛盾。
所以 `d* = d`。

这条证明也说明了 BFS 的写法要求：**第一次发现一个格子时就要立刻标记并记录距离**，
之后不再修改。中途允许「找到一个更短的再改小」就不再是 BFS 了。

### 一个数组干两件事：`dist` 里的 -1

`-1` 兼作两个用途：**没访问过**，以及**不可达**。

- 扩展时用 `dist[nx][ny] == -1` 判断这一格是否第一次到达；
- 结束时直接输出 `dist[tx][ty]`：能到就是最短步数，到不了就还是 -1，正好是题目要的输出，
  不需要为「不可达」单独写分支。

起点 `dist[sx][sy] = 0`，其余全是 -1。

### 写法二：按层处理，用 `steps` 数层

如果不想维护整张距离表，也可以每轮把「当前这一层」一次性处理完：

```python
steps = 0
while queue:
    for _ in range(len(queue)):      # len(queue) 在进入 for 时求值一次
        x, y = queue.popleft()
        if x == tx and y == ty:      # 出队即在第 steps 层
            print(steps)
            return
        # ……四个方向扩展，新格子入队（属于下一层）……
    steps += 1                       # 一层处理完，步数 +1
```

`for _ in range(len(queue))` 里的 `len(queue)` 是循环开始时算的，所以循环体内新入队的格子
属于下一层，本轮不会被处理。这种写法在「多源 BFS」「单词接龙」这类题里更自然 ——
那些题你关心的本来就是「第几步」，而不是每个点各自的距离。

代价是要单独开一张 `visited` 表（`dist` 那套是拿它兼职的），代码也更长一点。

### 坐标：x 是行、y 是列

输入 `x1 y1 x2 y2`，题目约定 x 是行号、y 是列号，且都从 1 开始。
读入后统一减 1 换成 0 起下标，写成 `sx, sy = x1 - 1, y1 - 1`，不要换顺序。

## 完整代码实现

```python
import sys
from collections import deque


def solve() -> None:
    """BFS 求网格最短步数"""
    data = sys.stdin.read().split()
    if not data:
        return
    idx = 0
    n = int(data[idx]); m = int(data[idx + 1]); idx += 2
    x1 = int(data[idx]); y1 = int(data[idx + 1])
    x2 = int(data[idx + 2]); y2 = int(data[idx + 3]); idx += 4
    grid = data[idx:idx + n]

    sx, sy = x1 - 1, y1 - 1          # 题目坐标从 1 开始，转成 0 开始
    tx, ty = x2 - 1, y2 - 1

    dist = [[-1] * m for _ in range(n)]
    dist[sx][sy] = 0
    queue = deque([(sx, sy)])
    while queue:
        x, y = queue.popleft()
        if x == tx and y == ty:
            break
        for dx, dy in ((1, 0), (-1, 0), (0, 1), (0, -1)):
            nx, ny = x + dx, y + dy
            if 0 <= nx < n and 0 <= ny < m and dist[nx][ny] == -1 and grid[nx][ny] == '.':
                dist[nx][ny] = dist[x][y] + 1
                queue.append((nx, ny))
    sys.stdout.write(str(dist[tx][ty]) + "\n")


if __name__ == "__main__":
    solve()
```

按层计数、用 `visited` 代替 `dist` 的版本，输出完全相同：

```python
import sys
from collections import deque


def solve() -> None:
    """BFS 逐层处理，steps 就是层号"""
    data = sys.stdin.read().split()
    if not data:
        return
    n, m = int(data[0]), int(data[1])
    x1, y1, x2, y2 = map(int, data[2:6])
    grid = data[6:6 + n]

    sx, sy = x1 - 1, y1 - 1
    tx, ty = x2 - 1, y2 - 1

    seen = [[False] * m for _ in range(n)]
    seen[sx][sy] = True
    queue = deque([(sx, sy)])
    steps = 0
    while queue:
        for _ in range(len(queue)):          # 只处理当前这一层
            x, y = queue.popleft()
            if x == tx and y == ty:
                sys.stdout.write(str(steps) + "\n")
                return
            for dx, dy in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                nx, ny = x + dx, y + dy
                if 0 <= nx < n and 0 <= ny < m and not seen[nx][ny] and grid[nx][ny] == '.':
                    seen[nx][ny] = True
                    queue.append((nx, ny))
        steps += 1
    sys.stdout.write("-1\n")


if __name__ == "__main__":
    solve()
```

## 示例推演

以示例 1 为例，起点 (1,1)、终点 (5,5)，网格里两处「窄门」很关键：

- 第 2 行只有第 5 列是 `.`，所以任何从第 1 行去第 3 行的路线都必须经过 **(2,5)**；
- 第 4 行只有第 3 列是 `.`，所以任何从第 3 行去第 5 行的路线都必须经过 **(4,3)**。

于是最短距离可以按三段算下限，三段都取曼哈顿距离：

| 段 | 从 → 到 | 曼哈顿距离 | 能否取到 |
|---|---|---|---|
| 1 | (1,1) → (2,5) | 1 + 4 = 5 | 能：沿第 1 行右移到 (1,5)，再下到 (2,5) |
| 2 | (2,5) → (4,3) | 2 + 2 = 4 | 能：(2,5)→(3,5)→(3,4)→(3,3)→(4,3) |
| 3 | (4,3) → (5,5) | 1 + 2 = 3 | 能：(4,3)→(5,3)→(5,4)→(5,5) |

三段的和是 12，且 12 步的路线确实存在，所以最短就是 12。

把 BFS 的 `dist` 铺开看（`-` 表示障碍，数字是到起点的步数）：

| `dist` | 第1列 | 第2列 | 第3列 | 第4列 | 第5列 |
|---|---|---|---|---|---|
| 第1行 | 0 | 1 | 2 | 3 | 4 |
| 第2行 | - | - | - | - | 5 |
| 第3行 | 10 | 9 | 8 | 7 | 6 |
| 第4行 | - | - | 9 | - | - |
| 第5行 | 12 | 11 | 10 | 11 | 12 |

数字的走向正好是「一圈一圈往里」：第 1 行从左往右、第 3 行从右往左、第 5 行两头往中间汇，
每一格都是它上一层邻居的 `+1`。右下角 `dist[5][5] = 12`，与样例一致。

另外两组样例是两种不同的「到不了」：

- 示例 2 的终点 (4,5) 本身就在障碍上（第 4 行是 `**.**`），这一格永远不会入队，
  `dist[4][5]` 保持 -1，输出 -1。
- 示例 3 的第 4 行整行是 `*`，第 3 行和第 5 行之间没有任何开口，终点虽然在 `.` 上，
  但从起点走不过去，`dist[5][5]` 同样保持 -1。

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| DFS 枚举所有路径 + 剪枝 | 最坏 O(4^(n·m)) | O(n·m) | 正确性依赖剪枝，最坏情况下要枚举的路径数仍是天文数字 |
| BFS + `dist` 数组（最优） | O(n·m) | O(n·m) | 首个代码块；每格最多入队一次，四个方向各看一次 |
| BFS 逐层计数 + `visited` | O(n·m) | O(n·m) | 用 `steps` 代替距离表，省不掉 `visited`，代码更长 |

> 网格有 `n·m` 个点、最多 `4·n·m` 条边，所以是 `O(n·m)` 级别；障碍多的图实际更快。

## 易错点总结

1. **`dist` 初值写成 0**：`dist = [[0] * m for _ in range(n)]`，那么判断「第一次到达」的
   `dist[nx][ny] == -1` 永远不成立，BFS 一格都不扩展，示例 1 输出 `0`。
   未访问必须是 -1，它同时承担「不可达」的返回值。
2. **行列顺序写反**：写成 `sx, sy = y1 - 1, x1 - 1`（把 x 当成列、y 当成行）。
   示例 1 的起点 (1,1) 和终点 (5,5) 在对角线上，写反了照样得 12；示例 2 的终点 (4,5) 会被读成
   第 5 行第 4 列 —— 那格是 `.`，于是输出 `11` 而不是 `-1`。
3. **障碍判断写成 `'#'`**：同目录的 BISHI76 用 `#` 表示墙，从那份代码照抄过来忘了改，
   本题的 `.` 全部过不了判定，示例 1 输出 `0`。本题的障碍是 `*`。

## 扩展思考

- **边权不全为 1**（有的格子走起来更慢）：BFS 失效，换成 Dijkstra；权只有 0 和 1 时用 0-1 BFS。
- **多个起点**：初始化时把所有起点都入队、`dist = 0`，其余不变 —— 这就是多源 BFS，
  算的是「到最近起点的距离」。
- **要输出具体路径**：再存一个 `from` 数组记「这一格是从哪来的」，从终点倒着走回起点。
