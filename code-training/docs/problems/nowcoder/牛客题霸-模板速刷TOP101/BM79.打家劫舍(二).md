# BM79. 打家劫舍(二)

## 题目描述

你是一个经验丰富的小偷，准备偷沿湖的一排房间。这些房间组成一个闭合的圆环，
即第一个房间和最后一个房间视为相邻。仍然不能偷相邻的两家。
给定长度为 n 的整数数组 nums，请你计算在不被发现的前提下最多的偷窃金额。

## 输入格式

- `nums`：int 型一维数组，表示每个房间的现金数额。

## 输出格式

返回 int 型，最多能偷到的金额。

## 示例

### 示例 1

**输入：**
```
nums = [1,2,3,4]
```

**输出：**
```
6
```

**说明：**
最优方案是偷第 2、4 个房间，金额 2 + 4 = 6。

### 示例 2

**输入：**
```
nums = [1,3,6]
```

**输出：**
```
6
```

**说明：**
由于 1 和 6 相邻，最优方案是只偷第 3 个房间，金额 6。

## 解题思路

### 输出是什么：环上「不能偷相邻」的最大金额

返回的是一个整数：所有合法偷法里金额最大的那一个。合法指的是没有两个被偷的房间相邻。

和「打家劫舍（一）」相比，房间的排列从一条线变成了一个圈。相邻关系因此多了一条：
**第 0 个和第 n-1 个也相邻**。其余每间房仍然只和左右两个邻居相邻。

### 环形只多出这一条约束，所以只需多讨论两种情况

线性版本好写，是因为「第 i 个偷不偷」只牵扯到 i-1，从前往后推就够了。
到了环上，第 0 个的选择会牵到第 n-1 个，这条先后关系断掉了。

但多出来的约束只有一句：**第 0 个和第 n-1 个不能同时被偷**。于是任何合法方案（包括最优的那个）
至少满足下面之一：

- 不偷第 n-1 个；
- 不偷第 0 个。

（两个都不偷的方案同时满足两条，不影响结论。）

把这两种情况各自变成一个**线性问题**：

- A = 在 `nums[0 .. n-2]` 上做线性打家劫舍；
- B = 在 `nums[1 .. n-1]` 上做线性打家劫舍。

### 为什么 `max(A, B)` 就是环上的答案

要两个方向都成立，等式才成立：

1. **`max(A, B) ≤ 最优值`**：A 和 B 都是环上的合法方案 —— A 没偷第 n-1 个，B 没偷第 0 个，
   首尾这两个「在环上相邻」的房间不会同时出现在方案里。既然合法，金额就不会超过最优值。
2. **`最优值 ≤ max(A, B)`**：最优方案要么不偷第 n-1 个 —— 那它就是 `nums[0 .. n-2]` 上的一个合法方案，
   金额不超过 A；要么不偷第 0 个 —— 金额不超过 B。两种情况必居其一。

两个不等式把答案夹住，所以 `max(A, B)` 正好是最优值。这里「恰好覆盖」是关键：
两种拆分不是随便挑的，而是把「首尾互斥」这一条约束拆成了两个互补的分支。

**只拆一侧是不够的。** 取 `nums = [10,1,1,1]`，环是 `10-1-1-1-10`（首尾相邻）。
最优解偷第 0、2 个，金额 10 + 1 = 11，它属于「不偷第 n-1 个」那一支；
若只看 `nums[1:] = [1,1,1]`，最多只能拿到 1 + 1 = 2。

### 线性子问题：一张表最直观

`dp[i]` 表示「只考虑前 i 个房间时的最大金额」。对第 i 个房间（金额 `x`）：

- **不偷**：金额等于前 i-1 个房间的结果 `dp[i-1]`；
- **偷**：第 i-1 个房间就不能偷，金额等于 `dp[i-2] + x`。

两者取大，边界 `dp[0] = 0`（没有房间时金额为 0）：

```python
def rob_line(arr: List[int]) -> int:
    """dp[i]：只考虑前 i 个房间时的最大金额"""
    dp = [0] * (len(arr) + 1)
    for i, x in enumerate(arr, 1):
        take = x + (dp[i - 2] if i >= 2 else 0)   # i == 1 时没有 dp[-1]，按 0 算
        dp[i] = max(dp[i - 1], take)
    return dp[len(arr)]
```

这个转移的不变量是：**填 `dp[i]` 时，`dp[0 .. i-1]` 都已经是对应前缀的正确答案**。
因为 `dp[i]` 只从 `dp[i-1]` 和 `dp[i-2]` 取值，而这两格在 i 递增的顺序下必然已经定稿，
所以从头往后填一遍就能得到全部答案。

### 只要前两格，两个变量就够

`dp[i]` 只依赖 `dp[i-1]`、`dp[i-2]`，更早的格子再也用不到，可以直接滚动：

```python
def rob_line(arr: List[int]) -> int:
    prev2, prev1 = 0, 0                       # dp[i-2], dp[i-1]
    for x in arr:
        prev2, prev1 = prev1, max(prev1, prev2 + x)
    return prev1
```

`prev2, prev1 = prev1, max(...)` 是**同时赋值**：右边全部用旧值算完才写到左边。
拆成两句 `prev2 = prev1` 再 `prev1 = max(prev1, prev2 + x)`，第二句里的 `prev2` 已经是新的
（也就是 `dp[i-1]`），`prev2 + x` 就成了「上一间和这间一起偷」，答案会偏大。

### 接回环形

```python
n = len(nums)
if n == 1:                       # 只有一个房间时，两个切片都是空的
    return nums[0]
return max(self._rob_line(nums[:-1]), self._rob_line(nums[1:]))
```

`nums[:-1]` 与 `nums[1:]` 各是一次 O(n) 的拷贝，换来的是两行就能读懂的结构。
`n == 1` 必须单独处理：那时 `nums[:-1]` 和 `nums[1:]` 都退化成空数组，
两次线性扫描都返回 0，而正确答案是这个房间本身。

## 完整代码实现

```python
from typing import List


class Solution:
    def rob(self, nums: List[int]) -> int:
        """环形打家劫舍：拆成两个线性子问题取最大值"""
        n = len(nums)
        if n == 0:
            return 0
        if n == 1:
            return nums[0]
        # 方案一：不考虑最后一个房间；方案二：不考虑第一个房间
        return max(self._rob_line(nums[:-1]), self._rob_line(nums[1:]))

    def _rob_line(self, arr: List[int]) -> int:
        """线性打家劫舍（辅助方法，下划线开头）"""
        prev, cur = 0, 0
        for x in arr:
            prev, cur = cur, max(cur, prev + x)
        return cur
```

线性部分改成数组 DP 的同一份答案，需要打印转移过程时更好用：

```python
from typing import List


class Solution:
    def rob(self, nums: List[int]) -> int:
        """同样的拆环，线性部分用数组 DP"""
        n = len(nums)
        if n == 1:
            return nums[0]
        return max(self._rob_line(nums[:-1]), self._rob_line(nums[1:]))

    def _rob_line(self, arr: List[int]) -> int:
        dp = [0] * (len(arr) + 1)
        for i, x in enumerate(arr, 1):
            take = x + (dp[i - 2] if i >= 2 else 0)
            dp[i] = max(dp[i - 1], take)
        return dp[len(arr)]
```

## 示例推演

以 `nums = [1,2,3,4]` 为例，环上的相邻关系是 `1-2-3-4-1`。

**A：不偷第 4 个房间**，在 `[1,2,3]` 上做线性 DP：

| i | x | 不偷：`dp[i-1]` | 偷：`dp[i-2] + x` | `dp[i]` |
|---|---|---|-----------|------|
| 1 | 1 | `dp[0] = 0` | 0 + 1 = 1 | 1 |
| 2 | 2 | 1 | `dp[0] + 2 = 2` | 2 |
| 3 | 3 | 2 | `dp[1] + 3 = 4` | 4 |

A = 4，对应偷第 1、3 个（1 + 3）。

**B：不偷第 1 个房间**，在 `[2,3,4]` 上做线性 DP：

| i | x | 不偷：`dp[i-1]` | 偷：`dp[i-2] + x` | `dp[i]` |
|---|---|---|-----------|------|
| 1 | 2 | 0 | 0 + 2 = 2 | 2 |
| 2 | 3 | 2 | `dp[0] + 3 = 3` | 3 |
| 3 | 4 | 3 | `dp[1] + 4 = 2 + 4 = 6` | 6 |

B = 6，对应偷第 2、4 个（2 + 4）。取较大者 `max(4, 6) = 6`，与样例一致。

再用首个代码块里的两个滚动变量走一遍 B：

| 处理 x | `prev`（新，即 `dp[i-2]`） | `cur`（新，即 `dp[i-1]`） | 说明 |
|---|---|---|---|
| 2 | 0 | `max(0, 0 + 2) = 2` | 偷第 2 个 |
| 3 | 2 | `max(2, 0 + 3) = 3` | 3 > 2，只偷第 3 个 |
| 4 | 3 | `max(3, 2 + 4) = 6` | 6 > 3，偷第 2、4 个 |

返回 6，与填表结果相同。

第二组样例 `nums = [1,3,6]`，环是 `1-3-6-1`（第 1 个和第 3 个相邻）：

- A（不偷第 3 个）：`[1,3]` → `dp[1] = 1`，`dp[2] = max(1, 0 + 3) = 3`，A = 3；
- B（不偷第 1 个）：`[3,6]` → `dp[1] = 3`，`dp[2] = max(3, 0 + 6) = 6`，B = 6；
- `max(3, 6) = 6`，只偷第 3 个房间，与样例一致。

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 线性 DP（数组） | O(n) | O(n) | 转移一眼可见，需要打印表或对拍时用 |
| 线性 DP（两个变量滚动）（最优） | O(n) | O(1) | 首个代码块；两个子数组各扫一遍，合计仍是 O(n) |

> 上面两行都指「已经拆好环之后」的线性部分。拆环本身只是两次切片（各 O(n)）和一次 `max`，
> 不改数量级。

## 易错点总结

1. **漏掉 `n == 1` 的特判**：删掉 `if n == 1: return nums[0]` 那两行之后，`nums[:-1]` 和 `nums[1:]`
   都退化成空数组，两次线性扫描都返回 0。输入 `[5]` 会输出 `0` 而不是 `5`。
2. **滚动赋值拆成两句**：写成 `prev = cur` 然后 `cur = max(cur, prev + x)`，`prev + x` 用的是刚更新的
   `prev`（即 `dp[i-1]`），等于允许连续偷相邻两家。`[1,2,3,4]` 会输出 `9`
   （`nums[1:] = [2,3,4]` 被算成 2+3+4）而不是 `6`。
3. **只保留一种拆分**：`return self._rob_line(nums[1:])` 少写 `nums[:-1]` 那一侧，
   `[10,1,1,1]` 输出 `2` 而不是 `11`。这个错在官方样例上看不出来 —— `[1,2,3,4]` 两侧都是 6。

## 扩展思考

- **不切片、给初值的等价写法**：偷第 0 个房间时，第 n-1 个被强制排除，于是把线性 DP 的
  `prev1` 初值设成 `nums[0]`、只往后处理 `nums[1 .. n-2]`；不偷第 0 个时正常处理 `nums[1:]`。
  两次结果取大，与切片版同解，省掉两次数组拷贝。
- 环被打断成一条链（给定某条边不能走）时，直接退化成 BM78 的线性问题。
- 「树上不能偷相邻节点」是同一个想法的升维：选择要传给父节点，用树形 DP。
