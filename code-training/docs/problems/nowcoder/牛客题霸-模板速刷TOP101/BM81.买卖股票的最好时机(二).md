# BM81. 买卖股票的最好时机(二)

## 题目描述

给定数组 prices，prices[i] 是某只股票第 i 天的价格。
你可以多次买卖该股票，但再次购买前必须卖出之前的股票（同一时刻最多持有一股）。
求最大收益；不能获取收益则返回 0。

## 输入格式

- `prices`：int 型一维数组，表示每一天的股票价格。

## 输出格式

返回 int 型，最大收益（不能获利则为 0）。

## 示例

### 示例 1

**输入：**
```
prices = [8,9,2,5,4,7,1]
```

**输出：**
```
7
```

**说明：**
第 1 天买第 2 天卖（+1）、第 3 天买第 4 天卖（+3）、
第 5 天买第 6 天卖（+3），合计 7。

### 示例 2

**输入：**
```
prices = [5,4,3,2,1]
```

**输出：**
```
0
```

**说明：**
价格持续下跌，不交易最优。

### 示例 3

**输入：**
```
prices = [1,2,3,4,5]
```

**输出：**
```
4
```

**说明：**
第 1 天买、最后一天卖，收益 4；中间当天买当天卖不影响结果。

---

## 解题思路

### 第一步：理解问题本质

可以交易任意多次，但同一时刻只能持有一股。
直觉上「逢低买入、逢高卖出」就能赚到每一段上涨。

### 第二步：为什么「逐日累加正差价」是对的

考虑从第 i 天持有到第 j 天卖出，收益是 `prices[j] - prices[i]`。
这个差值恰好等于这段时间里**所有相邻两天正差价之和**：

```
prices[j] - prices[i] = Σ (prices[k+1] - prices[k])
```

因此，只要我们把每对相邻两天的「正差价」全部累加，就不会漏掉任何利润；
负差价则直接跳过（相当于空仓观望）。这本质上把每一段上涨都完整拿下了。

### 第三步：贪心实现

```python
profit = 0
# 从第 2 天起逐日与前一天比，正好覆盖所有相邻差价
for i in range(1, n):
    # 今天比昨天高就拿下这段差价；今天更低则跳过，相当于空仓观望
    if prices[i] > prices[i - 1]:
        profit += prices[i] - prices[i - 1]
```

O(n) 时间、O(1) 空间。也可以理解为：
每天都可以「先卖出昨天的、再买入今天的」，所以只要今天比昨天高就赚差价。

---

## 完整代码实现

```python
from typing import List


class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        """多次交易：累加所有相邻正差价"""
        profit = 0
        for i in range(1, len(prices)):
            if prices[i] > prices[i - 1]:
                profit += prices[i] - prices[i - 1]
        return profit
```

## 示例推演

以 `prices = [8,9,2,5,4,7,1]` 为例，逐对比较相邻价格：

| 相邻对 | 差价 | 是否为正 | 累计收益 |
|--------|------|----------|----------|
| 8→9 | +1 | 是 | 1 |
| 9→2 | -7 | 否 | 1 |
| 2→5 | +3 | 是 | 4 |
| 5→4 | -1 | 否 | 4 |
| 4→7 | +3 | 是 | 7 |
| 7→1 | -6 | 否 | 7 |

最终收益 7，与答案一致。

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 贪心累加正差价 | O(n) | O(1) | 推荐 |

## 易错点总结

1. **把负差价也累加进去**：`ans += prices[i] - prices[i-1]` 不判断正负，遇到下跌日会把利润扣掉。必须写 `ans += max(0, prices[i] - prices[i-1])`。
2. **当成只允许一笔交易**：本题可以多次买卖，只求一段最大子段和会少赚。`[1,2,3,4,5]` 的正确收益是 4（每天买、第二天卖），只做一笔也是 4，但 `[1,5,2,6]` 会漏掉第二段。
3. **循环从 0 开始取 `prices[i-1]`**：`i = 0` 时 `prices[-1]` 会取到末尾元素，把首尾错误地连成一笔交易。差价循环必须从 `i = 1` 开始。
