# 22. 括号生成

## 题目描述

数字 `n` 代表生成括号的对数，请你设计一个函数，用于能够生成所有可能的并且**有效的**括号组合。答案可以按任意顺序返回。

**提示：**

- `1 <= n <= 8`

## 示例

### 示例 1

**输入：** n = 3

**输出：** ["((()))","(()())","(())()","()(())","()()()"]

### 示例 2

**输入：** n = 1

**输出：** ["()"]

## 解题思路

长度固定是 `2n`，逐位填括号即可。难点不在「填」，而在「什么时候允许填」：一个长度 `2n` 的括号串合法，当且仅当**任意前缀里左括号不少于右括号**，且最后左右各 `n` 个。把这两条写成两个 `if`，DFS 就只会走合法前缀，一步都不浪费。

### 合法前缀的两个条件

设已经放了 `left` 个左括号、`right` 个右括号：

- 还能放左括号，当且仅当 `left < n`（总数不能超）；
- 还能放右括号，当且仅当 `right < left`（当前前缀里右括号不能追上左括号）。

第二条是全部剪枝的来源。`())(` 这种串在第三个字符处就违反了它，而 DFS 根本不会走到那一步。

### 停止条件选 `right == n`

`right` 达到 `n` 时，由于全程都有 `right <= left <= n`，必然也有 `left == n`，`2n` 个位置刚好填满。所以终止条件写 `right == n` 就够，不需要再判断长度。

换成 `left == n` 会提前收工：左括号刚放完、右括号还没补齐的串也会被当作答案。

### 两个 `if` 必须并列

`left < n` 和 `right < left` 可以同时成立（比如 `n = 2` 的初始状态之后，`(0,0)` 只能放左，`(1,0)` 两条都成立）。写成 `if … elif …` 时，同一层只走一条分支，`()()` 这种「先关后开」的形态永远生成不出来。

代码里的两条分支各自 `append` / `pop`，恢复现场在递归返回之后立刻做：

```python
if left < n:
    path.append('(')
    dfs(left + 1, right)
    path.pop()              # 回到这一层，把刚才的左括号撤掉
if right < left:
    path.append(')')
    dfs(left, right + 1)
    path.pop()
```

### 推演：`n = 2` 的搜索树

`dfs(left, right)` 表示「已放 left 个左括号、right 个右括号」。

```
dfs(0,0)
├─ 放 '(' → dfs(1,0)
│  ├─ 放 '(' → dfs(2,0)          left 满了
│  │  └─ 放 ')' → dfs(2,1)
│  │     └─ 放 ')' → dfs(2,2)    收下 "(())"
│  └─ 放 ')' → dfs(1,1)
│     └─ 放 '(' → dfs(2,1)       left 还没满
│        └─ 放 ')' → dfs(2,2)    收下 "()()"
```

`dfs(2,0)` 处 `left == n`，不能再放左括号，只剩右括号一条路；`dfs(2,1)` 处同理。两条路径各产出一个答案，共 2 个，等于第 2 个卡特兰数。

## 完整代码实现

```python
from typing import List


class Solution:
    def generateParenthesis(self, n: int) -> List[str]:
        ans = []
        path = []

        def dfs(left: int, right: int) -> None:
            # right 到 n 时 left 必然也到 n，2n 个位置刚好填满
            if right == n:
                ans.append(''.join(path))
                return
            # 还能放左括号：总数没超过 n
            if left < n:
                path.append('(')
                dfs(left + 1, right)
                path.pop()
            # 还能放右括号：前缀里右括号还没追上左括号
            if right < left:
                path.append(')')
                dfs(left, right + 1)
                path.pop()

        dfs(0, 0)
        return ans
```

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| --- | --- | --- | --- |
| 枚举全部 `2n` 位再逐串校验 | O(2^(2n) · n) | O(n) | 绝大多数串在第一个非法前缀处就该被丢掉 |
| 回溯 + 前缀剪枝（最优） | O(C_n · n) | O(n) | 只访问合法前缀，C_n 是第 n 个卡特兰数，每个答案拼一次串 |

## 易错点总结

### 1. 终止条件写成 `left == n`

左括号一放完就 `append`，示例 2 会输出 `["((", "()("]` 这种长度不足 `2n` 的残串；示例 1 的 5 个答案也全部变成短串。正确写法是等 `right == n`，那时左右都齐了。

### 2. 两个 `if` 合并成 `if / elif`

`right < left` 那一条被 `elif` 挡在门外时，每个状态最多只有一条出路。示例 2 只会输出 `["(())"]`，示例 1 只会输出 `["((()))"]`，各少了「先关后开」的那一半。

### 3. 只 `append` 不 `pop`

少了 `path.pop()` 之后，列表只增不减，后面的答案会带着前面路径的残留：示例 2 的第二个答案是 `"(()))()"` 这种 7 个字符的串。定长数组下标写入的写法没有这个问题，用 `append` 就必须配对 `pop`。

## 扩展思考

- 合法组合的个数就是卡特兰数 `C_n = C(2n,n)/(n+1)`：每个前缀都满足「左不少于右」，等价于一条不能穿过对角线的格路。
- 也可以按「第一对括号包住了多少对」做区间 DP：`n` 对括号的答案由 `i` 对括号放在最外层、剩下 `n-1-i` 对接在后面拼成，`dp[n] = Σ dp[i] × dp[n-1-i]`。它和回溯枚举的是同一批串，只是顺序不同。
