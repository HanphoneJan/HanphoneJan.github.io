# 448. 找到所有数组中消失的数字

## 题目描述

给你一个含 `n` 个整数的数组 `nums`，其中 `nums[i]` 在区间 `[1, n]` 内。请你找出所有在 `[1, n]` 范围内但没有出现在 `nums` 中的数字，并以数组的形式返回结果。

## 示例

**示例 1：**
```
输入：nums = [4,3,2,7,8,2,3,1]
输出：[5,6]
```

**示例 2：**
```
输入：nums = [1,1]
输出：[2]
```

---

## 解题思路

### 值域就是下标：数组本身就能当哈希表

数组有 `n` 格，每个值又恰好落在 `[1, n]` 里。所以每个值 `v` 都对应唯一一个合法下标 `v - 1`，「`v` 出现过」这条信息可以直接写在下标 `v - 1` 的格子上，不必另开一张表。这就是「原地哈希」的来源：它不是技巧，而是值域与下标范围重合带来的机会。

要落地只剩两个问题：**往格子里写什么**（标记），以及**怎么从被写过的格子里读回下标**（还原）。两个问题各有几种答案，写法的差别都在这里。

### 方法一：哈希集合

```python
from typing import List

class Solution:
    def findDisappearedNumbers(self, nums: List[int]) -> List[int]:
        seen = set(nums)
        return [v for v in range(1, len(nums) + 1) if v not in seen]
```

两行有效代码，几乎不会写错，也不碰输入数组。代价是要 n 个格子的 set，题目额外要求常数空间时不能交。

### 方法二：取负做标记

用正负号当标记位：出现过就把它对应的格子取负。

```python
from typing import List

class Solution:
    def findDisappearedNumbers(self, nums: List[int]) -> List[int]:
        for v in nums:
            i = abs(v) - 1            # 标记过的格子是负的，先还原成下标
            if nums[i] > 0:           # 已经标记过就不再取负
                nums[i] = -nums[i]
        return [i + 1 for i, v in enumerate(nums) if v > 0]
```

`abs` 不能省：循环往后走时会读到前面已经取负的格子，`abs(-3) - 1` 才是下标 `2`，直接用 `-3 - 1` 得到的是 Python 的负下标，会悄悄改到别的格子上。`if nums[i] > 0` 也不能省：同一个数字出现两次时，第二次再取负会把标记抹掉，那个位置又变回正数。判定「没出现过」就是格子还是正数。

### 方法三：加 `n` 做标记

原值都在 `[1, n]`，统一加一个 `n` 之后必然大于 `n`；而 `(v - 1) % n` 与 `v - 1` 在模 `n` 下相同，所以从加过 `n` 的值里也能还原出下标。这样一来既不需要负数，也不需要 `abs`：

- `x = (num - 1) % n`：`num` 可能已经被加过 `n` 的若干倍，取模把倍数抹掉，剩下的正是原来的 `v - 1`；
- `nums[x] += n`：标记；
- 最后 `num <= n` 的格子就是没被标记过的，对应的数字 `i + 1` 没出现过。

这里有一处必须讲清楚：`for num in nums` 遍历的正是它自己修改的那个列表，后面的循环完全可能读到已经加过 `n` 的值。示例 1 的第 3 次循环读到的 `num` 就是 10（而不是原来的 2），`% n` 正是为这件事准备的。

```python
from typing import List

class Solution:
    def findDisappearedNumbers(self, nums: List[int]) -> List[int]:
        n = len(nums)
        for num in nums:
            nums[(num - 1) % n] += n      # 加 n 当标记；取模能还原下标
        return [i + 1 for i, v in enumerate(nums) if v <= n]
```

三种写法都是 `O(n)` 时间；集合版要 `O(n)` 额外空间，取负版与加 `n` 版都是 `O(1)` 额外空间但会改动输入。加 `n` 版比取负版少一次 `abs`、少一次正负判断，代价是要有一个统一的上界 `n` 才能取模。

## 完整代码实现

```python
from typing import List


class Solution:
    """
    找到所有数组中消失的数字 - 原地哈希

    将出现过的数字对应位置的值增加 n
    值仍 <= n 的位置就是没出现过的数字

    时间复杂度：O(n)
    空间复杂度：O(1)（不计输出空间）
    """

    def findDisappearedNumbers(self, nums: List[int]) -> List[int]:
        n = len(nums)
        for num in nums:
            x = (num - 1) % n  # 计算该数字对应的索引
            nums[x] += n         # 标记该数字出现过

        # 值仍 <= n 的位置，说明对应的数字(i+1)没有出现过
        return [i + 1 for i, num in enumerate(nums) if num <= n]
```

## 示例推演

以 `nums = [4,3,2,7,8,2,3,1]` 为例，`n = 8`。注意第三列是**实际读到**的值，它可能已经被前面的步骤加过 8：

| 轮次 | 读到的 `num` | `x = (num-1) % 8` | 操作 | `nums` 状态 |
|---|---|---|---|---|
| 初始 | — | — | — | `[4, 3, 2, 7, 8, 2, 3, 1]` |
| 1 | 4 | 3 | `nums[3] += 8` | `[4, 3, 2, 15, 8, 2, 3, 1]` |
| 2 | 3 | 2 | `nums[2] += 8` | `[4, 3, 10, 15, 8, 2, 3, 1]` |
| 3 | **10** | 1 | `nums[1] += 8` | `[4, 11, 10, 15, 8, 2, 3, 1]` |
| 4 | **15** | 6 | `nums[6] += 8` | `[4, 11, 10, 15, 8, 2, 11, 1]` |
| 5 | 8 | 7 | `nums[7] += 8` | `[4, 11, 10, 15, 8, 2, 11, 9]` |
| 6 | 2 | 1 | `nums[1] += 8` | `[4, 19, 10, 15, 8, 2, 11, 9]` |
| 7 | **11** | 2 | `nums[2] += 8` | `[4, 19, 18, 15, 8, 2, 11, 9]` |
| 8 | **9** | 0 | `nums[0] += 8` | `[12, 19, 18, 15, 8, 2, 11, 9]` |

第 3、4、7、8 轮读到的都是被标记过的值（10、15、11、9）。它们减 1 再对 8 取模，分别还原出下标 1、6、2、0 —— 正是这几个数字原本所在的位置。

最后扫描一遍，仍然 `<= 8` 的格子是下标 4（值 8）和下标 5（值 2），对应数字 **5** 和 **6**，与示例一致。

再验一个会被标记值「回读」影响的短例子：`nums = [2,2]`、`n = 2`。

| 轮次 | 读到的 `num` | `x` | 操作 | `nums` |
|---|---|---|---|---|
| 1 | 2 | 1 | `nums[1] += 2` | `[2, 4]` |
| 2 | **4** | `(4-1) % 2 = 1` | `nums[1] += 2` | `[2, 6]` |

下标 0 的值仍是 2，下标 1 已经大于 2，所以答案是 `[1]`。

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 哈希集合 | O(n) | O(n) | 需要一张 set |
| 取负标记 | O(n) | O(1) | 负数表示已出现，还原下标要 `abs` |
| 加 n 标记（最优） | O(n) | O(1) | 用 `% n` 还原下标，不需要 `abs` |

> 两种原地写法都是两趟扫描；`O(1)` 不计返回的列表。

---

## 易错点总结

1. **`x = (num - 1) % n` 里省掉 `% n`，直接写 `nums[num - 1] += n`**：后面读到被标记过的值时 `num` 会大于 `n`，下标越界。示例 1 第 3 轮读到的 `num` 是 10，`nums[9]` 直接抛 `IndexError: list index out of range`。
2. **取负版漏掉 `abs(v)`**：读到的 `v` 可能是负数，`v - 1` 变成负下标，Python 会从末尾倒着数，静默改到别的格子上。`nums = [2,2]` 时读到 `-2`，`nums[-3]` 直接 `IndexError`；示例 1 则返回 `[2, 5]`（正确 `[5, 6]`）。
3. **判定条件写成 `num < n`**：没被标记的格子保留原值，而原值可以正好等于 `n`，用严格小于会把它误判成「已出现」。示例 1 会返回 `[6]`，漏掉数字 5。
