# 20. 有效的括号

## 题目描述

给定一个只包括 `'('`、`')'`、`'{'`、`'}'`、`'['`、`']'` 的字符串 `s`，判断字符串是否有效。

有效字符串需满足：

1. 左括号必须用相同类型的右括号闭合；
2. 左括号必须以正确的顺序闭合；
3. 每个右括号都有一个对应的相同类型的左括号。

**提示：**

- `1 <= s.length <= 10^4`
- `s` 仅由括号 `'()[]{}'` 组成

## 示例

### 示例 1

**输入：** s = "()"

**输出：** true

### 示例 2

**输入：** s = "()[]{}"

**输出：** true

### 示例 3

**输入：** s = "(]"

**输出：** false

### 示例 4

**输入：** s = "([])"

**输出：** true

## 解题思路

「括号必须按正确顺序闭合」翻译成栈的语言就是一句话：**每个右括号必须和最近一个还没闭合的左括号配对**。那个「最近的」就是栈顶，所以左括号入栈、右括号检查栈顶，一次扫描就能判定。

### 左括号入栈，右括号查栈顶

扫描字符串：

- 遇到左括号，入栈——它成了「最近的未闭合括号」；
- 遇到右括号，看栈顶是不是它对应的左括号：是就弹出（这一对闭合了），不是（或者栈已经空了）就立刻返回 `false`。

```python
pairs = {')': '(', ']': '[', '}': '{'}
stack = []
for ch in s:
    if ch in pairs:
        if not stack or stack[-1] != pairs[ch]:
            return False
        stack.pop()
    else:
        stack.append(ch)
```

`not stack or stack[-1] != pairs[ch]` 里 `not stack` 必须写在前面：栈空时 `stack[-1]` 会抛 `IndexError`，靠 `or` 的短路把这一步挡掉。

### 结尾要确认栈空

扫描完只说明「没有配错」，还得说明「没有剩下的」。`"((("` 一路入栈、从不弹出，结束时栈里还有三个左括号，必须返回 `false`。所以最后是 `return not stack`，而不是 `return True`。

### 推演：示例 4

`s = "([])"`。

| 步骤 | 字符 | 动作 | 栈（底 → 顶） |
| --- | --- | --- | --- |
| 1 | `(` | 左括号，入栈 | `(` |
| 2 | `[` | 左括号，入栈 | `( [` |
| 3 | `]` | 栈顶 `[` 与它配对，弹出 | `(` |
| 4 | `)` | 栈顶 `(` 与它配对，弹出 | 空 |

结束时栈空，返回 `true`。

示例 3 `"(]"` 在第 2 步就停：栈顶是 `(`，而 `]` 要的是 `[`，直接返回 `false`——数量和类型都对不上，光数括号个数是看不出来的。

## 完整代码实现

```python
class Solution:
    def isValid(self, s: str) -> bool:
        pairs = {')': '(', ']': '[', '}': '{'}
        stack = []
        for ch in s:
            if ch in pairs:
                # 栈空说明这个右括号没有左括号可配；栈顶不是同类型也不行
                if not stack or stack[-1] != pairs[ch]:
                    return False
                stack.pop()
            else:
                stack.append(ch)
        return not stack        # 还有没闭合的左括号 -> 无效
```

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| --- | --- | --- | --- |
| 反复删掉 `"()"`、`"[]"`、`"{}"` | O(n²) | O(n) | 每轮 `replace` 重建字符串，最坏要做 n/2 轮 |
| 栈（最优） | O(n) | O(n) | 每个字符进栈、出栈各至多一次；全左括号时栈深 n |

## 易错点总结

### 1. 只数左右括号的个数

统计三种括号的数量各自相等就返回 `true`，`"([)]"` 会通过（三种括号都是一左一右，数量相等），而正确答案是 `false`——`(` 还没有闭合，`]` 就先出现了。数量相等只保证「总数对得上」，不保证「类型和顺序对得上」。

### 2. 结尾 `return True` 而不是 `return not stack`

少了这一步，`"((("` 这种从头到尾没弹出过的输入会返回 `true`。遍历过程中没有配错，不代表没有剩下的左括号，最后必须检查栈是否为空。

## 扩展思考

- 只有一种括号时不需要栈，用一个计数器就够：左括号 +1、右括号 −1，中途为负或结尾不为 0 就无效。多种括号必须记住类型，才需要栈。
- 问「最长有效括号子串」时是 [32. 最长有效括号](https://leetcode.cn/problems/longest-valid-parentheses/)，栈里存下标而不是字符。
