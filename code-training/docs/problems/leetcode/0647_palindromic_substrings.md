# 647. 回文子串

## 题目描述

给定字符串 `s`，统计其中回文子串的数目。位置不同但内容相同的子串分别计数。

## 示例

### 示例 1

**输入：** s = "abc"
**输出：** 3
**解释：** 回文子串是 `"a"`、`"b"`、`"c"`。

### 示例 2

**输入：** s = "aaa"
**输出：** 6
**解释：** `"a"` 三次、`"aa"` 两次、`"aaa"` 一次。

## 解题思路

### 路线：一个回文由它的中心唯一确定

回文左右对称，所以只要盯住中心往两边扩，扩到不相等就停。中心有两类：

- 奇数长度回文以某个字符为中心，共 `n` 个；
- 偶数长度回文以两个字符之间的缝隙为中心，共 `n-1` 个。

合起来 `2n-1` 个中心。每个中心能扩出几层，就贡献几个回文子串。中心扩展是 `O(n²)`；Manacher 用「已经算过的回文区间」给每个中心一个起步半径，把它压到 `O(n)`。

### 手法一：枚举 2n-1 个中心，逐层外扩

把第 `i` 个中心统一成一对左右指针：

- `i` 为偶数时是字符中心：`l = r = i / 2`；
- `i` 为奇数时是缝隙中心：`l = (i-1)/2`、`r = (i+1)/2`。

两种写法可以合成 `l = i // 2`、`r = (i + 1) // 2`：

```python
ans = 0
for i in range(2 * n - 1):
    l, r = i // 2, (i + 1) // 2
    while l >= 0 and r < n and s[l] == s[r]:
        ans += 1          # 这一层是回文
        l -= 1
        r += 1
```

`i = 2k` 时 `l = r = k`，从单字符开始；`i = 2k+1` 时 `l = k, r = k+1`，从缝隙开始。每成功外扩一层，就多一个更长的回文，所以循环体里直接 `ans += 1`。

### 手法二：Manacher，把半径的起点抬高

把字符串改造成 `^#a#b#c#$` 这样带分隔符的形式，所有回文都变成奇回文，中心落在一个确定的下标上。记 `half[i]` 为改造串里以 `i` 为中心的回文半径（含中心），它和原串回文数量的关系是：

> 每个中心贡献 `half[i] // 2` 个回文子串。

原因：分隔符把「一个字符」和「两个字符之间」都变成了中心；半径每多 1，原串里就多一层回文，而分隔符那一层不算新回文。

维护当前已探明的最右回文盒 `[box_m - box_r, box_m + box_r)`。若 `i` 落在盒内，它的镜像 `2*box_m - i` 已经算过，可以直接把半径起步值抬到 `min(half[mirror], box_r - i)`；只有超出盒子的部分才需要真正比较：

```python
t = "#".join("^" + s + "$")
half = [0] * (len(t) - 2)
half[1] = 1
ans = box_m = box_r = 0

for i in range(2, len(half)):
    hl = 1
    if i < box_r:
        hl = min(half[box_m * 2 - i], box_r - i)
    while t[i - hl] == t[i + hl]:
        hl += 1
        box_m, box_r = i, i + hl
    half[i] = hl
    ans += hl // 2
```

`^` 与 `$` 是哨兵，保证外扩循环一定会在边界停下，不必额外判越界。

### 推演：`s = "aaa"`

改造串为 `^#a#a#a#$`，只看产生贡献的中心：

| 中心 | 字符 | 半径 `half[i]` | 贡献 `half[i] // 2` | 对应原串回文 |
| --- | --- | --- | --- | --- |
| 2 | `a` | 2 | 1 | 第一个 `"a"` |
| 3 | `#` | 3 | 1 | 第一个 `"aa"` |
| 4 | `a` | 4 | 2 | 中间的 `"a"` 与 `"aaa"` |
| 5 | `#` | 3 | 1 | 第二个 `"aa"` |
| 6 | `a` | 2 | 1 | 最后一个 `"a"` |

合计 `1+1+2+1+1 = 6`。`s = "abc"` 时五个能扩的中心半径都是 2，各贡献 1，另两个缝隙中心半径为 1、贡献 0，合计 3。

## 完整代码实现

```python
class Solution:
    def countSubstrings(self, s: str) -> int:
        # 改造串：^ 与 $ 是哨兵，# 把字符中心与缝隙中心都变成奇回文中心
        t = "#".join("^" + s + "$")
        n = len(t)

        half = [0] * (n - 2)      # 只存真正中心（去掉两个哨兵）
        half[1] = 1
        ans = 0
        box_m = box_r = 0         # 当前最右回文盒的中心与右边界（开区间）

        for i in range(2, len(half)):
            hl = 1
            if i < box_r:
                # 盒内：镜像半径与「到盒右边界」取较小者作为起步
                hl = min(half[box_m * 2 - i], box_r - i)

            # 只有超出盒子的部分需要真正比较
            while t[i - hl] == t[i + hl]:
                hl += 1
                box_m, box_r = i, i + hl

            half[i] = hl
            ans += hl // 2        # 半径每多 1，原串多一层回文

        return ans
```

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| --- | --- | --- | --- |
| 中心扩展（最优） | O(n²) | O(1) | 2n-1 个中心，最坏每个扩 O(n)；实现最短 |
| Manacher | O(n) | O(n) | 每个中心只比较盒子外的新字符，总扩展量线性 |
| 二维 DP 判回文 | O(n²) | O(n²) | `pal[i][j]` 依赖 `pal[i+1][j-1]`，适合顺手做 132 题 |

本题 `n ≤ 1000`，中心扩展约 `5×10^5` 次比较，完全够用；Manacher 的收益要到 `n` 很大时才显现。

## 易错点总结

### 1. 只枚举 n 个字符中心

`for i in range(n)` 只数奇数长度回文，所有偶数长度回文都会漏掉。`s = "abba"` 的正确回文是 `a`、`b`、`b`、`a`、`bb`、`abba` 共 6 个，只枚举字符中心得到 4 个。中心数必须是 `2n-1`。

### 2. 中心扩展的右指针写成 `r = i // 2`

`l, r = i // 2, i // 2` 让两类中心都退化成单字符中心，等同于只枚举奇数回文。`"abba"` 同样会少掉 `"bb"` 与 `"abba"`，返回 4 而不是 6。

### 3. Manacher 里写成 `ans += hl`

`hl` 是改造串里的半径，其中一半是分隔符 `#`，只有 `hl // 2` 对应原串的回文层数。写成 `ans += hl` 会把分隔符也算成回文，`"abc"` 返回 8 而不是 3。

## 扩展思考

- **最长回文子串**（5 题）：同一套中心扩展，把 `ans += 1` 换成记录最大长度与起点即可。
- **分割回文串**（131 题）：需要的是「任意子串是否回文」的布尔表，中心扩展或 Manacher 都能在 `O(n²)` / `O(n)` 内先把表填出来。
- **回文子序列**与子串不同：子序列不要求连续，状态是 `dp[i][j]` 而不是中心。
