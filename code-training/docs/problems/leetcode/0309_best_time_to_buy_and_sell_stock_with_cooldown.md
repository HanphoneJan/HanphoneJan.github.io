# 309. 买卖股票的最佳时机含冷冻期

## 题目描述

给定一个整数数组 `prices`，其中 `prices[i]` 表示第 `i` 天的股票价格。

设计一个算法计算出最大利润。在满足以下约束条件下，你可以尽可能地完成更多的交易（多次买卖一支股票）：

- 卖出股票后，你无法在第二天买入股票（即冷冻期为 1 天）。

注意：你不能同时参与多笔交易（你必须在再次购买前出售掉之前的股票）。

**提示：**

- `1 <= prices.length <= 5000`
- `0 <= prices[i] <= 1000`

## 示例

### 示例 1

**输入：** prices = [1,2,3,0,2]

**输出：** 3

**解释：** 对应的交易状态为 `[买入, 卖出, 冷冻期, 买入, 卖出]`。

### 示例 2

**输入：** prices = [1]

**输出：** 0

## 解题思路

每天收盘时，手里要么拿着股票、要么空仓，这两种处境下能拿到的最大利润互不相同，所以状态只有两个。冷冻期不增加第三种状态——它只挡住「买入」这一个动作：今天买入，要求前天收盘时是空仓（昨天卖出的话今天就还在冷冻）。于是三个变量足够跑完全程。

### 两个状态，两个转移

设：

- `f0`：今天收盘时不持有股票的最大利润；
- `f1`：今天收盘时持有股票的最大利润；
- `pre0`：**前天**收盘时不持有股票的最大利润。

今天收盘不持股，只有两种来路：昨天就不持股（`f0`），或者今天把股票卖了（`f1 + p`）。今天收盘持股，也只有两种：昨天就持股，或者今天买入（`pre0 - p`）。

```python
f0 = max(f0, f1 + p)      # 不持有：昨天不持有，或今天卖出
f1 = max(f1, pre0 - p)    # 持有：昨天持有，或今天买入（前天必须空仓）
```

买入用 `pre0` 而不是 `f0`，就是全部冷冻期约束所在：`f0` 包含「昨天刚卖掉」的情况，拿它去买等于卖出次日就买回，违反题目。

### 三个变量怎么滚动

`f0`、`f1` 是「今天」的，`pre0` 是「前天」的。每轮结束时整体右移一天：今天的 `f0` 变成下一轮的 `pre0`，`pre0` 退场。三件事必须在同一时刻完成，所以写成一行元组赋值：

```python
pre0, f0, f1 = f0, max(f0, f1 + p), max(f1, pre0 - p)
```

等号右边用的全是更新前的值。拆成三条语句时，若先算 `f0` 再算 `f1`，`f1` 里的 `f0` 已经是今天的了——和「买入用 `pre0`」是同一个错误，只是换了个位置犯。

起点是第一天之前：`pre0 = f0 = 0`（空仓、没赚没亏），`f1 = -inf`（还没买，不可能持股）。这个 `-inf` 不能省：初值写成 0 等于允许「手里没股票也能卖出」，见「易错点」。

### 推演：示例 1 逐日走一遍

| 天 | 价格 | 进入时 `pre0 / f0 / f1` | 更新后 `f0` | 更新后 `f1` |
| --- | --- | --- | --- | --- |
| 0 | 1 | 0 / 0 / −∞ | 0 | −1 |
| 1 | 2 | 0 / 0 / −1 | 1 | −1 |
| 2 | 3 | 0 / 1 / −1 | 2 | −1 |
| 3 | 0 | 1 / 2 / −1 | 2 | 1 |
| 4 | 2 | 2 / 2 / 1 | 3 | 0 |

读第 3 天：进入时 `f0 = 2`（前三天最多赚 2），价格 0 元；`pre0 = 1` 是第 1 天收盘的利润（那天卖出赚了 1），第 2 天正好是冷冻期，所以第 3 天买入的来路正是 `pre0 - 0 = 1`，`f1` 从 −1 抬到 1。第 4 天卖出：`f1 + 2 = 3`，答案 3。

## 完整代码实现

```python
from math import inf
from typing import List


class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        # pre0: 前天收盘不持股的利润；f0: 今天收盘不持股；f1: 今天收盘持股
        pre0, f0, f1 = 0, 0, -inf
        for p in prices:
            # 买入只能从「前天不持股」来，这一项就是冷冻期
            pre0, f0, f1 = f0, max(f0, f1 + p), max(f1, pre0 - p)
        return f0
```

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| --- | --- | --- | --- |
| 记忆化搜索 `dfs(i, hold)` | O(n) | O(n) | 状态 `(天, 是否持股)` 共 2n 个，递归栈与缓存同阶 |
| 三变量滚动（最优） | O(n) | O(1) | 每天只做两次比较、三次赋值 |

## 易错点总结

### 1. 买入写成从「昨天不持股」转移

`pre0 - p` 写成 `f0 - p`，等于允许卖出后第二天立刻买回，冷冻期整条规则失效。示例 1 会输出 4（`1→2→3` 赚 2，再 `0→2` 赚 2），正确答案是 3。只有一天的示例 2 看不出区别，所以这个错误在样例上不会暴露。

### 2. `f1` 初始值写成 0

`f1 = -inf` 是「还没买过，不可能持有」。改成 `f1 = 0` 后，程序允许在第 1 天就以 0 元成本「卖出」，示例 1 输出 4、示例 2 输出 1（正确答案 0）——空仓的股票被白卖了一次。

## 扩展思考

- 冷冻期从 1 天变成 `k` 天，买入要看的就不是「前天」，而是「`k + 1` 天前」的空仓值；把 `pre0` 换成一个长度为 `k + 1` 的队列即可，转移式不变。
- 不限交易次数但不含冷冻期时（[122. 买卖股票的最佳时机 II](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-ii/)），买入用 `f0 - p` 就对了——两题只差这一个下标。
