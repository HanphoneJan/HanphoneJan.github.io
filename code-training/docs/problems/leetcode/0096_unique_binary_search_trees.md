# 96. 不同的二叉搜索树

## 题目描述

给你一个整数 `n`，求恰由 `n` 个节点组成且节点值从 `1` 到 `n` 互不相同的 **二叉搜索树** 有多少种？返回满足题意的二叉搜索树的种数。

## 示例

**示例 1：**
```
输入：n = 3
输出：5
```

**示例 2：**
```
输入：n = 1
输出：1
```

---

## 解题思路

### 先确认一件事：答案只跟节点个数有关

二叉搜索树的中序遍历是递增的。反过来，一棵形状确定的二叉树，把 `1..n` 按中序依次填进去，每个位置上该放哪个值就唯一确定了，而且填出来一定是合法的 BST。

所以「`1..n` 能组成多少种 BST」和「`n` 个节点的二叉树里，有多少种形状」是同一个问题——值具体是多少完全不影响计数。这是能把答案写成一元函数 `G(n)` 的前提；如果值会影响结果，状态就得多带一维。

### 选定根之后，左右两边毫无关系

根取 `i`（`1 ≤ i ≤ n`）：

- 左子树只能用 `{1, ..., i-1}`，共 `i-1` 个节点；
- 右子树只能用 `{i+1, ..., n}`，共 `n-i` 个节点。

BST 的性质保证左子树的任何形状配上右子树的任何形状都合法：左边的值全小于根、右边的值全大于根，这一条与形状无关。于是两边互相独立，用乘法原理：

```text
G(n) = Σ(i = 1..n) G(i-1) · G(n-i)
G(0) = 1        # 空树也算一种，否则所有乘积都是 0
G(1) = 1
```

这里 `G(0) = 1` 不是形式上的凑数：`i = 1` 时右子树是 `G(n-1)`、左子树是 `G(0)`，如果空树算 0 种，那么「根是最小值」这一整类树就凭空消失了，`n = 2` 会算成 1 而不是 2。

### 方法一：把定义直接翻译成递归

```python
class Solution:
    def numTrees(self, n: int) -> int:
        if n <= 1:
            return 1
        return sum(self.numTrees(i - 1) * self.numTrees(n - i)
                   for i in range(1, n + 1))
```

递归式和上面的定义一字不差，但它把同一个 `G(k)` 反复展开。`G(2)` 在算 `G(3)` 时被展开 2 次、算 `G(4)` 时 6 次、算 `G(5)` 时 18 次——重复次数自己就按 3 倍增长。总调用次数 `T(n) = 5 × 3^(n-2)`，`n = 19` 时约 `6.5 × 10⁸`。本题 `1 ≤ n ≤ 19`，这个量级跑不完。

### 方法二：自底向上填表

`G(i)` 只依赖比 `i` 小的值，那就从小到大把整张表填出来：

```python
class Solution:
    def numTrees(self, n: int) -> int:
        G = [1] * (n + 1)                  # G[0] 与 G[1] 都是 1：空树 / 单节点各一种
        for i in range(2, n + 1):          # 从 2 开始，保证 G[i] 用到的值都已算好
            G[i] = sum(G[j - 1] * G[i - j] for j in range(1, i + 1))   # j 就是根的位置
        return G[n]
```

三行各自承担一个决策：`G = [1] * (n + 1)` 一次性定下 `G(0) = G(1) = 1`（空树这条边界）；外层从 `2` 开始，是因为 `G(0)`、`G(1)` 就是初值，再算一遍只会把 `G[1]` 覆盖成 `G[0] * G[0]`；内层 `j` 是根取第几个值，`G[j-1]` 与 `G[i-j]` 分别是左边、右边的种数。

时间 `O(n²)`，空间 `O(n)`。它还有个递归和公式都没有的好处：想加约束（比如「高度不超过 h 的 BST 有多少种」）时，只需要把 `G` 扩成 `G[i][h]` 再加一层循环，递推框架不用动。

### 方法三：通项公式

这串数是卡特兰数，有闭式解：

```text
G(n) = C(2n, n) / (n + 1)
```

为什么是它：把 BST 的先序遍历写成括号串——进入一个节点写左括号，离开写右括号，`n` 个节点就得到 `n` 对括号组成的平衡序列（任意前缀里左括号不少于右括号），而且这个括号串能反过来唯一还原出树。于是「BST 形状数」= 「`n` 对括号的平衡序列数」= 第 `n` 个卡特兰数。

```python
from math import comb

class Solution:
    def numTrees(self, n: int) -> int:
        # C(2n, n) 一定能被 n+1 整除，所以这里用整数除法
        return comb(2 * n, n) // (n + 1)
```

一行出答案，`O(n)` 次大整数运算、`O(1)` 额外空间。代价是它只回答「有多少个」：要输出这些树（95 题）就得回到构造；带额外约束的变体也用不上闭式解。所以公式适合当结论记，递推才是能改的那一版。

## 完整代码实现

下面是可提交的完整版本，与方法二同构（`G` 先用 0 占位再补两个 1，内层用 `+=` 累加）。

```python
class Solution:
    """
    不同的二叉搜索树 - 动态规划（卡特兰数）

    G(n) = sum(G(i-1) * G(n-i)) for i in 1..n

    时间复杂度：O(n²)
    空间复杂度：O(n)
    """

    def numTrees(self, n: int) -> int:
        G = [0] * (n + 1)
        G[0], G[1] = 1, 1

        for i in range(2, n + 1):
            for j in range(1, i + 1):
                G[i] += G[j - 1] * G[i - j]

        return G[n]
```

## 示例推演

以 `n = 3` 为例，按 `G[2]`、`G[3]` 的顺序填表。

`G[0] = 1`、`G[1] = 1` 是初值。

**`i = 2`**：根可以取 1 或 2。

| 根 `j` | 左子树节点数 `j-1` | 右子树节点数 `2-j` | 乘积 |
|---|---|---|---|
| 1 | 0 | 1 | `G[0] × G[1] = 1 × 1 = 1` |
| 2 | 1 | 0 | `G[1] × G[0] = 1 × 1 = 1` |

`G[2] = 1 + 1 = 2`。

**`i = 3`**：根可以取 1、2、3。

| 根 `j` | 左子树 | 右子树 | 乘积 |
|---|---|---|---|
| 1 | `G[0] = 1` | `G[2] = 2` | 2 |
| 2 | `G[1] = 1` | `G[1] = 1` | 1 |
| 3 | `G[2] = 2` | `G[0] = 1` | 2 |

`G[3] = 2 + 1 + 2 = 5`，与示例一致。这 5 棵树分别是：

- 根为 1：右子树有两种——`1 → 2 → 3` 全右链，以及 `1` 的右孩子是 `3`、`3` 的左孩子是 `2`；
- 根为 2：`2` 的左孩子 `1`、右孩子 `3`；
- 根为 3：左子树有两种——`3 → 2 → 1` 全左链，以及 `3` 的左孩子是 `1`、`1` 的右孩子是 `2`。

用公式核对：`C(6, 3) / 4 = 20 / 4 = 5`。

顺带看几个值验证递推表：`G(0..6) = 1, 1, 2, 5, 14, 42, 132`。`G(19) = 1767263190`，是最后一个还能放进 32 位有符号整数的卡特兰数（`G(20) = 6564120420` 就超了）。

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 定义递归（无记忆） | O(3^n) | O(n) | 总调用次数 `5 × 3^(n-2)`，`G(k)` 被反复展开 |
| 递推填表 | O(n²) | O(n) | 内层枚举根的位置，加约束时最容易扩展 |
| 通项公式（最优） | O(n) | O(1) | `O(n)` 次大整数乘法，需要知道卡特兰数 |

## 易错点总结

1. **空树被算成 0 种**：`G[0], G[1] = 1, 1` 里第一个 1 改成 0，所有乘积都会带一个 0。`n = 2` 返回 0、`n = 3` 返回 1（正确答案是 2 和 5）。空树必须算 1 种。
2. **内层写成 `range(1, i)`**：漏掉 `j = i` 这一项，也就是「根取最大值、右子树为空」的那一类。`n = 2` 返回 1（应为 2），`n = 3` 返回 2（应为 5）。
