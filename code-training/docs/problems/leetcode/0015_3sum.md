# 15. 三数之和

## 题目描述

给你一个整数数组 `nums`，判断是否存在三元组 `[nums[i], nums[j], nums[k]]` 满足 `i != j`、`i != k` 且 `j != k`，同时还满足 `nums[i] + nums[j] + nums[k] == 0`。

请你返回所有和为 0 且**不重复**的三元组。

注意：答案中不可以包含重复的三元组。

**提示：**

- `3 <= nums.length <= 3000`
- `-10^5 <= nums[i] <= 10^5`

## 示例

### 示例 1

**输入：** nums = [-1,0,1,2,-1,-4]

**输出：** [[-1,-1,2],[-1,0,1]]

**解释：** 不同的三元组是 `[-1,0,1]` 和 `[-1,-1,2]`。注意输出的顺序和三元组的顺序并不重要。

### 示例 2

**输入：** nums = [0,1,1]

**输出：** []

**解释：** 唯一可能的三元组和不为 0。

### 示例 3

**输入：** nums = [0,0,0]

**输出：** [[0,0,0]]

**解释：** 唯一可能的三元组和为 0。

## 解题思路

三数之和拆成两层：排序后固定第一个数 `nums[i]`，剩下的问题就是「在 `i` 右边找两个数和为 `-nums[i]`」，这是标准的双指针。排序同时解决三件事——双指针要求有序、重复的三元组会挨在一起方便跳过、`nums[i] > 0` 时可以提前结束。

### 排序后固定第一个数

`nums[i]` 固定后，目标变成两数之和 `target = -nums[i]`。左右指针从 `i+1` 和 `n-1` 出发：

- 当前和小于 0：只有把左指针右移（让较小的数变大）才有机会；
- 当前和大于 0：只有把右指针左移（让较大的数变小）才有机会；
- 等于 0：收下这组，左右各走一步继续找。

```python
l, r = i + 1, n - 1
while l < r:
    s = nums[i] + nums[l] + nums[r]
    if s == 0:
        ans.append([nums[i], nums[l], nums[r]])
        l += 1
        r -= 1
    elif s < 0:
        l += 1
    else:
        r -= 1
```

`l < r` 而不是 `l <= r`：两个指针落在同一个下标上，等于同一个元素被用了两次，不合法。

### 三处去重

重复的三元组只会来自「同一组值被不同的下标凑出来」，所以三处都要跳过重复：

1. **第一个数**：`if i > 0 and nums[i] == nums[i-1]: continue`——同一个值已经当过第一个数，再算一遍只会得到重复结果；
2. **左指针**：收下一组之后 `while l < r and nums[l] == nums[l-1]: l += 1`；
3. **右指针**：`while l < r and nums[r] == nums[r+1]: r -= 1`。

后两条必须写在「收下这一组并移动指针之后」，否则会把刚刚用过的那个位置又跳过一遍。

### 提前结束

数组升序，`nums[i] > 0` 时后面所有数都不小于它，三数之和必然大于 0，直接 `break`。

### 推演：示例 1

排序后 `nums = [-4,-1,-1,0,1,2]`。

`i = 0`（`-4`）：`l = 1, r = 5`，和 `-4 + (-1) + 2 = -3 < 0`，`l` 一路右移，到 `l = 5` 时区间空，无解。

`i = 1`（`-1`）：

| `l` | `r` | `nums[l]` | `nums[r]` | 和 | 动作 |
| --- | --- | --- | --- | --- | --- |
| 2 | 5 | −1 | 2 | 0 | 收下 `[-1,-1,2]`，`l=3, r=4` |
| 3 | 4 | 0 | 1 | 0 | 收下 `[-1,0,1]`，`l=4, r=3`，结束 |

`i = 2`（`-1`）：与 `nums[1]` 相同，跳过。`i = 3`（`0`）：`l=4, r=5`，和 `0+1+2=3 > 0`，`r` 左移到 4 后区间空，无解。

最终 `[[-1,-1,2],[-1,0,1]]`。

## 完整代码实现

```python
from typing import List


class Solution:
    def threeSum(self, nums: List[int]) -> List[List[int]]:
        nums.sort()
        n = len(nums)
        ans = []

        for i in range(n - 2):
            if i > 0 and nums[i] == nums[i - 1]:
                continue                  # 第一个数去重
            if nums[i] > 0:
                break                     # 最小的数都大于 0，后面不可能凑出 0
            l, r = i + 1, n - 1
            while l < r:
                s = nums[i] + nums[l] + nums[r]
                if s == 0:
                    ans.append([nums[i], nums[l], nums[r]])
                    l += 1
                    r -= 1
                    while l < r and nums[l] == nums[l - 1]:
                        l += 1            # 左指针去重
                    while l < r and nums[r] == nums[r + 1]:
                        r -= 1            # 右指针去重
                elif s < 0:
                    l += 1
                else:
                    r -= 1

        return ans
```

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| --- | --- | --- | --- |
| 三重循环 + 集合去重 | O(n³) | O(n) | n = 3000 时约 2.7 × 10^10 组，超时 |
| 排序 + 固定一个数 + 双指针（最优） | O(n²) | O(1) | 外层 n 次，内层两个指针合计走 n 步；排序 O(n log n) 被主导 |

## 易错点总结

### 1. 第一个数没去重

外层少了 `i > 0 and nums[i] == nums[i-1]` 这一句，示例 1 会输出三组：`[-1,-1,2]`、`[-1,0,1]`、`[-1,0,1]`——第二个 `-1` 又把同样的结果算了一遍。排序后重复值相邻，这一句就是靠「和上一个比」把它们跳掉。

### 2. 双指针移动方向写反

`s < 0` 时应右移 `l`（让和变大），`s > 0` 时左移 `r`。写反后两个指针会朝着让和偏离 0 的方向走，大部分数据都会漏解。`nums = [4,3,3,4,-1,-2]` 排序后是 `[-2,-1,3,3,4,4]`，正确答案 `[[-2,-1,3]]`，方向写反时返回 `[]`。

## 扩展思考

- 「四数之和」是同一套骨架再套一层循环，复杂度 O(n³)；把最内层换成哈希表可以把一层循环换掉，但要额外处理去重。
- 若只问「是否存在」而不要求列出所有三元组，双指针遇到第一组就可以返回，省掉全部去重逻辑。
