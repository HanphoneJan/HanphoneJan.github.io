# 70. 爬楼梯

## 题目描述

假设你正在爬楼梯。需要 `n` 阶你才能到达楼顶。

每次你可以爬 1 或 2 个台阶。你有多少种不同的方法可以爬到楼顶呢？

**提示：**

- `1 <= n <= 45`

## 示例

### 示例 1

**输入：** n = 2

**输出：** 2

**解释：** 1 阶 + 1 阶，或者 2 阶。

### 示例 2

**输入：** n = 3

**输出：** 3

**解释：** 1+1+1、1+2、2+1，共三种。

## 解题思路

走到第 `n` 阶的最后一步只有两种可能：从第 `n-1` 阶跨 1 阶上来，或者从第 `n-2` 阶跨 2 阶上来。这两类走法互不重叠、合起来覆盖全部方案，所以方案数就是两者之和——`f(n) = f(n-1) + f(n-2)`，也就是斐波那契数列。递推只依赖前两项，所以两个变量滚动就够了。

### 最后一步拆成两类

`f(n)` 只和 `f(n-1)`、`f(n-2)` 有关，这就是全部推导。写成递归是一行，但同一层会被反复算，所以直接递推：

```python
f0, f1 = 1, 1                 # f(0) = 1, f(1) = 1
for _ in range(2, n + 1):
    f0, f1 = f1, f0 + f1      # 一起更新，右边全是旧值
return f1
```

`f(0) = 1` 是为了让递推在 `n = 2` 时也成立：`f(2) = f(1) + f(0) = 1 + 1 = 2`。写成 0 的话，`n = 2` 会得到 1。

### 更新顺序不能拆

`f0, f1 = f1, f0 + f1` 必须写成一行元组赋值。拆成 `f0 = f1` 再 `f1 = f0 + f1`，第二行里的 `f0` 已经是新的了，等于把 `f(n-1)` 加了两次。

### 推演：`n = 5`

| 轮次 | 进入时 `f0, f1` | 更新后 `f0, f1` | 含义 |
| --- | --- | --- | --- |
| 初始 | 1, 1 | — | `f(0), f(1)` |
| `n=2` | 1, 1 | 1, 2 | `f(1), f(2)` |
| `n=3` | 1, 2 | 2, 3 | `f(2), f(3)` |
| `n=4` | 2, 3 | 3, 5 | `f(3), f(4)` |
| `n=5` | 3, 5 | 5, 8 | `f(4), f(5)` |

返回 8。每一轮 `f1` 都是新的 `f(n)`，`f0` 退一位成为 `f(n-1)`。

## 完整代码实现

```python
class Solution:
    def climbStairs(self, n: int) -> int:
        f0, f1 = 1, 1              # f(0) = 1，f(1) = 1
        for _ in range(2, n + 1):
            f0, f1 = f1, f0 + f1   # 同一行更新，避免 f0 被提前覆盖
        return f1
```

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| --- | --- | --- | --- |
| 直接递归 | O(2^n) | O(n) | 同一个 `f(k)` 被重复计算多次 |
| 记忆化搜索 | O(n) | O(n) | 每个状态只算一次，但要开缓存 |
| 两个变量滚动（最优） | O(n) | O(1) | 只保留 `f(n-1)` 与 `f(n-2)` |

## 易错点总结

### 1. `f0` 初值写成 0

`f0, f1 = 0, 1` 时 `n = 2` 返回 1（正确 2），`n = 3` 返回 2（正确 3）——整个序列都往前错了一位。`f(0) = 1` 是让递推在 `n = 2` 处也成立的那块地基。

### 2. 把元组赋值拆成两条语句

先 `f0 = f1` 再 `f1 = f0 + f1`，第二行的 `f0` 已经是新的 `f(n-1)`，等于算成 `2 × f(n-1)`：`n = 2` 返回 2（碰巧对），`n = 3` 返回 4（正确 3），`n = 4` 返回 8（正确 5）。`n = 2` 的巧合会让人以为写对了。

## 扩展思考

- 一次可以爬 `1..k` 阶时，递推变成 `f(n) = f(n-1) + ... + f(n-k)`，用滑动窗口维护前缀和可以做到 O(n)。
- 这就是斐波那契数列，`n = 45` 时答案 1836311903，在 32 位整数范围内；再大就需要取模。
