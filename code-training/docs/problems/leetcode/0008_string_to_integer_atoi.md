# 0008. 字符串转换整数 (atoi)

## 题目描述

实现 `myAtoi(s)`，把字符串转成 32 位有符号整数：

1. 跳过前导空格；
2. 读一个可选的 `'+'` 或 `'-'`，没有则视为正号；
3. 读连续的数字字符，遇到第一个非数字就停止；
4. 结果超出 `[-2^31, 2^31 - 1]` 时夹到边界。

## 示例

### 示例 1

**输入：** s = "42"
**输出：** 42

### 示例 2

**输入：** s = "   -042"
**输出：** -42
**解释：** 跳过空格，读到负号，数字部分是 `042`，结果为 `-42`。

### 示例 3

**输入：** s = "1337c0d3"
**输出：** 1337
**解释：** 读到 `c` 时停止。

### 示例 4

**输入：** s = "0-1"
**输出：** 0
**解释：** 数字段读到 `0` 后遇到 `-` 就停止，后面的 `-1` 不再属于这个数。

### 示例 5

**输入：** s = "words and 987"
**输出：** 0
**解释：** 第一个非空格字符不是数字也不是符号，直接返回 0。

## 解题思路

### 路线：一根指针走完四个阶段

整道题是一条只前进、不回头的流水线：空格 → 符号 → 数字 → 夹紧。每个阶段的结束方式都只有两种——进入下一阶段，或者「这里不合法，立刻停，返回已经读到的部分」。

真正容易错的不是阶段本身，而是**每个阶段该在什么时候停**。比如数字段一旦开始，后面再出现 `'+'`、`'-'` 都只是普通字符，不能再当符号读；而符号段最多读一个字符，读完就必须切到数字段。下面按这四个阶段写，每个阶段的停止条件就写在它自己那几行里。

### 手法：四个 while，各管一段

```python
i, n = 0, len(s)

while i < n and s[i] == ' ':       # ① 跳过前导空格
    i += 1

sign = 1
if i < n and s[i] in '+-':         # ② 至多读一个符号
    sign = -1 if s[i] == '-' else 1
    i += 1

num = 0
while i < n and '0' <= s[i] <= '9':  # ③ 读连续数字，遇非数字立刻停
    num = num * 10 + int(s[i])
    i += 1
```

第 ③ 段用 `'0' <= s[i] <= '9'` 而不是 `s[i].isdigit()`：后者会把全角数字、上标等 Unicode 字符也认成数字，而题面的输入只含 ASCII 数字。数字段结束的位置就是整数的结尾，`i` 之后的内容一律不读。

夹紧放在最后：Python 的整数没有位宽上限，`num` 可以先算大再判断。

```python
num *= sign
if num < -2**31:
    return -2**31
if num > 2**31 - 1:
    return 2**31 - 1
return num
```

换到只有 32 位整数的语言，`num * 10 + d` 本身会溢出，必须在乘之前判断 `num > (2**31 - 1 - d) // 10`。本题用 Python，最后夹紧与提前夹紧结果相同，没必要多写一段。

### 停在哪儿：三个边界输入

- `"0-1"`：数字段读到 `0`，下一个字符 `-` 不是数字，数字段结束，返回 `0`。这里的 `-` 不是符号，因为符号段早就过去了。
- `"+-1"`：符号段读走 `+`，数字段第一个字符是 `-`，一个数字都没读到，返回 `0`。
- `"   "`：空格跳完 `i == n`，符号段与数字段都不进，返回 `0`。

三个阶段都靠「下标越界或字符不符合」来退出，没有任何一个阶段会回头重读。

### 推演：`s = "   -042"`

| 阶段 | 进入时 `i` | 动作 | 结束时 `i` |
| --- | --- | --- | --- |
| ① 空格 | 0 | 跳过 3 个空格 | 3 |
| ② 符号 | 3 | 读到 `'-'`，`sign = -1` | 4 |
| ③ 数字 | 4 | 依次读 `0`、`4`、`2`，`num = 42` | 7 |
| ④ 夹紧 | — | `-42` 在范围内 | — |

返回 `-42`。

`s = "1337c0d3"` 在第 ③ 段读到 `c` 就停：`num = 1337`，后面的 `c0d3` 完全不参与。

## 完整代码实现

```python
class Solution:
    def myAtoi(self, s: str) -> int:
        n = len(s)
        i = 0

        # ① 跳过前导空格
        while i < n and s[i] == ' ':
            i += 1

        # ② 至多读一个符号
        sign = 1
        if i < n and s[i] in '+-':
            if s[i] == '-':
                sign = -1
            i += 1

        # ③ 读连续数字：一旦不是 ASCII 数字就停
        num = 0
        while i < n and '0' <= s[i] <= '9':
            num = num * 10 + int(s[i])
            i += 1

        # ④ 乘符号后夹到 32 位有符号整数范围
        num *= sign
        if num < -2**31:
            return -2**31
        if num > 2**31 - 1:
            return 2**31 - 1
        return num
```

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| --- | --- | --- | --- |
| 切片版（`strip` + 反复 `s[1:]`） | O(n) | O(n) | 每次切片都复制一份字符串 |
| 指针版（最优） | O(n) | O(1) | 只移动下标，不创建中间字符串 |

`n` 是字符串长度；四个阶段加起来每个字符至多看一次。

## 易错点总结

### 1. 先判符号、后跳空格

符号段必须排在空格段之后。写成「先看 `s[0]` 是不是 `+/-`」，`"   -42"` 的首字符是空格，会被判成「没有符号」，随后数字段又在空格处停下，返回 `0`。示例 2 就是专门照这个的。

### 2. 把数字段里的 `-` 又当成符号

数字段一旦开始，就不再看符号。`"0-1"` 若在循环里见到 `-` 就翻转 `sign`，会读出 `-1`；正确结果是 `0`，因为数字段在 `0` 后面已经结束。符号只在第 ② 段读一次，这个「只读一次」要由代码结构保证，不能靠额外的标志位去补。

### 3. 忘记乘 `sign`

数字段算出来的 `num` 永远是非负数，最后必须 `num *= sign` 再夹紧。漏掉这一步，示例 2 会返回 `42` 而不是 `-42`——数值看着完全合法，只有对答案才发现符号丢了。

## 扩展思考

- **DFA 写法**：把「开始 / 已读符号 / 读数字 / 结束」四个状态和字符类别写成转移表，逻辑与上面四个 `while` 完全等价，只是把「阶段」显式化。状态多、分支杂的解析题用 DFA 更稳。
- **只有 32 位整数时**：`num = num * 10 + d` 可能先溢出。要在乘之前判断 `num > (limit - d) // 10`，正负两侧的 `limit` 分别是 `2^31 - 1` 与 `2^31`。
