# 136. 只出现一次的数字

## 题目描述

给你一个**非空**整数数组 `nums`，除了某个元素只出现一次以外，其余每个元素均出现两次。找出那个只出现了一次的元素。

你必须设计并实现线性时间复杂度的算法来解决此问题，且该算法只使用常量额外空间。

**提示：**

- `1 <= nums.length <= 3 * 10^4`
- `-3 * 10^4 <= nums[i] <= 3 * 10^4`
- 除某个元素仅出现一次外，其余每个元素都恰出现**两次**

## 示例

### 示例 1

**输入：** nums = [2,2,1]

**输出：** 1

### 示例 2

**输入：** nums = [4,1,2,1,2]

**输出：** 4

### 示例 3

**输入：** nums = [1]

**输出：** 1

## 解题思路

题目要求「线性时间 + 常数空间」，哈希表和排序都被排除。剩下的只有异或：`a ^ a = 0`、`a ^ 0 = a`，把数组全部异或起来，成对的元素两两抵消，剩下的就是那个只出现一次的数。异或还满足交换律和结合律，所以顺序无所谓。

### 全部异或一遍

```python
ans = 0
for x in nums:
    ans ^= x
return ans
```

初始值必须是 `0`：`0 ^ a = a`，从 0 开始才能让第一个数原样留下。用 `nums[0]` 当初始值也对，但那样就得特殊处理长度为 1 的情况，不如统一从 0 起。

### 为什么成对的元素会消失

异或有两条性质：`x ^ x = 0`（相同为 0）、`x ^ 0 = x`（和 0 异或不变）。整个数组的异或可以按值重新分组：每个出现两次的数贡献一次 `x ^ x = 0`，最后只剩那个出现一次的数与 0 异或。

这依赖「其余元素恰好出现两次」这个前提。若某个数出现三次，`x ^ x ^ x = x`，它会留在结果里，答案就错了——那时要换成按位统计（每个二进制位上 1 的个数对 3 取模）。

### 推演：示例 2

`nums = [4,1,2,1,2]`。

| 步骤 | 读入 | `ans` 变化 |
| --- | --- | --- |
| 初始 | — | 0 |
| 1 | 4 | `0 ^ 4 = 4` |
| 2 | 1 | `4 ^ 1 = 5` |
| 3 | 2 | `5 ^ 2 = 7` |
| 4 | 1 | `7 ^ 1 = 6` |
| 5 | 2 | `6 ^ 2 = 4` |

最终 `4`。中间值 5、7、6 没有意义，只有「成对抵消」这件事有意义：两个 1 和两个 2 各自归零，剩下的就是 4。

## 完整代码实现

```python
from functools import reduce
from operator import xor
from typing import List


class Solution:
    def singleNumber(self, nums: List[int]) -> int:
        ans = 0
        for x in nums:
            ans ^= x        # 成对的异或成 0，最后只剩落单的那个
        return ans
```

也可以一行写完：`return reduce(xor, nums, 0)`——`reduce` 的第三个参数正是初始值 0。

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| --- | --- | --- | --- |
| 哈希表计数 | O(n) | O(n) | 空间不满足常数要求 |
| 排序后找相邻不同的那个 | O(n log n) | O(1) | 时间不满足线性要求 |
| 全部异或（最优） | O(n) | O(1) | 一遍扫描，只用一个变量 |

## 易错点总结

### 1. 把「全部异或」当成通用解法

这招只在「其余元素恰好出现两次」时成立。若把示例 2 改成 `[4,1,1,1,2,2]`（1 出现三次），异或结果是 `4 ^ 1 = 5`，而正确答案是 4——三次的那个数会残留。题目给的前提就是这条解法的全部依据，换题面就得换算法。

### 2. 用 `reduce(xor, nums)` 却不给初始值

`reduce` 不传第三个参数时，空数组会抛 `TypeError`，而且语义上少了一次「与 0 异或」。本题数组非空，所以不会崩，但统一写成 `reduce(xor, nums, 0)` 更稳，也和在循环里从 `ans = 0` 起完全一致。

## 扩展思考

- 若其余元素出现三次，用「按位统计」：对 32 个二进制位分别数 1 的个数，模 3 后拼回答案，时间 O(32n)、空间 O(1)。
- 若有两个数各出现一次，把全部异或的结果取最低位的 1 当分组依据，分成两组再各自异或，就是 [260. 只出现一次的数字 III](https://leetcode.cn/problems/single-number-iii/)。
