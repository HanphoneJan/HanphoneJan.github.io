# 14. 最长公共前缀

## 题目描述

编写一个函数来查找字符串数组中的最长公共前缀。如果不存在公共前缀，返回空字符串 `""`。

**提示：**

- `1 <= strs.length <= 200`
- `0 <= strs[i].length <= 200`
- `strs[i]` 仅由小写英文字母组成

注意字符串可能是空串，此时答案一定是 `""`。

## 示例

### 示例 1

**输入：** strs = ["flower","flow","flight"]

**输出：** "fl"

### 示例 2

**输入：** strs = ["dog","racecar","car"]

**输出：** ""

**解释：** 输入不存在公共前缀。

## 解题思路

公共前缀一定是每个字符串的开头，所以拿第一个字符串当「候选前缀」，一列一列往后验：第 `i` 列所有字符串都还是同一个字符，就继续；哪一个字符串在这一列没字符了、或者字符不同，前 `i` 列就是答案。这比两两合并省事——不需要反复构造中间结果。

### 拿第一个串当候选，逐列验

`strs[0]` 的每个字符依次和所有字符串的同位置字符比。三种停下的情况：某个字符串长度不够（`i == len(s)`）、某个字符串这一位不同、或者 `strs[0]` 自己走完了。

停下的位置 `i` 就是公共前缀的长度，返回 `strs[0][:i]`。

```python
for i, c in enumerate(strs[0]):
    for s in strs:
        if i == len(s) or s[i] != c:   # 先判越界，再取字符
            return strs[0][:i]
return strs[0]
```

**越界判断要放在 `s[i]` 前面。** Python 的 `or` 从左往右短路，`i == len(s)` 成立时不会再取 `s[i]`；顺序写反就会在更短的字符串上抛 `IndexError`。

循环走完都没停，说明 `strs[0]` 的每一位都属于公共前缀，直接返回整个 `strs[0]`（示例里 `["abc"]` 这种只有一个串的情况就是这一条）。

### 为什么这是最小的公共前缀

设停下的位置是 `i`。前 `i` 列所有字符串都相同，所以长度至少是 `i`；第 `i` 列至少有一个字符串不同或没有字符，所以长度不可能超过 `i`。两个方向一夹，答案就是 `strs[0][:i]`。

### 推演：示例 1

`strs = ["flower","flow","flight"]`，以 `strs[0] = "flower"` 为候选。

| 列 `i` | 候选字符 | `"flow"` | `"flight"` | 结论 |
| --- | --- | --- | --- | --- |
| 0 | `f` | `f` | `f` | 继续 |
| 1 | `l` | `l` | `l` | 继续 |
| 2 | `o` | `o` | `i` | 不同，停 |

停下时 `i = 2`，返回 `"fl"`。注意 `"flight"` 的长度足够，这里停下是因为字符不同，不是越界——两种停法都要能处理。

## 完整代码实现

```python
from typing import List


class Solution:
    def longestCommonPrefix(self, strs: List[str]) -> str:
        first = strs[0]
        for i, c in enumerate(first):
            for s in strs:
                # 先判越界再比字符：or 的短路保证不会取到 s[i] 之外
                if i == len(s) or s[i] != c:
                    return first[:i]
        return first
```

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| --- | --- | --- | --- |
| 横向：两两求公共前缀再合并 | O(n · m) | O(m) | 每合并一次都要构造一个新字符串 |
| 纵向逐列比较（最优） | O(n · m) | O(1) | 有一列不同就立刻返回，只用到下标 |

`n` 是字符串个数，`m` 是最长公共前缀的长度。最坏情况要把每个字符串的前 `m` 位都看一遍，所以是 `n · m`；空间只用了两个下标，返回的字符串不算在内。

## 易错点总结

### 1. 先取 `s[i]` 再判越界

`if s[i] != c or i == len(s)` 把顺序写反，`strs = ["ab","a"]` 在 `i = 1` 时对 `"a"` 取 `s[1]`，抛 `IndexError: string index out of range`。必须先判长度，再取字符。

### 2. 返回时多带一位

停下时第 `i` 列已经不匹配了，公共前缀是前 `i` 列。写成 `first[:i + 1]`，示例 1 会返回 `"flo"`（含那个不同的 `o`），正确答案是 `"fl"`。

## 扩展思考

- 也可以先排序再只比较首尾两个字符串：排序后首尾的公共前缀就是全体的公共前缀，代价是 `O(n log n · m)` 的排序，代码更短。
- 换成「最长公共后缀」时，把字符串整体反转再跑一遍同样的逻辑即可。
