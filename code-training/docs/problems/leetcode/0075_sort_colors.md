# 75. 颜色分类

## 题目描述

给定一个包含红色、白色和蓝色、共 `n` 个元素的数组 `nums`，原地对它们进行排序，使得相同颜色的元素相邻，并按照红色、白色、蓝色顺序排列。

我们使用整数 `0`、 `1` 和 `2` 分别表示红色、白色和蓝色。

必须在不使用库内置的 sort 函数的情况下解决这个问题。

## 示例

**示例 1：**
```
输入：nums = [2,0,2,1,1,0]
输出：[0,0,1,1,2,2]
```

**示例 2：**
```
输入：nums = [2,0,1]
输出：[0,1,2]
```

---

## 解题思路

### 第一步：理解问题本质

这是一个经典的**荷兰国旗问题**。数组中只有 0, 1, 2 三个值，需要原地排序。

### 方法一：计数排序思路

**思路**：统计每个数字的个数，然后按顺序填充。

```python
class Solution:
    def sortColors(self, nums: List[int]) -> None:
        # 颜色值恰好是 0/1/2，可以直接当下标用
        count = [0, 0, 0]
        # 第一遍：数出每种颜色有多少个
        for num in nums:
            count[num] += 1

        # 第二遍：按 0、1、2 的顺序回填，天然就是有序的
        idx = 0
        for i in range(3):
            for j in range(count[i]):
                nums[idx] = i
                idx += 1
```

**缺点**：需要两次遍历。

### 方法二：三指针法

**核心洞察**：
- `p0`：指向 0 应该放置的位置（从数组开头）
- `p2`：指向 2 应该放置的位置（从数组末尾）
- `i`：当前遍历位置

**算法步骤**：
- `nums[i] == 0`：与 `p0` 交换，`p0++`，`i++`
- `nums[i] == 1`：`i++`
- `nums[i] == 2`：与 `p2` 交换，`p2--`（`i` 不递增）

```python
class Solution:
    def sortColors(self, nums: List[int]) -> None:
        n = len(nums)
        p0, p2 = 0, n - 1
        i = 0

        while i <= p2:
            if nums[i] == 0:
                # 0 换到前面；换过来的是 1（p0 左侧已经全是 0），可以放心 i++
                nums[i], nums[p0] = nums[p0], nums[i]
                p0 += 1
                i += 1
            elif nums[i] == 1:
                i += 1
            else:
                # 2 换到后面；换过来的元素还没看过，i 不能动
                nums[i], nums[p2] = nums[p2], nums[i]
                p2 -= 1
```

`p0` 左侧始终是已归位的 0，`p2` 右侧始终是已归位的 2，`[p0, i)` 是 1，`[i, p2]` 是还没处理的区域。循环条件写成 `i <= p2`，因为 `i == p2` 时这一格还没被检查。

## 完整代码实现

```python
from typing import List

class Solution:
    """
    颜色分类 - 荷兰国旗问题

    核心思想：
    数组中只有 0, 1, 2 三个值，需要原地排序。
    这是经典的"荷兰国旗问题"。

    三指针法（最优）：
    - p0：指向0应该放置的位置（从数组开头）
    - p2：指向2应该放置的位置（从数组末尾）
    - i：当前遍历位置

    遍历策略：
    - nums[i] == 0：与 p0 位置交换，p0++，i++
    - nums[i] == 1：i++
    - nums[i] == 2：与 p2 位置交换，p2--（i 不递增，因为交换过来的元素需要再判断）

    时间复杂度：O(n)
    空间复杂度：O(1)
    """

    def sortColors(self, nums: List[int]) -> None:
        n = len(nums)
        p0, p2 = 0, n - 1
        i = 0

        while i <= p2:
            if nums[i] == 0:
                nums[i], nums[p0] = nums[p0], nums[i]
                p0 += 1
                i += 1
            elif nums[i] == 1:
                i += 1
            else:  # nums[i] == 2
                nums[i], nums[p2] = nums[p2], nums[i]
                p2 -= 1
```

## 示例推演

以 `nums = [2,0,2,1,1,0]` 为例，初始 `p0 = 0`、`p2 = 5`、`i = 0`：

| 步骤 | `i` | `nums[i]` | 操作 | 数组状态 |
|---|---|---|---|---|
| 1 | 0 | 2 | 与 `p2` 交换，`p2 = 4` | `[0,0,2,1,1,2]` |
| 2 | 0 | 0 | 与 `p0` 交换，`p0 = 1`，`i = 1` | `[0,0,2,1,1,2]` |
| 3 | 1 | 0 | 与 `p0` 交换，`p0 = 2`，`i = 2` | `[0,0,2,1,1,2]` |
| 4 | 2 | 2 | 与 `p2` 交换，`p2 = 3` | `[0,0,1,1,2,2]` |
| 5 | 2 | 1 | `i = 3` | `[0,0,1,1,2,2]` |
| 6 | 3 | 1 | `i = 4`，此时 `i > p2`，结束 | `[0,0,1,1,2,2]` |

第 1 步把末尾的 0 换到前面后，`i` 没有动，因为换过来的 0 还要再判断一次；第 4 步把 2 换到后面后同样不动，换过来的 1 需要接着处理。最终数组按 0、1、2 有序。

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 计数排序 | O(n) | O(1) | 需要两次遍历 |
| **三指针（最优）** | **O(n)** | **O(1)** | 一次遍历 |

## 易错点总结

1. **和 `p2` 交换后也 `i++`**：换过来的元素还没检查过，直接跳过会漏掉它。`[2,0,1]` 会变成 `[1,0,2]` 而不是 `[0,1,2]`。
2. **循环条件写成 `i < p2`**：`i == p2` 时这一格还没处理，可能是 0，也可能是 2。用 `<` 会提前退出，`[2,0,1]` 同样会留下未排序的元素。
3. **`p0` 交换后忘记 `i++`**：`p0` 左侧已经全是 0，换到 `i` 位置的一定是 1（或 `p0 == i`），不前进会重复处理同一格，最坏情况下死循环。
