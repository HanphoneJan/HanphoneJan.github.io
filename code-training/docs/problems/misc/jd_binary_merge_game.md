# 01 数组合并博弈

> 京东笔试编程题 · ACM 模式（stdin/stdout）

## 题目描述

给出一个长度为 $n$ 的 01 数组。甲、乙轮流操作，甲先手。

一次操作选择一段长度至少为 2 的连续闭区间 $[l,r]$，把区间里的元素全部替换成一个数：

$$(a_l+a_{l+1}+\cdots+a_r+1)\bmod 2$$

区间被替换成一个元素后，数组长度减少 $r-l$。数组长度变成 1 时游戏结束：最后剩下的元素为 1 则甲胜，为 0 则乙胜。

问甲是否有必胜策略。

## 输入格式

- 第一行：一个整数 $n$；
- 第二行：$n$ 个 0 或 1，空格分隔。

## 输出格式

- 一行：`Yes` 或 `No`。

## 示例

### 示例 1

**输入：**
```
3
0 1 0
```

**输出：**
```
Yes
```

**说明：**
总和为 1（奇数）。甲合并前两个数：$[0,1]$ 的和为 1，替换成 $(1+1)\bmod2=0$，数组变成 $[0,0]$；乙只能合并这两个 0，得到 $(0+0+1)\bmod2=1$，甲胜。

### 示例 2

**输入：**
```
2
0 1
```

**输出：**
```
No
```

**说明：**
只有一种操作，合并整个数组：$(0+1+1)\bmod2=0$，最后元素为 0，乙胜。

### 示例 3

**输入：**
```
2
1 1
```

**输出：**
```
Yes
```

**说明：**
合并整个数组：$(1+1+1)\bmod2=1$，甲胜。

### 示例 4

**输入：**
```
1
0
```

**输出：**
```
No
```

**说明：**
数组长度已经是 1，没有操作；最后元素是 0，甲不胜。

## 解题思路

### 这题要走哪条路

游戏看着需要枚举「合并哪一段」，但每次合并只留下一个 0 或 1，真正决定胜负的只有**数组长度**和**总和的奇偶性**。先把 $n=1$、$n=2$ 这两种没有选择的情况定下来，再看 $n\ge3$ 能不能两步内结束。

### $n=1$ 与 $n=2$：没有选择

$n=1$ 时游戏直接结束，甲胜当且仅当 $a_0=1$。

$n=2$ 时只有一种操作：合并这两个数，结果是

$$(a_0+a_1+1)\bmod 2$$

它等于 1 当且仅当 $a_0+a_1$ 是偶数，也就是 $a_0=a_1$。所以 $n=2$ 时甲胜当且仅当两个数相等。

### $n\ge3$：分总和的奇偶两种走法

记总和为 $S=a_0+a_1+\cdots+a_{n-1}$。

**$S$ 为偶数**：甲直接合并整个数组，得到 $(S+1)\bmod2=1$，一步获胜。

**$S$ 为奇数**：甲合并前 $n-1$ 个数，也就是区间 $[0,n-2]$。新元素是

$$(S-a_{n-1}+1)\bmod 2$$

因为 $S$ 是奇数，$S+1$ 是偶数，所以这个值在模 2 意义下等于 $-a_{n-1}$，也就等于 $a_{n-1}$。数组剩下两个相等的数 $[a_{n-1},a_{n-1}]$，轮到乙。乙只有一种操作，合并它们：

$$(a_{n-1}+a_{n-1}+1)\bmod2=1$$

甲胜。

两条路都通向胜利，所以 $n\ge3$ 时甲恒有必胜策略。整个判断不需要搜索，甚至不需要知道数组具体长什么样，只要看长度；只有 $n=1$ 和 $n=2$ 需要读数组。

### 推演：拿示例 1 走一遍

数组 `[0,1,0]`，$n=3$，$S=1$ 是奇数。

| 步骤 | 操作 | 区间和 | 新元素 | 数组 |
|---|---|---|---|---|
| 甲 | 合并 $[0,1]$ | 1 | $(1+1)\bmod2=0$ | `[0,0]` |
| 乙 | 只能合并 $[0,1]$ | 0 | $(0+0+1)\bmod2=1$ | `[1]` |

最后元素是 1，甲胜。若甲第一步贪心合并整个数组，会得到 $(1+1)\bmod2=0$，反而输掉；奇数总和时必须留下两个相等的数给乙。

## 完整代码实现

```python
import sys


def first_player_wins(a) -> bool:
    """返回先手甲是否有必胜策略。"""
    n = len(a)
    if n == 1:
        return a[0] == 1
    if n == 2:
        return a[0] == a[1]
    # n >= 3：总和为偶数就一次合并全部；为奇数就合并前 n-1 个，留下两个相等的数
    return True


def solve() -> None:
    data = sys.stdin.read().split()
    if not data:
        return
    n = int(data[0])
    rest = data[1:]
    # 兼容两种写法：第二行是 n 个空格分隔的数，或一整串 "010"
    if len(rest) == 1 and len(rest[0]) == n and set(rest[0]) <= {"0", "1"}:
        a = [int(c) for c in rest[0]]
    else:
        a = [int(x) for x in rest[:n]]

    print("Yes" if first_player_wins(a) else "No")


if __name__ == "__main__":
    solve()
```

## 易错点总结

### 1. 把 $n\ge3$ 也拿去模拟或搜索

$n\ge3$ 时甲恒有必胜策略，不需要枚举合并方案。只有 $n=1$ 要看那个元素、$n=2$ 要看两个元素是否相等；漏掉这两个特判，或者对 $n\ge3$ 写搜索，都会把简单题做复杂。

### 2. $n=2$ 的胜负条件写反

甲胜的条件是 $(a_0+a_1+1)\bmod2=1$，即 $a_0+a_1$ 为偶数、两个数相等。写成「和为奇数甲胜」会把示例 2 的 `No` 判成 `Yes`。

### 3. 总和为奇数时合并了整个数组

奇数总和直接合并全部，得到的是 $(S+1)\bmod2=0$，最后元素为 0，乙胜。正确走法是合并前 $n-1$ 个，留下两个相等的数，让乙去合并。
