# 巷道矿车避碰

> 京东 9 月 5 日笔试第一题 · ACM 模式（stdin/stdout）

## 题目描述

一条直线巷道上有 $m$ 辆矿车，第 $i$ 辆当前停在 $p_i$，任务单要求它开到 $q_i$。

0 时刻所有被派出的车同时出发，以单位速度沿直线朝 $q_i$ 行驶；到达 $q_i$ 后停在原地不动。任意时刻两车不能处在同一个位置，$t=0$ 的出发瞬间也算相遇：只要存在某个时刻 $t\ge0$ 使两车位置相同，它们就不能同时派出。

从 $m$ 辆车中选出尽量多辆，要求任意两辆全程都不相遇，求最多能选多少辆。

## 输入格式

- 第一行：一个整数 $m$；
- 第二行：$m$ 个整数 $p_1,p_2,\ldots,p_m$；
- 第三行：$m$ 个整数 $q_1,q_2,\ldots,q_m$。

## 输出格式

- 一行：一个整数，表示最多能同时派出且全程不相遇的矿车数量。

## 数据范围

- $1\le m\le 2\times10^5$
- $1\le p_i,q_i\le 10^9$

## 示例

### 示例 1

**输入：**
```
3
4 6 9
7 3 9
```

**输出：**
```
2
```

**说明：**
三辆车分别是 $4\to7$、$6\to3$、$9\to9$。前两辆相向而行，在 $t=1$ 时同时到达位置 5，不能一起派出；第三辆始终停在 9，与前两辆都不相遇。最多派出 2 辆。

### 示例 2

**输入：**
```
3
8 8 2
3 12 5
```

**输出：**
```
2
```

**说明：**
前两辆在 $t=0$ 时都停在 8，已经算相遇，最多保留其中一辆。若保留 $8\to3$ 与 $2\to5$，后者在 $t=3$ 到达 5 并停下，前者同一时刻也开到 5，仍会相遇；保留 $8\to12$ 与 $2\to5$ 则互不重叠，答案为 2。

### 示例 3

**输入：**
```
3
1 3 5
10 8 6
```

**输出：**
```
1
```

**说明：**
三辆都向右开，且卸载点从左到右依次变近。左边的车会在右边的车已经停住之后，开到同一个卸载点上，因此任意两辆都会相遇，最多只能派出 1 辆。

## 解题思路

### 这题要走哪条路

直接按方向分情况讨论会漏掉「同向的车在前车停下后被追上」这种相遇。把每辆车在时刻 $t$ 的位置写成一个统一式子后，两车是否相遇只剩一条判据：**起点和终点必须同时严格递增**。选最多的车，就变成了在 $(p,q)$ 上找最长链，也就是排序后求 LIS。

### 第一步：位置写成一个中位数

第 $i$ 辆车在时刻 $t\ge0$ 的位置是

$$z_i(t)=\operatorname{mid}(p_i-t,\ q_i,\ p_i+t)$$

其中 $\operatorname{mid}$ 表示三个数中大小居中的那个。这个式子把三种情况写在了一起：

- $p_i<q_i$ 时，$p_i+t$ 从 $p_i$ 往上走，$p_i-t$ 在下面；没到站时 $p_i+t<q_i$，中位数是 $p_i+t$；到站后 $p_i+t>q_i$，中位数变成 $q_i$。
- $p_i>q_i$ 时，$p_i-t$ 从 $p_i$ 往下走；没到站时 $p_i-t>q_i$，中位数是 $p_i-t$；到站后中位数变成 $q_i$。
- $p_i=q_i$ 时，$p_i-t<p_i<p_i+t$，中位数恒为 $p_i$。

### 第二步：两辆车什么时候一定不相遇

假设 $p_i<p_j$。

**若 $q_i<q_j$：** 对任意 $t\ge0$，都有

$$p_i-t<p_j-t,\qquad q_i<q_j,\qquad p_i+t<p_j+t$$

三组数逐一严格更小，它们的中位数也严格更小，即 $z_i(t)<z_j(t)$ 恒成立，两车永不相遇。

**若 $q_i\ge q_j$：** $t=0$ 时 $z_i(0)=p_i<p_j=z_j(0)$；等两辆车都停下之后，$z_i=q_i\ge q_j=z_j$。位置随时间连续变化，从「左边更小」变成「右边更小」，中间一定存在某个时刻两者相等，也就是相遇。

所以 $p_i<p_j$ 时，两车不相遇的充要条件是 $q_i<q_j$。$p_i=p_j$ 时两车在 $t=0$ 就已经相遇，同样不满足严格递增。

把结论合起来：选出的车按 $p$ 从小到大排列后，$q$ 也必须严格递增。问题变成在二维点集 $(p_i,q_i)$ 上找最长的一条链。

### 第三步：排序与相同起点的处理

先按 $p$ 升序排序。**$p$ 相同时，按 $q$ 降序排**：起点相同的车在 $t=0$ 就相遇，最多只能选一辆；$q$ 降序能保证后面求严格递增子序列时不会同时选到同一组里的两辆。

排完后，对 $q$ 序列求**严格递增**的最长上升子序列，长度就是答案。$q$ 相同的两项也不能同时选（终点相同会在终点相遇），严格递增正好把它们挡掉。

### 第四步：$O(m\log m)$ 的 LIS

`tails[k]` 表示「长度为 $k+1$ 的严格递增子序列能取到的最小结尾」。遍历每个 $q$：

- 用 `bisect_left` 找到第一个大于等于 $q$ 的位置；
- 该位置存在就替换，不存在就追加到末尾。

`tails` 的长度就是 LIS 长度。严格递增必须用 `bisect_left`（下界）；用 `bisect_right` 会把相等的 $q$ 也接上去，答案偏大。

### 推演：拿示例 2 走一遍

三辆车是 $(8,3)$、$(8,12)$、$(2,5)$。按 $p$ 升序、$p$ 相同时 $q$ 降序：

| 车 | $p$ | $q$ |
|---|---|---|
| A | 2 | 5 |
| B | 8 | 12 |
| C | 8 | 3 |

$q$ 序列是 $5,12,3$：

| 处理 | `tails` | 动作 |
|---|---|---|
| 5 | `[5]` | 追加 |
| 12 | `[5,12]` | 追加 |
| 3 | `[3,12]` | 替换第一个 $\ge3$ 的位置 |

`tails` 长度是 2。对应选出的车是 $(2,5)$ 与 $(8,12)$；$(8,3)$ 与 $(2,5)$ 会在 $t=3$、位置 5 相遇，不能一起选。

## 完整代码实现

```python
import sys
from bisect import bisect_left


def max_non_meeting(p, q) -> int:
    """返回最多能同时派出且全程不相遇的矿车数量。"""
    # p 升序；p 相同时 q 降序，保证严格 LIS 不会同时选到起点相同的两辆车
    cars = sorted(zip(p, q), key=lambda x: (x[0], -x[1]))

    # tails[k] = 长度为 k+1 的严格递增子序列能取到的最小结尾
    tails = []
    for _, end in cars:
        # 严格递增用 lower_bound：找到第一个 >= end 的位置替换
        i = bisect_left(tails, end)
        if i == len(tails):
            tails.append(end)
        else:
            tails[i] = end
    return len(tails)


def solve() -> None:
    data = list(map(int, sys.stdin.read().split()))
    if not data:
        return
    m = data[0]
    p = data[1:1 + m]
    q = data[1 + m:1 + 2 * m]
    print(max_non_meeting(p, q))


if __name__ == "__main__":
    solve()
```

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 排序 + 朴素 LIS | O(m²) | O(m) | LIS 用两重循环，$m=2\times10^5$ 会超时 |
| 排序 + 二分 LIS（最优） | O(m log m) | O(m) | 排序 O(m log m)，每个 $q$ 一次 `bisect_left` |

其中 $m$ 为矿车数量。

## 易错点总结

### 1. 相同起点没有按 $q$ 降序排序

只写 `sort(key=lambda x: x[0])` 时，$p$ 相同的几辆车会按输入顺序排列，严格 LIS 可能把它们一起选进来，而它们在 $t=0$ 就相遇。例如 `p=[1,2,2]`、`q=[0,1,2]`，正确最多选 2 辆；$p$ 相同时不按 $q$ 降序，$q$ 序列会变成 $0,1,2$，LIS 误算成 3。

### 2. 严格 LIS 用了 `bisect_right`

`bisect_right` 找的是第一个大于 $q$ 的位置，相等的 $q$ 会被继续接在末尾。$q=[1,1,1]$ 时会算出 3，而严格递增最多只能选 1 辆。严格递增用 `bisect_left`。

### 3. 以为只有相向而行才会相遇

同向也会相遇：后车可能在前车停下后开到同一个位置，或者两辆车终点相同、后到的车撞上先停下的车。示例 3 三辆车全向右，仍然最多选 1 辆。判据必须是 $p$ 和 $q$ **同时**严格递增，不能只看方向。
