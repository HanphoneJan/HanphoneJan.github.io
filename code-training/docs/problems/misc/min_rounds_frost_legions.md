# 冰冻清剿：最少回合数

> 途游笔试编程题 · ACM 模式（stdin/stdout）

## 题目描述

敌方有 $n$ 支军团，第 $i$ 支军团的血量为 $a_i$。我方每回合固定做两件事：

1. 选择**一支**军团，造成 $x$ 点单体伤害；
2. 对所有军团造成 $y$ 点冰冻伤害。

单体伤害一回合只能落在一支军团上，超出其剩余血量的部分直接作废。两段伤害都在当回合结算，第 $R$ 回合的冰冻伤害同样生效。任意时刻所有军团的血量都不大于 $0$ 即获胜。

求获胜所需的最少回合数。

## 输入格式

- 第一行：三个整数 $n$、$x$、$y$；
- 第二行：$n$ 个整数 $a_1,a_2,\ldots,a_n$，相邻两数用空格分隔。

## 输出格式

- 一行：一个整数，表示最少回合数。

## 示例

### 示例 1

**输入：**
```
3 2 1
5 4 3
```

**输出：**
```
3
```

**说明：**
第 1 回合单体打第 1 支军团（$5\to3$），冰冻后血量为 $(2,3,2)$；第 2 回合再打第 1 支（$2\to0$），冰冻后为 $(0,2,1)$；第 3 回合打第 2 支（$2\to0$），冰冻收掉第 3 支。共 3 回合。

### 示例 2

**输入：**
```
5 100 1
4 4 4 4 4
```

**输出：**
```
4
```

**说明：**
单体伤害远大于单支军团的血量，每回合最多只能清掉一支；剩下的军团靠冰冻，每回合全体掉 1 点。3 回合后只剩两支各 1 点，第 4 回合的单体打掉一支，冰冻收掉最后一支。

### 示例 3

**输入：**
```
1 3 2
5
```

**输出：**
```
1
```

**说明：**
单体打掉 3 点（$5\to2$），同回合冰冻再打 2 点，一支军团一回合清空。

## 解题思路

### 这题要走哪条路

直接模拟「每回合打谁」有 $n$ 种选择，$R$ 回合就是 $n^R$ 条路径，不能枚举。换一个问法：**给定回合数 $R$，能不能清空？** 这个判定只要按军团逐个算「还差几次单体」，是 $O(n)$ 的；而且 $R$ 越大越容易成立，于是「求最小 $R$」可以变成「二分 $R$」。

### 第一步：$R$ 回合后每支军团还差多少血

冰冻伤害每回合都作用于全体，所以 $R$ 回合里军团 $i$ 一共吃到 $R\cdot y$ 点。扣掉这部分，剩下的

$$d_i=\max(0,\ a_i-R\cdot y)$$

只能由单体伤害补。这里的 $\max$ 不能省：被冰冻打死的军团不需要再补刀，$d_i$ 也不会是负数。

### 第二步：剩余血量要几次单体伤害

一次单体伤害是固定的 $x$，一回合只能打一支军团，溢出作废。所以军团 $i$ 需要

$$h_i=\left\lceil \frac{d_i}{x}\right\rceil$$

次单体伤害。向上取整是关键：$d_i=1$、$x=100$ 时也必须打一次，写成 `d // x` 会算成 0 次。

这一步不能把各军团的剩余血量加在一起再除以 $x$。伤害不能拆分，一支军团差 1 点也要占掉一个完整的回合；示例 2 里 5 支军团各差 1 点，需要 5 次，而不是 $\lceil 5/100\rceil=1$ 次。

### 第三步：判定与单调性

$R$ 回合只有 $R$ 次单体机会，所以 $R$ 可行的充要条件是

$$\sum_{i=1}^{n}\left\lceil \frac{\max(0,\ a_i-R\cdot y)}{x}\right\rceil \le R$$

为什么可以二分：$R$ 变大时，每支军团的 $d_i$ 不会变大，$h_i$ 也不会变大；右边可用的次数反而变多。所以某个 $R$ 可行之后，比它大的回合数全部可行，判定结果关于 $R$ 单调。

### 第四步：二分的上下界与落点

上界取「完全不用冰冻、每支军团纯靠单体打掉」的总次数：

$$hi=\sum_{i=1}^{n}\left\lceil \frac{a_i}{x}\right\rceil$$

这种打法一定可行，所以答案不会超过 $hi$。下界取 0。二分时 `ok(mid)` 为真就收缩到 `hi = mid`，为假就 `lo = mid + 1`；循环结束时 `lo == hi`，就是最小的可行回合数。

上界不能写成 $\lceil \sum a_i/x\rceil$。示例 2 的总血量是 20，$\lceil 20/100\rceil=1$，但 1 回合只能打一支军团，这个上界本身不可行，二分会停在一个打不完的回合数上。

### 推演：拿示例 2 走一遍二分

5 支军团血量全为 4，$x=100$，$y=1$。上界 $hi=\sum\lceil4/100\rceil=5$。

| 回合数 $R$ | 每支剩余 $d_i$ | 每支需要 $h_i$ | 总次数 | 判定 |
|---|---|---|---|---|
| 2 | 2 | 1 | 5 | $5>2$，不可行 |
| 3 | 1 | 1 | 5 | $5>3$，不可行 |
| 4 | 0 | 0 | 0 | $0\le4$，可行 |

二分过程：`lo=0, hi=5` → `mid=2` 不可行，`lo=3` → `mid=4` 可行，`hi=4` → `mid=3` 不可行，`lo=4`。最终答案是 4，和示例一致。

逐回合看这 4 回合：每回合单体清掉一支，冰冻让剩下的军团各掉 1 点；3 回合后还剩两支各 1 点，第 4 回合单体打掉一支，冰冻收掉最后一支。

## 完整代码实现

```python
import sys


def min_rounds(x: int, y: int, hp) -> int:
    """返回清空全部军团所需的最少回合数。"""
    # 上界：完全不用冰冻，每支军团都靠单体伤害单独打掉，一定可行
    lo, hi = 0, sum((h + x - 1) // x for h in hp)

    def ok(rounds: int) -> bool:
        """rounds 回合内能否清空。"""
        hits = 0
        for h in hp:
            rest = h - rounds * y
            if rest > 0:
                # 一次单体只能打一支军团，且溢出作废，所以按军团向上取整
                hits += (rest + x - 1) // x
                if hits > rounds:      # 后面只会更多，提前结束
                    return False
        return True

    while lo < hi:
        mid = (lo + hi) // 2
        if ok(mid):
            hi = mid        # mid 可行，答案在 [lo, mid]
        else:
            lo = mid + 1    # mid 不可行，答案在 [mid+1, hi]
    return lo


def solve() -> None:
    data = sys.stdin.read().split()
    if not data:
        return
    n, x, y = map(int, data[:3])
    hp = list(map(int, data[3:3 + n]))
    print(min_rounds(x, y, hp))


if __name__ == "__main__":
    solve()
```

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 二分答案 + 逐军团判定（最优） | O(n log S) | O(n) | S = Σ⌈aᵢ/x⌉ 为二分上界，共 O(log S) 轮，每轮 O(n) |

其中 $n$ 为军团数量，$S$ 为纯单体清空所需的总次数。即使 $n$ 到 $10^5$、血量到 $10^9$，$O(n\log S)$ 也能在时限内跑完。

## 易错点总结

### 1. 把「剩余总血量 ÷ x」当成判定

`sum(d_i) <= R * x` 看起来更宽松，但它允许把一回合的 $x$ 拆给多支军团。示例 2 里 5 支军团各剩 1 点，总量 5 远小于 $100$，会误判成 1 回合；实际每回合只能打一支，需要 4 回合。判定必须按军团分别取整再求和。

### 2. 二分的上界取 ⌈总血量 / x⌉

示例 2 的总血量是 20，$\lceil20/100\rceil=1$。这个上界本身不可行，二分会直接返回 1。上界要用 $\sum\lceil a_i/x\rceil$，也就是「纯单体一支一支打」的总次数。

### 3. 用 `d // x` 代替上取整

`rest // x` 在 $rest=1$、$x=100$ 时得到 0，判定会把一支还差 1 点血的军团当成已经清掉，答案偏小。写成 `(rest + x - 1) // x`，或者在 Python 里用 `math.ceil(rest / x)`（注意浮点精度，数据大时仍推荐整数写法）。

## 扩展思考

如果 $x$ 可以在一回合内拆给多支军团，判定就退化成 $\sum d_i \le R\cdot x$，示例 2 的答案会变成 1。本题「一次只能打一支军团」才是必须按军团向上取整的原因；读题时把这一条确认清楚，比套二分模板更重要。
