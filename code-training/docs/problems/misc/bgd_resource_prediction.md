# P4729. 路由器资源用量预测

## 题目描述

路由器的某资源利用率与多个运行特征强相关：协议连接数（单位：个）、转发数据包速率（单位：Mpps）、内存占用率（单位：%）。为了精准预测不同负载下的路由器资源利用率，保障网络稳定运行，请实现批量梯度下降法（BGD）来训练资源预测线性回归模型的参数。

**资源预测模型：** $y = w_0 + w_1 \cdot x_1 + w_2 \cdot x_2 + w_3 \cdot x_3$（$w_0$ 为偏置项，$w_1, w_2, w_3$ 为特征权重）

**损失函数：** 均方误差（MSE），$L = \frac{1}{2m} \sum_{i=1}^{m} (y_{\text{pred},i} - y_{\text{true},i})^2$（$m$ 为样本数）

**梯度更新规则：** $w_j = w_j - \alpha \cdot \frac{1}{m} \sum_{i=1}^{m} (y_{\text{pred},i} - y_{\text{true},i}) \cdot x_{ij}$（偏置项 $w_0$ 对应 $x_{i0}=1$，$\alpha$ 为学习率）

**迭代规则：** 初始权重（含偏置）全为0，迭代固定 $N$ 次后停止，无需判断收敛

**特征归一化与还原：**
- 归一化：$x_j^{\text{norm}} = \frac{x_j - \min(x_j)}{\max(x_j) - \min(x_j)}$，若 $\max = \min$ 则归一化值为 0
- 权重还原：$w_j = \frac{w_j^{\text{norm}}}{\max(x_j) - \min(x_j)}$，若差为 0 则 $w_j = 0$
- 偏置还原：$w_0 = w_0^{\text{norm}} - \sum_{j=1}^{3} w_j \cdot \min(x_j)$

## 输入格式

- 第一行：整数 $m$（样本数量，$[1, 10000]$）
- 第二行：整数 $N$（迭代次数，$[1, 1000]$）
- 第三行：浮点数 $\alpha$（学习率，$[0, 1]$，保留2位小数）
- 后续 $m$ 行：每行4个整数 $x_1, x_2, x_3, y$

## 输出格式

- 一行，4个浮点数，依次为还原后的 $w_0, w_1, w_2, w_3$，结果保留2位小数，银行家舍入

## 解题思路

### 要交的是原始尺度上的四个权重

题目要的输出不是训练过程中的那组权重，而是**还原后**的 $w_0,w_1,w_2,w_3$。训练在归一化空间进行，归一化把 $x_j$ 换成 $(x_j-\min_j)/(\max_j-\min_j)$，于是训练得到的 $w_j^{\text{norm}}$ 与原始尺度的 $w_j$ 差一个缩放，偏置还差一个平移。最后一步必须把这两处换算补上，只把训练循环写对、还原写错，输出照样是错的。

另外，迭代次数 $N$ 是输入的一部分，不是「跑到收敛为止」。本题的答案是「恰好做完 $N$ 轮全量更新」时的那组权重，多一轮少一轮数值都不同，所以循环只能写成 `for _ in range(N)`。

### 先归一化：原始尺度下，一步就跨过头

梯度里每一项都乘着对应的 $x_j$。样例 1 的 $x$ 是 $10^2$~$10^3$ 量级、误差是 $10^3$~$10^4$ 量级，乘出来的步长能到 $10^5$，比要拟合的 $y$（几千）还大一个数量级：第一步就跨过最优点，第二轮误差更大，如此正反馈下去。同时 $x_1$ 最大 300、$x_3$ 最小 60，特征之间也差着几倍到十几倍，同一组 $\alpha$ 本来就没法同时合适。

拿样例 1 的数据、按题面的更新式**不做归一化**跑一遍，能直接看到后果：

| 轮次 | $w_0$ | $w_1$ | $w_2$ | $w_3$ |
|---|---|---|---|---|
| 1 | 666.67 | 1.35e5 | 2.55e5 | 1.93e5 |
| 2 | -1.70e7 | -3.32e9 | -1.00e10 | -7.55e9 |
| 100 | nan | nan | nan | nan |

$w_1\sim w_3$ 第 1 轮就冲到十万量级，第 100 轮浮点溢出成 `nan`。把每个特征压到 $[0,1]$ 之后，三个特征的梯度量级接近，同一组 $(N,\alpha)$ 才能一起往下走。

```python
min_x1, max_x1 = min(x1_vals), max(x1_vals)
min_x2, max_x2 = min(x2_vals), max(x2_vals)
min_x3, max_x3 = min(x3_vals), max(x3_vals)

def normalize(val, min_val, max_val):
    if max_val == min_val:
        return 0.0
    return (val - min_val) / (max_val - min_val)
```

只归一化三个特征，$y$ 保持原值。损失函数算的是原始单位下的误差；如果把 $y$ 也缩到 $[0,1]$，训练目标就换成了另一个量，而题面只给了 $w$ 的还原公式，没有给 $y$ 的逆变换。

当某个特征的所有样本取值相同（$\max=\min$）时，它在归一化空间里恒为 0，对预测没有任何贡献，按题面归一化成 0；对应的权重在还原时也规定为 0。

### 一轮 BGD：把 m 个误差加完，再更新一次

损失是 $L=\frac{1}{2m}\sum_i(\hat y_i-y_i)^2$，对某个权重求偏导，链式法则把 $\hat y$ 对 $w_j$ 的导数 $x_{ij}$ 带出来：

$$
\frac{\partial L}{\partial w_j}
= \frac{1}{m}\sum_{i=1}^{m}(\hat y_i - y_i)\,x_{ij}
$$

偏置的「特征」是常数 $x_{i0}=1$，所以 $w_0$ 的梯度就是误差的平均值。**批量**的含义在这一步：这一轮里 $m$ 个样本的误差都用**同一组** $w$ 算出来，全部累加完才更新一次。如果在样本循环内部就更新 $w$，后面的样本会用上新权重，那是 SGD，走的轨迹和最终答案都不一样。

```python
w = [0.0, 0.0, 0.0, 0.0]

for _ in range(N):
    grad = [0.0, 0.0, 0.0, 0.0]
    for nx1, nx2, nx3, y_true in norm_samples:
        y_pred = w[0] + w[1] * nx1 + w[2] * nx2 + w[3] * nx3
        error = y_pred - y_true
        grad[0] += error * 1.0      # 偏置：x0 = 1
        grad[1] += error * nx1
        grad[2] += error * nx2
        grad[3] += error * nx3
    for j in range(4):
        w[j] -= alpha * (grad[j] / m)
```

初始权重全为 0（题面规定），所以第一轮每个样本的预测都是 0，误差就是 $-y_i$，这也让第一轮的梯度可以直接手算（见示例推演）。

### 还原：把归一化空间的直线换回原始坐标

记 $s_j=\max_j-\min_j$，训练出的那组权重记作 $w_j'$。归一化空间里的预测是

$$
\hat y = w_0' + \sum_j w_j'\cdot\frac{x_j-\min_j}{s_j}
      = \Bigl(w_0' - \sum_j \frac{w_j'\min_j}{s_j}\Bigr) + \sum_j \frac{w_j'}{s_j}\,x_j
$$

要和原始模型 $\hat y = w_0 + \sum_j w_j x_j$ 表示同一条直线，两边的系数必须逐项相等：

$$
w_j = \frac{w_j'}{s_j},\qquad w_0 = w_0' - \sum_j w_j \min_j
$$

这正是代码里那几行：先按跨度把三个特征权重量回来，再用**还原后**的 $w_j$ 和原始 $\min_j$ 修正偏置。

```python
# 跨度不为 0 时按下面的式子还原；跨度等于 0 时按题面规定 wj = 0（完整代码里写成了 if/else）
w1 = w1_norm / (max_x1 - min_x1)
w2 = w2_norm / (max_x2 - min_x2)
w3 = w3_norm / (max_x3 - min_x3)
w0 = w[0] - (w1 * min_x1 + w2 * min_x2 + w3 * min_x3)
```

输出用 `f"{x:.2f}"`，Python 的定点格式化就是银行家舍入（正好落在两个可表示值中间时取偶数），与题面要求一致。

## 完整代码实现

```python
"""
第2题-路由器资源用量预测 - 批量梯度下降(BGD)线性回归

输入格式：
- 第1行：整数 m（样本数量）
- 第2行：整数 N（迭代次数）
- 第3行：浮点数 alpha（学习率）
- 接下来 m 行：每行4个整数 x1 x2 x3 y

输出格式：
- 一行4个浮点数 w0 w1 w2 w3，保留2位小数
"""

import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    m = int(next(it))
    N = int(next(it))
    alpha = float(next(it))
    samples = []
    x1_vals, x2_vals, x3_vals = [], [], []
    for _ in range(m):
        x1 = float(next(it))
        x2 = float(next(it))
        x3 = float(next(it))
        y = float(next(it))
        samples.append([x1, x2, x3, y])
        x1_vals.append(x1)
        x2_vals.append(x2)
        x3_vals.append(x3)

    # 计算每个特征的最小最大值
    min_x1, max_x1 = min(x1_vals), max(x1_vals)
    min_x2, max_x2 = min(x2_vals), max(x2_vals)
    min_x3, max_x3 = min(x3_vals), max(x3_vals)

    # 归一化特征
    def normalize(val, min_val, max_val):
        if max_val == min_val:
            return 0.0
        return (val - min_val) / (max_val - min_val)

    norm_samples = []
    for x1, x2, x3, y in samples:
        nx1 = normalize(x1, min_x1, max_x1)
        nx2 = normalize(x2, min_x2, max_x2)
        nx3 = normalize(x3, min_x3, max_x3)
        norm_samples.append([nx1, nx2, nx3, y])

    # 初始化权重 [w0, w1, w2, w3]
    w = [0.0, 0.0, 0.0, 0.0]

    # 批量梯度下降
    for _ in range(N):
        grad = [0.0, 0.0, 0.0, 0.0]
        for nx1, nx2, nx3, y_true in norm_samples:
            y_pred = w[0] + w[1] * nx1 + w[2] * nx2 + w[3] * nx3
            error = y_pred - y_true
            grad[0] += error * 1.0
            grad[1] += error * nx1
            grad[2] += error * nx2
            grad[3] += error * nx3
        for j in range(4):
            w[j] -= alpha * (grad[j] / m)

    # 权重还原
    w1_norm, w2_norm, w3_norm = w[1], w[2], w[3]
    if max_x1 != min_x1:
        w1 = w1_norm / (max_x1 - min_x1)
    else:
        w1 = 0.0
    if max_x2 != min_x2:
        w2 = w2_norm / (max_x2 - min_x2)
    else:
        w2 = 0.0
    if max_x3 != min_x3:
        w3 = w3_norm / (max_x3 - min_x3)
    else:
        w3 = 0.0
    w0 = w[0] - (w1 * min_x1 + w2 * min_x2 + w3 * min_x3)

    print(f"{w0:.2f} {w1:.2f} {w2:.2f} {w3:.2f}")

if __name__ == "__main__":
    main()
```

## 示例推演

### 示例 1：从归一化到权重还原

$m=3$，$N=100$，$\alpha=0.10$。

**第一步，算每个特征的跨度：**

| 特征 | $\min$ | $\max$ | $s=\max-\min$ |
|---|---|---|---|
| $x_1$ | 100 | 300 | 200 |
| $x_2$ | 70 | 800 | 730 |
| $x_3$ | 60 | 600 | 540 |

**第二步，归一化**（$y$ 不动）：

| 样本 | $x_1'$ | $x_2'$ | $x_3'$ | $y$ |
|---|---|---|---|---|
| 1 | $(100-100)/200=0$ | $(200-70)/730=0.1781$ | $(150-60)/540=0.1667$ | 6000 |
| 2 | $(200-100)/200=0.5$ | $(800-70)/730=1$ | $(600-60)/540=1$ | 7500 |
| 3 | $(300-100)/200=1$ | $(70-70)/730=0$ | $(60-60)/540=0$ | 6500 |

**第 1 轮**：$w=[0,0,0,0]$，三个误差分别是 $-6000,-7500,-6500$。每个梯度的分母都是 $m=3$：

| 权重 | 累加式 | 平均梯度 | 更新后 |
|---|---|---|---|
| $w_0$ | $(-6000)+(-7500)+(-6500)$ | $-6666.67$ | $666.67$ |
| $w_1$ | $0\cdot(-6000)+0.5\cdot(-7500)+1\cdot(-6500)$ | $-3416.67$ | $341.67$ |
| $w_2$ | $0.1781\cdot(-6000)+1\cdot(-7500)+0\cdot(-6500)$ | $-2856.16$ | $285.62$ |
| $w_3$ | $0.1667\cdot(-6000)+1\cdot(-7500)+0\cdot(-6500)$ | $-2833.33$ | $283.33$ |

**第 2 轮**：先用上一轮的权重算预测值，再累加：

| 样本 | $\hat y$ | 误差 $\hat y-y$ |
|---|---|---|
| 1 | $666.67+285.62\times0.1781+283.33\times0.1667=764.75$ | $-5235.25$ |
| 2 | $666.67+170.83+285.62+283.33=1406.45$ | $-6093.55$ |
| 3 | $666.67+341.67=1008.33$ | $-5491.67$ |

平均梯度依次是 $-5606.82$、$-2846.15$、$-2341.95$、$-2322.03$，减掉 $\alpha=0.1$ 倍之后：

$$
w=[1227.35,\ 626.28,\ 519.81,\ 515.54]
$$

**第 100 轮结束后**，归一化空间的权重是

$$
w'=[5254.1330,\ 1364.5220,\ 879.6143,\ 836.3836]
$$

**第三步，还原**：

$$
\begin{aligned}
w_1 &= 1364.5220/200 = 6.822610\\
w_2 &= 879.6143/730 = 1.204951\\
w_3 &= 836.3836/540 = 1.548858\\
w_0 &= 5254.1330 - (6.822610\times100 + 1.204951\times70 + 1.548858\times60)\\
    &= 5254.1330 - 859.5391 = 4394.5939
\end{aligned}
$$

保留两位小数：`4394.59 6.82 1.20 1.55`。

### 示例 2：min 全为 0 时，偏置还原是空操作

$m=2$，$N=50$，$\alpha=0.05$。两个样本归一化后是 $(0,0,0)$ 配 $y=0$、$(1,1,1)$ 配 $y=100000$，跨度分别是 $1000$、$10000$、$100$。

**第 1 轮**：预测都是 0，误差是 $0$ 和 $-100000$，平均梯度 $-50000$，四个权重一起变成 $2500$。

**第 2 轮**：第一个样本预测 $2500$、误差 $2500$；第二个预测 $4\times2500=10000$、误差 $-90000$。

| 权重 | 累加式 | 平均梯度 | 更新后 |
|---|---|---|---|
| $w_0$ | $2500+(-90000)$ | $-43750$ | $4687.5$ |
| $w_1,w_2,w_3$ | $0\cdot2500+1\cdot(-90000)$ | $-45000$ | $4750$ |

50 轮之后 $w'=[11419.3336,\ 28261.7737,\ 28261.7737,\ 28261.7737]$。三个特征的 $\min$ 都是 0，所以 $w_0=w_0'=11419.33$；而三个权重虽然是同一个数，还原后完全不同：

$$
w_1=\frac{28261.7737}{1000}=28.26,\quad
w_2=\frac{28261.7737}{10000}=2.83,\quad
w_3=\frac{28261.7737}{100}=282.62
$$

归一化空间的权重不能直接当答案：它的大小取决于各自被压缩了多少倍。

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|---|---|---|---|
| 不归一化直接 BGD | O(N · m) | O(m) | 每轮计算量相同，但梯度被特征量级放大，样例 1 第 2 轮就到 1e10，第 100 轮溢出成 nan |
| 归一化 + BGD（最优） | O(N · m) | O(m) | 归一化扫一遍 O(m)；之后 N 轮、每轮对 m 个样本做常数次乘加 |

## 易错点总结

1. **更新时忘了除以 $m$**：`w[j] -= alpha * (grad[j] / m)` 里去掉 `/ m`，相当于把学习率放大 $m$ 倍（样例 1 是 3 倍）。样例 1 的输出会变成 `5166.74 4.02 1.00 1.24`，四个数全错，而程序不报错。
2. **偏置还原写成 `w0 = w[0]`**：样例 1 里 $w_0'=5254.13$，原始尺度的 $w_0$ 是 $4394.59$，差的就是 $\sum_j w_j\min_j=859.54$。输出第一项是 `5254.13`、后三项却正确，这种「只错一项」很容易被当成舍入误差看漏。
3. **还原时把跨度写成 $\max$**：`w1 = w1_norm / max_x1` 在样例 1 里给 $1364.5220/300=4.55$，输出变成 `4754.73 5.38 1.15 1.46`。归一化减的是 $\min$，还原就必须除 $\max-\min$，两处必须用同一个跨度。
