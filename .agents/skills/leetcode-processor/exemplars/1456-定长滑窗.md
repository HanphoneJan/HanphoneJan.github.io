# 范文：定长子串中元音的最大数目（1456）

- 作者：endlesscheng（灵茶山艾府）· 531 赞
- 原文：https://leetcode.cn/problems/maximum-number-of-vowels-in-a-substring-of-given-length/solutions/2809359/tao-lu-jiao-ni-jie-jue-ding-chang-hua-ch-fzfo
- 学什么：**把一个具体做法上升成三步套路，并让代码编号与套路对齐**

## 骨架

| 节 | 这一节在干什么 | 为什么在这个位置 |
|---|---|---|
| `## 核心思想` | 暴力枚举是 $O(nk)$，太慢；能不能 $O(1)$ 算出下一个窗口？→ 相邻窗口只差「进一个、出一个」 | 先给一句**能验证的关键观察**，后面全部靠它 |
| `## 举例` | 用示例 1 走 9 步，每步写「进 X → 元音数 → 更新答案 → 出 Y」 | 观察先用具体数字兑现一遍，读者才信 |
| `## 定长滑窗套路` | 把刚才的走法抽象成三步：**入—更新答案—出**，并逐条说明每步为什么、边界是什么 | 抽象放在具体之后，而且只抽一次 |
| `## 答疑` | 一个问题：右端点是 $i$ 时，左端点为什么是 $i-k+1$ | 只答「读者真的会卡住的那一处」，不是知识点清单 |
| （代码） | 注释就是 `# 1. 右端点进入窗口` / `# 2. 更新答案` / `# 3. 左端点离开窗口` | 编号与套路的 1/2/3 完全一致 |
| `## 优化` | 答案上限是 $k$，到了就 `break` | 有增量才写，没有就不写 |
| `#### 复杂度分析` | 两句：$O(n)$、$O(1)$ | 一句话说清，不列表格 |

## 可借的三处

1. **抽象只做一次，而且给出名字。** 原文：

   > 我总结成三步：**入-更新答案-出**。

   名字一给，代码注释、举例、答疑全部可以引用它，读者不用记第二套说法。

2. **边界写在步骤里，不另起一节。** 三步中的第一步末尾就是边界：

   > 如果窗口左端点 $i-k+1<0$，说明尚未形成第一个窗口，重复第一步。

   代码里对应 `if left < 0: continue`。**边界 = 某个步骤的一个分支**，所以它长在步骤里。

3. **离开窗口后长度是 $k-1$，这句必须说。** 原文专门加了个注：

   > **注**：元素离开窗口后，窗口长度为 $k-1$。下一轮循环元素进入窗口后，窗口长度为 $k$。

   这是「三步」最容易讲错的地方（读者会以为循环体结束时窗口还是 $k$）。
