# 范文：最大化区间选数的最小差值（3281）

- 作者：endlesscheng（灵茶山艾府）
- 原文：https://leetcode.cn/problems/maximize-score-of-numbers-in-ranges/solutions/2908931/er-fen-da-an-zui-da-hua-zui-xiao-zhi-pyt-twe2
- 学什么：**判定函数与「二分该往哪边走」绑在一起讲**

## 骨架

| 节 | 这一节在干什么 | 为什么在这个位置 |
|---|---|---|
| `## 题意` | 一句话把题目说成人话：每个区间选一个数，让任意两数之差的最小值尽量大 | 题面有 $n$、$d$、得分三层概念，先压成一句 |
| `## 二分答案` | 为什么能二分：得分越大越难放；顺带一句「看到最大化最小值就想二分」；再说明为什么要先排序（只需看相邻） | **先立「能二分」，再谈怎么写** |
| `## 贪心` | 判定函数：$x_i=\max(x_{i-1}+\text{score},\ \text{start}[i])$，超过 `start[i]+d` 就不可行 | 判定是这类题的全部难点，所以单开一节写透 |
| `## 细节` | 开区间写法为什么省掉 $\pm 1$；区间端点怎么定（下界 0，上界平均值 +1）；用 $-\infty$ 省掉第一个区间的特判 | 写法细节集中在代码前一节，不进「易错点」 |
| （代码） | 就是 `## 贪心` 里那两行公式 | 公式与代码一一对应，读者不用二次翻译 |
| `#### 复杂度分析` | $O(n\log n + n\log A)$，说清每一项来自哪 | |

## 可借的三处

1. **判定和二分边界是同一段话。** 原文讲完 $x_i$ 的递推，紧接着：

   > 如果第二个数 $x_1 = x_0+\text{score}$ 超过了区间右端点 $\text{start}[1] + d$，那么 $\text{score}$ 太大了，应当减小二分的右边界 $\text{right}$。

   判定返回 `False` 之后要动哪一侧，就在讲判定的那一句里说掉，不留给「易错点」回收。

2. **「至少」不是「恰好」，这层要说破。** 原文专门用一段（带 ⚠️）强调这一点，大意是：判定里要求的是「两数之差的最小值**至少**为 score」，而不是恰好等于；因为二分会不断收紧范围，最终落在「最小差值恰好等于 score」的位置上。

   这正是读者会卡住的概念点：判定写「至少」，答案却要「最大」，两者怎么统一 —— 一句话讲完。

3. **写法选择给出理由，而不是只给代码。** 原文：

   > 对于开区间写法，简单来说 `check(mid) == true` 时更新的是谁，最后就返回谁。相比其他二分写法，开区间写法不需要思考加一减一等细节，更简单。

   「为什么用这个模板」比「这个模板长什么样」更省读者的调试时间。
