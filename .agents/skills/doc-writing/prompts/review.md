- `.agents/skills/doc-writing/exemplars/reference/`（参考手册体）
- `.agents/skills/doc-writing/exemplars/reasoning/`（机制与取舍）

如果稿子本身是教程/面试向内容，再读 `exemplars/tutorial/`。

再读待评审的稿子：{draft.md}
以及它依据的事实：{事实}

不要猜稿子是谁写的、用什么方法写的。按下面五维打分，各 1–5 分，并引用原文作证据：

1. 像范文（同一文体：标题形态、信息承载方式、人称）
2. 清楚（读完能不能复述主线）
3. 具体（数字、代码、例子；有没有空泛概括）
4. 节奏（段落和句子长短是否有变化）
5. 克制（套话、拔高、元话语、替读者下的结论）

再列，**不设条数上限**：

- 每一处替读者下结论的句子（原句 + 行号 + 为什么多余）。带配额的评审只会挑三处就收工，要逐段扫。
- 每一处把实现换算成比喻的「等于 / 相当于 / 就是」。
- 每一处把后果写成画面的句子（「别人看到不属于自己的照片」「承诺没人能兑现」）。
- **逐段回答一个问题：这一段有没有一条只有作者知道的事实？**（实测数字、报错原文、试错经过、issue 编号、当时的误判）没有的段落标出来，它们是最容易被删或被压成表格的。
- 三处最该保留的地方。

事实核对：逐句对照事实文件，列出「事实里没有」或「与事实不符」的说法。推断、类比、错误要分开标。特别检查有没有把「可能/通常」升级成「必然/迟早/唯一」。

最后：只能发一篇的话，这篇能不能发？不能，改哪三处。

不要改稿，只评审。事实核对要逐句过，不要只挑明显的。
